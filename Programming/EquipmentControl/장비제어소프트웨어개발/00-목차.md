[다음: 1장. C# 기반 장비 제어 시스템 개요 ▶](ch01-CSharp기반장비제어시스템개요.md)

산업 현장의 PC 기반 장비 제어(반도체·디스플레이·자동화 설비 등) 소프트웨어를 C#/.NET으로
개발하는 실무 엔지니어를 위한 전문서입니다. 레이어드 아키텍처 설계부터 비동기/멀티스레딩,
하드웨어 통신, 모션/I/O 제어, 상태 머신과 시퀀스 설계, WPF/MVVM 기반 HMI, 알람·레시피·데이터
관리, SECS/GEM과 머신비전 연동, 시스템 최적화와 현장 셋업까지 실전 수준으로 다룹니다.

각 장은 개념 설명, 실전 C# 예제 코드, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는 이해를
돕는 다이어그램을 함께 실었습니다.

## 학습 방법 제안

1. 이 책은 입문서가 아니라 전문서이므로, 최소한 C#의 클래스/인터페이스/제네릭과 비동기 프로그래밍 기초를 알고 있는 상태에서 시작하는 것을 권장합니다.
2. 각 장의 예제 코드는 실제 하드웨어 없이도 9장의 가상 장비 시뮬레이터 개념을 먼저 적용해 구조를 이해한 뒤, 실제 보드/필드버스 SDK로 교체하는 순서로 학습하면 좋습니다.
3. 장 끝의 연습문제를 풀어보면서 이해도를 점검하세요.
4. 5장(FSM/시퀀스)과 2장(비동기/동시성)은 이 책 전체의 근간이 되는 내용이므로 특히 꼼꼼히 읽어보세요.
5. 9장까지 마친 뒤에는 부록의 API 요약표와 개발 환경 체크리스트를 실전 프로젝트 착수 시 참조용으로 활용하세요.
