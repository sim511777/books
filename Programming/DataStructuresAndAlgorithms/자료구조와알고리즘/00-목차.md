# 자료구조와 알고리즘

[다음: 1장. 자료구조와 알고리즘을 배우는 이유 ▶](ch01-자료구조와알고리즘을배우는이유.md)

---

프로그래밍 경험은 있지만 자료구조와 알고리즘을 체계적으로 배운 적은 없는 사람을 위한 입문서입니다.
Big-O 표기법부터 배열, 연결 리스트, 트리, 힙, 해시 테이블, 그래프, 정렬과 탐색, 재귀와
동적 프로그래밍까지 핵심 개념을 순서대로 다룹니다. 모든 예제 코드는 C#으로 작성했으며,
각 자료구조/알고리즘을 직접 구현해본 뒤 .NET BCL(표준 클래스 라이브러리)에 대응하는
실제 클래스가 있다면 함께 소개합니다.

각 장은 개념 설명, 직접 구현하는 C# 코드, (해당하는 경우) BCL 대응 클래스 소개, 요약,
연습문제로 구성되어 있으며, 필요한 곳에는 이해를 돕는 다이어그램을 함께 실었습니다.
