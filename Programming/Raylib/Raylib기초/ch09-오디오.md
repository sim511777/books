# 9장. 오디오

[◀ 이전: 8장. 충돌 감지](ch08-충돌감지.md) | [📖 목차](00-목차.md) | [다음: 10장. 폰트와 텍스트 렌더링 ▶](ch10-폰트와텍스트렌더링.md)


지금까지 만든 예제들은 전부 눈으로 보는 것에만 집중했습니다. 하지만 게임에서 소리가 빠지면 아무리 그래픽이 화려해도 완성도가 확 떨어져 보입니다. 총을 쐈는데 "탕" 소리가 안 나거나, 배경음악 없이 조용한 화면만 이어진다면 플레이어는 뭔가 허전함을 느낄 수밖에 없습니다.

raylib은 오디오 재생을 위한 기능도 그래픽 API 못지않게 간단하게 제공합니다. 이번 장에서는 짧은 효과음을 재생하는 `Sound`와 긴 배경음악을 재생하는 `Music`의 차이를 이해하고, 실제로 소리를 내는 방법을 배웁니다.

## 9.1 오디오 장치 초기화하기

raylib에서 소리를 재생하려면 가장 먼저 오디오 장치를 초기화해야 합니다. 2장에서 창을 열 때 `InitWindow()`를 호출했던 것처럼, 오디오를 쓰려면 `InitAudioDevice()`를 호출해야 합니다.

```c
#include "raylib.h"

int main(void)
{
    InitWindow(800, 450, "raylib 오디오 예제");
    InitAudioDevice();

    // ... 사운드 로드, 게임 루프 ...

    CloseAudioDevice();
    CloseWindow();

    return 0;
}
```

`InitAudioDevice()`는 프로그램 시작 시 딱 한 번, 보통 `InitWindow()` 바로 다음 줄에서 호출합니다. 그리고 프로그램을 종료하기 직전에는 반드시 `CloseAudioDevice()`를 호출해서 오디오 장치를 정리해줘야 합니다.

호출 순서도 중요합니다. `InitAudioDevice()`를 호출하기 전에 `LoadSound()`나 `LoadMusicStream()`을 먼저 호출하면 오디오 장치가 아직 준비되지 않은 상태이므로 소리가 로드되지 않거나 재생되지 않습니다. 항상 "오디오 장치 초기화 → 사운드/음악 로드 → 재생 → 언로드 → 오디오 장치 닫기" 순서를 지켜주세요.

## 9.2 짧은 효과음 재생하기: Sound

점프 소리, 타격 소리, 버튼 클릭음처럼 길이가 짧고 자주 재생되는 소리는 `Sound` 타입으로 다룹니다.

```c
Sound jumpSound = LoadSound("resources/jump.wav");

// 게임 루프 안에서
if (IsKeyPressed(KEY_SPACE))
{
    PlaySound(jumpSound);
}

// 프로그램 종료 전
UnloadSound(jumpSound);
```

`Sound`의 핵심 특징은 **파일 전체를 한 번에 메모리에 올려둔다**는 점입니다. `LoadSound()`를 호출하는 순간 오디오 파일의 압축이 풀려 PCM 데이터 전체가 메모리에 적재됩니다. 그래서 `PlaySound()`를 호출하면 별도의 디코딩 과정 없이 즉시 재생을 시작할 수 있습니다. 지연 없이 바로 소리가 나야 하는 효과음에 딱 맞는 방식이죠.

다만 이 방식은 파일이 클수록 메모리를 많이 잡아먹습니다. 몇 초짜리 효과음이라면 문제없지만, 몇 분짜리 배경음악을 `Sound`로 로드하면 메모리 낭비가 심해집니다. 그래서 raylib은 긴 음악을 위한 별도의 타입을 제공하는데, 이는 9.3절에서 다루겠습니다.

`Sound` 관련 주요 함수를 정리하면 다음과 같습니다.

```c
Sound LoadSound(const char *fileName);       // 파일에서 사운드 로드
void UnloadSound(Sound sound);               // 사운드 메모리 해제
void PlaySound(Sound sound);                 // 재생
void StopSound(Sound sound);                 // 즉시 정지
void PauseSound(Sound sound);                // 일시정지
void ResumeSound(Sound sound);               // 재개
bool IsSoundPlaying(Sound sound);            // 재생 중인지 확인
void SetSoundVolume(Sound sound, float volume); // 볼륨 설정 (0.0f ~ 1.0f)
void SetSoundPitch(Sound sound, float pitch);   // 음높이 설정 (1.0f가 기본)
void SetSoundPan(Sound sound, float pan);       // 좌우 스테레오 위치 (0.0f 왼쪽 ~ 1.0f 오른쪽)
```

`IsSoundPlaying()`은 예를 들어 "이 효과음이 끝날 때까지 다른 동작을 막고 싶다"는 상황에서 유용합니다.

## 9.3 배경음악 재생하기: Music

배경음악처럼 몇 분씩 이어지는 긴 오디오는 `Music` 타입을 사용합니다.

```c
Music bgm = LoadMusicStream("resources/theme.ogg");
PlayMusicStream(bgm);

while (!WindowShouldClose())
{
    UpdateMusicStream(bgm);  // 반드시 매 프레임 호출!

    BeginDrawing();
        ClearBackground(RAYWHITE);
        DrawText("배경음악 재생 중...", 190, 200, 20, LIGHTGRAY);
    EndDrawing();
}

UnloadMusicStream(bgm);
```

### 실전 함정: UpdateMusicStream을 잊지 마세요

`Music`은 `Sound`와 동작 방식이 근본적으로 다릅니다. `LoadMusicStream()`은 파일 전체를 메모리에 올리지 않습니다. 대신 파일을 조금씩 읽어와 재생 버퍼를 채우는 **스트리밍** 방식으로 동작합니다. 이 방식 덕분에 몇십 MB짜리 음악 파일도 메모리를 거의 쓰지 않고 재생할 수 있습니다.

그런데 스트리밍이라는 것은 누군가 계속해서 "다음 데이터를 버퍼에 채워 넣어라"라고 지시해줘야 한다는 뜻입니다. 그 역할을 하는 함수가 바로 `UpdateMusicStream(music)`이고, 이걸 **매 프레임 게임 루프 안에서** 호출해줘야 합니다.

만약 `UpdateMusicStream()`을 호출하지 않으면 어떻게 될까요? `PlayMusicStream()`을 호출한 직후에는 잠깐 소리가 나다가, 미리 채워둔 버퍼가 소진되는 순간 음악이 끊기거나 완전히 멈춰버립니다. 처음 raylib으로 오디오를 다루는 사람들이 가장 많이 겪는 실수가 바로 이겁니다. "분명 `PlayMusicStream()`을 호출했는데 몇 초 만에 음악이 멈춘다"는 문제가 생긴다면, 십중팔구 게임 루프 어딘가에서 `UpdateMusicStream()` 호출이 빠졌거나, `BeginDrawing()`/`EndDrawing()` 사이처럼 매 프레임 실행되지 않는 조건문 안에 잘못 들어가 있는 경우입니다.

정리하면 이렇습니다.

| | Sound | Music |
|---|---|---|
| 로딩 방식 | 파일 전체를 메모리에 적재 | 스트리밍(조금씩 디코딩) |
| 용도 | 짧고 즉각적인 효과음 | 길게 재생되는 배경음악 |
| 매 프레임 호출 필요 | 없음 | `UpdateMusicStream()` 필수 |

`Music` 관련 주요 함수는 다음과 같습니다.

```c
Music LoadMusicStream(const char *fileName);
void UnloadMusicStream(Music music);
void PlayMusicStream(Music music);
void UpdateMusicStream(Music music);         // 매 프레임 호출
bool IsMusicStreamPlaying(Music music);
void StopMusicStream(Music music);
void PauseMusicStream(Music music);
void ResumeMusicStream(Music music);
void SeekMusicStream(Music music, float position); // 초 단위로 재생 위치 이동
void SetMusicVolume(Music music, float volume);
float GetMusicTimeLength(Music music);       // 전체 길이(초)
float GetMusicTimePlayed(Music music);       // 현재까지 재생된 시간(초)
```

`GetMusicTimePlayed()`와 `GetMusicTimeLength()`를 조합하면 음악 재생 진행률을 표시하는 프로그레스 바도 쉽게 만들 수 있습니다.

```c
float played = GetMusicTimePlayed(bgm);
float total = GetMusicTimeLength(bgm);
float ratio = played / total;

DrawRectangle(20, 20, (int)(200 * ratio), 10, GREEN);
DrawRectangleLines(20, 20, 200, 10, DARKGRAY);
```

## 9.4 볼륨 조절과 여러 효과음 동시 재생

`SetSoundVolume()`과 `SetMusicVolume()`은 각각 개별 사운드와 음악의 볼륨을 0.0f(무음)에서 1.0f(최대) 사이로 조절합니다. 보통 옵션 메뉴에서 "효과음 볼륨"과 "배경음악 볼륨"을 따로 조절하게 만드는데, 이때 두 함수를 구분해서 쓰면 됩니다.

```c
SetSoundVolume(jumpSound, 0.7f);
SetMusicVolume(bgm, 0.5f);
```

전체 오디오 출력 자체의 볼륨을 한 번에 조절하고 싶다면 `SetMasterVolume(float volume)`을 사용합니다. 이 값은 개별 사운드/음악 볼륨에 곱해져 최종 출력에 반영됩니다.

### 같은 효과음을 여러 번 겹쳐 재생하기

총알이 연속으로 발사되는 슈팅 게임을 만든다고 해봅시다. 총소리 `Sound`를 하나만 로드해두고 발사할 때마다 `PlaySound()`를 호출하면, 이전 총소리가 채 끝나기도 전에 다음 총소리가 재생을 시작하는 경우가 자주 생깁니다. 이럴 때 같은 `Sound` 인스턴스에 대해 `PlaySound()`를 연속 호출하면 재생 중이던 소리가 끊기고 처음부터 다시 재생되는 것처럼 들릴 수 있습니다. 하나의 `Sound`는 내부적으로 재생 채널을 한 개만 관리하기 때문입니다.

같은 효과음을 여러 번 겹쳐서(동시에) 재생하고 싶다면 `LoadSoundAlias()`로 원본 사운드의 별칭을 만들어 재생하는 방법을 씁니다. 별칭은 원본과 오디오 데이터를 공유하면서도 독립적인 재생 상태를 가집니다.

```c
Sound shotAlias = LoadSoundAlias(shotSound);
PlaySound(shotAlias);
// ...
UnloadSoundAlias(shotAlias);
```

간단한 프로토타입 단계에서는 총소리마다 매번 `LoadSoundAlias()`/`UnloadSoundAlias()`를 호출하기보다, 같은 효과음을 미리 몇 개(예: 4~8개) 로드해두고 번갈아 재생하는 방식으로도 충분히 자연스러운 결과를 얻을 수 있습니다. 프로젝트의 규모와 요구사항에 맞춰 적절한 방식을 선택하면 됩니다.

또 한 가지 주의할 점은, 사운드와 음악 파일도 결국 6장에서 다룬 텍스처와 마찬가지로 로드한 개수만큼 반드시 언로드해줘야 한다는 것입니다. `LoadSound()`로 로드한 횟수와 `UnloadSound()`를 호출한 횟수가 맞지 않으면 메모리 누수로 이어집니다. 여러 개의 사운드와 음악을 관리해야 하는 프로젝트라면 구조체 배열이나 별도의 리소스 관리자를 만들어 로드와 언로드를 짝지어 관리하는 습관을 들이는 것이 좋습니다.

## 요약

- 오디오를 사용하려면 `InitWindow()` 이후 `InitAudioDevice()`를 한 번 호출해야 하고, 프로그램 종료 전에는 `CloseAudioDevice()`로 정리해야 합니다.
- `Sound`는 짧은 효과음에 적합하며, 파일 전체를 메모리에 미리 올려두기 때문에 `PlaySound()` 호출 즉시 재생이 시작됩니다.
- `Music`은 긴 배경음악에 적합하며, 파일을 조금씩 읽어오는 스트리밍 방식으로 동작합니다. `PlayMusicStream()`으로 재생을 시작한 뒤에는 **매 프레임 `UpdateMusicStream()`을 호출**해야 스트리밍이 끊기지 않습니다.
- `SetSoundVolume()`, `SetMusicVolume()`으로 개별 볼륨을, `SetMasterVolume()`으로 전체 볼륨을 조절할 수 있습니다.
- 같은 효과음을 동시에 여러 번 겹쳐 재생하려면 `LoadSoundAlias()`로 별칭을 만들어 재생합니다.
- 로드한 `Sound`와 `Music`은 각각 `UnloadSound()`, `UnloadMusicStream()`으로 반드시 해제해야 합니다.

## 연습문제

1. `InitAudioDevice()`를 호출하지 않은 상태에서 `LoadSound()`와 `PlaySound()`를 호출하면 어떤 문제가 생기는지 직접 코드를 작성해서 확인해보세요.
2. 배경음악을 재생하는 프로그램을 작성하되, 일부러 게임 루프 안에서 `UpdateMusicStream()` 호출을 빼보세요. 몇 초 후 어떤 현상이 나타나는지 관찰하고, 그 이유를 `Sound`와 `Music`의 로딩 방식 차이와 연결지어 설명해보세요.
3. 방향키를 누를 때마다 서로 다른 효과음 4종(위/아래/왼쪽/오른쪽)이 재생되는 프로그램을 만들어보세요.
4. 스페이스바를 빠르게 연타할 때 총소리가 자연스럽게 겹쳐 들리도록 `LoadSoundAlias()`를 활용한 프로그램을 작성해보세요.
5. `GetMusicTimePlayed()`와 `GetMusicTimeLength()`를 이용해 현재 재생 중인 배경음악의 진행률을 화면 하단에 프로그레스 바로 표시해보세요.
