# raylib로 배우는 게임 프로그래밍

[다음: 1장. raylib란 무엇인가 ▶](ch01-raylib란무엇인가.md)

---

C 언어 기반의 간단하고 빠른 게임/그래픽스 라이브러리 raylib 입문서입니다. 창을 띄우고 도형을
그리는 기초부터 입력 처리, 텍스처와 애니메이션, 충돌 감지, 오디오, 2D/3D 카메라, 셰이더,
게임 상태 관리, 파티클, 세이브/로드, 실전 미니 게임 제작까지 순서대로 다룹니다.

각 장은 개념 설명, C 예제 코드, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는 이해를 돕는
다이어그램을 함께 실었습니다.

## 학습 방법 제안

1. 각 장의 예제 코드를 직접 컴파일·실행하며 결과를 눈으로 확인하세요. 게임 프로그래밍은 특히 직접 움직여봐야 감이 잡힙니다.
2. 장 끝의 연습문제를 풀어보면서 이해도를 점검하세요.
3. 2~11장(2D 기초)을 충분히 익힌 뒤 12~14장(3D)으로 넘어가는 순서를 권장합니다.
4. 18장의 실전 프로젝트는 그동안 배운 내용을 종합하는 자리이니, 코드를 그대로 옮기기보다 스스로 변형해보며 완성해보세요.
