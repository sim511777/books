# 10장. 폰트와 텍스트 렌더링

[◀ 이전: 9장. 오디오](ch09-오디오.md) | [📖 목차](00-목차.md) | [다음: 11장. 2D 카메라 시스템 ▶](ch11-2D카메라시스템.md)


3장에서 우리는 이미 `DrawText()` 함수로 화면에 글자를 그려봤습니다. 점수를 표시하거나 안내 문구를 띄우는 정도라면 `DrawText()`만으로도 충분했습니다. 하지만 실제 게임을 만들다 보면 "폰트를 바꾸고 싶다", "글자 사이 간격을 조절하고 싶다", "텍스트를 화면 중앙에 정확히 맞추고 싶다", "한글이 화면에 안 나온다" 같은 문제에 부딪히게 됩니다.

이번 장에서는 `DrawText()`의 한계를 짚어보고, 커스텀 폰트를 로드해서 더 정교하게 텍스트를 그리는 방법을 배웁니다. 텍스트 크기를 미리 측정해서 레이아웃을 잡는 방법과, 한글 폰트를 다룰 때 특히 주의해야 할 점도 함께 살펴보겠습니다.

## 10.1 기본 DrawText의 한계

3장에서 사용했던 `DrawText()`의 시그니처를 다시 살펴봅시다.

```c
void DrawText(const char *text, int posX, int posY, int fontSize, Color color);
```

이 함수는 raylib이 내부에 기본으로 내장하고 있는 폰트를 사용합니다. 별도로 폰트 파일을 준비하지 않아도 바로 글자를 그릴 수 있다는 점에서 프로토타이핑 단계에는 아주 편리합니다.

하지만 몇 가지 한계가 뚜렷합니다.

- **폰트를 바꿀 수 없습니다.** 항상 raylib 기본 폰트(픽셀 느낌의 고정폭 비트맵 폰트)로만 그려집니다.
- **자간(글자 사이 간격)을 세밀하게 조절할 수 없습니다.**
- **한글, 일본어, 중국어 같은 비 ASCII 문자를 지원하지 않습니다.** 기본 폰트에는 영문 알파벳, 숫자, 기본 기호 정도의 글리프만 들어있어서, 한글이 포함된 문자열을 `DrawText()`에 넘기면 글자가 깨지거나 아예 표시되지 않습니다.

디자인이 중요한 UI, 타이틀 화면, 대사창처럼 폰트가 게임의 분위기를 좌우하는 부분에서는 직접 골라온 TTF 폰트를 로드해서 사용해야 합니다.

## 10.2 커스텀 폰트 로드하기: LoadFont

원하는 TTF(또는 OTF) 폰트 파일을 로드하려면 `LoadFont()`를 사용합니다.

```c
Font titleFont = LoadFont("resources/fonts/PressStart2P.ttf");

// ... 게임 루프 ...

UnloadFont(titleFont);
```

```c
Font LoadFont(const char *fileName);   // 파일에서 폰트 로드
void UnloadFont(Font font);            // 폰트 메모리 해제
```

폰트도 6장에서 다룬 텍스처, 9장에서 다룬 사운드와 마찬가지로 GPU/메모리 자원을 사용하는 리소스입니다. `LoadFont()`로 로드했다면 프로그램을 종료하기 전에 반드시 `UnloadFont()`로 해제해야 합니다.

`LoadFont()`는 기본적으로 ASCII 범위(라틴 문자, 숫자, 기본 기호)에 해당하는 글리프만 로드합니다. 한글처럼 글리프 수가 훨씬 많은 문자 집합을 다루려면 10.5절에서 소개할 `LoadFontEx()`를 사용해야 합니다.

## 10.3 DrawTextEx로 커스텀 폰트 그리기

폰트를 로드했다면 이제 `DrawText()` 대신 `DrawTextEx()`로 텍스트를 그립니다.

```c
void DrawTextEx(Font font, const char *text, Vector2 position, float fontSize, float spacing, Color tint);
```

각 매개변수는 다음과 같습니다.

- `font`: 사용할 폰트 (`LoadFont()`로 로드한 것, 혹은 `GetFontDefault()`로 얻은 기본 폰트)
- `text`: 그릴 문자열
- `position`: 텍스트를 그릴 좌상단 좌표
- `fontSize`: 글자 크기(픽셀 단위)
- `spacing`: 글자 사이 간격(자간)
- `tint`: 텍스트 색상

```c
Font titleFont = LoadFont("resources/fonts/PressStart2P.ttf");

while (!WindowShouldClose())
{
    BeginDrawing();
        ClearBackground(RAYWHITE);

        DrawTextEx(titleFont, "GAME OVER", (Vector2){ 220, 180 }, 40, 2.0f, MAROON);
        DrawTextEx(titleFont, "Press Enter to Restart", (Vector2){ 200, 250 }, 20, 1.0f, DARKGRAY);
    EndDrawing();
}

UnloadFont(titleFont);
```

`spacing` 값을 키우면 글자 사이가 넓어지고, 0에 가깝게 줄이면 글자끼리 다닥다닥 붙습니다. 폰트 자체의 디자인과 게임 분위기에 맞춰 적절한 값을 실험적으로 찾는 것이 좋습니다.

기본 폰트로도 `DrawTextEx()`를 사용할 수 있다는 점도 알아두면 좋습니다. `GetFontDefault()`를 넘기면 `DrawText()`와 비슷하지만 자간까지 조절할 수 있는 텍스트를 그릴 수 있습니다.

```c
DrawTextEx(GetFontDefault(), "Score: 100", (Vector2){ 10, 10 }, 20, 1.0f, BLACK);
```

## 10.4 텍스트 크기 측정하기: MeasureTextEx

텍스트를 화면 중앙에 배치하거나, 버튼 안에 딱 맞게 글자를 넣거나, 말풍선 크기를 텍스트 길이에 맞춰 자동으로 조절하고 싶을 때가 많습니다. 이런 레이아웃 작업을 하려면 텍스트를 그리기 전에 그 텍스트가 화면에서 차지할 너비와 높이를 미리 알아야 합니다. 이때 사용하는 함수가 `MeasureTextEx()`입니다.

```c
Vector2 MeasureTextEx(Font font, const char *text, float fontSize, float spacing);
```

반환값은 `Vector2`이며, `x`에는 텍스트 전체 너비, `y`에는 텍스트 높이가 담깁니다. `DrawTextEx()`를 호출할 때 넘긴 것과 동일한 `font`, `fontSize`, `spacing`을 넘겨야 정확한 값을 얻을 수 있습니다.

다음은 화면 정중앙에 텍스트를 정렬해서 그리는 예제입니다.

```c
Font font = LoadFont("resources/fonts/PressStart2P.ttf");
const char *message = "GAME CLEAR!";
float fontSize = 32.0f;
float spacing = 2.0f;

int screenWidth = 800;
int screenHeight = 450;

while (!WindowShouldClose())
{
    Vector2 textSize = MeasureTextEx(font, message, fontSize, spacing);

    Vector2 textPos = {
        (screenWidth - textSize.x) / 2.0f,
        (screenHeight - textSize.y) / 2.0f
    };

    BeginDrawing();
        ClearBackground(RAYWHITE);
        DrawTextEx(font, message, textPos, fontSize, spacing, DARKBLUE);
    EndDrawing();
}

UnloadFont(font);
```

텍스트 내용이 매 프레임 바뀌지 않는다면 `MeasureTextEx()`를 게임 루프 안에서 매번 호출할 필요 없이, 텍스트가 바뀌는 시점에만 한 번 계산해서 좌표를 캐싱해두는 방식으로 최적화할 수도 있습니다. 다만 대부분의 2D 게임에서는 이 계산 비용이 무시할 만한 수준이라 크게 신경 쓰지 않아도 됩니다.

참고로 기본 폰트만 사용한다면 `MeasureText(const char *text, int fontSize)`라는 더 단순한 함수도 있습니다. 이 함수는 정수 너비만 반환하며 내부적으로 기본 폰트를 기준으로 계산합니다. 커스텀 폰트나 자간을 다룰 때는 `MeasureTextEx()`를 쓰는 것이 정확합니다.

## 10.5 한글 폰트 다루기

앞서 언급했듯 raylib의 기본 폰트와 `LoadFont()`의 기본 동작은 한글을 지원하지 않습니다. 한글이 포함된 텍스트를 화면에 표시하려면 다음 두 가지가 반드시 필요합니다.

1. 한글 글리프가 포함된 TTF 폰트 파일 (예: 나눔고딕, Noto Sans KR 등 라이선스를 확인한 폰트)
2. 그 폰트에서 한글 코드포인트 범위를 명시적으로 로드하기

`LoadFont()`만으로는 ASCII 범위만 로드되므로, 한글처럼 코드포인트 개수가 많은 문자 집합을 다루려면 `LoadFontEx()`를 사용해서 필요한 코드포인트 목록을 직접 지정해야 합니다.

```c
Font LoadFontEx(const char *fileName, int fontSize, int *codepoints, int codepointCount);
```

`codepoints`에 `NULL`을 넘기면 기본 ASCII 범위가 로드되고, 원하는 문자들의 유니코드 코드포인트 배열을 직접 넘기면 그 문자들만 로드됩니다. 실제 화면에 표시할 문자열을 미리 알고 있다면, `LoadCodepoints()`로 그 문자열에 포함된 코드포인트 목록을 뽑아내는 방법이 편리합니다.

```c
const char *sampleText = "체력 점수 게임 시작 일시정지 다시하기";

int codepointCount = 0;
int *codepoints = LoadCodepoints(sampleText, &codepointCount);

Font koreanFont = LoadFontEx("resources/fonts/NotoSansKR-Regular.ttf", 32,
                              codepoints, codepointCount);

UnloadCodepoints(codepoints);

// ... 게임 루프 ...
DrawTextEx(koreanFont, "체력: 100", (Vector2){ 20, 20 }, 24, 1.0f, BLACK);

UnloadFont(koreanFont);
```

여기서 `sampleText`는 실제로 그릴 문자열은 아니고, 게임에서 사용할 모든 한글 글자를 한 번씩 모아둔 "샘플" 역할을 합니다. 이 샘플에 포함되지 않은 글자는 폰트에 로드되지 않으므로, 실제로 화면에 등장하는 모든 한글 단어(메뉴 항목, 대사, 아이템 이름 등)를 미리 모아서 샘플 문자열을 구성해두는 것이 중요합니다. 게임 규모가 커서 어떤 글자가 쓰일지 예측하기 어렵다면, 한글 완성형 전체 코드포인트 범위(가~힣, U+AC00~U+D7A3)를 직접 배열로 만들어 넘기는 방법도 있지만, 이 경우 글리프 수가 많아져 폰트 텍스처가 커지고 로딩 시간도 늘어난다는 점을 감안해야 합니다.

## 10.6 긴 문장 줄바꿈 처리하기

`DrawTextEx()`는 `\n`이 포함된 문자열이면 자동으로 줄바꿈을 인식해서 그려줍니다.

```c
DrawTextEx(font, "첫 번째 줄\n두 번째 줄\n세 번째 줄", (Vector2){ 20, 20 }, 24, 1.0f, BLACK);
```

문제는 한 줄이 너무 길어서 화면 폭을 넘어가는 경우입니다. 이런 긴 문장은 미리 적당한 길이로 잘라서 줄 단위 문자열 배열로 만들어두고, `y` 좌표를 한 줄 높이만큼씩 증가시키면서 반복해서 그리는 방식이 가장 간단하고 확실합니다.

```c
const char *lines[] = {
    "용사는 마을을 떠나",
    "깊은 숲속으로 향했다.",
    "그곳에서 오래된 지도를",
    "발견했다고 한다."
};
int lineCount = 4;

Font font = LoadFont("resources/fonts/NotoSansKR-Regular.ttf");
float fontSize = 20.0f;
float lineHeight = fontSize * 1.4f;  // 줄 간격은 폰트 크기의 1.2~1.5배 정도가 자연스럽습니다

Vector2 startPos = { 40, 300 };

for (int i = 0; i < lineCount; i++)
{
    Vector2 linePos = { startPos.x, startPos.y + lineHeight * i };
    DrawTextEx(font, lines[i], linePos, fontSize, 1.0f, DARKGRAY);
}
```

만약 문장이 고정된 대사가 아니라 동적으로 만들어지는 텍스트라서 미리 줄 단위로 나눠둘 수 없다면, `MeasureTextEx()`로 단어를 하나씩 추가하면서 폭을 계속 측정하다가 지정한 최대 폭을 넘어서는 순간 줄을 바꾸는 방식으로 자동 줄바꿈 로직을 직접 구현할 수도 있습니다. 다만 이런 자동 줄바꿈은 공백으로 단어를 구분하는 영어 문장에는 잘 맞지만, 띄어쓰기 규칙이 다른 한글 문장에서는 어절 단위로 나누는 등 별도의 처리가 필요할 수 있습니다. 대부분의 튜토리얼 수준 프로젝트에서는 대사나 안내문을 애초에 적절한 길이로 미리 나눠서 배열에 담아두는 방식만으로도 충분합니다.

## 요약

- 기본 `DrawText()`는 raylib 내장 폰트만 사용하며 한글 등 비 ASCII 문자를 지원하지 않습니다. 커스텀 폰트가 필요하면 `LoadFont()` 또는 `LoadFontEx()`로 TTF 파일을 로드해야 합니다.
- `DrawTextEx(font, text, position, fontSize, spacing, tint)`를 사용하면 커스텀 폰트와 자간을 지정해서 텍스트를 그릴 수 있습니다.
- `MeasureTextEx(font, text, fontSize, spacing)`으로 텍스트가 차지할 너비와 높이를 미리 계산할 수 있고, 이를 이용해 중앙 정렬 같은 레이아웃을 구현할 수 있습니다.
- 한글 텍스트를 그리려면 한글 글리프가 포함된 TTF 폰트를 `LoadFontEx()`로 로드하면서, 실제로 사용할 문자들의 코드포인트를 `LoadCodepoints()` 등으로 직접 지정해야 합니다.
- 화면 폭을 넘어가는 긴 문장은 줄 단위 문자열로 미리 나눠두고, `y` 좌표를 줄 높이만큼 증가시키며 반복해서 그리는 방식으로 처리할 수 있습니다.
- 로드한 `Font`는 사용이 끝나면 `UnloadFont()`로 반드시 해제해야 합니다.

## 연습문제

1. 기본 `DrawText()`로 "안녕하세요"를 그려보고, 커스텀 한글 폰트를 `LoadFontEx()`로 로드해서 `DrawTextEx()`로 같은 문자열을 그려본 뒤 결과를 비교해보세요.
2. `spacing` 값을 0, 2, 5, 10으로 바꿔가며 같은 텍스트를 그려보고 자간이 가독성에 어떤 영향을 주는지 관찰해보세요.
3. `MeasureTextEx()`를 이용해 화면 중앙이 아니라 화면 우측 하단에 텍스트가 딱 맞게 배치되도록 좌표를 계산하는 프로그램을 작성해보세요.
4. 사용자가 방향키로 여러 개의 메뉴 항목(예: "시작하기", "설정", "종료") 중 하나를 선택할 수 있는 화면을 만들어보세요. 각 항목의 텍스트 크기를 `MeasureTextEx()`로 측정해서 선택된 항목 뒤에 배경 사각형을 텍스트 크기에 딱 맞게 그려보세요.
5. 4~5줄 분량의 한글 대사를 줄 단위 문자열 배열로 나눠 화면에 순서대로 표시하는 간단한 대화창 프로그램을 작성해보세요.
