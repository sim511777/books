# 4장. 입력 처리

[◀ 이전: 3장. 게임 루프와 기본 도형 그리기](ch03-게임루프와기본도형그리기.md) | [📖 목차](00-목차.md) | [다음: 5장. 벡터와 기본 수학(raymath) ▶](ch05-벡터와기본수학.md)


3장에서는 델타 타임을 이용해 사각형이 스스로 화면을 가로지르며 움직이는 예제를 만들었습니다. 하지만 진짜 게임이라면 사용자가 직접 캐릭터를 조작할 수 있어야 합니다. 이번 장에서는 raylib가 제공하는 키보드, 마우스, 게임패드 입력 함수들을 배우고, 3장의 델타 타임 개념과 결합해 키보드로 사각형을 자유롭게 움직이는 예제를 만들어 봅니다.

## 키보드 입력: 세 가지 함수의 차이

raylib는 키보드 상태를 확인하는 함수를 여러 개 제공하는데, 그중 가장 자주 쓰이는 세 가지는 다음과 같습니다.

```c
bool IsKeyDown(int key);
bool IsKeyPressed(int key);
bool IsKeyReleased(int key);
```

이 세 함수는 이름이 비슷해서 처음 배울 때 헷갈리기 쉽지만, 동작 방식은 명확히 다릅니다.

- **`IsKeyDown(key)`**: 해당 키가 **눌려 있는 동안 매 프레임 계속** `true`를 반환합니다. 사용자가 키를 누르고 있는 한, 프레임마다 계속 호출해도 계속 `true`가 나옵니다.
- **`IsKeyPressed(key)`**: 키가 **눌리는 그 순간의 프레임에서만 한 번** `true`를 반환합니다. 키를 계속 누르고 있어도 다음 프레임부터는 다시 `false`가 됩니다. 즉 "누름 이벤트"가 발생한 딱 한 프레임만 감지합니다.
- **`IsKeyReleased(key)`**: 반대로, 키를 **떼는 순간의 프레임에서만 한 번** `true`를 반환합니다.

이 차이를 그림으로 표현하면, 사용자가 스페이스바를 0.5초 동안 눌렀다가 뗀다고 할 때 프레임별 반환값은 대략 다음과 같습니다.

```
프레임:        1(누름)  2      3      4(뗌)   5
IsKeyDown:      true    true   true   false   false
IsKeyPressed:   true    false  false  false   false
IsKeyReleased:  false   false  false  true    false
```

### 언제 무엇을 써야 하는가

이 차이는 단순한 문법 지식이 아니라 실제 게임 로직 설계와 직결됩니다.

- **이동**처럼 키를 누르고 있는 동안 계속 반응해야 하는 동작에는 `IsKeyDown`을 사용합니다. 캐릭터가 오른쪽으로 걸어가게 하려면 오른쪽 키를 누르고 있는 매 프레임마다 위치를 갱신해야 하기 때문입니다.
- **점프, 발사, 메뉴 선택**처럼 한 번의 입력에 한 번만 반응해야 하는 동작에는 `IsKeyPressed`를 사용합니다. 만약 점프에 `IsKeyDown`을 쓰면, 스페이스바를 누르고 있는 동안 매 프레임마다 점프가 계속 발동해서 캐릭터가 하늘로 솟구쳐 버릴 것입니다.

```c
// 이동: 누르고 있는 동안 계속
if (IsKeyDown(KEY_RIGHT)) playerX += speed * GetFrameTime();

// 점프: 누르는 순간 한 번만
if (IsKeyPressed(KEY_SPACE)) Jump();
```

`IsKeyReleased`는 상대적으로 사용 빈도는 낮지만, 예를 들어 활을 당겼다가 키를 떼는 순간 화살을 발사하는 "차지 후 발사" 같은 동작이나, 버튼에서 손을 뗄 때만 클릭이 확정되는 UI 등을 구현할 때 유용합니다. 참고로 정반대 개념인 `IsKeyUp(key)`도 존재하며, 이는 해당 키가 눌려있지 않은 동안 계속 `true`를 반환합니다. 실무에서는 `IsKeyDown`으로 충분한 경우가 많아 `IsKeyUp`은 상대적으로 적게 쓰입니다.

### 키 상수

`key` 매개변수에는 `KEY_` 접두사가 붙은 정수 상수를 전달합니다. raylib는 알파벳, 숫자, 방향키, 특수키를 아우르는 다양한 상수를 정의하고 있으며 자주 쓰이는 것들은 다음과 같습니다.

| 상수 | 키 |
|---|---|
| `KEY_RIGHT`, `KEY_LEFT`, `KEY_UP`, `KEY_DOWN` | 방향키 |
| `KEY_SPACE` | 스페이스바 |
| `KEY_ENTER` | 엔터 |
| `KEY_ESCAPE` | ESC |
| `KEY_A` ~ `KEY_Z` | 알파벳 키 |
| `KEY_ZERO` ~ `KEY_NINE` | 숫자 키(메인 키보드) |

간단한 사용 예시입니다.

```c
if (IsKeyDown(KEY_RIGHT)) DrawText("오른쪽 이동 중", 10, 10, 20, BLACK);
if (IsKeyPressed(KEY_SPACE)) TraceLog(LOG_INFO, "점프!");
```

`WindowShouldClose()`는 기본적으로 `KEY_ESCAPE`가 눌리거나 창의 닫기 버튼이 클릭되었을 때 `true`를 반환하도록 되어 있어, 2장의 첫 예제에서부터 이미 `KEY_ESCAPE`를 간접적으로 사용해 온 셈입니다.

## 마우스 입력

키보드와 마찬가지로 마우스도 위치와 버튼 상태를 확인하는 함수들을 제공합니다.

```c
Vector2 GetMousePosition(void);
bool IsMouseButtonPressed(int button);
bool IsMouseButtonDown(int button);
float GetMouseWheelMove(void);
```

`GetMousePosition()`은 현재 창 안에서 마우스 커서의 좌표를 `Vector2`(왼쪽 위가 `(0, 0)`)로 반환합니다.

```c
Vector2 mousePos = GetMousePosition();
DrawText(TextFormat("마우스 위치: %.0f, %.0f", mousePos.x, mousePos.y), 10, 10, 20, BLACK);
```

`TextFormat`은 `printf`처럼 서식 문자열로 텍스트를 조합해 반환하는 raylib의 편의 함수로, 앞으로 여러 장에서 값을 화면에 디버그 출력할 때 자주 사용하게 됩니다.

마우스 버튼 상태 확인은 키보드의 `IsKeyDown`/`IsKeyPressed`와 동일한 규칙을 따릅니다. `IsMouseButtonDown`은 누르고 있는 동안 계속, `IsMouseButtonPressed`는 클릭한 순간 한 번만 `true`를 반환합니다. 버튼은 `MOUSE_BUTTON_LEFT`, `MOUSE_BUTTON_RIGHT`, `MOUSE_BUTTON_MIDDLE` 상수로 지정합니다.

```c
if (IsMouseButtonPressed(MOUSE_BUTTON_LEFT))
{
    Vector2 clickPos = GetMousePosition();
    DrawCircle((int)clickPos.x, (int)clickPos.y, 10, RED);
}
```

`GetMouseWheelMove()`는 마우스 휠을 굴린 정도를 `float`로 반환합니다. 휠을 위로 굴리면 양수, 아래로 굴리면 음수가 반환되며, 휠을 움직이지 않은 프레임에는 `0.0f`가 반환됩니다. 11장에서 2D 카메라의 확대/축소를 구현할 때 이 함수를 다시 사용하게 됩니다.

```c
float wheelMove = GetMouseWheelMove();
if (wheelMove != 0.0f)
{
    zoom += wheelMove * 0.1f;
}
```

## 게임패드 입력

raylib는 Xbox나 PlayStation 계열 게임패드 입력도 지원합니다. 게임패드는 여러 개가 연결될 수 있으므로 대부분의 함수가 첫 번째 인자로 게임패드 번호(0번부터 시작)를 받습니다.

### 연결 확인

게임패드 관련 함수를 호출하기 전에는 먼저 해당 번호의 게임패드가 실제로 연결되어 있는지 확인하는 것이 안전합니다.

```c
bool IsGamepadAvailable(int gamepad);
```

```c
if (IsGamepadAvailable(0))
{
    DrawText("게임패드 0번 연결됨", 10, 40, 20, DARKGREEN);
}
```

### 버튼 입력

```c
bool IsGamepadButtonPressed(int gamepad, int button);
```

키보드의 `IsKeyPressed`와 마찬가지로, 버튼이 눌리는 순간의 프레임에서만 `true`를 반환합니다. 버튼 상수는 `GAMEPAD_BUTTON_` 접두사를 가지며, 페이스 버튼(십자 배열의 네 버튼)은 방향으로 이름이 붙어 있습니다.

```c
if (IsGamepadButtonPressed(0, GAMEPAD_BUTTON_RIGHT_FACE_DOWN))
{
    // Xbox 패드 기준 A 버튼, PlayStation 패드 기준 Cross(X) 버튼
    TraceLog(LOG_INFO, "점프 버튼 눌림");
}
```

계속 누르고 있는 상태를 확인하려면 `IsGamepadButtonDown(int gamepad, int button)`을 사용합니다. 이 역시 키보드의 `IsKeyDown`과 동일한 규칙을 따릅니다.

### 아날로그 스틱

아날로그 스틱처럼 -1.0f부터 1.0f 사이의 연속적인 값을 반환하는 입력은 `GetGamepadAxisMovement`로 읽습니다.

```c
float GetGamepadAxisMovement(int gamepad, int axis);
```

`axis`에는 `GAMEPAD_AXIS_LEFT_X`, `GAMEPAD_AXIS_LEFT_Y`, `GAMEPAD_AXIS_RIGHT_X`, `GAMEPAD_AXIS_RIGHT_Y` 등의 상수를 전달합니다. 왼쪽 스틱을 오른쪽으로 완전히 기울이면 `GAMEPAD_AXIS_LEFT_X`는 `1.0f`에 가까운 값을, 왼쪽으로 완전히 기울이면 `-1.0f`에 가까운 값을 반환합니다. 스틱을 건드리지 않은 중립 상태에서도 미세하게 0이 아닌 값이 들어올 수 있는데, 이를 **데드존(dead zone)**이라 부르는 작은 임계값으로 걸러주는 것이 일반적입니다.

```c
if (IsGamepadAvailable(0))
{
    float axisX = GetGamepadAxisMovement(0, GAMEPAD_AXIS_LEFT_X);

    const float deadZone = 0.1f;
    if (fabsf(axisX) > deadZone)
    {
        playerX += axisX * speed * GetFrameTime();
    }
}
```

`fabsf`는 `float` 절댓값을 구하는 표준 라이브러리 함수로, 사용하려면 `#include <math.h>`가 필요합니다. 데드존을 두지 않으면 스틱이 중립 위치에 있어도 캐릭터가 미세하게 떨리듯 움직이는 문제가 생길 수 있습니다.

## 실전 예제: 키보드로 사각형 움직이기

이제 3장에서 배운 델타 타임 기반 이동과 이번 장의 `IsKeyDown`을 결합해, 방향키로 자유롭게 움직이는 사각형을 만들어 보겠습니다.

```c
#include "raylib.h"

int main(void)
{
    const int screenWidth = 800;
    const int screenHeight = 450;

    InitWindow(screenWidth, screenHeight, "4장 - 키보드로 사각형 움직이기");
    SetTargetFPS(60);

    float rectWidth = 50.0f;
    float rectHeight = 50.0f;

    // 사각형을 화면 중앙에서 시작
    float rectX = screenWidth / 2.0f - rectWidth / 2.0f;
    float rectY = screenHeight / 2.0f - rectHeight / 2.0f;

    float speed = 300.0f;   // 초당 300픽셀 이동
    int jumpCount = 0;      // 스페이스바를 누른 횟수(단발 입력 확인용)

    while (!WindowShouldClose())
    {
        // --- 갱신 ---
        float deltaTime = GetFrameTime();

        // 이동: 누르고 있는 동안 계속 반응해야 하므로 IsKeyDown 사용
        if (IsKeyDown(KEY_RIGHT)) rectX += speed * deltaTime;
        if (IsKeyDown(KEY_LEFT))  rectX -= speed * deltaTime;
        if (IsKeyDown(KEY_UP))    rectY -= speed * deltaTime;
        if (IsKeyDown(KEY_DOWN))  rectY += speed * deltaTime;

        // 화면 밖으로 나가지 않도록 위치 제한
        if (rectX < 0) rectX = 0;
        if (rectY < 0) rectY = 0;
        if (rectX + rectWidth  > screenWidth)  rectX = screenWidth  - rectWidth;
        if (rectY + rectHeight > screenHeight) rectY = screenHeight - rectHeight;

        // 단발 입력: 누르는 순간 한 번만 반응해야 하므로 IsKeyPressed 사용
        if (IsKeyPressed(KEY_SPACE)) jumpCount++;

        // --- 그리기 ---
        BeginDrawing();

            ClearBackground(RAYWHITE);

            DrawText("방향키로 이동, 스페이스바로 카운트 증가", 20, 20, 20, DARKGRAY);
            DrawText(TextFormat("스페이스바 누른 횟수: %d", jumpCount), 20, 50, 20, DARKGRAY);

            DrawRectangle((int)rectX, (int)rectY, (int)rectWidth, (int)rectHeight, MAROON);

        EndDrawing();
    }

    CloseWindow();
    return 0;
}
```

이 예제에서 이동 처리와 스페이스바 카운트 처리가 각각 어떤 함수를 쓰는지 다시 한번 확인해 보세요. 방향키 네 개는 모두 `IsKeyDown`으로, 화면에 계속 힘을 가하는 것처럼 누르고 있는 동안 매 프레임 위치가 갱신됩니다. 반면 스페이스바는 `IsKeyPressed`로, 아무리 오래 누르고 있어도 `jumpCount`는 딱 한 번만 증가합니다. 만약 여기서 `IsKeyPressed`와 `IsKeyDown`을 서로 바꿔서 사용하면 어떻게 될지 한 번 예상해 보고, 실제로 바꿔서 실행해 확인해 보는 것도 좋은 연습이 됩니다.

또한 이 예제는 사각형이 화면 경계를 벗어나지 않도록 `rectX`, `rectY` 값을 매 프레임 범위 안으로 잘라주는 처리를 포함하고 있습니다. 이런 경계 처리는 8장에서 다룰 충돌 감지의 가장 단순한 형태라고 볼 수 있습니다.

## 요약

- `IsKeyDown`은 키가 눌려 있는 동안 매 프레임 계속 `true`를, `IsKeyPressed`는 눌리는 순간의 프레임에만 한 번 `true`를, `IsKeyReleased`는 떼는 순간의 프레임에만 한 번 `true`를 반환합니다.
- 이동처럼 지속적인 반응이 필요한 동작에는 `IsKeyDown`을, 점프나 발사처럼 한 번의 입력에 한 번만 반응해야 하는 동작에는 `IsKeyPressed`를 사용합니다.
- 키 상수는 `KEY_RIGHT`, `KEY_LEFT`, `KEY_SPACE`처럼 `KEY_` 접두사를 가지며, 마우스 버튼은 `MOUSE_BUTTON_LEFT` 등으로 지정합니다.
- 마우스 위치는 `GetMousePosition()`, 버튼 클릭은 `IsMouseButtonPressed`, 휠 스크롤은 `GetMouseWheelMove()`로 읽습니다.
- 게임패드는 `IsGamepadAvailable(gamepad)`로 연결을 확인한 뒤, `IsGamepadButtonPressed`로 버튼을, `GetGamepadAxisMovement`로 아날로그 스틱 값을 읽습니다.
- 3장의 델타 타임 기반 이동과 `IsKeyDown`을 결합하면, 프레임 속도와 무관하게 일정한 속도로 반응하는 키보드 조작 캐릭터를 만들 수 있습니다.

## 연습문제

1. 본문의 실전 예제에서 방향키 이동 코드를 `IsKeyDown` 대신 `IsKeyPressed`로 바꿔서 실행해 보세요. 방향키를 계속 누르고 있어도 사각형이 한 번만 움직이는 이유를 설명해 보세요.
2. `IsMouseButtonPressed(MOUSE_BUTTON_LEFT)`로 클릭한 위치에 매번 새로운 원을 그리는 프로그램을 작성해 보세요. 클릭할 때마다 원이 하나씩 추가로 남으려면 3장에서 배운 즉시 모드 렌더링의 어떤 습관(예: `ClearBackground` 호출 방식이나 위치를 저장하는 배열)을 바꿔야 할지 생각해 보세요.
3. `GetMouseWheelMove()` 값을 이용해 화면에 그려진 원의 반지름이 휠을 굴릴 때마다 커지거나 작아지는 예제를 만들어 보세요. 반지름이 음수가 되지 않도록 최솟값을 제한하는 것도 잊지 마세요.
4. 게임패드가 연결되어 있다면, `GAMEPAD_AXIS_LEFT_X`와 `GAMEPAD_AXIS_LEFT_Y` 값을 동시에 이용해 사각형을 8방향(또는 자유 방향)으로 움직이는 예제를 만들어 보세요. 데드존을 적용하지 않았을 때와 적용했을 때 차이를 관찰해 보세요.
5. 본문 예제에 `IsKeyReleased(KEY_SPACE)`를 추가해서, 스페이스바를 떼는 순간에만 "발사!"라는 텍스트가 잠시 표시되도록 만들어 보세요. (힌트: 텍스트를 몇 프레임 동안 유지할지 셀 변수를 하나 두고, `IsKeyReleased`가 감지될 때 그 변수를 초기화하세요.)
