## 6.1 왜 도형을 그리는가

지금까지는 이미지를 읽고, 색공간을 바꾸고, 화면에 표시하는 방법을 다뤘다. 이번 장에서는 이미지 위에 직접 무언가를 "그리는" 방법을 배운다. 단순히 예쁜 그림을 그리자는 것이 아니다. 컴퓨터 비전에서 도형 그리기는 대부분 **분석 결과를 시각적으로 확인하기 위한 도구**로 쓰인다.

예를 들어 얼굴 검출 알고리즘이 이미지 어딘가에서 얼굴을 찾았다면, 그 좌표를 콘솔에 숫자로만 찍어서는 결과가 맞는지 직관적으로 확인하기 어렵다. 대신 찾아낸 위치에 사각형을 그리고 "Face"라는 레이블을 붙이면, 결과가 한눈에 들어온다. 12장의 컨투어 분석, 15장의 특징점 매칭, 17장의 객체 검출 모두 이번 장에서 배우는 그리기 함수를 결과 시각화 도구로 사용한다. 그러니 이번 장의 예제들은 단순한 그림 그리기 연습이 아니라, 앞으로 계속 재사용할 "결과 보여주기"의 표준 패턴을 익히는 과정이라고 생각하면 된다.

이번 장에서는 먼저 기본 도형(선, 사각형, 원, 다각형, 텍스트)을 다시 짚고, 화살표와 타원을 추가로 배운다. 그다음 폰트 종류와 안티앨리어싱을 자세히 비교하고, 마우스 이벤트를 처리해 사용자가 직접 그림을 그리는 인터랙티브 프로그램을 만든다. 마지막으로 반투명 배경 박스 기법과, 객체 검출 결과를 시각화하는 완성된 실전 함수를 작성하며 장을 마무리한다.

## 6.2 색상 표현 방식: `(B, G, R)` 튜플

도형을 그리려면 먼저 색을 지정하는 방법을 알아야 한다. 5장에서 다룬 것처럼 OpenCV는 항상 **BGR 순서**로 색을 다루며, 이는 도형을 그릴 때도 예외 없이 적용된다. opencv-python에서 색상은 `(B, G, R)` 형태의 파이썬 튜플로 표현한다.

```python
red = (0, 0, 255)      # 순수한 빨간색
green = (0, 255, 0)    # 순수한 초록색
blue = (255, 0, 0)     # 순수한 파란색
white = (255, 255, 255)
black = (0, 0, 0)
yellow = (0, 255, 255)  # R + G
```

**첫 번째 값이 Blue, 마지막 값이 Red**라는 점을 다시 한번 강조한다. `(255, 0, 0)`을 "빨간색"이라는 느낌으로 실수로 쓰면, 실제로는 파란색이 그려진다. RGB 감각이 익숙한 사람일수록 이 실수를 자주 하므로, 색을 지정할 때마다 "이건 BGR이다"를 의식적으로 되새기는 습관이 필요하다.

NumPy의 `uint8` 스칼라나 `int`가 섞여 있어도 대부분의 그리기 함수는 문제없이 받아들이지만, 각 값은 0~255 범위의 정수여야 한다는 점도 기억해 두자. 값이 이 범위를 벗어나면 예상치 못한 색이 그려지거나 오류가 발생할 수 있다.

## 6.3 직선 그리기: `cv2.line`

가장 단순한 도형인 직선부터 시작한다. `line` 함수는 시작점과 끝점, 색상, 선의 두께를 받는다.

```python
cv2.line(img, pt1, pt2, color, thickness=1, lineType=cv2.LINE_8)
```

```python
import cv2
import numpy as np

img = np.zeros((400, 500, 3), dtype=np.uint8)

cv2.line(img, (50, 50), (450, 50), (0, 255, 0), 3)

cv2.imshow("Line", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

좌표는 항상 `(x, y)` 순서로 지정한다. 이는 3장에서 다룬 NumPy 배열 인덱싱의 `(row, col)`, 즉 `(y, x)` 순서와는 반대이므로 혼동하지 않도록 주의한다. 도형 그리기 함수의 좌표 인자는 항상 "가로(x), 세로(y)"라는 사람에게 익숙한 순서를 따른다.

## 6.4 사각형 그리기: `cv2.rectangle`

`rectangle`은 좌상단(top-left)과 우하단(bottom-right) 두 점을 받아 그 사이를 사각형으로 그린다. 두께에 음수(예: `-1` 또는 `cv2.FILLED`)를 지정하면 테두리가 아니라 내부가 채워진 사각형이 된다.

```python
import cv2
import numpy as np

img = np.zeros((400, 500, 3), dtype=np.uint8)

cv2.rectangle(img, (100, 80), (300, 220), (255, 0, 0), 2)          # 테두리만
cv2.rectangle(img, (320, 80), (420, 220), (0, 0, 255), cv2.FILLED)  # 채워진 사각형

cv2.imshow("Rectangle", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`cv2.FILLED`는 `-1`을 의미하는 상수일 뿐이므로, 그냥 `-1`을 직접 써도 동일하게 동작한다. 사각형은 뒤에서 볼 예제처럼 객체 검출 결과의 바운딩 박스(bounding box)를 표시하는 데 가장 많이 쓰이는 도형이다.

## 6.5 원 그리기: `cv2.circle`

`circle`은 중심점과 반지름을 받는다. 사각형과 마찬가지로 두께에 `-1`을 주면 내부가 채워진 원이 된다.

```python
import cv2
import numpy as np

img = np.zeros((400, 500, 3), dtype=np.uint8)

cv2.circle(img, (150, 200), 60, (0, 255, 255), 2)
cv2.circle(img, (350, 200), 60, (255, 0, 255), -1)

cv2.imshow("Circle", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

원은 특징점(15장)의 위치를 표시하거나, 검출된 얼굴에서 눈의 위치처럼 특정 지점을 강조할 때 자주 사용된다. 5장 마지막의 객체 추적 예제에서도 물체의 중심점을 표시하기 위해 이미 사용해 보았다.

## 6.6 다각형 그리기: `cv2.polylines`

`polylines`는 여러 개의 점을 순서대로 이어 다각형(또는 꺾인 선)을 그린다. 좌표를 하나의 정수 NumPy 배열로 모아서 전달해야 한다.

```python
import cv2
import numpy as np

img = np.zeros((400, 500, 3), dtype=np.uint8)

pts = np.array([[100, 300], [150, 200], [250, 220],
                 [280, 320], [180, 350]], dtype=np.int32)
pts = pts.reshape((-1, 1, 2))

cv2.polylines(img, [pts], isClosed=True, color=(0, 165, 255), thickness=2)

cv2.imshow("Polygon", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`pts.reshape((-1, 1, 2))`로 배열의 형태를 바꿔주는 이유는, `polylines`가 내부적으로 "여러 개의 다각형" 목록을 받도록 설계되어 있기 때문이다. 그래서 하나의 다각형만 그리더라도 `[pts]`처럼 리스트로 한 번 더 감싸서 넘겨야 한다. `isClosed`를 `True`로 주면 마지막 점과 첫 점이 자동으로 이어져 닫힌 도형이 되고, `False`로 주면 열린 꺾은선이 된다.

내부를 색으로 채운 다각형이 필요하다면 `polylines` 대신 `cv2.fillPoly`를 사용한다.

```python
overlay = img.copy()
cv2.fillPoly(overlay, [pts], (0, 165, 255))
```

`fillPoly`는 `polylines`와 인자 구성이 비슷하지만 `isClosed`나 `thickness` 인자가 없다. 항상 닫힌 도형으로 간주해 내부를 지정한 색으로 채운다.

## 6.7 화살표 그리기: `cv2.arrowedLine`

방향이나 흐름을 표시하고 싶을 때는 `cv2.arrowedLine`을 사용한다. 사용법은 `line`과 거의 같지만, 끝점 쪽에 화살촉이 그려진다.

```python
cv2.arrowedLine(img, pt1, pt2, color, thickness=1, line_type=cv2.LINE_8,
                 shift=0, tipLength=0.1)
```

```python
import cv2
import numpy as np

img = np.zeros((300, 500, 3), dtype=np.uint8)

cv2.arrowedLine(img, (50, 150), (450, 150), (0, 255, 0), 2, tipLength=0.05)
cv2.arrowedLine(img, (250, 250), (250, 30), (0, 200, 255), 3, tipLength=0.15)

cv2.imshow("Arrowed Line", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`tipLength`는 화살촉의 길이를 전체 선 길이에 대한 비율(0~1)로 지정하는 인자다. 값이 클수록 화살촉이 도드라지게 커진다. 화살표는 옵티컬 플로우(14장에서 다룰 예정)의 움직임 벡터를 시각화하거나, 두 특징점 사이의 대응 관계, 힘의 방향 같은 벡터 데이터를 표현할 때 특히 유용하다.

## 6.8 타원 그리기: `cv2.ellipse`

원보다 조금 더 일반적인 도형인 타원은 `cv2.ellipse`로 그린다. 원과 달리 가로·세로 반지름을 따로 지정하고, 타원 전체를 회전시키는 각도(`angle`)와, 타원의 일부(호, arc)만 그리기 위한 시작각·끝각도 지정할 수 있다.

```python
cv2.ellipse(img, center, axes, angle, startAngle, endAngle, color,
             thickness=1, lineType=cv2.LINE_8, shift=0)
```

```python
import cv2
import numpy as np

img = np.zeros((400, 500, 3), dtype=np.uint8)

# 완전한 타원: 가로 반지름 120, 세로 반지름 60, 회전 없음, 0도~360도 전체
cv2.ellipse(img, (150, 150), (120, 60), 0, 0, 360, (0, 255, 0), 2)

# 45도 기울어진 타원
cv2.ellipse(img, (380, 150), (100, 50), 45, 0, 360, (255, 0, 255), 2)

# 반원만 그리기 (0도부터 180도까지의 호), 내부를 채움
cv2.ellipse(img, (250, 300), (90, 90), 0, 0, 180, (0, 165, 255), -1)

cv2.imshow("Ellipse", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`angle`은 타원 전체가 시계방향으로 회전하는 각도(도 단위)이고, `startAngle`/`endAngle`은 타원 위에서 호를 그리기 시작하고 끝내는 각도다. 두 각도를 `0`과 `360`으로 주면 완전한 타원이 되고, 그 사이의 값을 주면 부채꼴 모양의 호나 파이 차트 조각 같은 모양을 만들 수 있다. 얼굴 검출 결과를 표시할 때 사각형보다 얼굴형에 더 가까운 타원을 사용하는 경우도 흔히 볼 수 있다.

## 6.9 텍스트 그리기: `cv2.putText`

`putText`는 이미지 위에 문자열을 그려주는 함수로, 폰트 종류, 크기(scale), 색상, 두께를 함께 지정한다.

```python
cv2.putText(img, text, org, fontFace, fontScale, color,
             thickness=1, lineType=cv2.LINE_8, bottomLeftOrigin=False)
```

```python
import cv2
import numpy as np

img = np.zeros((200, 500, 3), dtype=np.uint8)

cv2.putText(img, "OpenCV", (50, 100),
            cv2.FONT_HERSHEY_SIMPLEX, 1.5, (0, 255, 0), 2)

cv2.imshow("Text", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`putText`의 좌표(`org`)는 사각형이나 원과 달리 문자열의 "좌측 하단(baseline 기준선의 왼쪽 끝)"을 기준으로 삼는다는 점에 주의해야 한다. 즉 `(50, 100)`은 글자가 시작되는 왼쪽 아래 모서리 근처이며, 글자 대부분은 이 y좌표보다 위쪽에 그려진다. 이 특성은 뒤에서 볼 실전 예제에서 레이블의 위치를 잡을 때 중요하게 작용한다.

## 6.10 폰트 옵션 자세히 살펴보기

OpenCV는 별도의 폰트 파일을 불러오지 않고도 텍스트를 그릴 수 있도록, 내부적으로 벡터 형태의 "Hershey 폰트" 몇 종류를 상수로 제공한다. `cv2.FONT_HERSHEY_`로 시작하는 상수들이 이에 해당하며, 대표적인 것들은 다음과 같다.

| 상수 | 특징 |
|---|---|
| `cv2.FONT_HERSHEY_SIMPLEX` | 일반적인 굵기의 산세리프체. 가장 널리 쓰이는 기본 폰트. |
| `cv2.FONT_HERSHEY_PLAIN` | 얇은 선으로 그려지는 작은 산세리프체. 두께가 가늘어 작은 글자에 적합. |
| `cv2.FONT_HERSHEY_DUPLEX` | SIMPLEX보다 좀 더 두껍고 복잡한 선으로 그려지는 산세리프체. |
| `cv2.FONT_HERSHEY_COMPLEX` | 세리프에 가까운 느낌을 주는, 더 정교한 획으로 그려지는 폰트. |
| `cv2.FONT_HERSHEY_TRIPLEX` | COMPLEX보다 더 두꺼운 버전. |
| `cv2.FONT_HERSHEY_SCRIPT_SIMPLEX` | 손글씨(필기체) 느낌의 폰트. |

이 상수 중 하나에 `cv2.FONT_ITALIC`을 `|`(비트 OR)로 더하면 기울임(이탤릭) 효과가 추가된다.

```python
italic_font = cv2.FONT_HERSHEY_SIMPLEX | cv2.FONT_ITALIC
```

여러 폰트를 한 화면에 나란히 그려서 눈으로 직접 비교해보는 예제를 살펴보자.

```python
import cv2
import numpy as np

fonts = [
    ("SIMPLEX", cv2.FONT_HERSHEY_SIMPLEX),
    ("PLAIN", cv2.FONT_HERSHEY_PLAIN),
    ("DUPLEX", cv2.FONT_HERSHEY_DUPLEX),
    ("COMPLEX", cv2.FONT_HERSHEY_COMPLEX),
    ("TRIPLEX", cv2.FONT_HERSHEY_TRIPLEX),
    ("SCRIPT_SIMPLEX", cv2.FONT_HERSHEY_SCRIPT_SIMPLEX),
]

img = np.zeros((len(fonts) * 60 + 20, 500, 3), dtype=np.uint8)

for i, (name, font) in enumerate(fonts):
    y = 50 + i * 60
    cv2.putText(img, f"{name}: Hello, OpenCV 123", (20, y),
                font, 1.0, (0, 255, 0), 1, cv2.LINE_AA)

cv2.imshow("Font Comparison", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 안티앨리어싱: `cv2.LINE_AA`

지금까지의 예제에서 `lineType` 인자는 계속 기본값(`cv2.LINE_8`, 8방향 연결의 정수 좌표 기반 브레젠험 알고리즘)으로 남겨두었다. 기본값으로 그려진 선이나 글자를 확대해서 보면 경계가 계단처럼 삐뚤빼뚤하게(계단 현상, aliasing) 보이는 것을 확인할 수 있다. `lineType=cv2.LINE_AA`를 지정하면 안티앨리어싱(anti-aliasing)이 적용되어, 경계 픽셀의 색을 주변과 부드럽게 섞어 훨씬 매끄러운 곡선과 글자를 얻을 수 있다.

```python
import cv2
import numpy as np

img = np.zeros((300, 600, 3), dtype=np.uint8)

# 왼쪽: 기본 (LINE_8), 오른쪽: 안티앨리어싱 (LINE_AA)
cv2.circle(img, (150, 150), 100, (0, 255, 0), 2, cv2.LINE_8)
cv2.circle(img, (450, 150), 100, (0, 255, 0), 2, cv2.LINE_AA)

cv2.putText(img, "LINE_8", (90, 280), cv2.FONT_HERSHEY_SIMPLEX, 0.8, (255, 255, 255), 1, cv2.LINE_8)
cv2.putText(img, "LINE_AA", (390, 280), cv2.FONT_HERSHEY_SIMPLEX, 0.8, (255, 255, 255), 1, cv2.LINE_AA)

cv2.imshow("Anti-aliasing Comparison", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`line`, `rectangle`, `circle`, `ellipse`, `polylines`, `putText` 등 곡선이나 사선을 포함하는 대부분의 그리기 함수는 `lineType` 인자로 `cv2.LINE_AA`를 받을 수 있다. 다만 안티앨리어싱은 경계 픽셀을 섞는 추가 연산이 필요하므로 기본값보다 약간 느리다. 실시간으로 매 프레임 그림을 그려야 하는 영상 처리 파이프라인에서는 성능이 중요하다면 기본값(`LINE_8`)을, 사진처럼 한 번만 그려서 결과물의 품질이 중요하다면 `LINE_AA`를 선택하는 것이 일반적인 기준이다.

## 6.11 실전: 마우스로 직접 그리는 인터랙티브 프로그램

지금까지는 좌표를 코드에 직접 숫자로 적어 넣었지만, 실제 응용 프로그램에서는 사용자가 마우스로 클릭하거나 드래그한 위치에 맞춰 그림을 그려야 하는 경우가 많다. 예를 들어 관심 영역(ROI)을 사용자가 직접 지정하게 하거나, 어노테이션(주석) 도구를 만들 때 이런 상호작용이 필요하다. OpenCV는 `cv2.setMouseCallback`으로 윈도우에 마우스 이벤트 처리 함수를 등록할 수 있게 해준다.

### 마우스 이벤트의 기본 구조

마우스 콜백 함수는 항상 다음과 같은 고정된 형태를 가진다.

```python
def mouse_callback(event, x, y, flags, param):
    # event: 어떤 종류의 마우스 동작이 일어났는지 (클릭, 이동, 뗌 등)
    # x, y: 이벤트가 발생한 시점의 마우스 좌표
    # flags: Shift, Ctrl 키 등 추가 상태 정보
    # param: setMouseCallback에 넘긴 사용자 정의 데이터
    ...
```

자주 사용하는 이벤트 상수는 다음과 같다.

| 상수 | 의미 |
|---|---|
| `cv2.EVENT_LBUTTONDOWN` | 마우스 왼쪽 버튼을 누른 순간 |
| `cv2.EVENT_MOUSEMOVE` | 마우스가 움직이는 동안 (버튼을 누르지 않아도 계속 발생) |
| `cv2.EVENT_LBUTTONUP` | 마우스 왼쪽 버튼을 뗀 순간 |
| `cv2.EVENT_RBUTTONDOWN` | 마우스 오른쪽 버튼을 누른 순간 |
| `cv2.EVENT_LBUTTONDBLCLK` | 마우스 왼쪽 버튼을 더블클릭한 순간 |

### 예제: 드래그로 사각형 그리기

버튼을 누른 위치와 뗀 위치를 각각 시작점과 끝점으로 삼아 사각형을 그리는 프로그램을 만들어보자. 핵심은 "드래그 중"이라는 상태와 "시작점"을 함수 바깥의 변수에 계속 유지해야 한다는 점이다.

```python
import cv2
import numpy as np

drawing = False       # 현재 드래그 중인지 여부
start_point = (0, 0)  # 드래그가 시작된 좌표

canvas = np.zeros((500, 700, 3), dtype=np.uint8)


def draw_rectangle(event, x, y, flags, param):
    global drawing, start_point, canvas

    if event == cv2.EVENT_LBUTTONDOWN:
        drawing = True
        start_point = (x, y)

    elif event == cv2.EVENT_MOUSEMOVE:
        if drawing:
            # 매 프레임 다시 그리기 위해, 원본 캔버스를 복사한 임시 이미지에
            # "드래그 중인 사각형"을 그려서 미리보기를 보여준다.
            preview = canvas.copy()
            cv2.rectangle(preview, start_point, (x, y), (0, 255, 0), 2)
            cv2.imshow("Draw", preview)

    elif event == cv2.EVENT_LBUTTONUP:
        drawing = False
        # 실제로 캔버스에 확정해서 그린다.
        cv2.rectangle(canvas, start_point, (x, y), (0, 255, 0), 2)
        cv2.imshow("Draw", canvas)


cv2.namedWindow("Draw")
cv2.setMouseCallback("Draw", draw_rectangle)

cv2.imshow("Draw", canvas)
while True:
    key = cv2.waitKey(1) & 0xFF
    if key == 27:   # ESC로 종료
        break
    elif key == ord("c"):   # 'c' 키로 캔버스 지우기
        canvas[:] = 0
        cv2.imshow("Draw", canvas)

cv2.destroyAllWindows()
```

이 코드에서 눈여겨볼 부분은 세 가지다.

1. **상태를 함수 바깥에 유지한다**: 마우스 콜백은 이벤트가 발생할 때마다 독립적으로 호출되므로, "지금 드래그 중인가?", "드래그가 시작된 좌표는 어디였나?" 같은 정보를 콜백 함수 자신은 기억하지 못한다. 그래서 `drawing`, `start_point`, `canvas`를 함수 바깥(전역 스코프)에 두고 `global` 키워드로 함수 안에서 값을 갱신할 수 있게 했다.
2. **미리보기와 확정을 구분한다**: `EVENT_MOUSEMOVE`에서는 매번 `canvas.copy()`로 복사본을 만들어 그 위에 사각형을 그린 뒤 화면에 보여준다. 이렇게 하면 마우스를 움직이는 동안 사각형이 실시간으로 커지거나 작아지는 것처럼 보이지만, 원본 `canvas`는 아직 아무것도 그려지지 않은 상태로 유지된다. 버튼을 뗀 `EVENT_LBUTTONUP` 시점에만 실제로 `canvas`에 사각형을 확정해서 그린다. 이 구분이 없다면 마우스를 움직일 때마다 이전에 그렸던 미리보기 선이 캔버스에 겹겹이 남아버린다.
3. **메인 루프는 키 입력만 처리한다**: 그림 자체는 마우스 콜백 안에서 이미 `cv2.imshow`로 갱신되므로, `while` 루프는 `cv2.waitKey`로 키보드 입력(종료, 캔버스 지우기)만 처리하면 된다. `cv2.waitKey`를 호출하지 않으면 OpenCV의 이벤트 루프 자체가 돌지 않아 마우스 콜백도 호출되지 않으므로, 루프는 반드시 필요하다.

### 예제: 자유롭게 선 그리기 (그림판처럼)

버튼을 누른 상태로 움직이는 동안 계속 짧은 선을 이어 그리면, 마치 그림판처럼 자유롭게 선을 그릴 수 있다.

```python
import cv2
import numpy as np

drawing = False
last_point = None

canvas = np.zeros((500, 700, 3), dtype=np.uint8)


def free_draw(event, x, y, flags, param):
    global drawing, last_point

    if event == cv2.EVENT_LBUTTONDOWN:
        drawing = True
        last_point = (x, y)

    elif event == cv2.EVENT_MOUSEMOVE:
        if drawing and last_point is not None:
            cv2.line(canvas, last_point, (x, y), (0, 200, 255), 3, cv2.LINE_AA)
            last_point = (x, y)
            cv2.imshow("Free Draw", canvas)

    elif event == cv2.EVENT_LBUTTONUP:
        drawing = False
        last_point = None


cv2.namedWindow("Free Draw")
cv2.setMouseCallback("Free Draw", free_draw)
cv2.imshow("Free Draw", canvas)

while True:
    if cv2.waitKey(1) & 0xFF == 27:
        break

cv2.destroyAllWindows()
```

여기서는 미리보기와 확정을 구분할 필요가 없다. 마우스가 움직일 때마다 "바로 직전 위치"에서 "현재 위치"까지 짧은 선분을 캔버스에 곧바로 그려 넣고, 그 현재 위치를 다음 번 시작점(`last_point`)으로 갱신하는 방식이다. 이렇게 짧은 선분을 계속 이어 붙이면 매끄러운 곡선처럼 보이는 자유선이 완성된다. 이 패턴은 세그멘테이션 작업을 위한 마스크를 사람이 손으로 직접 그려주는 도구, 또는 이미지 위에 주석을 표시하는 라벨링 도구의 기초가 된다.

## 6.12 반투명 텍스트 배경으로 가독성 높이기

사진 위에 텍스트를 바로 얹으면, 배경이 텍스트와 비슷한 색이거나 무늬가 복잡할 때 글자가 잘 보이지 않는 경우가 많다. 이를 해결하는 방법 중 하나는 글자 뒤에 불투명한 배경 사각형을 까는 것이지만, 이는 뒤의 이미지 내용을 완전히 가려버린다. 조금 더 세련된 방법은 **반투명한 배경 박스**를 까는 것이다. 이 기법은 7장에서 본격적으로 다룰 `cv2.addWeighted`(두 이미지를 가중치로 섞는 함수)를 미리 활용한다.

```python
import cv2
import numpy as np

img = cv2.imread("street.jpg")

text = "Person detected"
x, y = 50, 50
font = cv2.FONT_HERSHEY_SIMPLEX
scale = 0.8
thickness = 2

(text_w, text_h), baseline = cv2.getTextSize(text, font, scale, thickness)

# 1. 원본과 같은 크기의 복사본(overlay)을 만들고, 그 위에만 불투명한 박스를 그린다.
overlay = img.copy()
box_tl = (x, y - text_h - baseline - 6)
box_br = (x + text_w + 10, y + baseline)
cv2.rectangle(overlay, box_tl, box_br, (0, 0, 0), cv2.FILLED)

# 2. overlay와 원본 img를 지정한 비율로 섞어서, 박스 부분만 반투명하게 만든다.
alpha = 0.5  # overlay(박스)의 반영 비율. 0에 가까울수록 원본이 그대로 보인다.
blended = cv2.addWeighted(overlay, alpha, img, 1 - alpha, 0)

# 3. 반투명 박스가 합성된 이미지 위에 글자를 또렷하게(불투명하게) 그린다.
cv2.putText(blended, text, (x + 5, y - baseline - 3),
            font, scale, (255, 255, 255), thickness, cv2.LINE_AA)

cv2.imshow("Original", img)
cv2.imshow("Semi-transparent Label", blended)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

이 기법의 핵심은 "이미지 전체가 아니라 박스가 그려진 부분만 반투명하게 만든다"는 점이다. `img`를 통째로 복사한 `overlay`에만 불투명한 검은 박스를 그린 뒤, `cv2.addWeighted(overlay, alpha, img, 1 - alpha, 0)`로 `overlay`와 원본 `img`를 섞으면, 박스가 그려지지 않은 나머지 영역은 `overlay`와 `img`가 완전히 같은 값이므로 섞어도 원본 그대로 유지되고, 박스가 그려진 영역만 검은색과 원본이 `alpha : (1 - alpha)` 비율로 섞여 반투명한 검은 막처럼 보이게 된다. 마지막으로 글자 자체는 반투명하게 만들지 않고 또렷한 흰색으로 그려야 가독성이 유지된다는 점도 중요하다. `cv2.addWeighted`의 정확한 동작 원리와 각 인자의 의미는 7장에서 이미지 연산을 다룰 때 자세히 설명한다.

## 6.13 실전: 객체 검출 결과 시각화 함수 완성하기

이제 이번 장에서 배운 모든 요소, 즉 사각형, 텍스트, `getTextSize`, 그리고 반투명 배경 기법을 하나로 합쳐서, 실무에서 바로 재사용할 수 있는 완성된 시각화 함수를 작성해보자. 어떤 객체 검출 알고리즘이 이미지 안에서 여러 물체를 찾아 각각 "바운딩 박스", "클래스 이름", "신뢰도(confidence)"를 반환했다고 가정한다. 17장에서 실제 딥러닝 기반 객체 검출기를 다룰 때도, 검출 결과를 화면에 표시하는 마지막 단계는 바로 이 함수를 거의 그대로 사용하게 된다.

```python
import cv2
import numpy as np


def draw_detections(image, detections, font=cv2.FONT_HERSHEY_SIMPLEX,
                      font_scale=0.5, thickness=1, box_thickness=2,
                      alpha=0.6):
    """객체 검출 결과를 이미지 위에 시각화한다.

    Parameters
    ----------
    image : np.ndarray
        검출을 그릴 원본 BGR 이미지. 이 함수는 원본을 바꾸지 않고
        새 이미지를 반환한다.
    detections : list of dict
        각 원소는 다음 키를 가진 딕셔너리다.
        - "box": (x1, y1, x2, y2) 형태의 바운딩 박스 좌표
        - "label": 클래스 이름 문자열
        - "score": 0.0 ~ 1.0 사이의 신뢰도
        - "color": (B, G, R) 형태의 표시 색상 (생략 시 초록색)
    font, font_scale, thickness : 레이블 텍스트의 폰트 설정
    box_thickness : 바운딩 박스 테두리의 두께
    alpha : 레이블 배경의 불투명도(0~1). 1이면 완전히 불투명.

    Returns
    -------
    np.ndarray
        검출 결과가 그려진 새 이미지.
    """
    output = image.copy()
    overlay = image.copy()

    # 먼저 모든 레이블 배경 박스를 overlay에 그려 모은다.
    label_positions = []
    for det in detections:
        x1, y1, x2, y2 = det["box"]
        label = f'{det["label"]} {det["score"]:.2f}'
        color = det.get("color", (0, 255, 0))

        (text_w, text_h), baseline = cv2.getTextSize(label, font, font_scale, thickness)

        # 레이블은 기본적으로 박스 위쪽에 배치하되, 화면 위쪽 경계를 벗어나면
        # 박스 안쪽(아래로 내려서) 배치한다.
        label_y_bottom = y1 - 4
        if label_y_bottom - text_h - baseline < 0:
            label_y_bottom = y1 + text_h + baseline + 4

        bg_top_left = (x1, label_y_bottom - text_h - baseline - 4)
        bg_bottom_right = (x1 + text_w + 8, label_y_bottom)

        cv2.rectangle(overlay, bg_top_left, bg_bottom_right, color, cv2.FILLED)
        label_positions.append((label, x1 + 4, label_y_bottom - baseline - 2, color))

    # 배경 박스만 반투명하게 원본과 합성한다.
    output = cv2.addWeighted(overlay, alpha, output, 1 - alpha, 0)

    # 바운딩 박스 테두리와 레이블 텍스트는 항상 또렷하게(불투명하게) 그린다.
    for det in detections:
        x1, y1, x2, y2 = det["box"]
        color = det.get("color", (0, 255, 0))
        cv2.rectangle(output, (x1, y1), (x2, y2), color, box_thickness, cv2.LINE_AA)

    for label, tx, ty, color in label_positions:
        # 밝은 배경색 위에서도 잘 보이도록 글자는 흰색으로 통일한다.
        cv2.putText(output, label, (tx, ty), font, font_scale,
                    (255, 255, 255), thickness, cv2.LINE_AA)

    return output


if __name__ == "__main__":
    img = cv2.imread("street.jpg")

    detections = [
        {"box": (120, 80, 260, 320), "label": "person", "score": 0.93,
         "color": (0, 255, 0)},
        {"box": (300, 150, 480, 260), "label": "car", "score": 0.87,
         "color": (255, 128, 0)},
        {"box": (10, 10, 130, 90), "label": "dog", "score": 0.61,
         "color": (0, 165, 255)},
    ]

    result = draw_detections(img, detections)

    cv2.imshow("Original", img)
    cv2.imshow("Detections", result)
    cv2.waitKey(0)
    cv2.destroyAllWindows()
```

이 함수에서 눈여겨볼 설계 결정 몇 가지를 짚어보자.

- **원본을 훼손하지 않는다**: 함수는 `image.copy()`로 작업용 복사본을 만들고 그 위에만 그림을 그려서 반환한다. 호출한 쪽의 원본 배열은 그대로 남아 있으므로, 같은 이미지에 여러 시각화 방식을 실험해보거나 나중에 원본이 다시 필요할 때 안전하다.
- **배경 박스는 한 번에 모아서 합성한다**: 검출 결과가 여러 개일 때 `addWeighted`를 검출마다 반복해서 호출하면 겹치는 영역의 투명도가 누적되어 예상치 못한 결과가 나올 수 있다. 그래서 모든 배경 박스를 `overlay`라는 하나의 이미지에 먼저 다 그려놓고, 원본과 딱 한 번만 `addWeighted`로 합성하는 방식을 택했다.
- **화면 경계를 벗어나는 경우를 처리한다**: 물체가 이미지 맨 위쪽에 걸쳐 있으면, 레이블을 박스 "위"에 그리려 할 때 좌표가 음수가 되어 화면 밖으로 나가버린다. `label_y_bottom - text_h - baseline < 0` 조건으로 이런 경우를 감지해서, 레이블을 박스 바깥 위쪽이 아니라 박스 안쪽 상단으로 옮겨 그리도록 예외 처리를 했다. 실전 코드에서는 이런 "경계 조건" 처리가 시각화 품질에 큰 영향을 준다.
- **`getTextSize`로 배경 크기를 텍스트에 맞춘다**: 클래스 이름과 신뢰도 점수를 합친 문자열의 길이는 검출마다 다르므로, `cv2.getTextSize`로 실제 렌더링될 크기를 미리 계산해서 배경 박스 크기를 동적으로 정한다. 이렇게 하면 "person 0.93"처럼 짧은 레이블이든 "bicycle 0.58"처럼 긴 레이블이든 배경이 항상 글자에 딱 맞게 그려진다.
- **테두리와 글자는 불투명하게 유지한다**: 배경만 반투명하게 처리하고, 바운딩 박스의 테두리 선과 레이블 글자 자체는 마지막에 원본 위(합성이 끝난 `output`)에 또렷하게 덧그린다. 이렇게 해야 여러 검출 결과가 겹쳐 있어도 각 테두리와 글자를 분명하게 구별할 수 있다.

이 `draw_detections` 함수는 지금은 임의로 만든 `detections` 리스트를 입력으로 받지만, 17장에서 실제 딥러닝 모델의 추론 결과를 같은 형식(박스, 레이블, 점수)으로만 변환해서 넘겨주면 그대로 재사용할 수 있다. 이처럼 "시각화 로직"과 "검출 로직"을 분리해서 설계하는 방식은 실제 컴퓨터 비전 프로젝트에서도 매우 흔한 구조다.

## 요약

- OpenCV의 모든 그리기 함수는 색상을 `(B, G, R)` 튜플로 받는다. 순서를 혼동하면 의도한 색과 정반대의 색이 그려질 수 있다.
- `cv2.line`, `cv2.rectangle`, `cv2.circle`은 각각 직선, 사각형, 원을 그리며, 두께를 `-1`(또는 `cv2.FILLED`)로 지정하면 내부가 채워진다.
- `cv2.polylines`는 여러 점을 이어 다각형을 그리며(`isClosed`로 닫힌 도형 여부 지정), `cv2.fillPoly`는 내부가 채워진 다각형을 그린다.
- `cv2.arrowedLine`은 방향을 나타내는 화살표를, `cv2.ellipse`는 회전·부분 호를 포함한 타원을 그린다.
- `cv2.putText`는 폰트, 크기, 색상, 두께를 지정해 텍스트를 그리며, 좌표는 텍스트의 좌측 하단 기준선을 기준으로 한다. `cv2.FONT_HERSHEY_*` 상수로 다양한 폰트를 선택할 수 있고, `lineType=cv2.LINE_AA`로 안티앨리어싱을 적용하면 훨씬 매끄러운 결과를 얻는다.
- `cv2.setMouseCallback`으로 등록한 콜백 함수에서 `EVENT_LBUTTONDOWN`/`EVENT_MOUSEMOVE`/`EVENT_LBUTTONUP` 이벤트를 처리하면, 사용자가 마우스로 직접 도형을 그리는 인터랙티브 프로그램을 만들 수 있다. 이때 드래그 상태는 콜백 바깥의 변수로 유지해야 한다.
- `cv2.addWeighted`로 복사본 이미지에만 그린 배경 박스를 원본과 합성하면, 특정 영역만 반투명하게 만들어 가독성을 높일 수 있다.
- `cv2.getTextSize`로 텍스트 크기를 미리 계산하면, 바운딩 박스와 레이블을 함께 그리는 객체 검출 시각화 패턴을 어떤 텍스트 길이에도 깔끔하게 맞출 수 있다. 이 원리를 확장하면 여러 검출 결과를 한 번에 시각화하는 재사용 가능한 함수를 만들 수 있다.

## 연습문제

1. 색상을 `(0, 0, 255)`가 아니라 `(255, 0, 0)`으로 주고 사각형을 그렸을 때 실제로 어떤 색이 나오는지 실행해보고, 왜 그런지 BGR 순서로 설명해 보라.
2. `cv2.LINE_8`과 `cv2.LINE_AA`로 같은 원을 각각 그린 뒤 이미지를 확대(zoom)해서 경계 픽셀이 어떻게 다른지 비교해 보라.
3. `cv2.polylines`로 별 모양(5개 꼭짓점을 안쪽 점과 바깥쪽 점이 교차하도록 배치)을 그리는 좌표 목록을 만들어 구현하고, `cv2.fillPoly`로 내부를 채운 버전도 함께 만들어 보라.
4. 6.11절의 자유선 그리기 예제를 확장해서, 's' 키를 누르면 현재 캔버스를 파일로 저장하고 'c' 키를 누르면 캔버스를 지우도록 기능을 추가해 보라.
5. 6.13절의 `draw_detections` 함수에 새로운 옵션을 추가해서, `score`가 특정 임계값(예: 0.5) 미만인 검출 결과는 화면에 그리지 않고 건너뛰도록 수정해 보라.
