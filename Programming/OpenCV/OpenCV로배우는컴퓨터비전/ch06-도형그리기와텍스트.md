## 6.1 왜 도형을 그리는가

지금까지는 이미지를 읽고, 색공간을 바꾸고, 화면에 표시하는 방법을 다뤘다. 이번 장에서는 이미지 위에 직접 무언가를 "그리는" 방법을 배운다. 단순히 예쁜 그림을 그리자는 것이 아니다. 컴퓨터 비전에서 도형 그리기는 대부분 **분석 결과를 시각적으로 확인하기 위한 도구**로 쓰인다.

예를 들어 얼굴 검출 알고리즘이 이미지 어딘가에서 얼굴을 찾았다면, 그 좌표를 콘솔에 숫자로만 찍어서는 결과가 맞는지 직관적으로 확인하기 어렵다. 대신 찾아낸 위치에 사각형을 그리고 "Face"라는 레이블을 붙이면, 결과가 한눈에 들어온다. 12장의 컨투어 분석, 15장의 특징점 매칭, 17장의 객체 검출 모두 이번 장에서 배우는 그리기 함수를 결과 시각화 도구로 사용한다. 그러니 이번 장의 예제들은 단순한 그림 그리기 연습이 아니라, 앞으로 계속 재사용할 "결과 보여주기"의 표준 패턴을 익히는 과정이라고 생각하면 된다.

## 6.2 색상 표현 방식: 세 언어의 차이

도형을 그리려면 먼저 색을 지정하는 방법을 알아야 한다. 5장에서 다룬 것처럼 OpenCV는 항상 **BGR 순서**로 색을 다루며, 이는 도형을 그릴 때도 예외 없이 적용된다. 다만 이 BGR 값을 함수에 전달하는 문법은 언어마다 조금씩 다르다.

| 언어 | 색상 표현 | 예: 순수한 빨간색 |
|---|---|---|
| Python | `(B, G, R)` 튜플 | `(0, 0, 255)` |
| C++ | `cv::Scalar(B, G, R)` | `cv::Scalar(0, 0, 255)` |
| C# | `Scalar(B, G, R)` | `new Scalar(0, 0, 255)` |

세 경우 모두 **첫 번째 값이 Blue, 마지막 값이 Red**라는 점을 다시 한번 강조한다. `(255, 0, 0)`을 "빨간색"이라는 느낌으로 실수로 쓰면, 실제로는 파란색이 그려진다. RGB 감각이 익숙한 사람일수록 이 실수를 자주 하므로, 색을 지정할 때마다 "이건 BGR이다"를 의식적으로 되새기는 습관이 필요하다. C++와 C#의 `Scalar`는 최대 4개의 값을 받을 수 있어 `Scalar(B, G, R, alpha)` 형태로 투명도 채널까지 지정할 수 있지만, 일반적인 3채널 이미지에서는 앞의 3개 값만 사용된다.

## 6.3 직선 그리기: `line`

가장 단순한 도형인 직선부터 시작한다. `line` 함수는 시작점과 끝점, 색상, 선의 두께를 받는다.

### Python

```python
import cv2
import numpy as np

img = np.zeros((400, 500, 3), dtype=np.uint8)

cv2.line(img, (50, 50), (450, 50), (0, 255, 0), 3)

cv2.imshow("Line", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img = cv::Mat::zeros(400, 500, CV_8UC3);

    cv::line(img, cv::Point(50, 50), cv::Point(450, 50),
              cv::Scalar(0, 255, 0), 3);

    cv::imshow("Line", img);
    cv::waitKey(0);
    return 0;
}
```

### C#

```csharp
using OpenCvSharp;

Mat img = new Mat(400, 500, MatType.CV_8UC3, Scalar.Black);

Cv2.Line(img, new Point(50, 50), new Point(450, 50),
         new Scalar(0, 255, 0), 3);

Cv2.ImShow("Line", img);
Cv2.WaitKey(0);
```

좌표는 세 언어 모두 `(x, y)` 순서로 지정한다. 이는 3장에서 다룬 배열 인덱싱의 `(row, col)`, 즉 `(y, x)` 순서와는 반대이므로 혼동하지 않도록 주의한다. 도형 그리기 함수의 좌표 인자는 항상 "가로(x), 세로(y)"라는 사람에게 익숙한 순서를 따른다.

## 6.4 사각형 그리기: `rectangle`

`rectangle`은 좌상단(top-left)과 우하단(bottom-right) 두 점을 받아 그 사이를 사각형으로 그린다. 두께에 음수(예: `-1` 또는 `cv2.FILLED`)를 지정하면 테두리가 아니라 내부가 채워진 사각형이 된다.

### Python

```python
import cv2
import numpy as np

img = np.zeros((400, 500, 3), dtype=np.uint8)

cv2.rectangle(img, (100, 80), (300, 220), (255, 0, 0), 2)          # 테두리만
cv2.rectangle(img, (320, 80), (420, 220), (0, 0, 255), cv2.FILLED)  # 채워진 사각형

cv2.imshow("Rectangle", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img = cv::Mat::zeros(400, 500, CV_8UC3);

    cv::rectangle(img, cv::Point(100, 80), cv::Point(300, 220),
                   cv::Scalar(255, 0, 0), 2);
    cv::rectangle(img, cv::Point(320, 80), cv::Point(420, 220),
                   cv::Scalar(0, 0, 255), cv::FILLED);

    cv::imshow("Rectangle", img);
    cv::waitKey(0);
    return 0;
}
```

### C#

```csharp
using OpenCvSharp;

Mat img = new Mat(400, 500, MatType.CV_8UC3, Scalar.Black);

Cv2.Rectangle(img, new Point(100, 80), new Point(300, 220),
              new Scalar(255, 0, 0), 2);
Cv2.Rectangle(img, new Point(320, 80), new Point(420, 220),
              new Scalar(0, 0, 255), -1);

Cv2.ImShow("Rectangle", img);
Cv2.WaitKey(0);
```

`cv2.FILLED`, `cv::FILLED`는 모두 `-1`을 의미하는 상수일 뿐이므로, C#에서처럼 그냥 `-1`을 직접 써도 동일하게 동작한다. 사각형은 뒤에서 볼 예제처럼 객체 검출 결과의 바운딩 박스(bounding box)를 표시하는 데 가장 많이 쓰이는 도형이다.

## 6.5 원 그리기: `circle`

`circle`은 중심점과 반지름을 받는다. 사각형과 마찬가지로 두께에 `-1`을 주면 내부가 채워진 원이 된다.

### Python

```python
import cv2
import numpy as np

img = np.zeros((400, 500, 3), dtype=np.uint8)

cv2.circle(img, (150, 200), 60, (0, 255, 255), 2)
cv2.circle(img, (350, 200), 60, (255, 0, 255), -1)

cv2.imshow("Circle", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img = cv::Mat::zeros(400, 500, CV_8UC3);

    cv::circle(img, cv::Point(150, 200), 60, cv::Scalar(0, 255, 255), 2);
    cv::circle(img, cv::Point(350, 200), 60, cv::Scalar(255, 0, 255), -1);

    cv::imshow("Circle", img);
    cv::waitKey(0);
    return 0;
}
```

### C#

```csharp
using OpenCvSharp;

Mat img = new Mat(400, 500, MatType.CV_8UC3, Scalar.Black);

Cv2.Circle(img, new Point(150, 200), 60, new Scalar(0, 255, 255), 2);
Cv2.Circle(img, new Point(350, 200), 60, new Scalar(255, 0, 255), -1);

Cv2.ImShow("Circle", img);
Cv2.WaitKey(0);
```

원은 특징점(15장)의 위치를 표시하거나, 검출된 얼굴에서 눈의 위치처럼 특정 지점을 강조할 때 자주 사용된다.

## 6.6 다각형 그리기: `polylines`

`polylines`는 여러 개의 점을 순서대로 이어 다각형(또는 꺾인 선)을 그린다. 사각형이나 원과 달리, 좌표를 하나의 정수 배열로 모아서 전달해야 하며, 이 배열을 준비하는 방식이 언어별로 조금 다르다.

### Python

```python
import cv2
import numpy as np

img = np.zeros((400, 500, 3), dtype=np.uint8)

pts = np.array([[100, 300], [150, 200], [250, 220],
                 [280, 320], [180, 350]], dtype=np.int32)
pts = pts.reshape((-1, 1, 2))

cv2.polylines(img, [pts], isClosed=True, color=(0, 165, 255), thickness=2)

cv2.imshow("Polygon", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### C++

```cpp
#include <opencv2/opencv.hpp>
#include <vector>

int main() {
    cv::Mat img = cv::Mat::zeros(400, 500, CV_8UC3);

    std::vector<cv::Point> pts = {
        {100, 300}, {150, 200}, {250, 220}, {280, 320}, {180, 350}
    };

    cv::polylines(img, pts, true, cv::Scalar(0, 165, 255), 2);

    cv::imshow("Polygon", img);
    cv::waitKey(0);
    return 0;
}
```

### C#

```csharp
using OpenCvSharp;

Mat img = new Mat(400, 500, MatType.CV_8UC3, Scalar.Black);

Point[] pts = new Point[] {
    new Point(100, 300), new Point(150, 200), new Point(250, 220),
    new Point(280, 320), new Point(180, 350)
};

Cv2.Polylines(img, new[] { pts }, true, new Scalar(0, 165, 255), 2);

Cv2.ImShow("Polygon", img);
Cv2.WaitKey(0);
```

Python에서 `pts.reshape((-1, 1, 2))`로 배열의 형태를 바꿔주는 이유는, `polylines`가 내부적으로 "여러 개의 다각형" 목록을 받도록 설계되어 있기 때문이다. C++와 C#에서도 각각 `std::vector<cv::Point>`를 다시 한번 리스트로 감싸거나(`pts`를 그대로 vector-of-vector로 넘기는 오버로드도 존재), 배열을 `new[] { pts }`처럼 감싸는 형태로 이 구조를 반영하고 있다. `isClosed`를 `true`로 주면 마지막 점과 첫 점이 자동으로 이어져 닫힌 도형이 되고, `false`로 주면 열린 꺾은선이 된다.

## 6.7 텍스트 그리기: `putText`

`putText`는 이미지 위에 문자열을 그려주는 함수로, 폰트 종류, 크기(scale), 색상, 두께를 함께 지정한다. 폰트는 OpenCV가 내부적으로 제공하는 벡터 폰트 중 하나를 상수로 선택하며, 가장 널리 쓰이는 것은 `FONT_HERSHEY_SIMPLEX`다.

### Python

```python
import cv2
import numpy as np

img = np.zeros((200, 500, 3), dtype=np.uint8)

cv2.putText(img, "OpenCV", (50, 100),
            cv2.FONT_HERSHEY_SIMPLEX, 1.5, (0, 255, 0), 2)

cv2.imshow("Text", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img = cv::Mat::zeros(200, 500, CV_8UC3);

    cv::putText(img, "OpenCV", cv::Point(50, 100),
                 cv::FONT_HERSHEY_SIMPLEX, 1.5, cv::Scalar(0, 255, 0), 2);

    cv::imshow("Text", img);
    cv::waitKey(0);
    return 0;
}
```

### C#

```csharp
using OpenCvSharp;

Mat img = new Mat(200, 500, MatType.CV_8UC3, Scalar.Black);

Cv2.PutText(img, "OpenCV", new Point(50, 100),
            HersheyFonts.HersheySimplex, 1.5, new Scalar(0, 255, 0), 2);

Cv2.ImShow("Text", img);
Cv2.WaitKey(0);
```

`putText`의 좌표는 사각형이나 원과 달리 문자열의 "좌측 하단(baseline 기준선의 왼쪽 끝)"을 기준으로 삼는다는 점에 주의해야 한다. 즉 `(50, 100)`은 글자가 시작되는 왼쪽 아래 모서리 근처이며, 글자 대부분은 이 y좌표보다 위쪽에 그려진다. 이 특성은 다음 절의 실전 예제에서 레이블의 위치를 잡을 때 중요하게 작용한다.

## 6.8 실전 예제: 객체 검출 결과 시각화 패턴

이제 배운 함수들을 조합해서, 실제 컴퓨터 비전 응용에서 가장 자주 반복되는 패턴을 만들어보자. 어떤 객체 검출 알고리즘이 이미지 안에서 물체를 찾아 "바운딩 박스(사각형 좌표)"와 "클래스 이름", "신뢰도(confidence)"를 반환했다고 가정한다. 이 결과를 사람이 한눈에 확인할 수 있도록, 사각형과 레이블 텍스트를 함께 그려주는 것이 표준적인 시각화 방법이다. 17장에서 실제 얼굴/객체 검출기를 다룰 때도 검출 결과를 화면에 표시하는 마지막 단계는 바로 이 패턴을 그대로 사용한다.

레이블을 그릴 때는 텍스트만 덜렁 올려두기보다, 배경에 색이 채워진 작은 사각형을 먼저 그리고 그 위에 흰색 글자를 얹으면 어떤 배경 위에서도 글자가 잘 보인다는 실용적인 이유로 이 방식이 널리 쓰인다.

### Python

```python
import cv2
import numpy as np

img = cv2.imread("street.jpg")

# 객체 검출기가 반환했다고 가정한 결과
box = (120, 80, 260, 220)   # (x1, y1, x2, y2)
label = "person 0.93"

x1, y1, x2, y2 = box
color = (0, 255, 0)

# 1. 바운딩 박스 그리기
cv2.rectangle(img, (x1, y1), (x2, y2), color, 2)

# 2. 레이블 텍스트 크기를 미리 계산해 배경 사각형 크기를 정한다.
(text_w, text_h), baseline = cv2.getTextSize(
    label, cv2.FONT_HERSHEY_SIMPLEX, 0.6, 1)

# 3. 텍스트 배경(채워진 사각형)을 박스 바로 위에 그린다.
cv2.rectangle(img, (x1, y1 - text_h - baseline - 4),
              (x1 + text_w + 4, y1), color, cv2.FILLED)

# 4. 배경 위에 흰색 글자로 레이블을 올린다.
cv2.putText(img, label, (x1 + 2, y1 - baseline - 2),
            cv2.FONT_HERSHEY_SIMPLEX, 0.6, (255, 255, 255), 1)

cv2.imshow("Detection", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img = cv::imread("street.jpg");

    // 객체 검출기가 반환했다고 가정한 결과
    cv::Rect box(120, 80, 140, 140);   // (x, y, width, height)
    std::string label = "person 0.93";
    cv::Scalar color(0, 255, 0);

    // 1. 바운딩 박스 그리기
    cv::rectangle(img, box, color, 2);

    // 2. 레이블 텍스트 크기를 미리 계산한다.
    int baseline = 0;
    cv::Size textSize = cv::getTextSize(
        label, cv::FONT_HERSHEY_SIMPLEX, 0.6, 1, &baseline);

    // 3. 텍스트 배경 사각형을 박스 바로 위에 그린다.
    cv::Point textOrigin(box.x, box.y);
    cv::rectangle(img,
                   cv::Point(textOrigin.x, textOrigin.y - textSize.height - baseline - 4),
                   cv::Point(textOrigin.x + textSize.width + 4, textOrigin.y),
                   color, cv::FILLED);

    // 4. 배경 위에 흰색 글자로 레이블을 올린다.
    cv::putText(img, label, cv::Point(textOrigin.x + 2, textOrigin.y - baseline - 2),
                 cv::FONT_HERSHEY_SIMPLEX, 0.6, cv::Scalar(255, 255, 255), 1);

    cv::imshow("Detection", img);
    cv::waitKey(0);
    return 0;
}
```

### C#

```csharp
using OpenCvSharp;

Mat img = Cv2.ImRead("street.jpg");

// 객체 검출기가 반환했다고 가정한 결과
Rect box = new Rect(120, 80, 140, 140); // (x, y, width, height)
string label = "person 0.93";
Scalar color = new Scalar(0, 255, 0);

// 1. 바운딩 박스 그리기
Cv2.Rectangle(img, box, color, 2);

// 2. 레이블 텍스트 크기를 미리 계산한다.
int baseline;
Size textSize = Cv2.GetTextSize(label, HersheyFonts.HersheySimplex, 0.6, 1, out baseline);

// 3. 텍스트 배경 사각형을 박스 바로 위에 그린다.
Point textOrigin = new Point(box.X, box.Y);
Cv2.Rectangle(img,
              new Point(textOrigin.X, textOrigin.Y - textSize.Height - baseline - 4),
              new Point(textOrigin.X + textSize.Width + 4, textOrigin.Y),
              color, -1);

// 4. 배경 위에 흰색 글자로 레이블을 올린다.
Cv2.PutText(img, label, new Point(textOrigin.X + 2, textOrigin.Y - baseline - 2),
            HersheyFonts.HersheySimplex, 0.6, new Scalar(255, 255, 255), 1);

Cv2.ImShow("Detection", img);
Cv2.WaitKey(0);
```

이 패턴에서 눈여겨볼 부분은 `getTextSize`(C#은 `GetTextSize`)다. 이 함수는 실제로 글자를 그리지 않고, 주어진 문자열이 특정 폰트·크기·두께로 그려졌을 때 차지할 가로/세로 크기와 baseline(글자가 걸쳐 있는 기준선에서 아래로 내려가는 부분의 높이, 예를 들어 "g"나 "y"의 아래 꼬리)을 미리 계산해준다. 이를 이용하면 텍스트 길이에 딱 맞는 배경 사각형을 동적으로 만들 수 있어서, 레이블이 짧든 길든 배경이 항상 글자에 맞게 그려진다.

C++와 C#에서는 사각형을 `cv::Rect`/`Rect` 구조체(좌상단 좌표 + 너비 + 높이)로 표현하는 오버로드를 사용했는데, 이는 Python에서 튜플 좌표로 직접 계산하는 것과 동일한 결과를 내지만 좀 더 객체지향적인 방식이라는 점도 함께 알아두면 좋다. 이 시각화 패턴은 뒤에서 배울 12장의 컨투어 바운딩 박스, 17장의 얼굴/객체 검출기 결과를 표시할 때 거의 그대로 재사용될 것이다.

## 요약

- OpenCV의 모든 그리기 함수는 색상을 BGR 순서로 받는다. Python은 `(B, G, R)` 튜플, C++는 `cv::Scalar(B, G, R)`, C#은 `new Scalar(B, G, R)`를 사용하지만 순서는 항상 동일하다.
- `line`, `rectangle`, `circle`은 각각 직선, 사각형, 원을 그리며, 두께를 `-1`(또는 `FILLED`)로 지정하면 내부가 채워진다.
- `polylines`는 여러 점을 이어 다각형을 그리며, 좌표 배열을 준비하는 문법이 언어마다 조금씩 다르다(`isClosed`로 닫힌 도형 여부를 지정).
- `putText`는 폰트, 크기, 색상, 두께를 지정해 텍스트를 그리며, 좌표는 텍스트의 좌측 하단 기준선을 기준으로 한다.
- `getTextSize`(C#: `GetTextSize`)로 텍스트 크기를 미리 계산하면, 바운딩 박스와 레이블을 함께 그리는 객체 검출 시각화 패턴을 어떤 텍스트 길이에도 깔끔하게 맞출 수 있다.

## 연습문제

1. 색상을 `(0, 0, 255)`가 아니라 `(255, 0, 0)`으로 주고 사각형을 그렸을 때 실제로 어떤 색이 나오는지 실행해보고, 왜 그런지 BGR 순서로 설명해 보라.
2. `rectangle`의 두께를 2에서 -1로 바꾸었을 때 결과가 어떻게 달라지는지 직접 실행해서 비교해 보라.
3. `polylines`로 별 모양(5개 꼭짓점을 안쪽 점과 바깥쪽 점이 교차하도록 배치)을 그리는 좌표 목록을 만들어 세 언어 중 하나로 구현해 보라.
4. `putText`에서 좌표를 텍스트의 좌측 상단으로 잘못 해석해서 발생할 수 있는 흔한 실수는 무엇인지, 그리고 왜 좌측 하단(baseline) 기준으로 이해해야 하는지 설명해 보라.
5. 6.8절의 시각화 패턴을 확장해서, 여러 개의 바운딩 박스와 레이블을 리스트로 받아 반복문으로 한 번에 그려주는 함수를 세 언어 중 하나로 작성해 보라.
