## 4.1 이미지 파일 읽기: imread

OpenCV는 `.jpg`, `.png`, `.bmp`를 비롯해 `.tiff`, `.webp` 등 다양한 포맷의 이미지를 읽고 쓸 수 있는 기능을 제공한다. 흥미로운 점은, 파일을 읽는 함수를 호출할 때 포맷을 직접 지정할 필요가 없다는 것이다. OpenCV는 파일의 내용(헤더)을 검사해서 포맷을 자동으로 판별하고, 그에 맞는 디코더를 사용해 파일을 해석한 뒤, 그 결과를 3장에서 다룬 것과 동일한 형태의 배열(픽셀의 3차원 배열)로 돌려준다. 즉 `.jpg`로 읽었든 `.png`로 읽었든, 한 번 메모리에 올라온 뒤에는 완전히 동일한 방식으로 다룰 수 있다.

### Python

```python
import cv2

img_jpg = cv2.imread("photo.jpg")
img_png = cv2.imread("photo.png")
img_bmp = cv2.imread("photo.bmp")

print(type(img_jpg))   # <class 'numpy.ndarray'>
print(img_jpg.shape)    # (높이, 너비, 3)
```

`cv2.imread()`는 파일 경로를 문자열로 받아, 성공하면 3장에서 살펴본 `numpy.ndarray`를 반환한다.

### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img_jpg = cv::imread("photo.jpg");
    cv::Mat img_png = cv::imread("photo.png");
    cv::Mat img_bmp = cv::imread("photo.bmp");

    std::cout << img_jpg.rows << " x " << img_jpg.cols << std::endl;

    return 0;
}
```

C++에서는 `cv::imread()` 함수가 `cv::Mat` 객체를 반환한다.

### C#

```csharp
using OpenCvSharp;

class Program
{
    static void Main()
    {
        Mat imgJpg = Cv2.ImRead("photo.jpg");
        Mat imgPng = Cv2.ImRead("photo.png");
        Mat imgBmp = Cv2.ImRead("photo.bmp");

        System.Console.WriteLine($"{imgJpg.Rows} x {imgJpg.Cols}");
    }
}
```

C#에서는 정적 클래스 `Cv2`의 `ImRead()` 메서드를 사용한다.

## 4.2 컬러/그레이스케일로 읽기 옵션

`imread`(그리고 `ImRead`)는 두 번째 인자로 "어떤 방식으로 이미지를 해석해서 읽어 올 것인가"를 지정하는 플래그를 받을 수 있다. 기본값은 컬러(3채널, BGR)로 읽어 오는 것이지만, 원본 파일이 흑백이든 컬러든 상관없이 그레이스케일(1채널)로 강제 변환해서 읽어 오도록 지정할 수도 있다. 이렇게 하면 나중에 직접 `cv2.cvtColor` 등으로 색공간을 변환하는 단계를 생략할 수 있어 편리하다. 색공간 변환 자체는 5장에서 자세히 다룬다.

### Python

```python
import cv2

# 기본값: 컬러(BGR, 3채널)로 읽기
img_color = cv2.imread("photo.jpg", cv2.IMREAD_COLOR)

# 그레이스케일(1채널)로 읽기
img_gray = cv2.imread("photo.jpg", cv2.IMREAD_GRAYSCALE)

print(img_color.shape)  # (480, 640, 3)
print(img_gray.shape)   # (480, 640)  -> 채널 차원이 사라짐

# 두 번째 인자를 생략하면 IMREAD_COLOR가 기본값으로 적용된다
img_default = cv2.imread("photo.jpg")
```

### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    // 기본값: 컬러(BGR, 3채널)로 읽기
    cv::Mat img_color = cv::imread("photo.jpg", cv::IMREAD_COLOR);

    // 그레이스케일(1채널)로 읽기
    cv::Mat img_gray = cv::imread("photo.jpg", cv::IMREAD_GRAYSCALE);

    std::cout << img_color.channels() << std::endl;  // 3
    std::cout << img_gray.channels() << std::endl;    // 1

    return 0;
}
```

### C#

```csharp
using OpenCvSharp;

class Program
{
    static void Main()
    {
        // 기본값: 컬러(BGR, 3채널)로 읽기
        Mat imgColor = Cv2.ImRead("photo.jpg", ImreadModes.Color);

        // 그레이스케일(1채널)로 읽기
        Mat imgGray = Cv2.ImRead("photo.jpg", ImreadModes.Grayscale);

        System.Console.WriteLine(imgColor.Channels()); // 3
        System.Console.WriteLine(imgGray.Channels());   // 1
    }
}
```

세 언어의 플래그 이름을 표로 정리하면 다음과 같다.

| 읽기 방식 | Python | C++ | C# |
|---|---|---|---|
| 컬러(기본값) | `cv2.IMREAD_COLOR` | `cv::IMREAD_COLOR` | `ImreadModes.Color` |
| 그레이스케일 | `cv2.IMREAD_GRAYSCALE` | `cv::IMREAD_GRAYSCALE` | `ImreadModes.Grayscale` |
| 원본 그대로(알파 채널 포함 등) | `cv2.IMREAD_UNCHANGED` | `cv::IMREAD_UNCHANGED` | `ImreadModes.Unchanged` |

## 4.3 파일을 읽지 못했을 때: 세 언어의 실패 처리 방식 차이

실무에서 가장 자주 발생하는 실수 중 하나가, 파일 경로를 잘못 지정했거나 파일이 손상되었을 때 이를 확인하지 않고 바로 다음 처리를 진행하는 것이다. 이 경우 프로그램은 이상한 위치에서 알아보기 힘든 오류를 내며 멈추기 때문에, 원인을 찾는 데 시간을 낭비하기 쉽다. 세 언어는 "읽기에 실패했다"는 사실을 서로 다른 방식으로 알려주므로, 반드시 각 언어의 관례에 맞는 방법으로 확인해야 한다.

### Python: None을 반환한다

Python에서 `cv2.imread()`가 파일을 열지 못하면 예외(exception)를 던지지 않고 조용히 **`None`을 반환**한다. 따라서 반환값이 `None`인지를 반드시 확인해야 한다.

```python
import cv2
import sys

img = cv2.imread("존재하지않는파일.jpg")

if img is None:
    print("이미지를 읽을 수 없습니다. 경로를 확인하세요.", file=sys.stderr)
    sys.exit(1)

print(img.shape)  # None을 확인하지 않고 이 줄에 도달하면 AttributeError 발생
```

만약 `None` 확인을 생략하고 곧바로 `img.shape`에 접근하면, `NoneType` 객체에는 `shape` 속성이 없으므로 `AttributeError: 'NoneType' object has no attribute 'shape'` 오류가 발생한다. 이 오류 메시지가 나온다면 대부분의 경우 `imread`가 파일을 찾지 못했다는 뜻이니, 경로나 파일명을 먼저 점검해야 한다.

### C++: 빈 Mat이 반환된다 — .empty()로 확인

C++에서 `cv::imread()`가 파일을 열지 못하면 예외를 던지지 않고 **비어 있는 `cv::Mat` 객체**를 반환한다. Python과 달리 "존재하지 않는 객체"가 아니라 "내용이 없는 유효한 객체"가 돌아온다는 점이 다르다. 이를 확인하려면 `.empty()` 메서드를 사용한다.

```cpp
#include <opencv2/opencv.hpp>
#include <iostream>

int main() {
    cv::Mat img = cv::imread("존재하지않는파일.jpg");

    if (img.empty()) {
        std::cerr << "이미지를 읽을 수 없습니다. 경로를 확인하세요." << std::endl;
        return 1;
    }

    std::cout << img.rows << " x " << img.cols << std::endl;
    return 0;
}
```

`img.empty()`가 `true`를 반환하면 데이터가 전혀 없는 `Mat`이라는 뜻이다. `.empty()` 확인을 생략하고 `img.rows`나 `img.at<...>()` 같은 접근을 시도하면, 크래시(비정상 종료)나 정의되지 않은 동작으로 이어질 수 있으므로 반드시 확인하는 습관을 들여야 한다.

### C#: 빈 Mat이 반환된다 — .Empty()로 확인

C#의 OpenCvSharp도 C++과 동일한 정책을 따른다. `Cv2.ImRead()`가 파일을 열지 못하면 **비어 있는 `Mat`**을 반환하며, `.Empty()` 속성으로 확인한다.

```csharp
using System;
using OpenCvSharp;

class Program
{
    static void Main()
    {
        Mat img = Cv2.ImRead("존재하지않는파일.jpg");

        if (img.Empty())
        {
            Console.Error.WriteLine("이미지를 읽을 수 없습니다. 경로를 확인하세요.");
            return;
        }

        Console.WriteLine($"{img.Rows} x {img.Cols}");
    }
}
```

세 언어의 실패 처리 방식을 정리하면 다음과 같다.

| 언어 | 실패 시 반환값 | 확인 방법 |
|---|---|---|
| Python | `None` | `if img is None:` |
| C++ | 비어 있는 `cv::Mat` | `if (img.empty())` |
| C# | 비어 있는 `Mat` | `if (img.Empty())` |

세 방식 모두 "예외를 던지지 않는다"는 공통점이 있다는 사실도 기억해 두자. 즉 파일을 못 찾았다고 해서 프로그램이 저절로 멈추거나 `try/catch`(또는 Python의 `try/except`)로 잡히는 예외가 발생하는 것이 아니라, 반환값 자체가 "실패"를 나타내는 특수한 상태(빈 값)로 나온다. 따라서 파일을 읽는 코드 바로 다음에는 항상 이 확인 절차를 넣는 것을 습관으로 만들어야 한다.

## 4.4 이미지 파일 쓰기: imwrite

처리한 이미지를 다시 파일로 저장할 때는 `imwrite`(C#에서는 `ImWrite`)를 사용한다. 저장할 파일의 확장자를 보고 OpenCV가 자동으로 인코딩 방식을 결정하므로, 원하는 포맷에 맞는 확장자를 파일명에 붙여 주기만 하면 된다.

### Python

```python
import cv2

img = cv2.imread("photo.jpg")

cv2.imwrite("output.png", img)
cv2.imwrite("output.jpg", img)
cv2.imwrite("output.bmp", img)

# JPEG 품질 옵션 지정 (0~100, 기본값은 95 정도)
cv2.imwrite("output_q50.jpg", img, [cv2.IMWRITE_JPEG_QUALITY, 50])
```

`cv2.imwrite()`는 저장에 성공하면 `True`, 실패하면 `False`를 반환하므로 필요하다면 이 값도 확인할 수 있다.

### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img = cv::imread("photo.jpg");

    cv::imwrite("output.png", img);
    cv::imwrite("output.jpg", img);
    cv::imwrite("output.bmp", img);

    // JPEG 품질 옵션 지정
    std::vector<int> params = {cv::IMWRITE_JPEG_QUALITY, 50};
    cv::imwrite("output_q50.jpg", img, params);

    return 0;
}
```

### C#

```csharp
using OpenCvSharp;

class Program
{
    static void Main()
    {
        Mat img = Cv2.ImRead("photo.jpg");

        Cv2.ImWrite("output.png", img);
        Cv2.ImWrite("output.jpg", img);
        Cv2.ImWrite("output.bmp", img);

        // JPEG 품질 옵션 지정
        Cv2.ImWrite("output_q50.jpg", img, new ImageEncodingParam(ImwriteFlags.JpegQuality, 50));
    }
}
```

## 4.5 비디오 캡처 기초

지금까지 다룬 이미지는 한 장의 정지된 프레임이었다. 비디오는 이런 프레임이 초당 수십 장씩 연속으로 이어진 것이라고 생각하면 된다. OpenCV는 웹캠 장치와 동영상 파일을 동일한 인터페이스로 다룰 수 있게 해 주는 `VideoCapture`(Python은 `cv2.VideoCapture`, C++은 `cv::VideoCapture`, C#은 `VideoCapture`) 클래스를 제공한다. 이 절에서는 카메라(또는 파일)를 열고, 한 프레임씩 읽어서 화면에 보여 주다가 키 입력으로 종료하는 가장 기본적인 패턴을 익힌다. 비디오의 속성 제어, 코덱, 저장, 배경 제거 등 더 깊은 내용은 16장에서 다룬다.

`VideoCapture`를 열 때 정수를 넘기면 그 번호에 해당하는 카메라 장치(보통 `0`은 컴퓨터에 기본으로 연결된 첫 번째 웹캠)를 열고, 문자열(파일 경로)을 넘기면 그 경로의 동영상 파일을 연다.

### Python

```python
import cv2

cap = cv2.VideoCapture(0)  # 0번 웹캠. 파일을 열려면 "video.mp4" 같은 경로를 넘긴다.

if not cap.isOpened():
    print("카메라(또는 파일)를 열 수 없습니다.")
    exit(1)

while True:
    ret, frame = cap.read()  # ret: 성공 여부(bool), frame: 프레임 이미지

    if not ret:
        print("더 이상 프레임을 읽을 수 없습니다.")
        break

    cv2.imshow("Camera", frame)

    # 1ms 대기하며 키 입력을 받는다. 'q' 키를 누르면 종료.
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
```

`cap.read()`는 두 개의 값을 튜플로 반환한다. 첫 번째 `ret`은 프레임을 성공적으로 읽었는지를 나타내는 불리언 값이고, 두 번째 `frame`은 실제 이미지(3장에서 다룬 것과 동일한 `ndarray`)다. 파일의 끝에 도달했거나 카메라 연결이 끊기면 `ret`이 `False`가 되므로, 반복문에서 이를 확인해 탈출하는 것이 정석이다. `cv2.waitKey(1)`은 1밀리초 동안 키 입력을 기다리는 함수로, 화면을 갱신할 시간을 벌어 주는 동시에 사용자의 키 입력을 받는 역할도 한다. 작업이 끝나면 `cap.release()`로 장치(또는 파일)를 반드시 해제해야 한다.

### C++

```cpp
#include <opencv2/opencv.hpp>
#include <iostream>

int main() {
    cv::VideoCapture cap(0);  // 0번 웹캠. 파일을 열려면 "video.mp4" 같은 경로를 넘긴다.

    if (!cap.isOpened()) {
        std::cerr << "카메라(또는 파일)를 열 수 없습니다." << std::endl;
        return 1;
    }

    cv::Mat frame;
    while (true) {
        bool ret = cap.read(frame);  // frame에 결과를 채워 넣고 성공 여부를 반환

        if (!ret) {
            std::cout << "더 이상 프레임을 읽을 수 없습니다." << std::endl;
            break;
        }

        cv::imshow("Camera", frame);

        // 1ms 대기하며 키 입력을 받는다. 'q' 키를 누르면 종료.
        if (cv::waitKey(1) == 'q') {
            break;
        }
    }

    cap.release();
    cv::destroyAllWindows();
    return 0;
}
```

C++의 `cap.read(frame)`은 Python과 달리 두 값을 튜플로 돌려주지 않고, 참조로 넘긴 `frame` 변수에 결과 이미지를 직접 채워 넣은 뒤 성공 여부만 `bool`로 반환한다. 이는 C++에서 반환값을 여러 개로 만드는 것이 Python보다 번거롭기 때문에 채택된 관례로, 결과가 담기는 그릇(`frame`)을 미리 만들어 두고 함수에 넘긴다는 차이를 기억해 두면 된다.

### C#

```csharp
using System;
using OpenCvSharp;

class Program
{
    static void Main()
    {
        VideoCapture cap = new VideoCapture(0);  // 0번 웹캠. 파일을 열려면 "video.mp4" 같은 경로를 넘긴다.

        if (!cap.IsOpened())
        {
            Console.Error.WriteLine("카메라(또는 파일)를 열 수 없습니다.");
            return;
        }

        Mat frame = new Mat();
        while (true)
        {
            bool ret = cap.Read(frame);  // frame에 결과를 채워 넣고 성공 여부를 반환

            if (!ret)
            {
                Console.WriteLine("더 이상 프레임을 읽을 수 없습니다.");
                break;
            }

            Cv2.ImShow("Camera", frame);

            // 1ms 대기하며 키 입력을 받는다. 'q' 키를 누르면 종료.
            int key = Cv2.WaitKey(1);
            if (key == 'q')
            {
                break;
            }
        }

        cap.Release();
        Cv2.DestroyAllWindows();
    }
}
```

C#의 `cap.Read(frame)`도 C++과 동일하게, 미리 만들어 둔 `Mat` 객체를 넘겨서 그 안에 프레임을 채워 넣고 성공 여부를 `bool`로 돌려받는 방식이다.

세 언어의 비디오 캡처 흐름을 비교하면 다음과 같다.

| 단계 | Python | C++ | C# |
|---|---|---|---|
| 캡처 열기 | `cap = cv2.VideoCapture(0)` | `cv::VideoCapture cap(0);` | `var cap = new VideoCapture(0);` |
| 열림 확인 | `cap.isOpened()` | `cap.isOpened()` | `cap.IsOpened()` |
| 프레임 읽기 | `ret, frame = cap.read()` | `bool ret = cap.read(frame);` | `bool ret = cap.Read(frame);` |
| 화면 표시 | `cv2.imshow(...)` | `cv::imshow(...)` | `Cv2.ImShow(...)` |
| 키 입력 대기 | `cv2.waitKey(1)` | `cv::waitKey(1)` | `Cv2.WaitKey(1)` |
| 자원 해제 | `cap.release()` | `cap.release()` | `cap.Release()` |

이 패턴, 즉 **"캡처를 열고 → 반복문 안에서 프레임을 읽고 → 화면에 보여 주고 → 키 입력으로 종료 조건을 확인하고 → 자원을 해제한다"**는 이후 웹캠이나 동영상을 다루는 모든 예제의 기본 골격이 된다. 16장에서는 여기에 프레임 속성 조회(FPS, 해상도), 동영상 저장(`VideoWriter`), 배경 제거 알고리즘 등을 추가하여 훨씬 실용적인 예제로 발전시킬 것이다.

## 요약

- `imread`(`imread`/`ImRead`)는 파일 확장자와 무관하게 내부 헤더를 분석해 자동으로 포맷을 판별하며, 결과는 3장에서 다룬 것과 동일한 이미지 자료구조로 반환된다.
- 읽기 모드는 `IMREAD_COLOR`(기본값, 컬러), `IMREAD_GRAYSCALE`(그레이스케일), `IMREAD_UNCHANGED`(원본 그대로) 등으로 지정할 수 있으며, 세 언어에서 이름의 표기 방식(대문자/PascalCase 등)만 다르고 의미는 동일하다.
- 파일을 읽지 못했을 때: Python은 `None`을 반환하고, C++과 C#은 비어 있는 `Mat`을 반환하며 각각 `.empty()` / `.Empty()`로 확인한다. 세 언어 모두 예외를 던지지 않는다는 공통점이 있으므로 반드시 반환값을 직접 확인해야 한다.
- `imwrite`(`imwrite`/`ImWrite`)는 저장할 파일명의 확장자에 따라 인코딩 방식을 자동으로 선택하며, JPEG 품질 등의 옵션을 추가로 지정할 수 있다.
- `VideoCapture`는 웹캠과 동영상 파일을 동일한 인터페이스로 다루며, 기본 패턴은 "열기 → `isOpened()` 확인 → 반복문에서 `read()` → `imshow()`로 표시 → `waitKey()`로 키 입력 확인 및 종료 → `release()`로 자원 해제"이다.
- C++과 C#의 `read()`/`Read()`는 Python처럼 튜플을 반환하지 않고, 미리 만든 `Mat` 변수를 채워 넣은 뒤 성공 여부만 `bool`로 돌려준다는 차이가 있다.

## 연습문제

1. 존재하지 않는 파일 경로를 `imread`에 넘겼을 때 Python, C++, C# 각각에서 어떤 값이 반환되는지 직접 실행해서 확인하고, 그 값을 확인하지 않고 다음 코드를 실행하면 어떤 오류가 발생하는지 관찰해 보아라.
2. 컬러로 읽은 이미지와 `IMREAD_GRAYSCALE`로 읽은 같은 이미지의 `shape`(또는 `channels()`)이 어떻게 다른지 세 언어로 각각 확인해 보아라.
3. 자신의 컴퓨터에 있는 웹캠을 열어, 화면에 실시간 영상을 띄우고 스페이스바를 누르면 현재 프레임을 `capture.png`로 저장하는 프로그램을 세 언어 중 하나로 작성해 보아라.
4. `imwrite`로 JPEG 품질 옵션을 90, 50, 10으로 각각 다르게 저장한 뒤 파일 크기와 이미지 품질을 비교해 보아라.
5. C++과 C#의 `VideoCapture.read()`가 Python처럼 튜플을 반환하는 방식이 아니라 참조/출력 매개변수를 채우는 방식을 택한 이유가 무엇일지 각 언어의 함수 반환 관례를 생각하며 설명해 보아라.
