# OpenCV로 배우는 컴퓨터 비전 (Python·C++·C#)

[다음: 1장. OpenCV란 무엇인가 ▶](ch01-OpenCV란무엇인가.md)

---

OpenCV를 Python, C++, C# 세 언어로 나란히 비교하며 배우는 컴퓨터 비전 입문서입니다. 같은
알고리즘이 언어마다 어떤 API 스타일로 노출되는지 비교하면서, 이미지 처리의 기본 개념부터
필터링, 엣지 검출, 컨투어 분석, 특징점 매칭, 얼굴/객체 검출, 실전 프로젝트까지 순서대로
다룹니다.

각 장의 주요 예제는 `### Python`, `### C++`, `### C#` 세 섹션으로 나란히 제공되며, 요약과
연습문제, 필요한 곳에는 이해를 돕는 다이어그램을 함께 실었습니다.
