## 9.1 컨볼루션: 필터링의 핵심 아이디어

이미지 필터링 대부분은 컨볼루션(convolution, 합성곱)이라는 하나의 연산 원리를 공유합니다. 개념은 생각보다 단순합니다.

작은 격자 형태의 숫자 배열을 하나 준비합니다. 이 배열을 커널(kernel) 또는 마스크(mask)라고 부릅니다. 예를 들어 3×3 크기의 커널이라면 9개의 숫자가 들어 있습니다. 이 커널을 이미지의 왼쪽 위부터 오른쪽 아래까지 한 칸씩 옮겨가며(슬라이딩) 이미지 전체를 훑습니다.

커널이 어떤 위치에 놓이면, 그 위치를 중심으로 커널과 겹치는 이미지 픽셀 값들을 커널의 숫자와 각각 곱한 뒤 모두 더합니다. 이 합산 결과가 커널의 중심(anchor)에 대응하는 출력 픽셀의 새로운 값이 됩니다. 커널을 한 칸씩 옮길 때마다 이 계산을 반복하면, 원본과 같은 크기의 새로운 이미지가 만들어집니다.

예를 들어 커널의 모든 값이 1/9인 3×3 커널을 사용하면, 각 픽셀은 자기 자신과 주변 8개 픽셀의 평균값으로 대체됩니다. 이렇게 하면 이미지가 부드러워지는데, 이것이 바로 블러(blur)의 원리입니다. 반대로 커널의 중심 값이 크고 주변 값이 음수인 커널을 쓰면 픽셀 간 차이가 강조되어 이미지가 선명해집니다.

커널이 이미지 가장자리에 놓이면 일부가 이미지 바깥으로 벗어나는데, OpenCV는 `borderType` 옵션(`BORDER_REPLICATE`, `BORDER_REFLECT`, `BORDER_CONSTANT` 등)으로 가장자리를 어떻게 채울지 결정합니다. 대부분의 함수는 기본값으로 `BORDER_REFLECT_101`을 사용하며, 특별한 이유가 없다면 기본값을 그대로 쓰는 것으로 충분합니다.

이번 장에서 다루는 `blur`, `GaussianBlur`, `medianBlur`, `bilateralFilter`, `filter2D`는 모두 이 컨볼루션(또는 그와 유사한 슬라이딩 윈도우 연산)을 기반으로 동작하지만, 커널을 어떻게 구성하고 어떤 계산을 하느냐에 따라 서로 다른 결과를 냅니다.

### 9.1.1 컨볼루션을 직접 계산해 보기

OpenCV의 함수는 내부적으로 최적화된 C++ 코드로 컨볼루션을 수행하지만, 원리를 눈으로 확인하기 위해 아주 단순한 버전을 NumPy만으로 직접 구현해 볼 수 있습니다. 아래 코드는 3×3 평균 커널을 이용한 컨볼루션을 반복문으로 구현하고, 그 결과가 `cv2.blur`의 결과와 (경계 처리 방식의 차이를 제외하면) 거의 같다는 것을 확인합니다.

```python
import cv2
import numpy as np

img = cv2.imread('sample.jpg', cv2.IMREAD_GRAYSCALE)
if img is None:
    raise FileNotFoundError('sample.jpg를 찾을 수 없습니다.')

# 계산량을 줄이기 위해 작은 크기로 리사이즈합니다.
small = cv2.resize(img, (120, 90))

def manual_convolution(src, kernel):
    """아주 단순한 방식의 2D 컨볼루션 구현 (교육용, 속도는 고려하지 않음)."""
    kh, kw = kernel.shape
    pad_h, pad_w = kh // 2, kw // 2
    # 가장자리를 반사(reflect)해서 패딩합니다. cv2의 BORDER_REFLECT_101과 유사합니다.
    padded = np.pad(src.astype(np.float32), ((pad_h, pad_h), (pad_w, pad_w)), mode='reflect')
    out = np.zeros_like(src, dtype=np.float32)

    for y in range(src.shape[0]):
        for x in range(src.shape[1]):
            region = padded[y:y + kh, x:x + kw]
            out[y, x] = np.sum(region * kernel)
    return out

box_kernel = np.ones((3, 3), dtype=np.float32) / 9.0
manual_result = manual_convolution(small, box_kernel)
opencv_result = cv2.blur(small, (3, 3)).astype(np.float32)

diff = np.abs(manual_result - opencv_result)
print('직접 구현한 컨볼루션과 cv2.blur 결과의 최대 차이:', diff.max())
print('평균 차이:', diff.mean())
```

경계 부분에서 패딩 방식이 완전히 같지 않아 아주 작은 차이가 남을 수 있지만, 이미지 내부(경계에서 멀리 떨어진 영역)에서는 두 결과가 거의 완전히 일치합니다. 이 실험이 보여주는 것은, `cv2.blur`나 `cv2.filter2D` 같은 함수들이 특별한 "블랙박스"가 아니라 위에서 손으로 구현한 것과 똑같은 연산을 훨씬 빠르게 수행하고 있을 뿐이라는 사실입니다. 이후 절에서 다루는 다양한 필터들도 결국 "어떤 숫자로 채워진 커널을 슬라이딩시키느냐"의 차이일 뿐입니다.

## 9.2 평균 블러: blur

가장 단순한 블러는 커널 영역 안의 모든 픽셀 값을 동일한 비중으로 평균 내는 평균 블러(average blur, box filter)입니다. OpenCV는 이를 `blur` 함수로 제공합니다.

평균 블러는 계산이 빠르고 이해하기 쉽지만, 커널 안의 모든 픽셀을 똑같이 취급하기 때문에 경계 부분이 뭉개지는 단점이 있습니다.

### 예제 9-1. 평균 블러 적용하기

```python
import cv2

img = cv2.imread('sample.jpg')
if img is None:
    raise FileNotFoundError('sample.jpg를 찾을 수 없습니다.')

# 커널 크기가 클수록 더 강하게 블러됩니다.
blur_3 = cv2.blur(img, (3, 3))
blur_9 = cv2.blur(img, (9, 9))
blur_15 = cv2.blur(img, (15, 15))

cv2.imshow('Original', img)
cv2.imshow('Blur 3x3', blur_3)
cv2.imshow('Blur 9x9', blur_9)
cv2.imshow('Blur 15x15', blur_15)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

> 참고: `blur`는 내부적으로 `boxFilter`를 정규화(`normalize=True`)하여 호출하는 것과 동일합니다. 정규화하지 않은 합계가 필요하다면 `cv2.boxFilter(img, -1, (9, 9), normalize=False)`처럼 직접 `boxFilter`를 호출할 수 있습니다. 정규화하지 않으면 각 픽셀 값이 "합"이 되므로, 8비트 이미지(`uint8`)에서는 255를 넘는 값이 잘려버릴 수 있습니다. 이런 경우 출력 깊이를 `cv2.CV_32F`나 `cv2.CV_16U`처럼 더 넓게 지정해야 값이 손실되지 않습니다.

평균 블러는 커널 크기가 커질수록 블러 강도가 세지지만, 계산 비용도 커널 넓이에 비례해서 늘어납니다. 다만 OpenCV의 `boxFilter` 구현은 적분 이미지(integral image)와 유사한 누적 합 기법을 활용하기 때문에, 커널이 커져도 픽셀당 계산량이 크게 늘지 않도록 최적화되어 있습니다.

## 9.3 가우시안 블러: GaussianBlur

평균 블러는 커널 안의 모든 픽셀에 같은 가중치를 주지만, 가우시안 블러는 중심에서 멀어질수록 가중치가 정규분포(가우시안 분포)를 따라 작아지도록 설계된 커널을 사용합니다. 그 결과 평균 블러보다 훨씬 자연스럽고 부드러운 블러 효과를 얻을 수 있어, 실무에서 가장 널리 쓰이는 블러 방식입니다.

`GaussianBlur(src, ksize, sigmaX, sigmaY=0)`에서 `sigmaX`, `sigmaY`가 0이면 커널 크기로부터 표준편차를 자동으로 계산합니다. 커널 크기(`ksize`)의 가로세로는 반드시 양의 홀수여야 합니다. OpenCV가 커널 크기로부터 표준편차를 자동 계산할 때 사용하는 근사식은 다음과 같습니다.

```
sigma = 0.3 * ((ksize - 1) * 0.5 - 1) + 0.8
```

즉 커널이 클수록 자동으로 계산되는 표준편차도 커져서, 결과적으로 더 넓은 범위의 픽셀이 블러에 관여하게 됩니다. 반대로 `sigmaX`를 직접 지정하면 커널 크기가 고정되어 있어도 블러의 "퍼짐 정도"를 세밀하게 조절할 수 있습니다. `ksize`를 `(0, 0)`으로 주고 `sigmaX`만 지정하면, OpenCV가 그 시그마 값에 맞는 적절한 커널 크기를 자동으로 계산해 줍니다.

### 예제 9-2. 가우시안 블러로 노이즈 완화하기

```python
import cv2

img = cv2.imread('sample.jpg')

gaussian_5 = cv2.GaussianBlur(img, (5, 5), 0)
gaussian_15 = cv2.GaussianBlur(img, (15, 15), 0)
# sigmaX를 직접 지정하면 커널 크기가 같아도 블러 강도를 조절할 수 있습니다.
gaussian_sigma = cv2.GaussianBlur(img, (15, 15), sigmaX=10)
# 커널 크기를 (0, 0)으로 두고 sigmaX만 지정하면 OpenCV가 적절한 커널 크기를 계산합니다.
gaussian_auto = cv2.GaussianBlur(img, (0, 0), sigmaX=3)

cv2.imshow('Gaussian 5x5', gaussian_5)
cv2.imshow('Gaussian 15x15', gaussian_15)
cv2.imshow('Gaussian sigma=10', gaussian_sigma)
cv2.imshow('Gaussian auto ksize', gaussian_auto)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

가우시안 커널의 실제 값이 궁금하다면 `cv2.getGaussianKernel(ksize, sigma)`로 1차원 가우시안 가중치를 직접 확인할 수 있습니다. `GaussianBlur`는 내부적으로 이 1차원 커널을 가로 방향과 세로 방향에 순차적으로 적용하는 분리 가능한(separable) 필터로 구현되어 있어서, 2차원 커널을 통째로 컨볼루션하는 것보다 훨씬 효율적으로 동작합니다.

```python
import cv2

kernel_1d = cv2.getGaussianKernel(ksize=5, sigma=1.0)
print(kernel_1d.ravel())
# 예: [0.0545 0.2442 0.4026 0.2442 0.0545]  (중심이 가장 크고 좌우 대칭)
```

가우시안 블러는 12장에서 다룰 캐니(Canny) 엣지 검출의 표준 전처리 단계로도 사용됩니다. 노이즈를 미리 눌러 두지 않으면 엣지 검출 결과에 잡음이 섞여 들어가기 때문입니다.

## 9.4 미디안 블러: medianBlur

평균 블러와 가우시안 블러는 모두 주변 픽셀 값을 가중 평균하는 방식이라, 이미지에 소금-후추 잡음(salt-and-pepper noise, 갑자기 튀는 극단적인 흰 점이나 검은 점)이 섞여 있으면 그 잡음 값까지 평균에 반영되어 결과가 흐려집니다.

미디안 블러는 평균 대신 커널 영역 안의 픽셀 값들을 정렬한 뒤 중앙값(median)을 선택합니다. 극단값 하나가 평균을 크게 왜곡시키는 평균 블러와 달리, 중앙값은 소수의 극단값에 영향을 받지 않습니다. 그래서 미디안 블러는 소금-후추 잡음 제거에 특히 강력합니다. 이 특성은 9.9절에서 정량적인 실험으로 다시 확인합니다.

`medianBlur(src, ksize)`는 `ksize`가 1보다 큰 홀수여야 하며, 정사각형 커널만 지원합니다(가로세로를 따로 지정할 수 없습니다).

### 예제 9-3. 미디안 블러의 기본 동작 확인하기

```python
import cv2
import numpy as np

img = cv2.imread('sample.jpg')

# 소금-후추 잡음을 인위적으로 조금 추가해 봅니다. (본격적인 실험은 9.9절에서)
noisy = img.copy()
rng = np.random.default_rng(42)
mask = rng.random(img.shape[:2])
noisy[mask < 0.02] = 0        # 후추(검은 점)
noisy[mask > 0.98] = 255      # 소금(흰 점)

gaussian_result = cv2.GaussianBlur(noisy, (5, 5), 0)
median_result = cv2.medianBlur(noisy, 5)

cv2.imshow('Noisy', noisy)
cv2.imshow('GaussianBlur result', gaussian_result)
cv2.imshow('MedianBlur result', median_result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

결과를 비교해 보면 가우시안 블러는 소금-후추 잡음의 흔적을 흐릿하게 남기지만, 미디안 블러는 잡음 점들을 훨씬 깨끗하게 제거하면서도 실제 경계선은 비교적 잘 보존합니다. 왜 그런지는 중앙값의 통계적 성질로 설명할 수 있습니다. 3×3 커널(9개 값) 안에 극단값이 1~2개 섞여 있어도, 나머지 7~8개 값이 정상적인 값이라면 정렬했을 때 정중앙에 위치하는 값은 거의 항상 정상값 쪽에서 나옵니다. 반면 평균은 극단값 하나만 있어도 그 값이 전체 합에 그대로 반영되어 결과가 한쪽으로 쏠립니다.

## 9.5 양방향 필터: bilateralFilter

지금까지 살펴본 세 가지 블러(평균, 가우시안, 미디안)는 모두 이미지의 경계(edge)까지 함께 뭉개 버린다는 공통된 단점이 있습니다. 필터가 위치 정보만 보고 커널 안의 모든 픽셀을 계산에 포함시키기 때문입니다.

양방향 필터(bilateral filter)는 여기에 한 가지 조건을 추가합니다. 위치가 가까울 뿐만 아니라 색상(밝기) 값도 비슷한 픽셀에만 높은 가중치를 줍니다. 즉 두 가지 가우시안 가중치, 공간적 거리에 대한 가중치와 색상 차이에 대한 가중치를 동시에 곱해서 사용합니다. 그래서 평평한 영역(색이 비슷한 픽셀들)은 강하게 블러되지만, 색상 차이가 큰 경계 부분은 원래 값이 그대로 유지됩니다. 이런 특성 때문에 "경계를 보존하는 블러(edge-preserving blur)"라고 부릅니다.

`bilateralFilter(src, d, sigmaColor, sigmaSpace)`에서 `d`는 필터링에 사용할 픽셀 이웃의 지름, `sigmaColor`는 색상 차이에 대한 표준편차(값이 클수록 색상 차이가 커도 섞임), `sigmaSpace`는 공간 거리에 대한 표준편차입니다. 다만 계산량이 다른 블러들보다 훨씬 많아 큰 이미지나 실시간 처리에는 부담이 될 수 있습니다.

### 예제 9-4. 양방향 필터로 경계를 보존하며 블러하기

```python
import cv2

img = cv2.imread('sample.jpg')

gaussian_result = cv2.GaussianBlur(img, (15, 15), 0)
bilateral_result = cv2.bilateralFilter(img, d=15, sigmaColor=75, sigmaSpace=75)

cv2.imshow('Original', img)
cv2.imshow('GaussianBlur (edge lost)', gaussian_result)
cv2.imshow('BilateralFilter (edge preserved)', bilateral_result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`sigmaColor`를 바꿔가며 그 영향을 직접 확인해 볼 수도 있습니다.

```python
import cv2

img = cv2.imread('sample.jpg')

low_color = cv2.bilateralFilter(img, d=15, sigmaColor=10, sigmaSpace=75)
high_color = cv2.bilateralFilter(img, d=15, sigmaColor=150, sigmaSpace=75)

cv2.imshow('sigmaColor=10 (edge 매우 보존)', low_color)
cv2.imshow('sigmaColor=150 (거의 GaussianBlur처럼)', high_color)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`sigmaColor`가 작으면 아주 비슷한 색상의 픽셀만 섞이므로 경계가 거의 완벽하게 보존되지만 블러 효과도 약해집니다. 반대로 `sigmaColor`가 크면 색상 차이에 대한 민감도가 떨어져서 결국 색상 조건이 거의 무시되고, 공간 거리만 고려하는 가우시안 블러와 비슷한 결과가 나옵니다. 즉 `sigmaColor`는 "얼마나 다른 색상까지 같은 영역으로 봐줄 것인가"를 조절하는 다이얼이라고 이해하면 됩니다.

인물 사진의 피부를 부드럽게 보정하면서도 눈, 코, 입의 윤곽은 살리고 싶을 때, 또는 노이즈를 줄이면서도 이후 엣지 검출 품질을 유지하고 싶을 때 양방향 필터가 유용합니다.

## 9.6 커널 샤프닝: 이미지를 선명하게 만들기

블러가 픽셀 간의 차이를 줄이는 것이라면, 샤프닝(sharpening)은 반대로 픽셀 간의 차이를 강조해서 경계를 뚜렷하게 만드는 작업입니다. 대표적인 방법은 중심 값이 크고 주변 값이 음수인 커널을 사용하는 것입니다.

```
 0  -1   0
-1   5  -1
 0  -1   0
```

이 커널의 모든 값을 더하면 정확히 1이 됩니다(5 - 1 - 1 - 1 - 1 = 1). 커널 값의 합이 1이라는 것은 평평한 영역(주변 픽셀 값이 모두 같은 영역)에서는 출력이 입력과 같은 밝기를 유지한다는 뜻입니다. 대신 중심 픽셀 값을 5배 강조하는 동시에 상하좌우 픽셀 값을 빼기 때문에, 밝기가 급격히 변하는 경계 부분에서는 그 차이(고주파 성분)가 더 크게 증폭되어 이미지가 더 "또렷하게" 보입니다.

### 예제 9-5. filter2D로 커널 샤프닝 적용하기

```python
import cv2
import numpy as np

img = cv2.imread('sample.jpg')

sharpen_kernel = np.array([[0, -1, 0],
                            [-1, 5, -1],
                            [0, -1, 0]], dtype=np.float32)
sharpened = cv2.filter2D(img, -1, sharpen_kernel)

cv2.imshow('Original', img)
cv2.imshow('Kernel Sharpen', sharpened)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

샤프닝은 노이즈도 함께 강조한다는 점에 주의해야 합니다. 경계뿐 아니라 노이즈 역시 밝기가 급격히 변하는 지점이기 때문에, 노이즈가 많은 이미지를 무작정 샤프닝하면 잡음까지 도드라져 결과가 오히려 나빠질 수 있습니다. 따라서 실무에서는 먼저 가벼운 블러나 노이즈 제거를 적용한 뒤 샤프닝을 적용하는 순서를 고려하는 것이 좋습니다.

## 9.7 언샤프 마스킹 심화: 블러의 차이로 선명함을 만들기

앞 절의 커널 샤프닝은 "고정된 커널 하나"로 선명함의 정도를 결정하기 때문에 조절할 수 있는 여지가 많지 않습니다. 반면 언샤프 마스킹(unsharp masking)은 블러의 강도(반경)와 강조 정도(양)를 각각 독립적으로 조절할 수 있는, 훨씬 유연하고 실무에서 널리 쓰이는 샤프닝 기법입니다.

### 9.7.1 원리: 저주파를 빼면 고주파만 남는다

이미지를 아주 단순하게 "천천히 변하는 성분(저주파, 즉 큰 형태와 색의 흐름)"과 "빠르게 변하는 성분(고주파, 즉 경계와 세부 디테일)"의 합으로 생각해 볼 수 있습니다. 블러 필터는 고주파 성분을 억제하고 저주파 성분만 남기는 필터입니다. 따라서 다음 식이 성립합니다.

```
원본 = 저주파(대략적인 형태) + 고주파(경계·디테일)
블러된 이미지 ≈ 저주파(대략적인 형태)
```

이 관계에서 "원본 - 블러된 이미지"를 계산하면 저주파 성분이 서로 상쇄되어 고주파 성분(경계 정보)만 남게 됩니다. 이렇게 추출한 고주파 성분을 마스크(mask)라고 부르는데, 재미있게도 이 마스크는 원본을 "선명하지 않게(unsharp)" 만드는 저주파 정보를 원본에서 빼서 얻어낸 것이기 때문에 "언샤프 마스킹"이라는 이름이 붙었습니다. 이제 이 고주파 성분을 원본에 다시 얼마나 강하게 더해줄지 정하는 계수 `amount`(흔히 α로 표기)를 곱해서 더해주면 다음과 같은 식이 됩니다.

```
결과 = 원본 + amount × (원본 − 블러된 이미지)
```

`amount`가 0이면 원본과 동일하고, `amount`가 클수록 경계 대비가 강하게 증폭되어 더 선명하게 보입니다. 블러에 사용한 표준편차(`sigma`, 흔히 `radius`라고도 부름)는 "얼마나 넓은 영역의 변화를 저주파로 볼 것인가"를 결정합니다. `sigma`가 작으면 미세한 디테일 위주로 강조되고, `sigma`가 크면 더 넓은 스케일의 명암 대비까지 강조됩니다.

### 9.7.2 addWeighted로 구현하기

OpenCV의 `addWeighted(src1, alpha, src2, beta, gamma)`는 `dst = src1 * alpha + src2 * beta + gamma`를 계산하는 함수입니다. 언샤프 마스킹 식을 이 형태에 맞춰 정리하면 다음과 같습니다.

```
결과 = 원본 + amount × 원본 − amount × 블러
     = (1 + amount) × 원본 + (−amount) × 블러
```

즉 `src1=원본, alpha=1+amount, src2=블러, beta=-amount, gamma=0`으로 `addWeighted`를 호출하면 됩니다.

### 예제 9-6. amount와 radius를 바꿔가며 언샤프 마스킹 실험하기

```python
import cv2

img = cv2.imread('sample.jpg')

def unsharp_mask(image, sigma=3.0, amount=1.0):
    """원본과 블러된 이미지의 차이를 이용한 언샤프 마스킹.

    sigma  : 블러 반경(클수록 더 넓은 영역의 대비를 강조)
    amount : 고주파 성분을 얼마나 강하게 더할지 결정하는 계수
    """
    blurred = cv2.GaussianBlur(image, (0, 0), sigmaX=sigma)
    sharpened = cv2.addWeighted(image, 1 + amount, blurred, -amount, 0)
    return sharpened

result_default = unsharp_mask(img, sigma=3.0, amount=1.0)
result_strong = unsharp_mask(img, sigma=3.0, amount=2.5)      # amount만 증가
result_wide = unsharp_mask(img, sigma=10.0, amount=1.0)        # sigma(반경)만 증가

cv2.imshow('Original', img)
cv2.imshow('Unsharp (amount=1.0)', result_default)
cv2.imshow('Unsharp (amount=2.5, 더 강한 대비)', result_strong)
cv2.imshow('Unsharp (sigma=10, 더 넓은 영역 강조)', result_wide)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`addWeighted`는 내부적으로 계산 결과를 8비트 범위(0~255)로 자동으로 saturate(초과분을 잘라내기)해 주기 때문에, 직접 NumPy 배열 연산으로 구현할 때 흔히 겪는 오버플로 문제를 신경 쓰지 않아도 됩니다. 만약 `addWeighted` 없이 NumPy만으로 같은 계산을 하고 싶다면 다음처럼 float 타입으로 변환한 뒤 `np.clip`으로 직접 범위를 제한해야 합니다.

```python
import cv2
import numpy as np

img = cv2.imread('sample.jpg')
blurred = cv2.GaussianBlur(img, (0, 0), sigmaX=3.0)

amount = 1.0
img_f = img.astype(np.float32)
blurred_f = blurred.astype(np.float32)

high_freq = img_f - blurred_f                       # 고주파(경계) 성분 추출
result_f = img_f + amount * high_freq                # 원본에 다시 더하기
result = np.clip(result_f, 0, 255).astype(np.uint8)   # 0~255로 클리핑 후 uint8 변환
```

### 9.7.3 임계값(threshold)을 추가해 노이즈 강조 억제하기

사진 편집 프로그램의 "언샤프 마스크" 도구에는 흔히 `amount`, `radius` 외에 `threshold`라는 세 번째 옵션이 있습니다. 이 옵션은 "차이가 threshold보다 작은 부분은 노이즈로 간주하고 강조하지 않는다"는 아이디어입니다. OpenCV에는 이 기능이 내장되어 있지 않지만, 고주파 성분을 계산한 뒤 마스킹으로 직접 구현할 수 있습니다.

```python
import cv2
import numpy as np

img = cv2.imread('sample.jpg')
blurred = cv2.GaussianBlur(img, (0, 0), sigmaX=3.0)

img_f = img.astype(np.float32)
blurred_f = blurred.astype(np.float32)
diff = img_f - blurred_f

threshold = 5.0
# 채널별 차이의 절댓값이 threshold보다 작은 픽셀은 0으로 눌러서 노이즈 강조를 억제합니다.
diff_thresholded = np.where(np.abs(diff) < threshold, 0, diff)

amount = 1.5
result_f = img_f + amount * diff_thresholded
result = np.clip(result_f, 0, 255).astype(np.uint8)

cv2.imshow('Unsharp with threshold', result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

이렇게 하면 평평한 영역에 남아 있는 미세한 노이즈는 강조되지 않고, 실제로 대비가 뚜렷한 경계 부분만 선명해지는 효과를 얻을 수 있습니다.

## 9.8 커스텀 커널 필터링: filter2D로 다양한 효과 만들기

앞선 예제에서 이미 사용했듯, `filter2D`는 사용자가 정의한 임의의 커널로 컨볼루션을 수행하는 범용 함수입니다. `blur`, `GaussianBlur` 등이 특정 목적에 최적화된 전용 함수라면, `filter2D`는 원하는 커널을 직접 설계해서 적용할 수 있는 가장 유연한 도구입니다.

`filter2D(src, ddepth, kernel, anchor=(-1,-1), delta=0, borderType=BORDER_DEFAULT)`에서 `ddepth`에 -1을 지정하면 입력과 동일한 비트 깊이로 출력됩니다. `anchor`는 커널 내에서 기준이 되는 위치(기본값은 커널 중심)이고, `delta`는 계산 결과에 더해주는 상수입니다. `delta`는 특히 커널 값의 합이 0에 가까운 경우(엠보싱, 엣지 강조 등) 결과가 음수나 0 근처로 몰리는 것을 막고 중간 밝기(예: 128)로 이동시키는 데 유용합니다.

### 9.8.1 엠보싱 효과

엠보싱(embossing)은 마치 이미지가 돋아 있는 부조(浮彫)처럼 보이게 만드는 효과입니다. 커널이 한쪽 방향으로는 양수, 반대쪽 방향으로는 음수를 갖도록 설계하면, 그 방향으로 밝기가 증가하는 경계는 밝게, 감소하는 경계는 어둡게 표현되고, 평평한 영역은 `delta`로 지정한 회색(대개 128)으로 수렴합니다.

```python
import cv2
import numpy as np

img = cv2.imread('sample.jpg')

emboss_kernel = np.array([[-2, -1, 0],
                           [-1,  1, 1],
                           [ 0,  1, 2]], dtype=np.float32)
emboss_result = cv2.filter2D(img, -1, emboss_kernel, delta=128)

cv2.imshow('Emboss Filter', emboss_result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 9.8.2 방향성 엣지 강조 커널

밝기 변화를 특정 방향으로만 강조하는 커널을 만들 수도 있습니다. 아래는 수평 방향 변화를 강조하는 커널과 수직 방향 변화를 강조하는 커널, 그리고 대각선 방향을 강조하는 커널의 예입니다. 이 커널들은 12장에서 배우게 될 소벨(Sobel) 필터의 형태와 매우 비슷합니다.

```python
import cv2
import numpy as np

img = cv2.imread('sample.jpg')

# 수평 방향(좌우) 밝기 변화를 강조 -> 수직선 경계가 두드러짐
horizontal_kernel = np.array([[-1, 0, 1],
                               [-2, 0, 2],
                               [-1, 0, 1]], dtype=np.float32)

# 수직 방향(상하) 밝기 변화를 강조 -> 수평선 경계가 두드러짐
vertical_kernel = np.array([[-1, -2, -1],
                             [ 0,  0,  0],
                             [ 1,  2,  1]], dtype=np.float32)

# 대각선(좌상단-우하단) 방향 밝기 변화를 강조
diagonal_kernel = np.array([[-2, -1, 0],
                             [-1,  0, 1],
                             [ 0,  1, 2]], dtype=np.float32)

horizontal_edges = cv2.filter2D(img, -1, horizontal_kernel, delta=128)
vertical_edges = cv2.filter2D(img, -1, vertical_kernel, delta=128)
diagonal_edges = cv2.filter2D(img, -1, diagonal_kernel, delta=128)

cv2.imshow('Horizontal Emphasis', horizontal_edges)
cv2.imshow('Vertical Emphasis', vertical_edges)
cv2.imshow('Diagonal Emphasis', diagonal_edges)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

이 커널들을 직접 만들어보면, 결국 엣지 검출이라는 것도 "밝기 변화가 큰 특정 방향으로 큰 값을 내는 커널"을 컨볼루션하는 것에서 출발한다는 점을 체감할 수 있습니다. `horizontal_kernel`은 왼쪽 값을 빼고 오른쪽 값을 더하기 때문에 세로로 뻗은 경계(좌우 밝기가 급격히 바뀌는 곳)에서 큰 반응을 보이고, `vertical_kernel`은 반대로 가로로 뻗은 경계에서 큰 반응을 보입니다.

### 9.8.3 커널 값의 합과 전체 밝기의 관계

`filter2D`로 여러 커널을 실험해 보면 한 가지 규칙을 발견할 수 있습니다. 커널 값의 합이 1이면(예: 평균 블러, 커널 샤프닝) 평평한 영역의 밝기가 그대로 유지되지만, 합이 1보다 크면 이미지 전체가 밝아지고, 합이 1보다 작으면 전체가 어두워집니다. 합이 0에 가까운 커널(엠보싱, 방향성 엣지 커널)은 평평한 영역의 결과가 0 근처로 쏠리기 때문에 `delta`로 중간 밝기를 더해주지 않으면 대부분 새까맣게 보이게 됩니다.

```python
import cv2
import numpy as np

img = cv2.imread('sample.jpg')

kernel_sum_1 = np.array([[0, 0, 0],
                          [0, 1, 0],
                          [0, 0, 0]], dtype=np.float32)          # 합 = 1, 원본과 동일
kernel_sum_2 = kernel_sum_1 * 2                                    # 합 = 2, 전체적으로 밝아짐
kernel_sum_half = kernel_sum_1 * 0.5                               # 합 = 0.5, 전체적으로 어두워짐

print('합이 1:', cv2.filter2D(img, -1, kernel_sum_1).mean())
print('합이 2:', cv2.filter2D(img, -1, kernel_sum_2).mean())
print('합이 0.5:', cv2.filter2D(img, -1, kernel_sum_half).mean())
```

## 9.9 실전 실험: 노이즈 시뮬레이션과 필터 성능 비교

지금까지는 필터별로 개별 예제를 살펴봤습니다. 이번 절에서는 서로 다른 두 종류의 노이즈, 가우시안 노이즈(gaussian noise)와 소금-후추 노이즈(salt-and-pepper noise)를 직접 만들어서 이미지에 추가하고, 평균 블러·가우시안 블러·미디안 블러가 각각의 노이즈에 얼마나 효과적인지 시각적으로, 그리고 PSNR(Peak Signal-to-Noise Ratio) 수치로 비교해 보겠습니다.

### 9.9.1 노이즈 생성하기

가우시안 노이즈는 각 픽셀에 평균 0, 표준편차 σ인 정규분포를 따르는 난수를 더해서 만듭니다. 실제 카메라 센서의 열 노이즈(thermal noise)나 저조도 환경에서 발생하는 노이즈와 비슷한 통계적 성질을 가집니다.

소금-후추 노이즈는 무작위로 선택된 일부 픽셀을 아예 흰색(255, 소금) 또는 검은색(0, 후추)으로 바꿔치기하는 방식으로 만듭니다. 오래된 아날로그 회선을 통한 전송 오류나 손상된 센서 픽셀에서 나타나는 노이즈와 비슷합니다.

```python
import cv2
import numpy as np

img = cv2.imread('sample.jpg')
if img is None:
    raise FileNotFoundError('sample.jpg를 찾을 수 없습니다.')

rng = np.random.default_rng(42)

def add_gaussian_noise(image, sigma=25.0):
    """평균 0, 표준편차 sigma인 가우시안 노이즈를 이미지에 더합니다."""
    noise = rng.normal(loc=0.0, scale=sigma, size=image.shape)
    noisy = image.astype(np.float32) + noise
    return np.clip(noisy, 0, 255).astype(np.uint8)

def add_salt_and_pepper_noise(image, amount=0.04):
    """전체 픽셀 중 amount 비율만큼을 무작위로 흰 점/검은 점으로 바꿉니다."""
    noisy = image.copy()
    mask = rng.random(image.shape[:2])
    noisy[mask < amount / 2] = 0        # 후추(검은 점)
    noisy[mask > 1 - amount / 2] = 255  # 소금(흰 점)
    return noisy

gaussian_noisy = add_gaussian_noise(img, sigma=25.0)
sp_noisy = add_salt_and_pepper_noise(img, amount=0.04)

cv2.imshow('Original', img)
cv2.imshow('Gaussian Noise', gaussian_noisy)
cv2.imshow('Salt-and-Pepper Noise', sp_noisy)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 9.9.2 세 가지 필터로 각각의 노이즈 제거해 보기

이제 두 노이즈 이미지에 평균 블러, 가우시안 블러, 미디안 블러를 각각 적용해서 결과를 비교합니다.

```python
import cv2

def denoise_all(noisy_image, ksize=5):
    avg = cv2.blur(noisy_image, (ksize, ksize))
    gau = cv2.GaussianBlur(noisy_image, (ksize, ksize), 0)
    med = cv2.medianBlur(noisy_image, ksize)
    return avg, gau, med

gaussian_avg, gaussian_gau, gaussian_med = denoise_all(gaussian_noisy)
sp_avg, sp_gau, sp_med = denoise_all(sp_noisy)

cv2.imshow('[Gaussian Noise] Average Blur', gaussian_avg)
cv2.imshow('[Gaussian Noise] Gaussian Blur', gaussian_gau)
cv2.imshow('[Gaussian Noise] Median Blur', gaussian_med)

cv2.imshow('[Salt-Pepper Noise] Average Blur', sp_avg)
cv2.imshow('[Salt-Pepper Noise] Gaussian Blur', sp_gau)
cv2.imshow('[Salt-Pepper Noise] Median Blur', sp_med)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 9.9.3 PSNR으로 정량적으로 비교하기

눈으로 보는 비교는 주관적이기 쉽습니다. OpenCV는 두 이미지 사이의 화질 차이를 숫자로 표현하는 `cv2.PSNR(src1, src2)` 함수를 제공합니다. PSNR 값이 높을수록 두 이미지(여기서는 "원본"과 "노이즈 제거 후 이미지")가 더 비슷하다는 뜻이며, 즉 필터가 원본을 더 잘 복원했다는 의미입니다.

```python
import cv2

def report_psnr(name, original, restored):
    value = cv2.PSNR(original, restored)
    print(f'{name}: PSNR = {value:.2f} dB')

print('=== 가우시안 노이즈 제거 성능 ===')
report_psnr('노이즈 제거 전', img, gaussian_noisy)
report_psnr('Average Blur', img, gaussian_avg)
report_psnr('Gaussian Blur', img, gaussian_gau)
report_psnr('Median Blur', img, gaussian_med)

print()
print('=== 소금-후추 노이즈 제거 성능 ===')
report_psnr('노이즈 제거 전', img, sp_noisy)
report_psnr('Average Blur', img, sp_avg)
report_psnr('Gaussian Blur', img, sp_gau)
report_psnr('Median Blur', img, sp_med)
```

실제로 이 코드를 실행해 보면 대체로 다음과 같은 경향이 나타납니다.

- **가우시안 노이즈**에 대해서는 평균 블러와 가우시안 블러가 미디안 블러와 비슷하거나 오히려 더 나은 PSNR을 보이는 경우가 많습니다. 가우시안 노이즈는 모든 픽셀에 작은 크기의 변화가 골고루 퍼져 있는 노이즈이기 때문에, 평균이나 가중 평균을 취하면 양수/음수 방향의 노이즈가 서로 상쇄되면서 효과적으로 줄어듭니다.
- **소금-후추 노이즈**에 대해서는 미디안 블러가 다른 두 필터를 압도적인 차이로 앞서는 것을 확인할 수 있습니다. 평균이나 가우시안 블러는 극단값(0 또는 255)까지 평균 계산에 포함시키기 때문에, 노이즈 픽셀 주변까지 얼룩처럼 흐려집니다. 반면 미디안 블러는 정렬 후 중앙값을 취하므로, 커널 안에 극단값이 절반 미만으로 섞여 있다면 그 극단값이 결과에 전혀 반영되지 않습니다.

이 실험이 주는 실무적인 시사점은 분명합니다. "노이즈를 제거해야 한다"는 목표만으로는 어떤 필터를 써야 할지 결정할 수 없습니다. 노이즈의 종류를 먼저 파악(또는 추정)하고, 그 특성에 맞는 필터를 선택해야 합니다. 실제로 어떤 종류의 노이즈인지 확신할 수 없다면, 두 필터를 순차적으로 적용해 보거나(예: 미디안 블러 후 가벼운 가우시안 블러), 양방향 필터처럼 경계를 보존하는 필터로 절충하는 방법도 고려할 수 있습니다.

## 9.10 어떤 필터를 언제 써야 할까

지금까지 다룬 필터들을 상황별로 정리하면 다음과 같습니다.

| 필터 | 함수 | 특징 | 강한 노이즈 유형 | 적합한 상황 |
|---|---|---|---|---|
| 평균 블러 | `blur` | 가장 단순하고 빠름, 경계가 뭉개짐 | 가우시안형 노이즈 | 대략적인 블러가 필요하고 속도가 중요할 때 |
| 가우시안 블러 | `GaussianBlur` | 자연스러운 블러, 실무 기본값 | 가우시안형 노이즈 | 일반적인 노이즈 완화, 엣지 검출 전처리 |
| 미디안 블러 | `medianBlur` | 극단값에 강함 | 소금-후추 노이즈 | 스캔 이미지·센서 노이즈처럼 튀는 잡음 제거 |
| 양방향 필터 | `bilateralFilter` | 경계 보존, 계산량 많음 | 가우시안형 노이즈(경계 보존이 필요할 때) | 경계를 살리면서 노이즈만 줄이고 싶을 때 |
| 커스텀 필터 | `filter2D` | 원하는 어떤 커널도 적용 가능 | 해당 없음(효과 목적) | 샤프닝, 엠보싱 등 특수 효과나 직접 설계한 커널 실험 |

실무에서는 먼저 가우시안 블러로 시작해서, 튀는 잡음(점, 스크래치 등)이 두드러지면 미디안 블러로 바꿔보고, 경계 보존이 특히 중요하면 양방향 필터를 고려하는 순서로 접근하는 경우가 많습니다. 그리고 블러로 노이즈를 다스린 뒤에는 9.7절의 언샤프 마스킹으로 손실된 선명도를 다시 보충하는 "노이즈 제거 → 샤프닝"의 조합도 실무에서 자주 사용되는 패턴입니다.

## 요약

- 대부분의 필터링은 커널을 이미지 위에서 슬라이딩하며 가중합을 계산하는 컨볼루션 연산에 기반하며, NumPy만으로 직접 구현해 봐도 OpenCV 함수와 동일한 결과를 얻을 수 있습니다.
- `blur`는 커널 영역의 단순 평균으로 빠르게 블러 처리하지만 경계도 함께 뭉개집니다.
- `GaussianBlur`는 중심에 가까운 픽셀에 더 큰 가중치를 주어 더 자연스러운 블러를 만들며, `sigmaX`와 커널 크기로 블러의 강도를 세밀하게 조절할 수 있습니다.
- `medianBlur`는 평균이 아닌 중앙값을 사용해 소금-후추 잡음 같은 극단값 노이즈 제거에 특히 강합니다.
- `bilateralFilter`는 공간 거리와 색상 차이를 함께 고려해 경계를 보존하면서 블러하며, `sigmaColor`로 경계 보존의 민감도를 조절합니다.
- 커널 샤프닝은 고정된 커널로 경계를 강조하고, 언샤프 마스킹은 원본과 블러된 이미지의 차이(고주파 성분)를 `amount`만큼 다시 더해주는 방식으로 더 유연하게 선명도를 조절합니다.
- `filter2D`는 사용자가 직접 설계한 임의의 커널로 컨볼루션을 수행하는 범용 함수로, 엠보싱이나 방향성 엣지 강조 같은 효과에도 활용되며, 커널 값의 합이 전체 밝기에 어떤 영향을 주는지 이해하는 것이 중요합니다.
- 가우시안 노이즈에는 평균/가우시안 블러가, 소금-후추 노이즈에는 미디안 블러가 상대적으로 더 효과적이며, `cv2.PSNR`을 이용하면 이 차이를 정량적으로 확인할 수 있습니다.
