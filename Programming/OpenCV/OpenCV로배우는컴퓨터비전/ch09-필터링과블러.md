# 9장. 필터링과 블러

[◀ 이전: 8장. 기하 변환(리사이즈·회전·워프)](ch08-기하변환.md) | [📖 목차](00-목차.md) | [다음: 10장. 임계처리와 이진화 ▶](ch10-임계처리와이진화.md)


지금까지는 이미지를 회전하거나 크기를 바꾸는 등 픽셀의 "위치"를 다루는 기하 변환을 살펴봤습니다. 이번 장에서는 픽셀의 "값"을 주변 픽셀과의 관계 속에서 다시 계산하는 필터링(filtering) 기법을 다룹니다. 필터링은 노이즈를 줄이고, 이미지를 부드럽게 만들거나 반대로 선명하게 만드는 데 쓰이며, 12장의 엣지 검출과 13장의 컨투어 검출로 넘어가기 전에 반드시 거치는 전처리 단계이기도 합니다.

## 9.1 컨볼루션: 필터링의 핵심 아이디어

이미지 필터링 대부분은 컨볼루션(convolution, 합성곱)이라는 하나의 연산 원리를 공유합니다. 개념은 생각보다 단순합니다.

작은 격자 형태의 숫자 배열을 하나 준비합니다. 이 배열을 커널(kernel) 또는 마스크(mask)라고 부릅니다. 예를 들어 3×3 크기의 커널이라면 9개의 숫자가 들어 있습니다. 이 커널을 이미지의 왼쪽 위부터 오른쪽 아래까지 한 칸씩 옮겨가며(슬라이딩) 이미지 전체를 훑습니다.

커널이 어떤 위치에 놓이면, 그 위치를 중심으로 커널과 겹치는 이미지 픽셀 값들을 커널의 숫자와 각각 곱한 뒤 모두 더합니다. 이 합산 결과가 커널의 중심(anchor)에 대응하는 출력 픽셀의 새로운 값이 됩니다. 커널을 한 칸씩 옮길 때마다 이 계산을 반복하면, 원본과 같은 크기의 새로운 이미지가 만들어집니다.

예를 들어 커널의 모든 값이 1/9인 3×3 커널을 사용하면, 각 픽셀은 자기 자신과 주변 8개 픽셀의 평균값으로 대체됩니다. 이렇게 하면 이미지가 부드러워지는데, 이것이 바로 블러(blur)의 원리입니다. 반대로 커널의 중심 값이 크고 주변 값이 음수인 커널을 쓰면 픽셀 간 차이가 강조되어 이미지가 선명해집니다.

커널이 이미지 가장자리에 놓이면 일부가 이미지 바깥으로 벗어나는데, OpenCV는 `borderType` 옵션(`BORDER_REPLICATE`, `BORDER_REFLECT`, `BORDER_CONSTANT` 등)으로 가장자리를 어떻게 채울지 결정합니다. 대부분의 함수는 기본값으로 `BORDER_REFLECT_101`을 사용하며, 특별한 이유가 없다면 기본값을 그대로 쓰는 것으로 충분합니다.

이번 장에서 다루는 `blur`, `GaussianBlur`, `medianBlur`, `bilateralFilter`, `filter2D`는 모두 이 컨볼루션(또는 그와 유사한 슬라이딩 윈도우 연산)을 기반으로 동작하지만, 커널을 어떻게 구성하고 어떤 계산을 하느냐에 따라 서로 다른 결과를 냅니다.

## 9.2 평균 블러: blur

가장 단순한 블러는 커널 영역 안의 모든 픽셀 값을 동일한 비중으로 평균 내는 평균 블러(average blur, box filter)입니다. OpenCV는 이를 `blur` 함수로 제공합니다.

평균 블러는 계산이 빠르고 이해하기 쉽지만, 커널 안의 모든 픽셀을 똑같이 취급하기 때문에 경계 부분이 뭉개지는 단점이 있습니다.

### 예제 9-1. 평균 블러 적용하기

#### Python

```python
import cv2

img = cv2.imread('sample.jpg')
if img is None:
    raise FileNotFoundError('sample.jpg를 찾을 수 없습니다.')

# 커널 크기가 클수록 더 강하게 블러됩니다.
blur_3 = cv2.blur(img, (3, 3))
blur_9 = cv2.blur(img, (9, 9))
blur_15 = cv2.blur(img, (15, 15))

cv2.imshow('Original', img)
cv2.imshow('Blur 3x3', blur_3)
cv2.imshow('Blur 9x9', blur_9)
cv2.imshow('Blur 15x15', blur_15)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

#### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img = cv::imread("sample.jpg");
    if (img.empty()) {
        CV_Error(cv::Error::StsError, "sample.jpg를 찾을 수 없습니다.");
    }

    cv::Mat blur3, blur9, blur15;
    cv::blur(img, blur3, cv::Size(3, 3));
    cv::blur(img, blur9, cv::Size(9, 9));
    cv::blur(img, blur15, cv::Size(15, 15));

    cv::imshow("Original", img);
    cv::imshow("Blur 3x3", blur3);
    cv::imshow("Blur 9x9", blur9);
    cv::imshow("Blur 15x15", blur15);
    cv::waitKey(0);
    return 0;
}
```

#### C#

```csharp
using OpenCvSharp;

using Mat img = Cv2.ImRead("sample.jpg");
if (img.Empty())
    throw new FileNotFoundException("sample.jpg를 찾을 수 없습니다.");

using Mat blur9 = new Mat();
using Mat blur15 = new Mat();

Cv2.Blur(img, blur3, new Size(3, 3));
Cv2.Blur(img, blur9, new Size(9, 9));
Cv2.Blur(img, blur15, new Size(15, 15));

```

> 참고: `blur`는 내부적으로 `boxFilter`를 정규화(normalize=true)하여 호출하는 것과 동일합니다. 정규화하지 않은 합계가 필요하다면 `cv2.boxFilter(img, -1, (9, 9), normalize=False)`처럼 직접 `boxFilter`를 호출할 수 있습니다.

## 9.3 가우시안 블러: GaussianBlur

평균 블러는 커널 안의 모든 픽셀에 같은 가중치를 주지만, 가우시안 블러는 중심에서 멀어질수록 가중치가 정규분포(가우시안 분포)를 따라 작아지도록 설계된 커널을 사용합니다. 그 결과 평균 블러보다 훨씬 자연스럽고 부드러운 블러 효과를 얻을 수 있어, 실무에서 가장 널리 쓰이는 블러 방식입니다.

`GaussianBlur(src, dst, ksize, sigmaX, sigmaY=0)`에서 `sigmaX`, `sigmaY`가 0이면 커널 크기로부터 표준편차를 자동으로 계산합니다. 커널 크기(`ksize`)의 가로세로는 반드시 양의 홀수여야 합니다.

### 예제 9-2. 가우시안 블러로 노이즈 완화하기

#### Python

```python
import cv2

img = cv2.imread('sample.jpg')

gaussian_5 = cv2.GaussianBlur(img, (5, 5), 0)
gaussian_15 = cv2.GaussianBlur(img, (15, 15), 0)
# sigmaX를 직접 지정하면 커널 크기가 같아도 블러 강도를 조절할 수 있습니다.
gaussian_sigma = cv2.GaussianBlur(img, (15, 15), sigmaX=10)

cv2.imshow('Gaussian 5x5', gaussian_5)
cv2.imshow('Gaussian 15x15', gaussian_15)
cv2.imshow('Gaussian sigma=10', gaussian_sigma)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

#### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img = cv::imread("sample.jpg");

    cv::Mat gaussian5, gaussian15, gaussianSigma;
    cv::GaussianBlur(img, gaussian5, cv::Size(5, 5), 0);
    cv::GaussianBlur(img, gaussian15, cv::Size(15, 15), 0);
    cv::GaussianBlur(img, gaussianSigma, cv::Size(15, 15), 10);

    cv::imshow("Gaussian 5x5", gaussian5);
    cv::imshow("Gaussian 15x15", gaussian15);
    cv::imshow("Gaussian sigma=10", gaussianSigma);
    cv::waitKey(0);
    return 0;
}
```

#### C#

```csharp

using Mat gaussian15 = new Mat();
using Mat gaussianSigma = new Mat();
```

가우시안 블러는 12장에서 다룰 캐니(Canny) 엣지 검출의 표준 전처리 단계로도 사용됩니다. 노이즈를 미리 눌러 두지 않으면 엣지 검출 결과에 잡음이 섞여 들어가기 때문입니다.

## 9.4 미디안 블러: medianBlur

평균 블러와 가우시안 블러는 모두 주변 픽셀 값을 가중 평균하는 방식이라, 이미지에 소금-후추 잡음(salt-and-pepper noise, 갑자기 튀는 극단적인 흰 점이나 검은 점)이 섞여 있으면 그 잡음 값까지 평균에 반영되어 결과가 흐려집니다.

미디안 블러는 평균 대신 커널 영역 안의 픽셀 값들을 정렬한 뒤 중앙값(median)을 선택합니다. 극단값 하나가 평균을 크게 왜곡시키는 평균 블러와 달리, 중앙값은 소수의 극단값에 영향을 받지 않습니다. 그래서 미디안 블러는 소금-후추 잡음 제거에 특히 강력합니다.

`medianBlur(src, ksize)`는 `ksize`가 1보다 큰 홀수여야 하며, 정사각형 커널만 지원합니다(가로세로를 따로 지정할 수 없습니다).

### 예제 9-3. 미디안 블러로 소금-후추 잡음 제거하기

#### Python

```python
import cv2
import numpy as np

img = cv2.imread('sample.jpg')

# 소금-후추 잡음을 인위적으로 추가해 봅니다.
noisy = img.copy()
rng = np.random.default_rng(42)
mask = rng.random(img.shape[:2])
noisy[mask < 0.02] = 0        # 후추(검은 점)
noisy[mask > 0.98] = 255      # 소금(흰 점)

gaussian_result = cv2.GaussianBlur(noisy, (5, 5), 0)
median_result = cv2.medianBlur(noisy, 5)

cv2.imshow('Noisy', noisy)
cv2.imshow('GaussianBlur result', gaussian_result)
cv2.imshow('MedianBlur result', median_result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

#### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img = cv::imread("sample.jpg");

    cv::Mat noisy = img.clone();
    cv::RNG rng(42);
    for (int r = 0; r < noisy.rows; ++r) {
        for (int c = 0; c < noisy.cols; ++c) {
            double p = rng.uniform(0.0, 1.0);
            if (p < 0.02) noisy.at<cv::Vec3b>(r, c) = cv::Vec3b(0, 0, 0);
            else if (p > 0.98) noisy.at<cv::Vec3b>(r, c) = cv::Vec3b(255, 255, 255);
        }
    }

    cv::Mat gaussianResult, medianResult;
    cv::GaussianBlur(noisy, gaussianResult, cv::Size(5, 5), 0);
    cv::medianBlur(noisy, medianResult, 5);

    cv::imshow("Noisy", noisy);
    cv::imshow("GaussianBlur result", gaussianResult);
    cv::imshow("MedianBlur result", medianResult);
    cv::waitKey(0);
    return 0;
}
```

#### C#

```csharp
using OpenCvSharp;

using Mat img = Cv2.ImRead("sample.jpg");
using Mat noisy = img.Clone();

var rng = new Random(42);
for (int r = 0; r < noisy.Rows; r++)
{
    for (int c = 0; c < noisy.Cols; c++)
    {
        double p = rng.NextDouble();
        if (p < 0.02)
            noisy.Set(r, c, new Vec3b(0, 0, 0));
        else if (p > 0.98)
            noisy.Set(r, c, new Vec3b(255, 255, 255));
    }
}

using Mat gaussianResult = new Mat();
using Mat medianResult = new Mat();

Cv2.GaussianBlur(noisy, gaussianResult, new Size(5, 5), 0);
Cv2.MedianBlur(noisy, medianResult, 5);

Cv2.ImShow("Noisy", noisy);
Cv2.ImShow("GaussianBlur result", gaussianResult);
Cv2.ImShow("MedianBlur result", medianResult);
Cv2.WaitKey(0);
```

결과를 비교해 보면 가우시안 블러는 소금-후추 잡음의 흔적을 흐릿하게 남기지만, 미디안 블러는 잡음 점들을 훨씬 깨끗하게 제거하면서도 실제 경계선은 비교적 잘 보존합니다.

## 9.5 양방향 필터: bilateralFilter

지금까지 살펴본 세 가지 블러(평균, 가우시안, 미디안)는 모두 이미지의 경계(edge)까지 함께 뭉개 버린다는 공통된 단점이 있습니다. 필터가 위치 정보만 보고 커널 안의 모든 픽셀을 계산에 포함시키기 때문입니다.

양방향 필터(bilateral filter)는 여기에 한 가지 조건을 추가합니다. 위치가 가까울 뿐만 아니라 색상(밝기) 값도 비슷한 픽셀에만 높은 가중치를 줍니다. 즉 두 가지 가우시안 가중치, 공간적 거리에 대한 가중치와 색상 차이에 대한 가중치를 동시에 곱해서 사용합니다. 그래서 평평한 영역(색이 비슷한 픽셀들)은 강하게 블러되지만, 색상 차이가 큰 경계 부분은 원래 값이 그대로 유지됩니다. 이런 특성 때문에 "경계를 보존하는 블러(edge-preserving blur)"라고 부릅니다.

`bilateralFilter(src, d, sigmaColor, sigmaSpace)`에서 `d`는 필터링에 사용할 픽셀 이웃의 지름, `sigmaColor`는 색상 차이에 대한 표준편차(값이 클수록 색상 차이가 커도 섞임), `sigmaSpace`는 공간 거리에 대한 표준편차입니다. 다만 계산량이 다른 블러들보다 훨씬 많아 큰 이미지나 실시간 처리에는 부담이 될 수 있습니다.

### 예제 9-4. 양방향 필터로 경계를 보존하며 블러하기

#### Python

```python
import cv2

img = cv2.imread('sample.jpg')

gaussian_result = cv2.GaussianBlur(img, (15, 15), 0)
bilateral_result = cv2.bilateralFilter(img, d=15, sigmaColor=75, sigmaSpace=75)

cv2.imshow('Original', img)
cv2.imshow('GaussianBlur (edge lost)', gaussian_result)
cv2.imshow('BilateralFilter (edge preserved)', bilateral_result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

#### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img = cv::imread("sample.jpg");

    cv::Mat gaussianResult, bilateralResult;
    cv::GaussianBlur(img, gaussianResult, cv::Size(15, 15), 0);
    cv::bilateralFilter(img, bilateralResult, 15, 75, 75);

    cv::imshow("Original", img);
    cv::imshow("GaussianBlur (edge lost)", gaussianResult);
    cv::imshow("BilateralFilter (edge preserved)", bilateralResult);
    cv::waitKey(0);
    return 0;
}
```

#### C#

```csharp

using Mat img = Cv2.ImRead("sample.jpg");

using Mat bilateralResult = new Mat();

Cv2.WaitKey(0);
```

인물 사진의 피부를 부드럽게 보정하면서도 눈, 코, 입의 윤곽은 살리고 싶을 때, 또는 노이즈를 줄이면서도 이후 엣지 검출 품질을 유지하고 싶을 때 양방향 필터가 유용합니다.

## 9.6 샤프닝: 커널로 이미지를 선명하게 만들기

블러가 픽셀 간의 차이를 줄이는 것이라면, 샤프닝(sharpening)은 반대로 픽셀 간의 차이를 강조해서 경계를 뚜렷하게 만드는 작업입니다. 대표적인 방법은 중심 값이 크고 주변 값이 음수인 커널을 사용하는 것입니다.

```
 0  -1   0
-1   5  -1
 0  -1   0
```

이 커널은 중심 픽셀 값을 5배 강조하는 대신, 상하좌우 픽셀 값을 빼서 주변과의 차이(고주파 성분)를 더합니다. 그 결과 경계 부분의 명암 대비가 커져 이미지가 더 "또렷하게" 보입니다.

또 다른 널리 쓰이는 방법은 언샵 마스킹(unsharp masking)입니다. 원본에서 블러된 이미지를 일정 비율로 빼서 고주파(경계) 성분만 추출한 뒤, 그 성분을 원본에 다시 더해주는 방식입니다. `원본 + α × (원본 − 블러본)` 형태로 계산하며, OpenCV의 `addWeighted`를 이용해 간단히 구현할 수 있습니다.

### 예제 9-5. 커널 샤프닝과 언샵 마스킹

#### Python

```python
import cv2
import numpy as np

img = cv2.imread('sample.jpg')

# 방법 1: 샤프닝 커널을 filter2D로 적용
sharpen_kernel = np.array([[0, -1, 0],
                            [-1, 5, -1],
                            [0, -1, 0]], dtype=np.float32)
sharpened = cv2.filter2D(img, -1, sharpen_kernel)

# 방법 2: 언샵 마스킹 (블러된 이미지를 빼고 다시 더하기)
blurred = cv2.GaussianBlur(img, (0, 0), sigmaX=3)
unsharp = cv2.addWeighted(img, 1.5, blurred, -0.5, 0)

cv2.imshow('Original', img)
cv2.imshow('Kernel Sharpen', sharpened)
cv2.imshow('Unsharp Masking', unsharp)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

## 9.7 커스텀 커널 필터링: filter2D

앞선 예제에서 이미 사용했듯, `filter2D`는 사용자가 정의한 임의의 커널로 컨볼루션을 수행하는 범용 함수입니다. `blur`, `GaussianBlur` 등이 특정 목적에 최적화된 전용 함수라면, `filter2D`는 원하는 커널을 직접 설계해서 적용할 수 있는 가장 유연한 도구입니다.

`filter2D(src, ddepth, kernel, anchor=(-1,-1), delta=0, borderType=BORDER_DEFAULT)`에서 `ddepth`에 -1을 지정하면 입력과 동일한 비트 깊이로 출력됩니다. `anchor`는 커널 내에서 기준이 되는 위치(기본값은 커널 중심)이고, `delta`는 계산 결과에 더해주는 상수입니다.

### 예제 9-6. filter2D로 엣지 강조 커널 실험하기

#### Python

```python
import cv2
import numpy as np

img = cv2.imread('sample.jpg')

# 수평 방향 밝기 변화를 강조하는 커널 (간단한 엣지 검출 예)
edge_kernel = np.array([[-1, 0, 1],
                         [-2, 0, 2],
                         [-1, 0, 1]], dtype=np.float32)

edge_result = cv2.filter2D(img, -1, edge_kernel)

# 엠보싱(embossing) 효과를 주는 커널
emboss_kernel = np.array([[-2, -1, 0],
                           [-1,  1, 1],
                           [ 0,  1, 2]], dtype=np.float32)
emboss_result = cv2.filter2D(img, -1, emboss_kernel, delta=128)

cv2.imshow('Edge-like Filter', edge_result)
cv2.imshow('Emboss Filter', emboss_result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

#### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img = cv::imread("sample.jpg");

    cv::Mat edgeKernel = (cv::Mat_<float>(3, 3) <<

        -2, 0, 2,
        -1, 0, 1);

    cv::Mat edgeResult;

    cv::Mat embossKernel = (cv::Mat_<float>(3, 3) <<
        -2, -1, 0,
        -1,  1, 1,
         0,  1, 2);

    cv::Mat embossResult;
    cv::filter2D(img, embossResult, -1, embossKernel, cv::Point(-1, -1), 128);

    cv::imshow("Edge-like Filter", edgeResult);
    cv::imshow("Emboss Filter", embossResult);
    cv::waitKey(0);
    return 0;
}
```

#### C#


`filter2D`로 실험해 본 엣지 강조 커널은 12장에서 배울 소벨(Sobel), 라플라시안(Laplacian) 필터의 원형이라고 볼 수 있습니다. 결국 엣지 검출도 "밝기 변화가 큰 방향으로 큰 값을 내는 커널"을 컨볼루션하는 것에서 출발합니다.

## 9.8 어떤 필터를 언제 써야 할까

지금까지 다룬 필터들을 상황별로 정리하면 다음과 같습니다.

| 필터 | 함수 | 특징 | 적합한 상황 |
|---|---|---|---|
| 평균 블러 | `blur` | 가장 단순하고 빠름, 경계가 뭉개짐 | 대략적인 블러가 필요하고 속도가 중요할 때 |
| 가우시안 블러 | `GaussianBlur` | 자연스러운 블러, 실무 기본값 | 일반적인 노이즈 완화, 엣지 검출 전처리 |
| 미디안 블러 | `medianBlur` | 극단값(소금-후추 잡음)에 강함 | 스캔 이미지·센서 노이즈처럼 튀는 잡음 제거 |
| 양방향 필터 | `bilateralFilter` | 경계 보존, 계산량 많음 | 경계를 살리면서 노이즈만 줄이고 싶을 때 |
| 커스텀 필터 | `filter2D` | 원하는 어떤 커널도 적용 가능 | 샤프닝, 엠보싱 등 특수 효과나 직접 설계한 커널 실험 |

실무에서는 먼저 가우시안 블러로 시작해서, 튀는 잡음이 두드러지면 미디안 블러로 바꿔보고, 경계 보존이 특히 중요하면 양방향 필터를 고려하는 순서로 접근하는 경우가 많습니다.

## 요약

- 대부분의 필터링은 커널을 이미지 위에서 슬라이딩하며 가중합을 계산하는 컨볼루션 연산에 기반합니다.
- `blur`는 커널 영역의 단순 평균으로 빠르게 블러 처리하지만 경계도 함께 뭉개집니다.
- `GaussianBlur`는 중심에 가까운 픽셀에 더 큰 가중치를 주어 더 자연스러운 블러를 만들며, 실무에서 가장 널리 쓰입니다.
- `medianBlur`는 평균이 아닌 중앙값을 사용해 소금-후추 잡음 같은 극단값 노이즈 제거에 특히 강합니다.
- `bilateralFilter`는 공간 거리와 색상 차이를 함께 고려해 경계를 보존하면서 블러합니다.
- `filter2D`는 사용자가 직접 설계한 임의의 커널로 컨볼루션을 수행하는 범용 함수로, 샤프닝이나 엠보싱 같은 효과에도 활용됩니다.
- 필터 선택은 속도, 노이즈의 종류, 경계 보존 필요성을 함께 고려해서 결정해야 합니다.
