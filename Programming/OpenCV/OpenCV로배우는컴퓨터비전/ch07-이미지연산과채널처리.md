## 7.1 이미지 산술 연산: saturate 덧셈과 뺄셈

OpenCV의 `cv2.add`, `cv2.subtract` 함수는 겉보기에 단순한 사칙연산이지만, 일반적인 배열 연산과 결정적으로 다른 점이 하나 있습니다. **결과값이 데이터 타입의 표현 범위를 벗어나지 않도록 saturate(포화) 처리**를 한다는 것입니다.

예를 들어 8비트 이미지(`uint8`)의 픽셀 값은 0~255 범위만 가질 수 있습니다. 두 픽셀 값 200과 100을 더하면 산술적으로는 300이지만, `uint8`로는 표현할 수 없습니다. 이때 동작 방식이 라이브러리마다 다릅니다.

- NumPy의 `+` 연산자는 **오버플로(overflow)** 방식입니다. 300을 8비트로 표현하면 300 - 256 = 44가 되어, 결과가 실제보다 훨씬 작은 값으로 "돌아 넘어갑니다."
- `cv2.add`는 **saturate(포화)** 방식입니다. 255를 넘는 값은 무조건 255로 잘립니다.

이 차이는 밝기를 높이는 것처럼 단순한 작업에서 결과를 완전히 다르게 만듭니다. NumPy의 `+`로 밝기를 올리면 원래 밝았던 픽셀이 갑자기 검은색에 가깝게 반전되어 버리는 반면, `cv2.add`는 단순히 흰색으로 밝게 날아갈(clipping) 뿐입니다. 실무에서는 거의 항상 saturate 동작이 원하는 결과이므로, 이미지 값을 더하거나 뺄 때는 NumPy 연산자 대신 OpenCV 함수를 사용하는 것이 안전합니다.

같은 원리가 뺄셈에도 적용됩니다. 50 - 100처럼 결과가 음수가 되는 경우, saturate 뺄셈은 0으로 잘라내지만, NumPy의 `-`는 언더플로가 발생해 156처럼 엉뚱하게 큰 값이 나옵니다.

`cv2.add`와 `cv2.subtract`는 두 이미지를 더하거나 빼는 용도 외에도, 스칼라 값(밝기 상수)을 더하거나 빼는 데도 그대로 쓸 수 있습니다. 이때는 `numpy.full`로 이미지와 같은 shape의 배열을 만들 필요 없이, 스칼라 튜플을 바로 두 번째 인자로 넘길 수 있습니다.

```python
import cv2
import numpy as np

img = cv2.imread('lena.jpg')

# 모든 픽셀에 100을 더할 값 행렬 (같은 shape, 같은 타입)
value = np.full(img.shape, 100, dtype=np.uint8)

# 1) OpenCV의 saturate 덧셈: 255를 넘지 않는다
saturated = cv2.add(img, value)

# 2) NumPy의 일반 덧셈: 256을 넘으면 오버플로(모듈로 연산)로 값이 되돌아간다
overflowed = img + value  # 예: 200 + 100 = 300 -> 300 % 256 = 44

print('원본 픽셀:', img[0, 0])
print('cv2.add 결과:', saturated[0, 0])      # 255를 초과하지 않음
print('NumPy + 결과:', overflowed[0, 0])     # 값이 튀어 어두워질 수 있음

cv2.imshow('Saturated (cv2.add)', saturated)
cv2.imshow('Overflowed (numpy +)', overflowed)
cv2.waitKey(0)
cv2.destroyAllWindows()

# 뺄셈도 동일한 원리
darker = cv2.subtract(img, value)   # 0 아래로는 내려가지 않음(saturate)
darker_np = img - value             # 음수가 되면 언더플로 발생

# 스칼라를 직접 더하거나 뺄 수도 있다 (배열을 따로 만들 필요 없음)
brighter_scalar = cv2.add(img, (40, 40, 40, 0))   # BGR 각 채널에 40을 더함
darker_scalar = cv2.subtract(img, (40, 40, 40, 0))
```

> **주의**: `cv2.add(img, (40, 40, 40, 0))`처럼 스칼라를 넘길 때는 4개의 원소를 가진 튜플을 넘겨야 합니다. OpenCV는 내부적으로 `cv::Scalar`를 4채널(B, G, R, A)로 다루기 때문입니다. 3채널 이미지라면 마지막 값은 무시되지만, 튜플의 길이를 맞춰 주는 습관을 들이면 예상치 못한 브로드캐스팅 오류를 피할 수 있습니다.

### `mask` 매개변수로 연산 범위 제한하기

`cv2.add`와 `cv2.subtract`는 선택적으로 `mask` 매개변수를 받습니다. 마스크가 0이 아닌 픽셀에만 연산이 적용되고, 나머지 픽셀은 출력 배열에서 변경되지 않습니다(단, 출력 배열을 미리 준비해 두지 않으면 마스크 밖 영역은 0으로 초기화되어 있을 수 있으니 주의해야 합니다). 마스크의 자세한 개념은 7.4절에서 다시 다룹니다.

```python
mask = np.zeros(img.shape[:2], dtype=np.uint8)
cv2.circle(mask, (img.shape[1] // 2, img.shape[0] // 2), 100, 255, -1)

dst = img.copy()
cv2.add(img, value, dst=dst, mask=mask)  # 원 안쪽만 밝아지고 바깥은 원본 그대로 유지
```

## 7.2 가중합: addWeighted로 이미지 합성하기

두 이미지를 서로 투명하게 겹쳐 보여주고 싶을 때는 `cv2.addWeighted`를 사용합니다. 이 함수는 다음 수식을 계산합니다.

```
dst = src1 * alpha + src2 * beta + gamma
```

`alpha`와 `beta`를 각각 0~1 사이의 값으로 설정하고 보통 `beta = 1 - alpha`로 두면, 두 이미지를 자연스럽게 섞은 크로스 디졸브(cross-dissolve) 효과를 얻을 수 있습니다. `gamma`는 결과 전체의 밝기를 조절하는 상수입니다. 두 이미지는 크기와 타입이 동일해야 합니다.

내부적으로 `addWeighted`도 `add`와 마찬가지로 saturate 연산을 수행하므로, `alpha + beta`가 1을 넘도록 설정해도 결과가 255를 넘어가는 대신 흰색으로 클리핑될 뿐 오류가 나지는 않습니다.

```python
import cv2

img1 = cv2.imread('lena.jpg')
img2 = cv2.imread('baboon.jpg')

# 두 이미지 크기를 맞춘다
img2 = cv2.resize(img2, (img1.shape[1], img1.shape[0]))

alpha = 0.6
beta = 1 - alpha
blended = cv2.addWeighted(img1, alpha, img2, beta, 0)

cv2.imshow('Blended', blended)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 페이드 인/아웃 효과: 여러 프레임에 걸친 점진적 전환

`addWeighted`의 진짜 힘은 정지 영상 한 장을 합성하는 데서 끝나지 않습니다. `alpha` 값을 시간(프레임)에 따라 조금씩 바꾸면서 반복적으로 호출하면, 슬라이드 쇼나 영상 편집 프로그램에서 흔히 보는 **크로스 디졸브(fade transition)** 효과를 직접 만들 수 있습니다. 아래 예제는 세 단계로 구성됩니다.

1. **페이드 인(fade-in)**: 검은 화면에서 시작해서 `img1`이 서서히 나타난다.
2. **크로스 디졸브(cross-dissolve)**: `img1`이 서서히 사라지면서 `img2`가 서서히 나타난다.
3. **페이드 아웃(fade-out)**: `img2`가 서서히 검은 화면으로 사라진다.

```python
import cv2
import numpy as np

img1 = cv2.imread('lena.jpg')
img2 = cv2.imread('baboon.jpg')
img2 = cv2.resize(img2, (img1.shape[1], img1.shape[0]))

black = np.zeros_like(img1)
n_steps = 30       # 전환에 사용할 프레임 수 (많을수록 더 부드럽다)
delay_ms = 30       # 각 프레임을 화면에 유지할 시간(ms)

# 1) 페이드 인: 검은 화면 -> img1
for i in range(n_steps + 1):
    a = i / n_steps
    frame = cv2.addWeighted(black, 1 - a, img1, a, 0)
    cv2.imshow('Fade transition', frame)
    if cv2.waitKey(delay_ms) == 27:  # ESC로 중단 가능
        break

# 2) 크로스 디졸브: img1 -> img2
for i in range(n_steps + 1):
    a = i / n_steps
    frame = cv2.addWeighted(img1, 1 - a, img2, a, 0)
    cv2.imshow('Fade transition', frame)
    if cv2.waitKey(delay_ms) == 27:
        break

# 3) 페이드 아웃: img2 -> 검은 화면
for i in range(n_steps + 1):
    a = i / n_steps
    frame = cv2.addWeighted(img2, 1 - a, black, a, 0)
    cv2.imshow('Fade transition', frame)
    if cv2.waitKey(delay_ms) == 27:
        break

cv2.destroyAllWindows()
```

이 반복문들을 함수로 감싸고 `n_steps`를 프레임레이트(fps)와 원하는 지속 시간(초)으로부터 계산하면, 재사용 가능한 트랜지션 유틸리티를 만들 수 있습니다.

```python
def cross_dissolve(src1, src2, n_steps=30, delay_ms=30, window='dissolve'):
    """src1에서 src2로 서서히 전환되는 애니메이션을 보여준다."""
    for i in range(n_steps + 1):
        a = i / n_steps
        frame = cv2.addWeighted(src1, 1 - a, src2, a, 0)
        cv2.imshow(window, frame)
        key = cv2.waitKey(delay_ms)
        if key == 27:
            return False
    return True

fps = 30
seconds = 1.0
cross_dissolve(img1, img2, n_steps=int(fps * seconds), delay_ms=int(1000 / fps))
```

이 프레임들을 화면에 표시하는 대신 `cv2.VideoWriter`에 순서대로 기록하면, 똑같은 로직으로 전환 효과가 들어간 동영상 파일도 만들 수 있습니다(동영상 입출력은 4장에서 다룬 내용을 참고하세요).

## 7.3 채널 분리와 병합: split과 merge

컬러 이미지는 B, G, R(또는 알파 채널이 있으면 A까지) 여러 채널이 겹쳐진 배열입니다. `cv2.split`은 이 채널들을 각각 독립된 단일 채널 이미지로 떼어내고, `cv2.merge`는 반대로 여러 개의 단일 채널 이미지를 하나의 다채널 이미지로 합칩니다.

채널을 분리하면 특정 채널만 밝기를 조절하거나, 특정 채널을 0으로 만들어 색을 제거하는 등의 작업이 가능해집니다. 예를 들어 R 채널만 남기고 나머지를 0으로 만들면 붉은 색조만 강조된 이미지를 얻을 수 있습니다.

> **주의**: `split`은 채널 수만큼 배열 전체를 복사하므로 비교적 비용이 큰 연산입니다. 단순히 한 채널의 값에 읽기 전용으로 접근하고 싶다면 NumPy 슬라이싱(`img[:, :, 0]`)을 쓰는 것이 훨씬 가볍습니다. 다만 슬라이싱으로 얻은 배열은 원본 이미지의 뷰(view)이므로 그 값을 직접 수정하면 원본 이미지도 함께 바뀐다는 점에 주의해야 합니다. 독립적인 복사본이 필요하다면 `.copy()`를 호출하세요.

```python
import cv2
import numpy as np

img = cv2.imread('lena.jpg')  # BGR 순서

# 채널 분리
b, g, r = cv2.split(img)

cv2.imshow('Blue channel', b)
cv2.imshow('Green channel', g)
cv2.imshow('Red channel', r)

# R 채널만 강조: G, B를 0으로 만든 뒤 다시 합치기
zeros = np.zeros_like(b)
red_only = cv2.merge([zeros, zeros, r])
cv2.imshow('Red only', red_only)

# G 채널의 밝기를 절반으로 낮춘 뒤 재합성
g_dark = (g * 0.5).astype(np.uint8)
dimmed_green = cv2.merge([b, g_dark, r])
cv2.imshow('Dimmed green', dimmed_green)

# NumPy 슬라이싱으로 같은 채널에 더 가볍게 접근하기
b_view = img[:, :, 0]          # 원본의 뷰 -- 수정하면 img도 바뀐다
r_copy = img[:, :, 2].copy()   # 독립된 복사본 -- 수정해도 img는 그대로

cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 각 채널을 그레이스케일 히트맵처럼 살펴보기

`split`으로 얻은 각 채널은 흑백(단일 채널) 이미지이므로, 그 자체로는 "얼마나 파란지, 얼마나 붉은지"를 밝기로 표현합니다. 컬러맵을 입혀서 시각적으로 더 직관적으로 볼 수도 있습니다.

```python
b, g, r = cv2.split(img)

b_colored = cv2.applyColorMap(b, cv2.COLORMAP_JET)
g_colored = cv2.applyColorMap(g, cv2.COLORMAP_JET)
r_colored = cv2.applyColorMap(r, cv2.COLORMAP_JET)

stacked = np.hstack([b_colored, g_colored, r_colored])
cv2.imshow('B / G / R channel heatmaps', stacked)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

## 7.4 마스크(mask)의 개념: 원하는 영역만 골라 연산하기

마스크란 원본 이미지와 같은 크기의 단일 채널(그레이스케일) 이미지로, 픽셀 값이 0이 아닌 위치는 "적용", 0인 위치는 "무시"라는 의미로 사용하는 보조 이미지입니다. 흔히 흰색(255) 영역은 관심 영역(ROI), 검은색(0) 영역은 배경으로 삼습니다.

5장에서 `cv2.inRange`를 이용해 HSV 색공간에서 특정 색상만 골라내는 색상 마스킹을 다뤘습니다. 그때 만든 마스크가 바로 이번 절에서 말하는 마스크입니다. `inRange`의 결과물은 조건을 만족하는 픽셀은 255, 만족하지 않는 픽셀은 0인 이진 이미지이며, 이를 그대로 비트 연산이나 `copyTo`에 활용할 수 있습니다.

많은 OpenCV 함수(`bitwise_and`, `copyTo`, `calcHist`, `add`/`subtract` 등)는 `mask`라는 선택적 매개변수를 받습니다. 이 매개변수에 마스크를 넘기면, 함수는 마스크가 0이 아닌 픽셀에만 연산을 적용하고 나머지는 그대로 둡니다.

```python
import cv2
import numpy as np

img = cv2.imread('lena.jpg')

# 원 모양의 마스크 만들기: 배경은 검정(0), 관심 영역은 흰색(255)
mask = np.zeros(img.shape[:2], dtype=np.uint8)
h, w = mask.shape
cv2.circle(mask, (w // 2, h // 2), min(h, w) // 3, 255, -1)

# 마스크가 적용된 영역만 결과에 복사되고, 나머지는 0(검정)으로 남는다
masked = np.zeros_like(img)
cv2.copyTo(img, mask, masked)   # mask가 0이 아닌 곳만 img 값을 masked로 복사

cv2.imshow('Mask', mask)
cv2.imshow('Masked region only', masked)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 마스크를 조합하기: 논리 연산으로 복잡한 관심 영역 만들기

마스크 자체도 결국 0과 255로 이루어진 이미지이므로, 여러 개의 단순한 마스크를 비트 연산으로 조합해서 더 복잡한 모양의 관심 영역을 만들 수 있습니다.

```python
h, w = img.shape[:2]

circle_mask = np.zeros((h, w), dtype=np.uint8)
cv2.circle(circle_mask, (w // 2, h // 2), min(h, w) // 3, 255, -1)

rect_mask = np.zeros((h, w), dtype=np.uint8)
cv2.rectangle(rect_mask, (0, 0), (w // 2, h // 2), 255, -1)

union_mask = cv2.bitwise_or(circle_mask, rect_mask)          # 원 또는 사각형
intersection_mask = cv2.bitwise_and(circle_mask, rect_mask)  # 원과 사각형이 겹치는 부분만
difference_mask = cv2.bitwise_and(circle_mask, cv2.bitwise_not(rect_mask))  # 원에서 사각형 부분을 뺀 나머지

cv2.imshow('Union', union_mask)
cv2.imshow('Intersection', intersection_mask)
cv2.imshow('Difference', difference_mask)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

## 7.5 비트 연산으로 마스크 실전 적용하기: 로고 합성 예제

`bitwise_and`, `bitwise_or`, `bitwise_not`, `bitwise_xor`는 픽셀 값을 이진수로 보고 비트 단위 논리 연산을 수행합니다. 이진 마스크(값이 0 또는 255)와 함께 쓰면 사실상 "이 영역은 통과, 저 영역은 차단"이라는 스위치처럼 동작하기 때문에, 특정 모양의 영역만 잘라내거나 두 이미지를 합성할 때 즉시 활용할 수 있습니다.

대표적인 예로 투명 배경이 없는 로고 이미지를 배경 사진 위에 자연스럽게 합성하는 작업을 살펴보겠습니다. 흔히 쓰는 순서는 다음과 같습니다.

1. 로고 이미지를 그레이스케일로 바꾸고 임계처리해서, 로고 모양의 이진 마스크와 그 반전 마스크를 만든다.
2. 배경 사진에서 로고가 들어갈 영역을 반전 마스크로 "구멍을 낸다"(`bitwise_and`로 로고가 들어갈 부분만 지운다).
3. 로고 이미지에서 마스크로 로고 부분만 추출한다.
4. 구멍이 난 배경과 추출한 로고를 `bitwise_or` 또는 단순 덧셈으로 합친다.

```python
import cv2
import numpy as np

background = cv2.imread('background.jpg')
logo = cv2.imread('logo.png')

# 로고를 배경의 좌측 상단 영역 크기에 맞춘다
lh, lw = 100, 100
logo = cv2.resize(logo, (lw, lh))
roi = background[10:10 + lh, 10:10 + lw]  # 로고가 들어갈 배경 영역(ROI)

# 로고를 그레이스케일 -> 이진화하여 마스크 생성
logo_gray = cv2.cvtColor(logo, cv2.COLOR_BGR2GRAY)
_, mask = cv2.threshold(logo_gray, 200, 255, cv2.THRESH_BINARY_INV)  # 로고 모양=255
mask_inv = cv2.bitwise_not(mask)  # 배경 유지 부분=255

# 배경 ROI에서 로고가 들어갈 자리를 검정으로 파낸다
background_hole = cv2.bitwise_and(roi, roi, mask=mask_inv)

# 로고 이미지에서 로고 모양만 추출한다
logo_fg = cv2.bitwise_and(logo, logo, mask=mask)

# 둘을 합쳐서 ROI에 다시 넣는다
combined = cv2.bitwise_or(background_hole, logo_fg)
background[10:10 + lh, 10:10 + lw] = combined

cv2.imshow('Mask', mask)
cv2.imshow('Result', background)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

이 예제는 10장에서 배울 `threshold`를 미리 활용했습니다. 마스크를 만드는 표준적인 방법 중 하나가 임계처리이기 때문인데, 자세한 원리는 10장에서 다시 설명합니다. 또한 5장에서 배운 `inRange` 마스크도 이번 절의 `bitwise_and`, `bitwise_or`와 그대로 조합해서 쓸 수 있습니다. 이 조합을 색상 기반으로 확장한 것이 바로 7.7절에서 다룰 그린 스크린 합성입니다.

## 7.6 룩업 테이블(LUT)로 픽셀 값 매핑하기: 감마 보정

지금까지 살펴본 연산들은 모두 "픽셀 값에 어떤 수식을 적용한다"는 방식이었습니다. 그런데 어떤 매핑 규칙이 이미지 전체에 걸쳐 항상 똑같이 적용된다면 — 즉 입력 0은 항상 출력 A, 입력 1은 항상 출력 B로 바뀐다면 — 매번 픽셀마다 수식을 계산하는 대신, **입력값 0~255 각각에 대응하는 출력값을 미리 표로 만들어 두고 그 표를 찾아보기만 하면** 훨씬 빠릅니다. 이 표가 바로 **룩업 테이블(Look-Up Table, LUT)**이고, `cv2.LUT`가 이 표를 이미지 전체에 한 번에 적용해 주는 함수입니다.

```python
dst = cv2.LUT(src, lut)
```

- `src`: `uint8` 타입의 입력 이미지(단일 채널 또는 다채널 모두 가능).
- `lut`: 길이 256인 `uint8` 배열. `lut[i]`가 입력값 `i`에 대응하는 출력값이 된다. `lut`가 단일 채널이면 `src`의 모든 채널에 동일한 표가 적용되고, `src`와 채널 수가 같은 `lut`를 주면 채널마다 다른 표를 적용할 수도 있다.

가장 대표적인 활용 예가 **감마 보정(gamma correction)**입니다. 감마 보정은 다음 공식으로 픽셀 값을 비선형적으로 변환합니다.

```
output = 255 * (input / 255) ** (1 / gamma)
```

- `gamma > 1`이면 어두운 영역이 확장되어 이미지가 전체적으로 **밝아집니다**. 어두운 실내 사진을 보정할 때 사용합니다.
- `gamma < 1`이면 밝은 영역이 압축되어 이미지가 전체적으로 **어두워집니다**. 과다 노출된 사진을 보정할 때 사용합니다.
- `gamma == 1`이면 아무 변화가 없습니다(항등 매핑).

단순히 모든 픽셀에 상수를 더하는 `cv2.add`와 달리, 감마 보정은 밝은 영역과 어두운 영역에 서로 다른 세기로 보정을 가하기 때문에 하이라이트가 날아가거나 어두운 부분이 뭉개지는 것을 어느 정도 방지할 수 있다는 장점이 있습니다.

```python
import cv2
import numpy as np

def build_gamma_lut(gamma: float) -> np.ndarray:
    """gamma 값에 대응하는 256 크기의 uint8 룩업 테이블을 만든다."""
    inv_gamma = 1.0 / gamma
    table = np.array([
        ((i / 255.0) ** inv_gamma) * 255
        for i in range(256)
    ]).astype(np.uint8)
    return table

# 1) 어두운 사진을 밝게 보정 (gamma > 1)
dark_img = cv2.imread('dark_room.jpg')
bright_lut = build_gamma_lut(gamma=2.2)
brightened = cv2.LUT(dark_img, bright_lut)

# 2) 과다 노출된 사진을 어둡게 보정 (gamma < 1)
bright_img = cv2.imread('overexposed_beach.jpg')
dark_lut = build_gamma_lut(gamma=0.5)
darkened = cv2.LUT(bright_img, dark_lut)

cv2.imshow('Dark original', dark_img)
cv2.imshow('Gamma-corrected (brighter)', brightened)
cv2.imshow('Overexposed original', bright_img)
cv2.imshow('Gamma-corrected (darker)', darkened)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 여러 감마 값 비교하기

감마 값에 따라 보정 강도가 어떻게 달라지는지 한눈에 비교하고 싶다면, 여러 개의 LUT를 만들어 나란히 이어 붙여 보면 됩니다.

```python
img = cv2.imread('dark_room.jpg')
gammas = [0.4, 0.7, 1.0, 1.5, 2.2]

results = []
for g in gammas:
    lut = build_gamma_lut(g)
    corrected = cv2.LUT(img, lut)
    cv2.putText(corrected, f'gamma={g}', (10, 30),
                cv2.FONT_HERSHEY_SIMPLEX, 0.8, (0, 255, 0), 2)
    results.append(corrected)

comparison = np.hstack(results)
cv2.imshow('Gamma comparison', comparison)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### LUT로 다른 종류의 매핑도 가능하다

감마 보정 외에도 `cv2.LUT`는 다양한 픽셀 매핑에 활용됩니다. 예를 들어 명암 대비를 강조하는 S자형(sigmoid) 곡선, 특정 밝기 구간만 반전시키는 솔라리제이션(solarization) 효과, 색상 채널별로 다른 톤 커브를 적용하는 색보정(color grading) 등이 모두 "입력값 → 출력값 매핑 표를 만들고 `cv2.LUT`로 적용한다"는 동일한 패턴을 따릅니다.

```python
# 이미지 반전(negative)도 LUT로 표현할 수 있다
invert_lut = np.array([255 - i for i in range(256)], dtype=np.uint8)
inverted = cv2.LUT(img, invert_lut)

# 특정 임계값 아래는 0, 위는 그대로 두는 임계 매핑도 LUT로 흉내낼 수 있다
threshold_lut = np.array([0 if i < 128 else i for i in range(256)], dtype=np.uint8)
thresholded_like = cv2.LUT(img, threshold_lut)
```

## 7.7 크로마키(그린 스크린) 합성 실전 예제

방송이나 영상 편집에서 흔히 쓰는 **크로마키(chroma key)** 기법은, 초록색(또는 파란색) 배경 앞에서 촬영한 인물을 배경만 제거하고 다른 이미지나 영상 위에 합성하는 기법입니다. 원리는 사실 이 장에서 배운 도구들의 조합일 뿐입니다.

1. HSV 색공간에서 `inRange`로 초록색 범위를 골라 **초록 배경 마스크**를 만든다.
2. 마스크를 반전해서 **인물(전경) 마스크**를 만든다.
3. `bitwise_and`로 원본 인물 이미지에서 인물 부분만 추출한다.
4. `bitwise_and`로 새 배경 이미지에서 초록 배경이 있던 자리만 추출한다.
5. 두 결과를 합쳐서 최종 합성 이미지를 만든다.

```python
import cv2
import numpy as np

person = cv2.imread('green_screen_person.jpg')
new_bg = cv2.imread('beach.jpg')
new_bg = cv2.resize(new_bg, (person.shape[1], person.shape[0]))

# 1) HSV로 변환 후 초록색 범위를 마스킹한다
hsv = cv2.cvtColor(person, cv2.COLOR_BGR2HSV)

# 초록 스크린의 색상(Hue) 범위는 스튜디오 조명에 따라 조금씩 다르므로
# 실제 촬영 환경에서는 트랙바 등으로 값을 미세 조정하는 것이 좋다 (5장 참고)
lower_green = np.array([35, 80, 80])
upper_green = np.array([85, 255, 255])
green_mask = cv2.inRange(hsv, lower_green, upper_green)  # 초록 배경=255

# 2) 마스크 경계를 다듬는다: 작은 잡티 제거 + 경계 매끄럽게
#    (모폴로지 연산의 자세한 원리는 11장에서 다룬다)
kernel = np.ones((5, 5), np.uint8)
green_mask = cv2.morphologyEx(green_mask, cv2.MORPH_OPEN, kernel)
green_mask = cv2.medianBlur(green_mask, 5)

# 3) 인물(전경) 마스크는 초록 마스크의 반전
person_mask = cv2.bitwise_not(green_mask)

# 4) 각 이미지에서 필요한 부분만 추출
person_fg = cv2.bitwise_and(person, person, mask=person_mask)   # 인물만
bg_only = cv2.bitwise_and(new_bg, new_bg, mask=green_mask)       # 새 배경 중 초록이 있던 자리만

# 5) 둘을 합쳐서 최종 합성 결과를 만든다
composite = cv2.add(person_fg, bg_only)

cv2.imshow('Green mask', green_mask)
cv2.imshow('Person only', person_fg)
cv2.imshow('Composite', composite)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 트랙바로 초록색 범위를 실시간으로 조정하기

실제 촬영 환경(조명, 카메라, 배경지 재질)에 따라 "초록"의 정확한 HSV 범위가 달라지므로, 5장에서 배운 트랙바를 이용해 범위를 실시간으로 조정하면서 결과를 확인하는 것이 실전에서는 필수적입니다.

```python
def nothing(x):
    pass

cv2.namedWindow('Chroma Key Tuning')
cv2.createTrackbar('H min', 'Chroma Key Tuning', 35, 179, nothing)
cv2.createTrackbar('H max', 'Chroma Key Tuning', 85, 179, nothing)
cv2.createTrackbar('S min', 'Chroma Key Tuning', 80, 255, nothing)
cv2.createTrackbar('V min', 'Chroma Key Tuning', 80, 255, nothing)

while True:
    h_min = cv2.getTrackbarPos('H min', 'Chroma Key Tuning')
    h_max = cv2.getTrackbarPos('H max', 'Chroma Key Tuning')
    s_min = cv2.getTrackbarPos('S min', 'Chroma Key Tuning')
    v_min = cv2.getTrackbarPos('V min', 'Chroma Key Tuning')

    lower = np.array([h_min, s_min, v_min])
    upper = np.array([h_max, 255, 255])
    mask = cv2.inRange(hsv, lower, upper)
    preview = cv2.bitwise_and(person, person, mask=cv2.bitwise_not(mask))

    cv2.imshow('Chroma Key Tuning', preview)
    if cv2.waitKey(1) == 27:  # ESC로 종료
        break

cv2.destroyAllWindows()
```

이 기법은 배경뿐 아니라, 두 영상을 실시간으로 합성하는 화상회의 프로그램의 "가상 배경" 기능이나, 촬영한 제품 사진의 배경을 흰색으로 통일하는 이커머스 이미지 처리에도 그대로 활용됩니다. 핵심은 언제나 동일합니다 — 색이나 밝기로 마스크를 만들고, 그 마스크로 비트 연산을 수행해 원하는 영역만 조합하는 것입니다.

## 요약

- `cv2.add`, `cv2.subtract`는 결과를 데이터 타입의 표현 범위 안으로 saturate(포화)시킨다. NumPy의 `+`, `-` 연산자는 이런 보호가 없어 오버플로/언더플로가 발생할 수 있으므로, 이미지 값 연산에는 OpenCV 함수를 쓰는 것이 안전하다. 두 함수 모두 `mask` 매개변수로 연산 범위를 제한할 수 있다.
- `addWeighted`는 `dst = src1*alpha + src2*beta + gamma` 공식으로 두 이미지를 투명도를 조절해 합성한다. `alpha` 값을 프레임마다 조금씩 바꾸며 반복 호출하면 페이드 인/아웃, 크로스 디졸브 같은 전환 애니메이션을 만들 수 있다.
- `split`은 다채널 이미지를 단일 채널 이미지들로 분리하고, `merge`는 반대로 합친다. 단순 조회만 필요하다면 NumPy 슬라이싱이 더 가볍다.
- 마스크는 원본과 같은 크기의 단일 채널 이미지로, 0이 아닌 픽셀만 연산 대상으로 삼는 데 쓰인다. 마스크끼리도 비트 연산으로 조합해 더 복잡한 관심 영역을 만들 수 있다.
- `bitwise_and`, `bitwise_or`, `bitwise_not`, `bitwise_xor`는 이진 마스크와 결합해 특정 모양의 영역만 골라내거나, 두 이미지를 자연스럽게 합성하는 실전 도구로 쓰인다.
- `cv2.LUT`는 256개의 입력값 각각에 대응하는 출력값을 미리 계산해 둔 표를 이미지 전체에 한 번에 적용한다. 감마 보정, 명암 대비 조정, 색상 반전 등 "같은 입력은 항상 같은 출력"인 매핑을 빠르게 처리하는 데 쓰인다.
- 크로마키 합성은 `inRange`로 배경색 마스크를 만들고, 그 마스크와 반전 마스크에 `bitwise_and`를 적용해 인물과 새 배경을 각각 추출한 뒤 합치는 방식으로 구현한다.
