## 7.1 이미지 산술 연산: saturate 덧셈과 뺄셈

OpenCV의 `add`, `subtract` 함수는 겉보기에 단순한 사칙연산이지만, 일반적인 배열 연산과 결정적으로 다른 점이 하나 있습니다. **결과값이 데이터 타입의 표현 범위를 벗어나지 않도록 saturate(포화) 처리**를 한다는 것입니다.

예를 들어 8비트 이미지(`uint8`)의 픽셀 값은 0~255 범위만 가질 수 있습니다. 두 픽셀 값 200과 100을 더하면 산술적으로는 300이지만, `uint8`로는 표현할 수 없습니다. 이때 동작 방식이 라이브러리마다 다릅니다.

- NumPy의 `+` 연산자는 **오버플로(overflow)** 방식입니다. 300을 8비트로 표현하면 300 - 256 = 44가 되어, 결과가 실제보다 훨씬 작은 값으로 "돌아 넘어갑니다."
- `cv2.add` (C++의 `cv::add`, C#의 `Cv2.Add`)는 **saturate(포화)** 방식입니다. 255를 넘는 값은 무조건 255로 잘립니다.

이 차이는 밝기를 높이는 것처럼 단순한 작업에서 결과를 완전히 다르게 만듭니다. NumPy의 `+`로 밝기를 올리면 원래 밝았던 픽셀이 갑자기 검은색에 가깝게 반전되어 버리는 반면, `cv2.add`는 단순히 흰색으로 밝게 날아갈(clipping) 뿐입니다. 실무에서는 거의 항상 saturate 동작이 원하는 결과이므로, 이미지 값을 더하거나 뺄 때는 NumPy 연산자 대신 OpenCV 함수를 사용하는 것이 안전합니다.

같은 원리가 뺄셈에도 적용됩니다. 50 - 100처럼 결과가 음수가 되는 경우, saturate 뺄셈은 0으로 잘라내지만, NumPy의 `-`는 언더플로가 발생해 156처럼 엉뚱하게 큰 값이 나옵니다.

### Python

```python
import cv2
import numpy as np

img = cv2.imread('lena.jpg')

# 모든 픽셀에 100을 더할 값 행렬 (같은 shape, 같은 타입)
value = np.full(img.shape, 100, dtype=np.uint8)

# 1) OpenCV의 saturate 덧셈: 255를 넘지 않는다
saturated = cv2.add(img, value)

# 2) NumPy의 일반 덧셈: 256을 넘으면 오버플로(모듈로 연산)로 값이 되돌아간다
overflowed = img + value  # 예: 200 + 100 = 300 -> 300 % 256 = 44

print('원본 픽셀:', img[0, 0])
print('cv2.add 결과:', saturated[0, 0])      # 255를 초과하지 않음
print('NumPy + 결과:', overflowed[0, 0])     # 값이 튀어 어두워질 수 있음

cv2.imshow('Saturated (cv2.add)', saturated)
cv2.imshow('Overflowed (numpy +)', overflowed)
cv2.waitKey(0)
cv2.destroyAllWindows()

# 뺄셈도 동일한 원리
darker = cv2.subtract(img, value)   # 0 아래로는 내려가지 않음(saturate)
darker_np = img - value             # 음수가 되면 언더플로 발생
```

### C++

```cpp
#include <opencv2/opencv.hpp>
#include <iostream>

int main() {
    cv::Mat img = cv::imread("lena.jpg");

    // 모든 픽셀에 더할 값 행렬 (같은 shape, 같은 타입)
    cv::Mat value(img.size(), img.type(), cv::Scalar(100, 100, 100));

    // 1) OpenCV의 saturate 덧셈
    cv::Mat saturated;
    cv::add(img, value, saturated);

    // 2) 순수 배열 연산과 비교하기 위해 직접 오버플로를 흉내내는 예시
    //    (C++에서는 cv::Mat의 operator+ 도 내부적으로 saturate_cast를 사용하므로
    //     실제 오버플로를 보려면 원소 단위로 직접 계산해야 한다)
    cv::Mat overflowed = img.clone();
    for (int r = 0; r < img.rows; r++) {
        for (int c = 0; c < img.cols; c++) {
            cv::Vec3b p = img.at<cv::Vec3b>(r, c);
            cv::Vec3b v;
            for (int k = 0; k < 3; k++) {
                v[k] = static_cast<uchar>((static_cast<int>(p[k]) + 100) % 256); // 오버플로 흉내
            }
            overflowed.at<cv::Vec3b>(r, c) = v;
        }
    }

    std::cout << "원본 픽셀: " << img.at<cv::Vec3b>(0, 0) << std::endl;
    std::cout << "cv::add 결과: " << saturated.at<cv::Vec3b>(0, 0) << std::endl;
    std::cout << "오버플로 결과: " << overflowed.at<cv::Vec3b>(0, 0) << std::endl;

    cv::imshow("Saturated (cv::add)", saturated);
    cv::imshow("Overflowed (raw wraparound)", overflowed);
    cv::waitKey(0);

    // 뺄셈
    cv::Mat darker;
    cv::subtract(img, value, darker);   // 0 아래로는 내려가지 않음(saturate)

    return 0;
}
```

### C#

```csharp
using System;
using OpenCvSharp;

class Program
{
    static void Main()
    {
        Mat img = Cv2.ImRead("lena.jpg");

        // 모든 픽셀에 더할 값 행렬
        Mat value = new Mat(img.Size(), img.Type(), new Scalar(100, 100, 100));

        // 1) OpenCvSharp의 saturate 덧셈
        Mat saturated = new Mat();
        Cv2.Add(img, value, saturated);

        // 2) 오버플로 동작을 직접 흉내내어 비교
        Mat overflowed = img.Clone();
        for (int r = 0; r < img.Rows; r++)
        {
            for (int c = 0; c < img.Cols; c++)
            {
                Vec3b p = img.Get<Vec3b>(r, c);
                Vec3b v = new Vec3b(
                    (byte)((p.Item0 + 100) % 256),
                    (byte)((p.Item1 + 100) % 256),
                    (byte)((p.Item2 + 100) % 256));
                overflowed.Set(r, c, v);
            }
        }

        Console.WriteLine($"원본 픽셀: {img.Get<Vec3b>(0, 0)}");
        Console.WriteLine($"Cv2.Add 결과: {saturated.Get<Vec3b>(0, 0)}");
        Console.WriteLine($"오버플로 결과: {overflowed.Get<Vec3b>(0, 0)}");

        Cv2.ImShow("Saturated (Cv2.Add)", saturated);
        Cv2.ImShow("Overflowed (raw wraparound)", overflowed);
        Cv2.WaitKey(0);

        // 뺄셈
        Mat darker = new Mat();
        Cv2.Subtract(img, value, darker);   // 0 아래로는 내려가지 않음(saturate)
    }
}
```

> **참고**: C++와 C#에서는 `cv::Mat`/`Mat`의 `+`, `-` 연산자 자체가 내부적으로 saturate 처리를 하도록 구현되어 있어서, Python의 NumPy처럼 눈에 띄는 오버플로 문제가 잘 발생하지 않습니다. 오버플로 문제는 주로 Python에서 `cv2` 함수 대신 NumPy 배열 연산자를 직접 사용할 때 발생하는 함정이라는 점을 기억해 두세요.

## 7.2 가중합: addWeighted로 이미지 합성하기

두 이미지를 서로 투명하게 겹쳐 보여주고 싶을 때는 `addWeighted`를 사용합니다. 이 함수는 다음 수식을 계산합니다.

```
dst = src1 * alpha + src2 * beta + gamma
```

`alpha`와 `beta`를 각각 0~1 사이의 값으로 설정하고 보통 `beta = 1 - alpha`로 두면, 두 이미지를 자연스럽게 섞은 크로스 디졸브(cross-dissolve) 효과를 얻을 수 있습니다. `gamma`는 결과 전체의 밝기를 조절하는 상수입니다. 두 이미지는 크기와 타입이 동일해야 합니다.

### Python

```python
import cv2

img1 = cv2.imread('lena.jpg')
img2 = cv2.imread('baboon.jpg')

# 두 이미지 크기를 맞춘다
img2 = cv2.resize(img2, (img1.shape[1], img1.shape[0]))

alpha = 0.6
beta = 1 - alpha
blended = cv2.addWeighted(img1, alpha, img2, beta, 0)

cv2.imshow('Blended', blended)
cv2.waitKey(0)
cv2.destroyAllWindows()

# 슬라이더처럼 alpha를 서서히 바꾸며 페이드 전환 효과를 낼 수도 있다
for i in range(0, 11):
    a = i / 10.0
    frame = cv2.addWeighted(img1, a, img2, 1 - a, 0)
    cv2.imshow('Cross-dissolve', frame)
    cv2.waitKey(100)
cv2.destroyAllWindows()
```

### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img1 = cv::imread("lena.jpg");
    cv::Mat img2 = cv::imread("baboon.jpg");

    cv::resize(img2, img2, img1.size());

    double alpha = 0.6;
    double beta = 1.0 - alpha;
    cv::Mat blended;
    cv::addWeighted(img1, alpha, img2, beta, 0, blended);

    cv::imshow("Blended", blended);
    cv::waitKey(0);

    // alpha를 점진적으로 바꾸며 페이드 전환 효과
    for (int i = 0; i <= 10; i++) {
        double a = i / 10.0;
        cv::Mat frame;
        cv::addWeighted(img1, a, img2, 1.0 - a, 0, frame);
        cv::imshow("Cross-dissolve", frame);
        cv::waitKey(100);
    }
    return 0;
}
```

## 7.3 채널 분리와 병합: split과 merge

컬러 이미지는 B, G, R(또는 알파 채널이 있으면 A까지) 여러 채널이 겹쳐진 배열입니다. `split`은 이 채널들을 각각 독립된 단일 채널 이미지로 떼어내고, `merge`는 반대로 여러 개의 단일 채널 이미지를 하나의 다채널 이미지로 합칩니다.

채널을 분리하면 특정 채널만 밝기를 조절하거나, 특정 채널을 0으로 만들어 색을 제거하는 등의 작업이 가능해집니다. 예를 들어 R 채널만 남기고 나머지를 0으로 만들면 붉은 색조만 강조된 이미지를 얻을 수 있습니다.

> **주의**: `split`은 채널 수만큼 반복해서 배열을 순회하므로 비교적 비용이 큰 연산입니다. 단순히 한 채널의 값에 접근하고 싶다면 NumPy 슬라이싱(`img[:, :, 0]`)이나 `cv::extractChannel`처럼 더 가벼운 방법을 쓰는 것이 효율적입니다.

### Python

```python
import cv2
import numpy as np

img = cv2.imread('lena.jpg')  # BGR 순서

# 채널 분리
b, g, r = cv2.split(img)

cv2.imshow('Blue channel', b)
cv2.imshow('Green channel', g)
cv2.imshow('Red channel', r)

# R 채널만 강조: G, B를 0으로 만든 뒤 다시 합치기
zeros = np.zeros_like(b)
red_only = cv2.merge([zeros, zeros, r])
cv2.imshow('Red only', red_only)

# G 채널의 밝기를 절반으로 낮춘 뒤 재합성
g_dark = (g * 0.5).astype(np.uint8)
dimmed_green = cv2.merge([b, g_dark, r])
cv2.imshow('Dimmed green', dimmed_green)

cv2.waitKey(0)
cv2.destroyAllWindows()
```

### C++

```cpp
#include <opencv2/opencv.hpp>
#include <vector>

int main() {
    cv::Mat img = cv::imread("lena.jpg");  // BGR 순서

    // 채널 분리
    std::vector<cv::Mat> channels;
    cv::split(img, channels);
    cv::Mat b = channels[0], g = channels[1], r = channels[2];

    cv::imshow("Blue channel", b);
    cv::imshow("Green channel", g);
    cv::imshow("Red channel", r);

    // R 채널만 강조: G, B를 0으로 만든 뒤 다시 합치기
    cv::Mat zeros = cv::Mat::zeros(b.size(), b.type());
    std::vector<cv::Mat> redOnlyChannels = {zeros, zeros, r};
    cv::Mat redOnly;
    cv::merge(redOnlyChannels, redOnly);
    cv::imshow("Red only", redOnly);

    // G 채널의 밝기를 절반으로 낮춘 뒤 재합성
    cv::Mat gDark = g * 0.5;
    std::vector<cv::Mat> dimmedChannels = {b, gDark, r};
    cv::Mat dimmedGreen;
    cv::merge(dimmedChannels, dimmedGreen);
    cv::imshow("Dimmed green", dimmedGreen);

    cv::waitKey(0);
    return 0;
}
```

### C#

```csharp

        Cv2.Merge(new Mat[] { b, gDark, r }, dimmedGreen);
        Cv2.ImShow("Dimmed green", dimmedGreen);

        Cv2.WaitKey(0);
    }
}
```

## 7.4 마스크(mask)의 개념: 원하는 영역만 골라 연산하기

마스크란 원본 이미지와 같은 크기의 단일 채널(그레이스케일) 이미지로, 픽셀 값이 0이 아닌 위치는 "적용", 0인 위치는 "무시"라는 의미로 사용하는 보조 이미지입니다. 흔히 흰색(255) 영역은 관심 영역(ROI), 검은색(0) 영역은 배경으로 삼습니다.

5장에서 `cv2.inRange`를 이용해 HSV 색공간에서 특정 색상만 골라내는 색상 마스킹을 다뤘습니다. 그때 만든 마스크가 바로 이번 절에서 말하는 마스크입니다. `inRange`의 결과물은 조건을 만족하는 픽셀은 255, 만족하지 않는 픽셀은 0인 이진 이미지이며, 이를 그대로 아래에서 설명할 비트 연산이나 `copyTo`에 활용할 수 있습니다.

많은 OpenCV 함수(`bitwise_and`, `copyTo`, `calcHist` 등)는 `mask`라는 선택적 매개변수를 받습니다. 이 매개변수에 마스크를 넘기면, 함수는 마스크가 0이 아닌 픽셀에만 연산을 적용하고 나머지는 그대로 둡니다.

### Python

```python
import cv2
import numpy as np

img = cv2.imread('lena.jpg')

# 원 모양의 마스크 만들기: 배경은 검정(0), 관심 영역은 흰색(255)
mask = np.zeros(img.shape[:2], dtype=np.uint8)
h, w = mask.shape
cv2.circle(mask, (w // 2, h // 2), min(h, w) // 3, 255, -1)

# 마스크가 적용된 영역만 결과에 복사되고, 나머지는 0(검정)으로 남는다
masked = np.zeros_like(img)
cv2.copyTo(img, mask, masked)   # mask가 0이 아닌 곳만 img 값을 masked로 복사

cv2.imshow('Mask', mask)
cv2.imshow('Masked region only', masked)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img = cv::imread("lena.jpg");

    // 원 모양의 마스크 만들기: 배경은 검정(0), 관심 영역은 흰색(255)
    cv::Mat mask = cv::Mat::zeros(img.size(), CV_8UC1);
    cv::circle(mask, cv::Point(img.cols / 2, img.rows / 2),
               std::min(img.rows, img.cols) / 3, cv::Scalar(255), -1);

    // 마스크가 적용된 영역만 결과에 복사되고, 나머지는 0(검정)으로 남는다
    cv::Mat masked = cv::Mat::zeros(img.size(), img.type());
    img.copyTo(masked, mask);   // mask가 0이 아닌 곳만 img 값을 masked로 복사

    cv::imshow("Mask", mask);
    cv::imshow("Masked region only", masked);
    cv::waitKey(0);
    return 0;
}
```

### C#

```csharp
using OpenCvSharp;

class Program
{
    static void Main()
    {
        Mat img = Cv2.ImRead("lena.jpg");

        // 원 모양의 마스크 만들기: 배경은 검정(0), 관심 영역은 흰색(255)
        Mat mask = Mat.Zeros(img.Size(), MatType.CV_8UC1).ToMat();
        Cv2.Circle(mask, new Point(img.Cols / 2, img.Rows / 2),
                   Math.Min(img.Rows, img.Cols) / 3, Scalar.White, -1);

        // 마스크가 적용된 영역만 결과에 복사되고, 나머지는 0(검정)으로 남는다
        Mat masked = Mat.Zeros(img.Size(), img.Type()).ToMat();
        img.CopyTo(masked, mask);   // mask가 0이 아닌 곳만 img 값을 masked로 복사

        Cv2.ImShow("Mask", mask);
        Cv2.ImShow("Masked region only", masked);
        Cv2.WaitKey(0);
    }
}
```

## 7.5 비트 연산으로 마스크 실전 적용하기: 로고 합성 예제

`bitwise_and`, `bitwise_or`, `bitwise_not`은 픽셀 값을 이진수로 보고 비트 단위 논리 연산을 수행합니다. 이진 마스크(값이 0 또는 255)와 함께 쓰면 사실상 "이 영역은 통과, 저 영역은 차단"이라는 스위치처럼 동작하기 때문에, 특정 모양의 영역만 잘라내거나 두 이미지를 합성할 때 즉시 활용할 수 있습니다.

대표적인 예로 투명 배경이 없는 로고 이미지를 배경 사진 위에 자연스럽게 합성하는 작업을 살펴보겠습니다. 흔히 쓰는 순서는 다음과 같습니다.

1. 로고 이미지를 그레이스케일로 바꾸고 임계처리해서, 로고 모양의 이진 마스크와 그 반전 마스크를 만든다.
2. 배경 사진에서 로고가 들어갈 영역을 반전 마스크로 "구멍을 낸다"(`bitwise_and`로 로고가 들어갈 부분만 지운다).
3. 로고 이미지에서 마스크로 로고 부분만 추출한다.
4. 구멍이 난 배경과 추출한 로고를 `bitwise_or` 또는 단순 덧셈으로 합친다.

### Python

```python
import cv2
import numpy as np

background = cv2.imread('background.jpg')
logo = cv2.imread('logo.png')

# 로고를 배경의 우측 하단 영역 크기에 맞춘다
lh, lw = 100, 100
logo = cv2.resize(logo, (lw, lh))
roi = background[10:10 + lh, 10:10 + lw]  # 로고가 들어갈 배경 영역(ROI)

# 로고를 그레이스케일 -> 이진화하여 마스크 생성
logo_gray = cv2.cvtColor(logo, cv2.COLOR_BGR2GRAY)
_, mask = cv2.threshold(logo_gray, 200, 255, cv2.THRESH_BINARY_INV)  # 로고 모양=255
mask_inv = cv2.bitwise_not(mask)  # 배경 유지 부분=255

# 배경 ROI에서 로고가 들어갈 자리를 검정으로 파낸다
background_hole = cv2.bitwise_and(roi, roi, mask=mask_inv)

# 로고 이미지에서 로고 모양만 추출한다
logo_fg = cv2.bitwise_and(logo, logo, mask=mask)

# 둘을 합쳐서 ROI에 다시 넣는다
combined = cv2.bitwise_or(background_hole, logo_fg)
background[10:10 + lh, 10:10 + lw] = combined

cv2.imshow('Mask', mask)
cv2.imshow('Result', background)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat background = cv::imread("background.jpg");
    cv::Mat logo = cv::imread("logo.png");

    // 로고를 배경의 좌측 상단 영역 크기에 맞춘다
    int lh = 100, lw = 100;
    cv::resize(logo, logo, cv::Size(lw, lh));
    cv::Rect roiRect(10, 10, lw, lh);
    cv::Mat roi = background(roiRect);  // 로고가 들어갈 배경 영역(ROI)

    // 로고를 그레이스케일 -> 이진화하여 마스크 생성
    cv::Mat logoGray, mask, maskInv;
    cv::cvtColor(logo, logoGray, cv::COLOR_BGR2GRAY);
    cv::threshold(logoGray, mask, 200, 255, cv::THRESH_BINARY_INV);  // 로고 모양=255
    cv::bitwise_not(mask, maskInv);  // 배경 유지 부분=255

    // 배경 ROI에서 로고가 들어갈 자리를 검정으로 파낸다
    cv::Mat backgroundHole;
    cv::bitwise_and(roi, roi, backgroundHole, maskInv);

    // 로고 이미지에서 로고 모양만 추출한다
    cv::Mat logoFg;
    cv::bitwise_and(logo, logo, logoFg, mask);

    // 둘을 합쳐서 ROI에 다시 넣는다
    cv::Mat combined;
    cv::bitwise_or(backgroundHole, logoFg, combined);
    combined.copyTo(roi);

    cv::imshow("Mask", mask);
    cv::imshow("Result", background);
    cv::waitKey(0);
    return 0;
}
```

## 요약

- `cv2.add`/`cv::add`/`Cv2.Add`와 `subtract` 계열 함수는 결과를 데이터 타입의 표현 범위 안으로 saturate(포화)시킨다. NumPy의 `+`, `-` 연산자는 이런 보호가 없어 오버플로/언더플로가 발생할 수 있으므로, 이미지 값 연산에는 OpenCV 함수를 쓰는 것이 안전하다.
- `addWeighted`는 `dst = src1*alpha + src2*beta + gamma` 공식으로 두 이미지를 투명도를 조절해 합성한다. `alpha + beta = 1`로 두면 자연스러운 크로스 디졸브 효과를 낼 수 있다.
- `split`은 다채널 이미지를 단일 채널 이미지들로 분리하고, `merge`는 반대로 합친다. 채널별로 값을 조정한 뒤 다시 합성하는 데 활용된다.
- 마스크는 원본과 같은 크기의 단일 채널 이미지로, 0이 아닌 픽셀만 연산 대상으로 삼는 데 쓰인다. 5장의 색상 마스킹(`inRange`)이 대표적인 마스크 생성 방법이다.
- `bitwise_and`, `bitwise_or`, `bitwise_not`은 이진 마스크와 결합해 특정 모양의 영역만 골라내거나, 두 이미지를 자연스럽게 합성하는 실전 도구로 쓰인다.
