지금까지는 이미지의 밝기나 색, 픽셀 값을 다루는 방법을 배웠습니다. 이 장에서는 이미지의 **모양과 위치**를 바꾸는 기하 변환(geometric transformation)을 다룹니다. 크기를 조절하는 리사이즈, 회전과 이동을 함께 표현하는 어파인 변환, 카메라 각도로 기울어진 물체를 정면으로 펴는 원근 변환, 좌우/상하로 뒤집는 플립, 이미지를 단계적으로 축소·확대하는 피라미드, 그리고 임의의 픽셀 매핑을 가능하게 하는 리매핑까지 살펴봅니다. 마지막에는 딥러닝 파이프라인에서 거의 항상 등장하는 전처리 기법인 **letterbox 리사이즈**를 직접 구현해 봅니다.

기하 변환은 데이터 증강(data augmentation), 문서 스캔 보정, 이미지 정합(image registration) 등 실전에서 매우 자주 쓰이는 기법이며, 15장에서 다룰 특징점 매칭 후 이미지를 정렬하는 작업의 기초가 되기도 합니다.

## 8.1 리사이즈(resize)와 보간법

`cv2.resize`는 이미지의 가로·세로 크기를 바꾸는 함수입니다. 크기를 줄이거나 늘릴 때는 원래 없던 픽셀 값을 새로 계산해서 채워야 하는데, 이 계산 방식을 **보간법(interpolation)**이라고 부릅니다. OpenCV가 지원하는 주요 보간법은 다음과 같습니다.

| 보간법 | 설명 | 특징 |
|---|---|---|
| `INTER_NEAREST` (최근접 이웃) | 가장 가까운 픽셀 값을 그대로 사용 | 계산이 가장 빠르지만 결과가 계단처럼 거칠다 |
| `INTER_LINEAR` (양선형) | 주변 4개 픽셀을 거리 기반으로 선형 보간 | 기본값. 속도와 품질의 균형이 좋다 |
| `INTER_CUBIC` (3차 보간) | 주변 16개 픽셀을 3차 함수로 보간 | 더 부드럽고 선명하지만 계산량이 많다 |
| `INTER_AREA` | 픽셀 영역의 평균을 사용 | 이미지를 축소할 때 특히 품질이 좋다 |
| `INTER_LANCZOS4` | 8×8 Lanczos 커널 사용 | 가장 고품질이지만 가장 느리다 |

일반적인 규칙은 "**확대할 때는 `INTER_CUBIC`이나 `INTER_LINEAR`, 축소할 때는 `INTER_AREA`**"입니다. 실시간 처리처럼 속도가 중요한 경우에는 `INTER_NEAREST`나 `INTER_LINEAR`를 선택합니다.

`resize`는 목표 크기를 `(width, height)` 튜플로 직접 지정할 수도 있고, `fx`, `fy` 배율을 지정할 수도 있습니다.

```python
import cv2

img = cv2.imread('lena.jpg')
print('원본 크기:', img.shape[:2])  # (height, width)

# 1) 목표 크기를 직접 지정 (가로 300, 세로 200)
resized_fixed = cv2.resize(img, (300, 200), interpolation=cv2.INTER_LINEAR)

# 2) 배율로 지정 (가로세로 각각 1.5배 확대)
resized_scale = cv2.resize(img, None, fx=1.5, fy=1.5, interpolation=cv2.INTER_CUBIC)

# 3) 보간법 비교: 같은 축소 작업을 여러 방법으로
small_nearest = cv2.resize(img, None, fx=0.2, fy=0.2, interpolation=cv2.INTER_NEAREST)
small_area = cv2.resize(img, None, fx=0.2, fy=0.2, interpolation=cv2.INTER_AREA)

cv2.imshow('Fixed size', resized_fixed)
cv2.imshow('Scaled up (cubic)', resized_scale)
cv2.imshow('Shrunk (nearest)', small_nearest)
cv2.imshow('Shrunk (area)', small_area)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 네 가지 보간법을 한 화면에서 직접 비교하기

말로만 설명하는 것보다 같은 확대/축소 작업을 여러 보간법으로 수행한 뒤 나란히 놓고 비교하면 차이가 훨씬 분명하게 보입니다. 아래 예제는 작은 이미지를 크게 확대해서 보간법별 결과를 비교합니다(확대할수록 방식 간 차이가 눈에 잘 보입니다).

```python
import cv2
import numpy as np

img = cv2.imread('small_icon.png')  # 일부러 작은 이미지를 사용
scale = 8  # 8배 확대해서 차이를 극명하게 드러낸다

methods = {
    'NEAREST': cv2.INTER_NEAREST,
    'LINEAR': cv2.INTER_LINEAR,
    'CUBIC': cv2.INTER_CUBIC,
    'LANCZOS4': cv2.INTER_LANCZOS4,
}

results = []
for name, flag in methods.items():
    up = cv2.resize(img, None, fx=scale, fy=scale, interpolation=flag)
    cv2.putText(up, name, (10, 25), cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 0, 255), 2)
    results.append(up)

comparison = np.hstack(results)
cv2.imshow('Interpolation comparison (upscale)', comparison)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

반대로 이미지를 **축소**할 때는 `INTER_AREA`가 특히 유리합니다. `INTER_NEAREST`나 `INTER_LINEAR`로 이미지를 크게 축소하면 원본의 여러 픽셀 정보가 듬성듬성 샘플링되면서 잘게 반복되는 패턴(예: 옷의 격자무늬, 건물의 창문들)에서 계단 형태의 앨리어싱(aliasing)이 생기기 쉽습니다. `INTER_AREA`는 축소 영역에 대응하는 원본 픽셀들의 평균을 취하므로 이런 잔상이 훨씬 덜 생깁니다.

```python
img = cv2.imread('checkerboard_pattern.jpg')

small_linear = cv2.resize(img, None, fx=0.1, fy=0.1, interpolation=cv2.INTER_LINEAR)
small_area = cv2.resize(img, None, fx=0.1, fy=0.1, interpolation=cv2.INTER_AREA)

# 비교하기 쉽게 다시 원본 크기로 확대해서 나란히 놓는다
h, w = img.shape[:2]
small_linear_big = cv2.resize(small_linear, (w, h), interpolation=cv2.INTER_NEAREST)
small_area_big = cv2.resize(small_area, (w, h), interpolation=cv2.INTER_NEAREST)

cv2.imshow('Shrunk with LINEAR (more aliasing)', small_linear_big)
cv2.imshow('Shrunk with AREA (less aliasing)', small_area_big)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

정리하면 다음과 같은 선택 기준을 기억해 두면 됩니다.

- **확대(scale > 1)**: 품질이 중요하면 `INTER_CUBIC` 또는 `INTER_LANCZOS4`, 속도가 중요하면 `INTER_LINEAR`.
- **축소(scale < 1)**: `INTER_AREA`가 기본 선택. 앨리어싱을 최소화한다.
- **실시간/저지연 처리(예: 영상 스트림 전처리)**: `INTER_NEAREST`나 `INTER_LINEAR`처럼 계산량이 적은 방식.
- **픽셀 값 자체가 의미를 가지는 데이터(예: 라벨 마스크, 깊이 맵)**: 새 값을 "만들어 내면" 안 되므로 `INTER_NEAREST`를 사용해 기존 값만 그대로 옮긴다.

## 8.2 이동과 회전: warpAffine과 getRotationMatrix2D

**어파인 변환(affine transformation)**은 이동, 회전, 크기 조절, 기울임(shear)을 하나의 2×3 행렬로 표현하는 변환입니다. 어파인 변환의 중요한 성질은 변환 전에 평행했던 두 직선이 변환 후에도 평행을 유지한다는 점입니다. 이는 뒤에서 다룰 원근 변환과 구분되는 핵심적인 차이입니다.

이동만 표현하려면 다음과 같은 2×3 행렬을 사용합니다.

```
M = [ 1  0  tx ]
    [ 0  1  ty ]
```

여기서 `tx`, `ty`는 각각 x축, y축으로 이동할 픽셀 수입니다. 회전을 표현하려면 회전 중심, 회전 각도(도 단위), 크기 배율(scale)을 입력받아 자동으로 2×3 회전 행렬을 만들어 주는 `cv2.getRotationMatrix2D`를 사용하는 것이 편리합니다. 이렇게 만든 행렬 `M`을 `cv2.warpAffine`에 넘기면 실제 이미지에 변환이 적용됩니다.

```python
import cv2
import numpy as np

img = cv2.imread('lena.jpg')
h, w = img.shape[:2]

# 1) 평행 이동: x축으로 50px, y축으로 30px 이동
M_translate = np.float32([[1, 0, 50], [0, 1, 30]])
translated = cv2.warpAffine(img, M_translate, (w, h))

# 2) 회전: 이미지 중심을 기준으로 45도 회전, 크기는 그대로(scale=1.0)
center = (w // 2, h // 2)
M_rotate = cv2.getRotationMatrix2D(center, angle=45, scale=1.0)
rotated = cv2.warpAffine(img, M_rotate, (w, h))

# 3) 회전 + 축소를 동시에 (scale=0.7)
M_rotate_scale = cv2.getRotationMatrix2D(center, angle=30, scale=0.7)
rotated_scaled = cv2.warpAffine(img, M_rotate_scale, (w, h))

cv2.imshow('Translated', translated)
cv2.imshow('Rotated 45deg', rotated)
cv2.imshow('Rotated+Scaled', rotated_scaled)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 회전 후 잘림 방지: 캔버스 크기 보정하기

`warpAffine`으로 회전을 하면 이미지의 모서리 부분이 캔버스 밖으로 잘려 나갈 수 있습니다. 회전 후 전체 내용을 보존하려면 회전 각도에 따라 필요한 새 캔버스 크기를 삼각함수로 계산하고, 회전 행렬의 이동 성분(`M[0, 2]`, `M[1, 2]`)을 그만큼 보정해 주어야 합니다.

```python
import cv2
import numpy as np

def rotate_without_cropping(img, angle):
    h, w = img.shape[:2]
    center = (w / 2, h / 2)

    M = cv2.getRotationMatrix2D(center, angle, 1.0)

    # 회전 후 필요한 새 캔버스 크기를 계산
    cos = abs(M[0, 0])
    sin = abs(M[0, 1])
    new_w = int(h * sin + w * cos)
    new_h = int(h * cos + w * sin)

    # 회전 중심이 새 캔버스의 중심으로 오도록 이동 성분을 보정
    M[0, 2] += (new_w / 2) - center[0]
    M[1, 2] += (new_h / 2) - center[1]

    return cv2.warpAffine(img, M, (new_w, new_h))

img = cv2.imread('lena.jpg')
rotated_full = rotate_without_cropping(img, 45)
cv2.imshow('Rotated without cropping', rotated_full)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### warpAffine의 그 외 옵션: 경계 처리와 역방향 매핑

`warpAffine`은 변환 후 원본 이미지 범위를 벗어난 픽셀을 어떻게 채울지 `borderMode`와 `borderValue`로 지정할 수 있고, `flags`에 `cv2.WARP_INVERSE_MAP`을 추가하면 `M`을 목적지→원본 방향의 역변환 행렬로 해석하게 만들 수 있습니다.

```python
# 캔버스 밖으로 나간 영역을 검정이 아닌 특정 색으로 채우기
translated_colored_border = cv2.warpAffine(
    img, M_translate, (w, h),
    borderMode=cv2.BORDER_CONSTANT, borderValue=(255, 0, 0)  # 파란색으로 채움
)

# 경계를 이미지 자체의 반사로 채우기 (검은 테두리가 어색할 때 유용)
translated_reflected = cv2.warpAffine(
    img, M_translate, (w, h), borderMode=cv2.BORDER_REFLECT
)
```

## 8.3 원근 변환: 기울어진 문서를 정면으로 펴기

어파인 변환은 평행선을 그대로 유지하기 때문에, 카메라를 비스듬히 기울여 촬영한 문서처럼 "원근감" 때문에 사각형이 사다리꼴로 찍힌 이미지는 어파인 변환만으로 완벽하게 펼 수 없습니다. 이런 경우에는 **원근 변환(perspective transformation)**이 필요합니다.

원근 변환은 3×3 행렬을 사용하며, 어파인 변환과 달리 평행선이 평행하지 않게(또는 그 반대로) 바뀔 수 있습니다. 어파인 변환에는 3개의 대응점만 있으면 행렬을 유일하게 구할 수 있지만, 원근 변환에는 4개의 대응점이 필요합니다.

사용 순서는 다음과 같습니다.

1. 원본 이미지에서 네 모서리(왜곡된 사각형)의 좌표 4개를 찾는다.
2. 이 점들이 옮겨갈 목표 좌표 4개(보통 정사각형이나 직사각형의 네 모서리)를 정한다.
3. `cv2.getPerspectiveTransform(src_points, dst_points)`로 3×3 변환 행렬을 구한다.
4. `cv2.warpPerspective`에 이 행렬을 넘겨 실제 변환을 적용한다.

아래 예제는 기울어진 각도에서 촬영된 문서의 네 꼭짓점을 지정해서, 이를 정면에서 본 것처럼 평평하게 펴는 작업을 보여줍니다.

```python
import cv2
import numpy as np

img = cv2.imread('document.jpg')

# 1) 원본 이미지에서 기울어진 문서의 네 모서리 좌표
#    (좌상, 우상, 우하, 좌하 순서로 지정하는 것이 관례)
src_points = np.float32([
    [120, 80],    # 좌상
    [430, 60],    # 우상
    [460, 500],   # 우하
    [80, 480],    # 좌하
])

# 2) 목표: 가로 400 x 세로 500 크기의 정면 문서로 편다
dst_w, dst_h = 400, 500
dst_points = np.float32([
    [0, 0],
    [dst_w, 0],
    [dst_w, dst_h],
    [0, dst_h],
])

# 3) 원근 변환 행렬 계산
M = cv2.getPerspectiveTransform(src_points, dst_points)

# 4) 변환 적용
warped = cv2.warpPerspective(img, M, (dst_w, dst_h))

# 참고용으로 원본에 선택한 4점을 표시
preview = img.copy()
for pt in src_points:
    cv2.circle(preview, tuple(pt.astype(int)), 6, (0, 0, 255), -1)

cv2.imshow('Original with points', preview)
cv2.imshow('Warped (flattened)', warped)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

아래 다이어그램은 같은 정사각형 이미지가 어파인 변환과 원근 변환을 각각 거쳤을 때 결과 모양이 어떻게 다른지 비교해서 보여줍니다. 어파인 변환은 변의 평행 관계를 유지한 채 평행사변형으로만 바뀌지만, 원근 변환은 사다리꼴처럼 평행 관계가 무너지는 왜곡까지 표현할 수 있습니다.

### 마우스로 네 꼭짓점을 직접 클릭해서 지정하기

실전에서는 문서의 네 꼭짓점 좌표를 미리 알 수 없는 경우가 많습니다. 6장에서 배운 마우스 콜백을 응용하면, 화면에 표시된 이미지를 클릭해서 네 점을 직접 지정하고 곧바로 원근 변환을 적용하는 간단한 도구를 만들 수 있습니다.

```python
import cv2
import numpy as np

img = cv2.imread('document.jpg')
clicked_points = []

def on_mouse(event, x, y, flags, param):
    if event == cv2.EVENT_LBUTTONDOWN and len(clicked_points) < 4:
        clicked_points.append((x, y))
        cv2.circle(img, (x, y), 6, (0, 0, 255), -1)
        cv2.imshow('Click 4 corners (TL, TR, BR, BL)', img)

cv2.imshow('Click 4 corners (TL, TR, BR, BL)', img)
cv2.setMouseCallback('Click 4 corners (TL, TR, BR, BL)', on_mouse)
cv2.waitKey(0)
cv2.destroyAllWindows()

if len(clicked_points) == 4:
    src_points = np.float32(clicked_points)
    dst_w, dst_h = 400, 500
    dst_points = np.float32([[0, 0], [dst_w, 0], [dst_w, dst_h], [0, dst_h]])
    M = cv2.getPerspectiveTransform(src_points, dst_points)
    warped = cv2.warpPerspective(cv2.imread('document.jpg'), M, (dst_w, dst_h))
    cv2.imshow('Warped', warped)
    cv2.waitKey(0)
    cv2.destroyAllWindows()
```

## 8.4 뒤집기(flip)

`cv2.flip`은 이미지를 좌우 또는 상하로 뒤집는 간단하지만 자주 쓰이는 함수입니다. 플래그 값으로 방향을 지정합니다.

- `1` (양수): 좌우 반전(수평 방향, 세로축을 기준으로 좌우 대칭)
- `0`: 상하 반전(수직 방향, 가로축을 기준으로 위아래 대칭)
- `-1` (음수): 좌우와 상하를 모두 반전(180도 회전과 같은 효과)

```python
import cv2

img = cv2.imread('lena.jpg')

flipped_horizontal = cv2.flip(img, 1)   # 좌우 반전
flipped_vertical = cv2.flip(img, 0)     # 상하 반전
flipped_both = cv2.flip(img, -1)        # 좌우 + 상하 반전

cv2.imshow('Horizontal flip', flipped_horizontal)
cv2.imshow('Vertical flip', flipped_vertical)
cv2.imshow('Both flip', flipped_both)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`flip`은 딥러닝 학습 데이터를 늘리는 **데이터 증강**에서 가장 손쉽게 쓸 수 있는 변환 중 하나입니다. 다만 좌우 반전을 적용할 때는 이미지 안에 방향성이 있는 정보(예: 도로 표지판의 글자, 좌/우가 구분되는 라벨)가 있다면 라벨도 함께 바꿔줘야 한다는 점을 주의해야 합니다.

## 8.5 이미지 피라미드: pyrDown과 pyrUp으로 멀티스케일 다루기

지금까지의 `resize`는 임의의 배율로 이미지를 조절했습니다. 반면 **이미지 피라미드(image pyramid)**는 이미지를 정확히 절반씩 축소하거나 두 배씩 확대하는 것을 반복해서, 마치 피라미드처럼 크기가 층층이 다른 여러 버전을 만드는 기법입니다.

- `cv2.pyrDown(src)`: 가우시안 블러로 이미지를 부드럽게 만든 뒤 가로세로를 각각 절반으로 다운샘플링한다. 결과 크기는 대략 `((cols+1)//2, (rows+1)//2)`이다.
- `cv2.pyrUp(src)`: 가로세로를 각각 두 배로 업샘플링한 뒤 가우시안 블러로 부드럽게 만든다. 결과 크기는 대략 `(cols*2, rows*2)`이다.

여기서 블러를 함께 적용하는 이유는 단순히 픽셀을 건너뛰며 축소하면 앨리어싱이 발생하기 때문입니다. 가우시안 커널로 먼저 부드럽게 만든 뒤 다운샘플링하면 원본의 저주파(큰 구조) 정보를 최대한 보존하면서 크기를 줄일 수 있습니다. 이 원리 때문에 이런 계층 구조를 **가우시안 피라미드(Gaussian pyramid)**라고 부릅니다.

```python
import cv2

img = cv2.imread('lena.jpg')

# 피라미드 아래 방향(축소): 절반씩 줄여가며 4단계를 생성
pyramid_down = [img]
for i in range(3):
    down = cv2.pyrDown(pyramid_down[-1])
    pyramid_down.append(down)

for i, level in enumerate(pyramid_down):
    print(f'Level {i}: {level.shape[:2]}')
    cv2.imshow(f'pyrDown level {i}', level)

cv2.waitKey(0)
cv2.destroyAllWindows()
```

중요한 점은 `pyrDown`으로 한 번 줄인 이미지를 `pyrUp`으로 다시 키워도, **원본과 완전히 같아지지는 않는다**는 것입니다. 다운샘플링 과정에서 세부 정보(고주파 성분)가 이미 사라졌기 때문입니다. 즉 이 두 함수는 서로 완전한 역연산이 아니라 손실이 있는(lossy) 연산입니다.

```python
small = cv2.pyrDown(img)          # 절반 크기로 축소
restored = cv2.pyrUp(small)       # 다시 두 배로 확대 (원본과 크기는 같아지지만 내용은 다르다)

diff = cv2.absdiff(img, restored)
print('픽셀 차이 평균:', diff.mean())  # 0이 아니다 -- 정보가 손실되었다는 뜻

cv2.imshow('Original', img)
cv2.imshow('Down -> Up restored', restored)
cv2.imshow('Difference', diff)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 피라미드를 실제로 어디에 쓰는가

- **멀티스케일 처리**: 같은 알고리즘(예: 얼굴 검출, 템플릿 매칭)을 원본과 여러 축소 단계에 반복 적용하면, 이미지 안에 크기가 다른 물체가 있어도 놓치지 않고 찾아낼 수 있습니다.
- **이미지 블렌딩**: 두 이미지를 이어 붙일 때 각 피라미드 단계에서 서로 다른 크기의 경계 영역을 블렌딩하면, 경계가 훨씬 자연스럽게 이어지는 결과를 얻을 수 있습니다(라플라시안 피라미드 블렌딩).
- **연산량 절감**: 큰 이미지에서 대략적인 위치를 먼저 저해상도로 빠르게 찾고, 그 근처만 원본 해상도로 정밀하게 다시 처리하는 방식으로 전체 연산 시간을 줄일 수 있습니다.

```python
# 여러 스케일에서 같은 작업(여기서는 단순히 크기 출력)을 반복하는 전형적인 패턴
level = img.copy()
scale_factor = 1.0
while min(level.shape[:2]) > 32:
    print(f'현재 스케일: {scale_factor:.3f}, 크기: {level.shape[:2]}')
    # 이 지점에서 얼굴 검출, 템플릿 매칭 등 원하는 알고리즘을 수행할 수 있다
    level = cv2.pyrDown(level)
    scale_factor /= 2.0
```

## 8.6 리매핑(remap): 임의의 픽셀 매핑

`warpAffine`과 `warpPerspective`는 각각 정해진 형태(2×3, 3×3 행렬)의 변환만 표현할 수 있습니다. 반면 `cv2.remap`은 "출력 이미지의 각 픽셀이 입력 이미지의 어느 좌표에서 값을 가져올지"를 **좌표별로 자유롭게** 지정할 수 있는, 훨씬 일반적인 변환 함수입니다.

```python
dst = cv2.remap(src, map_x, map_y, interpolation)
```

- `map_x`, `map_y`: 출력 이미지와 같은 크기의 `float32` 배열. `map_x[y, x]`와 `map_y[y, x]`는 출력 픽셀 `(x, y)`의 값을 입력 이미지의 어느 좌표 `(map_x[y,x], map_y[y,x])`에서 가져올지를 나타낸다.
- `interpolation`: 계산된 좌표가 정수가 아닐 때 사용할 보간법(`cv2.INTER_LINEAR` 등).

행렬로 표현되지 않는 임의의 왜곡 — 예를 들어 렌즈 왜곡 보정, 어안 렌즈(fisheye) 펴기, 물결 효과 — 을 표현하려면 `remap`이 필요합니다. 실제로 `cv2.initUndistortRectifyMap`으로 만든 왜곡 보정용 맵을 `remap`에 넘겨 렌즈 왜곡을 펴는 작업(16장에서 다루는 카메라 캘리브레이션과 연결됩니다)이 대표적인 활용 예입니다.

간단한 예로, `flip`과 동일한 좌우 반전을 `remap`으로 직접 구현해 보겠습니다.

```python
import cv2
import numpy as np

img = cv2.imread('lena.jpg')
h, w = img.shape[:2]

xs, ys = np.meshgrid(np.arange(w), np.arange(h))

# 출력의 (x, y)는 입력의 (w-1-x, y)에서 값을 가져온다 -> 좌우 반전
map_x = (w - 1 - xs).astype(np.float32)
map_y = ys.astype(np.float32)

flipped_by_remap = cv2.remap(img, map_x, map_y, interpolation=cv2.INTER_LINEAR)
cv2.imshow('Flipped via remap', flipped_by_remap)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`remap`의 진짜 힘은 이렇게 규칙적인 변환이 아니라, 좌표마다 다른 규칙을 적용할 수 있다는 데 있습니다. 아래는 사인 함수를 이용해 이미지에 물결(wave) 왜곡을 주는 예제입니다.

```python
amplitude = 15    # 물결의 높이(픽셀)
wavelength = 60   # 물결의 주기(픽셀)

wave_map_x = xs.astype(np.float32)
wave_map_y = (ys + amplitude * np.sin(2 * np.pi * xs / wavelength)).astype(np.float32)

wavy = cv2.remap(img, wave_map_x, wave_map_y, interpolation=cv2.INTER_LINEAR,
                  borderMode=cv2.BORDER_REFLECT)
cv2.imshow('Wave distortion via remap', wavy)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`map_x`, `map_y`를 이중 for문으로 한 픽셀씩 계산하면 매우 느려지므로, 위 예제처럼 `numpy.meshgrid`와 배열 연산으로 맵 전체를 한 번에 벡터화해서 계산하는 것이 실전에서 훨씬 효율적입니다.

## 8.7 실전 유틸리티: letterbox 리사이즈

딥러닝 이미지 분류·객체 검출 모델(YOLO 계열 등)은 대부분 정해진 정사각형 또는 고정 비율의 입력 크기(예: 640×640)를 요구합니다. 그런데 원본 이미지의 가로세로 비율이 그 입력 비율과 다르면, 단순히 `resize`로 크기를 맞추면 이미지가 찌그러져(aspect ratio distortion) 물체의 형태가 왜곡됩니다.

이를 방지하기 위한 표준적인 방법이 **letterbox 리사이즈**입니다. 원본의 가로세로 비율을 유지한 채로 목표 크기 안에 들어갈 수 있는 최대 크기로 리사이즈하고, 남는 여백은 검은색(또는 다른 지정 색)으로 패딩해서 채우는 방식입니다. 마치 와이드스크린 영상을 4:3 화면에 띄울 때 위아래에 검은 띠(letterbox)가 생기는 것과 같은 원리입니다.

```python
import cv2
import numpy as np

def letterbox(img, target_size=(640, 640), color=(0, 0, 0)):
    """
    종횡비를 유지한 채 target_size에 맞춰 리사이즈하고,
    남는 공간은 지정한 색(기본값: 검정)으로 패딩한다.
    딥러닝 모델 입력 전처리(YOLO 등)에서 흔히 쓰는 방식이다.

    Parameters
    ----------
    img : np.ndarray
        입력 이미지, shape은 (H, W, C) 또는 (H, W)
    target_size : tuple[int, int]
        (target_width, target_height)
    color : tuple
        패딩에 사용할 색상 (BGR 순서)

    Returns
    -------
    padded : np.ndarray
        (target_height, target_width, C) 크기의 결과 이미지
    scale : float
        원본에 적용된 리사이즈 배율 (원본 좌표 -> 리사이즈 후 좌표로 환산할 때 곱하는 값)
    pad : tuple[int, int]
        (left, top) -- 패딩으로 추가된 좌측/상단 여백 폭(픽셀)
    """
    target_w, target_h = target_size
    h, w = img.shape[:2]

    # 가로세로 중 더 작은 배율을 선택해야 이미지가 목표 크기를 벗어나지 않는다
    scale = min(target_w / w, target_h / h)
    new_w, new_h = int(round(w * scale)), int(round(h * scale))

    # 축소면 INTER_AREA, 확대면 INTER_LINEAR를 선택 (8.1절 참고)
    interp = cv2.INTER_AREA if scale < 1 else cv2.INTER_LINEAR
    resized = cv2.resize(img, (new_w, new_h), interpolation=interp)

    pad_w = target_w - new_w
    pad_h = target_h - new_h
    top, bottom = pad_h // 2, pad_h - pad_h // 2
    left, right = pad_w // 2, pad_w - pad_w // 2

    padded = cv2.copyMakeBorder(
        resized, top, bottom, left, right,
        borderType=cv2.BORDER_CONSTANT, value=color
    )
    return padded, scale, (left, top)


img = cv2.imread('landscape_photo.jpg')  # 예: 1920x1080 (16:9)
letterboxed, scale, (pad_left, pad_top) = letterbox(img, target_size=(640, 640))

print('결과 크기:', letterboxed.shape[:2])   # (640, 640)
print('적용된 배율:', scale)
print('패딩 (left, top):', pad_left, pad_top)

cv2.imshow('Letterboxed', letterboxed)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 좌표 역변환: 모델 출력을 원본 이미지 좌표로 되돌리기

객체 검출 모델은 letterbox된 이미지 위의 좌표(예: 바운딩 박스)를 출력합니다. 이 좌표를 원본 이미지 위에 다시 그리려면, letterbox를 적용할 때 사용한 `scale`과 `pad`를 거꾸로 적용해서 되돌려야 합니다.

```python
def unletterbox_point(x, y, scale, pad):
    """letterbox된 이미지 위의 좌표를 원본 이미지 좌표로 되돌린다."""
    pad_left, pad_top = pad
    orig_x = (x - pad_left) / scale
    orig_y = (y - pad_top) / scale
    return orig_x, orig_y

# 모델이 letterbox 이미지 위에서 (300, 250) 지점을 검출했다고 가정
model_x, model_y = 300, 250
orig_x, orig_y = unletterbox_point(model_x, model_y, scale, (pad_left, pad_top))
print(f'원본 이미지 좌표: ({orig_x:.1f}, {orig_y:.1f})')
```

이 letterbox 함수는 이미지 분류·검출뿐 아니라, 서로 다른 비율의 사진을 정해진 썸네일 틀에 통일된 크기로 넣어야 하는 갤러리 UI 등 일반적인 이미지 처리 작업에도 그대로 활용할 수 있습니다.

## 요약

- `resize`는 이미지 크기를 바꾸며, 보간법(`INTER_NEAREST`, `INTER_LINEAR`, `INTER_CUBIC`, `INTER_AREA`, `INTER_LANCZOS4`)에 따라 속도와 품질이 달라진다. 확대에는 `CUBIC`/`LANCZOS4`, 축소에는 `AREA`가 일반적으로 권장되며, 라벨·마스크처럼 값 자체가 의미를 가지는 데이터는 `NEAREST`를 써야 한다.
- 어파인 변환은 2×3 행렬로 이동·회전·크기·기울임을 표현하며, 평행선을 그대로 유지한다. `getRotationMatrix2D`로 회전 행렬을 만들고 `warpAffine`으로 적용하며, 회전 후 잘림을 막으려면 캔버스 크기와 이동 성분을 함께 보정해야 한다.
- 원근 변환은 3×3 행렬과 4개의 대응점을 사용하며, 평행선이 평행하지 않게 바뀔 수 있어 카메라 각도로 왜곡된 문서나 평면을 정면 시점으로 펴는 데 쓰인다. `getPerspectiveTransform`으로 행렬을 구하고 `warpPerspective`로 적용한다.
- `flip`은 플래그 값(1: 좌우, 0: 상하, -1: 양쪽 모두)으로 이미지를 반전시키며, 데이터 증강에서 자주 쓰인다.
- `pyrDown`/`pyrUp`은 가우시안 블러와 결합된 절반/두 배 크기 조절을 제공하며, 이 계층 구조를 가우시안 피라미드라고 부른다. 멀티스케일 처리, 이미지 블렌딩, 연산량 절감 등에 활용되며 축소-확대가 원본을 완전히 복원하지는 못하는 손실 연산이다.
- `remap`은 출력 픽셀마다 입력 이미지의 어느 좌표를 참조할지 자유롭게 지정할 수 있는 가장 일반적인 기하 변환 함수로, 렌즈 왜곡 보정이나 물결 효과처럼 행렬로 표현할 수 없는 임의의 매핑에 사용된다.
- letterbox 리사이즈는 종횡비를 유지한 채 목표 크기에 맞춰 리사이즈하고 남는 공간을 패딩으로 채우는 방식으로, 딥러닝 모델의 입력 전처리에서 표준적으로 쓰인다. 모델 출력 좌표를 원본 이미지로 되돌리려면 적용했던 `scale`과 패딩 값을 거꾸로 계산해야 한다.
