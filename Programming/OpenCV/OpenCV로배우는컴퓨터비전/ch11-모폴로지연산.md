## 11.1 모폴로지 연산은 왜 이진 이미지에서 시작하는가

10장에서는 `threshold`와 `adaptiveThreshold`를 이용해 그레이스케일 이미지를 흑과 백 두 값만 남은 이진 이미지로 바꾸는 방법을 다뤘다. 그런데 실제로 이진화를 해보면 결과가 깨끗한 경우가 드물다. 배경에 조명이 살짝 얼룩진 부분이 있으면 그 자리에 작은 흰 점(노이즈)이 튀어나오고, 글자나 객체 내부에 조명 반사나 얼룩이 있으면 그 부분만 값이 반전되어 작은 검은 구멍이 남는다. 이런 잡티는 눈으로 보면 사소해 보이지만, 이후 13장에서 다룰 컨투어 검출이나 객체 개수 세기 같은 작업에서는 각각 하나의 "가짜 객체"나 "끊어진 경계"로 인식되어 결과를 심각하게 왜곡시킨다.

모폴로지(morphology) 연산은 바로 이 문제, 즉 이진 이미지에 남은 작은 노이즈와 구멍을 정리하기 위해 만들어진 도구다. 이름 그대로 "형태학적" 연산으로, 픽셀의 밝기 값 자체를 계산하는 것이 아니라 객체의 모양(shape)을 구조 요소(structuring element)라는 작은 틀에 맞춰 깎아내거나 부풀리는 방식으로 동작한다. 그래서 모폴로지 연산은 원칙적으로 이진 이미지(객체 = 흰색 255, 배경 = 검은색 0)를 대상으로 하며, 그레이스케일 이미지에 적용할 수도 있지만 이 장에서는 10장에서 만든 이진 이미지를 다듬는 용도로 다룬다.

핵심 아이디어는 간단하다. 작은 창(kernel)을 이미지 위에서 한 픽셀씩 이동시키면서, 그 창이 걸쳐 있는 영역의 값들을 보고 중심 픽셀의 값을 새로 정한다. 창 안의 모든 픽셀이 흰색이어야 중심을 흰색으로 유지하면 침식이 되고, 창 안에 흰색이 하나라도 있으면 중심을 흰색으로 만들면 팽창이 된다. 이 두 가지 기본 연산을 조합하면 노이즈 제거, 구멍 메우기, 객체 분리, 경계 강조 등 다양한 후처리를 할 수 있다.

이 장에서는 침식과 팽창이라는 두 기본 연산에서 출발해, 이를 조합한 열림·닫힘·그라디언트·탑햇·블랙햇까지 OpenCV의 `morphologyEx` 함수가 제공하는 대표적인 모폴로지 연산을 순서대로 살펴본다. 마지막에는 서로 다른 모양의 구조 요소가 실제로 결과에 어떤 차이를 만드는지 직접 비교하는 실전 예제로 마무리한다.

## 11.2 구조 요소: 연산의 모양을 결정하는 틀

모폴로지 연산에서 구조 요소(structuring element, 흔히 kernel이라고도 부른다)는 "이웃을 어떤 모양으로 볼 것인가"를 정의하는 작은 행렬이다. 3×3 정사각형을 쓰면 상하좌우와 대각선을 포함한 8방향 이웃을 보는 것이고, 십자형을 쓰면 상하좌우 4방향만 본다. 구조 요소의 모양과 크기에 따라 연산의 결과가 달라지므로, 상황에 맞는 구조 요소를 선택하는 것이 모폴로지 연산의 실질적인 튜닝 포인트다.

OpenCV는 `cv2.getStructuringElement` 함수로 자주 쓰이는 세 가지 형태의 구조 요소를 바로 만들어준다.

- `cv2.MORPH_RECT`: 사각형. 모든 픽셀이 1인 정사각형(또는 직사각형) 커널이다. 가장 강하게 깎거나 부풀리며, 객체의 모서리가 사각형에 가깝게 다듬어진다.
- `cv2.MORPH_ELLIPSE`: 타원형. 커널 내부에 타원을 그린 모양으로, 사각형보다 부드럽고 둥근 결과를 낸다. 둥근 객체(세포, 동전, 얼굴 등)를 다룰 때 자연스럽다.
- `cv2.MORPH_CROSS`: 십자형. 중심을 지나는 가로선과 세로선만 1인 모양으로, 대각선 방향의 연결을 무시하고 상하좌우 방향으로만 얇게 침식/팽창한다.

```python
import cv2

rect_kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
ellipse_kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
cross_kernel = cv2.getStructuringElement(cv2.MORPH_CROSS, (5, 5))

print(rect_kernel)
print(ellipse_kernel)
print(cross_kernel)
```

세 커널을 실제로 출력해 보면 값이 0과 1로만 채워진 작은 행렬이라는 사실을 눈으로 확인할 수 있다. `MORPH_RECT`는 전부 1이고, `MORPH_ELLIPSE`는 모서리 쪽이 0으로 깎여 둥근 모양을 이루며, `MORPH_CROSS`는 중심 행과 중심 열만 1이고 나머지는 모두 0이다.

`getStructuringElement`는 세 번째 인자로 `anchor`(기준점)도 받을 수 있다. 기본값은 `(-1, -1)`로, 이는 커널의 정중앙을 기준점으로 삼으라는 의미다. 기준점을 커널 중심에서 벗어난 위치로 옮기면 침식/팽창이 특정 방향으로 더 강하게 일어나도록 만들 수 있지만, 실무에서는 대부분 기본값인 중앙 기준점을 그대로 사용한다.

구조 요소를 반드시 `getStructuringElement`로 만들어야 하는 것은 아니다. NumPy 배열로 직접 만들어도 똑같이 동작한다.

```python
import numpy as np

# getStructuringElement(MORPH_RECT, (5, 5))와 완전히 동일한 커널
manual_kernel = np.ones((5, 5), dtype=np.uint8)
```

다만 `getStructuringElement`를 쓰면 "이 커널이 사각형인지 타원형인지"라는 의도가 코드에 명확히 드러나고, 크기를 바꿀 때도 튜플 하나만 수정하면 되므로 가독성과 유지보수 측면에서 유리하다. 이 장의 예제에서는 특별한 이유가 없는 한 `getStructuringElement`를 사용한다.

가로와 세로 길이가 다른 비대칭 구조 요소도 자주 쓰인다. 예를 들어 스캔한 표(table) 이미지에서 가로로 뻗은 실선만 남기고 싶다면, 세로 길이는 1에 가깝고 가로 길이만 아주 긴 사각형 구조 요소로 침식을 적용하면 된다. 가로선은 폭이 좁고 옆으로 길게 이어져 있으므로 이런 커널로 침식해도 살아남지만, 표의 세로선이나 글자처럼 가로로 길게 이어지지 않은 구조는 이 커널을 통과하지 못하고 사라진다.

```python
import cv2

table_img = cv2.imread("table_scan.png", cv2.IMREAD_GRAYSCALE)
_, table_binary = cv2.threshold(table_img, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

# 가로 40픽셀, 세로 1픽셀: 가로로 긴 직선만 살아남는 구조 요소
horizontal_kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (40, 1))
horizontal_lines = cv2.erode(table_binary, horizontal_kernel, iterations=1)
horizontal_lines = cv2.dilate(horizontal_lines, horizontal_kernel, iterations=1)

# 세로 1픽셀, 가로 40픽셀 커널을 90도 돌린 형태: 세로로 긴 직선만 추출
vertical_kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (1, 40))
vertical_lines = cv2.erode(table_binary, vertical_kernel, iterations=1)
vertical_lines = cv2.dilate(vertical_lines, vertical_kernel, iterations=1)

cv2.imshow("Horizontal lines only", horizontal_lines)
cv2.imshow("Vertical lines only", vertical_lines)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

이렇게 침식 직후 같은 커널로 다시 팽창해 주면(사실상 열림을 커널을 바꿔서 두 번 적용한 것과 같다) 원래 선의 길이를 거의 그대로 복원하면서도 방향에 맞지 않는 구조물은 모두 제거된 결과를 얻는다. 이 기법은 표의 격자선을 검출해 셀 영역을 나누는 문서 분석 작업에서 실제로 흔히 쓰인다.

## 11.3 침식(erode): 객체를 깎아내기

침식은 구조 요소를 이미지 위에서 슬라이딩시키면서, 구조 요소가 덮는 영역의 모든 픽셀이 흰색(255)일 때만 중심 픽셀을 흰색으로 유지하는 연산이다. 구조 요소 영역 안에 검은 픽셀이 하나라도 있으면 중심 픽셀은 검은색으로 바뀐다. 결과적으로 객체의 경계가 구조 요소의 크기만큼 안쪽으로 깎여 들어가며, 객체는 전체적으로 작아진다.

침식의 대표적인 효과는 두 가지다. 첫째, 배경에 흩어진 작은 흰색 노이즈 점들이 구조 요소보다 작으면 완전히 사라진다. 둘째, 서로 붙어 있던 두 객체 사이의 좁은 다리(bridge)가 끊어지면서 두 객체가 분리된다.

```python
import cv2
import numpy as np

img = cv2.imread("binary.png", cv2.IMREAD_GRAYSCALE)

kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
eroded = cv2.erode(img, kernel, iterations=1)

cv2.imshow("Original", img)
cv2.imshow("Eroded", eroded)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`cv2.erode`의 시그니처는 `cv2.erode(src, kernel, dst=None, anchor=(-1, -1), iterations=1, borderType=cv2.BORDER_CONSTANT, borderValue=None)`이다. `iterations` 매개변수는 같은 침식을 몇 번 반복할지를 지정한다. 반복 횟수를 늘리는 것은 구조 요소를 더 크게 만드는 것과 비슷한 효과를 내지만, 완전히 같지는 않다. 반복 침식은 매 단계마다 이전 결과를 다시 깎기 때문에 모서리가 더 각지게 다듬어지는 경향이 있다.

경계 처리 방식(`borderType`)도 눈여겨볼 값이다. 기본값인 `cv2.BORDER_CONSTANT`는 이미지 바깥을 특정 값으로 채워진 것처럼 취급하는데, 침식 연산에서는 이 바깥 채움 값이 흰색(255)으로 자동 설정되어 있어서 이미지 가장자리에 있는 객체가 부당하게 깎여 나가는 것을 막아준다. 이 기본 동작을 신뢰하고 대부분의 경우 `borderType`은 건드리지 않는 것이 안전하다.

## 11.4 팽창(dilate): 객체를 부풀리기

팽창은 침식의 반대다. 구조 요소가 덮는 영역 안에 흰색 픽셀이 하나라도 있으면 중심 픽셀을 흰색으로 만든다. 결과적으로 객체의 경계가 구조 요소의 크기만큼 바깥쪽으로 부풀어 오르며, 객체는 전체적으로 커진다.

팽창의 대표적인 효과 역시 두 가지다. 첫째, 객체 내부에 있는 작은 검은 구멍(흰색 객체 안에 반점처럼 남은 검은 픽셀)이 구조 요소보다 작으면 메워진다. 둘째, 서로 가까이 있지만 떨어져 있던 두 객체가 팽창으로 커지면서 서로 이어질 수 있다.

```python
dilated = cv2.dilate(img, kernel, iterations=1)

cv2.imshow("Dilated", dilated)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`cv2.dilate`의 매개변수 구성은 `cv2.erode`와 완전히 대칭이다. `iterations`를 늘리면 객체가 더 크게 부풀고, 서로 떨어져 있던 객체들이 이어지는 지점이 늘어난다. 텍스트 인식(OCR) 전처리에서는 글자의 획이 얇아서 끊어져 보일 때 작은 커널로 한두 번 팽창을 적용해 획을 두껍게 이어주는 용도로 자주 쓰인다.

침식과 팽창은 서로 대칭적인 연산이지만, 침식 후 팽창(또는 팽창 후 침식)을 하더라도 원래 이미지로 완전히 돌아오지는 않는다는 점이 중요하다. 침식으로 사라진 작은 노이즈나 좁은 다리는 팽창으로도 복원되지 않는다. 이 "비가역성"이 바로 다음 절에서 다룰 열림과 닫힘이 노이즈 제거에 유용한 이유다.

## 11.5 열림과 닫힘: 침식과 팽창의 조합

침식과 팽창을 각각 한 번만 쓰면 부작용이 남는다. 침식만 하면 노이즈는 사라지지만 남아 있는 객체도 함께 작아진다. 팽창만 하면 구멍은 메워지지만 객체도 함께 커진다. 이 부작용을 상쇄하기 위해 두 연산을 순서대로 조합한 것이 열림(opening)과 닫힘(closing)이다.

**열림(opening)**은 침식을 먼저 하고 그 결과에 팽창을 적용한다. 침식 단계에서 구조 요소보다 작은 흰색 노이즈 점들이 완전히 지워지고, 이어지는 팽창 단계에서는 남아 있는 큰 객체가 침식으로 줄어든 만큼 다시 원래 크기 근처로 복원된다. 노이즈는 한번 지워지면 팽창으로도 다시 생겨나지 않으므로, 열림은 "객체 크기는 거의 유지하면서 작은 흰색 노이즈만 제거"하는 효과를 낸다.

**닫힘(closing)**은 순서가 반대다. 팽창을 먼저 하고 그 결과에 침식을 적용한다. 팽창 단계에서 객체 내부의 작은 검은 구멍이 메워지고, 이어지는 침식 단계에서는 객체의 바깥 경계가 팽창으로 부풀었던 만큼 다시 줄어든다. 구멍은 한번 메워지면 침식으로도 다시 생기지 않으므로, 닫힘은 "객체 크기는 거의 유지하면서 작은 검은 구멍만 메우기"하는 효과를 낸다.

이 두 연산을 직접 `cv2.erode`와 `cv2.dilate`를 두 번 호출해서 구현할 수도 있지만, OpenCV는 `cv2.morphologyEx` 함수에 연산 종류를 지정해서 한 번에 처리하는 방법을 제공한다.

```python
opened = cv2.morphologyEx(img, cv2.MORPH_OPEN, kernel)
closed = cv2.morphologyEx(img, cv2.MORPH_CLOSE, kernel)
```

`morphologyEx`는 `MORPH_OPEN`, `MORPH_CLOSE` 외에도 이 장의 나머지 절에서 다룰 `MORPH_GRADIENT`, `MORPH_TOPHAT`, `MORPH_BLACKHAT` 같은 연산들을 동일한 인터페이스(`cv2.morphologyEx(src, op, kernel)`)로 제공한다. 연산의 종류만 바꿔서 넘기면 되므로, 하나의 함수 이름만 기억해 두면 이 장에서 다루는 대부분의 모폴로지 연산을 처리할 수 있다.

## 11.6 모폴로지 그라디언트: 객체의 경계선만 남기기

`morphologyEx`에 `cv2.MORPH_GRADIENT`를 지정하면, 내부적으로 팽창 결과에서 침식 결과를 뺀 값을 계산한다.

```
gradient = dilate(img, kernel) - erode(img, kernel)
```

팽창은 객체를 바깥으로 부풀리고 침식은 객체를 안쪽으로 깎아내므로, 두 결과의 차이는 정확히 "객체의 바깥쪽 경계 띠"에서만 값이 남고 객체 내부와 배경은 모두 0으로 사라진다. 결과적으로 원본 객체의 윤곽선만 하얗게 남은 이미지를 얻는다.

```python
gradient = cv2.morphologyEx(img, cv2.MORPH_GRADIENT, kernel)

cv2.imshow("Morphological Gradient", gradient)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

이 결과는 12장에서 다룰 캐니(Canny) 엣지 검출과 비슷하게 "객체의 경계"를 뽑아낸다는 점에서 목적이 닮아 있지만, 원리는 전혀 다르다. 캐니는 그레이스케일 이미지의 밝기 변화율(그래디언트)을 계산해서 경계를 찾는 반면, 모폴로지 그라디언트는 이미 이진화된 이미지에서 침식과 팽창의 차이만으로 경계를 얻는다. 따라서 모폴로지 그라디언트는 입력이 이진 이미지일 때만 의미가 분명하며, 컨투어 검출 전에 객체의 두께를 대략적으로 파악하거나 경계 띠의 폭을 조절하고 싶을 때(커널을 크게 하면 경계 띠도 두꺼워진다) 유용하다.

## 11.7 탑햇과 블랙햇: 밝고 어두운 작은 구조물 강조하기

열림과 닫힘 자체는 노이즈를 제거하거나 구멍을 메우는 "정리" 목적으로 쓰이지만, 열림·닫힘의 결과와 원본 이미지의 차이를 취하면 정리되기 전에는 보이지 않던 정보, 즉 "지워진 부분"만 뽑아낼 수 있다. 이 아이디어를 활용한 것이 탑햇(top hat)과 블랙햇(black hat)이다.

**탑햇(`cv2.MORPH_TOPHAT`)**은 원본에서 열림 결과를 뺀 값이다.

```
tophat = img - opening(img, kernel)
```

열림은 구조 요소보다 작은 밝은 구조물을 지워버리는 연산이므로, 원본에서 열림 결과를 빼면 "열림으로 지워진 것", 즉 구조 요소보다 작은 밝은 돌출부만 남는다. 조명이 불균일한 배경 위에 작고 밝은 물체(예: 어두운 배경 위의 별, 얼룩진 종이 위의 밝은 반점)가 있을 때, 탑햇을 쓰면 배경의 완만한 밝기 변화는 사라지고 작은 밝은 구조물만 두드러지게 강조된다.

**블랙햇(`cv2.MORPH_BLACKHAT`)**은 방향이 반대다. 닫힘 결과에서 원본을 뺀 값이다.

```
blackhat = closing(img, kernel) - img
```

닫힘은 구조 요소보다 작은 어두운 구멍을 메워버리는 연산이므로, 닫힘 결과에서 원본을 빼면 "닫힘으로 메워진 것", 즉 구조 요소보다 작은 어두운 반점만 남는다. 밝은 배경 위에 작고 어두운 결함(인쇄 얼룩, 표면 스크래치 등)을 찾아내는 검사 용도에 잘 맞는다.

```python
import cv2

gray = cv2.imread("uneven_lighting.jpg", cv2.IMREAD_GRAYSCALE)

# 배경의 완만한 밝기 변화보다 큰 커널을 사용해야
# "작은 구조물"과 "배경"을 구분할 수 있다.
kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (15, 15))

tophat = cv2.morphologyEx(gray, cv2.MORPH_TOPHAT, kernel)
blackhat = cv2.morphologyEx(gray, cv2.MORPH_BLACKHAT, kernel)

cv2.imshow("Original", gray)
cv2.imshow("Top Hat (bright small objects)", tophat)
cv2.imshow("Black Hat (dark small objects)", blackhat)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

탑햇과 블랙햇은 반드시 이진 이미지에만 적용해야 하는 것은 아니다. 그레이스케일 이미지에도 자연스럽게 적용되며, 오히려 조명이 불균일한 그레이스케일 이미지에서 "배경 조명"과 "작은 전경 구조물"을 분리하는 용도로 더 널리 쓰인다. 예를 들어 문서 스캔 이미지에서 배경이 한쪽으로 그늘져 있을 때, 탑햇을 적용하면 그늘진 배경은 사라지고 글자(주변보다 어두운 경우는 블랙햇, 밝은 경우는 탑햇)만 균일한 밝기로 도드라진다. 이때 커널 크기는 강조하고 싶은 구조물보다는 크고, 배경이 변화하는 규모보다는 작게 잡는 것이 핵심이다. 커널이 너무 작으면 강조하려는 구조물 자체가 "배경"으로 취급되어 사라지고, 너무 크면 배경의 변화까지 그대로 남아 효과가 없어진다.

## 11.8 스켈레톤화: 반복적 침식으로 형태의 뼈대 얻기

지금까지 다룬 연산들은 모두 객체의 두께나 크기를 조절하는 데 초점이 있었다. 그런데 어떤 응용에서는 객체의 두께 정보는 버리고, 객체가 대략 어떤 "선"의 형태로 뻗어 있는지 그 골격만 알고 싶을 때가 있다. 예를 들어 손글씨의 획이 몇 번이나 꺾이는지 분석하거나, 도로나 혈관처럼 가늘고 긴 구조물의 중심선을 추출하는 경우가 그렇다. 이런 "객체의 뼈대(skeleton)"를 얻는 과정을 스켈레톤화(skeletonization) 또는 씨닝(thinning)이라고 부른다.

스켈레톤화의 직관적인 원리는 침식을 반복하는 것과 관련이 있다. 객체에 침식을 한 번 적용하면 경계가 한 겹 깎여 나가고, 그 상태에서 다시 침식을 적용하면 또 한 겹이 깎여 나간다. 이렇게 침식을 계속 반복하면 객체는 점점 얇아지다가 결국 완전히 사라진다. 이 과정에서 "이번 침식 단계에서 막 사라진 픽셀들"을 계속 모아 나가면, 객체의 중심을 지나는 얇은 선 형태의 골격이 드러난다는 것이 뼈대 변환(medial axis transform)의 기본 아이디어다. 즉 스켈레톤은 "객체 내부에서 경계까지의 거리가 사방으로 동시에 가장 멀리 유지되는 지점들을 이어놓은 선"으로 이해할 수 있다.

이 아이디어를 아주 단순하게 흉내 내면 다음과 같은 형태가 된다. 다만 아래 코드는 원리를 보여주기 위한 개념적인 스케치일 뿐, 실제로 끊어짐 없는 매끄러운 골격을 안정적으로 만들어내는 알고리즘(예: Zhang-Suen 씨닝)에는 침식만으로는 해결되지 않는 세밀한 연결성 규칙이 추가로 필요하다.

```python
import cv2
import numpy as np

def naive_skeleton_sketch(binary_img, kernel):
    """반복 침식의 아이디어를 보여주기 위한 단순화된 예시.
    실제 골격 추출에는 cv2.ximgproc.thinning() 같은
    전용 알고리즘을 쓰는 것이 정확하고 안전하다."""
    img = binary_img.copy()
    skeleton = np.zeros_like(img)

    while cv2.countNonZero(img) > 0:
        eroded = cv2.erode(img, kernel)
        opened = cv2.dilate(eroded, kernel)
        # 침식 후 다시 팽창해도 복원되지 않는 부분 = 이번 단계에서 사라질 골격 후보
        temp = cv2.subtract(img, opened)
        skeleton = cv2.bitwise_or(skeleton, temp)
        img = eroded

    return skeleton
```

실무에서 정확하고 끊어짐 없는 골격이 필요하다면, `opencv-contrib-python` 패키지를 설치했을 때 함께 제공되는 `cv2.ximgproc.thinning()` 함수를 쓰는 것이 훨씬 안전하다. 이 함수는 위에서 스케치한 단순 반복 침식보다 훨씬 정교한 규칙으로 골격의 연결성을 보장한다. 이 장에서는 스켈레톤화가 "반복적인 침식으로 객체의 뼈대를 얻는다"는 개념을 이해하는 데 초점을 두고, 정밀한 구현은 필요한 시점에 전용 함수를 찾아 쓰는 것을 권장한다.

반복 침식이 객체를 어떻게 "한 겹씩 벗겨내는지"는 중간 단계를 직접 눈으로 확인해 보면 감을 잡기 쉽다. 아래 코드는 매 반복마다 침식된 이미지를 따로 저장해서, 객체가 몇 단계를 거쳐 사라지는지, 그리고 각 단계에서 객체의 실루엣이 어떻게 줄어드는지를 나란히 보여준다.

```python
import cv2
import numpy as np

img = cv2.imread("thick_shape.png", cv2.IMREAD_GRAYSCALE)
_, binary = cv2.threshold(img, 127, 255, cv2.THRESH_BINARY)

kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))
stages = [binary]

current = binary.copy()
while cv2.countNonZero(current) > 0:
    current = cv2.erode(current, kernel, iterations=1)
    stages.append(current)

print(f"완전히 사라지기까지 걸린 침식 횟수: {len(stages) - 1}")

# 처음 6단계만 나란히 붙여서 관찰
preview = np.hstack(stages[:6])
cv2.imshow("Erosion stages (peeling toward the skeleton)", preview)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

이 실험을 굵고 둥근 도형과 가늘고 긴 도형에 각각 적용해 보면, 굵은 도형은 사라지기까지 훨씬 많은 반복이 필요하고 마지막까지 남는 픽셀들이 도형의 중심을 지나는 위치에 몰려 있는 반면, 가느다란 도형은 몇 번의 침식만으로 완전히 사라져 버린다는 차이를 관찰할 수 있다. 이것이 바로 "두께 정보는 반복 횟수에 흡수되고, 위치 정보(중심선)만 남는다"는 스켈레톤화의 핵심 아이디어다.

## 11.9 실전 비교: 구조 요소 모양이 결과에 미치는 차이

이론적으로 `MORPH_RECT`, `MORPH_ELLIPSE`, `MORPH_CROSS`가 서로 다른 결과를 낸다는 것은 알았지만, 실제로 눈으로 비교해 보면 그 차이가 더 분명하게 느껴진다. 둥근 점들과 대각선으로 뻗은 얇은 선이 함께 있는 이진 이미지를 예로 들어, 같은 크기의 세 구조 요소로 침식을 적용해 보자.

```python
import cv2
import numpy as np

img = cv2.imread("dots_and_lines.png", cv2.IMREAD_GRAYSCALE)
_, binary = cv2.threshold(img, 127, 255, cv2.THRESH_BINARY)

shapes = {
    "RECT": cv2.MORPH_RECT,
    "ELLIPSE": cv2.MORPH_ELLIPSE,
    "CROSS": cv2.MORPH_CROSS,
}

results = []
for name, shape in shapes.items():
    kernel = cv2.getStructuringElement(shape, (7, 7))
    eroded = cv2.erode(binary, kernel, iterations=1)
    label = eroded.copy()
    cv2.putText(label, name, (10, 30), cv2.FONT_HERSHEY_SIMPLEX,
                1.0, 128, 2, cv2.LINE_AA)
    results.append(label)
    print(f"{name}: 남은 흰색 픽셀 수 = {cv2.countNonZero(eroded)}")

comparison = np.hstack(results)
cv2.imshow("RECT vs ELLIPSE vs CROSS (erode)", comparison)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

이 실험을 실제로 돌려 보면 다음과 같은 경향을 관찰할 수 있다.

- `MORPH_RECT`는 둥근 점의 모서리를 사각형에 가깝게 깎아내면서 가장 강하게 축소시킨다. 대각선 방향의 얇은 선도 사각형 커널의 모서리 부분이 걸리기 때문에 비교적 쉽게 끊어진다.
- `MORPH_ELLIPSE`는 둥근 점의 원래 형태(둥근 윤곽)를 가장 잘 보존한다. 세포나 동전처럼 원형 객체를 다루는 작업에서 결과가 부자연스럽게 각지지 않아 선호된다.
- `MORPH_CROSS`는 상하좌우로만 좁게 작용하기 때문에 세 커널 중 가장 약하게 깎아내는 경향이 있고, 대각선으로 뻗은 선의 연결성을 가장 잘 유지한다. 다만 대각선 방향의 노이즈에는 상대적으로 둔감해서, 대각선 잡음이 많은 이미지에서는 노이즈 제거 효과가 떨어질 수 있다.

`countNonZero`로 남은 흰색 픽셀 수를 함께 출력해 보면, 같은 크기의 커널이라도 `MORPH_RECT`가 가장 많은 픽셀을 지우고 `MORPH_CROSS`가 가장 적게 지우는 경향을 수치로도 확인할 수 있다. 실무에서 구조 요소를 고를 때는 "지우고 싶은 노이즈의 모양"과 "보존하고 싶은 객체의 모양"을 함께 고려해서, 둥근 객체에는 타원형을, 격자나 배선처럼 축에 정렬된 구조에는 십자형이나 사각형을 선택하는 식으로 접근하면 된다.

## 11.10 실전 가이드: 구조 요소 크기와 반복 횟수 선택하기

지금까지 개별 연산을 하나씩 살펴봤다면, 이 절에서는 실무에서 실제로 부딪히는 질문, 즉 "구조 요소 크기는 몇으로 잡아야 하는가"와 "같은 커널로 여러 번 반복하는 것과 커널을 크게 잡고 한 번만 적용하는 것 중 무엇이 나은가"를 정리한다.

**구조 요소 크기는 지우려는 대상의 크기에서 출발한다.** 배경에 남은 소금-후추 노이즈의 지름이 대략 2~3픽셀이라면, 구조 요소는 그보다 살짝 큰 3×3이나 5×5 정도로 시작하는 것이 안전하다. 구조 요소가 노이즈보다 크면 노이즈는 확실히 지워지지만, 보존해야 할 객체의 얇은 부분(글자의 획, 가느다란 선 등)까지 함께 지워질 위험이 커진다. 그래서 처음에는 작은 커널로 시작해서, 노이즈가 남아 있으면 한 단계씩 키워가는 점진적 접근이 안전하다.

```python
import cv2

img = cv2.imread("binary.png", cv2.IMREAD_GRAYSCALE)

for size in (3, 5, 7, 9):
    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (size, size))
    opened = cv2.morphologyEx(img, cv2.MORPH_OPEN, kernel)
    remaining_noise = cv2.countNonZero(opened) - cv2.countNonZero(
        cv2.morphologyEx(opened, cv2.MORPH_OPEN, kernel)
    )
    print(f"kernel {size}x{size}: 남은 흰색 픽셀 수 = {cv2.countNonZero(opened)}")
```

**커널을 키우는 것과 반복 횟수를 늘리는 것은 비슷하지만 똑같지 않다.** 3×3 커널로 침식을 두 번 반복한 결과와 5×5 커널로 한 번 침식한 결과는 얼추 비슷해 보이지만, 정확히 같지는 않다. 반복 침식은 매 단계가 이전 단계의 결과 위에서 다시 수행되므로 객체의 모서리가 더 각지게 다듬어지는 경향이 있고, 특히 `MORPH_CROSS`처럼 대각선을 보지 못하는 커널을 반복하면 사각형 모서리가 계단처럼 깎이는 부작용이 누적된다. 반면 큰 커널을 한 번만 적용하면 원래 구조 요소의 모양(원형이면 둥글게)이 비교적 그대로 유지된 채 크게 작용한다. 정밀하게 형태를 보존해야 하는 작업이라면 큰 커널 한 번을, 단순히 강하게 정리하는 것이 목적이라면 작은 커널 반복도 무방하다.

**연산의 순서도 결과에 영향을 준다.** 열림과 닫힘을 섞어서 여러 번 적용할 때, "열림 → 닫힘"과 "닫힘 → 열림"은 서로 다른 결과를 낸다. 배경 노이즈가 객체 내부 구멍보다 심하다면 열림을 먼저, 구멍이 노이즈보다 심하다면 닫힘을 먼저 적용해서 더 심각한 문제부터 해결하는 순서를 잡는 것이 일반적인 경험 규칙이다.

## 11.11 실전 예제: 이진화 결과에서 노이즈 제거하기

10장에서 만든 이진 이미지를 그대로 가져와 열림 연산으로 정리해 보자. 배경에 흩어진 소금-후추(salt-and-pepper) 잡음이 threshold를 거치면서 작은 흰 점들로 남아 있다고 가정한다. 원본 그레이스케일 이미지에 `THRESH_BINARY + THRESH_OTSU`로 이진화를 수행한 뒤, 타원형 구조 요소로 열림을 적용해서 노이즈를 제거한다.

```python
import cv2

gray = cv2.imread("document.jpg", cv2.IMREAD_GRAYSCALE)

# 10장: Otsu 방법으로 자동 이진화
_, binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

# 11장: 열림으로 작은 흰색 노이즈 제거
kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))
cleaned = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel, iterations=1)

cv2.imshow("Binary (with noise)", binary)
cv2.imshow("Cleaned (opening)", cleaned)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

만약 노이즈가 배경의 작은 흰 점이 아니라 객체 내부의 작은 검은 구멍이라면, 같은 커널로 `MORPH_OPEN` 대신 `MORPH_CLOSE`를 적용하면 된다. 실무에서는 두 가지를 순서대로 적용하는 경우도 흔하다. 먼저 닫힘으로 구멍을 메우고, 이어서 열림으로 남은 노이즈 점을 제거하는 식이다.

```python
# 구멍 메우기(닫힘) → 노이즈 제거(열림)를 순서대로 적용
denoised = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel, iterations=1)
denoised = cv2.morphologyEx(denoised, cv2.MORPH_OPEN, kernel, iterations=1)
```

이 파이프라인은 이후 컨투어 검출 전처리 단계로 그대로 재사용할 수 있는 형태다. 다만 이 경우 구조 요소 크기를 너무 크게 잡으면 글자나 얇은 선처럼 원래 있어야 할 세부 구조까지 지워질 수 있으므로, 3×3이나 5×5 같은 작은 커널부터 시작해서 필요한 만큼만 키워 가는 것이 안전하다. 또한 이 장에서 배운 탑햇/블랙햇을 이 파이프라인 앞에 추가하면, 이진화 이전 단계에서부터 불균일한 조명을 보정해 이진화 자체의 품질을 높일 수도 있다. 즉 "탑햇/블랙햇으로 조명 보정 → threshold로 이진화 → 열림/닫힘으로 잔여 노이즈 정리"는 문서나 산업 검사 이미지를 다룰 때 자주 쓰이는 전체 흐름이다.

전체 파이프라인을 하나의 함수로 묶어두면 여러 이미지에 반복해서 적용하기 편하다.

```python
import cv2

def clean_binary_document(gray_img, kernel_size=3, shape=cv2.MORPH_ELLIPSE,
                           fix_illumination=False, illum_kernel_size=15):
    """조명 보정(선택) → Otsu 이진화 → 닫힘 → 열림 순서로
    문서 이미지를 정리하는 표준 파이프라인."""
    prepared = gray_img

    if fix_illumination:
        illum_kernel = cv2.getStructuringElement(
            cv2.MORPH_ELLIPSE, (illum_kernel_size, illum_kernel_size)
        )
        # 배경이 글자보다 밝다고 가정: 블랙햇으로 어두운 글자만 강조
        prepared = cv2.morphologyEx(gray_img, cv2.MORPH_BLACKHAT, illum_kernel)

    _, binary = cv2.threshold(prepared, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

    kernel = cv2.getStructuringElement(shape, (kernel_size, kernel_size))
    closed = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel, iterations=1)
    opened = cv2.morphologyEx(closed, cv2.MORPH_OPEN, kernel, iterations=1)

    return opened


gray = cv2.imread("document.jpg", cv2.IMREAD_GRAYSCALE)
result = clean_binary_document(gray, fix_illumination=True)

cv2.imshow("Cleaned document", result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

이런 형태로 함수화해 두면 `fix_illumination`이나 `kernel_size` 같은 매개변수만 바꿔서 다양한 촬영 조건의 문서에 같은 파이프라인을 재사용할 수 있고, 나중에 13장에서 컨투어를 검출할 때도 이 함수의 반환값을 그대로 입력으로 넘기면 된다.

## 요약

- 모폴로지 연산은 이진 이미지(흰색 객체 vs. 검은색 배경)를 대상으로 객체의 모양을 다듬는 연산이며, 구조 요소(kernel)는 `cv2.getStructuringElement`로 만든다.
- 사각형(`MORPH_RECT`), 타원형(`MORPH_ELLIPSE`), 십자형(`MORPH_CROSS`) 구조 요소는 같은 크기라도 결과가 다르다. 타원형은 둥근 객체의 형태를 가장 잘 보존하고, 십자형은 대각선 연결을 가장 잘 유지하며, 사각형이 가장 강하게 깎거나 부풀린다.
- 침식(`cv2.erode`)은 구조 요소 영역이 모두 흰색일 때만 중심을 흰색으로 유지해 객체를 깎아내며, 작은 노이즈 제거와 붙은 객체 분리에 쓰인다. 팽창(`cv2.dilate`)은 그 반대로 객체를 부풀려 작은 구멍을 메우고 떨어진 객체를 연결한다.
- 열림(opening, 침식 후 팽창)은 객체 크기를 거의 유지하면서 작은 흰색 노이즈를 제거하고, 닫힘(closing, 팽창 후 침식)은 작은 검은 구멍을 메운다. 모두 `cv2.morphologyEx`로 연산 종류를 지정해 한 번에 수행할 수 있다.
- 모폴로지 그라디언트(`MORPH_GRADIENT`)는 팽창 결과에서 침식 결과를 빼서 객체의 경계 띠만 남기고, 탑햇(`MORPH_TOPHAT`)은 원본에서 열림 결과를 빼서 작은 밝은 구조물을, 블랙햇(`MORPH_BLACKHAT`)은 닫힘 결과에서 원본을 빼서 작은 어두운 구조물을 강조한다.
- 스켈레톤화(skeletonization)는 반복적인 침식으로 객체를 점점 얇게 만들며 그 과정에서 사라지는 픽셀들을 모아 객체의 뼈대를 얻는다는 개념이며, 실무에서 정밀한 골격이 필요하다면 `cv2.ximgproc.thinning()` 같은 전용 알고리즘을 사용하는 것이 안전하다.

## 연습문제

1. 침식과 팽창을 한 번씩 순서대로 적용했을 때(침식 후 팽창, 즉 열림)와 반대 순서로 적용했을 때(팽창 후 침식, 즉 닫힘)의 결과가 왜 서로 다른지, 각 연산이 노이즈와 구멍에 미치는 영향을 기준으로 설명하라.
2. `MORPH_RECT`, `MORPH_ELLIPSE`, `MORPH_CROSS` 세 가지 구조 요소로 같은 이진 이미지에 동일한 크기의 침식을 적용하고, `cv2.countNonZero`로 남은 흰색 픽셀 수를 비교하라. 어떤 모양이 둥근 객체의 형태를 더 잘 보존하고, 어떤 모양이 대각선 구조를 더 잘 유지하는가?
3. 배경에 흰색 노이즈 점과 객체 내부의 검은 구멍이 동시에 있는 이진 이미지가 있다고 하자. 이를 정리하기 위해 열림과 닫힘을 어떤 순서로 적용해야 하는지, 그리고 그 이유를 설명하라.
4. 조명이 불균일한 그레이스케일 이미지에 탑햇과 블랙햇을 각각 적용해 보고, 커널 크기를 배경 조명 변화보다 작게 잡았을 때와 크게 잡았을 때 결과가 어떻게 달라지는지 관찰하라.
5. `morphologyEx`의 `MORPH_GRADIENT` 옵션을 이진 이미지에 적용해 객체의 경계 띠를 얻고, 12장에서 다룰 캐니 엣지 검출 결과와 비교했을 때 두 방법이 "경계를 찾는" 원리에서 어떻게 다른지 설명하라.
