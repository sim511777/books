## 11.1 모폴로지 연산은 왜 이진 이미지에서 시작하는가

10장에서는 `threshold`와 `adaptiveThreshold`를 이용해 그레이스케일 이미지를 흑과 백 두 값만 남은 이진 이미지로 바꾸는 방법을 다뤘다. 그런데 실제로 이진화를 해보면 결과가 깨끗한 경우가 드물다. 배경에 조명이 살짝 얼룩진 부분이 있으면 그 자리에 작은 흰 점(노이즈)이 튀어나오고, 글자나 객체 내부에 조명 반사나 얼룩이 있으면 그 부분만 값이 반전되어 작은 검은 구멍이 남는다. 이런 잡티는 눈으로 보면 사소해 보이지만, 이후 13장에서 다룰 컨투어 검출이나 객체 개수 세기 같은 작업에서는 각각 하나의 "가짜 객체"나 "끊어진 경계"로 인식되어 결과를 심각하게 왜곡시킨다.

모폴로지(morphology) 연산은 바로 이 문제, 즉 이진 이미지에 남은 작은 노이즈와 구멍을 정리하기 위해 만들어진 도구다. 이름 그대로 "형태학적" 연산으로, 픽셀의 밝기 값 자체를 계산하는 것이 아니라 객체의 모양(shape)을 구조 요소(structuring element)라는 작은 틀에 맞춰 깎아내거나 부풀리는 방식으로 동작한다. 그래서 모폴로지 연산은 원칙적으로 이진 이미지(객체 = 흰색 255, 배경 = 검은색 0)를 대상으로 하며, 그레이스케일 이미지에 적용할 수도 있지만 이 장에서는 10장에서 만든 이진 이미지를 다듬는 용도로 다룬다.

핵심 아이디어는 간단하다. 작은 창(kernel)을 이미지 위에서 한 픽셀씩 이동시키면서, 그 창이 걸쳐 있는 영역의 값들을 보고 중심 픽셀의 값을 새로 정한다. 창 안의 모든 픽셀이 흰색이어야 중심을 흰색으로 유지하면 침식이 되고, 창 안에 흰색이 하나라도 있으면 중심을 흰색으로 만들면 팽창이 된다. 이 두 가지 기본 연산을 조합하면 노이즈 제거, 구멍 메우기, 객체 분리, 경계 강조 등 다양한 후처리를 할 수 있다.

## 11.2 구조 요소: 연산의 모양을 결정하는 틀

모폴로지 연산에서 구조 요소(structuring element, 흔히 kernel이라고도 부른다)는 "이웃을 어떤 모양으로 볼 것인가"를 정의하는 작은 행렬이다. 3×3 정사각형을 쓰면 상하좌우와 대각선을 포함한 8방향 이웃을 보는 것이고, 십자형을 쓰면 상하좌우 4방향만 본다. 구조 요소의 모양과 크기에 따라 연산의 결과가 달라지므로, 상황에 맞는 구조 요소를 선택하는 것이 모폴로지 연산의 실질적인 튜닝 포인트다.

OpenCV는 `getStructuringElement` 함수로 자주 쓰이는 세 가지 형태의 구조 요소를 바로 만들어준다.

- `MORPH_RECT`: 사각형. 모든 픽셀이 1인 정사각형(또는 직사각형) 커널이다. 가장 강하게 깎거나 부풀리며, 객체의 모서리가 사각형에 가깝게 다듬어진다.
- `MORPH_ELLIPSE`: 타원형. 커널 내부에 타원을 그린 모양으로, 사각형보다 부드럽고 둥근 결과를 낸다. 둥근 객체(세포, 동전, 얼굴 등)를 다룰 때 자연스럽다.
- `MORPH_CROSS`: 십자형. 중심을 지나는 가로선과 세로선만 1인 모양으로, 대각선 방향의 연결을 무시하고 상하좌우 방향으로만 얇게 침식/팽창한다.

구조 요소는 직접 NumPy 배열이나 `Mat`으로 만들어도 되지만, `getStructuringElement`를 쓰면 의도가 코드에 명확히 드러나고 오타로 인한 실수도 줄어든다.

## 11.3 침식(erode): 객체를 깎아내기

침식은 구조 요소를 이미지 위에서 슬라이딩시키면서, 구조 요소가 덮는 영역의 모든 픽셀이 흰색(255)일 때만 중심 픽셀을 흰색으로 유지하는 연산이다. 구조 요소 영역 안에 검은 픽셀이 하나라도 있으면 중심 픽셀은 검은색으로 바뀐다. 결과적으로 객체의 경계가 구조 요소의 크기만큼 안쪽으로 깎여 들어가며, 객체는 전체적으로 작아진다.

침식의 대표적인 효과는 두 가지다. 첫째, 배경에 흩어진 작은 흰색 노이즈 점들이 구조 요소보다 작으면 완전히 사라진다. 둘째, 서로 붙어 있던 두 객체 사이의 좁은 다리(bridge)가 끊어지면서 두 객체가 분리된다.

### Python

```python
import cv2
import numpy as np

img = cv2.imread("binary.png", cv2.IMREAD_GRAYSCALE)

kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
eroded = cv2.erode(img, kernel, iterations=1)

cv2.imshow("Original", img)
cv2.imshow("Eroded", eroded)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat img = cv::imread("binary.png", cv::IMREAD_GRAYSCALE);

    cv::Mat kernel = cv::getStructuringElement(cv::MORPH_RECT, cv::Size(3, 3));
    cv::Mat eroded;
    cv::erode(img, eroded, kernel, cv::Point(-1, -1), 1);

    cv::imshow("Original", img);
    cv::imshow("Eroded", eroded);
    cv::waitKey(0);
    return 0;
}
```

### C#

```csharp
using OpenCvSharp;

using Mat img = Cv2.ImRead("binary.png", ImreadModes.Grayscale);

using Mat kernel = Cv2.GetStructuringElement(MorphShapes.Rect, new Size(3, 3));
using var eroded = new Mat();
Cv2.Erode(img, eroded, kernel, iterations: 1);

Cv2.ImShow("Original", img);
Cv2.ImShow("Eroded", eroded);
Cv2.WaitKey(0);
```

`iterations` 매개변수는 같은 침식을 몇 번 반복할지를 지정한다. 반복 횟수를 늘리는 것은 구조 요소를 더 크게 만드는 것과 비슷한 효과를 내지만, 완전히 같지는 않다. 반복 침식은 매 단계마다 이전 결과를 다시 깎기 때문에 모서리가 더 각지게 다듬어지는 경향이 있다.

## 11.4 팽창(dilate): 객체를 부풀리기

팽창은 침식의 반대다. 구조 요소가 덮는 영역 안에 흰색 픽셀이 하나라도 있으면 중심 픽셀을 흰색으로 만든다. 결과적으로 객체의 경계가 구조 요소의 크기만큼 바깥쪽으로 부풀어 오르며, 객체는 전체적으로 커진다.

팽창의 대표적인 효과 역시 두 가지다. 첫째, 객체 내부에 있는 작은 검은 구멍(흰색 객체 안에 반점처럼 남은 검은 픽셀)이 구조 요소보다 작으면 메워진다. 둘째, 서로 가까이 있지만 떨어져 있던 두 객체가 팽창으로 커지면서 서로 이어질 수 있다.

### Python

```python
dilated = cv2.dilate(img, kernel, iterations=1)

cv2.imshow("Dilated", dilated)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### C++

```cpp
cv::Mat dilated;
cv::dilate(img, dilated, kernel, cv::Point(-1, -1), 1);

cv::imshow("Dilated", dilated);
cv::waitKey(0);
```

### C#

```csharp
using var dilated = new Mat();
Cv2.Dilate(img, dilated, kernel, iterations: 1);

Cv2.ImShow("Dilated", dilated);
Cv2.WaitKey(0);
```

침식과 팽창은 서로 대칭적인 연산이지만, 침식 후 팽창(또는 팽창 후 침식)을 하더라도 원래 이미지로 완전히 돌아오지는 않는다는 점이 중요하다. 침식으로 사라진 작은 노이즈나 좁은 다리는 팽창으로도 복원되지 않는다. 이 "비가역성"이 바로 다음 절에서 다룰 열림과 닫힘이 노이즈 제거에 유용한 이유다.

## 11.5 열림과 닫힘: 침식과 팽창의 조합

침식과 팽창을 각각 한 번만 쓰면 부작용이 남는다. 침식만 하면 노이즈는 사라지지만 남아 있는 객체도 함께 작아진다. 팽창만 하면 구멍은 메워지지만 객체도 함께 커진다. 이 부작용을 상쇄하기 위해 두 연산을 순서대로 조합한 것이 열림(opening)과 닫힘(closing)이다.

**열림(opening)**은 침식을 먼저 하고 그 결과에 팽창을 적용한다. 침식 단계에서 구조 요소보다 작은 흰색 노이즈 점들이 완전히 지워지고, 이어지는 팽창 단계에서는 남아 있는 큰 객체가 침식으로 줄어든 만큼 다시 원래 크기 근처로 복원된다. 노이즈는 한번 지워지면 팽창으로도 다시 생겨나지 않으므로, 열림은 "객체 크기는 거의 유지하면서 작은 흰색 노이즈만 제거"하는 효과를 낸다.

**닫힘(closing)**은 순서가 반대다. 팽창을 먼저 하고 그 결과에 침식을 적용한다. 팽창 단계에서 객체 내부의 작은 검은 구멍이 메워지고, 이어지는 침식 단계에서는 객체의 바깥 경계가 팽창으로 부풀었던 만큼 다시 줄어든다. 구멍은 한번 메워지면 침식으로도 다시 생기지 않으므로, 닫힘은 "객체 크기는 거의 유지하면서 작은 검은 구멍만 메우기"하는 효과를 낸다.

이 두 연산을 직접 `erode`와 `dilate`를 두 번 호출해서 구현할 수도 있지만, OpenCV는 `morphologyEx` 함수에 연산 종류를 지정해서 한 번에 처리하는 방법을 제공한다.

### Python

```python
opened = cv2.morphologyEx(img, cv2.MORPH_OPEN, kernel)
closed = cv2.morphologyEx(img, cv2.MORPH_CLOSE, kernel)
```

### C++

```cpp
cv::Mat opened, closed;
cv::morphologyEx(img, opened, cv::MORPH_OPEN, kernel);
cv::morphologyEx(img, closed, cv::MORPH_CLOSE, kernel);
```

### C#

```csharp
using var opened = new Mat();
using var closed = new Mat();
Cv2.MorphologyEx(img, opened, MorphTypes.Open, kernel);
Cv2.MorphologyEx(img, closed, MorphTypes.Close, kernel);
```

`morphologyEx`는 `MORPH_OPEN`, `MORPH_CLOSE` 외에도 `MORPH_GRADIENT`(팽창 결과에서 침식 결과를 빼서 경계선만 남기는 모폴로지 그래디언트), `MORPH_TOPHAT`, `MORPH_BLACKHAT` 같은 연산도 같은 인터페이스로 제공한다. 이 장에서는 열림과 닫힘에 집중하지만, 필요할 때 이런 변형들이 있다는 점은 기억해 두면 좋다.

## 11.6 실전 예제: 이진화 결과에서 노이즈 제거하기

10장에서 만든 이진 이미지를 그대로 가져와 열림 연산으로 정리해 보자. 배경에 흩어진 소금-후추(salt-and-pepper) 잡음이 threshold를 거치면서 작은 흰 점들로 남아 있다고 가정한다. 원본 그레이스케일 이미지에 `THRESH_BINARY + THRESH_OTSU`로 이진화를 수행한 뒤, 타원형 구조 요소로 열림을 적용해서 노이즈를 제거한다.

### Python

```python
import cv2

gray = cv2.imread("document.jpg", cv2.IMREAD_GRAYSCALE)

# 10장: Otsu 방법으로 자동 이진화
_, binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

# 11장: 열림으로 작은 흰색 노이즈 제거
kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))
cleaned = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel, iterations=1)

cv2.imshow("Binary (with noise)", binary)
cv2.imshow("Cleaned (opening)", cleaned)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### C++

```cpp
#include <opencv2/opencv.hpp>

int main() {
    cv::Mat gray = cv::imread("document.jpg", cv::IMREAD_GRAYSCALE);

    // 10장: Otsu 방법으로 자동 이진화
    cv::Mat binary;
    cv::threshold(gray, binary, 0, 255, cv::THRESH_BINARY + cv::THRESH_OTSU);

    // 11장: 열림으로 작은 흰색 노이즈 제거
    cv::Mat kernel = cv::getStructuringElement(cv::MORPH_ELLIPSE, cv::Size(3, 3));
    cv::Mat cleaned;
    cv::morphologyEx(binary, cleaned, cv::MORPH_OPEN, kernel, cv::Point(-1, -1), 1);

    cv::imshow("Binary (with noise)", binary);
    cv::imshow("Cleaned (opening)", cleaned);
    cv::waitKey(0);
    return 0;
}
```

### C#

```csharp
using OpenCvSharp;

using Mat gray = Cv2.ImRead("document.jpg", ImreadModes.Grayscale);

// 10장: Otsu 방법으로 자동 이진화
using var binary = new Mat();
Cv2.Threshold(gray, binary, 0, 255, ThresholdTypes.Binary | ThresholdTypes.Otsu);

// 11장: 열림으로 작은 흰색 노이즈 제거
using Mat kernel = Cv2.GetStructuringElement(MorphShapes.Ellipse, new Size(3, 3));
using var cleaned = new Mat();
Cv2.MorphologyEx(binary, cleaned, MorphTypes.Open, kernel, iterations: 1);

Cv2.ImShow("Binary (with noise)", binary);
Cv2.ImShow("Cleaned (opening)", cleaned);
Cv2.WaitKey(0);
```

만약 노이즈가 배경의 작은 흰 점이 아니라 객체 내부의 작은 검은 구멍이라면, 같은 커널로 `MORPH_OPEN` 대신 `MORPH_CLOSE`를 적용하면 된다. 실무에서는 두 가지를 순서대로 적용하는 경우도 흔하다. 먼저 닫힘으로 구멍을 메우고, 이어서 열림으로 남은 노이즈 점을 제거하는 식이다. 다만 이 경우 구조 요소 크기를 너무 크게 잡으면 글자나 얇은 선처럼 원래 있어야 할 세부 구조까지 지워질 수 있으므로, 3×3이나 5×5 같은 작은 커널부터 시작해서 필요한 만큼만 키워 가는 것이 안전하다.

## 요약

- 모폴로지 연산은 이진 이미지(흰색 객체 vs. 검은색 배경)를 대상으로 객체의 모양을 다듬는 연산이다.
- 구조 요소(kernel)는 `getStructuringElement`로 만들며, 사각형(`MORPH_RECT`), 타원형(`MORPH_ELLIPSE`), 십자형(`MORPH_CROSS`) 모양을 지정할 수 있다.
- 침식(`erode`)은 구조 요소 영역이 모두 흰색일 때만 중심을 흰색으로 유지해 객체를 깎아내며, 작은 노이즈 제거와 붙은 객체 분리에 쓰인다.
- 팽창(`dilate`)은 구조 요소 영역에 흰색이 하나라도 있으면 중심을 흰색으로 만들어 객체를 부풀리며, 작은 구멍 메우기와 떨어진 객체 연결에 쓰인다.
- 열림(opening, 침식 후 팽창)은 객체 크기를 거의 유지하면서 작은 흰색 노이즈를 제거하고, 닫힘(closing, 팽창 후 침식)은 작은 검은 구멍을 메운다. 둘 다 `morphologyEx`로 한 번에 수행할 수 있다.
- 이진화 결과를 그대로 다음 단계(컨투어 검출 등)에 넘기기보다, 열림/닫힘으로 정리한 뒤 넘기면 훨씬 안정적인 결과를 얻을 수 있다.

## 연습문제

1. 침식과 팽창을 한 번씩 순서대로 적용했을 때(침식 후 팽창, 즉 열림)와 반대 순서로 적용했을 때(팽창 후 침식, 즉 닫힘)의 결과가 왜 서로 다른지, 각 연산이 노이즈와 구멍에 미치는 영향을 기준으로 설명하라.
2. `MORPH_RECT`, `MORPH_ELLIPSE`, `MORPH_CROSS` 세 가지 구조 요소로 같은 이진 이미지에 동일한 크기의 침식을 적용하고 결과를 비교하라. 어떤 모양이 둥근 객체의 형태를 더 잘 보존하는가?
3. 배경에 흰색 노이즈 점과 객체 내부의 검은 구멍이 동시에 있는 이진 이미지가 있다고 하자. 이를 정리하기 위해 열림과 닫힘을 어떤 순서로 적용해야 하는지, 그리고 그 이유를 설명하라.
4. `erode`와 `dilate`의 `iterations` 매개변수를 2와 3으로 각각 바꿔서 실행하고, 구조 요소 크기를 키우는 것과 반복 횟수를 늘리는 것이 결과에 어떤 차이를 만드는지 관찰하라.
5. `morphologyEx`의 `MORPH_GRADIENT` 옵션(팽창 결과에서 침식 결과를 뺀 값)을 이진 이미지에 적용해 보고, 그 결과가 객체의 어떤 부분을 강조하는지 확인하라.
