## 13.1 컨투어란 무엇인가

**컨투어(contour)**란 같은 색이나 밝기를 가진 영역의 경계를 따라 연결한 곡선입니다. 쉽게 말해, 이진 이미지에서 흰색(또는 0이 아닌) 픽셀들이 모여 있는 영역의 윤곽선을 점들의 연속으로 표현한 것입니다.

예를 들어 흰 종이 위에 검은 동전 사진을 찍어 이진화하면, 동전이 있던 자리는 하나의 흰색(혹은 검은색) 덩어리로 남습니다. 이 덩어리의 바깥 경계를 따라가며 점을 찍으면 동전의 윤곽이 대략 원 모양의 폐곡선으로 나타나는데, 이것이 바로 컨투어입니다.

컨투어는 다음과 같은 특징을 가집니다.

- 컨투어는 좌표 점들의 목록(배열)입니다. 각 점은 이미지 위의 한 픽셀 위치 `(x, y)`를 가리킵니다.
- 하나의 이미지 안에는 여러 개의 컨투어가 존재할 수 있습니다. 동전이 세 개 찍힌 사진이라면 컨투어도 세 개가 검출됩니다.
- 객체 안에 구멍이 있으면(예: 도넛 모양) 바깥 경계와 안쪽 구멍 경계가 각각 별도의 컨투어로 검출될 수 있습니다.
- 컨투어 자체는 "점들의 나열"일 뿐 도형의 이름(삼각형, 원 등)을 알려주지는 않습니다. 도형의 종류를 알아내려면 이 장의 뒷부분에서 다룰 컨투어 근사와 같은 후처리가 필요합니다.

컨투어를 찾으려면 대상 이미지가 **이진 이미지**여야 합니다. 그레이스케일이나 컬러 이미지를 그대로 넣으면 원하는 결과를 얻을 수 없으므로, 보통 10장에서 배운 `threshold`나 `adaptiveThreshold`, 12장에서 배운 캐니 엣지 검출 결과를 먼저 만들어 놓고 그 결과에 컨투어 검출을 적용합니다. 즉, 컨투어 검출은 언제나 "이진화 → 컨투어 검출 → 분석"이라는 3단계 파이프라인의 마지막 단계에 위치합니다.

## 13.2 findContours로 컨투어 찾기

OpenCV는 이진 이미지에서 컨투어를 찾는 `cv2.findContours` 함수를 제공합니다. 이 함수를 사용할 때 결정해야 할 두 가지 중요한 옵션이 있습니다.

**검색 모드(retrieval mode)**: 컨투어들 사이의 계층 관계를 얼마나 자세히 알아낼 것인지를 정합니다.

- `cv2.RETR_EXTERNAL`: 가장 바깥쪽 컨투어만 찾습니다. 객체 내부에 구멍이 있어도 무시하고, 서로 겹치지 않는 객체들의 개수를 셀 때 가장 간단하고 흔히 쓰입니다.
- `cv2.RETR_LIST`: 모든 컨투어를 찾지만 계층 구조(부모-자식 관계)는 따지지 않고 단순히 나열합니다.
- `cv2.RETR_TREE`: 모든 컨투어를 찾고, 바깥 경계와 안쪽 구멍 경계 사이의 포함 관계까지 트리 구조로 구성합니다.
- `cv2.RETR_CCOMP`: 모든 컨투어를 찾되 2단계(바깥 경계, 구멍 경계)로만 계층을 구성합니다.

이 장의 예제에서는 대부분 객체의 개수를 세거나 각 객체의 바깥 윤곽만 필요하므로 `RETR_EXTERNAL`을 기본으로 사용합니다. 다만 도넛처럼 구멍이 있는 도형을 구별해야 하거나, 글자의 안쪽 구멍(예: "O", "8"의 내부)까지 분석해야 하는 작업에서는 `RETR_TREE`와 함께 반환되는 계층 정보(`hierarchy`)를 활용해야 합니다.

**근사 방법(approximation method)**: 컨투어를 이루는 점들을 얼마나 촘촘하게 저장할 것인지를 정합니다.

- `cv2.CHAIN_APPROX_NONE`: 경계를 이루는 모든 픽셀 좌표를 하나도 빠짐없이 저장합니다. 메모리를 많이 사용합니다.
- `cv2.CHAIN_APPROX_SIMPLE`: 직선으로 이어지는 구간은 양 끝점만 저장하여 점의 개수를 크게 줄입니다. 대부분의 경우 이 옵션으로 충분하며, 실무에서 가장 널리 사용됩니다.

```python
import cv2

img = cv2.imread("shapes.png")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

contours, hierarchy = cv2.findContours(
    binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE
)

print(f"검출된 컨투어 개수: {len(contours)}")
print(f"첫 번째 컨투어의 점 개수: {len(contours[0])}")
print(f"첫 번째 컨투어의 자료형: {type(contours[0])}, shape={contours[0].shape}")
```

`findContours`가 반환하는 각 컨투어는 `(N, 1, 2)` 모양의 넘파이 배열입니다. 여기서 `N`은 점의 개수이고, 마지막 차원 2는 `(x, y)` 좌표를 담습니다. 이 구조가 조금 어색하게 느껴질 수 있는데, `contours[0].reshape(-1, 2)`처럼 재구성하면 `(N, 2)` 형태의 일반적인 좌표 배열로 다루기 편해집니다.

> 참고: OpenCV 3.x 버전의 Python/C++ API에서는 `findContours`가 컨투어와 함께 원본 이미지를 변형된 형태로 반환값 맨 앞에 추가로 돌려주었지만, OpenCV 4.x부터는 이 동작이 사라지고 컨투어와 계층 정보 두 가지만 반환합니다. 이 책은 4.x 기준으로 설명합니다.

`hierarchy`는 `(1, N, 4)` 모양의 배열로, 각 컨투어마다 `[다음 형제, 이전 형제, 첫 자식, 부모]` 인덱스를 담습니다. 해당하는 컨투어가 없으면 -1이 저장됩니다. `RETR_EXTERNAL`을 사용할 때는 모든 컨투어가 최상위이므로 부모/자식 인덱스가 항상 -1이지만, `RETR_TREE`를 사용하면 이 값들을 통해 "이 컨투어는 저 컨투어 내부에 있는 구멍이다"와 같은 포함 관계를 코드로 판단할 수 있습니다.

## 13.3 drawContours로 컨투어 시각화하기

컨투어는 좌표 점들의 배열일 뿐이므로, 눈으로 확인하려면 이미지 위에 그려야 합니다. `cv2.drawContours`는 6장에서 배운 도형 그리기 함수들과 비슷하게 동작하며, 컨투어 전체 또는 특정 인덱스의 컨투어만 골라 그릴 수 있습니다.

```python
import cv2

img = cv2.imread("shapes.png")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

result = img.copy()
# -1을 넘기면 모든 컨투어를 그린다
cv2.drawContours(result, contours, -1, (0, 255, 0), 2)

cv2.imshow("Contours", result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

세 번째 인수(인덱스)에 -1을 넘기면 찾아낸 모든 컨투어를 그리고, 0, 1, 2와 같은 특정 값을 넘기면 그 인덱스에 해당하는 컨투어 하나만 그립니다. 네 번째 인수는 선의 색이고, 다섯 번째 인수로 선의 두께를 지정하는데, 이 값을 음수(예: `-1`)로 주면 컨투어 내부를 색으로 채워 그립니다.

```python
# 컨투어를 하나씩 다른 색으로, 내부를 채워서 그리기
result = img.copy()
colors = [(0, 0, 255), (0, 255, 0), (255, 0, 0), (0, 255, 255), (255, 0, 255)]

for i, cnt in enumerate(contours):
    color = colors[i % len(colors)]
    cv2.drawContours(result, contours, i, color, thickness=-1)
```

이렇게 컨투어마다 다른 색으로 채워 그리면, 검출된 각 객체가 서로 잘 분리되어 있는지를 눈으로 빠르게 검증할 수 있습니다. 만약 두 객체가 실제로는 붙어 있지 않은데도 한 덩어리로 채워진다면, 이진화 단계나 모폴로지 연산 단계를 다시 점검해야 한다는 신호입니다.

## 13.4 컨투어의 특성 분석하기

컨투어를 찾았다면 이제 그 형태를 수치로 분석할 수 있습니다. 자주 쓰이는 네 가지 함수를 살펴봅니다.

- `cv2.contourArea`: 컨투어가 감싸는 영역의 **면적**을 계산합니다. 픽셀 개수와 비슷하지만 정확히는 그린의 정리(Green's theorem)를 이용해 계산한 다각형의 면적입니다.
- `cv2.arcLength`: 컨투어의 **둘레** 길이를 계산합니다. 두 번째 인수를 `True`로 주면 컨투어가 폐곡선(닫힌 도형)이라고 가정합니다.
- `cv2.boundingRect`: 컨투어를 완전히 감싸는 축에 평행한 **최소 직사각형**을 구합니다. `(x, y, width, height)` 형태로 반환됩니다.
- `cv2.minEnclosingCircle`: 컨투어의 모든 점을 포함하는 **최소 외접원**을 구합니다. 중심 좌표와 반지름을 반환합니다.

```python
import cv2

img = cv2.imread("shapes.png")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

for cnt in contours:
    area = cv2.contourArea(cnt)
    perimeter = cv2.arcLength(cnt, True)
    x, y, w, h = cv2.boundingRect(cnt)
    (cx, cy), radius = cv2.minEnclosingCircle(cnt)

    print(f"면적: {area:.1f}, 둘레: {perimeter:.1f}")
    print(f"경계 사각형: x={x}, y={y}, w={w}, h={h}")
    print(f"외접원: 중심=({cx:.1f}, {cy:.1f}), 반지름={radius:.1f}")
```

`contourArea`가 계산하는 면적과 단순히 경계 사각형(`boundingRect`)의 넓이(`w * h`)는 서로 다르다는 점에 주의해야 합니다. 경계 사각형은 컨투어를 감싸는 상자일 뿐이므로 도형이 원형이나 별 모양처럼 복잡할수록 실제 면적보다 훨씬 크게 나옵니다. 따라서 "객체의 실제 크기"를 판단할 때는 `contourArea`를, "객체가 화면에서 차지하는 대략적인 위치와 범위"를 판단할 때는 `boundingRect`를 사용하는 것이 적절합니다.

아래 그림은 하나의 별 모양 컨투어에 대해 면적, 둘레, 경계 사각형, 외접원이 각각 어떤 영역을 가리키는지를 보여줍니다.

![컨투어 특성 비교](images/ch13-contour-properties.svg)

축에 평행하지 않고 도형에 딱 맞게 기울어진 사각형이 필요하다면 `cv2.minAreaRect`를 사용할 수 있습니다. 이 함수는 중심점, `(너비, 높이)`, 회전각을 담은 튜플을 반환하며, 실제 꼭짓점 좌표가 필요하면 `cv2.boxPoints`로 변환합니다.

```python
rect = cv2.minAreaRect(cnt)          # ((cx, cy), (w, h), angle)
box = cv2.boxPoints(rect)            # 4개의 꼭짓점 좌표 (실수)
box = box.astype("int32")            # 그리기 위해 정수로 변환
cv2.drawContours(result, [box], 0, (0, 255, 255), 2)
```

기울어진 물체(예: 컨베이어 벨트 위에서 회전된 채로 놓인 부품)의 크기와 방향을 함께 파악해야 할 때 `minAreaRect`가 `boundingRect`보다 훨씬 정확한 정보를 제공합니다. `boundingRect`는 항상 이미지 좌표축에 평행하므로 물체가 45도 기울어진 경우 실제 크기보다 훨씬 큰 사각형을 반환하지만, `minAreaRect`는 물체의 실제 회전을 반영한 최소 크기의 사각형을 찾아줍니다.

## 13.5 컨벡스 헐(Convex Hull)

**컨벡스 헐(convex hull, 볼록 껍질)**은 컨투어를 이루는 점들을 모두 포함하는 가장 작은 **볼록 다각형**입니다. 직관적으로는 도형의 바깥쪽에 고무줄을 씌워 팽팽하게 당겼을 때 만들어지는 모양이라고 생각하면 됩니다. 오목한 부분(움푹 들어간 부분)이 있는 도형이라면, 컨벡스 헐은 그 오목한 부분을 무시하고 겉을 매끈하게 감싼 형태가 됩니다.

OpenCV에서는 `cv2.convexHull` 함수로 컨벡스 헐을 구합니다.

```python
import cv2

img = cv2.imread("hand.png")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
cnt = max(contours, key=cv2.contourArea)  # 가장 큰 컨투어(예: 손 모양) 선택

hull = cv2.convexHull(cnt)

result = img.copy()
cv2.drawContours(result, [cnt], -1, (0, 255, 0), 2)   # 원본 컨투어: 초록색
cv2.drawContours(result, [hull], -1, (0, 0, 255), 2)  # 컨벡스 헐: 빨간색

cv2.imshow("Convex Hull", result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

컨벡스 헐과 원본 컨투어를 비교하면 도형이 얼마나 오목한지를 정량적으로 판단할 수 있습니다. 예를 들어 손을 촬영해 이진화한 뒤 컨투어를 구하면, 손가락 사이의 움푹 들어간 부분 때문에 원본 컨투어는 오목한 모양이 되지만 컨벡스 헐은 손가락 끝을 매끄럽게 이어 감싸는 볼록한 모양이 됩니다. 이 둘의 면적 비율(`contourArea(cnt) / contourArea(hull)`)을 **견고성(solidity)**이라고 부르며, 1에 가까울수록 도형이 원래부터 볼록했다는 뜻이고, 값이 작을수록 오목한 부분이 많다는 뜻입니다.

```python
hull_area = cv2.contourArea(hull)
cnt_area = cv2.contourArea(cnt)
solidity = cnt_area / hull_area if hull_area > 0 else 0
print(f"견고성(solidity): {solidity:.3f}")
```

견고성은 손가락을 편 손 모양과 주먹을 쥔 손 모양을 구분하거나, 별 모양처럼 뾰족한 돌기가 많은 도형과 원처럼 매끈한 도형을 구분하는 데 활용할 수 있는 유용한 특징값입니다. 또한 `cv2.isContourConvex(cnt)`를 호출하면 해당 컨투어 자체가 이미 볼록한 도형인지 아닌지를 `True`/`False`로 바로 확인할 수 있습니다.

## 13.6 컨투어 근사와 실전 프로젝트: 도형 분류기

`cv2.approxPolyDP`는 **Douglas-Peucker 알고리즘**을 이용해 컨투어를 이루는 수십, 수백 개의 점을 훨씬 적은 수의 꼭짓점으로 단순화합니다. 예를 들어 사각형을 촬영해 컨투어를 구하면 모서리가 완벽한 직선이 아니라 픽셀 단위의 미세한 계단 모양으로 인해 수십 개의 점으로 표현되는데, `approxPolyDP`를 적용하면 이 점들을 실제 의도에 맞게 4개의 꼭짓점으로 근사할 수 있습니다.

```python
epsilon = 0.02 * cv2.arcLength(cnt, True)
approx = cv2.approxPolyDP(cnt, epsilon, True)
```

두 번째 인수 `epsilon`은 근사 정밀도를 결정하는 값으로, 원본 컨투어와 근사된 다각형 사이에 허용하는 최대 거리입니다. 이 값을 절대 픽셀 수로 고정하면 이미지 크기나 도형 크기에 따라 결과가 들쑥날쑥해지므로, 실무에서는 **둘레 길이에 대한 비율**(보통 1~4% 사이)로 지정하는 것이 일반적입니다. `epsilon`이 너무 작으면 원본 컨투어와 거의 같은, 점이 여전히 많은 다각형이 나오고, 너무 크면 단순화가 지나쳐 사각형이 삼각형으로 뭉개지는 등 원래 모양을 왜곡할 수 있습니다. 세 번째 인수 `True`는 컨투어가 닫힌 도형임을 의미합니다.

이 성질을 이용하면 매우 실용적인 아이디어가 떠오릅니다. **근사된 다각형의 꼭짓점 개수를 세어보면, 그 도형이 삼각형인지 사각형인지 원(다각형이 아닌 매끈한 곡선)인지를 대략 구분할 수 있습니다.** 삼각형은 꼭짓점이 3개, 사각형(정사각형/직사각형)은 4개로 근사되고, 원은 아무리 epsilon을 조절해도 3~4개로는 잘 근사되지 않고 꼭짓점이 5개 이상으로 남는 경향이 있습니다. 이 원리를 이용해 이미지 속 여러 도형을 자동으로 분류하는 프로그램을 만들어 보겠습니다.

### 실전 프로젝트: 꼭짓점 개수 기반 도형 분류기

```python
import cv2

MIN_AREA = 300  # 노이즈로 간주할 최소 면적 기준

img = cv2.imread("shapes.png")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

result = img.copy()

for cnt in contours:
    area = cv2.contourArea(cnt)
    if area < MIN_AREA:
        continue

    perimeter = cv2.arcLength(cnt, True)
    epsilon = 0.02 * perimeter
    approx = cv2.approxPolyDP(cnt, epsilon, True)
    vertices = len(approx)

    # 무게중심 계산 (13.7절에서 자세히 다룰 moments 활용)
    M = cv2.moments(cnt)
    cx = int(M["m10"] / M["m00"]) if M["m00"] != 0 else 0
    cy = int(M["m01"] / M["m00"]) if M["m00"] != 0 else 0

    if vertices == 3:
        shape_name, color = "Triangle", (0, 0, 255)
    elif vertices == 4:
        # 가로세로 비율로 정사각형과 직사각형을 한 번 더 구분
        x, y, w, h = cv2.boundingRect(approx)
        ratio = w / float(h)
        shape_name = "Square" if 0.90 <= ratio <= 1.10 else "Rectangle"
        color = (0, 255, 0)
    else:
        # 꼭짓점이 5개 이상이면 원(또는 다각형 곡선)으로 근사 분류
        shape_name, color = "Circle", (255, 0, 0)

    cv2.drawContours(result, [cnt], -1, color, 2)
    cv2.putText(result, shape_name, (cx - 40, cy),
                cv2.FONT_HERSHEY_SIMPLEX, 0.6, color, 2)
    print(f"중심=({cx},{cy}), 꼭짓점={vertices}, 면적={area:.0f} -> {shape_name}")

cv2.imshow("Shape Classifier", result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

이 분류기는 "꼭짓점이 3개면 삼각형, 4개면 사각형, 그 이상이면 원"이라는 단순한 규칙만으로도 실전에서 꽤 잘 동작합니다. 다만 몇 가지 한계와 개선 방향을 알아두면 좋습니다.

- 오각형, 육각형처럼 실제로 존재하는 다각형도 꼭짓점이 5개 이상이면 이 분류기는 모두 "원"으로 분류합니다. 오각형/육각형까지 구분하려면 `vertices == 5`, `vertices == 6`인 경우를 별도의 분기로 추가하면 됩니다.
- 사진에 잡티나 그림자가 있으면 매끈한 사각형의 컨투어에도 미세한 굴곡이 생겨 꼭짓점이 5~6개로 잘못 근사될 수 있습니다. 이런 경우 `epsilon`을 조금 더 크게(예: 0.03~0.04) 주면 안정성이 높아집니다.
- 원과 다각형을 더 확실하게 구분하고 싶다면, 꼭짓점 개수만 보는 대신 **원형도(circularity)** 지표를 함께 사용하는 것이 좋습니다. 원형도는 `4 * π * area / perimeter²`로 계산하며, 완벽한 원은 이 값이 1에 가깝고 별 모양처럼 뾰족한 도형일수록 1보다 훨씬 작아집니다.

```python
import math

circularity = 4 * math.pi * area / (perimeter ** 2) if perimeter > 0 else 0
is_circle = vertices >= 5 and circularity > 0.8
```

꼭짓점 개수와 원형도를 함께 사용하면 "꼭짓점은 많지만 찌그러진 도형"과 "실제로 매끈한 원"을 훨씬 안정적으로 구분할 수 있습니다.

## 13.7 모멘트(Moments)와 무게중심 추적

**모멘트(moments)**는 컨투어(또는 이미지 영역)의 형태를 요약하는 통계적인 값들의 집합입니다. 모멘트라는 용어가 낯설게 느껴질 수 있지만, 실전에서 가장 자주 쓰이는 활용은 단 하나, 바로 **무게중심(centroid)**을 계산하는 것입니다.

OpenCV에서는 `cv2.moments` 함수로 컨투어의 모멘트를 계산하며, 반환값은 `m00`, `m10`, `m01`처럼 이름이 붙은 딥셔너리(파이썬 딕셔너리)입니다. 이 중 무게중심 계산에 필요한 것은 세 가지뿐입니다.

- `m00`: 0차 모멘트로, `contourArea`와 거의 같은 값(컨투어가 감싸는 면적)입니다.
- `m10`, `m01`: 1차 모멘트로, 각각 x좌표와 y좌표에 대한 가중합입니다.

무게중심의 x좌표는 `m10 / m00`, y좌표는 `m01 / m00`으로 계산합니다. 이는 물리학에서 배우는 "질량 중심 = (위치 × 질량)의 합 / 전체 질량"과 정확히 같은 원리이며, 여기서는 픽셀 하나하나가 동일한 질량을 가진다고 보는 셈입니다.

```python
import cv2

img = cv2.imread("shapes.png")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

result = img.copy()
for cnt in contours:
    if cv2.contourArea(cnt) < 300:
        continue

    M = cv2.moments(cnt)
    if M["m00"] == 0:      # 면적이 0인 퇴화된 컨투어는 0으로 나누기 방지
        continue

    cx = int(M["m10"] / M["m00"])
    cy = int(M["m01"] / M["m00"])

    cv2.drawContours(result, [cnt], -1, (0, 255, 0), 2)
    cv2.circle(result, (cx, cy), 5, (0, 0, 255), -1)
    print(f"무게중심: ({cx}, {cy})")

cv2.imshow("Centroids", result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`M["m00"]`이 0이 되는 경우(예: 점 하나 또는 일직선으로만 이루어진 퇴화된 컨투어)를 반드시 확인하고 나누기 전에 걸러내야 합니다. 이 검사를 빼먹으면 실전 영상에서 드물게 `ZeroDivisionError`가 발생해 프로그램이 멈추는 원인이 됩니다.

### 실전 활용: 영상에서 물체의 무게중심 추적하기

무게중심은 정지 영상뿐 아니라 **영상(비디오)에서 움직이는 물체를 프레임마다 추적**하는 데 특히 유용합니다. 색상 기반으로 특정 물체(예: 빨간색 공)를 이진화한 뒤, 매 프레임에서 가장 큰 컨투어의 무게중심을 계산해 이어 그리면 물체의 이동 경로를 실시간으로 시각화할 수 있습니다.

```python
import cv2

cap = cv2.VideoCapture(0)
trail = []          # 지금까지의 무게중심 좌표를 저장해 이동 경로를 표시
MAX_TRAIL_LEN = 64   # 경로가 너무 길어지지 않도록 제한

while True:
    ret, frame = cap.read()
    if not ret:
        break

    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    # 빨간색 계열만 이진화 (5장에서 배운 색공간 기반 필터링)
    lower_red = (0, 120, 70)
    upper_red = (10, 255, 255)
    mask = cv2.inRange(hsv, lower_red, upper_red)

    contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

    if contours:
        largest = max(contours, key=cv2.contourArea)
        if cv2.contourArea(largest) > 500:
            M = cv2.moments(largest)
            if M["m00"] != 0:
                cx = int(M["m10"] / M["m00"])
                cy = int(M["m01"] / M["m00"])
                trail.append((cx, cy))
                if len(trail) > MAX_TRAIL_LEN:
                    trail.pop(0)
                cv2.circle(frame, (cx, cy), 6, (0, 255, 0), -1)

    for i in range(1, len(trail)):
        cv2.line(frame, trail[i - 1], trail[i], (0, 0, 255), 2)

    cv2.imshow("Centroid Tracking", frame)
    if cv2.waitKey(1) & 0xFF == 27:   # ESC 키로 종료
        break

cap.release()
cv2.destroyAllWindows()
```

이 예제는 매 프레임마다 (1) 색상으로 이진화하고 (2) 가장 큰 컨투어를 찾고 (3) 그 무게중심을 계산해 리스트에 쌓는 세 단계를 반복합니다. `trail` 리스트에 좌표를 계속 추가하고 인접한 두 점을 선으로 이으면, 물체가 화면 안에서 그린 궤적이 자연스럽게 시각화됩니다. `MAX_TRAIL_LEN`으로 경로의 최대 길이를 제한한 것은 물체가 오래 움직일 경우 화면이 선으로 가득 차는 것을 막기 위한 실용적인 장치입니다.

> 심화 참고: `cv2.moments`는 `m00`, `m10`, `m01` 외에도 `mu20`, `mu02`, `mu11`과 같은 **중심 모멘트(central moments)**도 함께 반환합니다. 이 값들을 이용하면 무게중심뿐 아니라 도형이 어느 방향으로 길게 늘어져 있는지(주축 방향, orientation)까지 계산할 수 있습니다. 이는 이 책의 범위를 넘어서는 심화 주제이므로, 관심 있는 독자는 OpenCV 공식 문서의 "Image Moments" 튜토리얼을 참고하기 바랍니다.

## 13.8 실전 예제: 객체 개수 세기

지금까지 배운 내용을 종합해, 이진화된 이미지에서 일정 면적 이상인 컨투어만 골라 개수를 세고 각 객체에 경계 사각형과 무게중심을 함께 그리는 예제를 만들어 보겠습니다. 이런 기법은 부품 검사, 세포 계수, 동전 인식처럼 "화면 안에 특정 크기 이상의 객체가 몇 개 있는가"를 판단해야 하는 실무 상황에서 널리 쓰입니다.

작은 노이즈로 인한 잡티나 먼지가 이진화 과정에서 작은 컨투어로 함께 검출되는 경우가 많으므로, 면적이 일정 기준(`MIN_AREA`) 이상인 컨투어만 실제 객체로 인정하는 필터링 단계가 핵심입니다.

```python
import cv2

MIN_AREA = 500  # 이 값보다 작은 컨투어는 노이즈로 간주하고 무시

img = cv2.imread("coins.png")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
blurred = cv2.GaussianBlur(gray, (5, 5), 0)
_, binary = cv2.threshold(blurred, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

# 면적이 큰 순서로 정렬해두면, 가장 큰 객체부터 확인하거나
# 상위 N개만 별도로 처리하는 등의 후속 작업이 쉬워진다
contours = sorted(contours, key=cv2.contourArea, reverse=True)

result = img.copy()
count = 0

for cnt in contours:
    area = cv2.contourArea(cnt)
    if area < MIN_AREA:
        continue

    count += 1
    x, y, w, h = cv2.boundingRect(cnt)
    cv2.rectangle(result, (x, y), (x + w, y + h), (0, 255, 0), 2)

    M = cv2.moments(cnt)
    if M["m00"] != 0:
        cx, cy = int(M["m10"] / M["m00"]), int(M["m01"] / M["m00"])
        cv2.circle(result, (cx, cy), 3, (0, 0, 255), -1)

    cv2.putText(result, f"#{count}", (x, y - 5),
                cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 0, 255), 2)

print(f"검출된 객체 개수: {count}")
cv2.imshow("Detected Objects", result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

이 예제는 10장의 오츠 이진화(`THRESH_OTSU`)와 9장의 가우시안 블러를 함께 사용해 조명이 일정하지 않은 사진에서도 안정적으로 이진화되도록 했습니다. 만약 실제 사진에서 객체 개수가 예상보다 많거나 적게 나온다면, `MIN_AREA` 값을 조정하거나 11장에서 배운 모폴로지 연산(열림 연산)을 이진화 이후에 추가로 적용해 작은 잡티를 먼저 제거하는 것이 좋습니다.

## 요약

- 컨투어는 이진 이미지에서 같은 값을 가진 영역의 경계를 이루는 점들의 연결입니다. 컨투어를 찾기 전에는 반드시 이진화 과정을 거쳐야 합니다.
- `findContours`는 검색 모드(`RETR_EXTERNAL`, `RETR_TREE` 등)와 근사 방법(`CHAIN_APPROX_SIMPLE` 등)을 지정해 컨투어 목록과 계층 정보를 반환합니다. 객체 개수만 세는 경우에는 `RETR_EXTERNAL`과 `CHAIN_APPROX_SIMPLE`의 조합이 가장 간단하고 효율적입니다.
- `drawContours`로 컨투어를 이미지 위에 그려 눈으로 확인할 수 있으며, 인덱스에 -1을 넘기면 모든 컨투어를 한 번에 그리고, 두께를 음수로 주면 내부를 채워서 그립니다.
- `contourArea`, `arcLength`, `boundingRect`, `minAreaRect`, `minEnclosingCircle`은 컨투어의 형태를 수치로 요약하는 대표적인 함수입니다. 특히 `contourArea`는 실제 도형의 면적을, `boundingRect`의 넓이는 도형을 감싸는 사각형의 넓이를 나타내므로 서로 다른 값임을 기억해야 합니다.
- `convexHull`은 컨투어를 감싸는 최소 볼록 다각형을 구하며, 원본 면적과의 비율(견고성)로 도형이 얼마나 오목한지를 정량화할 수 있습니다.
- `approxPolyDP`는 컨투어를 적은 수의 꼭짓점으로 단순화합니다. 이 꼭짓점 개수를 이용해 삼각형(3개), 사각형(4개), 원(5개 이상)으로 도형을 분류하는 실전 분류기를 만들 수 있으며, 원형도(circularity) 지표를 함께 쓰면 더 안정적으로 분류할 수 있습니다.
- `moments`로 계산한 `m00`, `m10`, `m01`을 이용하면 컨투어의 무게중심을 구할 수 있고, 이를 매 프레임마다 계산해 이어 붙이면 영상 속 물체의 이동 경로를 추적할 수 있습니다.
- 작은 노이즈로 생기는 잡티 컨투어는 면적 기준으로 걸러내는 것이 실전에서 매우 흔한 패턴입니다.

## 연습문제

1. `RETR_EXTERNAL`과 `RETR_TREE`로 같은 이미지에서 컨투어를 찾았을 때, 도넛 모양(구멍이 있는 도형)이 포함된 이미지라면 두 결과의 컨투어 개수와 `hierarchy` 값이 어떻게 달라지는지 직접 실행해 비교해 보세요.
2. 손이나 별 모양처럼 오목한 부분이 있는 도형의 컨투어와 `convexHull` 결과를 함께 그려보고, 두 면적의 비율(견고성)을 계산해 출력하는 프로그램을 작성해 보세요.
3. 13.6절의 도형 분류기를 확장하여, 꼭짓점이 5개인 경우와 6개인 경우를 각각 "Pentagon", "Hexagon"으로 별도 분류하고 7개 이상인 경우에만 "Circle"로 분류하도록 수정해 보세요.
4. `approxPolyDP`의 `epsilon` 값을 둘레의 1%, 2%, 5%, 10%로 각각 바꿔가며 같은 사각형 이미지에 적용했을 때 근사된 꼭짓점 개수가 어떻게 달라지는지 표로 정리해 보세요.
5. 13.7절의 무게중심 추적 예제를 참고하여, 정지된 이미지 안에 있는 여러 개의 도형 각각의 무게중심을 계산하고, 무게중심 사이의 거리가 가장 가까운 두 도형의 쌍을 찾아 출력하는 프로그램을 작성해 보세요.
