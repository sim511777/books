# Slint로 배우는 C++ GUI 프로그래밍

[다음: 1장. Slint란 무엇인가 ▶](ch01-Slint란무엇인가.md)

---

Rust 코어에 C++/Rust/JavaScript/Python 바인딩을 제공하는 선언적(declarative) GUI 툴킷
Slint를 C++로 사용하는 입문서입니다. `.slint` 언어 기초 문법부터 레이아웃, 프로퍼티 바인딩,
콜백, C++ 연동, 표준 위젯, 상태와 애니메이션, 리스트/모델, 전역 싱글톤, 다중 창, 임베디드
타겟팅, 실전 프로젝트까지 순서대로 다룹니다.

각 장은 개념 설명, Slint/C++ 예제 코드, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는
이해를 돕는 다이어그램을 함께 실었습니다.

## 학습 방법 제안

1. 각 장의 `.slint` 예제는 `slint-viewer`로 먼저 빠르게 미리보기하고, C++ 연동이 필요한 예제는 CMake 프로젝트에 옮겨 직접 빌드해보세요.
2. 장 끝의 연습문제를 풀어보면서 이해도를 점검하세요.
3. 5장(프로퍼티와 바인딩)과 7~8장(C++ 연동)은 이 책 전체의 근간이 되는 내용이므로 특히 꼼꼼히 읽어보세요.
4. 18장의 실전 프로젝트는 그동안 배운 내용을 종합하는 자리이니, 코드를 그대로 옮기기보다 스스로 변형해보며 완성해보세요.
