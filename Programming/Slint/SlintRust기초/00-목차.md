# Slint로 배우는 Rust GUI 프로그래밍

[다음: 1장. Slint란 무엇인가 ▶](ch01-Slint란무엇인가.md)

---

Rust 코어에 Rust/C++/JavaScript/Python 바인딩을 제공하는 선언적(declarative) GUI 툴킷
Slint를 Rust로 사용하는 입문서입니다. 이 저장소의 [Slint로 배우는 C++ GUI 프로그래밍](../Slint기초/00-목차.md)의
자매서로, Slint 코어 자체가 Rust로 작성된 만큼 가장 직접적인 언어 바인딩인 Rust API를 기준으로
`.slint` 언어 기초부터 프로퍼티 바인딩, 콜백, Rust 연동, 표준 위젯, 상태/애니메이션, 리스트/모델,
전역 싱글톤, 다중 창, 임베디드 타겟팅, 실전 프로젝트까지 순서대로 다룹니다.

각 장은 개념 설명, `.slint`/Rust 예제 코드, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는
이해를 돕는 다이어그램을 함께 실었습니다.

## 학습 방법 제안

1. 각 장의 `.slint` 예제는 `slint-viewer`로 먼저 빠르게 미리보기하고, Rust 연동이 필요한 예제는 `cargo run`으로 직접 빌드해보세요.
2. 장 끝의 연습문제를 풀어보면서 이해도를 점검하세요.
3. 5장(프로퍼티와 바인딩)과 7~8장(Rust 연동)은 이 책 전체의 근간이 되는 내용이므로 특히 꼼꼼히 읽어보세요. 특히 콜백 클로저에서 `Weak`를 캡처하는 패턴(6장, 8장)은 Rust의 소유권 규칙과 맞물려 있으니 원리를 정확히 이해하고 넘어가세요.
4. 이 저장소의 [Slint(C++)](../Slint기초/00-목차.md) 책과 비교하며 읽으면, 같은 선언적 UI 개념이 C++과 Rust에서 각각 어떻게 연동되는지(빌드 방식, 메모리 관리 철학의 차이) 더 잘 이해할 수 있습니다. 자세한 비교는 부록을 참고하세요.
5. 18장의 실전 프로젝트는 그동안 배운 내용을 종합하는 자리이니, 코드를 그대로 옮기기보다 스스로 변형해보며 완성해보세요.
