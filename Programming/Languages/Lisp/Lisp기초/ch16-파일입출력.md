## 시작하며

지금까지 작성한 프로그램들은 REPL 화면에 결과를 출력하거나, 코드 안에 값을 직접 적어 넣는 방식으로 동작했습니다. 하지만 실제 프로그램은 대부분 파일에서 데이터를 읽어오고, 처리 결과를 파일에 저장합니다. 이번 장에서는 Lisp가 파일을 다루는 방식을 배웁니다. 파일을 안전하게 열고 닫는 관용구인 `with-open-file`, 텍스트를 한 줄씩 또는 하나의 Lisp 데이터로 읽어오는 방법, 그리고 14장에서 배운 `format`을 이용해 파일에 원하는 모양으로 값을 기록하는 방법까지 차례로 살펴보겠습니다.

## 스트림이라는 개념

Lisp에서 파일은 **스트림(stream)**이라는 객체를 통해 다룹니다. 스트림은 데이터가 흘러들어오거나 흘러나가는 통로라고 생각하면 됩니다. 우리가 지금까지 써온 `format t ...`의 `t`도 사실 "표준 출력 스트림"을 가리키는 특수한 표기였습니다. 파일을 읽고 쓰려면 먼저 그 파일에 연결된 스트림을 얻어야 하고, 작업이 끝나면 스트림을 닫아 자원을 반납해야 합니다.

## with-open-file: 열고, 쓰고, 자동으로 닫기

파일을 다룰 때 가장 신경 써야 할 부분은 "다 쓴 스트림을 반드시 닫는 것"입니다. 스트림을 닫지 않으면 운영체제가 파일에 대한 자원을 계속 붙들고 있어, 다른 프로그램이 그 파일을 열지 못하거나 최악의 경우 쓰기 내용이 디스크에 반영되지 않을 수도 있습니다. `open`과 `close`를 직접 짝지어 호출할 수도 있지만, 중간에 에러가 나서 `close`가 실행되지 못하는 상황을 매번 대비하기는 번거롭습니다.

Common Lisp는 이 문제를 `with-open-file`이라는 매크로로 해결합니다. `with-open-file`은 파일을 열고, 본문(body)을 실행한 뒤, 정상적으로 끝나든 에러로 끝나든 관계없이 스트림을 자동으로 닫아줍니다.

```lisp
(with-open-file (stream "greeting.txt"
                         :direction :output
                         :if-exists :supersede)
  (format stream "안녕하세요, Lisp!~%"))
```

각 부분을 뜯어보면 다음과 같습니다.

- `stream`: 이 블록 안에서 파일을 가리키는 변수 이름입니다. 원하는 이름을 자유롭게 지을 수 있습니다.
- `"greeting.txt"`: 열고자 하는 파일 경로입니다.
- `:direction :output`: 파일에 쓰기 위해 연다는 뜻입니다. 읽기만 할 때는 `:direction :input`(기본값이므로 생략 가능)을 사용합니다.
- `:if-exists :supersede`: 파일이 이미 존재할 경우 기존 내용을 덮어쓰겠다는 뜻입니다. 이 옵션을 지정하지 않고 `:output`으로 열면 파일이 이미 존재할 때 에러가 납니다.

이 코드를 실행하면 `greeting.txt`라는 파일이 만들어지고, `with-open-file` 블록이 끝나는 순간 자동으로 파일이 닫혀 내용이 디스크에 반영됩니다.

```lisp
* (with-open-file (stream "greeting.txt"
                           :direction :output
                           :if-exists :supersede)
    (format stream "안녕하세요, Lisp!~%"))
NIL
```

## write-line으로 한 줄씩 쓰기

`format`이 다양한 서식을 지정할 수 있어 강력하지만, 단순히 한 줄의 문자열을 그대로 기록하고 싶을 때는 `write-line`이 더 간단합니다.

```lisp
(with-open-file (out "fruits.txt"
                      :direction :output
                      :if-exists :supersede)
  (write-line "사과" out)
  (write-line "바나나" out)
  (write-line "체리" out))
```

`write-line`은 문자열 뒤에 줄바꿈을 자동으로 붙여 씁니다. 이렇게 만든 `fruits.txt`는 다음과 같은 세 줄짜리 텍스트 파일이 됩니다.

```
사과
바나나
체리
```

## read-line으로 한 줄씩 읽기

이제 방금 만든 파일을 읽어봅시다. 파일을 읽을 때는 `:direction :input`을 사용합니다(생략하면 기본값이 `:input`이므로 생략해도 무방합니다).

```lisp
(with-open-file (in "fruits.txt")
  (loop for line = (read-line in nil :eof)
        until (eq line :eof)
        do (format t "읽은 줄: ~a~%" line)))
```

`read-line`은 스트림에서 한 줄을 읽어 문자열로 돌려줍니다. 여기서 눈여겨볼 부분은 `read-line`에 넘긴 두 번째, 세 번째 인자입니다.

```lisp
(read-line in nil :eof)
```

- 두 번째 인자 `nil`: 파일 끝(EOF)에 도달했을 때 에러를 낼지 여부입니다. `nil`을 넘기면 에러 대신 세 번째 인자로 지정한 값을 돌려줍니다.
- 세 번째 인자 `:eof`: 파일 끝에 도달했을 때 돌려줄 값입니다. 파일 내용과 절대 겹치지 않을 만한 값(여기서는 키워드 `:eof`)을 정해두면, `until (eq line :eof)`처럼 반복을 멈출 조건으로 깔끔하게 쓸 수 있습니다.

이 인자들을 생략하면 파일 끝에서 `read-line`이 에러를 일으키므로, 파일 전체를 읽는 반복문에서는 위와 같은 패턴이 표준적인 관용구로 자리 잡았습니다. `loop`의 자세한 사용법은 17장에서 본격적으로 다룹니다. 지금 단계에서는 "파일 끝을 감지하며 한 줄씩 읽는 흔한 패턴" 정도로 기억해 두면 충분합니다.

실행 결과는 다음과 같습니다.

```lisp
* (with-open-file (in "fruits.txt")
    (loop for line = (read-line in nil :eof)
          until (eq line :eof)
          do (format t "읽은 줄: ~a~%" line)))
읽은 줄: 사과
읽은 줄: 바나나
읽은 줄: 체리
NIL
```

## read로 Lisp 데이터 그대로 읽기

지금까지는 파일 내용을 항상 "문자열"로 읽어왔습니다. 하지만 파일에 저장된 내용이 애초에 숫자나 리스트 같은 Lisp 데이터 형태라면, 문자열로 읽은 뒤 다시 파싱하는 대신 `read`를 사용해 한 번에 Lisp 값으로 읽어올 수 있습니다.

```lisp
(with-open-file (out "numbers.lisp"
                      :direction :output
                      :if-exists :supersede)
  (format out "(1 2 3 4 5)~%")
  (format out "(:name \"홍길동\" :age 30)~%"))
```

이렇게 만든 파일을 `read`로 읽으면, 문자열이 아니라 실제 리스트와 심볼로 구성된 Lisp 데이터가 그대로 돌아옵니다.

```lisp
* (with-open-file (in "numbers.lisp")
    (let ((numbers (read in))
          (person (read in)))
      (format t "숫자 리스트: ~a~%" numbers)
      (format t "합계: ~a~%" (apply #'+ numbers))
      (format t "이름: ~a~%" (getf person :name))))
숫자 리스트: (1 2 3 4 5)
합계: 15
이름: 홍길동
NIL
```

`read`는 스트림에서 S-표현식 하나를 읽어 그에 대응하는 Lisp 객체(리스트, 심볼, 숫자, 문자열 등)로 반환합니다. `read-line`이 "한 줄의 텍스트"를 반환하는 것과 달리, `read`는 "하나의 완전한 Lisp 표현식"을 반환한다는 점에서 근본적으로 다릅니다. 이 방식은 설정 파일이나 프로그램이 저장한 데이터를 다시 불러올 때 특히 유용합니다. 문자열을 직접 파싱하는 코드를 작성할 필요 없이, Lisp 리더(reader)가 그 일을 대신해 주기 때문입니다.

## format으로 파일에 서식 있는 출력 남기기

14장에서 배운 `format`의 다양한 지시자는 화면 출력뿐 아니라 파일 스트림에도 그대로 적용됩니다. 첫 번째 인자에 `t` 대신 스트림 변수를 넘기기만 하면 됩니다. 학생들의 점수를 표 형태로 파일에 기록하는 예제를 만들어 봅시다.

```lisp
(defparameter *scores*
  '(("홍길동" 88) ("김철수" 95) ("이영희" 76)))

(with-open-file (out "report.txt"
                      :direction :output
                      :if-exists :supersede)
  (format out "~&이름~10t점수~%")
  (format out "~&--------------~%")
  (dolist (entry *scores*)
    (format out "~&~a~10t~d~%" (first entry) (second entry)))
  (format out "~&--------------~%")
  (format out "~&평균: ~,1f~%"
          (/ (reduce #'+ *scores* :key #'second)
             (length *scores*))))
```

여기서 `~t`는 지정한 칸으로 커서를 이동시켜 표 형태의 정렬을 만들어주고, `~,1f`는 소수점 첫째 자리까지 실수를 출력합니다. 모두 14장에서 다룬 지시자입니다. 실행하면 `report.txt`에 다음과 같은 내용이 저장됩니다.

```
이름      점수
--------------
홍길동      88
김철수      95
이영희      76
--------------
평균: 86.3
```

화면에 출력하던 코드를 파일에 출력하는 코드로 바꾸는 데 필요한 변경은 사실상 `format`의 첫 번째 인자를 `t`에서 스트림 변수로 바꾸는 것뿐입니다. 이는 `format`이 "어디에 쓸지"와 "무엇을 어떻게 쓸지"를 깔끔하게 분리해 설계되었기 때문입니다.

## 파일이 없을 때, 이미 있을 때

파일 입출력에서 자주 마주치는 상황은 "파일이 없으면 어떻게 할까", "파일이 이미 있으면 어떻게 할까"입니다. `with-open-file`은 이를 위한 옵션을 제공합니다.

```lisp
;; 파일이 없으면 그냥 nil을 반환하고 넘어가기
(with-open-file (in "maybe-missing.txt" :if-does-not-exist nil)
  (if in
      (format t "파일 내용: ~a~%" (read-line in))
      (format t "파일이 존재하지 않습니다.~%")))

;; 파일이 있으면 이어서 쓰기(append)
(with-open-file (out "log.txt"
                      :direction :output
                      :if-exists :append
                      :if-does-not-exist :create)
  (format out "~&로그 기록: 작업 완료~%"))
```

`:if-exists :append`와 `:if-does-not-exist :create`를 함께 쓰면, 로그 파일처럼 "있으면 뒤에 이어 붙이고, 없으면 새로 만드는" 흔한 패턴을 구현할 수 있습니다. 이런 옵션들을 상황에 맞게 조합하는 것이 파일 입출력 코드를 안전하게 작성하는 핵심입니다.

## 요약

- Lisp에서 파일은 **스트림**을 통해 다루며, `with-open-file`을 사용하면 블록이 끝날 때 스트림이 자동으로 닫혀 자원 누수를 걱정할 필요가 없습니다.
- 파일에 쓸 때는 `:direction :output`과 `:if-exists`(예: `:supersede`, `:append`) 옵션을, 새 파일 생성을 허용할 때는 `:if-does-not-exist :create`를 함께 지정합니다.
- `write-line`은 문자열 한 줄을 그대로 기록하고, `read-line`은 한 줄을 문자열로 읽어옵니다. `read-line in nil :eof` 형태로 파일 끝을 감지하는 패턴이 널리 쓰입니다.
- `read`는 스트림에서 완전한 S-표현식을 읽어 리스트, 숫자, 심볼 등의 Lisp 데이터로 곧바로 반환하므로, 저장된 데이터를 다시 불러올 때 유용합니다.
- 14장에서 배운 `format`의 지시자는 첫 번째 인자를 `t` 대신 파일 스트림으로 바꾸기만 하면 그대로 파일 출력에 적용됩니다.

## 연습문제

1. `with-open-file`로 자신의 이름과 좋아하는 숫자 세 개를 `my-data.txt`에 한 줄씩 기록한 뒤, 다시 읽어와 화면에 출력해 보세요.
2. `read-line`과 `read`의 차이를 `(1 2 3)`이라는 내용이 담긴 파일을 각각 두 함수로 읽어보며 확인해 보세요.
3. `:if-exists` 옵션을 `:supersede`, `:append`, 지정하지 않은 경우로 각각 바꿔가며 같은 파일에 두 번 쓰기를 시도하고, 결과가 어떻게 달라지는지 관찰해 보세요.
4. 이름과 점수 쌍의 리스트를 `format`으로 표 형태의 파일에 기록하는 프로그램을 작성하고, `~t` 지시자로 열을 정렬해 보세요.
5. 존재하지 않는 파일을 `:if-does-not-exist nil` 옵션으로 열었을 때 반환되는 값을 확인하고, 이를 이용해 "파일이 있으면 읽고 없으면 기본값을 쓰는" 함수를 작성해 보세요.
