# 14장. 문자열과 포맷팅

지금까지 우리는 리스트, 숫자, 심볼 같은 데이터를 다루는 법을 배웠다. 하지만 프로그램이 사람에게 결과를 보여주려면 결국 문자열로 표현해야 한다. 이번 장에서는 Common Lisp의 문자열 기본기를 다지고, 화면 출력의 핵심 도구인 `format` 함수를 익힌다.

## 문자열 리터럴

Common Lisp에서 문자열은 큰따옴표로 감싸 표현한다.

```lisp
* "안녕하세요"
"안녕하세요"

* (type-of "안녕하세요")
(SIMPLE-ARRAY CHARACTER (5))
```

문자열은 사실 문자(character)의 배열이다. 3장에서 배운 것처럼 Common Lisp의 자료형 체계는 서로 촘촘히 연결되어 있는데, 문자열도 예외가 아니다. 문자열 안에서 큰따옴표 자체를 쓰고 싶다면 백슬래시로 이스케이프한다.

```lisp
* "그가 \"안녕\"이라고 말했다"
"그가 \"안녕\"이라고 말했다"
```

문자열은 `aref`나 `char` 함수로 개별 문자에 접근할 수 있다. 인덱스는 0부터 시작한다.

```lisp
* (char "hello" 0)
#\h

* (length "hello")
5
```

## 기본 문자열 함수

### concatenate — 문자열 이어붙이기

여러 문자열을 하나로 합칠 때는 `concatenate`를 쓴다. 이 함수는 문자열 전용이 아니라 시퀀스 전반에 쓰이는 범용 함수라서, 첫 번째 인자로 결과 타입을 명시해야 한다.

```lisp
* (concatenate 'string "안녕, " "Lisp" "!")
"안녕, Lisp!"
```

`'string`은 "결과를 문자열로 만들어라"는 뜻이다. 리스트를 합칠 때는 같은 함수에 `'list`를 넘기면 된다. 시퀀스라는 큰 우산 아래 문자열과 리스트가 같은 도구를 공유한다는 점은 7장에서 리스트 함수를 배울 때 느꼈던 Lisp 특유의 통일성과 맞닿아 있다.

### string-upcase, string-downcase — 대소문자 변환

```lisp
* (string-upcase "hello world")
"HELLO WORLD"

* (string-downcase "HELLO WORLD")
"hello world"
```

이름 그대로다. 원본 문자열은 바뀌지 않고 새 문자열이 만들어져 리턴된다. Common Lisp은 대소문자만 바꾸는 함수 외에도 `string-capitalize`(각 단어의 첫 글자만 대문자로)를 제공한다.

```lisp
* (string-capitalize "common lisp is fun")
"Common Lisp Is Fun"
```

### subseq — 부분 문자열 추출

`subseq`는 문자열(또는 어떤 시퀀스든)의 일부를 잘라낸다.

```lisp
* (subseq "Hello, World!" 0 5)
"Hello"

* (subseq "Hello, World!" 7)
"World!"
```

두 번째 인자는 시작 인덱스, 세 번째 인자는 끝 인덱스(포함하지 않음)다. 세 번째 인자를 생략하면 문자열 끝까지 잘라낸다. 이 함수는 7장에서 배운 리스트의 `subseq`와 동일한 이름, 동일한 규칙을 그대로 따른다.

이 외에도 두 문자열이 같은지 비교하는 `string=`, 부분 문자열의 위치를 찾는 `search`, 공백을 제거하는 `string-trim` 같은 함수들이 있다. 필요할 때마다 하나씩 찾아 쓰면 되지만, 지금 소개한 세 함수만으로도 웬만한 문자열 조작은 다 할 수 있다.

```lisp
* (string= "lisp" "lisp")
T

* (search "World" "Hello, World!")
7

* (string-trim " " "  padded  ")
"padded"
```

## format 함수

문자열을 조합하는 것과 화면에 보기 좋게 출력하는 것은 다른 문제다. Common Lisp에서 이 역할을 맡는 것이 `format`이다.

```lisp
* (format t "안녕, ~a!~%" "세계")
안녕, 세계!
NIL
```

`format`의 첫 번째 인자는 **어디에 출력할지**를 정하는 대상(destination)이다.

- `t`는 표준 출력(화면)을 의미한다.
- `nil`이면 출력하지 않고 대신 결과 문자열을 리턴한다.
- 스트림 객체를 직접 넘길 수도 있다(16장 파일 입출력에서 다시 만난다).

두 번째 인자는 **포맷 문자열**이고, 그 뒤에는 포맷 문자열 안의 지시자(directive)에 대응하는 값들을 순서대로 넘긴다. `~a`처럼 물결표(`~`)로 시작하는 것이 바로 지시자다.

```lisp
* (format nil "안녕, ~a!" "세계")
"안녕, 세계!"
```

`nil`을 대상으로 넘기면 화면에 찍지 않고 조합된 문자열을 그대로 값으로 받을 수 있다. 문자열을 만들어 변수에 저장하거나 다른 함수에 넘기고 싶을 때 이 방식을 즐겨 쓰게 될 것이다.

## 대표적인 포맷 지시자

### ~a — aesthetic, 사람이 읽기 좋은 형태

`~a`는 값을 "사람이 읽기 좋은" 형태로 출력한다. 문자열이면 따옴표 없이, 숫자면 숫자 그대로, 리스트나 심볼도 자연스럽게 출력한다.

```lisp
* (format t "이름: ~a, 나이: ~a~%" "철수" 25)
이름: 철수, 나이: 25
NIL

* (format t "리스트: ~a~%" '(1 2 3))
리스트: (1 2 3)
NIL
```

### ~s — standard, 다시 읽어들일 수 있는 형태

`~s`는 `read`로 다시 읽었을 때 원래 값을 복원할 수 있도록 출력한다. 문자열이라면 따옴표를 포함해서 찍는다는 점이 `~a`와 다르다.

```lisp
* (format t "~a vs ~s~%" "hello" "hello")
hello vs "hello"
NIL
```

디버깅할 때 문자열 안에 숨어 있는 공백이나 특수문자를 눈으로 확인하고 싶다면 `~s`가 유용하다.

### ~d — decimal, 정수 출력

`~d`는 값을 10진 정수로 출력한다. 콤마로 자릿수를 구분하는 등의 옵션도 붙일 수 있다.

```lisp
* (format t "점수: ~d점~%" 95)
점수: 95점
NIL

* (format t "인구: ~:d명~%" 1234567)
인구: 1,234,567명
NIL
```

`~:d`처럼 콜론을 붙이면 천 단위 구분자가 자동으로 들어간다. 이런 세부 옵션은 `~d` 외의 여러 지시자에도 비슷한 방식으로 적용되는 경우가 많다.

### ~% — 줄바꿈

`~%`는 값을 소비하지 않고 그 자리에 개행 문자를 출력한다. 지금까지의 예제에서 계속 등장한 바로 그것이다.

```lisp
* (format t "첫 줄~%둘째 줄~%")
첫 줄
둘째 줄
NIL
```

`~%`는 인자를 받지 않는 지시자라는 점에서 `~a`, `~d`, `~s`와 다르다. 여러 번 반복해서 여러 줄을 띄울 수도 있다: `~2%`는 개행을 두 번 넣으라는 뜻이다.

## format이 강력한 이유

다른 언어에서는 문자열 연결(`+`), 템플릿 리터럴, `printf` 계열 함수, 별도의 포매팅 라이브러리 등 상황에 따라 여러 도구를 오간다. Common Lisp의 `format`은 이 모든 역할을 하나의 함수로 통합한다.

- 화면에 바로 찍을지(`t`), 문자열로 받을지(`nil`), 파일에 쓸지(스트림)를 대상 하나로 결정한다.
- 지시자 하나하나가 작은 미니 언어를 이루어, 반복 출력(`~{~a~^, ~}`처럼 리스트를 순회하며 구분자를 넣는 것), 조건부 출력, 열 맞추기, 진법 변환까지 문자열 조작 없이 처리할 수 있다.
- 포맷 문자열 자체가 데이터이므로, 다국어 메시지나 리포트 템플릿처럼 출력 형식을 별도로 관리하기에도 좋다.

간단한 예로 리스트를 쉼표로 구분해 출력하는 지시자를 보자.

```lisp
* (format t "장바구니: ~{~a~^, ~}~%" '("사과" "바나나" "포도"))
장바구니: 사과, 바나나, 포도
NIL
```

`~{ ~}`는 리스트를 순회하고, `~^`는 마지막 원소를 제외하고 구분자를 넣으라는 뜻이다. 이런 반복 지시자는 17장에서 배울 반복 매크로(`loop`, `dolist`)와 목적은 다르지만 "반복해서 무언가를 만든다"는 감각은 비슷하다.

## 3장의 데이터 타입을 문자열로 표현하기

3장에서 배운 정수, 실수, 심볼, 리스트, 불리언 값을 `format`으로 표현해보면서 이번 장을 마무리하자.

```lisp
(defun describe-value (v)
  (format nil "값: ~s, 타입: ~a" v (type-of v)))
```

```lisp
* (describe-value 42)
"값: 42, 타입: (INTEGER 0 4611686018427387903)"

* (describe-value 3.14)
"값: 3.14, 타입: SINGLE-FLOAT"

* (describe-value 'hello)
"값: HELLO, 타입: SYMBOL"

* (describe-value '(1 2 3))
"값: (1 2 3), 타입: CONS"

* (describe-value t)
"값: T, 타입: (MEMBER T)"

* (describe-value nil)
"값: NIL, 타입: NULL"
```

`~s`를 쓴 이유는 값을 다시 읽어들일 수 있는 정확한 표현으로 보여주고 싶었기 때문이다. 만약 문자열 값을 이 함수에 넣는다면 `~a`와의 차이가 뚜렷이 드러난다.

```lisp
* (describe-value "hello")
"값: \"hello\", 타입: (SIMPLE-ARRAY CHARACTER (5))"
```

문자열 주위에 따옴표가 그대로 보존되어, 이 값이 문자열이라는 것을 문자열 자체의 표현만으로도 알 수 있다. 이렇게 `format`과 몇 가지 지시자만 익혀두면, 3장에서 배운 어떤 데이터 타입이든 사람이 읽기 좋은 형태로도, 기계가 다시 읽을 수 있는 형태로도 자유롭게 출력할 수 있다.

## 요약

- 문자열은 문자의 배열이며, 큰따옴표로 리터럴을 표현하고 `char`, `length`로 개별 문자와 길이에 접근한다.
- `concatenate`, `string-upcase`/`string-downcase`, `subseq`는 문자열을 조합하고 변형하는 기본 도구다. `concatenate`는 결과 타입을 첫 인자로 지정해야 하는 범용 시퀀스 함수다.
- `format`은 대상(`t`, `nil`, 스트림), 포맷 문자열, 인자들로 이루어지며 하나의 함수로 화면 출력과 문자열 생성을 모두 처리한다.
- `~a`는 사람이 읽기 좋은 출력, `~s`는 다시 읽어들일 수 있는 출력, `~d`는 정수 출력, `~%`는 줄바꿈을 담당하는 대표적인 지시자다.
- `format`의 반복·조건 지시자를 이용하면 별도의 문자열 조작 없이도 복잡한 출력 형식을 하나의 포맷 문자열 안에서 표현할 수 있다.

## 연습문제

1. 이름과 나이를 받아 `"이름은 철수이고, 나이는 25살입니다."` 형태의 문자열을 `format`의 `nil` 대상을 이용해 리턴하는 `introduce` 함수를 작성하라.
2. 문자열 리스트를 받아 각 문자열을 대문자로 바꾸고 `concatenate`로 하나의 문자열에 공백을 넣어 이어붙이는 `shout-all` 함수를 작성하라. (예: `("hello" "world")` → `"HELLO WORLD"`)
3. 정수 리스트를 받아 `~{~a~^, ~}` 지시자를 이용해 쉼표로 구분된 문자열로 만드는 `numbers-to-string` 함수를 작성하라. (예: `(1 2 3)` → `"1, 2, 3"`)
4. `describe-value` 함수를 확장하여, 값이 문자열일 때는 `subseq`로 앞 3글자만 잘라 함께 보여주도록 수정하라. 단, 문자열 길이가 3보다 짧을 때는 전체 문자열을 보여줘야 한다.
5. `~:d` 지시자를 이용해 임의의 정수를 받아 천 단위 구분 콤마가 들어간 문자열로 리턴하는 `format-with-commas` 함수를 작성하고, 음수에 대해서도 잘 동작하는지 REPL에서 확인하라.
