# Lisp 기초부터 응용까지

[다음: 1장. Lisp란 무엇인가 ▶](ch01-lisp란.md)

---

프로그래밍 경험은 있지만 Lisp 계열 언어는 처음 접하는 사람을 위한 입문서입니다. "Lisp"는 여러
방언이 있는 언어 계열이므로, 이 책은 **Common Lisp**(SBCL 등의 처리기로 실행 가능)를 기준으로
합니다. S-표현식과 기본 문법부터 재귀, 고차 함수, 클로저, 매크로, CLOS, 조건 시스템까지
Common Lisp의 핵심 개념을 순서대로 다룹니다.

각 장은 개념 설명, REPL 예제, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는 이해를 돕는
다이어그램을 함께 실었습니다.
