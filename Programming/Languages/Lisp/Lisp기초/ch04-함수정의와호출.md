# 4장. 함수 정의(defun)와 호출

[◀ 이전: 3장. 기본 문법과 데이터 타입](ch03-기본문법과데이터타입.md) | [📖 목차](00-목차.md) | [다음: 5장. 조건문 ▶](ch05-조건문.md)

3장에서 `(+ 1 2)`처럼 이미 만들어진 함수를 호출해 보았습니다. 이번 장에서는 여러분만의 함수를 직접 정의하는 방법을 배웁니다. Lisp에서 함수를 만드는 일은 매우 자연스러운 과정입니다. 함수 이름을 짓고, 매개변수를 나열하고, 그 매개변수로 무엇을 계산할지 적기만 하면 됩니다.

## `defun`으로 함수 정의하기

함수를 정의하는 기본 형태는 다음과 같습니다.

```lisp
(defun 함수이름 (매개변수...)
  본문)
```

간단한 예로, 숫자를 제곱하는 함수를 만들어 봅시다.

```lisp
* (defun square (x)
    (* x x))
=> SQUARE

* (square 5)
=> 25

* (square 12)
=> 144
```

`defun`은 "define function"의 줄임말입니다. `square`는 함수 이름, `(x)`는 매개변수 목록, `(* x x)`는 함수의 본문입니다. 함수를 정의하면 REPL은 함수 이름을 대문자 심볼로 돌려주는데, 이는 이제 `square`라는 이름이 함수로 등록되었다는 뜻입니다.

함수 이름도 변수 이름과 마찬가지로 kebab-case로 짓는 것이 관례입니다.

```lisp
* (defun celsius-to-fahrenheit (celsius)
    (+ (* celsius 9/5) 32))
=> CELSIUS-TO-FAHRENHEIT

* (celsius-to-fahrenheit 100)
=> 212
```

매개변수를 여러 개 받는 함수도 같은 방식으로 정의합니다.

```lisp
* (defun rectangle-area (width height)
    (* width height))
=> RECTANGLE-AREA

* (rectangle-area 3 4)
=> 12
```

## 반환값: 마지막 표현식이 곧 결과

Lisp 함수에는 `return`이라는 키워드가 따로 필요 없습니다. 함수 본문에 여러 표현식을 나열하면 그것들이 차례로 평가되고, **가장 마지막에 평가된 표현식의 값이 함수의 반환값**이 됩니다.

```lisp
* (defun greet (name)
    (format t "인사를 준비합니다...~%")
    (format t "안녕하세요, ~a님!~%" name)
    (concatenate 'string "안녕, " name))
=> GREET

* (greet "지훈")
인사를 준비합니다...
안녕하세요, 지훈님!
=> "안녕, 지훈"
```

`format` 호출 두 번은 화면에 무언가를 출력할 뿐이고, 함수가 최종적으로 돌려주는 값은 마지막 줄 `(concatenate 'string "안녕, " name)`의 결과인 문자열입니다. `format`과 문자열 다루기는 14장에서 본격적으로 배우니, 지금은 "여러 줄을 순서대로 실행하다가 마지막 값만 반환한다"는 규칙에 집중하면 됩니다.

이 규칙 덕분에 조건문(5장)이나 `let`(6장)처럼 값을 만들어내는 다른 구문들과 함수를 자연스럽게 조합할 수 있습니다. 예를 들어 절댓값을 구하는 함수를 `if`로 작성하면 이렇습니다.

```lisp
* (defun my-abs (n)
    (if (< n 0)
        (- n)
        n))
=> MY-ABS

* (my-abs -7)
=> 7

* (my-abs 7)
=> 7
```

`if` 표현식 자체가 조건에 따라 값을 만들어내고, 그 값이 바로 함수의 마지막(이자 유일한) 표현식이므로 함수의 반환값이 됩니다.

## `&optional`: 선택적 인자

지금까지 정의한 함수는 매개변수 개수를 정확히 맞춰서 호출해야 합니다. 하지만 때로는 "인자를 안 주면 기본값을 쓰겠다"는 함수가 필요합니다. 이럴 때 `&optional`을 사용합니다.

```lisp
* (defun greet (name &optional (greeting "안녕하세요"))
    (format nil "~a, ~a님!" greeting name))
=> GREET

* (greet "수민")
=> "안녕하세요, 수민님!"

* (greet "수민" "반갑습니다")
=> "반갑습니다, 수민님!"
```

`&optional` 뒤에 오는 매개변수들은 호출 시 생략할 수 있습니다. `(greeting "안녕하세요")`처럼 괄호로 묶어 기본값을 지정할 수 있고, 기본값을 생략하면 인자를 주지 않았을 때 `nil`이 들어갑니다.

```lisp
* (defun describe-item (name &optional price)
    (if price
        (format nil "~a: ~a원" name price)
        (format nil "~a: 가격 미정" name)))
=> DESCRIBE-ITEM

* (describe-item "사과")
=> "사과: 가격 미정"

* (describe-item "사과" 1500)
=> "사과: 1500원"
```

`&optional` 매개변수는 여러 개 나열할 수 있으며, 반드시 필수 매개변수 뒤에 위치해야 합니다.

```lisp
* (defun make-range-label (start &optional (end 10) (step 1))
    (format nil "~a부터 ~a까지 (간격 ~a)" start end step))
=> MAKE-RANGE-LABEL

* (make-range-label 0)
=> "0부터 10까지 (간격 1)"

* (make-range-label 0 100)
=> "0부터 100까지 (간격 1)"

* (make-range-label 0 100 5)
=> "0부터 100까지 (간격 5)"
```

## `&rest`: 개수를 정하지 않은 나머지 인자

함수가 몇 개의 인자를 받을지 미리 정할 수 없는 경우도 있습니다. 이럴 때는 `&rest`를 사용해 나머지 인자를 하나의 리스트로 모두 받을 수 있습니다.

```lisp
* (defun sum-all (&rest numbers)
    (apply #'+ numbers))
=> SUM-ALL

* (sum-all 1 2 3)
=> 6

* (sum-all 1 2 3 4 5)
=> 15

* (sum-all)
=> 0
```

`&rest numbers`라고 쓰면, 호출할 때 넘긴 인자들이 몇 개든 상관없이 모두 `numbers`라는 하나의 리스트로 묶여 들어옵니다. 위 예제에서 `apply`는 리스트에 담긴 값들을 함수에 낱개 인자로 풀어서 전달하는 함수인데, `(apply #'+ '(1 2 3))`은 `(+ 1 2 3)`을 호출한 것과 같은 효과를 냅니다. `#'`은 함수 자체를 값으로 참조하는 표기법으로, 9장 고차함수에서 자세히 다룹니다.

`&rest`는 필수 매개변수, `&optional` 매개변수 뒤에 올 수 있습니다.

```lisp
* (defun log-message (level &rest details)
    (format nil "[~a] ~{~a~^ ~}" level details))
=> LOG-MESSAGE

* (log-message :info "서버" "시작됨")
=> "[INFO] 서버 시작됨"

* (log-message :error "연결" "실패" "재시도" "중")
=> "[ERROR] 연결 실패 재시도 중"
```

여기서 `level` 자리에 키워드 `:info`, `:error`를 넘기고 있는데, 이는 3장에서 배운 키워드가 "상태 값"을 표현하는 전형적인 쓰임입니다. `~{...~}`나 `~^` 같은 포맷 지시어의 정확한 의미는 14장에서 다루니 지금은 몰라도 괜찮습니다.

## 독스트링(docstring) 작성하기

함수 정의 바로 다음 줄에 문자열을 하나 적으면, 그 문자열은 함수의 설명서 역할을 하는 **독스트링**이 됩니다.

```lisp
* (defun square (x)
    "숫자 X를 제곱한 값을 반환한다."
    (* x x))
=> SQUARE

* (documentation 'square 'function)
=> "숫자 X를 제곱한 값을 반환한다."
```

독스트링은 함수의 동작에 아무런 영향을 주지 않지만, `describe`나 `documentation` 같은 도구로 나중에 조회할 수 있어 협업하는 코드베이스에서 매우 유용합니다. 관례적으로 다음 사항을 지킵니다.

- 한 문장으로 함수가 "무엇을" 하는지 설명하고 마침표로 끝냅니다.
- 매개변수를 문장 안에서 언급할 때는 대문자로 씁니다 (`X`, `NAME`처럼).
- 부수 효과(화면 출력, 파일 쓰기 등)가 있다면 언급해 줍니다.

```lisp
* (defun celsius-to-fahrenheit (celsius)
    "섭씨 온도 CELSIUS를 화씨 온도로 변환하여 반환한다."
    (+ (* celsius 9/5) 32))
=> CELSIUS-TO-FAHRENHEIT
```

독스트링은 매개변수 목록 바로 다음, 본문이 시작되기 전에 위치해야 하며, 함수 본문에 표현식이 하나도 없이 문자열만 있는 경우에는 그 문자열이 독스트링이 아니라 반환값으로 취급되니 주의하세요.

```lisp
* (defun just-a-string ()
    "이건 독스트링이 아니라 반환값입니다")
=> JUST-A-STRING

* (just-a-string)
=> "이건 독스트링이 아니라 반환값입니다"
```

## 함수 호출 문법 다시 보기: 산술도 결국 함수 호출이다

3장에서 `(+ 1 2)`가 전위 표기법으로 쓰인 함수 호출이라고 배웠습니다. 이제 여러분이 직접 함수를 정의해 보았으니, 이 사실이 훨씬 더 분명하게 다가올 것입니다. `square`를 호출하는 것과 `+`를 호출하는 것은 문법적으로 전혀 다르지 않습니다.

```lisp
* (square 5)
=> 25

* (+ 5 5)
=> 10
```

`square`와 `+`는 둘 다 "괄호를 열고, 함수 이름을 적고, 인자를 나열한다"는 똑같은 규칙을 따릅니다. 여러분이 만든 함수와 Lisp가 기본으로 제공하는 `+`, `*`, `list` 같은 함수 사이에는 문법적 특권 차이가 전혀 없습니다. 이것이 바로 Lisp 문법의 단순함이 주는 힘입니다. 새로운 문법 규칙을 배울 필요 없이, 함수를 정의하는 순간 그 함수는 언어에 원래 있던 함수들과 완전히 동등한 자격으로 코드 어디서든 호출될 수 있습니다.

함수를 여러 개 조합해서 호출하는 것도 낯설지 않을 것입니다.

```lisp
* (defun average (a b)
    (/ (+ a b) 2))
=> AVERAGE

* (square (average 4 6))
=> 25
```

`(average 4 6)`이 먼저 평가되어 `5`가 되고, 그 값이 `square`의 인자로 전달되어 최종적으로 `25`가 나옵니다. 함수 호출이 겹겹이 중첩되는 이 방식은 6장에서 배울 `let`을 이용한 지역 바인딩, 7장의 리스트 처리, 8장의 재귀에서도 계속 반복되는 Lisp의 기본 리듬입니다.

## 요약

- `defun`은 `(defun 이름 (매개변수...) 본문)` 형태로 함수를 정의하며, 함수 본문의 마지막 표현식 값이 자동으로 반환값이 됩니다.
- `&optional`을 사용하면 생략 가능한 매개변수를, 필요하면 기본값과 함께 선언할 수 있습니다.
- `&rest`를 사용하면 개수가 정해지지 않은 인자들을 하나의 리스트로 모아 받을 수 있습니다.
- 매개변수 목록 바로 다음에 문자열을 적으면 독스트링이 되며, `documentation`으로 조회할 수 있습니다. 본문이 그 문자열뿐이라면 독스트링이 아니라 반환값으로 취급됩니다.
- 사용자가 정의한 함수와 `+`, `*` 같은 내장 함수는 문법적으로 완전히 동등하며, 모두 `(함수이름 인자...)`라는 동일한 전위 표기법 호출 규칙을 따릅니다.
