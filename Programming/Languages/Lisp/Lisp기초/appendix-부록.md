이 부록은 책 전체에서 등장한 함수와 특수 형식·매크로를 한눈에 찾아볼 수 있도록 정리한 자료입니다. 처음 읽을 때보다는, 코드를 작성하다가 "그 함수 이름이 뭐였더라"할 때 사전처럼 펼쳐보는 용도로 활용하기 바랍니다.

## 자주 쓰는 함수 치트시트

### 리스트 함수 (7장, 8장, 9장)

| 함수 | 설명 | 예시 |
|---|---|---|
| `cons` | 두 값으로 새 쌍(리스트의 한 칸)을 만든다 | `(cons 1 '(2 3))` → `(1 2 3)` |
| `car` | 리스트의 첫 원소를 꺼낸다 | `(car '(1 2 3))` → `1` |
| `cdr` | 리스트의 첫 원소를 뺀 나머지를 꺼낸다 | `(cdr '(1 2 3))` → `(2 3)` |
| `list` | 인자들을 모아 새 리스트를 만든다 | `(list 1 2 3)` → `(1 2 3)` |
| `append` | 여러 리스트를 이어 붙인다 | `(append '(1 2) '(3 4))` → `(1 2 3 4)` |
| `reverse` | 리스트의 순서를 뒤집는다 | `(reverse '(1 2 3))` → `(3 2 1)` |
| `length` | 리스트(또는 시퀀스)의 길이를 구한다 | `(length '(1 2 3))` → `3` |
| `nth` | n번째(0부터 시작) 원소를 꺼낸다 | `(nth 1 '(a b c))` → `B` |
| `member` | 리스트에 값이 있으면 그 지점부터의 리스트를 반환한다 | `(member 2 '(1 2 3))` → `(2 3)` |
| `null` | 빈 리스트(nil)인지 검사한다 | `(null '())` → `T` |
| `mapcar` | 리스트의 각 원소에 함수를 적용해 새 리스트를 만든다 | `(mapcar #'1+ '(1 2 3))` → `(2 3 4)` |
| `remove-if` | 조건을 만족하는 원소를 제거한 새 리스트를 만든다 | `(remove-if #'evenp '(1 2 3 4))` → `(1 3)` |
| `find-if` | 조건을 만족하는 첫 원소를 찾는다 | `(find-if #'evenp '(1 3 4 5))` → `4` |
| `reduce` | 리스트 전체를 하나의 값으로 접는다 | `(reduce #'+ '(1 2 3 4))` → `10` |
| `sort` | 리스트를 정렬한다(원본이 파괴될 수 있음에 주의) | `(sort '(3 1 2) #'<)` → `(1 2 3)` |

### 문자열 함수 (14장)

| 함수 | 설명 | 예시 |
|---|---|---|
| `string=` | 두 문자열의 내용이 같은지 비교한다 | `(string= "abc" "abc")` → `T` |
| `string-upcase` | 문자열을 대문자로 바꾼 새 문자열을 만든다 | `(string-upcase "abc")` → `"ABC"` |
| `string-downcase` | 문자열을 소문자로 바꾼 새 문자열을 만든다 | `(string-downcase "ABC")` → `"abc"` |
| `concatenate` | 여러 문자열(또는 시퀀스)을 이어 붙인다 | `(concatenate 'string "a" "b")` → `"ab"` |
| `subseq` | 문자열의 일부분을 잘라낸다 | `(subseq "hello" 1 3)` → `"el"` |
| `string-trim` | 양 끝의 지정한 문자들을 제거한다 | `(string-trim " " "  hi  ")` → `"hi"` |
| `search` | 부분 문자열의 위치를 찾는다 | `(search "lo" "hello")` → `3` |
| `format` | 형식 문자열에 값을 채워 출력하거나 문자열을 만든다 | `(format nil "~A개" 3)` → `"3개"` |
| `parse-integer` | 문자열을 정수로 변환한다 | `(parse-integer "42")` → `42` |
| `princ-to-string` | 임의의 값을 사람이 읽기 좋은 문자열로 바꾼다 | `(princ-to-string 42)` → `"42"` |

### 수치 연산 함수 (3장, 8장)

| 함수 | 설명 | 예시 |
|---|---|---|
| `+`, `-`, `*`, `/` | 사칙연산 | `(+ 1 2 3)` → `6` |
| `mod` | 나머지를 구한다(부호는 나누는 수를 따름) | `(mod -7 3)` → `2` |
| `rem` | 나머지를 구한다(부호는 나뉘는 수를 따름) | `(rem -7 3)` → `-1` |
| `1+`, `1-` | 1을 더하거나 뺀다 | `(1+ 5)` → `6` |
| `incf`, `decf` | 변수의 값을 1(또는 지정한 만큼) 늘리거나 줄인다 | `(incf x)` |
| `expt` | 거듭제곱을 구한다 | `(expt 2 10)` → `1024` |
| `sqrt` | 제곱근을 구한다 | `(sqrt 16)` → `4.0` |
| `abs` | 절댓값을 구한다 | `(abs -5)` → `5` |
| `max`, `min` | 최댓값·최솟값을 구한다 | `(max 3 7 2)` → `7` |
| `zerop`, `plusp`, `minusp` | 0인지, 양수인지, 음수인지 검사한다 | `(zerop 0)` → `T` |
| `evenp`, `oddp` | 짝수인지 홀수인지 검사한다 | `(evenp 4)` → `T` |
| `floor`, `ceiling`, `round` | 내림, 올림, 반올림한다 | `(round 3.6)` → `4` |

## 특수 형식과 매크로 요약표

| 형식 | 설명 | 관련 장 |
|---|---|---|
| `defun` | 함수를 정의한다 | 4장 |
| `if` | 조건 하나를 검사해 둘 중 하나의 식을 평가한다 | 5장 |
| `cond` | 여러 조건을 순서대로 검사해 처음 참인 절을 평가한다 | 5장 |
| `when` | 조건이 참일 때만 여러 식을 순서대로 실행한다 | 5장 |
| `unless` | 조건이 거짓일 때만 여러 식을 순서대로 실행한다 | 5장 |
| `let` | 서로 독립적으로 평가되는 지역 변수들을 한 번에 바인딩한다 | 6장 |
| `let*` | 앞서 바인딩한 변수를 뒤 변수의 초깃값 계산에 사용할 수 있게 순차적으로 바인딩한다 | 6장 |
| `lambda` | 이름 없는 함수를 만든다 | 9장, 10장 |
| `defmacro` | 매크로를 정의한다 | 11장 |
| `quote` (`'`) | 식을 평가하지 않고 데이터 그대로 다룬다 | 1장, 3장 |
| `` ` `` (백쿼트)와 `,`, `,@` | 매크로 안에서 코드 템플릿을 만들 때 값을 부분적으로 끼워 넣는다 | 11장 |
| `defstruct` | 구조체 타입을 정의한다 | 12장 |
| `defclass`, `defmethod` | CLOS 클래스와 메서드를 정의한다 | 12장 |
| `handler-case` | 조건(에러)이 발생했을 때 처리할 방법을 지정한다 | 13장 |
| `defpackage`, `in-package` | 패키지를 정의하고 현재 패키지를 전환한다 | 15장 |
| `with-open-file` | 파일을 열고, 블록이 끝나면 자동으로 닫는다 | 16장 |
| `dotimes` | 정해진 횟수만큼 반복한다 | 17장 |
| `dolist` | 리스트의 각 원소를 순서대로 순회한다 | 17장 |
| `loop` | `for`, `collect`, `sum`, `when` 등의 절을 조합하는 범용 반복 매크로 | 17장 |

## 더 찾아볼 자료

이 책은 Common Lisp의 기초를 다지는 데 초점을 맞추었기 때문에, 다루지 않은 함수나 세부 규칙이 훨씬 많이 남아 있습니다. 앞으로 더 깊이 있는 내용이 필요할 때는 다음과 같은 유형의 자료를 참고하는 것을 권합니다.

- **언어 표준 문서(HyperSpec)**: Common Lisp는 ANSI 표준으로 규정된 언어이며, 이 표준 전체를 웹에서 검색 가능한 형태로 정리한 문서가 "Common Lisp HyperSpec"이라는 이름으로 널리 쓰입니다. 특정 함수나 매크로의 정확한 인자 순서, 반환값의 세부 규칙이 궁금할 때 가장 신뢰할 수 있는 1차 자료입니다. 대부분의 처리기 개발 환경에는 커서가 위치한 심볼의 HyperSpec 항목을 바로 열어주는 단축 기능이 마련되어 있으니 찾아 활용해 보세요.
- **처리기(구현체) 공식 문서**: 이 책에서 사용한 SBCL을 포함해 각 Common Lisp 처리기는 표준에서 정하지 않은 확장 기능(스레드, 외부 라이브러리 연동, 컴파일러 옵션 등)을 자체 문서로 제공합니다. 표준 문법만으로 해결되지 않는 문제를 만났다면 사용 중인 처리기의 공식 문서를 확인해 보세요.
- **패키지 저장소와 라이브러리 목록**: 15장에서 다룬 패키지 시스템 위에서, 커뮤니티가 만든 다양한 라이브러리를 모아놓은 저장소들이 존재합니다. 웹 서버, 데이터베이스 연동, 테스트 프레임워크 등 이 책에서 다루지 않은 실전 기능이 필요할 때 검색해 보면 이미 만들어진 도구를 찾을 수 있는 경우가 많습니다.
- **커뮤니티 채널**: 오래된 언어인 만큼 온라인 포럼, 채팅 커뮤니티, 메일링 리스트 등에 축적된 논의가 풍부합니다. 특정 에러 메시지나 관용구가 낯설게 느껴질 때, 비슷한 질문을 이미 다룬 논의를 찾아보는 것도 좋은 학습 방법입니다.
- **처리기에 내장된 문서화 함수**: `describe`, `documentation`, `apropos` 같은 함수는 REPL을 벗어나지 않고도 심볼에 대한 정보를 즉시 확인하게 해 줍니다. 예를 들어 `(describe 'loop)`나 `(apropos "STRING")`처럼 사용하면 관련 정보나 이름이 비슷한 심볼 목록을 바로 확인할 수 있습니다. 외부 자료를 찾기 전에 먼저 시도해 볼 만한 습관입니다.

무엇을 찾아보든, 이 책에서 반복해서 강조한 태도, 즉 REPL을 열어두고 직접 식을 평가하며 확인하는 습관이 가장 확실한 학습 도구라는 점은 변하지 않습니다.
