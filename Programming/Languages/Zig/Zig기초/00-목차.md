프로그래밍을 처음 접하는 사람과 다른 언어 경험자를 모두 아우르는 Zig 입문서입니다.
변수와 자료형 같은 기초 문법부터 Zig의 정체성이라 할 수 있는 명시적 메모리 관리,
에러 유니온, comptime 메타프로그래밍까지 순서대로 다룹니다.

각 장은 개념 설명, 실행 예시, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는 이해를 돕는
다이어그램을 함께 실었습니다.

## 학습 방법 제안

1. 각 장의 예제 코드를 직접 `zig run`이나 `zig build run`으로 실행하며 결과를 확인하세요.
2. 장 끝의 연습문제를 풀어보면서 이해도를 점검하세요.
3. 11장(에러 처리), 14장(comptime), 15장(Allocator)은 Zig의 정체성과 직결되는 내용이므로 특히 꼼꼼히 읽어보세요.
4. 18장까지 마친 뒤에는 부록의 요약표를 필요할 때마다 참조용으로 활용하세요.
