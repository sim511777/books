# 부록

이 부록은 본문에서 다루지 않은 실용적인 정보를 모아 둔 참고 자료입니다. Zig를 설치하는 방법, 이 책에서 사용한 주요 키워드와 문법을 한눈에 볼 수 있는 표, 더 공부할 때 참고할 만한 자료, 그리고 이 책 이후의 학습 방향을 정리합니다.

## Zig 설치하기

### 공식 사이트에서 바이너리 받기

Zig는 별도의 설치 프로그램 없이, 컴파일된 바이너리를 압축 파일 형태로 내려받아 압축을 풀기만 하면 바로 사용할 수 있습니다. 공식 홈페이지(ziglang.org)의 다운로드 페이지에는 플랫폼별로 다음과 같은 파일들이 올라와 있습니다.

- Windows용: `zig-windows-x86_64-<버전>.zip`
- macOS용(Intel): `zig-macos-x86_64-<버전>.tar.xz`
- macOS용(Apple Silicon): `zig-macos-aarch64-<버전>.tar.xz`
- Linux용: `zig-linux-x86_64-<버전>.tar.xz` (ARM 등 다른 아키텍처용 파일도 별도로 제공됩니다)

다운로드 페이지에는 안정적으로 유지되는 정식 릴리스 버전과, 매일 새로 빌드되는 최신 개발 버전(master)이 함께 안내되어 있습니다. 처음 Zig를 배우는 단계에서는 정식 릴리스 버전을 받는 것이 안전합니다. 개발 버전은 문법이나 표준 라이브러리 API가 예고 없이 바뀔 수 있기 때문입니다.

### 플랫폼별 설치 절차 요약

**Windows**

1. 다운로드 페이지에서 `zig-windows-x86_64-<버전>.zip` 파일을 받습니다.
2. 원하는 위치(예: `C:\zig`)에 압축을 풀어 둡니다. 압축을 풀면 그 안에 `zig.exe`와 관련 파일들이 들어 있습니다.
3. 그 폴더 경로를 시스템 환경 변수 `PATH`에 추가합니다. 그러면 어떤 폴더에서 터미널을 열어도 `zig` 명령을 바로 사용할 수 있습니다.

**macOS / Linux**

1. 다운로드 페이지에서 자신의 CPU 아키텍처에 맞는 `.tar.xz` 파일을 받습니다.
2. 원하는 위치에 압축을 풉니다(예: `tar -xf zig-macos-aarch64-<버전>.tar.xz -C ~/zig`).
3. 압축을 푼 폴더의 경로를 셸 설정 파일(`.zshrc`, `.bashrc` 등)의 `PATH`에 추가합니다.

두 경우 모두 마지막 확인 단계는 동일합니다. 새 터미널을 열고 다음 명령을 실행해 설치된 버전이 올바르게 나오는지 확인합니다.

```bash
zig version
```

### 여러 버전을 관리하기: zigup

Zig는 아직 빠르게 발전하고 있는 언어라서, 프로젝트마다 서로 다른 버전의 Zig를 요구하는 경우가 흔합니다. 매번 공식 사이트에서 파일을 받아 압축을 풀고 `PATH`를 바꾸는 과정을 반복하는 대신, `zigup`이라는 커뮤니티 도구를 사용하면 여러 버전의 Zig를 설치해 두고 필요할 때 명령 한 줄로 전환할 수 있습니다. `zigup`은 Zig 공식 배포판에 포함된 도구는 아니며 별도로 설치해야 하는 커뮤니티 프로젝트이므로, 이름을 기억해 두고 필요할 때 검색해서 설치 방법을 확인하는 것을 권합니다. 여러 프로젝트를 넘나들며 작업하게 되는 시점부터는 이런 버전 관리 도구가 실질적인 편의를 줍니다.

## 이 책에서 사용한 주요 키워드와 문법 요약

아래 표는 본문에서 등장한 순서를 대략적인 기준으로 삼아, 키워드와 문법 요소의 의미를 간단히 정리한 것입니다. 더 자세한 설명은 표에 적힌 장을 참고하세요.

| 키워드 / 문법 | 의미 | 관련 장 |
|---|---|---|
| `const` | 재대입할 수 없는 불변 바인딩 선언 | 3장 |
| `var` | 재대입할 수 있는 가변 바인딩 선언 | 3장 |
| `undefined` | 아직 초기화되지 않은 상태를 명시하는 값 | 3장 |
| `if` / `else` | 조건 분기 | 5장 |
| `switch` | 값에 따른 다중 분기, 모든 경우를 다루도록 강제 | 5장 |
| `while` | 조건 기반 반복문 | 6장 |
| `for` | 배열, 슬라이스 등을 순회하는 반복문 | 6장 |
| `break` / `continue` | 반복문 중단 / 다음 반복으로 건너뛰기 | 6장 |
| `fn` | 함수 정의 | 7장 |
| `pub` | 다른 파일에서 접근할 수 있도록 공개 | 7장 |
| `*T` / `[*]T` | 단일 항목 포인터 / 크기를 모르는 다중 항목 포인터 | 8장 |
| `[N]T` | 크기가 고정된 배열 타입 | 8장 |
| `struct` | 여러 필드를 묶는 구조체 타입 정의 | 9장 |
| `?T` | 값이 있거나 없을 수 있음을 나타내는 옵셔널 타입 | 10장 |
| `orelse` | 옵셔널이 `null`일 때 대체값을 제공 | 10장 |
| `if (opt) |v|` | 옵셔널을 언랩하며 값에 이름을 붙이는 구문 | 10장 |
| `error` | 에러 집합을 정의하는 키워드 | 11장 |
| `!T` | 에러이거나 `T` 값일 수 있는 에러 유니온 타입 | 11장 |
| `try` | 에러가 나면 즉시 호출자에게 전파 | 11장 |
| `catch` | 에러를 그 자리에서 처리하거나 대체값 제공 | 11장 |
| `defer` | 현재 스코프를 벗어날 때(정상/비정상 모두) 실행할 코드 예약 | 12장 |
| `errdefer` | 현재 스코프를 에러로 벗어날 때만 실행할 코드 예약 | 12장 |
| `[]T` | 길이 정보를 함께 가지는 슬라이스 타입 | 13장 |
| `comptime` | 컴파일 시점에 값이나 코드를 확정 | 14장 |
| `anytype` | 컴파일 시점에 실제 타입이 결정되는 매개변수 타입 | 14장 |
| `std.mem.Allocator` | 메모리 할당 전략을 표현하는 표준 인터페이스 | 15장 |
| `enum` | 정해진 값들 중 하나를 나타내는 열거형 타입 | 16장 |
| `union` / `union(enum)` | 여러 타입 중 하나를 담는 유니온, 태그가 붙은 유니온 | 16장 |
| `pub fn build(b: *std.Build) void` | `build.zig`의 진입점이 되는 빌드 함수 | 17장 |
| `test "설명" { ... }` | 언어에 내장된 테스트 블록 | 18장 |

## 참고할 만한 자료

이 책은 Zig 언어의 기초를 다루는 입문서이며, 언어와 표준 라이브러리의 모든 세부사항을 담고 있지는 않습니다. 더 깊이 알아보고 싶을 때는 다음 자료들을 참고하는 것을 권합니다. 아래 이름들은 실제로 클릭할 수 있는 링크가 아니라, 검색해서 찾아갈 수 있도록 이름만 텍스트로 남겨 둔 것입니다.

- **ziglang.org**: Zig 공식 홈페이지입니다. 다운로드, 공식 문서(Language Reference), 학습 자료 링크를 모두 이곳에서 찾을 수 있습니다.
- **Zig 언어 레퍼런스(Language Reference)**: 공식 홈페이지에서 제공하는 문서로, 언어의 모든 문법 요소를 빠짐없이 정리한 참고 문서입니다. 이 책을 읽고 나서 특정 문법의 정확한 세부 규칙이 궁금할 때 찾아보기 좋습니다.
- **표준 라이브러리 문서**: Zig 컴파일러 배포판에는 표준 라이브러리 소스 코드 자체가 훌륭한 문서 역할을 합니다. `std` 모듈 아래의 각 파일에 달린 주석을 직접 읽어 보는 것도 유용한 학습 방법입니다.
- **Ziggit**: Zig 커뮤니티가 운영하는 포럼으로, 질문과 답변, 공지사항, 프로젝트 공유 글을 찾을 수 있습니다.
- **Zig 공식 Discord 서버**: 실시간으로 다른 Zig 사용자나 언어 개발자와 소통할 수 있는 공간입니다.
- **Zig 컴파일러 GitHub 저장소**: 언어와 컴파일러 자체의 소스 코드가 공개되어 있는 저장소입니다. 이슈 트래커를 살펴보면 언어가 현재 어떤 방향으로 발전하고 있는지 파악할 수 있습니다.

## 다음 학습 단계

이 책을 마친 뒤에는 다음과 같은 순서로 학습을 이어가는 것을 제안합니다.

1. **작은 프로젝트를 직접 만들어 보기**: 명령줄 도구, 간단한 텍스트 처리 프로그램, 자료구조 라이브러리처럼 범위가 작고 명확한 프로젝트를 하나 골라 처음부터 끝까지 완성해 봅니다. 이 과정에서 이 책에서 배운 개념들이 실제로 어떻게 맞물려 쓰이는지 몸에 익힐 수 있습니다.
2. **표준 라이브러리의 다른 모듈 탐구하기**: `std.ArrayList`, `std.HashMap`, `std.json`처럼 이 책에서 다루지 않은 자료구조와 유틸리티를 하나씩 사용해 보면서 표준 라이브러리에 대한 감각을 넓힙니다.
3. **다른 사람이 작성한 Zig 코드 읽어 보기**: Zig 컴파일러 자체나 커뮤니티의 공개 프로젝트 소스 코드를 읽어 보면, 이 책에서 다룬 관용구들이 실전 코드에서 어떻게 응용되는지 확인할 수 있습니다.
4. **17장에서 다룬 패키지 의존성을 실제로 사용해 보기**: `build.zig.zon`으로 외부 패키지를 추가하고 `build.zig`에서 연결하는 과정을 직접 경험하며, 여러 패키지로 구성된 프로젝트 구조에 익숙해집니다.
5. **관심 있는 응용 분야로 확장하기**: C 라이브러리와의 연동, 임베디드 타겟, WebAssembly 빌드처럼 18장에서 언급한 방향 중 자신의 관심사와 맞는 분야를 골라 더 깊이 파고들어 봅니다.

Zig는 여전히 활발하게 발전하고 있는 언어이며, 그만큼 배우는 사람에게도 언어의 설계와 발전 과정을 지켜보는 재미가 있습니다. 이 책에서 다진 기초를 바탕으로, 직접 코드를 작성하고 실패하고 고쳐 나가는 과정을 통해 Zig에 대한 이해를 계속 넓혀 가기를 바랍니다.
