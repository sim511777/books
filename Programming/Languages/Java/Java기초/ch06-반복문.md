# 6장. 반복문

[◀ 이전: 5장. 제어문](ch05-제어문.md) | [📖 목차](00-목차.md) | [다음: 7장. 배열 ▶](ch07-배열.md)

---

5장에서 배운 제어문은 코드를 "선택적으로" 실행하는 방법이었습니다. 이번 장에서 다룰 **반복문(loop)**은 같은 코드를 조건이 만족되는 동안 여러 번 실행하는 방법입니다. 화면에 별표를 100개 찍거나, 배열에 담긴 숫자들의 합을 구하거나, 사용자가 올바른 값을 입력할 때까지 재요청하는 등의 작업은 반복문 없이는 매우 번거롭습니다. Java는 `while`, `do-while`, `for`, 그리고 배열이나 컬렉션 순회에 특화된 `for-each` 네 가지 형태의 반복문을 제공합니다.

## while문

`while`문은 조건이 `true`인 동안 블록을 계속 실행합니다. 조건은 반복이 시작되기 **전에** 검사되므로, 처음부터 조건이 거짓이면 블록은 한 번도 실행되지 않을 수 있습니다.

```java
public class CountDown {
    public static void main(String[] args) {
        int count = 5;

        while (count > 0) {
            System.out.println(count);
            count--; // 이 줄이 없으면 무한 루프에 빠진다
        }

        System.out.println("발사!");
    }
}
```

`while`문에서 가장 흔한 실수는 반복 변수를 갱신하는 코드를 빠뜨려서 조건이 영원히 `true`로 유지되는 **무한 루프**입니다. `while`문을 작성할 때는 항상 "이 조건이 언제 거짓이 되는가"를 먼저 생각하는 습관을 들이는 것이 좋습니다.

## do-while문

`do-while`문은 `while`문과 로직은 같지만, 조건을 블록을 실행한 **후에** 검사합니다. 따라서 조건이 처음부터 거짓이더라도 블록은 최소 한 번은 실행됩니다.

```java
public class MenuLoop {
    public static void main(String[] args) {
        int choice = 0;
        int attempts = 0;

        do {
            attempts++;
            System.out.println("메뉴를 확인하는 중... (" + attempts + "번째 시도)");
            choice = attempts; // 실제로는 사용자 입력을 받는 코드가 들어갈 자리
        } while (choice < 3);

        System.out.println("메뉴 선택이 끝났습니다. 총 " + attempts + "번 시도했습니다.");
    }
}
```

"최소 한 번은 실행해야 하는" 로직, 예를 들어 사용자에게 값을 입력받고 나서야 그 값이 올바른지 검사할 수 있는 상황에서는 `do-while`이 `while`보다 자연스럽습니다. 다만 실무에서는 `for`나 `while`에 비해 `do-while`을 쓰는 빈도가 훨씬 낮으므로, 정말로 "먼저 한 번 실행"이 필요한 경우에만 선택하는 것이 좋습니다.

## for문

반복 횟수를 미리 알고 있거나, 초기화·조건·증감이라는 세 요소가 명확하게 구분되는 상황에서는 `for`문이 가장 널리 쓰입니다.

```java
public class ForBasics {
    public static void main(String[] args) {
        // 초기화; 조건; 증감 순서로 한 줄에 모여 있어 반복 구조가 한눈에 보인다
        for (int i = 1; i <= 5; i++) {
            System.out.println(i + "번째 반복입니다.");
        }
    }
}
```

`for (초기화; 조건; 증감)` 구조에서 초기화는 반복이 시작되기 전 딱 한 번 실행되고, 조건은 매 반복 시작 전에 검사되며, 증감은 매 반복이 끝날 때마다 실행됩니다. `while`문으로도 똑같은 로직을 작성할 수 있지만, `for`문은 반복에 필요한 세 요소가 한 곳에 모여 있어 반복 범위를 파악하기 훨씬 쉽습니다.

```java
// 위의 for문과 완전히 동일하게 동작하는 while문
int i = 1;
while (i <= 5) {
    System.out.println(i + "번째 반복입니다.");
    i++;
}
```

## 중첩 반복문 - 구구단 예제

반복문 안에 또 다른 반복문을 넣을 수 있습니다. 대표적인 예가 구구단입니다.

```java
public class MultiplicationTable {
    public static void main(String[] args) {
        for (int dan = 2; dan <= 9; dan++) {
            System.out.println("=== " + dan + "단 ===");
            for (int i = 1; i <= 9; i++) {
                System.out.println(dan + " x " + i + " = " + (dan * i));
            }
        }
    }
}
```

바깥쪽 반복문이 한 번 돌 때마다 안쪽 반복문이 처음부터 끝까지 완전히 실행됩니다. 즉 바깥쪽이 `dan = 2`일 때 안쪽은 `i = 1`부터 `9`까지 모두 돌고, 그다음 바깥쪽이 `dan = 3`으로 넘어가면 안쪽은 다시 `i = 1`부터 시작합니다. 전체 반복 횟수는 바깥쪽 8번(2단~9단) × 안쪽 9번으로, 총 72번의 출력이 이루어집니다. 중첩 반복문의 실행 횟수를 계산할 때는 이렇게 각 반복문의 횟수를 곱하는 감각을 갖고 있으면 유용합니다.

별을 삼각형 모양으로 찍는 예제도 중첩 반복문의 동작을 이해하는 데 도움이 됩니다.

```java
public class StarTriangle {
    public static void main(String[] args) {
        int height = 5;

        for (int row = 1; row <= height; row++) {
            for (int col = 1; col <= row; col++) {
                System.out.print("*");
            }
            System.out.println(); // 한 줄이 끝나면 줄바꿈
        }
    }
}
```

`row`가 커질수록 안쪽 반복문이 도는 횟수(`col`의 최댓값)도 함께 늘어나기 때문에, 별의 개수가 1개, 2개, 3개... 순서로 늘어나며 삼각형 모양이 만들어집니다.

## for-each문

배열이나 컬렉션(14장에서 다룰 `List`, `Set` 등)의 모든 원소를 처음부터 끝까지 순서대로 순회할 때는 `for-each`문이 인덱스 관리 없이 훨씬 간결하게 표현됩니다.

```java
public class ForEachArray {
    public static void main(String[] args) {
        int[] scores = {88, 92, 76, 100, 65};
        int total = 0;

        // "scores 배열에 들어 있는 각 값을 score라는 이름으로 하나씩 꺼내 쓴다"
        for (int score : scores) {
            total += score;
        }

        System.out.println("합계: " + total);
        System.out.println("평균: " + (double) total / scores.length);
    }
}
```

같은 로직을 일반 `for`문으로 작성하면 다음과 같습니다.

```java
int[] scores = {88, 92, 76, 100, 65};
int total = 0;

for (int i = 0; i < scores.length; i++) {
    total += scores[i];
}
```

`for-each`문은 인덱스 변수 `i`와 배열 길이(`scores.length`), 배열 접근(`scores[i]`)을 신경 쓸 필요가 없어서 코드가 훨씬 단순해집니다. 배열은 7장에서 자세히 다루겠지만, 지금 단계에서는 "여러 개의 값을 순서대로 순회한다"는 감각만 잡아두어도 충분합니다.

다만 `for-each`문에는 중요한 제약이 있습니다. 순회 중인 원소의 값을 바꿀 수는 있어도(원시 타입이라면 그 변경이 원본 배열에는 반영되지 않습니다), 인덱스에 직접 접근할 수 없고, 특정 위치를 건너뛰거나 배열의 크기를 반복 중에 바꾸는 것도 불가능합니다. 인덱스 자체가 필요하거나 역순으로 순회해야 한다면 일반 `for`문을 사용해야 합니다.

```java
int[] numbers = {10, 20, 30};

for (int n : numbers) {
    n = n * 2; // n은 배열 원소의 "복사값"이므로 원본 배열은 바뀌지 않는다
}

System.out.println(numbers[0]); // 여전히 10이 출력된다
```

## break와 continue

`break`는 반복문을 즉시 종료하고 빠져나갑니다. `continue`는 현재 반복만 건너뛰고 다음 반복으로 넘어갑니다.

```java
public class BreakContinueDemo {
    public static void main(String[] args) {
        System.out.println("--- break 예제: 처음 발견한 3의 배수에서 멈춤 ---");
        for (int i = 1; i <= 20; i++) {
            if (i % 3 == 0) {
                System.out.println(i + "는 3의 배수입니다. 여기서 종료합니다.");
                break;
            }
        }

        System.out.println("--- continue 예제: 짝수만 건너뛰고 홀수만 출력 ---");
        for (int i = 1; i <= 10; i++) {
            if (i % 2 == 0) {
                continue; // 짝수면 아래 출력 코드를 건너뛰고 다음 반복으로
            }
            System.out.println(i);
        }
    }
}
```

중첩 반복문에서 `break`는 기본적으로 자신이 속한 **가장 안쪽** 반복문만 종료시킵니다. 바깥쪽 반복문까지 한꺼번에 빠져나가야 한다면 **레이블(label)**을 사용할 수 있습니다.

```java
public class LabeledBreak {
    public static void main(String[] args) {
        outer: // 바깥쪽 for문에 붙인 레이블
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 3; j++) {
                if (i == 2 && j == 2) {
                    System.out.println("i=2, j=2에서 바깥 루프까지 종료");
                    break outer; // 레이블을 지정해 바깥쪽 반복문까지 탈출
                }
                System.out.println("i=" + i + ", j=" + j);
            }
        }
    }
}
```

레이블 문법은 유용하지만 남용하면 코드 흐름을 따라가기 어려워지므로, 정말로 다층 반복문을 한꺼번에 빠져나가야 하는 경우로 제한해서 사용하는 것이 좋습니다. 많은 경우 조건을 별도의 `boolean` 변수로 관리하거나, 8장에서 배울 메서드로 로직을 분리해서 `return`으로 빠져나가는 방식이 더 읽기 쉽습니다.

## 어떤 반복문을 선택할까

- 반복 횟수가 명확하게 정해져 있다면(예: "1부터 100까지") `for`문이 자연스럽습니다.
- 반복 종료 조건이 반복 중간에 결정되고 몇 번 반복할지 미리 알 수 없다면(예: "사용자가 종료를 입력할 때까지") `while`문이 적합합니다.
- 최소 한 번은 실행해야 하는 로직이라면 `do-while`을 고려합니다.
- 배열이나 컬렉션의 모든 원소를 순서대로 처리하기만 하면 된다면 `for-each`가 가장 간결합니다.

## 요약

- `while`문은 조건을 반복 전에 검사하고, `do-while`문은 조건을 반복 후에 검사하므로 블록이 최소 한 번은 실행됩니다.
- `for`문은 초기화, 조건, 증감이 한 줄에 모여 있어 반복 횟수가 정해진 경우에 가독성이 좋습니다.
- 중첩 반복문에서는 바깥쪽 반복 한 번당 안쪽 반복문이 전체를 한 번씩 도므로, 전체 실행 횟수는 각 반복문 횟수의 곱이 됩니다. 구구단이나 별 찍기 예제로 이 동작을 확인했습니다.
- `for-each`문은 배열과 컬렉션을 순회할 때 인덱스 관리 없이 각 원소에 바로 접근할 수 있게 해주지만, 인덱스 접근이나 원본 수정이 필요한 경우에는 일반 `for`문을 써야 합니다.
- `break`는 반복문을 즉시 종료하고, `continue`는 현재 반복만 건너뜁니다. 중첩 반복문에서 바깥쪽까지 종료하려면 레이블을 사용할 수 있지만, 남용하지 않는 것이 좋습니다.

1. `while`문을 사용해 1부터 100까지의 합을 구하는 프로그램을 작성하세요.
2. `do-while`문이 `while`문보다 적합한 상황을 하나 예로 들고, 두 반복문으로 각각 구현해 동작 차이를 비교해보세요.
3. 중첩 `for`문을 사용해 별을 역삼각형 모양(위쪽이 넓고 아래로 갈수록 좁아지는 모양)으로 출력하는 프로그램을 작성하세요.
4. 정수 배열을 하나 선언하고, `for-each`문으로 원소 중 최댓값을 찾는 코드를 작성하세요. 그다음 왜 이 문제에서는 인덱스가 필요 없어 `for-each`가 적합한지 설명해보세요.
5. 2중 `for`문과 레이블이 붙은 `break`를 사용해, 두 개의 정수 배열에서 값이 같은 첫 번째 쌍을 찾으면 즉시 두 반복문을 모두 종료하는 프로그램을 작성하세요.
