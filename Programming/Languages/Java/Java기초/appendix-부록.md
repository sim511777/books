## String 클래스 메서드 치트시트

3장에서 다룬 문자열은 실무 코드에서 가장 많이 다루는 자료형 중 하나입니다. `String`은 불변(immutable) 객체이므로, 아래 메서드들은 모두 원본 문자열을 바꾸지 않고 **새로운 문자열을 반환**한다는 점을 기억해두세요.

| 메서드 | 설명 | 예시 |
|---|---|---|
| `length()` | 문자열의 길이(문자 개수) 반환 | `"hello".length()` → `5` |
| `charAt(int index)` | 지정한 위치의 문자 반환 | `"hello".charAt(1)` → `'e'` |
| `substring(int begin)` | begin부터 끝까지 잘라낸 부분 문자열 | `"hello".substring(2)` → `"llo"` |
| `substring(int begin, int end)` | begin 이상 end 미만 구간을 잘라낸 부분 문자열 | `"hello".substring(1, 4)` → `"ell"` |
| `indexOf(String str)` | str이 처음 나타나는 위치, 없으면 `-1` | `"hello".indexOf("ll")` → `2` |
| `contains(CharSequence s)` | 문자열이 s를 포함하는지 여부 | `"hello".contains("ell")` → `true` |
| `equals(Object obj)` | 두 문자열의 내용이 같은지 비교 | `"a".equals("a")` → `true` |
| `equalsIgnoreCase(String s)` | 대소문자를 무시하고 내용 비교 | `"A".equalsIgnoreCase("a")` → `true` |
| `compareTo(String s)` | 사전 순서 비교(음수/0/양수 반환) | `"a".compareTo("b")` → 음수 |
| `toUpperCase()` / `toLowerCase()` | 대문자/소문자로 변환한 새 문자열 | `"Hi".toUpperCase()` → `"HI"` |
| `trim()` / `strip()` | 앞뒤 공백 제거(`strip()`은 유니코드 공백까지 처리) | `"  hi  ".trim()` → `"hi"` |
| `replace(CharSequence old, CharSequence new)` | old를 new로 모두 교체 | `"a-b-c".replace("-", "_")` → `"a_b_c"` |
| `split(String regex)` | 정규식을 기준으로 문자열 분할 | `"a,b,c".split(",")` → `["a","b","c"]` |
| `isEmpty()` | 길이가 0인지 여부 | `"".isEmpty()` → `true` |
| `isBlank()` | 공백만으로 이루어졌거나 비어있는지 여부 | `"  ".isBlank()` → `true` |
| `startsWith(String prefix)` / `endsWith(String suffix)` | 접두사/접미사 검사 | `"hello".startsWith("he")` → `true` |
| `join(CharSequence delim, ...)` | 여러 문자열을 구분자로 연결(정적 메서드) | `String.join(",", "a", "b")` → `"a,b"` |
| `format(String format, Object... args)` | 형식 문자열에 값을 채워 생성(정적 메서드) | `String.format("%d개", 3)` → `"3개"` |
| `valueOf(Object obj)` | 다른 타입을 문자열로 변환(정적 메서드) | `String.valueOf(123)` → `"123"` |
| `toCharArray()` | 문자열을 `char[]`로 변환 | `"abc".toCharArray()` → `['a','b','c']` |

## Math 클래스 메서드 치트시트

`Math` 클래스는 4장에서 다룬 산술 연산을 넘어서는 수학 계산이 필요할 때 사용합니다. 모든 메서드가 `static`이므로 객체를 만들지 않고 `Math.메서드명()` 형태로 바로 호출합니다.

| 메서드 | 설명 | 예시 |
|---|---|---|
| `abs(x)` | 절댓값 | `Math.abs(-5)` → `5` |
| `max(a, b)` / `min(a, b)` | 두 값 중 큰 값/작은 값 | `Math.max(3, 7)` → `7` |
| `pow(base, exp)` | 거듭제곱 | `Math.pow(2, 10)` → `1024.0` |
| `sqrt(x)` | 제곱근 | `Math.sqrt(9.0)` → `3.0` |
| `round(x)` | 가장 가까운 정수로 반올림 | `Math.round(3.6)` → `4` |
| `ceil(x)` | 올림(소수 부분이 있으면 항상 큰 정수로) | `Math.ceil(3.1)` → `4.0` |
| `floor(x)` | 내림(항상 작은 정수로) | `Math.floor(3.9)` → `3.0` |
| `random()` | `0.0` 이상 `1.0` 미만의 임의 실수 반환 | `Math.random()` → 예: `0.372…` |
| `PI` | 원주율 상수 (필드) | `Math.PI` → `3.14159…` |

## System 클래스 메서드 치트시트

`System`은 프로그램이 실행되는 환경(콘솔, 시간, 메모리 등)과 상호작용할 때 사용합니다.

| 메서드/필드 | 설명 | 예시 |
|---|---|---|
| `out.println(x)` | 콘솔에 값을 출력하고 줄바꿈 (2장부터 계속 사용) | `System.out.println("hi")` |
| `out.print(x)` | 줄바꿈 없이 출력 | `System.out.print("hi")` |
| `currentTimeMillis()` | 1970년 1월 1일 이후 경과한 밀리초(long) | 성능 측정 등에 활용 |
| `nanoTime()` | 정밀한 시간 간격 측정용 나노초 값(절대 시각 의미 없음) | 두 시점 사이 실행 시간 측정 |
| `arraycopy(src, srcPos, dest, destPos, length)` | 배열의 일부를 다른 배열로 빠르게 복사(7장 배열 참고) | 대량 배열 복사 시 사용 |
| `exit(int status)` | 프로그램을 즉시 종료 (0은 정상 종료를 의미) | `System.exit(0)` |
| `getProperty(String key)` | JVM/OS 관련 시스템 속성 조회 | `System.getProperty("os.name")` |

## 컬렉션 프레임워크 메서드 요약표

14장에서 다룬 컬렉션 프레임워크의 핵심 인터페이스별 대표 메서드를 정리합니다.

### List, Set, Map 공통 (Collection 인터페이스)

| 메서드 | 설명 |
|---|---|
| `add(e)` | 요소 추가 |
| `remove(o)` | 요소 제거 |
| `contains(o)` | 포함 여부 확인 |
| `size()` | 요소 개수 |
| `isEmpty()` | 비어있는지 확인 |
| `clear()` | 모든 요소 제거 |
| `iterator()` | 반복자(Iterator) 획득 |
| `forEach(action)` | 각 요소에 대해 동작 실행 (15장의 람다와 함께 자주 사용) |

### List 고유 메서드

| 메서드 | 설명 |
|---|---|
| `get(int index)` | 인덱스로 요소 조회 |
| `set(int index, e)` | 인덱스의 요소 교체 |
| `add(int index, e)` | 특정 위치에 요소 삽입 |
| `indexOf(o)` | 요소의 첫 위치 반환 |
| `sort(comparator)` | 정렬 (13장 제네릭, 15장 람다와 연결) |

### Map 고유 메서드

| 메서드 | 설명 |
|---|---|
| `put(key, value)` | 키-값 저장 |
| `get(key)` | 키로 값 조회 (없으면 `null`) |
| `getOrDefault(key, default)` | 없을 때 기본값 반환 |
| `containsKey(key)` / `containsValue(v)` | 키/값 존재 여부 확인 |
| `remove(key)` | 키에 해당하는 항목 제거 |
| `keySet()` / `values()` / `entrySet()` | 키 집합 / 값 집합 / (키,값) 쌍 집합 조회 |
| `putIfAbsent(key, value)` | 키가 없을 때만 저장 |

### Set 고유 특징

`Set`은 `Collection`의 공통 메서드만 가지지만, 중복을 허용하지 않는다는 점이 핵심입니다. `add()`로 이미 존재하는 요소를 추가하면 무시되고 `false`가 반환됩니다.

## 스트림 메서드 요약표

16장에서 다룬 스트림 연산을 중간 연산과 최종 연산으로 나누어 정리합니다. 중간 연산은 스트림을 반환해서 계속 이어붙일 수 있고, 최종 연산은 스트림을 소비해서 결과를 만들어냅니다.

### 중간 연산 (intermediate operations)

| 메서드 | 설명 |
|---|---|
| `filter(predicate)` | 조건을 만족하는 요소만 남김 |
| `map(function)` | 각 요소를 변환 |
| `sorted()` / `sorted(comparator)` | 정렬 |
| `distinct()` | 중복 제거 |
| `limit(n)` | 앞에서 n개만 남김 |
| `skip(n)` | 앞에서 n개를 건너뜀 |
| `peek(action)` | 요소를 소비하지 않고 살짝 관찰(주로 디버깅용) |

### 최종 연산 (terminal operations)

| 메서드 | 설명 |
|---|---|
| `forEach(action)` | 각 요소에 대해 동작 실행 |
| `collect(collector)` | `List`, `Set`, `Map` 등으로 결과 수집 (흔히 `Collectors.toList()` 등과 함께) |
| `count()` | 요소 개수 반환 |
| `sum()` / `average()` / `max()` / `min()` | (`IntStream` 등 숫자 스트림에서) 집계 연산 |
| `reduce(identity, accumulator)` | 요소들을 하나의 값으로 누적 |
| `anyMatch(predicate)` / `allMatch(predicate)` / `noneMatch(predicate)` | 조건 충족 여부 검사 |
| `findFirst()` / `findAny()` | 조건에 맞는 요소 하나를 `Optional`로 반환 |
| `toArray()` | 배열로 변환 |

## 연산자 우선순위표

4장에서 다룬 연산자들을 우선순위가 높은 것부터 낮은 것 순서로 정리합니다. 같은 줄에 있는 연산자는 우선순위가 같으며, 대부분 왼쪽에서 오른쪽으로 계산됩니다(결합 방향이 다른 경우 별도로 표시).

| 우선순위 | 연산자 | 설명 | 결합 방향 |
|---|---|---|---|
| 1 (최고) | `()` `[]` `.` | 괄호, 배열 인덱스, 멤버 접근 | 왼쪽 → 오른쪽 |
| 2 | `++` `--` (후위) | 후위 증감 | 왼쪽 → 오른쪽 |
| 3 | `++` `--` (전위), `+` `-` (단항), `!` `~` | 전위 증감, 단항 부호, 논리/비트 NOT | 오른쪽 → 왼쪽 |
| 4 | `(type)` | 형변환(캐스팅, 3장 참고) | 오른쪽 → 왼쪽 |
| 5 | `*` `/` `%` | 곱셈, 나눗셈, 나머지 | 왼쪽 → 오른쪽 |
| 6 | `+` `-` | 더하기, 빼기(문자열 결합 포함) | 왼쪽 → 오른쪽 |
| 7 | `<<` `>>` `>>>` | 비트 이동 | 왼쪽 → 오른쪽 |
| 8 | `<` `<=` `>` `>=` `instanceof` | 크기 비교, 타입 검사(10장 참고) | 왼쪽 → 오른쪽 |
| 9 | `==` `!=` | 동등 비교 | 왼쪽 → 오른쪽 |
| 10 | `&` | 비트 AND | 왼쪽 → 오른쪽 |
| 11 | `^` | 비트 XOR | 왼쪽 → 오른쪽 |
| 12 | `\|` | 비트 OR | 왼쪽 → 오른쪽 |
| 13 | `&&` | 논리 AND | 왼쪽 → 오른쪽 |
| 14 | `\|\|` | 논리 OR | 왼쪽 → 오른쪽 |
| 15 | `?:` | 삼항 조건 연산자 | 오른쪽 → 왼쪽 |
| 16 (최저) | `=` `+=` `-=` `*=` `/=` `%=` 등 | 대입 및 복합 대입 | 오른쪽 → 왼쪽 |

헷갈릴 때는 항상 괄호 `()`를 추가하는 것이 안전합니다. 우선순위를 정확히 외우는 것보다, "이 표현식이 이렇게 계산될 것이다"라는 의도를 괄호로 명시적으로 드러내는 코드가 읽는 사람에게 훨씬 친절합니다.

## 더 공부하고 싶다면 — 참고할 자료의 유형

이 책을 마친 뒤 더 깊이 있는 내용이나 최신 정보가 필요할 때 찾아볼 만한 자료의 종류를 소개합니다. 특정 책이나 강의를 추천하기보다, 어떤 "종류"의 자료를 어떤 상황에 찾아보면 좋은지 안내합니다.

- **공식 언어·API 문서.** Java를 배포하는 조직이 제공하는 공식 문서에는 `String`, `List`, `Stream` 등 표준 라이브러리에 속한 모든 클래스와 메서드의 정확한 동작이 설명되어 있습니다. 이 부록의 치트시트에 없는 메서드를 찾고 있다면 가장 먼저 확인해야 할 곳입니다. 메서드 이름과 클래스 이름을 검색 엔진에 함께 입력하면 대부분 공식 문서 페이지가 먼저 나타납니다.
- **언어 명세와 버전별 변경 사항 안내.** Java는 정기적으로 새 버전이 나오면서 문법이나 표준 라이브러리에 기능이 추가됩니다. 새 버전을 설치했다면 그 버전에서 무엇이 달라졌는지 정리된 공식 릴리스 노트를 확인하는 습관을 들이면 좋습니다.
- **오픈소스 프로젝트의 소스 코드.** 컬렉션 프레임워크나 스트림처럼 이 책에서 다룬 기능들이 실제로 어떻게 구현되어 있는지 궁금하다면, Java 표준 라이브러리 자체도 오픈소스로 공개되어 있어 소스 코드를 직접 열어볼 수 있습니다. 실무에서 널리 쓰이는 오픈소스 라이브러리(예: 스프링 계열 프로젝트)의 코드를 읽어보는 것도 좋은 코드 스타일을 익히는 데 도움이 됩니다.
- **커뮤니티 질문·답변 사이트.** 특정 오류 메시지나 예외 상황을 마주쳤을 때, 같은 문제를 겪은 다른 개발자들의 질문과 답변이 쌓여 있는 커뮤니티 사이트를 검색하면 대부분 비슷한 사례를 찾을 수 있습니다. 다만 답변의 Java 버전이 오래되었을 수 있으니, 공식 문서와 함께 교차 확인하는 습관이 중요합니다.
- **각 프레임워크의 공식 가이드.** 18장에서 언급한 스프링처럼 특정 프레임워크를 배우게 된다면, 그 프레임워크가 직접 제공하는 공식 가이드나 튜토리얼 문서로 시작하는 것이 가장 신뢰할 수 있는 출발점입니다. 대부분의 주요 프레임워크는 처음 시작하는 사용자를 위한 공식 입문 가이드를 별도로 제공합니다.

무엇을 찾아보든, 예제 코드를 그대로 복사하기보다 직접 타이핑하고 값을 바꿔가며 실행해보는 것이 가장 오래 남는 학습 방법이라는 점은 이 책 전체에서 강조하고 싶었던 태도입니다.
