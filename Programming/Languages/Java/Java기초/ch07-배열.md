## 배열이 필요한 이유

5명의 시험 점수를 저장하고 평균을 구하려면 어떻게 해야 할까요? 지금까지 배운 지식으로는 변수 5개를 따로 선언해야 합니다.

```java
int score1 = 90;
int score2 = 85;
int score3 = 77;
int score4 = 92;
int score5 = 88;
```

학생이 5명일 때는 그럭저럭 버틸 만하지만, 50명이라면 변수 50개를 일일이 선언하고 관리해야 합니다. 반복문(6장)으로 처리하기도 어렵습니다. `score1`, `score2`, ... 같은 이름은 코드 상에서 서로 다른 변수이기 때문에 반복문의 인덱스로 접근할 방법이 없기 때문입니다.

**배열(array)**은 이런 문제를 해결합니다. 같은 자료형의 값을 여러 개 묶어서 하나의 이름으로 관리하고, 각 값에는 번호(인덱스)를 붙여 접근할 수 있게 해 줍니다.

```java
int[] scores = {90, 85, 77, 92, 88};
```

이제 `scores`라는 이름 하나로 다섯 개의 점수를 모두 다루면서, 반복문과 결합해 훨씬 간결한 코드를 작성할 수 있습니다.

## 배열 선언과 생성

배열을 다루는 방법은 크게 두 단계로 나뉩니다. 먼저 배열 변수를 **선언**하고, 그다음 실제로 값을 담을 공간을 **생성**합니다.

```java
int[] numbers;              // 배열 변수 선언 (아직 공간 없음)
numbers = new int[5];       // 크기 5인 int 배열 생성
```

`new int[5]`는 "정수 5개를 담을 수 있는 공간을 만들어라"는 뜻입니다. 이렇게 생성한 배열의 각 요소는 자료형의 기본값으로 초기화됩니다. `int` 배열이라면 모든 요소가 `0`, `boolean` 배열이라면 `false`, 참조형 배열이라면 `null`로 채워집니다.

값을 알고 있다면 선언과 동시에 초기화할 수도 있습니다.

```java
int[] numbers = {10, 20, 30, 40, 50};
String[] names = {"철수", "영희", "민수"};
```

이 방식을 **배열 초기화 리스트**라고 부르며, 중괄호 안에 나열한 값의 개수만큼 배열 크기가 자동으로 결정됩니다.

선언 위치에 대해 한 가지 참고할 점이 있습니다. `int[] numbers`와 `int numbers[]`는 둘 다 문법적으로 허용되지만, 자바에서는 앞쪽 표기(`int[] numbers`)가 더 널리 쓰이는 관례입니다.

## 인덱스로 접근하기

배열의 각 요소는 **인덱스(index)**라는 번호로 접근합니다. 중요한 규칙은 인덱스가 **0부터 시작**한다는 것입니다.

```java
int[] numbers = {10, 20, 30, 40, 50};

System.out.println(numbers[0]);  // 10 (첫 번째 요소)
System.out.println(numbers[4]);  // 50 (다섯 번째 요소)

numbers[2] = 99;                 // 세 번째 요소 값을 변경
System.out.println(numbers[2]);  // 99
```

배열의 크기는 `length` 필드로 확인할 수 있습니다. 메서드가 아니라 필드이므로 괄호 없이 사용합니다.

```java
System.out.println(numbers.length);  // 5
```

배열 크기가 5라면 유효한 인덱스는 `0`부터 `4`까지입니다. 존재하지 않는 인덱스에 접근하면 `ArrayIndexOutOfBoundsException`이라는 예외가 발생하며 프로그램이 비정상적으로 종료됩니다. 예외를 다루는 자세한 방법은 12장에서 배우지만, 지금은 "인덱스는 항상 `0`부터 `length - 1`까지"라는 규칙을 확실히 기억해 두는 것이 중요합니다.

```java
int[] numbers = new int[3];
System.out.println(numbers[3]);  // 오류! 유효 범위는 0~2
```

## 배열과 반복문 활용

배열의 진짜 힘은 반복문과 결합할 때 드러납니다. 5장의 제어문과 6장의 반복문을 떠올리며 다음 예제를 살펴봅시다.

```java
public class ScoreAnalyzer {
    public static void main(String[] args) {
        int[] scores = {90, 85, 77, 92, 88};

        // 합계 구하기
        int sum = 0;
        for (int i = 0; i < scores.length; i++) {
            sum += scores[i];
        }

        // 평균 구하기
        double average = (double) sum / scores.length;

        // 최댓값 찾기
        int max = scores[0];
        for (int i = 1; i < scores.length; i++) {
            if (scores[i] > max) {
                max = scores[i];
            }
        }

        System.out.println("합계: " + sum);
        System.out.println("평균: " + average);
        System.out.println("최댓값: " + max);
    }
}
```

최댓값을 찾는 로직은 "첫 번째 값을 임시 최댓값으로 놓고, 나머지 값과 하나씩 비교하며 더 큰 값이 나오면 갈아치운다"는 전형적인 패턴입니다. 최솟값을 찾을 때도 비교 방향(`<`)만 바꾸면 동일한 방식이 그대로 적용됩니다.

`length`가 아니라 배열의 요소만 순서대로 훑고 싶을 때는 **향상된 for문(for-each)**을 쓰면 더 간결합니다.

```java
int sum = 0;
for (int score : scores) {
    sum += score;
}
```

다만 향상된 for문은 인덱스 값을 직접 알 수 없다는 한계가 있습니다. 인덱스가 필요한 로직(예: 이전/다음 요소 비교)에는 여전히 전통적인 for문이 필요합니다.

## 2차원 배열

배열의 요소로 또 다른 배열을 담을 수도 있습니다. 이를 **2차원 배열**이라고 하며, 표나 행렬처럼 행(row)과 열(column)로 구성된 데이터를 표현할 때 유용합니다.

```java
int[][] matrix = new int[3][4];  // 3행 4열 배열

int[][] grades = {
    {90, 85, 77},   // 1반 성적
    {88, 92, 79},   // 2반 성적
    {70, 65, 95}    // 3반 성적
};
```

`grades[1][2]`는 "2반의 세 번째 성적"인 `79`를 의미합니다. 첫 번째 인덱스가 행, 두 번째 인덱스가 열입니다.

2차원 배열을 순회할 때는 이중 for문을 사용합니다.

```java
public class GradeTable {
    public static void main(String[] args) {
        int[][] grades = {
            {90, 85, 77},
            {88, 92, 79},
            {70, 65, 95}
        };

        for (int i = 0; i < grades.length; i++) {
            int classSum = 0;
            for (int j = 0; j < grades[i].length; j++) {
                classSum += grades[i][j];
            }
            System.out.println((i + 1) + "반 합계: " + classSum);
        }
    }
}
```

바깥쪽 for문은 행을, 안쪽 for문은 그 행의 열을 순회합니다. 자바의 2차원 배열은 사실 "배열의 배열"이므로 각 행의 길이가 서로 달라도 됩니다. 이런 배열을 **가변 배열(jagged array)**이라고 부릅니다.

## 배열의 고정 크기 한계

배열을 쓰면서 반드시 기억해야 할 특징이 하나 있습니다. **배열은 한 번 생성하면 크기를 바꿀 수 없습니다.** `new int[5]`로 만든 배열은 영원히 5칸짜리 배열입니다.

```java
int[] numbers = new int[5];
// numbers를 6칸으로 늘리는 방법은 없다!
```

만약 요소를 더 담아야 한다면, 더 큰 배열을 새로 만들고 기존 값을 복사해야 합니다.

```java
int[] numbers = {1, 2, 3, 4, 5};
int[] bigger = new int[10];

for (int i = 0; i < numbers.length; i++) {
    bigger[i] = numbers[i];
}
// 이제 bigger에 numbers의 값이 복사되었고, 5칸이 더 남아 있다
```

`java.util.Arrays` 클래스의 `Arrays.copyOf(numbers, 10)` 메서드를 쓰면 이 복사 과정을 한 줄로 줄일 수 있습니다. 하지만 어느 방법을 쓰든 본질은 같습니다. "크기 변경"이 아니라 "더 큰 배열을 만들어 통째로 옮기는" 작업이라는 점입니다. 이 방식은 요소를 자주 추가하거나 삭제해야 하는 상황에서는 비효율적입니다. 매번 새 배열을 만들고 기존 데이터를 복사해야 하기 때문입니다.

또한 배열은 참조형(reference type)이라서 배열 변수를 다른 변수에 대입하거나 메서드에 전달하면 배열 전체가 복사되는 것이 아니라 같은 배열을 가리키는 참조가 전달됩니다. 이 특성이 메서드 호출과 어떻게 맞물리는지는 8장에서 자세히 다룹니다.

이러한 한계 때문에 실무에서는 크기가 자유롭게 늘어나고 줄어드는 자료구조가 필요합니다. 자바는 이를 위해 `ArrayList`, `HashMap` 등을 포함한 **컬렉션 프레임워크**를 제공하며, 14장에서 배열의 이러한 한계를 어떻게 극복하는지 자세히 살펴볼 것입니다. 지금은 배열이 "크기가 고정된, 가장 기본적인 데이터 묶음"이라는 점과 그 안에서 인덱스와 반복문을 다루는 방법을 확실히 익혀두는 것이 목표입니다.

## 요약

- 배열은 같은 자료형의 값을 여러 개 묶어 하나의 이름으로 관리하는 자료구조입니다.
- `int[] arr = new int[5];`처럼 선언과 생성을 하거나, `int[] arr = {1, 2, 3};`처럼 초기화 리스트를 사용할 수 있습니다.
- 인덱스는 `0`부터 `length - 1`까지이며, 범위를 벗어나면 `ArrayIndexOutOfBoundsException`이 발생합니다.
- 반복문(for, for-each)과 결합하면 합계, 평균, 최댓값/최솟값 찾기 같은 작업을 간결하게 처리할 수 있습니다.
- 2차원 배열은 배열의 배열로, 이중 for문으로 순회하며 표 형태의 데이터를 표현합니다.
- 배열은 생성 후 크기를 바꿀 수 없다는 한계가 있으며, 이를 보완하는 컬렉션 프레임워크는 14장에서 다룹니다.

## 연습문제

1. 정수 10개를 저장하는 배열을 만들고, 반복문을 이용해 짝수만 더한 합계를 구해 보세요.
2. 문자열 배열에 담긴 이름들 중 가장 긴 이름을 찾는 프로그램을 작성하세요. (힌트: `String`의 `length()` 메서드를 활용)
3. 크기 5인 `int` 배열을 만들고, 이를 크기 8인 새 배열에 복사한 뒤 나머지 3칸에 `0`을 채워 출력하세요.
4. 3행 3열의 2차원 배열로 구구단의 일부(2단~4단, 1~3까지)를 표현하고 이중 for문으로 출력해 보세요.
5. 배열에서 최댓값과 최솟값을 동시에 찾는 메서드가 있다면 어떤 모양일지 생각해 보세요. 이 궁금증은 8장에서 메서드를 배우면서 직접 해결해 볼 것입니다.
