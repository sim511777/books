## 메서드가 필요한 이유

7장에서 배열의 최댓값을 찾는 코드를 작성했습니다. 만약 프로그램의 여러 곳에서 "배열의 최댓값 찾기"가 반복해서 필요하다면 어떻게 해야 할까요? 매번 똑같은 for문을 복사해서 붙여넣는 것은 좋은 방법이 아닙니다. 코드가 길어지고, 나중에 로직을 수정할 때 모든 복사본을 찾아 고쳐야 하기 때문입니다.

**메서드(method)**는 자주 사용하는 코드 블록에 이름을 붙여 재사용할 수 있게 해 줍니다. 메서드를 한 번 정의해 두면, 필요할 때마다 이름만 불러서(호출해서) 같은 로직을 반복 실행할 수 있습니다.

```java
public static int findMax(int[] numbers) {
    int max = numbers[0];
    for (int i = 1; i < numbers.length; i++) {
        if (numbers[i] > max) {
            max = numbers[i];
        }
    }
    return max;
}
```

이제 `findMax(scores)`, `findMax(prices)`처럼 배열만 바꿔서 얼마든지 재사용할 수 있습니다. 사실 지금까지 작성한 모든 예제의 `main` 메서드 자체도 메서드입니다. 자바 프로그램은 결국 메서드들이 서로를 호출하며 실행되는 구조입니다.

## 메서드 정의의 구조

메서드는 다음과 같은 형태로 정의합니다.

```java
접근제어자 static 반환형 메서드이름(매개변수 목록) {
    // 메서드 본문
    return 반환값;
}
```

`findMax` 메서드를 예로 각 부분을 살펴보겠습니다.

```java
public static int findMax(int[] numbers) {
    ...
}
```

- `public`: 접근제어자입니다. 이 메서드를 어디까지 공개할지 정하는데, 접근제어자에 대한 자세한 내용은 9장에서 클래스와 함께 다룹니다.
- `static`: 클래스에 속한 메서드임을 나타냅니다. 지금까지 작성한 `main` 메서드가 항상 `static`이었던 이유도 이 장 마지막에서 짚어봅니다.
- `int`: **반환형(return type)**입니다. 이 메서드가 실행을 마치고 어떤 자료형의 값을 돌려줄지를 정합니다.
- `findMax`: 메서드 이름입니다. camelCase로 짓는 것이 관례입니다.
- `(int[] numbers)`: **매개변수(parameter)** 목록입니다. 메서드가 호출될 때 전달받는 값의 자료형과 이름을 정의합니다.

반환할 값이 없는 메서드는 반환형 자리에 `void`를 씁니다.

```java
public static void printLine() {
    System.out.println("--------------------");
}
```

## 메서드 호출

메서드는 이름 뒤에 괄호를 붙여 호출합니다. 괄호 안에는 매개변수 목록에 맞는 값(**인자, argument**)을 순서대로 전달합니다.

```java
public class Calculator {
    public static void main(String[] args) {
        int[] scores = {90, 85, 77, 92, 88};
        int max = findMax(scores);       // 메서드 호출, 결과를 max에 저장
        System.out.println("최댓값: " + max);

        printLine();                     // 반환값이 없는 메서드 호출
    }

    public static int findMax(int[] numbers) {
        int max = numbers[0];
        for (int i = 1; i < numbers.length; i++) {
            if (numbers[i] > max) {
                max = numbers[i];
            }
        }
        return max;
    }

    public static void printLine() {
        System.out.println("--------------------");
    }
}
```

`return`문을 만나면 메서드는 즉시 종료되고, 지정한 값을 호출한 자리로 돌려줍니다. `void` 메서드에서도 `return;`처럼 값 없이 메서드를 조기 종료할 수 있지만, 반드시 필요한 것은 아닙니다.

## 매개변수와 반환값

매개변수는 메서드가 호출될 때마다 다른 값을 전달받아 다르게 동작하도록 해 줍니다. 매개변수는 여러 개 정의할 수 있습니다.

```java
public static double calculateAverage(int sum, int count) {
    return (double) sum / count;
}
```

메서드를 호출할 때 전달하는 인자의 개수와 자료형은 매개변수 목록과 정확히 일치해야 합니다.

```java
double avg = calculateAverage(430, 5);  // sum=430, count=5로 전달
```

반환값이 있는 메서드는 호출 결과를 변수에 저장하거나, 다른 표현식의 일부로 바로 사용할 수 있습니다.

```java
System.out.println("평균: " + calculateAverage(430, 5));
```

## 메서드 오버로딩

같은 이름의 메서드를 매개변수의 개수나 자료형을 다르게 하여 여러 개 정의할 수 있습니다. 이를 **메서드 오버로딩(overloading)**이라고 합니다.

```java
public static int add(int a, int b) {
    return a + b;
}

public static double add(double a, double b) {
    return a + b;
}

public static int add(int a, int b, int c) {
    return a + b + c;
}
```

자바는 호출할 때 전달한 인자의 개수와 자료형을 보고 어떤 `add` 메서드를 실행할지 자동으로 결정합니다.

```java
add(1, 2);        // add(int, int) 호출
add(1.5, 2.5);     // add(double, double) 호출
add(1, 2, 3);      // add(int, int, int) 호출
```

오버로딩은 "이름은 같지만 하는 일은 비슷하되 입력의 형태가 다른" 메서드들을 하나의 직관적인 이름으로 묶어주는 역할을 합니다. 단, 반환형만 다르고 매개변수 목록이 완전히 같은 경우는 오버로딩으로 인정되지 않습니다. 자바는 매개변수 목록만으로 메서드를 구분하기 때문입니다.

## 가변 인자

몇 개의 값이 전달될지 미리 알 수 없을 때는 **가변 인자(varargs)**를 사용합니다. 매개변수 자료형 뒤에 `...`을 붙여 정의합니다.

```java
public static int sum(int... numbers) {
    int total = 0;
    for (int n : numbers) {
        total += n;
    }
    return total;
}
```

이렇게 정의하면 인자를 원하는 개수만큼 자유롭게 전달할 수 있습니다.

```java
System.out.println(sum());           // 0
System.out.println(sum(1, 2));        // 3
System.out.println(sum(1, 2, 3, 4));  // 10
```

메서드 내부에서 `numbers`는 평범한 `int[]` 배열처럼 취급됩니다. 실제로 배열을 직접 전달해도 동작합니다. 가변 인자는 한 메서드에 하나만 쓸 수 있고, 반드시 매개변수 목록의 맨 마지막 자리에 위치해야 합니다.

```java
public static void printAll(String title, int... values) {  // OK
    ...
}
```

## 값에 의한 전달 (Call by Value)

자바에서 메서드를 호출할 때 인자는 항상 **값으로 전달**됩니다. 즉, 매개변수는 전달받은 값의 "복사본"입니다. 기본 자료형(3장)을 전달하면 이 원칙이 직관적으로 이해됩니다.

```java
public class ValueTest {
    public static void main(String[] args) {
        int number = 10;
        changeValue(number);
        System.out.println(number);  // 여전히 10
    }

    public static void changeValue(int n) {
        n = 99;  // 복사본 n만 바뀔 뿐, 원본 number는 그대로
    }
}
```

`changeValue`에 전달된 `n`은 `number`의 값을 복사한 별개의 변수입니다. 메서드 안에서 `n`을 바꿔도 `main`의 `number`에는 영향이 없습니다.

그런데 배열이나 객체 같은 참조형을 전달할 때는 조금 더 주의가 필요합니다. 참조형 변수에 담긴 "값"은 실제 데이터가 아니라 데이터가 저장된 위치를 가리키는 **참조(reference)**입니다. 메서드를 호출하면 이 참조값이 복사되어 전달되므로, 매개변수와 원본 변수는 결국 **같은 배열(또는 객체)을 가리키게** 됩니다.

```java
public class ArrayTest {
    public static void main(String[] args) {
        int[] numbers = {1, 2, 3};
        modifyArray(numbers);
        System.out.println(numbers[0]);  // 99 — 원본이 바뀐다!
    }

    public static void modifyArray(int[] arr) {
        arr[0] = 99;  // arr가 가리키는 배열의 내용을 직접 수정
    }
}
```

여기서 `arr`은 `numbers`와 별개의 변수지만, 같은 배열을 가리키고 있습니다. `arr[0]`을 수정하면 그 배열 자체의 내용이 바뀌므로 `numbers[0]`도 함께 바뀝니다.

반면, 메서드 안에서 매개변수 자체를 새로운 배열로 **재할당**하면 원본에는 아무 영향이 없습니다.

```java
public static void reassign(int[] arr) {
    arr = new int[]{100, 200, 300};  // arr가 새 배열을 가리키도록 바뀔 뿐
}
```

이 경우 `arr`이라는 참조 변수(복사본)가 다른 배열을 가리키도록 바뀔 뿐, `main`에 있던 원본 `numbers` 변수는 여전히 원래 배열을 가리킵니다.

정리하면, 자바는 예외 없이 항상 값에 의한 전달을 사용합니다. 다만 참조형의 경우 전달되는 "값"이 참조(주소 같은 개념)이기 때문에, 그 참조를 통해 원본 데이터의 내용을 바꾸는 것은 가능하지만, 매개변수를 다른 대상으로 재할당하는 것은 원본에 영향을 주지 않습니다. 이 구분은 특히 9장에서 객체를 메서드에 전달하고 상태를 변경할 때 정확히 같은 원리로 다시 등장하니 꼭 기억해 두기 바랍니다.

## 클래스 속의 메서드를 향해

지금까지 다룬 메서드는 모두 `static` 메서드였습니다. `static` 메서드는 특정 객체 없이도 클래스 이름(또는 같은 클래스 안에서는 이름만으로) 호출할 수 있는 메서드입니다. 하지만 자바는 원래 객체 지향 언어이며, 실제로 자주 사용하는 메서드는 특정 객체의 상태와 연결된 **인스턴스 메서드**입니다.

예를 들어 "학생 객체가 자신의 평균 점수를 계산한다"거나 "자동차 객체가 스스로 속도를 높인다"처럼, 메서드가 객체 하나에 속한 데이터를 다루는 경우가 훨씬 많습니다. 9장에서 클래스와 객체를 배우면서 `static` 메서드와 인스턴스 메서드의 차이, 그리고 `this`를 이용해 객체 자신을 참조하는 방법을 자세히 살펴볼 것입니다. 지금 익힌 매개변수, 반환값, 오버로딩, 값에 의한 전달의 원리는 인스턴스 메서드에도 그대로 적용되므로, 이 장의 내용은 다음 장의 든든한 발판이 될 것입니다.

## 요약

- 메서드는 반복되는 코드를 이름으로 묶어 재사용할 수 있게 해 주며, 반환형·이름·매개변수·본문으로 구성됩니다.
- 메서드는 이름과 인자를 통해 호출하며, `return`문으로 값을 돌려주거나(`void`가 아니라면), 실행을 종료합니다.
- 메서드 오버로딩은 같은 이름을 매개변수의 개수·자료형이 다른 여러 메서드에 붙이는 기법입니다.
- 가변 인자(`...`)를 사용하면 개수가 정해지지 않은 인자를 배열처럼 받을 수 있습니다.
- 자바는 항상 값에 의한 전달(call by value)을 사용합니다. 기본형은 값 자체가 복사되고, 참조형(배열·객체)은 참조값이 복사되어 내부 내용은 바꿀 수 있지만 재할당은 원본에 영향을 주지 않습니다.
- 9장에서는 이러한 메서드가 클래스와 객체 안에서 인스턴스 메서드로 어떻게 쓰이는지 배웁니다.

## 연습문제

1. 두 정수 중 더 큰 값을 반환하는 `max(int a, int b)` 메서드를 작성하고, 세 정수를 받는 오버로딩 버전도 추가해 보세요.
2. 임의 개수의 문자열을 가변 인자로 받아, 하나로 이어 붙인 결과를 반환하는 메서드를 작성하세요.
3. `int[]` 배열을 매개변수로 받아 모든 요소를 두 배로 만드는 `doubleAll(int[] arr)` 메서드를 작성하고, 호출 후 원본 배열이 실제로 바뀌었는지 출력해서 확인하세요.
4. 정수 변수를 매개변수로 받아 값을 `0`으로 만드는 메서드를 작성하고, 호출 후 원본 변수의 값이 바뀌지 않는 이유를 설명해 보세요.
5. 7장에서 작성한 최댓값·최솟값 찾기 코드를 각각 `findMax`, `findMin` 메서드로 분리하고, `main`에서 두 메서드를 호출하는 프로그램으로 다시 작성해 보세요.
