# Java 기초부터 응용까지

[다음: 1장. Java란 무엇인가 ▶](ch01-java란.md)

---

프로그래밍을 처음 접하는 사람과 다른 언어 경험자를 모두 아우르는 Java 입문서입니다.
변수와 자료형 같은 기초 문법부터 클래스와 상속, 제네릭, 컬렉션, 람다와 스트림,
멀티스레딩 기초까지 Java의 핵심 개념을 순서대로 다룹니다.

각 장은 개념 설명, 예제 코드, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는 이해를 돕는
다이어그램을 함께 실었습니다.
