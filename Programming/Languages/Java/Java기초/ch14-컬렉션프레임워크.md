## 배열의 한계에서 시작하기

7장에서 배열을 배우면서, 배열은 같은 타입의 값을 여러 개 순서대로 저장할 수 있는 아주 기본적인 자료구조라는 것을 확인했다. 하지만 실제로 프로그램을 작성하다 보면 배열만으로는 불편한 상황을 자주 만난다.

```java
// 배열은 크기를 미리 정해야 한다
String[] names = new String[3];
names[0] = "철수";
names[1] = "영희";
names[2] = "민수";
// names[3] = "지훈"; // ArrayIndexOutOfBoundsException! 크기를 늘릴 수 없다
```

이름이 몇 개나 필요할지 모르는 상황에서는 배열 크기를 미리 정하기가 어렵다. 크기를 늘리려면 더 큰 배열을 새로 만들고 기존 값을 복사해야 한다. 게다가 특정 값을 찾거나(`"영희"가 몇 번째에 있지?`), 중간에 있는 값을 삭제하거나, 중복 없이 값을 저장하는 작업도 배열 자체에는 그런 기능이 없어서 직접 반복문을 짜서 구현해야 한다.

자바는 이런 반복적인 필요를 해결하기 위해 **컬렉션 프레임워크(Collections Framework)**라는 표준 라이브러리를 제공한다. 컬렉션 프레임워크는 값의 모음을 다루는 다양한 자료구조를 인터페이스와 클래스로 미리 만들어 두었고, 13장에서 배운 제네릭을 활용해서 어떤 타입의 값이든 타입 안전하게 담을 수 있도록 설계되어 있다.

컬렉션 프레임워크의 핵심 인터페이스는 크게 세 가지다.

- `List`: 순서가 있고 중복을 허용하는 목록
- `Set`: 순서를 보장하지 않고 중복을 허용하지 않는 집합
- `Map`: 키(key)와 값(value)을 한 쌍으로 저장하는 연관 배열

이 장에서는 각 인터페이스의 대표 구현체와 주요 메서드를 하나씩 살펴본다.

## List와 ArrayList: 순서 있는 목록

`List`는 배열처럼 순서를 유지하면서 값을 저장하지만, 크기가 자동으로 늘어난다는 점이 배열과 다르다. `List`는 인터페이스이고, 가장 널리 쓰이는 구현체는 `ArrayList`다.

```java
import java.util.ArrayList;
import java.util.List;

List<String> names = new ArrayList<>(); // List 타입으로 선언하고 ArrayList로 생성
names.add("철수");
names.add("영희");
names.add("민수");
names.add("지훈"); // 크기 제한 없이 계속 추가 가능

System.out.println(names.get(1));  // 영희 (인덱스로 접근)
System.out.println(names.size());  // 4 (현재 원소 개수)

names.remove("영희");              // 값으로 삭제
System.out.println(names);         // [철수, 민수, 지훈]

names.remove(0);                   // 인덱스로 삭제
System.out.println(names);         // [민수, 지훈]

System.out.println(names.contains("지훈")); // true
```

`List<String> names = new ArrayList<>();`처럼 변수 선언에는 인터페이스 타입(`List`)을 쓰고, 실제 객체 생성에는 구현체(`ArrayList`)를 쓰는 것이 관례다. 이렇게 해두면 나중에 `ArrayList`를 다른 구현체로 바꾸더라도 `names`를 사용하는 나머지 코드는 전혀 손댈 필요가 없다. 이는 10장과 11장에서 배운, 인터페이스를 통해 구체적인 구현에 의존하지 않고 프로그래밍한다는 원칙을 그대로 적용한 것이다.

배열과 비교하면 `ArrayList`는 원소를 추가·삭제할 때 내부적으로 배열 크기를 자동으로 조정해 주기 때문에, 개발자가 크기를 신경 쓰지 않고 `add`와 `remove`만 호출하면 된다.

## Set과 HashSet: 중복 없는 집합

`Set`은 중복된 값을 저장할 수 없고, 값 사이의 순서도 보장하지 않는다. 가장 많이 쓰는 구현체는 `HashSet`이다.

```java
import java.util.HashSet;
import java.util.Set;

Set<String> visitedCities = new HashSet<>();
visitedCities.add("서울");
visitedCities.add("부산");
visitedCities.add("서울"); // 이미 있는 값이므로 무시된다

System.out.println(visitedCities.size());        // 2
System.out.println(visitedCities.contains("부산")); // true

visitedCities.remove("부산");
System.out.println(visitedCities);                // [서울] (순서는 보장되지 않음)
```

`Set`이 유용한 대표적인 상황은 "중복 없이 어떤 값들의 집합만 필요하고, 순서는 상관없을 때"다. 예를 들어 방문한 도시 목록에서 같은 도시를 여러 번 추가해도 실제로는 한 번만 저장되기를 원한다면 `List` 대신 `Set`을 쓰는 것이 자연스럽다. 만약 배열이나 `List`로 중복 제거를 직접 구현하려면 매번 `contains`로 검사한 뒤에 추가하는 반복문을 짜야 하는데, `Set`은 이 로직을 이미 내장하고 있다.

## Map과 HashMap: 키와 값의 연관 관계

`Map`은 배열이나 `List`, `Set`과 다르게 값을 하나씩 저장하지 않고, 키(key)와 값(value)을 한 쌍으로 저장한다. 키를 이용해서 값을 빠르게 찾을 수 있다는 것이 핵심이다. 대표 구현체는 `HashMap`이다.

```java
import java.util.HashMap;
import java.util.Map;

Map<String, Integer> scores = new HashMap<>(); // 키: String, 값: Integer
scores.put("철수", 90);
scores.put("영희", 85);
scores.put("민수", 78);

System.out.println(scores.get("영희"));          // 85
System.out.println(scores.containsKey("민수"));  // true
System.out.println(scores.containsKey("지훈"));  // false

scores.put("철수", 95); // 같은 키로 다시 put하면 값이 덮어써진다
System.out.println(scores.get("철수"));          // 95

scores.remove("민수");
System.out.println(scores.size()); // 2
```

배열이나 `List`로 이름과 점수를 함께 관리하려면 이름 배열과 점수 배열을 따로 두고 인덱스를 맞춰야 하는데, 이는 실수하기 쉽고 관리하기도 번거롭다. `Map`을 쓰면 "이름"이라는 키로 바로 "점수"라는 값을 얻을 수 있어서 훨씬 직관적이다.

`Map`의 타입 매개변수는 `Map<K, V>` 형태로 키의 타입 `K`와 값의 타입 `V`를 각각 지정한다. 이는 13장에서 살펴본 `Pair<A, B>` 같은, 두 개의 타입 매개변수를 갖는 제네릭 클래스와 같은 원리다.

## 컬렉션 순회하기: for-each와 Iterator

컬렉션에 담긴 값을 하나씩 꺼내 보는 것을 **순회(iteration)**라고 한다. 6장에서 배운 for-each 문은 컬렉션을 순회할 때도 그대로 사용할 수 있다.

```java
List<String> names = new ArrayList<>();
names.add("철수");
names.add("영희");
names.add("민수");

for (String name : names) {
    System.out.println(name);
}
```

`Map`은 값이 키와 짝을 이루기 때문에 순회 방식이 조금 다르다. `entrySet()`을 사용하면 키와 값을 한 쌍으로 순회할 수 있다.

```java
Map<String, Integer> scores = new HashMap<>();
scores.put("철수", 90);
scores.put("영희", 85);

for (Map.Entry<String, Integer> entry : scores.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}

// 키만 필요하다면 keySet(), 값만 필요하다면 values()를 사용할 수 있다
for (String name : scores.keySet()) {
    System.out.println(name);
}
```

for-each 문 내부에서는 실제로 **`Iterator`**라는 객체가 동작한다. `Iterator`는 컬렉션을 한 번에 하나씩 순회하면서, 순회 중에 안전하게 원소를 삭제할 수 있게 해주는 객체다. for-each 문은 삭제가 필요 없는 단순 순회에는 편리하지만, 순회하면서 특정 조건의 원소를 지우고 싶다면 `Iterator`를 직접 사용해야 한다.

```java
List<Integer> numbers = new ArrayList<>();
numbers.add(1);
numbers.add(2);
numbers.add(3);
numbers.add(4);

Iterator<Integer> it = numbers.iterator();
while (it.hasNext()) {
    int value = it.next();
    if (value % 2 == 0) {
        it.remove(); // 순회 중 안전하게 삭제
    }
}
System.out.println(numbers); // [1, 3]
```

참고로 for-each 문을 순회하는 도중에 `list.remove(...)`를 직접 호출하면 `ConcurrentModificationException`이 발생한다. 순회하면서 삭제해야 한다면 반드시 `Iterator`의 `remove()`를 사용해야 한다는 점을 기억해 두자.

## Collections 유틸리티 클래스

자바는 컬렉션을 다루는 데 유용한 정적(static) 메서드들을 모아둔 `Collections` 클래스도 제공한다. (`List`, `Set`, `Map`과 이름이 비슷해서 혼동하기 쉬운데, `Collections`는 클래스 이름이고 나머지는 인터페이스 이름이다.)

```java
import java.util.Collections;

List<Integer> numbers = new ArrayList<>();
numbers.add(5);
numbers.add(2);
numbers.add(8);
numbers.add(1);

Collections.sort(numbers);              // 정렬: [1, 2, 5, 8]
System.out.println(numbers);

Collections.reverse(numbers);           // 순서 뒤집기: [8, 5, 2, 1]
System.out.println(numbers);

System.out.println(Collections.max(numbers)); // 8
System.out.println(Collections.min(numbers)); // 1
```

`Collections.sort`로 사용자 정의 클래스를 정렬하려면, 13장에서 다룬 `Comparable` 인터페이스를 그 클래스가 구현하고 있어야 한다. `<T extends Comparable<T>>` 같은 제한된 타입 매개변수가 실제로 `Collections.sort`의 내부 시그니처에도 쓰이고 있다는 점을 알아두면, 제네릭과 컬렉션이 서로 어떻게 맞물려 설계되었는지 이해하는 데 도움이 된다.

## 다음 장 예고: 스트림으로 컬렉션 다루기

지금까지 살펴본 방식은 컬렉션을 순회하면서 반복문으로 원하는 값을 걸러내거나 가공하는 전통적인 방법이었다. 예를 들어 "점수가 80점 이상인 학생의 이름만 뽑아서 정렬하기" 같은 작업을 하려면 `for` 문과 조건문, `Collections.sort`를 조합해서 여러 줄의 코드를 작성해야 한다.

16장에서 배울 **스트림(Stream)**은 이런 "컬렉션에서 데이터를 걸러내고, 변형하고, 모으는" 작업을 훨씬 간결하고 선언적인 방식으로 표현할 수 있게 해준다. 스트림을 제대로 활용하려면 이 장에서 배운 `List`, `Set`, `Map`의 기본 개념과, 15장에서 배울 람다식이 먼저 필요하다. 지금은 컬렉션에 값을 담고 꺼내고 순회하는 기본 동작에 익숙해지는 것이 중요하다.

## 요약

- 배열은 크기가 고정되어 있고 검색·삭제 기능이 없어서, 자바는 이를 보완하는 컬렉션 프레임워크를 제공한다.
- `List`(대표 구현체 `ArrayList`)는 순서를 유지하고 중복을 허용하는 목록으로, 크기가 자동으로 늘어난다.
- `Set`(대표 구현체 `HashSet`)은 중복을 허용하지 않는 집합으로, 순서를 보장하지 않는다.
- `Map`(대표 구현체 `HashMap`)은 키와 값을 쌍으로 저장하며, 키를 통해 값을 빠르게 조회한다.
- 컬렉션 순회는 for-each 문이 가장 간결하지만, 순회 중 삭제가 필요하면 `Iterator`를 직접 사용해야 한다.
- `Collections` 클래스는 정렬, 최대/최소 찾기 등 컬렉션을 다루는 유틸리티 정적 메서드를 제공한다.
- 16장에서는 스트림을 이용해 컬렉션 데이터를 더 간결하게 걸러내고 변형하는 방법을 배운다.

## 연습문제

1. `ArrayList<String>`을 사용해서 이름을 5개 저장하고, 그중 하나를 인덱스로 삭제한 뒤 결과를 출력하라.
2. `HashSet<Integer>`를 사용해서 배열에 담긴 정수 중 중복을 제거한 목록을 만들어라. (배열을 순회하며 `Set`에 추가하기만 하면 된다.)
3. `HashMap<String, Integer>`를 사용해서 과일 이름과 가격을 저장하고, `entrySet()`을 순회하며 "사과: 1000원"과 같은 형식으로 출력하라.
4. `List<Integer>`에서 짝수만 `Iterator`를 사용해 제거하는 코드를 작성하고, for-each 문으로 같은 작업을 시도하면 왜 `ConcurrentModificationException`이 발생하는지 설명하라.
5. `Collections.sort`와 `Collections.max`, `Collections.min`을 사용해서 정수 리스트의 정렬 결과와 최댓값, 최솟값을 함께 출력하는 프로그램을 작성하라.
