## 스코프 함수 치트시트

Kotlin 표준 라이브러리에는 어떤 객체를 대상으로 짧은 코드 블록을 실행할 때 쓰는 다섯 가지 스코프 함수(scope function)가 있습니다. `let`, `also`, `apply`, `run`, `with`가 그것입니다. 이들은 8장의 null 안전성 관용구, 13장의 람다와 고차 함수를 조합해서 만들어진 함수로, 겉보기에는 비슷해 보이지만 "블록 안에서 대상을 어떻게 가리키는지"와 "블록의 결과로 무엇을 돌려주는지"가 각각 다릅니다.

| 함수 | 블록 안에서 대상 참조 | 반환값 | 주로 쓰는 상황 |
|---|---|---|---|
| `let` | `it` (람다 매개변수) | 블록의 마지막 표현식 결과 | null이 아닐 때만 실행하기, 값을 변형해서 다른 값으로 넘기기 |
| `also` | `it` (람다 매개변수) | 객체 자기 자신 | 부수 효과(로그 출력, 검증 등)를 끼워 넣으면서 원래 값을 그대로 이어쓰기 |
| `apply` | `this` (수신 객체) | 객체 자기 자신 | 객체를 생성하면서 여러 프로퍼티를 한 번에 설정하기 |
| `run` | `this` (수신 객체) | 블록의 마지막 표현식 결과 | 객체의 프로퍼티·메서드를 여러 번 참조하며 계산한 결과를 돌려받기 |
| `with` | `this` (수신 객체) | 블록의 마지막 표현식 결과 | 이미 있는 객체를 대상으로 여러 작업을 묶어서 수행하기 (확장 함수가 아니라 일반 함수) |

```kotlin
data class User(var name: String, var age: Int = 0)

fun main() {
    // let: null이 아닐 때만 실행 + 변형된 값을 반환
    val nickname: String? = "서연"
    val greeting = nickname?.let { "$it 님, 안녕하세요!" } ?: "손님, 안녕하세요!"
    println(greeting)

    // also: 원래 객체를 그대로 이어받으면서 부수 효과만 끼워 넣기
    val user = User("민준").also {
        println("생성된 사용자: ${it.name}")
    }

    // apply: 객체를 만들면서 여러 프로퍼티를 한 번에 설정하기
    val configured = User("하윤").apply {
        age = 27   // this.age = 27과 동일
    }

    // run: 수신 객체를 대상으로 계산한 결과를 바로 반환
    val description = configured.run {
        "$name(${age}세)"
    }
    println(description)

    // with: 이미 있는 객체를 대상으로 여러 작업을 묶어서 수행
    val summary = with(configured) {
        "이름=$name, 나이=$age"
    }
    println(summary)
}
```

다섯 함수를 고를 때는 다음 두 질문을 떠올리면 됩니다.

1. 블록 안에서 `it`으로 받는 게 편한가, `this`로 받아 마치 그 객체 안에 있는 것처럼 쓰는 게 편한가? (`let`, `also`는 `it` / `apply`, `run`은 `this`)
2. 블록의 결과가 필요한가, 아니면 원래 객체를 그대로 이어쓰고 싶은가? (`also`, `apply`는 객체 자신을 반환 / `let`, `run`, `with`는 블록의 계산 결과를 반환)

## 컬렉션 메서드 요약표

12장에서 컬렉션의 기초를, 13장에서 람다와 결합한 고차 함수를 배웠습니다. 아래는 `List`, `Set`, `Map` 등에서 자주 쓰는 메서드를 목적별로 정리한 표입니다. 대부분 `Iterable`을 대상으로 하는 확장 함수(14장)이며, 원본 컬렉션을 바꾸지 않고 새 컬렉션이나 값을 반환합니다.

| 목적 | 메서드 | 한 줄 설명 |
|---|---|---|
| 변형 | `map { }` | 각 원소를 변환한 새 컬렉션을 만듭니다. |
| 변형 | `mapNotNull { }` | 변환 결과 중 `null`인 원소는 제외하고 모읍니다. |
| 필터링 | `filter { }` | 조건을 만족하는 원소만 남깁니다. |
| 필터링 | `filterNot { }` | 조건을 만족하지 않는 원소만 남깁니다. |
| 검색 | `find { }` / `firstOrNull { }` | 조건을 만족하는 첫 원소를 찾거나, 없으면 `null`을 반환합니다. |
| 검색 | `any { }` / `all { }` / `none { }` | 조건을 만족하는 원소가 하나라도/전부/하나도 없는지 검사합니다. |
| 집계 | `sum()` / `average()` / `count()` | 합계, 평균, 개수를 구합니다. |
| 집계 | `maxOrNull()` / `minOrNull()` | 최댓값, 최솟값을 구하며 컬렉션이 비어 있으면 `null`을 반환합니다. |
| 집계 | `reduce { }` / `fold(초기값) { }` | 원소를 순서대로 누적해 하나의 값으로 합칩니다. `fold`는 초기값을 직접 지정할 수 있습니다. |
| 그룹화 | `groupBy { }` | 조건에 따라 원소를 묶어 `Map`으로 반환합니다. |
| 정렬 | `sorted()` / `sortedBy { }` / `sortedDescending()` | 자연 순서, 기준 값, 내림차순으로 정렬한 새 컬렉션을 반환합니다. |
| 조합 | `zip(다른컬렉션)` | 두 컬렉션의 같은 위치 원소끼리 짝지어 새 컬렉션을 만듭니다. |
| 문자열 변환 | `joinToString(구분자)` | 모든 원소를 하나의 문자열로 이어 붙입니다. |
| 순회 | `forEach { }` | 각 원소에 대해 블록을 실행합니다(반환값 없음). |
| 변경 가능 컬렉션 | `add`, `remove`, `clear` | `MutableList`, `MutableSet` 등에서 컬렉션 내용을 직접 바꿉니다(18장 참고: 외부에 노출할 때는 주의). |

```kotlin
fun main() {
    val numbers = listOf(3, 1, 4, 1, 5, 9, 2, 6)

    val doubled = numbers.map { it * 2 }
    val evens = numbers.filter { it % 2 == 0 }
    val total = numbers.sum()
    val grouped = numbers.groupBy { if (it % 2 == 0) "짝수" else "홀수" }
    val sortedDesc = numbers.sorted().reversed()

    println(doubled)
    println(evens)
    println(total)
    println(grouped)
    println(sortedDesc)
}
```

## 연산자 우선순위표

4장에서 배운 연산자들을 우선순위가 높은 것부터 낮은 것 순서로 정리했습니다. 같은 줄에 있는 연산자는 우선순위가 같으며, 이 경우 대부분 왼쪽에서 오른쪽으로 계산됩니다. 헷갈릴 때는 표를 참고하되, 실제 코드에서는 괄호 `()`를 적극적으로 사용해 의도를 명확히 드러내는 편이 안전합니다.

| 우선순위 | 연산자 | 설명 |
|---|---|---|
| 높음 | `.`, `?.`, `?`, `[]`, `()` | 멤버 접근, 안전 호출, 인덱스 접근, 함수 호출 |
| ↑ | `!!` | non-null assertion |
| | `-`, `+` (단항) | 단항 부호, `!` (논리 부정) |
| | `*`, `/`, `%` | 곱셈, 나눗셈, 나머지 |
| | `+`, `-` (이항) | 덧셈, 뺄셈 |
| | `..` | 범위(range) 생성 |
| | `in`, `!in` | 포함 여부 검사 |
| | `is`, `!is` | 타입 검사 |
| | `<`, `>`, `<=`, `>=` | 비교 연산자 |
| | `==`, `!=` | 동등성 비교 |
| | `&&` | 논리 AND |
| ↓ | `\|\|` | 논리 OR |
| 낮음 | `=`, `+=`, `-=`, `*=`, `/=`, `%=` | 대입 및 복합 대입 연산자 |

```kotlin
fun main() {
    val a = 2
    val b = 3
    val c = 4

    // *가 +보다 먼저 계산되므로 b * c가 먼저 실행된다
    val result = a + b * c   // 2 + 12 = 14
    println(result)

    // 범위(..)는 비교 연산자보다 우선순위가 높다
    val inRange = a in 1..5 && c > b   // (a in 1..5) && (c > b)
    println(inRange)
}
```

## 더 깊이 공부하고 싶다면: 참고할 자료 유형

이 책은 Kotlin 언어의 기초를 다지는 것에 초점을 맞췄기 때문에, 다루지 않은 세부 사항이나 최신 변경 사항은 앞으로 직접 찾아 익혀야 합니다. 특정 책이나 강의를 추천하기보다는, 어떤 "종류"의 자료를 어떤 상황에 찾아보면 좋을지 안내합니다.

- **언어 공식 레퍼런스**: 문법의 정확한 동작, 새로 추가된 기능, 각 표준 라이브러리 함수의 정확한 매개변수와 동작 방식을 확인하고 싶을 때는 언어를 관리하는 조직이 직접 제공하는 공식 문서를 최우선으로 참고하는 것이 좋습니다. 특히 이 책에서 다루지 않은 제네릭의 변성, 위임 프로퍼티, 애노테이션, 코루틴의 `Flow` 등은 공식 문서에 예제와 함께 잘 정리되어 있습니다.
- **표준 라이브러리 API 문서**: `let`, `map`, `filter`처럼 이 부록에서 소개한 함수들의 정확한 시그니처와 반환 타입이 궁금할 때는 표준 라이브러리 API 문서를 검색해서 확인하는 습관을 들이면 좋습니다.
- **플랫폼별 공식 가이드**: 18장에서 언급한 안드로이드 개발, 서버 백엔드, 멀티플랫폼처럼 특정 분야로 학습을 이어가려면, 해당 플랫폼을 관리하는 조직이 제공하는 공식 가이드나 튜토리얼부터 시작하는 것이 가장 최신 정보를 얻는 방법입니다.
- **언어 변경 로그와 릴리스 노트**: Kotlin은 지금도 계속 발전하는 언어입니다. 새 버전이 나올 때마다 공개되는 릴리스 노트를 훑어보면, 문법이 어떻게 개선되고 있는지, 어떤 관용구가 새롭게 권장되는지를 꾸준히 따라갈 수 있습니다.
- **커뮤니티와 오픈소스 코드**: 다른 사람이 작성한 실전 코드를 읽는 것도 좋은 학습 방법입니다. 잘 정비된 오픈소스 프로젝트의 코드를 읽으며 이 책에서 배운 관용구(데이터 클래스, 확장 함수, 스코프 함수, sealed class 등)가 실제로 어떻게 쓰이는지 관찰해 보면 도움이 됩니다.

무엇을 참고하든, 새로운 문법을 발견하면 이 책에서 했던 것처럼 "왜 이 기능이 필요했을까"를 먼저 생각해보는 습관이 학습을 오래 지속시키는 데 도움이 됩니다.
