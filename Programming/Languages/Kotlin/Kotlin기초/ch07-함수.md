지금까지 작성한 코드는 대부분 `main` 함수 안에 순서대로 늘어놓은 문장들이었습니다. 프로그램이 커지면 같은 계산을 여러 곳에서 반복하게 되고, 그때마다 코드를 복사해서 붙여 넣으면 실수하기도 쉽고 나중에 수정하기도 어려워집니다. 함수(function)는 이런 반복되는 작업을 이름을 가진 하나의 단위로 묶어두는 도구입니다. 이 장에서는 Kotlin에서 함수를 정의하는 방법, 매개변수와 반환값을 다루는 방법, 그리고 코드를 더 간결하게 만들어주는 몇 가지 문법을 살펴봅니다.

## fun으로 함수 정의하기

Kotlin에서 함수는 `fun` 키워드로 시작합니다. 이미 2장에서 본 `main` 함수도 사실 `fun` 키워드로 정의된 함수입니다.

```kotlin
fun greet() {
    println("안녕하세요!")
}

fun main() {
    greet()
    greet()
}
```

`greet`라는 이름의 함수를 한 번 정의해두면, `main`에서 필요할 때마다 `greet()`라고 호출해서 재사용할 수 있습니다. 함수 이름 뒤의 괄호 `()`는 이 함수가 받는 매개변수 목록이 들어가는 자리인데, 위 예제에서는 매개변수가 없어서 빈 괄호로 남아 있습니다.

## 매개변수와 반환값

함수가 외부에서 값을 받아서 작업하려면 매개변수(parameter)를 선언합니다. Kotlin에서는 매개변수마다 이름과 타입을 반드시 함께 적어야 합니다. 3장에서 배운 변수 선언과 비슷하게 `이름: 타입` 형태를 씁니다.

```kotlin
fun addTax(price: Int, taxRate: Double): Int {
    val tax = (price * taxRate).toInt()
    return price + tax
}

fun main() {
    val total = addTax(10000, 0.1)
    println("세금 포함 가격: $total")
}
```

함수가 값을 돌려줄 때는 함수 이름과 매개변수 목록 뒤에 콜론(`:`)을 쓰고 반환 타입을 적습니다. 함수 본문 안에서는 `return` 키워드로 실제 값을 돌려줍니다. `addTax` 함수는 `Int`를 반환하므로, 호출한 쪽에서는 `total`이라는 변수에 그 결과를 담을 수 있습니다.

반환할 값이 없는 함수도 있습니다. 앞서 본 `greet` 함수처럼 화면에 출력만 하고 끝나는 경우인데, 이런 함수의 반환 타입은 `Unit`입니다. `Unit`은 "특별히 의미 있는 값을 반환하지 않는다"는 뜻을 가진 타입으로, 다른 언어의 `void`와 비슷한 역할을 합니다. Kotlin에서는 반환 타입이 `Unit`일 때는 생략해도 되므로, 지금까지 본 예제들처럼 반환 타입을 따로 적지 않은 함수는 모두 `Unit`을 반환한다고 보면 됩니다.

```kotlin
fun greet(): Unit {   // Unit은 생략 가능
    println("안녕하세요!")
}
```

## 기본값 매개변수

함수를 호출할 때마다 모든 매개변수에 값을 채워 넣어야 한다면 번거로울 때가 많습니다. 예를 들어 인사말을 출력하는 함수에서 상대방의 이름은 매번 다르지만, 인사말 자체는 대부분 "안녕하세요"로 충분한 경우가 많습니다. 이런 상황을 위해 Kotlin은 기본값 매개변수(default parameter)를 지원합니다.

```kotlin
fun greet(name: String, message: String = "안녕하세요") {
    println("$name 님, $message!")
}

fun main() {
    greet("지수")                     // message는 기본값 사용
    greet("민준", "좋은 하루입니다")   // message를 직접 지정
}
```

매개변수 선언 뒤에 `= 값`을 붙이면 호출할 때 그 인자를 생략할 수 있습니다. 첫 번째 호출 `greet("지수")`는 `message`에 기본값인 "안녕하세요"가 그대로 쓰이고, 두 번째 호출은 직접 넘긴 값으로 덮어씁니다. Java에서는 오버로딩(같은 이름의 함수를 매개변수 개수만 다르게 여러 번 정의하는 방식)으로 이런 유연함을 흉내 냈지만, Kotlin에서는 기본값 매개변수 하나로 충분한 경우가 많습니다.

## 이름 붙은 인자

매개변수가 여러 개이고 그중 몇몇이 같은 타입일 때는, 호출하는 코드만 봐서는 어떤 값이 어떤 매개변수로 들어가는지 헷갈리기 쉽습니다.

```kotlin
fun createUser(name: String, age: Int, isAdmin: Boolean = false) {
    println("이름: $name, 나이: $age, 관리자여부: $isAdmin")
}

fun main() {
    // 위치로만 넘기면 순서를 착각하기 쉽다
    createUser("서연", 27)

    // 이름을 붙이면 순서와 무관하게 의도가 분명해진다
    createUser(age = 27, name = "서연", isAdmin = true)
}
```

`age = 27`처럼 매개변수 이름을 명시하면서 값을 넘기는 방식을 이름 붙은 인자(named argument)라고 합니다. 이름 붙은 인자를 쓰면 순서를 바꿔도 되고, 코드를 읽을 때도 각 값이 무엇을 의미하는지 바로 알 수 있습니다. 특히 기본값 매개변수가 여러 개 있는 함수에서, 뒤쪽에 있는 매개변수 하나만 바꾸고 싶을 때 이름 붙은 인자가 유용합니다.

```kotlin
fun createUser(name: String, age: Int = 20, isAdmin: Boolean = false) {
    println("이름: $name, 나이: $age, 관리자여부: $isAdmin")
}

fun main() {
    // age는 기본값 그대로 두고 isAdmin만 지정
    createUser(name = "하윤", isAdmin = true)
}
```

이름 붙은 인자와 위치 인자를 섞어 쓸 수도 있지만, 위치 인자는 반드시 이름 붙은 인자보다 먼저 와야 합니다.

## 단일 표현식 함수

`addTax` 함수처럼 함수 본문이 계산 하나로 끝나는 경우, Kotlin에서는 중괄호와 `return`을 생략하고 등호(`=`)로 바로 결과를 연결할 수 있습니다.

```kotlin
fun square(x: Int) = x * x

fun addTax(price: Int, taxRate: Double) = price + (price * taxRate).toInt()

fun main() {
    println(square(5))          // 25
    println(addTax(10000, 0.1)) // 11000
}
```

이런 형태를 단일 표현식 함수(single-expression function)라고 부릅니다. 함수 본문이 `{ }` 블록이 아니라 표현식 하나이기 때문에, 컴파일러는 그 표현식의 타입을 보고 반환 타입을 스스로 추론합니다. 그래서 반환 타입을 따로 적지 않아도 됩니다. 다만 함수가 재귀적으로 자기 자신을 호출하거나, 여러 사람이 코드를 읽을 때 반환 타입이 명확히 드러나는 게 좋다고 판단되면 타입을 명시적으로 적어주는 것도 좋은 습관입니다.

```kotlin
fun square(x: Int): Int = x * x
```

단일 표현식 함수는 짧고 명확한 계산 로직을 표현할 때 특히 자주 쓰입니다. 4장에서 다룬 연산자와 표현식, 5장의 `if` 표현식을 떠올려보면, `if`도 값을 반환하는 표현식이었으므로 단일 표현식 함수의 본문으로 자연스럽게 들어갈 수 있습니다.

```kotlin
fun maxOf(a: Int, b: Int) = if (a > b) a else b
```

## 함수를 값으로 다루기, 그리고 다음 장 예고

지금까지 본 함수는 모두 이름을 가지고 특정 위치에서 정의된 다음, 필요할 때 그 이름으로 호출되는 형태였습니다. 그런데 Kotlin에서는 함수 자체를 변수에 담거나 다른 함수의 매개변수로 넘기는 것도 가능합니다. 즉 함수를 정수나 문자열 같은 하나의 값처럼 다룰 수 있다는 뜻입니다. 이런 함수를 람다(lambda)라고 부르며, 컬렉션을 다루거나 콜백을 작성할 때 매우 자주 사용됩니다. 이 내용은 12장에서 컬렉션 기초를 다진 뒤, 13장 "람다와 고차함수"에서 본격적으로 배웁니다.

## 요약

- 함수는 `fun` 키워드로 정의하며, 반복되는 코드를 이름을 가진 단위로 묶어 재사용할 수 있게 해줍니다.
- 매개변수는 `이름: 타입` 형태로 선언하고, 반환 타입은 함수 선언 뒤에 콜론과 함께 적습니다. 반환값이 없으면 `Unit`이며 생략할 수 있습니다.
- 기본값 매개변수(`매개변수: 타입 = 기본값`)를 이용하면 호출할 때 일부 인자를 생략할 수 있습니다.
- 이름 붙은 인자(`이름 = 값`)를 사용하면 인자의 순서에 얽매이지 않고 의도를 명확하게 드러낼 수 있습니다.
- 본문이 표현식 하나로 끝나는 함수는 `fun 이름(...) = 표현식` 형태의 단일 표현식 함수로 간결하게 작성할 수 있습니다.
- 함수를 값처럼 다루는 람다는 13장에서 자세히 배웁니다.

## 연습문제

1. 두 정수를 받아 더 큰 값을 반환하는 단일 표현식 함수 `maxOf(a: Int, b: Int)`를 작성하세요.
2. 학생의 점수를 받아 등급을 반환하는 함수 `getGrade(score: Int): String`을 작성하세요. 90 이상은 "A", 80 이상은 "B", 70 이상은 "C", 그 미만은 "F"를 반환해야 합니다.
3. 이름, 나이(기본값 없음), 도시(기본값 "서울")를 매개변수로 받아 자기소개 문장을 출력하는 함수 `introduce`를 작성하고, 도시를 생략한 호출과 이름 붙은 인자로 도시만 지정한 호출을 각각 만들어보세요.
4. 원의 반지름을 받아 넓이를 계산하는 단일 표현식 함수 `circleArea(radius: Double)`을 작성하고, `println`으로 결과를 확인하세요. (원주율은 `Math.PI` 사용)
5. 세 개의 정수를 매개변수로 받되 두 번째와 세 번째 매개변수에 기본값을 설정한 함수를 정의하고, 위치 인자와 이름 붙은 인자를 섞어서 호출하는 예제를 최소 두 가지 이상 작성해보세요.
