프로그래밍을 처음 접하는 사람과 다른 언어 경험자를 모두 아우르는 Kotlin 입문서입니다.
변수와 자료형 같은 기초 문법부터 null 안전성, 클래스와 상속, 람다와 확장 함수,
sealed class, 코루틴, Java 상호운용까지 Kotlin의 핵심 개념을 순서대로 다룹니다.

각 장은 개념 설명, 예제 코드, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는 이해를 돕는
다이어그램을 함께 실었습니다.
