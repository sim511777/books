## 함수도 값이다

7장에서 함수를 정의하고 호출하는 방법을 배웠다. 그때는 함수를 "코드를 실행하는 도구"로만 다뤘지만, Kotlin에서 함수는 그 이상이다. 정수나 문자열처럼 변수에 담을 수 있고, 다른 함수의 매개변수로 넘길 수 있고, 함수의 반환값이 될 수도 있다. 이런 성질을 가리켜 함수를 "일급 시민(first-class citizen)"으로 다룬다고 말한다.

함수를 값으로 다룬다는 게 어떤 의미인지 간단한 예로 살펴보자.

```kotlin
fun square(x: Int): Int = x * x

fun main() {
    // square 함수 자체를 변수에 담는다 (호출이 아니라 참조)
    val operation: (Int) -> Int = ::square
    println(operation(5)) // 25
}
```

`::square`는 함수 참조 문법이다. `(Int) -> Int`는 "Int를 받아서 Int를 반환하는 함수"라는 타입을 뜻한다. 함수의 타입을 이렇게 명시적으로 쓸 수 있다는 사실이 핵심이다. 매개변수로 함수를 받거나 함수를 반환하는 함수를 **고차 함수(higher-order function)**라고 부른다.

## 람다: 이름 없는 함수

매번 `fun square(x: Int) = x * x`처럼 이름을 붙여 함수를 선언하는 건 번거롭다. 특히 딱 한 번만 쓰고 버릴 짧은 함수라면 이름조차 필요 없다. 이럴 때 쓰는 것이 **람다식(lambda expression)**이다.

```kotlin
val square: (Int) -> Int = { x -> x * x }

fun main() {
    println(square(5)) // 25
}
```

람다의 기본 문법은 중괄호 `{ }` 안에 매개변수와 화살표(`->`), 그리고 실행할 코드를 나열하는 것이다.

```kotlin
{ 매개변수1, 매개변수2 -> 실행할 코드 }
```

매개변수가 여러 개면 쉼표로 구분한다.

```kotlin
val add: (Int, Int) -> Int = { a, b -> a + b }
println(add(3, 4)) // 7
```

람다의 마지막 줄에 있는 식이 곧 반환값이 된다. `return` 키워드는 필요 없다(오히려 람다 안에서 `return`을 쓰면 다른 의미를 가지므로 주의가 필요한데, 이는 나중에 더 깊이 다룰 주제다).

## 고차 함수를 직접 만들어보기

이제 람다를 매개변수로 받는 함수를 직접 만들어보자.

```kotlin
// operation이라는 이름의 매개변수가 함수를 받는다
fun calculate(a: Int, b: Int, operation: (Int, Int) -> Int): Int {
    return operation(a, b)
}

fun main() {
    val sum = calculate(10, 20) { x, y -> x + y }
    val product = calculate(10, 20) { x, y -> x * y }

    println(sum)     // 30
    println(product) // 200
}
```

여기서 `calculate(10, 20) { x, y -> x + y }`처럼 마지막 인자가 람다일 때 소괄호 밖으로 빼내 중괄호만 남기는 문법을 볼 수 있다. 이것이 **트레일링 람다(trailing lambda)**다. 원래대로라면 `calculate(10, 20, { x, y -> x + y })`라고 써야 하지만, Kotlin은 마지막 매개변수가 함수 타입일 경우 괄호 밖으로 꺼내는 것을 허용한다. 매개변수가 람다 하나뿐이라면 소괄호 자체를 생략할 수도 있다.

## 컬렉션과 람다의 만남

람다가 가장 빛을 발하는 곳은 12장에서 배운 컬렉션이다. 리스트나 맵을 다룰 때 반복문을 직접 쓰는 대신, 컬렉션이 제공하는 고차 함수에 람다를 넘기면 훨씬 간결하고 읽기 쉬운 코드가 된다.

### forEach: 각 요소에 대해 실행

```kotlin
val fruits = listOf("사과", "바나나", "포도")

fun main() {
    fruits.forEach { fruit -> println(fruit) }
}
```

### map: 각 요소를 변환

```kotlin
val numbers = listOf(1, 2, 3, 4, 5)

fun main() {
    val doubled = numbers.map { n -> n * 2 }
    println(doubled) // [2, 4, 6, 8, 10]
}
```

### filter: 조건을 만족하는 요소만 남기기

```kotlin
fun main() {
    val evens = numbers.filter { n -> n % 2 == 0 }
    println(evens) // [2, 4]
}
```

이 세 함수는 조합해서 쓸 수도 있다.

```kotlin
fun main() {
    val result = numbers
        .filter { n -> n % 2 == 0 } // 짝수만 남기고
        .map { n -> n * n }          // 제곱한 뒤
        .forEach { n -> println(n) } // 출력
}
```

이런 식으로 "무엇을 할지"를 선언적으로 나열하는 방식은, `for` 문으로 인덱스를 관리하며 조건을 검사하던 6장의 코드보다 의도가 훨씬 뚜렷하게 드러난다.

## it: 매개변수가 하나뿐일 때의 축약

람다의 매개변수가 단 하나뿐이면, 매개변수 이름과 화살표를 생략하고 `it`이라는 암시적 이름을 쓸 수 있다.

```kotlin
fun main() {
    val doubled = numbers.map { it * 2 }
    val evens = numbers.filter { it % 2 == 0 }

    println(doubled) // [2, 4, 6, 8, 10]
    println(evens)   // [2, 4]
}
```

`{ n -> n * 2 }`와 `{ it * 2 }`는 완전히 같은 코드다. `it`은 람다가 짧고 단순할 때 특히 유용하지만, 람다가 길어지거나 중첩되면 `it`이 어느 람다를 가리키는지 헷갈릴 수 있다. 그럴 때는 명시적으로 이름(`n`, `fruit` 등)을 붙이는 편이 가독성에 좋다.

```kotlin
val words = listOf("kotlin", "java", "swift")

fun main() {
    // 중첩된 람다에서는 it 대신 이름을 명시하는 것이 안전하다
    val result = words.map { word ->
        word.filter { char -> char != 'a' }
    }
    println(result) // [kotln, jv, swift]
}
```

## 실전 예제: 학생 점수 처리

12장에서 다룬 데이터를 람다와 함께 활용해보자.

```kotlin
data class Student(val name: String, val score: Int)

fun main() {
    val students = listOf(
        Student("민준", 85),
        Student("서연", 92),
        Student("도윤", 78),
        Student("하은", 95)
    )

    // 90점 이상인 학생의 이름만 추출
    val topStudents = students
        .filter { it.score >= 90 }
        .map { it.name }

    println(topStudents) // [서연, 하은]

    // 전체 평균 점수 계산 (average는 map 결과에 사용 가능)
    val average = students.map { it.score }.average()
    println(average) // 87.5
}
```

`data class`는 10장에서 배울 내용을 미리 살짝 엿본 것인데, 지금은 "값을 담는 상자"라고만 이해해도 충분하다. 중요한 것은 `filter`와 `map`을 연결해서 원하는 결과를 단계적으로 만들어내는 흐름이다.

## 요약

- Kotlin에서 함수는 값으로 다뤄질 수 있다. 변수에 담거나 다른 함수의 인자로 전달할 수 있다.
- 함수를 매개변수로 받거나 반환하는 함수를 고차 함수라고 부른다.
- 람다식은 `{ 매개변수 -> 코드 }` 형태로 이름 없는 함수를 정의하는 문법이다.
- 마지막 매개변수가 함수 타입이면 소괄호 밖으로 람다를 빼낼 수 있다(트레일링 람다). 매개변수가 람다 하나뿐이면 소괄호 자체를 생략할 수 있다.
- 람다의 매개변수가 하나뿐일 때는 `it`으로 축약할 수 있지만, 중첩되거나 복잡해지면 이름을 명시하는 편이 안전하다.
- `forEach`, `map`, `filter` 등 컬렉션의 고차 함수와 람다를 조합하면 반복문보다 선언적이고 읽기 쉬운 코드를 작성할 수 있다.

## 연습문제

1. `(String) -> Int` 타입의 람다를 하나 작성하여, 문자열의 길이를 반환하도록 만들고 변수에 담아 호출해보라.
2. `listOf(3, 1, 4, 1, 5, 9, 2, 6)`에서 `filter`와 `map`을 사용해 "3보다 큰 수를 두 배로 만든 리스트"를 만들어보라.
3. 매개변수 두 개를 받아 그 중 더 큰 값을 반환하는 람다를 작성하고, 이를 인자로 받는 고차 함수 `pickLarger`를 정의해보라.
4. `it`을 사용한 람다와 명시적 이름을 사용한 람다를 각각 작성해보고, 어느 경우에 `it`이 가독성을 해칠 수 있는지 예를 들어 설명해보라.
5. 문자열 리스트 `listOf("kotlin", "is", "fun")`에서 `forEach`를 사용해 각 단어를 대문자로 변환하여 출력하는 코드를 작성해보라(`uppercase()` 함수를 활용).
