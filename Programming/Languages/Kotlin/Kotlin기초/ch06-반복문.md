5장에서 조건에 따라 코드 흐름을 분기하는 방법을 배웠다면, 이번 장에서는 같은 코드를 반복해서 실행하는 방법을 다룹니다. Kotlin의 반복문은 `while`, `do-while`, `for` 세 가지이며, 문법 자체는 다른 언어를 접해본 독자라면 낯설지 않을 것입니다. 다만 Kotlin의 `for`는 Java의 전통적인 `for (int i = 0; i < n; i++)` 형태가 아니라 범위(range)와 반복 가능한 대상을 순회하는 형태로만 존재한다는 점이 다릅니다. 이 장을 마치면 3장에서 배운 범위 문법과 12장에서 본격적으로 다룰 컬렉션을 반복문으로 조합해 다루는 감각을 익히게 됩니다.

## while과 do-while

`while`은 조건이 참인 동안 블록을 반복 실행합니다. 조건은 반복 시작 전에 검사됩니다.

```kotlin
fun main() {
    var count = 0

    while (count < 5) {
        println("현재 카운트: $count")
        count++
    }
}
```

조건이 처음부터 거짓이면 블록은 한 번도 실행되지 않습니다. 예를 들어 `count`가 이미 5 이상이라면 위 코드는 아무것도 출력하지 않습니다.

이와 달리 `do-while`은 블록을 **먼저 한 번 실행한 뒤** 조건을 검사합니다. 즉, 조건과 무관하게 최소 한 번은 반드시 실행되어야 하는 로직에 적합합니다.

```kotlin
fun main() {
    var input: String

    do {
        input = readLine() ?: ""
        println("입력받은 값: $input")
    } while (input != "종료")
}
```

사용자 입력을 받아 처리하는 상황처럼, 일단 한 번은 입력을 받아봐야 종료 조건을 판단할 수 있는 경우에 `do-while`이 자연스럽습니다. `readLine()`이 반환하는 값이 nullable이라는 점은 8장에서 다시 자세히 설명하며, 지금은 `?:` 연산자로 null일 때 빈 문자열을 대신 쓴다는 정도로만 이해하면 충분합니다.

`while`과 `do-while` 모두 Java와 문법이 거의 동일하므로, 이미 다른 언어 경험이 있는 독자라면 어려움 없이 사용할 수 있을 것입니다.

## for 문: 범위 순회

Kotlin의 `for`는 Java의 C 스타일 `for (int i = 0; i < n; i++)`를 지원하지 않습니다. 대신 3장에서 소개한 범위(range) 문법과 결합해 사용합니다.

```kotlin
fun main() {
    for (i in 1..5) {
        println("숫자: $i")
    }
}
```

`1..5`는 1부터 5까지(양 끝 포함)를 나타내는 `IntRange`입니다. 끝 값을 포함하고 싶지 않다면 `until`이나 배타적 범위 연산자를 씁니다.

```kotlin
for (i in 1 until 5) {
    println(i) // 1, 2, 3, 4 출력, 5는 포함되지 않음
}
```

이 두 방식의 차이는 사소해 보이지만 실무에서는 자주 실수하는 지점입니다. 배열이나 리스트의 인덱스를 순회할 때 마지막 원소를 하나 빼먹거나 하나 초과해서 접근하는 오류(off-by-one error)를 줄이려면 `until`이 유용합니다.

```kotlin
val fruits = listOf("사과", "바나나", "체리")

for (index in 0 until fruits.size) {
    println("${index}번째 과일: ${fruits[index]}")
}
```

## for 문: 컬렉션 순회

`for`의 진짜 강점은 인덱스를 직접 계산하지 않고 컬렉션의 원소를 곧바로 순회할 수 있다는 점입니다.

```kotlin
val fruits = listOf("사과", "바나나", "체리")

for (fruit in fruits) {
    println(fruit)
}
```

인덱스와 값이 모두 필요할 때는 `withIndex()`를 사용하면 인덱스 계산을 손수 하지 않아도 됩니다.

```kotlin
for ((index, fruit) in fruits.withIndex()) {
    println("$index: $fruit")
}
```

문자열도 문자(`Char`)의 시퀀스이므로 바로 순회할 수 있습니다.

```kotlin
for (ch in "Kotlin") {
    print("$ch-")
}
// 출력: K-o-t-l-i-n-
```

이런 순회 방식들은 12장에서 배울 `List`, `Set`, `Map` 등 다양한 컬렉션 타입에도 동일하게 적용되며, 13장에서 배울 `forEach` 같은 람다 기반 순회 함수와도 자연스럽게 연결됩니다. 지금 단계에서는 `for`가 값 자체를 다루는 데 집중한다는 점만 기억해 두면 됩니다.

## downTo와 step

범위를 거꾸로, 혹은 간격을 두고 순회해야 할 때는 `downTo`와 `step`을 씁니다.

```kotlin
fun main() {
    // 5부터 1까지 역순으로 순회
    for (i in 5 downTo 1) {
        println(i)
    }
}
```

`1..5`처럼 `..`로 만든 범위는 항상 작은 값에서 큰 값으로만 증가하기 때문에, 거꾸로 세려면 반드시 `downTo`를 써야 합니다. `1..5`를 역순으로 순회하려고 `reversed()`를 호출할 수도 있지만, `downTo`가 훨씬 직관적이고 별도의 컬렉션을 만들지 않아 효율적입니다.

`step`은 증가(또는 감소) 폭을 지정합니다.

```kotlin
fun main() {
    // 1부터 10까지 2씩 증가
    for (i in 1..10 step 2) {
        println(i) // 1, 3, 5, 7, 9
    }

    // 10부터 1까지 3씩 감소
    for (i in 10 downTo 1 step 3) {
        println(i) // 10, 7, 4, 1
    }
}
```

`downTo`와 `step`을 조합하면 짝수만 순회하거나, 일정 간격으로 샘플링하는 등의 로직을 별도의 조건문 없이 표현할 수 있습니다.

## break와 continue

반복문 중간에 흐름을 제어해야 할 때는 `break`와 `continue`를 사용합니다. `break`는 반복문을 즉시 종료하고, `continue`는 현재 반복만 건너뛰고 다음 반복으로 넘어갑니다.

```kotlin
fun main() {
    for (i in 1..10) {
        if (i == 6) break
        println(i)
    }
    // 1, 2, 3, 4, 5 출력 후 반복 종료
}
```

```kotlin
fun main() {
    for (i in 1..10) {
        if (i % 2 == 0) continue
        println(i)
    }
    // 홀수만 출력: 1, 3, 5, 7, 9
}
```

`break`와 `continue`는 `while`, `do-while`에서도 동일하게 동작합니다. 특정 값을 찾으면 더 이상 순회할 필요가 없는 경우(예: 리스트에서 조건을 만족하는 첫 원소를 찾는 상황) `break`로 불필요한 반복을 피할 수 있습니다. 다만 12장에서 배울 `find`, `first` 같은 컬렉션 함수를 쓰면 이런 탐색 로직을 반복문 없이도 표현할 수 있으므로, 반복문의 `break`는 어디까지나 직접 순회가 필요한 상황을 위한 도구로 이해하는 것이 좋습니다.

## 레이블을 이용한 중첩 루프 제어

반복문이 중첩되어 있을 때 `break`나 `continue`는 기본적으로 **가장 안쪽 반복문**에만 영향을 줍니다. 바깥쪽 반복문까지 한꺼번에 제어하려면 레이블(label)을 사용합니다. 레이블은 `이름@` 형태로 반복문 앞에 붙입니다.

```kotlin
fun main() {
    outer@ for (i in 1..3) {
        for (j in 1..3) {
            if (j == 2) break@outer
            println("i=$i, j=$j")
        }
    }
    // i=1, j=1 출력 후 바깥쪽 루프까지 종료
}
```

레이블이 없는 `break`였다면 안쪽 `for`만 종료되어 `i=2, j=1`, `i=3, j=1`이 이어서 출력됐을 것입니다. `break@outer`는 레이블이 붙은 `outer` 반복문 자체를 종료시킵니다.

`continue`에도 레이블을 붙일 수 있습니다.

```kotlin
fun main() {
    outer@ for (i in 1..3) {
        for (j in 1..3) {
            if (j == 2) continue@outer
            println("i=$i, j=$j")
        }
    }
    // i=1,j=1 / i=2,j=1 / i=3,j=1 만 출력됨
}
```

`continue@outer`는 안쪽 반복문의 남은 부분을 건너뛰고 바로 바깥쪽 반복문의 다음 순회로 넘어갑니다.

레이블은 강력하지만 과용하면 코드 흐름을 따라가기 어려워집니다. 이중 반복문 이상으로 중첩이 깊어지면서 레이블로 흐름을 제어해야 하는 상황이라면, 안쪽 로직을 별도의 함수로 분리하고 `return`으로 빠져나오는 편이 코드의 가독성 측면에서 더 나은 선택일 때가 많습니다. 이는 5장에서 다룬 조기 반환 패턴과도 일관된 방향입니다.

## 요약

- `while`은 조건을 먼저 검사하고, `do-while`은 블록을 한 번 실행한 뒤 조건을 검사합니다. 최소 한 번의 실행이 보장되어야 하는 로직에는 `do-while`이 적합합니다.
- Kotlin의 `for`는 C 스타일 반복문 대신 범위(`1..5`, `1 until 5`)와 컬렉션(`for (item in list)`) 순회로 동작합니다.
- `downTo`는 역순 순회, `step`은 증가/감소 간격을 지정합니다. 두 키워드는 조합해서 사용할 수 있습니다.
- `break`는 반복문을 종료하고, `continue`는 현재 반복을 건너뜁니다. 기본적으로는 가장 안쪽 반복문에만 적용됩니다.
- 레이블(`이름@`)을 반복문에 붙이면 `break@label`, `continue@label`로 바깥쪽 반복문까지 제어할 수 있지만, 과용은 가독성을 해칠 수 있습니다.
