3장에서 변수와 자료형을 다뤘으니 이제 그 값들을 가지고 실제로 무언가를 계산하고 비교하는 방법을 배울 차례입니다. 이번 장에서는 Kotlin의 연산자들을 살펴봅니다. 산술 연산부터 시작해서 관계 연산, 논리 연산, 그리고 Kotlin에 특징적인 범위 연산자까지 다룹니다. 마지막에는 8장에서 본격적으로 배울 null 관련 연산자를 살짝 미리 보겠습니다.

## 산술 연산자

가장 익숙한 연산자들부터 시작합시다.

```kotlin
val a = 10
val b = 3

println(a + b)   // 13, 더하기
println(a - b)   // 7,  빼기
println(a * b)   // 30, 곱하기
println(a / b)   // 3,  나누기 (정수 나눗셈은 소수부를 버린다)
println(a % b)   // 1,  나머지
```

여기서 주의할 점은 `Int`끼리 나눈 결과는 `Int`라는 것입니다. `10 / 3`은 수학적으로 3.333...이지만 정수끼리의 나눗셈이므로 결과는 3이 됩니다. 소수 결과가 필요하다면 둘 중 하나 이상을 `Double`로 만들어야 합니다.

```kotlin
val result1 = 10 / 3          // 3 (Int)
val result2 = 10.0 / 3        // 3.3333333333333335 (Double)
val result3 = 10 / 3.0        // 3.3333333333333335 (Double)
val result4 = a.toDouble() / b.toDouble()  // 명시적으로 변환
```

이 실수는 초보자가 자주 저지르는 실수 중 하나입니다. "왜 계산 결과가 소수점 없이 나오지?"라는 의문이 든다면 피연산자의 타입을 먼저 확인해보세요.

증감 연산자와 복합 대입 연산자도 자바와 동일하게 사용할 수 있습니다.

```kotlin
var count = 0
count++          // count = count + 1
count--          // count = count - 1
count += 5        // count = count + 5
count -= 2        // count = count - 2
count *= 3        // count = count * 3
```

증감 연산자를 쓰려면 대상이 재할당 가능해야 하므로, `val`로 선언된 변수에는 사용할 수 없습니다.

## 관계 연산자

두 값을 비교해서 `Boolean` 결과를 얻는 연산자들입니다.

```kotlin
val x = 5
val y = 8

println(x == y)   // false, 같다
println(x != y)   // true,  다르다
println(x < y)    // true
println(x > y)    // false
println(x <= y)   // true
println(x >= y)   // false
```

여기서 짚어두고 싶은 부분이 있습니다. 자바에서는 객체를 `==`로 비교하면 참조(주소)가 같은지를 확인하고, 값 자체가 같은지 확인하려면 `equals()`를 따로 호출해야 했습니다. Kotlin에서는 `==`가 곧 `equals()`를 호출하는 것과 같습니다. 즉 `==`는 값이 같은지를 비교하는 연산자입니다.

```kotlin
val s1 = "hello"
val s2 = "hel" + "lo"

println(s1 == s2)   // true, 내용이 같으면 true (Java의 equals와 동일)
println(s1 === s2)  // 참조가 같은지 비교하고 싶다면 === 를 사용
```

만약 두 참조가 정확히 같은 객체를 가리키는지 확인하고 싶다면 `===`(참조 동등성)를 사용합니다. 대부분의 실무 코드에서는 값 비교인 `==`를 사용하는 경우가 훨씬 많습니다. 클래스에서 이 비교 동작을 직접 정의하는 방법은 9장과 10장(데이터 클래스)에서 다룹니다.

## 논리 연산자

`Boolean` 값들을 조합할 때 사용합니다.

```kotlin
val isAdult = true
val hasTicket = false

println(isAdult && hasTicket)   // false, 논리 AND (둘 다 true여야 true)
println(isAdult || hasTicket)   // true,  논리 OR (하나라도 true면 true)
println(!isAdult)               // false, 논리 NOT (값을 반전)
```

`&&`와 `||`는 단축 평가(short-circuit evaluation)를 수행합니다. 즉 `&&`의 왼쪽이 `false`면 오른쪽은 평가하지 않고 곧바로 `false`를 반환하고, `||`의 왼쪽이 `true`면 오른쪽을 평가하지 않고 곧바로 `true`를 반환합니다. 이 특성은 함수 호출처럼 비용이 있는 연산을 오른쪽에 두어 불필요한 실행을 피할 때 유용합니다.

```kotlin
fun expensiveCheck(): Boolean {
    println("비용이 큰 검사 실행")
    return true
}

val skip = false
if (skip && expensiveCheck()) {
    // skip이 false이므로 expensiveCheck()는 호출되지 않는다
}
```

논리 연산자를 활용한 조건 판단은 5장 제어문에서 `if`, `when`과 함께 훨씬 자주 등장합니다.

## 범위 연산자

Kotlin에는 다른 언어에서 보기 힘든 독특한 연산자가 있습니다. 바로 범위(range)를 표현하는 `..` 연산자입니다.

```kotlin
val range = 1..5    // 1부터 5까지 (5를 포함)

for (i in range) {
    print("$i ")   // 1 2 3 4 5
}
```

범위는 `for` 반복문과 함께 자주 쓰이며, 이는 6장 반복문에서 더 깊이 다룹니다. 여기서는 범위 자체가 하나의 값이라는 점, 그리고 `in` 연산자와 짝을 이루어 "어떤 값이 이 범위 안에 있는가"를 검사할 수 있다는 점을 기억해두면 좋습니다.

```kotlin
val score = 85

val isPassGrade = score in 60..100      // true, 60 이상 100 이하인지 검사
val isFailGrade = score !in 60..100     // false, 범위에 포함되지 않는지 검사

println(isPassGrade)
println(isFailGrade)
```

`in`은 범위뿐 아니라 컬렉션에도 사용할 수 있어서 "이 리스트에 이 값이 들어 있는가"를 검사하는 데도 쓰입니다. 이 활용은 12장 컬렉션 기초에서 자세히 다룹니다.

끝값을 포함하지 않는 범위가 필요하다면 `until`을, 특정 간격으로 값을 건너뛰고 싶다면 `step`을 사용할 수 있습니다.

```kotlin
val until = 1 until 5   // 1, 2, 3, 4 (5는 포함하지 않는다)
val stepped = 1..10 step 3   // 1, 4, 7, 10
```

## null 관련 연산자 살짝 맛보기

지금까지 다룬 값들은 모두 항상 어떤 값을 갖고 있다고 가정했습니다. 그런데 실제 프로그램에서는 "값이 아직 없다" 또는 "값을 구할 수 없다"는 상황이 자주 생깁니다. Kotlin은 이런 상황을 `null`이라는 특별한 값과, 그것을 다루기 위한 전용 연산자로 표현합니다. 본격적인 내용은 8장 null 안전성에서 다루지만, 여기서 두 가지 연산자만 미리 살짝 소개하겠습니다.

```kotlin
val name: String? = null   // 타입 뒤에 ?를 붙이면 null을 허용한다는 뜻

// 안전 호출 연산자 ?. : name이 null이 아니면 length를 호출, null이면 결과도 null
println(name?.length)   // null

// 엘비스 연산자 ?: : 왼쪽 값이 null이면 오른쪽 값을 대신 사용
val displayName = name ?: "이름 없음"
println(displayName)    // 이름 없음
```

`String?`처럼 타입 뒤에 물음표가 붙으면 그 변수는 `null`을 담을 수 있다는 뜻입니다. `?.`는 값이 `null`이 아닐 때만 메서드나 속성에 접근하고, `null`이면 예외 없이 조용히 `null`을 반환합니다. `?:`(흔히 "엘비스 연산자"라고 부릅니다)는 왼쪽 값이 `null`일 때 사용할 기본값을 오른쪽에 지정합니다. 이 두 연산자는 Kotlin이 자바의 대표적인 골칫거리인 `NullPointerException`을 언어 차원에서 줄이는 핵심 도구입니다. 지금 당장 완전히 이해하지 않아도 괜찮습니다. 8장에서 이 개념을 처음부터 차근차근 풀어드립니다.

## 연산자 우선순위

지금까지 소개한 연산자들을 한 식에서 함께 사용하면, 어떤 연산이 먼저 계산되는지가 중요해집니다.

```kotlin
val result = 2 + 3 * 4      // 곱하기가 먼저 계산되어 14
val check = 1 + 2 > 2 && true  // 산술 -> 관계 -> 논리 순으로 계산
```

일반적으로 산술 연산자가 관계 연산자보다 먼저 계산되고, 관계 연산자는 논리 연산자보다 먼저 계산됩니다. 전체 연산자의 정확한 우선순위 표는 외워야 할 필요가 없습니다. 대신 의도가 헷갈릴 여지가 있다면 소괄호 `()`를 사용해 명시적으로 순서를 표현하는 것이 훨씬 안전하고 읽기 좋은 코드입니다. Kotlin 연산자 전체의 우선순위 표는 부록에 정리되어 있으니 필요할 때 참고하세요.

## 요약

- 산술 연산자(`+ - * / %`)는 자바와 유사하지만, `Int`끼리의 나눗셈은 소수부가 버려진 정수 결과를 낸다는 점에 주의해야 한다.
- `==`는 값(내용)이 같은지를 비교하며, 참조 자체가 같은지 비교하려면 `===`를 사용한다.
- `&&`, `||`, `!`는 단축 평가를 수행하는 논리 연산자다.
- `..`, `until`, `step`으로 범위를 만들고, `in`/`!in`으로 어떤 값이 범위나 컬렉션에 속하는지 검사할 수 있다.
- `?.`(안전 호출)와 `?:`(엘비스 연산자)는 `null`을 다루기 위한 연산자로, 자세한 내용은 8장에서 다룬다.
- 연산자 우선순위가 헷갈리면 외우려 하지 말고 괄호로 명확히 표현하는 것이 좋다. 전체 표는 부록 참고.

   ```kotlin
   val ready = true

       println("진행")
   }
   ```
