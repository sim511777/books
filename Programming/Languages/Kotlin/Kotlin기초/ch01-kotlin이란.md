# 1장. Kotlin이란 무엇인가

## 들어가며

새로운 프로그래밍 언어를 배우기 전에는 항상 "이 언어가 왜 만들어졌고, 어디에 쓰이는가"를 먼저 이해하는 것이 좋습니다. 목적을 알면 문법을 외울 때도 왜 그렇게 설계되었는지 납득할 수 있고, 학습 우선순위를 정하기도 쉬워집니다. 이 장에서는 Kotlin이 어떤 언어인지, Java와 어떤 관계인지, 실무에서 어디에 쓰이는지, 그리고 앞으로 이 책을 어떻게 읽어나가면 좋을지 살펴봅니다.

## Kotlin의 탄생 배경

Kotlin은 체코의 소프트웨어 회사 JetBrains가 2011년에 공개하고 2016년에 정식 1.0 버전을 발표한 프로그래밍 언어입니다. JetBrains는 IntelliJ IDEA 같은 개발 도구를 만드는 회사로, 자신들이 매일 사용하던 Java의 불편함—장황한 문법, null로 인한 예외, 느린 언어 진화 속도—을 해결하기 위해 사내 프로젝트로 Kotlin을 시작했습니다. 이름은 러시아 상트페테르부르크 인근의 코틀린(Kotlin)섬에서 따왔는데, Java라는 이름이 인도네시아의 자바섬에서 온 것에 대한 재치 있는 오마주로 알려져 있습니다.

Kotlin이 대중적으로 크게 주목받은 계기는 2017년 구글의 발표였습니다. 구글은 그해 I/O 컨퍼런스에서 Kotlin을 안드로이드 공식 개발 언어로 채택한다고 발표했고, 2019년에는 안드로이드 앱 개발의 "선호 언어(preferred language)"로 지정했습니다. 이후 Kotlin은 모바일 개발을 넘어 서버 백엔드, 데이터 처리, 심지어 iOS나 웹까지 아우르는 멀티플랫폼 언어로 영역을 넓혀가고 있습니다.

## Kotlin의 핵심 특징

### JVM 기반 언어

Kotlin은 기본적으로 JVM(Java Virtual Machine) 위에서 동작하는 언어입니다. Kotlin 코드를 작성하고 컴파일하면 Java와 동일한 형태의 바이트코드가 만들어지고, 이 바이트코드는 JVM이 실행합니다. 이 과정은 2장에서 그림과 함께 자세히 다룹니다. 지금은 "Kotlin은 Java가 쌓아온 생태계(JVM, 라이브러리, 실행 환경) 위에서 동작하는 새로운 언어"라는 점만 기억하면 충분합니다.

### Java와의 100% 상호운용성

Kotlin의 가장 실용적인 장점 중 하나는 Java와의 상호운용성(interoperability)입니다. 하나의 프로젝트 안에서 Kotlin 파일과 Java 파일을 동시에 두고, Kotlin 코드에서 Java 클래스를 그대로 가져와 쓰거나 반대로 Java 코드에서 Kotlin으로 작성한 클래스를 호출할 수 있습니다. 이 덕분에 기존에 Java로 작성된 대규모 프로젝트도 한 번에 전부 새로 작성하지 않고, 파일 단위로 점진적으로 Kotlin으로 전환할 수 있습니다. Java와의 상호운용에 관한 자세한 내용은 17장에서 다룹니다.

### null 안전성

Java 개발자들이 가장 흔히 겪는 오류 중 하나가 `NullPointerException`입니다. 값이 없어야 할 자리에 `null`이 들어가 있는데 이를 사전에 걸러내지 못해 실행 중에 프로그램이 멈춰버리는 문제입니다. Kotlin은 타입 시스템 차원에서 이 문제를 다룹니다. 변수를 선언할 때 그 변수가 `null`을 담을 수 있는지 없는지를 타입에 명시하도록 강제하는데, 이를 null 안전성이라고 부릅니다. 예를 들어 `String`은 절대 `null`이 될 수 없는 타입이고, `String?`처럼 물음표가 붙은 널러블 타입만 `null`을 담을 수 있습니다. 이 규칙 덕분에 컴파일 시점에서 상당수의 null 관련 오류를 미리 잡아낼 수 있습니다. null 안전성은 이 책에서 가장 중요하게 다루는 주제 중 하나이며, 8장에서 본격적으로 배웁니다.

### 간결한 문법

Kotlin은 같은 동작을 Java보다 훨씬 적은 코드로 표현할 수 있도록 설계되었습니다. 변수의 타입을 대부분 추론해 주고, 데이터를 담는 용도의 클래스는 한 줄로 선언할 수 있으며(9장, 10장), 함수를 값처럼 다루는 람다와 고차 함수 문법도 매우 간결합니다(13장). 다음은 두 언어의 느낌을 비교해 볼 수 있는 간단한 예시입니다.

```kotlin
// Kotlin: 이름과 나이를 담는 데이터 클래스
data class Person(val name: String, val age: Int)

fun main() {
    val person = Person("지민", 26)
    println("${person.name}은 ${person.age}살입니다.")
}
```

같은 기능을 Java로 작성하면 게터, 세터, `equals()`, `hashCode()`, `toString()`을 모두 직접 구현하거나 IDE로 생성해야 하지만, Kotlin은 `data class` 키워드 하나로 이 모든 것을 자동으로 만들어 줍니다. 데이터 클래스는 10장에서 자세히 다룹니다.

## Kotlin은 어디에 쓰이는가

- **안드로이드 앱 개발**: 구글의 공식 권장 언어로, 오늘날 새로 시작하는 안드로이드 프로젝트의 대다수가 Kotlin으로 작성됩니다.
- **서버 백엔드 개발**: Ktor, Spring(Spring Boot는 Kotlin을 1급 언어로 지원)과 같은 프레임워크를 통해 웹 서버와 API를 구축하는 데 널리 쓰입니다.
- **멀티플랫폼 개발**: Kotlin Multiplatform 기술을 활용하면 비즈니스 로직을 한 번 작성해 안드로이드, iOS, 데스크톱, 웹에서 공유할 수 있습니다.
- **데이터 처리와 스크립팅**: 간결한 문법과 함수형 스타일 덕분에 데이터 처리 파이프라인이나 간단한 자동화 스크립트 작성에도 활용됩니다.

## 다른 언어와의 비교

Kotlin의 위치를 가늠하는 데 도움이 되도록 자주 비교되는 두 언어를 짧게 살펴봅니다.

**Java와 비교하면**, Kotlin은 Java가 가진 JVM 생태계와 라이브러리를 그대로 활용하면서도 더 간결한 문법과 더 강력한 null 안전성을 제공합니다. Java는 오랜 역사와 방대한 생태계, 안정성이 강점이고, Kotlin은 같은 생태계 위에서 더 생산적인 개발 경험을 제공한다고 볼 수 있습니다.

**Swift와 비교하면**, Swift는 애플이 iOS/macOS 개발을 위해 만든 언어로, 옵셔널(optional)이라는 개념으로 null 안전성을 다루는 방식이 Kotlin의 널러블 타입과 사상적으로 매우 비슷합니다. 실제로 두 언어 모두 "값이 없을 수 있음"을 타입 시스템에 녹여낸 비교적 젊은 언어라는 공통점이 있습니다. 다만 Swift는 애플 플랫폼 중심이고 Kotlin은 JVM과 안드로이드, 서버 생태계 중심이라는 차이가 있습니다.

## 개발 환경 준비하기

이 책을 따라 실습하려면 다음 두 가지가 필요합니다.

1. **JDK(Java Development Kit)**: Kotlin은 JVM 위에서 동작하므로 JDK 설치가 먼저 필요합니다. 17 이상의 LTS(장기 지원) 버전을 추천합니다.
2. **IntelliJ IDEA**: Kotlin을 만든 JetBrains의 통합 개발 환경(IDE)으로, Kotlin 플러그인이 기본 내장되어 있어 별도 설정 없이 바로 Kotlin 프로젝트를 만들 수 있습니다. Community(무료) 버전으로도 이 책의 모든 예제를 실습할 수 있습니다.

설치 방법은 운영체제마다 조금씩 다르므로 이 책에서는 세부 절차를 반복해서 다루지 않고, 대신 2장에서 IntelliJ IDEA로 첫 프로젝트를 만들고 실행하는 과정을 단계별로 보여드립니다.

## 이 책을 읽는 방향

이 책은 총 18개 장으로 구성되어 있으며, 뒤로 갈수록 앞 장의 개념을 전제로 설명합니다. 1~7장은 변수, 연산자, 제어문, 함수 같은 기본 문법을 다지는 구간이고, 8장의 null 안전성은 Kotlin다운 코드를 작성하기 위한 전환점입니다. 9~11장은 객체지향 프로그래밍을, 12~15장은 컬렉션과 함수형 스타일을, 16장은 비동기 처리를 위한 코루틴을 다룹니다. 17장에서는 Java와의 상호운용을 실전 관점에서 정리하고, 18장에서는 지금까지 배운 내용을 좋은 코드 습관으로 엮어냅니다. 각 장은 앞 장에서 다룬 개념을 다시 언급하면서 이어지므로, 순서대로 읽는 것을 권장합니다.

## 요약

- Kotlin은 JetBrains가 만들고 2016년 1.0으로 공개한 JVM 기반 프로그래밍 언어이며, Java의 불편함을 해결하기 위해 탄생했습니다.
- 2017년 구글이 안드로이드 공식 언어로 채택하면서 대중화되었고, 지금은 안드로이드뿐 아니라 서버 백엔드, 멀티플랫폼 개발까지 영역을 넓히고 있습니다.
- Kotlin의 핵심 특징은 JVM 기반 실행, Java와의 100% 상호운용성, 타입 시스템 차원의 null 안전성, 간결한 문법입니다.
- Java와는 같은 생태계를 공유하면서 더 생산적인 문법을 제공하고, Swift와는 null(옵셔널) 처리 방식이 사상적으로 유사합니다.
- 실습을 위해서는 JDK와 IntelliJ IDEA(Community 버전 가능)를 준비하면 됩니다.
- 이 책은 8장 null 안전성을 기점으로 기본 문법에서 Kotlin다운 스타일로 넘어가며, 순서대로 읽을 것을 권장합니다.
