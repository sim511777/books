지금까지는 변수 하나에 값 하나를 담아 다뤘습니다. 하지만 실제 프로그램에서는 "학생 명단", "장바구니에 담긴 상품들", "이름과 나이를 짝지은 목록"처럼 여러 값을 한꺼번에 다뤄야 하는 경우가 훨씬 많습니다. 이런 값들의 묶음을 다루는 자료구조를 컬렉션(collection)이라고 부릅니다. 이번 장에서는 Kotlin의 대표적인 컬렉션인 `List`, `Set`, `Map`을 알아보고, Kotlin 컬렉션의 가장 중요한 특징인 읽기 전용(불변) 컬렉션과 변경 가능(가변) 컬렉션의 구분을 살펴봅니다.

## List: 순서가 있는 목록

`List`는 순서를 유지하면서 값을 담는 컬렉션입니다. 같은 값을 여러 번 담을 수도 있고, 인덱스(0부터 시작하는 번호)로 각 원소에 접근할 수 있습니다.

```kotlin
fun main() {
    val fruits = listOf("사과", "바나나", "체리")
    println(fruits[0])        // 사과
    println(fruits.size)      // 3
    println(fruits.contains("바나나")) // true
}
```

`listOf`로 만든 `fruits`는 읽기 전용 리스트입니다. 원소를 추가하거나 제거하는 함수 자체가 존재하지 않기 때문에, `fruits.add("포도")`처럼 작성하면 컴파일 오류가 발생합니다.

## 불변 컬렉션과 가변 컬렉션: Kotlin의 핵심 특징

8장에서 null 안전성을 다루면서 Kotlin이 "안전"을 언어 차원에서 강조한다는 점을 확인했습니다. 컬렉션에서도 비슷한 철학이 드러납니다. Kotlin은 컬렉션을 만들 때부터 "이 컬렉션을 나중에 바꿀 수 있게 할 것인가?"를 명확히 구분하도록 설계되어 있습니다.

- `listOf`, `setOf`, `mapOf`: 읽기 전용(불변) 컬렉션을 만듭니다. 생성 이후 원소를 추가·삭제·변경할 수 없습니다.
- `mutableListOf`, `mutableSetOf`, `mutableMapOf`: 가변 컬렉션을 만듭니다. 생성 이후에도 자유롭게 내용을 바꿀 수 있습니다.

```kotlin
fun main() {
    val readOnlyList = listOf(1, 2, 3)
    // readOnlyList.add(4) // 컴파일 오류: add 함수가 없음

    val mutableList = mutableListOf(1, 2, 3)
    mutableList.add(4)       // 정상 동작
    mutableList.removeAt(0)
    println(mutableList)     // [2, 3, 4]
}
```

이 구분은 Java 등 다른 언어의 컬렉션과 비교했을 때 Kotlin이 가진 뚜렷한 특징입니다. Java의 `List` 인터페이스는 기본적으로 변경 가능한 함수(`add`, `remove` 등)를 모두 포함하고 있어서, "이 리스트를 변경해도 되는가"를 함수 목록만 보고는 알기 어렵습니다. 반면 Kotlin은 타입 자체를 읽기 전용 인터페이스(`List`)와 변경 가능 인터페이스(`MutableList`)로 나누어 놓았기 때문에, 함수 시그니처에 `List<String>`이라고 적혀 있으면 "이 함수는 리스트를 변경하지 않는다"는 의도를 코드만 보고도 짐작할 수 있습니다.

```kotlin
// 매개변수 타입이 List이므로 이 함수는 목록을 변경하지 않는다는 신호
fun printAll(items: List<String>) {
    for (item in items) {
        println(item)
    }
}

// 매개변수 타입이 MutableList이므로 목록을 변경할 수 있다는 신호
fun addGreeting(items: MutableList<String>) {
    items.add("안녕하세요")
}
```

참고로 읽기 전용 `List`라고 해서 항상 완전히 "얼려진(frozen)" 상태인 것은 아닙니다. 예를 들어 `val` 변수에 담긴 읽기 전용 리스트라도, 그 리스트가 사실은 다른 곳에서 가변 리스트로 참조되고 있다면 외부에서 내용이 바뀔 수 있습니다. 다만 입문 단계에서는 "읽기 전용 타입으로 선언된 컬렉션은 그 타입을 통해서는 수정할 수 없다"는 정도로 이해하면 충분합니다.

## Set: 중복 없는 모음

`Set`은 중복된 값을 허용하지 않는 컬렉션입니다. 같은 값을 여러 번 추가해도 실제로는 한 번만 저장됩니다. 또한 `Set`은 일반적으로 순서를 보장하지 않는다고 알려져 있지만, Kotlin의 기본 구현체인 `LinkedHashSet` 기반의 `setOf`는 입력한 순서를 유지합니다.

```kotlin
fun main() {
    val numbers = setOf(1, 2, 2, 3, 3, 3)
    println(numbers)          // [1, 2, 3] - 중복이 제거됨
    println(numbers.size)     // 3

    val mutableNumbers = mutableSetOf(1, 2, 3)
    mutableNumbers.add(2)     // 이미 있으므로 무시됨
    mutableNumbers.add(4)     // 새로운 값이므로 추가됨
    println(mutableNumbers)   // [1, 2, 3, 4]
}
```

`Set`은 "이 값이 이미 목록에 있는가?"를 자주 확인해야 하거나, 애초에 중복을 허용하고 싶지 않은 데이터를 다룰 때 유용합니다. 예를 들어 방문한 사용자 ID 집합, 태그 목록 등이 대표적인 예입니다.

## Map: 키와 값의 짝

`Map`은 키(key)와 값(value)을 짝지어 저장하는 컬렉션입니다. 키는 중복될 수 없으며, 각 키는 정확히 하나의 값과 연결됩니다.

```kotlin
fun main() {
    val ages = mapOf("영수" to 25, "지민" to 30, "하나" to 28)
    println(ages["영수"])         // 25
    println(ages.keys)            // [영수, 지민, 하나]
    println(ages.values)          // [25, 30, 28]

    val mutableAges = mutableMapOf("영수" to 25)
    mutableAges["지민"] = 30       // 새 항목 추가
    mutableAges["영수"] = 26       // 기존 항목 값 변경
    println(mutableAges)          // {영수=26, 지민=30}
}
```

`to`는 Kotlin이 제공하는 특별한 함수로, `"영수" to 25`는 `"영수"`와 `25`를 짝지은 `Pair` 객체를 만들어줍니다. `mapOf`는 이런 `Pair`들을 여러 개 받아 `Map`을 구성합니다.

## for문으로 컬렉션 순회하기

6장에서 배운 `for`문은 컬렉션을 순회하는 가장 기본적인 방법입니다. `List`, `Set`, `Map` 모두 `for`문으로 순회할 수 있습니다.

```kotlin
fun main() {
    val fruits = listOf("사과", "바나나", "체리")

    // 값만 순회
    for (fruit in fruits) {
        println(fruit)
    }

    // 인덱스와 값을 함께 순회
    for ((index, fruit) in fruits.withIndex()) {
        println("${index}: ${fruit}")
    }

    val ages = mapOf("영수" to 25, "지민" to 30)

    // Map은 (key, value) 쌍으로 순회
    for ((name, age) in ages) {
        println("${name}은 ${age}살입니다.")
    }
}
```

`withIndex()`는 리스트의 각 원소를 인덱스와 함께 짝지어주는 함수이며, `Map`은 구조 분해 선언을 통해 `(name, age)`처럼 키와 값을 바로 이름 붙여 꺼낼 수 있습니다.

## 자주 쓰는 컬렉션 메서드

Kotlin 컬렉션은 다양한 편의 함수를 기본으로 제공합니다. 몇 가지 핵심적인 함수를 살펴보겠습니다.

```kotlin
fun main() {
    val numbers = listOf(5, 3, 8, 1, 9)

    println(numbers.first())          // 5 (첫 번째 원소)
    println(numbers.last())           // 9 (마지막 원소)
    println(numbers.max())            // 9 (최댓값)
    println(numbers.min())            // 1 (최솟값)
    println(numbers.sum())            // 26 (합계)
    println(numbers.sorted())         // [1, 3, 5, 8, 9] (정렬된 새 리스트)
    println(numbers.isEmpty())        // false
    println(numbers.reversed())       // [9, 1, 8, 3, 5]
}
```

`sorted()`나 `reversed()`처럼 이름이 "~ed"로 끝나는 함수들은 원본 컬렉션을 바꾸지 않고 새로운 컬렉션을 만들어 반환한다는 공통된 규칙이 있습니다. 가변 리스트라도 이런 함수를 호출한다고 원본이 바로 바뀌지는 않으므로, 결과를 변수에 다시 담아야 한다는 점에 주의해야 합니다.

## 다음 장을 위한 예고: 고차 함수로 컬렉션 다루기

지금까지 살펴본 것처럼 컬렉션은 `for`문으로 하나씩 순회하면서 처리할 수 있습니다. 하지만 "짝수만 골라내기", "모든 값에 2를 곱하기", "이름만 모아 새 리스트 만들기" 같은 작업을 매번 `for`문과 조건문으로 직접 작성하면 코드가 길어지고 반복적입니다.

Kotlin은 이런 작업을 훨씬 간결하게 표현할 수 있는 `filter`, `map`, `forEach` 같은 함수를 제공합니다. 이 함수들은 "함수를 인자로 받는 함수", 즉 고차 함수(higher-order function)입니다.

```kotlin
fun main() {
    val numbers = listOf(1, 2, 3, 4, 5, 6)

    // filter: 조건을 만족하는 원소만 골라 새 리스트 생성
    val evens = numbers.filter { it % 2 == 0 }
    println(evens) // [2, 4, 6]

    // map: 각 원소를 변형해 새 리스트 생성
    val doubled = numbers.map { it * 2 }
    println(doubled) // [2, 4, 6, 8, 10, 12]
}
```

`for`문으로 같은 작업을 하려면 빈 리스트를 만들고, 조건을 확인하고, 결과를 하나씩 추가하는 여러 줄이 필요하지만, `filter`와 `map`은 이를 한 줄로 표현합니다. 이러한 고차 함수와 람다 표현식(`{ it % 2 == 0 }` 같은 중괄호 문법)은 13장 "람다와 고차 함수"에서 원리부터 자세히 다룰 예정입니다. 지금은 컬렉션을 다루는 더 간결한 방법이 존재한다는 것만 기억해두면 충분합니다.

## 요약

이번 장에서는 Kotlin의 세 가지 기본 컬렉션인 `List`(순서가 있는 목록), `Set`(중복 없는 모음), `Map`(키-값 쌍의 모음)을 배웠습니다. Kotlin 컬렉션의 가장 중요한 특징은 `listOf`, `setOf`, `mapOf`로 만드는 읽기 전용 컬렉션과 `mutableListOf`, `mutableSetOf`, `mutableMapOf`로 만드는 가변 컬렉션을 타입 차원에서 명확히 구분한다는 점입니다. 이 덕분에 함수의 매개변수 타입만 보고도 컬렉션이 변경될 수 있는지를 짐작할 수 있습니다. 6장에서 배운 `for`문은 `withIndex()`나 구조 분해 선언과 함께 컬렉션을 순회하는 기본적인 도구이며, `first()`, `sorted()`, `sum()` 같은 다양한 메서드로 자주 하는 작업을 간단히 처리할 수 있습니다. 다음 13장에서는 `filter`, `map` 같은 고차 함수와 람다 표현식을 통해 컬렉션을 더 선언적이고 간결하게 다루는 방법을 배웁니다.
