지금까지 만든 프로그램은 대부분 값을 하나씩 다뤘습니다. 하지만 실제 프로그램은 "학생 명단", "장바구니에 담긴 상품", "아이디와 이름의 짝" 같이 여러 값의 묶음을 다루는 경우가 훨씬 많습니다. Dart는 이런 묶음을 다루기 위해 `List`, `Set`, `Map`이라는 세 가지 핵심 컬렉션 타입을 제공합니다. 이번 장에서는 이 세 타입의 기본 사용법을 익히고, 7장에서 맛본 함수를 값처럼 다루는 능력을 활용해 컬렉션을 선언적으로 가공하는 방법을 배웁니다.

## List: 순서가 있는 값의 목록

`List`는 값을 순서대로 저장하는 컬렉션입니다. 대괄호로 리터럴을 만들 수 있습니다.

```dart
void main() {
  var fruits = ['사과', '바나나', '체리'];
  print(fruits[0]); // 사과
  print(fruits.length); // 3

  fruits.add('포도'); // 끝에 추가
  fruits.removeAt(1); // 인덱스 1(바나나) 제거
  print(fruits); // [사과, 체리, 포도]
}
```

리스트는 요소 타입을 명시할 수도 있습니다. `List<int>`처럼 제네릭 타입 매개변수를 붙이면, 이후 12장에서 다룰 제네릭의 이점을 그대로 누릴 수 있습니다.

```dart
List<int> scores = [90, 85, 100];
scores.sort(); // 오름차순 정렬: [85, 90, 100]
scores.sort((a, b) => b.compareTo(a)); // 내림차순 정렬
print(scores.contains(100)); // true
print(scores.indexOf(90)); // 1
```

자주 쓰이는 메서드로는 `add`, `addAll`, `remove`, `removeAt`, `insert`, `sort`, `contains`, `indexOf`, `sublist`, `reversed`, `isEmpty`/`isNotEmpty` 등이 있습니다. 리스트는 크기가 고정되지 않은 "가변(growable)" 리스트가 기본값이며, `List.filled(3, 0)`처럼 크기와 초깃값을 지정해 고정 크기 리스트를 만들 수도 있습니다.

## Set: 중복 없는 값의 모음

`Set`은 리스트와 비슷하지만 같은 값을 중복해서 저장하지 않고, 순서를 보장하지 않습니다. 중괄호로 리터럴을 만듭니다.

```dart
void main() {
  var tags = {'dart', 'flutter', 'dart'}; // 중복된 dart는 하나로 합쳐짐
  print(tags.length); // 2
  print(tags.contains('flutter')); // true

  var a = {1, 2, 3};
  var b = {2, 3, 4};
  print(a.union(b)); // {1, 2, 3, 4}
  print(a.intersection(b)); // {2, 3}
  print(a.difference(b)); // {1}
}
```

`Set`은 "이 값이 이미 있는지"를 빠르게 확인해야 하는 상황, 혹은 값의 집합 연산(합집합, 교집합, 차집합)이 필요한 상황에서 리스트보다 훨씬 적합합니다.

## Map: 키와 값의 짝

`Map`은 키(key)와 값(value)을 한 쌍으로 저장하는 컬렉션입니다. 다른 언어의 딕셔너리, 해시맵과 같은 역할을 합니다.

```dart
void main() {
  var ages = {
    '철수': 20,
    '영희': 22,
  };

  print(ages['철수']); // 20
  ages['민수'] = 25; // 새 키 추가
  ages.remove('영희'); // 키 삭제

  ages.forEach((name, age) {
    print('$name은 $age살입니다');
  });

  print(ages.keys); // (철수, 민수)
  print(ages.values); // (20, 25)
  print(ages.containsKey('철수')); // true
}
```

Map도 타입 매개변수를 두 개 받아 `Map<String, int>`처럼 키와 값의 타입을 명시할 수 있습니다. 존재하지 않는 키에 접근하면 `null`이 반환되므로, 8장에서 배운 sound null safety와 자연스럽게 맞물립니다. `ages['없는사람']`의 타입은 `int?`가 됩니다.

## 고차 함수로 컬렉션 가공하기

7장에서 함수를 값처럼 다룰 수 있다는 것과 화살표 함수 문법을 배웠습니다. 컬렉션은 이 능력을 활용하는 대표적인 무대입니다. 반복문으로 하나씩 처리하는 대신, "무엇을 하고 싶은지"를 함수로 표현하면 코드가 훨씬 선언적이고 짧아집니다.

`map`은 각 요소를 변환한 새로운 컬렉션을 만듭니다.

```dart
var numbers = [1, 2, 3, 4, 5];
var doubled = numbers.map((n) => n * 2).toList();
print(doubled); // [2, 4, 6, 8, 10]
```

`where`는 조건을 만족하는 요소만 걸러냅니다.

```dart
var evens = numbers.where((n) => n % 2 == 0).toList();
print(evens); // [2, 4]
```

`reduce`는 컬렉션의 모든 요소를 하나의 값으로 누적해 합칩니다. 초깃값 없이 첫 요소부터 시작하므로 빈 컬렉션에는 사용할 수 없습니다.

```dart
var sum = numbers.reduce((a, b) => a + b);
print(sum); // 15
```

초깃값이 필요하거나 결과 타입이 요소 타입과 다르다면 `fold`를 사용합니다.

```dart
var total = numbers.fold<int>(100, (acc, n) => acc + n);
print(total); // 115 (100에서 시작)
```

`forEach`는 값을 새로 만들지 않고 각 요소에 대해 부수 효과(출력, 저장 등)를 실행할 때 씁니다.

```dart
numbers.forEach((n) => print('숫자: $n'));
```

이 네 가지는 얼마든지 연결(chaining)할 수 있습니다. 익명 함수 대신 화살표 함수를 쓰면 한 줄로도 의도가 분명하게 드러납니다.

```dart
var result = numbers
    .where((n) => n > 1)
    .map((n) => n * n)
    .reduce((a, b) => a + b);
print(result); // 4 + 9 + 16 + 25 = 54
```

`map`과 `where`가 반환하는 값은 `Iterable`이라는 지연 평가(lazy) 시퀀스입니다. `toList()`나 `toSet()`을 호출하기 전까지는 실제로 순회하지 않으므로, 여러 연산을 이어붙여도 컬렉션을 여러 번 복사하지 않는다는 점을 기억해두면 좋습니다.

## 컬렉션 리터럴 안의 for와 if

Dart는 컬렉션 리터럴 안에서 직접 반복문과 조건문을 쓸 수 있는 독특한 문법을 제공합니다. 이를 "컬렉션 for"와 "컬렉션 if"라고 부릅니다.

```dart
var base = [1, 2, 3];
var doubledList = [for (var x in base) x * 2];
print(doubledList); // [2, 4, 6]
```

일반 for문과 마찬가지로 인덱스 기반 반복도 가능합니다.

```dart
var indexed = [for (var i = 0; i < 5; i++) i * i];
print(indexed); // [0, 1, 4, 9, 16]
```

조건에 따라 요소를 포함하거나 제외하려면 `if`를 함께 사용합니다.

```dart
var onlyEvens = [for (var x in base) if (x % 2 == 0) x];
print(onlyEvens); // [2]

var withLabel = [
  for (var x in base)
    if (x.isEven) '짝수: $x' else '홀수: $x',
];
print(withLabel); // [홀수: 1, 짝수: 2, 홀수: 3]
```

이 문법은 `Set`과 `Map` 리터럴에서도 그대로 동작합니다.

```dart
var squares = {for (var x in base) x: x * x}; // Map<int, int>
print(squares); // {1: 1, 2: 4, 3: 9}
```

컬렉션 for/if는 `map`, `where`를 조합하는 것과 결과는 비슷하지만, 리스트 리터럴 안에 고정된 값과 계산된 값을 자연스럽게 섞어 쓸 수 있다는 장점이 있습니다.

```dart
var menu = [
  '기본 메뉴',
  for (var item in ['커피', '차', '주스']) item,
  if (base.isNotEmpty) '추천 메뉴 있음',
];
print(menu); // [기본 메뉴, 커피, 차, 주스, 추천 메뉴 있음]
```

## 요약

- `List`는 순서가 있는 값의 목록, `Set`은 중복 없는 값의 모음, `Map`은 키-값 쌍의 모음입니다.
- 세 타입 모두 리터럴 문법과 제네릭 타입 매개변수를 지원하며, `add`, `remove`, `contains` 등 목적에 맞는 다양한 메서드를 제공합니다.
- `map`, `where`, `reduce`, `fold`, `forEach` 같은 고차 함수는 반복문 대신 함수를 값으로 전달해 컬렉션을 선언적으로 가공하게 해줍니다. 7장의 화살표 함수 문법과 결합하면 코드가 짧고 명확해집니다.
- `map`/`where`는 지연 평가되는 `Iterable`을 반환하므로, 실제 리스트나 셋이 필요할 때는 `toList()`/`toSet()`을 호출합니다.
- 컬렉션 리터럴 안에서 `for`와 `if`를 직접 사용하는 컬렉션 for/if 문법은 Dart 고유의 기능으로, `[for (x in list) x*2]`처럼 반복과 조건을 리터럴 작성 시점에 바로 표현할 수 있습니다.
