프로그램은 위에서 아래로 한 줄씩 실행되는 것이 기본이지만, 실제로 의미 있는 로직을 만들려면 "조건에 따라 다른 코드를 실행"하는 능력이 필요하다. 이번 장에서는 Dart의 조건 분기 도구인 `if`/`else`, `switch`, 삼항 연산자를 다루고, 조건문이 복잡해질 때 가독성을 지키는 방법까지 살펴본다.

## if, else if, else

가장 기본적인 조건 분기는 `if`문이다. 조건식은 반드시 `bool` 타입이어야 하며, Dart는 다른 언어처럼 정수나 문자열을 자동으로 참/거짓으로 취급하지 않는다.

```dart
void checkTemperature(double celsius) {
  if (celsius >= 30) {
    print('무더운 날씨입니다.');
  } else if (celsius >= 15) {
    print('쾌적한 날씨입니다.');
  } else if (celsius >= 0) {
    print('쌀쌀한 날씨입니다.');
  } else {
    print('한파 주의보입니다.');
  }
}
```

`else if`는 새로운 문법이 아니라 `else` 블록 안에 다시 `if`문을 넣은 형태다. 조건은 위에서부터 순서대로 검사되며, 처음으로 참이 되는 블록만 실행되고 나머지는 건너뛴다. 조건 순서를 바꾸면 결과가 달라질 수 있다는 점을 항상 염두에 두어야 한다. 예를 들어 위 코드에서 `celsius >= 0` 조건을 맨 앞에 두면, 30도인 날씨도 "쌀쌀한 날씨"로 잘못 분류된다.

중괄호 `{}`는 블록이 한 줄이어도 생략하지 않는 것이 안전하다. 생략하면 나중에 코드를 추가할 때 실수로 조건 밖의 코드가 되어버리는 실수를 막을 수 있다.

```dart
// 권장하지 않음: 중괄호 생략
if (celsius >= 30) print('무덥다');

// 권장: 항상 중괄호 사용
if (celsius >= 30) {
  print('무덥다');
}
```

## switch문

`switch`문은 하나의 값을 여러 경우와 비교해서 분기할 때 `if-else` 체인보다 의도를 명확히 드러낸다. 전통적인 형태는 다음과 같다.

```dart
void printDayName(int weekday) {
  switch (weekday) {
    case 1:
      print('월요일');
      break;
    case 2:
      print('화요일');
      break;
    case 3:
      print('수요일');
      break;
    default:
      print('그 외 요일');
  }
}
```

Dart의 `switch`문은 `case` 사이에 값이 흘러넘어가는 것을 허용하지 않는다(이른바 fallthrough 금지). 즉, C나 JavaScript처럼 `break`를 빼먹으면 다음 `case`로 넘어가는 실수가 원천적으로 발생하지 않는다. 대신 여러 case를 같은 코드로 묶고 싶다면 다음과 같이 나열한다.

```dart
void describeSeason(String month) {
  switch (month) {
    case '12':
    case '1':
    case '2':
      print('겨울');
      break;
    case '3':
    case '4':
    case '5':
      print('봄');
      break;
    default:
      print('그 외 계절');
  }
}
```

### Dart 3의 확장 switch: 패턴 매칭과 switch 표현식

Dart 3부터 `switch`는 단순 값 비교를 넘어서 **패턴 매칭**을 지원하도록 크게 확장되었다. 가장 눈에 띄는 변화는 `switch`를 문(statement)이 아니라 **식(expression)**으로도 쓸 수 있게 된 것이다. 즉, `switch` 자체가 값을 반환할 수 있다.

```dart
String sizeLabel(int score) {
  return switch (score) {
    >= 90 => 'A',
    >= 80 => 'B',
    >= 70 => 'C',
    _ => 'F',
  };
}
```

여기서 `=>`는 각 case에 대응하는 결과값을 나타내고, `_`는 다른 언어의 `default`와 같은 역할을 하는 와일드카드 패턴이다. `break`가 필요 없고, 각 분기가 하나의 값을 만들어낸다는 점에서 함수형 스타일에 가깝다. 비교 조건(`>= 90`처럼)을 패턴 안에 직접 쓸 수 있는 것도 기존 `switch`문과 다른 점이다.

패턴 매칭은 레코드(record)나 객체의 구조를 분해하는 데도 쓸 수 있다.

```dart
String describePoint((int, int) point) {
  return switch (point) {
    (0, 0) => '원점',
    (var x, 0) => 'x축 위의 점 ($x, 0)',
    (0, var y) => 'y축 위의 점 (0, $y)',
    (var x, var y) => '($x, $y)',
  };
}
```

레코드는 아직 등장하지 않은 개념이므로 지금은 "switch가 값의 모양(shape)까지 검사할 수 있다"는 정도로만 이해하면 충분하다. 자세한 패턴 문법은 컬렉션과 클래스를 배운 뒤 다시 다룰 기회가 있을 것이다. 지금 단계에서 기억할 것은 두 가지다. 전통적인 `switch`문은 여러 줄의 동작을 실행할 때, `switch` 식은 조건에 따라 값 하나를 골라야 할 때 각각 적합하다는 점이다.

## 삼항 연산자

`if-else`로 값을 하나만 고르는 짧은 로직은 삼항 연산자(`조건 ? 참일 때 값 : 거짓일 때 값`)로 표현하면 코드가 간결해진다.

```dart
int age = 17;
String category = age >= 18 ? '성인' : '미성년자';
print(category); // 미성년자
```

앞 장에서 배운 `??`(null 병합 연산자)와 함께 자주 쓰인다.

```dart
String? nickname;
String displayName = nickname != null ? nickname : '익명';
// 위 코드는 아래와 완전히 동일하다.
String displayNameShort = nickname ?? '익명';
```

삼항 연산자는 편리하지만 중첩해서 쓰면 순식간에 읽기 어려워진다.

```dart
// 가독성이 나쁜 예: 중첩된 삼항 연산자
String grade = score >= 90 ? 'A' : score >= 80 ? 'B' : score >= 70 ? 'C' : 'F';
```

이런 경우는 앞서 소개한 `switch` 식을 사용하는 것이 훨씬 명확하다. "값 하나를 즉시 대입해야 하고, 분기가 2개뿐"인 단순한 경우에만 삼항 연산자를 쓰는 것을 원칙으로 삼으면 코드 리뷰에서 다툴 일이 줄어든다.

## 중첩 조건문과 가독성

조건문 안에 조건문이 들어가는 중첩 구조는 로직이 복잡해질수록 자연스럽게 늘어난다. 문제는 중첩이 3단계, 4단계로 깊어지면 코드를 읽는 사람이 어느 조건이 어느 블록에 속하는지 추적하기 힘들어진다는 점이다.

```dart
// 중첩이 깊어서 읽기 어려운 예
void processOrder(int stock, bool isMember, double amount) {
  if (stock > 0) {
    if (isMember) {
      if (amount >= 50000) {
        print('무료 배송 + 회원 할인 적용');
      } else {
        print('회원 할인만 적용');
      }
    } else {
      print('할인 없이 정가 결제');
    }
  } else {
    print('재고 없음');
  }
}
```

이런 코드는 **조건을 일찍 걸러내는(guard clause)** 방식으로 바꾸면 중첩 깊이를 줄일 수 있다. 함수 초입에서 예외적인 상황을 먼저 처리하고 `return`으로 빠져나가면, 나머지 코드는 "정상 흐름"만 다루므로 읽기 쉬워진다.

```dart
// guard clause로 중첩을 줄인 예
void processOrderClean(int stock, bool isMember, double amount) {
  if (stock <= 0) {
    print('재고 없음');
    return;
  }
  if (!isMember) {
    print('할인 없이 정가 결제');
    return;
  }
  if (amount >= 50000) {
    print('무료 배송 + 회원 할인 적용');
  } else {
    print('회원 할인만 적용');
  }
}
```

두 함수는 동일한 결과를 내지만, 두 번째 버전은 각 `if` 블록이 한 가지 예외 상황만 책임지므로 로직을 따라가기 쉽다. 조건문이 세 단계 이상 중첩된다면 guard clause나 `switch` 식으로 구조를 펼쳐낼 수 있는지 먼저 검토하는 습관을 들이자. 7장에서 함수를 본격적으로 다룰 때, 조건 로직을 작은 함수로 쪼개서 이름을 붙이는 방법도 함께 살펴본다.

## 요약

- `if`/`else if`/`else`는 조건을 위에서부터 순서대로 검사하며, 처음 참이 되는 블록만 실행된다. 중괄호는 항상 붙이는 것이 안전하다.
- 전통적인 `switch`문은 fallthrough가 없고, 여러 case를 한 블록에 묶을 수 있다.
- Dart 3의 확장 `switch`는 `switch (값) { 패턴 => 결과, ... }` 형태의 식으로 사용할 수 있으며, 비교 조건과 구조 분해 패턴까지 지원한다.
- 삼항 연산자(`조건 ? A : B`)는 값 하나를 즉시 골라야 하는 단순한 상황에만 쓰고, 중첩은 피한다.
- 조건문이 깊게 중첩되면 guard clause로 예외 상황을 먼저 걸러내어 가독성을 높인다.

## 연습문제

1. 정수 `score`(0~100)를 받아 90 이상 `A`, 80 이상 `B`, 70 이상 `C`, 그 외 `F`를 반환하는 함수를 전통적인 `if-else`와 `switch` 식 두 가지 방식으로 각각 작성해 보라.
2. 세 개의 정수를 입력받아 그 중 가장 큰 값을 구하는 함수를 중첩 `if` 없이 작성해 보라.
3. 문자열 `'가위'`, `'바위'`, `'보'` 중 하나를 받아 이모지(`✌️`, `✊`, `✋`)를 반환하는 함수를 `switch` 식으로 작성해 보라.
4. 나이(`int`)와 학생 여부(`bool`)를 받아 입장료를 계산하는 함수를 guard clause 스타일로 작성해 보라. 조건: 7세 미만 무료, 학생 5000원, 성인 10000원.
5. 위 4번 문제의 중첩 `if` 버전과 guard clause 버전을 나란히 작성한 뒤, 어느 쪽이 읽기 쉬운지 스스로 비교해 보라.
