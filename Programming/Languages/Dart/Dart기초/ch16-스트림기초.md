# 16장. 스트림(Stream) 기초

15장에서 배운 `Future<T>`는 "미래의 어느 시점에 값 하나가 도착한다"는 상황을 표현하는 도구였습니다. 하지만 실제 프로그램에는 값이 딱 한 번만 오는 것이 아니라, 여러 번에 걸쳐 계속 도착하는 상황도 많습니다. 사용자가 키보드를 두드릴 때마다 발생하는 입력, 센서가 1초마다 보내오는 측정값, 채팅방에 올라오는 메시지들이 그런 예입니다. Dart는 이런 "시간에 걸쳐 여러 번 도착하는 값의 흐름"을 `Stream<T>`로 표현합니다.

## Future와 Stream의 차이

두 개념을 비교하는 가장 쉬운 방법은 우편물을 떠올리는 것입니다. `Future<T>`는 등기 우편 하나와 같습니다. 보내는 사람도 하나, 도착하는 물건도 하나이며, 도착하고 나면 그 관계는 끝입니다. 반면 `Stream<T>`는 구독하는 신문과 같습니다. 한 번 구독을 신청하면 신문이 나올 때마다 계속해서 배달되고, 몇 번이 배달될지는 구독을 시작하는 시점에는 알 수 없습니다. 구독을 끝내기 전까지 이 흐름은 계속됩니다.

| | Future&lt;T&gt; | Stream&lt;T&gt; |
|---|---|---|
| 전달하는 값의 개수 | 값 하나 (또는 오류 하나) | 값 0개 이상 (여러 번, 시간차를 두고) |
| 받는 방법 | `await` 또는 `then` | `listen` 또는 `await for` |
| 종료 | 값이 오면 자동으로 끝 | 명시적으로 끝나거나(`onDone`), 계속될 수 있음 |

`Stream`은 완전히 새로운 개념이 아니라, 13장에서 배운 `Iterable`의 비동기 버전이라고 생각하면 이해하기 쉽습니다. `Iterable`이 이미 메모리에 있는 값들을 순서대로 하나씩 꺼내주는 반면, `Stream`은 아직 도착하지 않은 값들을 시간이 지나면서 하나씩 흘려보냅니다.

## async*와 yield로 스트림 만들기

스트림을 만드는 가장 직관적인 방법은 함수 선언에 `async*`를 붙이는 것입니다. `async*`가 붙은 함수는 **비동기 제너레이터(asynchronous generator)**가 되며, `return` 대신 `yield`로 값을 하나씩 내보냅니다.

```dart
// 1부터 max까지, 1초 간격으로 숫자를 내보내는 스트림
Stream<int> countUpTo(int max) async* {
  for (var i = 1; i <= max; i++) {
    await Future.delayed(Duration(seconds: 1));
    yield i; // 값을 스트림 밖으로 내보내지만 함수는 끝나지 않는다
  }
}
```

`yield i`는 값 하나를 스트림으로 내보낸 뒤, 함수 실행을 그 자리에 유지한 채로 계속 진행합니다. 이 점이 `return`과 다릅니다. `return`은 함수를 즉시 끝내지만, `yield`는 "이번 값은 여기까지, 다음 값을 준비할게"라는 뜻입니다. 다른 스트림이 내보내는 값을 그대로 이어받아 전달하고 싶을 때는 `yield*`를 사용합니다.

```dart
Stream<int> countUpToTwice(int max) async* {
  yield* countUpTo(max); // 1~max까지 먼저 전달
  yield* countUpTo(max); // 이어서 1~max까지 다시 전달
}
```

## listen으로 스트림 구독하기

만들어진 스트림에서 값을 받으려면 `listen` 메서드로 콜백 함수를 등록합니다. `listen`은 등록만 하고 즉시 반환되므로, 스트림의 값이 도착하기를 기다리며 프로그램을 멈추지 않습니다.

```dart
void main() {
  final stream = countUpTo(5);

  stream.listen(
    (value) => print('받은 값: $value'),
    onError: (e) => print('오류 발생: $e'),
    onDone: () => print('스트림 종료'),
  );

  print('구독을 시작했고, 다른 작업도 계속할 수 있다');
}
```

`listen`의 첫 번째 인자는 값이 도착할 때마다 호출되는 콜백이고, `onError`와 `onDone`은 각각 오류가 발생했을 때와 스트림이 완전히 끝났을 때 호출되는 콜백입니다. `listen`은 `StreamSubscription` 객체를 반환하는데, 이 객체의 `pause()`, `resume()`, `cancel()` 메서드로 구독을 일시 정지하거나 완전히 취소할 수 있습니다.

```dart
final subscription = stream.listen((value) => print(value));
// 더 이상 값을 받고 싶지 않을 때
subscription.cancel();
```

## await for로 순차 처리하기

`listen`은 콜백을 등록하는 방식이라 반복문 안에서 자연스럽게 쓰기 어렵습니다. `async` 함수 안에서는 `await for` 문법으로 스트림의 값을 마치 리스트를 순회하듯 하나씩 받아 처리할 수 있습니다.

```dart
Future<void> printAll() async {
  final stream = countUpTo(5);

  await for (final value in stream) {
    print('처리 중: $value'); // 값이 도착할 때마다 한 번씩 실행
  }

  print('모든 값을 처리했다'); // 스트림이 완전히 끝난 뒤에만 실행
}
```

`await for`는 스트림의 각 값이 도착할 때까지 기다렸다가 반복문 본문을 실행하고, 스트림이 끝나면(`onDone`에 해당하는 시점) 반복문을 빠져나가 다음 줄로 넘어갑니다. `listen`과 달리 스트림이 끝날 때까지 `printAll` 함수의 실행이 이어지므로, "이 스트림의 모든 값을 처리한 다음에 무언가를 하고 싶다"는 상황에는 `await for`가 훨씬 자연스럽습니다.

## 컬렉션 메서드로 스트림 가공하기

`Stream`도 13장에서 배운 `map`, `where` 같은 메서드를 그대로 지원합니다. 다만 결과가 즉시 나오는 것이 아니라, 원본 스트림의 값이 도착할 때마다 변환되어 새로운 스트림으로 흘러나온다는 점이 다릅니다.

```dart
void main() {
  final evenStream = countUpTo(10).where((n) => n.isEven);
  evenStream.listen((n) => print('짝수: $n'));

  final labeledStream = countUpTo(5).map((n) => '숫자 $n번째 도착');
  labeledStream.listen((label) => print(label));
}
```

## 흔한 사용 사례: 사용자 입력과 실시간 데이터

스트림이 가장 자주 쓰이는 곳은 "언제 얼마나 발생할지 미리 알 수 없는 이벤트"를 다룰 때입니다. 대표적으로 키보드 입력이나 마우스 클릭 같은 사용자 입력, 그리고 센서 측정값이나 서버가 실시간으로 보내오는 데이터가 있습니다. 이런 상황은 `async*`/`yield`로 미리 정해진 값을 순서대로 내보내는 방식과는 조금 다릅니다. 이벤트가 언제 발생할지 프로그램이 미리 알 수 없기 때문입니다. 이런 경우에는 `StreamController`를 사용해 필요할 때마다 값을 스트림에 직접 흘려보냅니다.

```dart
import 'dart:async';

void main() {
  final controller = StreamController<String>();

  // 스트림을 구독해서 입력이 들어올 때마다 처리
  controller.stream.listen((character) => print('입력된 문자: $character'));

  // 실제로는 키보드 이벤트 등에서 호출되었을 상황을 흉내 낸다
  controller.add('H');
  controller.add('i');
  controller.close(); // 더 이상 값이 없다면 스트림을 닫는다
}
```

`StreamController`의 `add`는 새 값을 스트림에 흘려보내고, `close`는 더 이상 값이 없음을 알리며 스트림을 종료합니다. 기본적으로 만들어진 스트림은 `listen`을 단 한 번만 호출할 수 있는 **단일 구독(single-subscription) 스트림**입니다. 여러 구독자가 동시에 같은 이벤트를 받아야 하는 상황(예를 들어 여러 화면에서 같은 채팅 메시지를 받아야 할 때)에는 `StreamController.broadcast()`로 만든 **브로드캐스트(broadcast) 스트림**을 사용합니다. 두 종류의 구체적인 차이와 실전 활용은 이후 Flutter나 서버 프로그래밍을 다루는 자료에서 더 깊이 만나게 될 것입니다.

## 요약

- `Future<T>`는 값 하나가 미래에 도착하는 것을 표현하고, `Stream<T>`는 값 여러 개가 시간에 걸쳐 도착하는 것을 표현합니다. `Stream`은 `Iterable`의 비동기 버전이라고 생각하면 이해하기 쉽습니다.
- `async*`가 붙은 함수는 비동기 제너레이터가 되어 `Stream`을 반환하며, 함수 안에서 `yield`로 값을 하나씩 내보냅니다. `yield*`는 다른 스트림의 값을 그대로 이어서 전달합니다.
- `listen`은 콜백을 등록하고 즉시 반환되는 비차단 방식으로 스트림을 구독하며, `onError`와 `onDone` 콜백, 그리고 구독을 제어하는 `StreamSubscription`을 함께 제공합니다.
- `async` 함수 안에서는 `await for`로 스트림의 값을 순서대로 기다리며 처리할 수 있고, 스트림이 끝날 때까지 함수의 실행이 이어집니다.
- `Stream`도 `map`, `where` 같은 익숙한 컬렉션 메서드를 지원해, 흘러오는 값을 선언적으로 변환하거나 걸러낼 수 있습니다.
- 사용자 입력이나 실시간 데이터처럼 발생 시점을 미리 알 수 없는 이벤트는 `StreamController`로 직접 값을 흘려보내 스트림으로 다룰 수 있으며, 구독자가 여럿이라면 `StreamController.broadcast()`를 사용합니다.

`Future`와 `Stream`은 Dart 언어 자체가 제공하는 비동기 도구입니다. 17장에서는 이런 도구를 활용해 만들어진 외부 패키지들을 pub.dev 생태계에서 가져와 프로젝트에 더하는 방법을 다루고, 18장에서는 지금까지 배운 문법들을 실제로 어떻게 조합해야 읽기 좋고 유지보수하기 쉬운 Dart 코드가 되는지 정리합니다.

## 연습문제

1. 1초 간격으로 `'준비'`, `'시작'`, `'완료'` 세 문자열을 순서대로 내보내는 `Stream<String>`을 `async*`와 `yield`로 작성하고, `listen`으로 각 값을 출력해보세요.
2. 1번에서 만든 스트림을 이번에는 `await for`를 사용하는 `async` 함수 안에서 처리하도록 바꿔보고, 모든 값을 처리한 뒤 `'끝!'`을 출력해보세요.
3. 1부터 20까지의 정수를 내보내는 스트림을 만들고, `where`로 3의 배수만 걸러낸 뒤 `map`으로 `'3의 배수: N'` 형태의 문자열로 바꾸어 출력해보세요.
4. `StreamController<int>`를 만들어 `add`로 임의의 정수 5개를 흘려보내고, 구독 콜백에서 지금까지 받은 값의 합계를 누적해서 출력해보세요.
5. `onError` 콜백이 호출되는 상황을 직접 만들어보세요. `async*` 함수 안에서 특정 조건일 때 `throw`를 실행하고, `listen`의 `onError`에서 그 오류를 잡아 출력해보세요.
