본문에서 배운 내용 중 실무에서 참조용으로 자주 찾아보게 되는 메서드와 표를 한곳에 모았습니다. 각 표는 관련 장을 함께 표시해두었으니, 자세한 설명이 필요하면 해당 장을 다시 펼쳐보세요.

## 컬렉션 메서드 치트시트 (13장 총정리)

### List / Set / Iterable 공통

| 메서드 | 설명 |
| --- | --- |
| `add(e)` / `addAll(it)` | 요소 하나 / 여러 개를 끝에 추가 (List, Set) |
| `remove(e)` | 값이 일치하는 첫 요소 제거 |
| `removeAt(i)` | 인덱스 `i`의 요소 제거 (List) |
| `removeWhere(test)` | 조건을 만족하는 모든 요소 제거 |
| `contains(e)` | 값이 존재하는지 확인 |
| `isEmpty` / `isNotEmpty` | 비어 있는지 / 비어 있지 않은지 확인 |
| `length` | 요소 개수 |
| `first` / `last` | 첫 번째 / 마지막 요소 |
| `sort([compare])` | 리스트를 제자리에서 정렬 (List) |
| `reversed` | 순서를 뒤집은 이터러블 반환 |
| `toList()` / `toSet()` | 다른 컬렉션 타입으로 변환 |
| `map(f)` | 각 요소를 변환한 지연 평가 이터러블 반환 |
| `where(test)` | 조건을 만족하는 요소만 걸러낸 이터러블 반환 |
| `any(test)` / `every(test)` | 하나라도 / 모두 조건을 만족하는지 확인 |
| `reduce(combine)` | 첫 요소부터 시작해 하나의 값으로 누적 (빈 컬렉션 불가) |
| `fold(initial, combine)` | 초깃값에서 시작해 하나의 값으로 누적 |
| `forEach(f)` | 각 요소에 대해 부수 효과 실행 (반환값 없음) |
| `take(n)` / `skip(n)` | 앞에서 `n`개만 취하기 / 건너뛰기 |
| `firstWhere(test)` | 조건을 만족하는 첫 요소 (없으면 예외 또는 `orElse`) |
| `indexOf(e)` | 값의 인덱스 (List, 없으면 -1) |

### Set 전용

| 메서드 | 설명 |
| --- | --- |
| `union(other)` | 합집합 |
| `intersection(other)` | 교집합 |
| `difference(other)` | 차집합 |

### Map 전용

| 메서드/속성 | 설명 |
| --- | --- |
| `map[key]` | 키에 대응하는 값 (없으면 `null`) |
| `map[key] = value` | 키-값 추가/갱신 |
| `remove(key)` | 키-값 쌍 제거 |
| `containsKey(key)` / `containsValue(v)` | 키/값 존재 여부 확인 |
| `keys` / `values` | 키 전체 / 값 전체 (Iterable) |
| `forEach((k, v) => ...)` | 모든 키-값 쌍에 대해 실행 |
| `putIfAbsent(key, f)` | 키가 없을 때만 `f()` 결과로 추가 |
| `update(key, f, ifAbsent: ...)` | 기존 값을 `f`로 갱신, 없으면 `ifAbsent` 사용 |

## 문자열 메서드 치트시트 (13장, 3장 총정리)

| 메서드/속성 | 설명 |
| --- | --- |
| `length` | 문자 개수 |
| `isEmpty` / `isNotEmpty` | 비어 있는지 확인 |
| `toUpperCase()` / `toLowerCase()` | 대소문자 변환 |
| `trim()` / `trimLeft()` / `trimRight()` | 앞뒤(또는 한쪽) 공백 제거 |
| `contains(s)` | 부분 문자열 포함 여부 |
| `startsWith(s)` / `endsWith(s)` | 시작/끝 문자열 확인 |
| `substring(start, [end])` | 부분 문자열 추출 |
| `split(sep)` | 구분자로 나눠 `List<String>` 반환 |
| `replaceAll(from, to)` | 모든 일치 부분을 치환 |
| `replaceFirst(from, to)` | 첫 일치 부분만 치환 |
| `trim().isEmpty` | 공백만 있는 문자열인지 확인하는 흔한 패턴 |
| `codeUnits` / `runes` | 문자 코드 단위 / 유니코드 코드 포인트 시퀀스 |
| `padLeft(width, [pad])` / `padRight(...)` | 지정한 폭까지 채워 넣기 |
| `join(sep)` | (List의 메서드) 요소들을 구분자로 이어 붙여 문자열로 |
| `int.parse(s)` / `double.parse(s)` | 문자열을 숫자로 변환 (실패 시 예외) |
| `int.tryParse(s)` / `double.tryParse(s)` | 문자열을 숫자로 변환 (실패 시 `null`) |
| `'$변수'`, `'${표현식}'` | 문자열 보간(interpolation) |

## Future / Stream 메서드 요약표 (15장, 16장 총정리)

### Future

| 메서드/함수 | 설명 |
| --- | --- |
| `Future(computation)` | 비동기적으로 한 번 실행되는 `Future` 생성 |
| `Future.value(v)` | 이미 완료된 값을 담은 `Future` 생성 |
| `Future.delayed(duration, [computation])` | 지정한 시간 뒤에 완료되는 `Future` 생성 |
| `Future.wait(futures)` | 여러 `Future`가 모두 완료되기를 기다려 결과 리스트 반환 |
| `.then(onValue, {onError})` | 완료되면 콜백 실행 (`await`의 저수준 형태) |
| `.catchError(onError)` | 실패했을 때 처리 |
| `.whenComplete(action)` | 성공/실패와 관계없이 항상 실행 |
| `await future` | `Future`가 완료될 때까지 기다리고 값을 꺼냄 (`async` 함수 안에서만) |
| `try { ... } catch (e) { ... }` | `await` 중 발생한 예외를 동기 코드처럼 처리 |
| `unawaited(future)` | 의도적으로 기다리지 않음을 명시 (`dart:async`) |

### Stream

| 메서드/함수 | 설명 |
| --- | --- |
| `Stream.fromIterable(it)` | 이터러블의 각 값을 순서대로 방출하는 스트림 생성 |
| `Stream.periodic(duration, [f])` | 일정 주기로 값을 방출하는 스트림 생성 |
| `.listen(onData, {onError, onDone})` | 스트림을 구독해 이벤트마다 콜백 실행 |
| `await for (var v in stream)` | `async` 함수 안에서 스트림 값을 순서대로 기다리며 처리 |
| `.map(f)` / `.where(test)` | 스트림 값을 변환/필터링한 새 스트림 반환 |
| `.first` / `.last` / `.toList()` | 스트림의 첫 값 / 마지막 값 / 전체를 리스트로 (모두 `Future` 반환) |
| `.asyncMap(f)` | 각 값을 비동기 함수로 변환한 새 스트림 반환 |
| `StreamController` | 직접 이벤트를 추가(`add`)해 스트림을 만들어내는 도구 |
| `subscription.cancel()` | 구독 해제 (자원 정리를 위해 반드시 필요할 때 호출) |
| `subscription.pause()` / `.resume()` | 구독을 잠시 멈추고 다시 시작 |

## 연산자 우선순위표 (4장 총정리)

아래 표는 우선순위가 높은 연산자부터 낮은 연산자 순으로 정리한 것입니다. 같은 줄에 있는 연산자는 우선순위가 같으며, 결합 방향은 대부분 왼쪽에서 오른쪽입니다(단항 연산자와 대입 연산자는 예외).

| 우선순위 | 연산자 | 설명 |
| --- | --- | --- |
| 1 (가장 높음) | `()`, `[]`, `.`, `?.`, `!` | 함수 호출, 인덱싱, 멤버 접근, null 인지 접근, null 단정 |
| 2 | `-`(단항), `!`(논리 부정), `~`, `++`, `--` (전위) | 단항 연산자 |
| 3 | `*`, `/`, `~/`, `%` | 곱셈, 나눗셈, 정수 나눗셈, 나머지 |
| 4 | `+`, `-` | 덧셈, 뺄셈 (이항) |
| 5 | `<<`, `>>`, `>>>` | 비트 시프트 |
| 6 | `&` | 비트 AND |
| 7 | `^` | 비트 XOR |
| 8 | `\|` | 비트 OR |
| 9 | `>=`, `>`, `<=`, `<`, `as`, `is`, `is!` | 비교, 타입 검사/캐스팅 |
| 10 | `==`, `!=` | 동등/부등 비교 |
| 11 | `&&` | 논리 AND |
| 12 | `\|\|` | 논리 OR |
| 13 | `??` | null 병합 |
| 14 | `? :` | 조건(삼항) 연산자 |
| 15 | `=`, `+=`, `-=`, `*=`, `/=`, `??=` 등 | 대입 연산자 (오른쪽에서 왼쪽으로 결합) |
| 16 (가장 낮음) | `,` | 쉼표(주로 나열 구분) |

우선순위를 외우기보다, 헷갈릴 때는 괄호 `()`로 의도를 명시적으로 드러내는 것이 가장 안전합니다. 특히 `??`와 삼항 연산자, 비트 연산자를 섞어 쓸 때는 괄호를 아끼지 않는 것을 권장합니다.

## 더 배우고 싶을 때 참고할 자료

이 책은 Dart 언어의 기초를 다지는 데 집중했습니다. 더 깊이 있는 내용이나 최신 변경 사항이 궁금하다면 다음과 같은 종류의 자료를 찾아보는 것이 좋습니다.

- **언어 공식 문서**: Dart 언어 자체의 문법과 라이브러리 API를 정확하고 최신으로 설명하는 1차 자료입니다. 이 책에서 다룬 개념의 세부 규칙이나 예외 상황을 확인할 때 가장 신뢰할 수 있는 출처입니다.
- **패키지 문서와 예제 코드**: pub.dev에 등록된 패키지들은 대개 사용법 문서와 예제 코드를 함께 제공합니다. 17장에서 소개한 패키지 생태계를 실제로 활용하려면 이런 문서를 직접 읽고 작은 예제를 따라 실행해보는 연습이 가장 효과적입니다.
- **언어/프레임워크 변경 내역**: Dart와 Flutter는 꾸준히 발전하는 언어와 프레임워크입니다. 새 버전이 나올 때 공개되는 변경 사항 목록을 훑어보면 이 책 이후에 추가된 기능이나 달라진 관용구를 파악할 수 있습니다.
- **커뮤니티 토론과 코드 저장소**: 다른 개발자들이 실제로 어떤 문제를 겪고 어떻게 해결했는지를 살펴보는 것은, 특히 18장에서 다룬 것과 같은 코드 습관을 체득하는 데 큰 도움이 됩니다. 활발히 관리되는 오픈소스 프로젝트의 코드를 읽어보는 것도 좋은 학습 방법입니다.

어떤 자료를 보든, 설명을 읽는 데서 멈추지 않고 직접 코드를 타이핑하고 실행해보며 결과를 확인하는 습관이 가장 오래 남는 학습으로 이어진다는 점을 기억하세요.
