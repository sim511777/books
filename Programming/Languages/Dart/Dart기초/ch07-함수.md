## 함수는 왜 필요한가

5장과 6장에서 조건문과 반복문을 다루면서, 어떤 로직이 여러 번 되풀이될 때 코드가 금방 지저분해진다는 것을 눈치챘을 것이다. 예를 들어 두 숫자 중 더 큰 값을 찾는 로직을 프로그램 여기저기서 써야 한다면, 그 로직을 매번 다시 적는 대신 이름을 붙여 한 곳에 모아두고 필요할 때마다 불러 쓰는 편이 훨씬 낫다. 이렇게 특정 작업을 이름으로 묶어 재사용 가능하게 만든 것이 바로 **함수(function)**다.

함수를 잘 쓰면 코드의 중복이 줄고, 각 함수가 "이 이름이 무슇을 하는지"만 알면 내부 구현을 몰라도 사용할 수 있게 되어 프로그램 전체의 가독성이 올라간다. Dart는 함수를 클래스 밖에 독립적으로 선언할 수도 있고(다른 언어에서는 이런 걸 지원하지 않는 경우도 많다), 클래스 안의 메서드로 선언할 수도 있다. 이번 장에서는 클래스 없이 최상위(top-level)에 선언하는 함수를 중심으로 문법을 익히고, 클래스의 메서드는 9장 클래스와 객체에서 자세히 다룬다.

## 함수 정의의 기본 형태

Dart에서 함수는 반환 타입, 함수 이름, 매개변수 목록, 본문(body)으로 구성된다.

```dart
// 두 정수를 더해서 반환하는 함수
int add(int a, int b) {
  return a + b;
}

void main() {
  final result = add(3, 4);
  print(result); // 7
}
```

여기서 `int`는 반환 타입, `add`는 함수 이름, `(int a, int b)`는 매개변수 목록이다. 반환값이 없는 함수는 반환 타입 자리에 `void`를 적는다. `void`는 "아무 값도 돌려주지 않는다"는 뜻이며, 3장에서 배운 자료형과 달리 값 자체를 표현하지 않는 특별한 표시라고 생각하면 된다.

```dart
// 값을 반환하지 않고 화면에 출력만 하는 함수
void greet(String name) {
  print('안녕하세요, $name님!');
}
```

이미 2장에서 본 `main()` 함수도 `void main() { ... }` 형태의, Dart 프로그램의 시작점이 되는 최상위 함수였다는 것을 다시 떠올려보자.

## 필수 위치 매개변수

앞의 `add(int a, int b)`처럼 괄호 안에 그냥 나열한 매개변수를 **필수 위치 매개변수(required positional parameter)**라고 부른다. "위치"라는 말은 호출할 때 순서대로 값을 넘겨야 한다는 뜻이고, "필수"라는 말은 값을 반드시 넘겨야 한다는 뜻이다. 순서를 바꾸면 의미가 완전히 달라질 수 있으니 주의해야 한다.

```dart
// 순서에 따라 결과가 달라지는 예
double divide(double dividend, double divisor) {
  return dividend / divisor;
}

void main() {
  print(divide(10, 2)); // 5.0
  print(divide(2, 10)); // 0.2 — 순서를 바꾸면 결과가 다르다
}
```

## 선택적 위치 매개변수 `[]`

경우에 따라 어떤 매개변수는 값을 넘기지 않아도 괜찮게 만들고 싶을 때가 있다. 대괄호 `[]`로 감싼 매개변수는 **선택적 위치 매개변수(optional positional parameter)**가 되어, 호출할 때 생략할 수 있다.

```dart
// unit을 생략하면 기본적으로 'cm' 단위로 취급한다고 가정한 함수
String describeLength(double value, [String unit = 'cm']) {
  return '$value$unit';
}

void main() {
  print(describeLength(180));       // 180.0cm
  print(describeLength(1.8, 'm'));  // 1.8m
}
```

선택적 매개변수에는 기본값을 지정할 수 있는데, 기본값을 지정하지 않으면 값을 넘기지 않았을 때 해당 매개변수는 `null`이 된다. 이때 매개변수의 타입은 `String?`처럼 널러블(nullable)로 선언해야 하는데, 이 부분은 8장 sound null safety에서 왜 그렇게 해야 하는지 자세히 설명한다. 지금은 "값이 안 넘어올 수도 있는 매개변수는 기본값을 주거나 null을 허용하는 타입으로 선언해야 한다"는 정도만 기억해두자.

선택적 위치 매개변수는 반드시 필수 매개변수 뒤에만 위치할 수 있다. 즉 `[String unit = 'cm']` 앞에 다른 선택적 매개변수가 오는 것은 가능하지만, 필수 매개변수를 선택적 매개변수 뒤에 두는 것은 문법 오류다.

## 이름 붙은 매개변수 `{}`

매개변수가 여러 개일 때 호출하는 쪽에서 각 값이 무엇을 의미하는지 헷갈리기 쉽다. 예를 들어 `createUser('철수', 25, true)` 같은 호출문만 보면 `true`가 무엇을 의미하는지 코드만 봐서는 알기 어렵다. 이런 문제를 해결하기 위해 Dart는 중괄호 `{}`로 매개변수를 감싸는 **이름 붙은 매개변수(named parameter)**를 제공한다. 이름 붙은 매개변수는 호출할 때 `매개변수이름: 값` 형태로 전달하며, 순서는 상관없다.

```dart
// 이름 붙은 매개변수를 사용해 호출 코드의 의미를 명확히 한다
void createUser({required String name, required int age, bool isAdmin = false}) {
  print('$name ($age세) — 관리자 여부: $isAdmin');
}

void main() {
  createUser(name: '철수', age: 25, isAdmin: true);
  createUser(age: 30, name: '영희'); // 순서를 바꿔도 문제없다
  createUser(name: '민수', age: 17); // isAdmin은 기본값 false
}
```

이름 붙은 매개변수는 기본적으로 선택 사항이지만, `required` 키워드를 붙이면 반드시 값을 넘겨야 하는 필수 매개변수가 된다. `required`가 붙지 않은 이름 붙은 매개변수는 기본값을 지정하지 않으면 `null`이 될 수 있으므로 타입을 널러블로 선언해야 한다는 규칙 역시 위치 매개변수와 동일하다.

실무에서는 매개변수가 두세 개를 넘어가는 함수라면 이름 붙은 매개변수를 적극적으로 사용하는 편이 좋다. 호출 코드만 읽어도 각 값의 의미가 드러나기 때문이다. Flutter 위젯 생성자들이 대부분 이름 붙은 매개변수로 구성된 것도 같은 이유다.

## 위치 매개변수와 이름 붙은 매개변수 함께 쓰기

하나의 함수에 필수 위치 매개변수와 이름 붙은 매개변수를 함께 쓸 수도 있다.

```dart
// 필수 위치 매개변수와 이름 붙은 매개변수를 함께 사용
String formatPrice(num price, {String currency = '원', bool showSign = false}) {
  final sign = showSign ? '+' : '';
  return '$sign$price$currency';
}

void main() {
  print(formatPrice(15000));                          // 15000원
  print(formatPrice(15000, currency: '\$'));           // 15000$
  print(formatPrice(15000, showSign: true));           // +15000원
}
```

단, 선택적 위치 매개변수 `[]`와 이름 붙은 매개변수 `{}`는 같은 함수에서 동시에 사용할 수 없다. 둘 중 하나를 선택해야 한다.

## 화살표 함수 `=>`

함수 본문이 표현식 하나로 끝나고 그 값을 그대로 반환하는 경우, 중괄호와 `return` 키워드를 생략하고 `=>` 기호로 간단히 적을 수 있다. 이것을 **화살표 함수(arrow function)** 또는 화살표 문법이라고 부른다.

```dart
// 중괄호와 return을 쓴 일반적인 형태
int square(int n) {
  return n * n;
}

// 화살표 함수로 같은 내용을 간결하게 표현
int squareArrow(int n) => n * n;

void main() {
  print(square(5));      // 25
  print(squareArrow(5)); // 25
}
```

`=>` 뒤에는 표현식 하나만 올 수 있으며, 세미콜론으로 문장을 끝낸다. 조건문이나 반복문처럼 여러 문장이 필요한 로직에는 화살표 함수를 쓸 수 없고, 중괄호를 사용한 일반적인 함수 본문을 써야 한다. 다만 삼항 연산자(4장에서 다룬 `조건 ? 참일때값 : 거짓일때값`)를 활용하면 조건에 따른 분기도 화살표 함수 하나로 표현할 수 있다.

```dart
// 삼항 연산자와 화살표 함수를 함께 사용
String evenOrOdd(int n) => n % 2 == 0 ? '짝수' : '홀수';

void main() {
  print(evenOrOdd(7));  // 홀수
  print(evenOrOdd(10)); // 짝수
}
```

화살표 함수는 짧고 단순한 함수를 표현할 때 코드를 눈에 잘 들어오게 만들어주는 문법적 설탕(syntactic sugar)이다. 실행 방식은 중괄호를 쓴 함수와 완전히 동일하며, 성능상의 차이도 없다.

## 익명 함수 맛보기

지금까지 살펴본 함수들은 모두 이름이 있는 함수였다. 하지만 Dart에서는 이름 없이 그 자리에서 즉석으로 정의하는 함수, 즉 **익명 함수(anonymous function)**도 만들 수 있다. 익명 함수는 함수를 변수에 담거나, 다른 함수의 인자로 즉시 전달할 때 특히 유용하다.

```dart
void main() {
  // 익명 함수를 변수에 저장
  final multiply = (int a, int b) {
    return a * b;
  };
  print(multiply(3, 4)); // 12

  // 화살표 문법을 쓴 익명 함수
  final multiplyArrow = (int a, int b) => a * b;
  print(multiplyArrow(3, 4)); // 12

  // 리스트의 forEach에 익명 함수를 바로 전달
  final numbers = [1, 2, 3];
  numbers.forEach((n) {
    print('숫자: $n');
  });
}
```

여기서 `multiply`라는 변수에 담긴 것은 값이 아니라 "실행 가능한 코드 조각" 그 자체다. Dart에서는 함수도 하나의 값처럼 다룰 수 있는데, 이런 성질을 활용해 함수를 다른 함수의 매개변수로 넘기는 패턴을 **고차 함수(higher-order function)**라고 부른다. `numbers.forEach(...)`에 넘긴 익명 함수가 바로 그 예다.

익명 함수와 고차 함수는 13장 컬렉션과 컬렉션 처리에서 `map`, `where`, `reduce` 같은 컬렉션 메서드와 함께 훨씬 자세히 다룰 것이다. 지금은 "함수도 변수에 담거나 다른 함수에 전달할 수 있는 값이 될 수 있다"는 감각만 잡아두면 충분하다.

## 요약

- 함수는 반환 타입, 이름, 매개변수 목록, 본문으로 구성되며 값을 반환하지 않으면 `void`를 반환 타입으로 쓴다.
- 필수 위치 매개변수는 순서대로 값을 전달해야 하는 기본적인 매개변수 형태다.
- 대괄호 `[]`로 선언한 선택적 위치 매개변수는 값을 생략할 수 있고, 기본값을 지정할 수 있다.
- 중괄호 `{}`로 선언한 이름 붙은 매개변수는 `이름: 값` 형태로 호출하며, `required`를 붙이면 필수가 된다.
- 선택적 위치 매개변수와 이름 붙은 매개변수는 같은 함수에서 함께 쓸 수 없다.
- 화살표 함수 `=>`는 표현식 하나로 끝나는 함수 본문을 간결하게 표현하는 문법이다.
- 익명 함수는 이름 없이 즉석에서 정의하는 함수로, 변수에 담거나 다른 함수의 인자로 전달할 수 있으며 자세한 활용은 13장에서 이어진다.

## 연습문제

1. 세 정수를 받아 그중 가장 큰 값을 반환하는 함수 `maxOfThree`를 작성하라.
2. 학생의 이름(필수)과 점수(선택, 기본값 0)를 받아 `"철수: 85점"` 형태의 문자열을 반환하는 함수를 선택적 위치 매개변수를 사용해 작성하라.
3. 상품명(필수 위치 매개변수)과 가격, 할인율(이름 붙은 매개변수, 할인율은 기본값 0)을 받아 최종 가격을 계산해 반환하는 함수를 작성하라.
4. 정수를 받아 3의 배수이면 `"Fizz"`, 5의 배수이면 `"Buzz"`, 둘 다이면 `"FizzBuzz"`, 아니면 그 숫자를 문자열로 반환하는 함수를 화살표 함수와 조건 연산자를 활용해 최대한 간결하게 작성해보라.
5. 정수 리스트와 익명 함수를 매개변수로 받아, 리스트의 각 원소에 익명 함수를 적용한 새 리스트를 반환하는 함수 `applyToAll`을 작성해보라. (힌트: 매개변수의 타입으로 `int Function(int)` 같은 함수 타입을 사용할 수 있다.)
