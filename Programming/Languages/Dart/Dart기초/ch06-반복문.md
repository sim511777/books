# 6장. 반복문

같은 작업을 여러 번 반복해야 할 때마다 코드를 복사해서 붙여넣을 수는 없다. 반복문은 "조건이 유지되는 동안" 또는 "정해진 횟수만큼" 코드 블록을 되풀이해서 실행하게 해주는 도구다. 이번 장에서는 Dart가 제공하는 `while`, `do-while`, `for`, `for-in`을 살펴보고, 반복을 중간에 제어하는 `break`/`continue`, 그리고 반복문을 겹쳐 쓰는 중첩 반복까지 다룬다.

## while문

`while`문은 조건식이 참인 동안 블록을 계속 실행한다. 조건을 먼저 검사하고 나서 블록을 실행하기 때문에, 처음부터 조건이 거짓이면 블록은 한 번도 실행되지 않는다.

```dart
void countDown(int start) {
  int current = start;
  while (current > 0) {
    print(current);
    current--;
  }
  print('발사!');
}
```

`while`문을 쓸 때 가장 흔한 실수는 반복 변수를 갱신하는 코드를 빠뜻리는 것이다. `current--`가 없다면 `current`는 영원히 `start` 값에 머물러 있고, 조건은 계속 참이 되어 프로그램이 멈추지 않는 **무한 루프**에 빠진다. 반복문을 작성할 때는 항상 "이 조건이 언젠가 거짓이 될 수 있는가?"를 스스로 확인하는 습관을 들이자.

## do-while문

`do-while`문은 `while`문과 반대로, 블록을 먼저 한 번 실행한 뒤에 조건을 검사한다. "최소 한 번은 실행되어야 하는" 로직에 적합하다.

```dart
void askUntilValid() {
  int attempt = 0;
  int guess;
  do {
    guess = attempt * 3 - 1; // 실제로는 사용자 입력을 받는 자리라고 가정
    print('시도 $attempt: 값은 $guess');
    attempt++;
  } while (guess < 10);
}
```

두 반복문의 차이를 표로 정리하면 다음과 같다.

| 반복문 | 조건 검사 시점 | 최소 실행 횟수 |
|---|---|---|
| `while` | 블록 실행 전 | 0회 |
| `do-while` | 블록 실행 후 | 1회 |

## for문: 전통형과 for-in

`for`문은 "초기화 → 조건 검사 → 블록 실행 → 증감"의 흐름을 한 줄에 압축해서 표현한다. 정해진 횟수만큼 반복할 때 `while`문보다 코드가 짧고, 반복 변수의 범위와 갱신 로직이 한눈에 보인다.

```dart
void printSquares(int n) {
  for (int i = 1; i <= n; i++) {
    print('$i의 제곱은 ${i * i}');
  }
}
```

세 부분(`int i = 1`, `i <= n`, `i++`) 중 어느 것도 필수는 아니다. 예를 들어 증감식을 생략하고 블록 안에서 직접 변수를 조작할 수도 있지만, 그렇게 하면 `for`문 특유의 가독성이 사라지므로 특별한 이유가 없다면 세 부분을 모두 채우는 것을 권장한다.

컬렉션(리스트, 셋, 맵 등)을 다룰 때는 인덱스를 직접 계산하는 대신 `for-in`문을 쓰는 것이 훨씬 자연스럽다.

```dart
void printAllFruits() {
  final fruits = ['사과', '바나나', '포도'];
  for (final fruit in fruits) {
    print(fruit);
  }
}
```

`for-in`은 리스트뿐 아니라 `Iterable`을 구현한 모든 타입(셋, 맵의 키/값, 문자열의 문자 등)에 사용할 수 있다. 인덱스가 굳이 필요하다면 전통형 `for`문을 쓰거나, 나중에 13장에서 다룰 `asMap()`, `indexed` 같은 컬렉션 메서드를 활용할 수도 있다.

```dart
void printWithIndex() {
  final fruits = ['사과', '바나나', '포도'];
  for (int i = 0; i < fruits.length; i++) {
    print('$i번: ${fruits[i]}');
  }
}
```

## 컬렉션 순회

맵(`Map`)은 리스트와 구조가 달라서 `for-in`을 그대로 쓰면 키만 순회하게 된다. 키와 값을 함께 다루려면 `entries`를 사용한다.

```dart
void printScores() {
  final scores = {'철수': 88, '영희': 95, '민수': 76};

  // 키만 순회
  for (final name in scores.keys) {
    print(name);
  }

  // 키와 값을 함께 순회
  for (final entry in scores.entries) {
    print('${entry.key}: ${entry.value}점');
  }
}
```

`Set`은 리스트와 마찬가지로 `for-in`으로 바로 순회할 수 있다. 다만 셋은 순서를 보장하지 않는 구현도 있으므로(Dart의 기본 `Set`은 삽입 순서를 유지하지만), 순서에 의존하는 로직을 짤 때는 주의가 필요하다. 컬렉션의 세부 종류는 13장에서 본격적으로 다룬다.

## break와 continue

`break`는 반복문을 즉시 종료하고 빠져나간다. `continue`는 현재 반복만 건너뛰고 다음 반복으로 넘어간다. 두 키워드 모두 `while`, `do-while`, `for`, `for-in` 어디에나 쓸 수 있다.

```dart
void findFirstEven(List<int> numbers) {
  for (final n in numbers) {
    if (n % 2 != 0) {
      continue; // 홀수는 건너뛰고 다음 원소로
    }
    print('첫 짝수를 찾았습니다: $n');
    break; // 찾았으니 반복문 종료
  }
}
```

`break`와 `continue`는 편리하지만 남용하면 반복문의 흐름을 눈으로 따라가기 어려워진다. 조건이 두세 개 이상 겹치면, 차라리 반복문 안의 로직을 별도 함수로 분리하고 `return`으로 대체하는 것이 더 명확할 때가 많다.

## 중첩 반복문

반복문 안에 또 다른 반복문을 넣는 중첩 구조는 2차원 데이터(표, 좌표, 격자)를 다룰 때 자주 등장한다.

```dart
void printMultiplicationTable() {
  for (int i = 2; i <= 9; i++) {
    for (int j = 1; j <= 9; j++) {
      print('$i x $j = ${i * j}');
    }
    print('---');
  }
}
```

중첩 반복문에서 `break`나 `continue`는 **가장 안쪽 반복문에만** 적용된다는 점에 주의해야 한다. 바깥쪽 반복문까지 한꺼번에 빠져나가고 싶다면, Dart는 **라벨(label)**을 이용한 `break`를 지원한다.

```dart
void findPairSum(List<int> numbers, int target) {
  outerLoop:
  for (int i = 0; i < numbers.length; i++) {
    for (int j = i + 1; j < numbers.length; j++) {
      if (numbers[i] + numbers[j] == target) {
        print('${numbers[i]} + ${numbers[j]} = $target');
        break outerLoop; // 바깥쪽 반복문까지 함께 종료
      }
    }
  }
}
```

라벨은 반복문 앞에 `이름:` 형태로 붙이고, `break 이름` 또는 `continue 이름`으로 참조한다. 유용한 기능이지만 남발하면 코드 흐름이 오히려 복잡해지므로, "정말로 두 단계 이상 바깥으로 빠져나가야 하는 경우"에만 제한적으로 사용하는 것이 좋다. 대부분의 경우는 조건을 만족하면 즉시 함수를 종료하는 `return`으로 대체할 수 있는지 먼저 고민해보자.

## 요약

- `while`은 조건을 먼저 검사하고, `do-while`은 블록을 먼저 실행한 뒤 조건을 검사한다.
- 전통형 `for`문은 반복 횟수가 정해져 있을 때, `for-in`은 컬렉션의 각 원소를 순회할 때 적합하다.
- 맵은 `keys`, `values`, `entries`를 통해 원하는 형태로 순회할 수 있다.
- `break`는 반복문 종료, `continue`는 현재 반복 건너뛰기이며, 둘 다 남용하면 가독성이 떨어진다.
- 중첩 반복문에서 `break`/`continue`는 기본적으로 가장 안쪽 반복문에만 적용되며, 바깥쪽까지 제어하려면 라벨을 사용할 수 있다.

## 연습문제

1. `while`문을 사용해 1부터 100까지의 합을 구하는 함수를 작성해 보라.
2. `for-in`문을 사용해 문자열 리스트 중 길이가 가장 긴 단어를 찾는 함수를 작성해 보라.
3. 1부터 30까지의 수 중 3의 배수는 건너뛰고(`continue`), 20을 만나면 반복을 종료(`break`)하는 `for`문을 작성하고 그 결과를 출력해 보라.
4. 두 개의 정수 리스트를 받아, 두 리스트에서 각각 하나씩 골라 곱이 특정 목표값과 같아지는 첫 번째 쌍을 라벨이 붙은 `break`로 찾는 함수를 작성해 보라.
5. `Map<String, int>` 형태의 재고 데이터를 순회하며 수량이 0인 항목의 이름만 모아 리스트로 반환하는 함수를 작성해 보라.
