프로그램은 결국 데이터를 담고, 옮기고, 바꾸는 일의 연속입니다. 그 데이터를 담는 상자가 바로 변수입니다. Dart는 변수를 선언하는 방법이 세 가지나 있고, 각각이 미묘하게 다른 의미를 가지고 있습니다. 이번 장에서는 `var`, `final`, `const`의 차이를 명확히 구분하고, Dart의 기본 자료형들을 살펴본 뒤, 타입 사이를 오가는 형변환까지 정리합니다.

## var, final, const — 무엇이 다른가

셋 다 "변수를 만든다"는 점은 같지만, 그 변수에 다시 값을 넣을 수 있는지, 그리고 그 값이 언제 결정되는지가 다릅니다.

`var`는 가장 평범한 변수입니다. 값을 나중에 다른 값으로 바꿔 끼울 수 있습니다.

```dart
void main() {
  var score = 10;
  score = 20; // 문제없음: var는 재할당 가능
  print(score); // 20
}
```

`final`은 "한 번만 대입할 수 있는" 변수입니다. 선언할 때 값을 정해두면, 그 이후로는 다른 값을 대입할 수 없습니다. 다만 그 값이 정해지는 시점은 프로그램이 실행되는 도중(런타임)이어도 괜찮습니다.

```dart
void main() {
  final now = DateTime.now(); // 실행 시점에 결정되는 값
  // now = DateTime.now(); // 오류: final 변수는 재할당 불가
  print(now);
}
```

`const`는 한 걸음 더 나아가서, 값이 프로그램을 컴파일하는 시점에 이미 확정되어 있어야 합니다. 즉 실행하지 않아도 컴파일러가 그 값을 알 수 있어야 합니다.

```dart
void main() {
  const pi = 3.14159; // 컴파일 시점에 이미 알 수 있는 값
  const daysInWeek = 7;
  // const now = DateTime.now(); // 오류: 실행해야 알 수 있는 값이라 const 불가
  print(pi * daysInWeek);
}
```

정리하면 이렇습니다.

- `var`: 나중에 값을 바꿔도 되는 보통의 변수
- `final`: 딱 한 번 대입, 그 값은 런타임에 결정되어도 됨(런타임 상수)
- `const`: 딱 한 번 대입, 그 값은 컴파일타임에 이미 확정(컴파일타임 상수)

실무에서는 "값이 바뀔 필요가 없다면 `var` 대신 `final`을 쓰자"는 습관이 널리 퍼져 있습니다. 이렇게 하면 나중에 실수로 값을 덮어써서 발생하는 버그를 원천적으로 막을 수 있고, 코드를 읽는 사람도 "이 값은 절대 바뀌지 않는다"는 확신을 가질 수 있습니다. 값이 정말로 컴파일 시점에 고정된 리터럴이라면 `const`를 쓰는 것이 더 유리합니다. `const`로 만든 값은 메모리에 단 하나만 존재하도록 공유되기 때문에, 특히 컬렉션을 다룰 때 성능상 이점이 있습니다. 이 부분은 13장 컬렉션과 컬렉션 처리에서 다시 다룹니다.

## 기본 자료형

Dart는 모든 값이 객체입니다. 숫자도, 문자열도, 심지어 함수도 객체입니다. 하지만 처음 배울 때는 다음 몇 가지 기본 타입만 알아도 충분합니다.

### 정수와 실수: int, double

```dart
void main() {
  int age = 28;
  double height = 174.5;

  print(age + 2); // 30
  print(height / 2); // 87.25
}
```

`int`는 정수, `double`은 소수점이 있는 실수를 나타냅니다. 정수를 실수로 나누면 결과는 자동으로 `double`이 됩니다. 두 타입을 함께 가리킬 필요가 있을 때는 상위 타입인 `num`을 쓸 수도 있습니다.

```dart
void main() {
  num anything = 10; // int도, double도 담을 수 있는 상위 타입
  anything = 10.5;
  print(anything);
}
```

### 문자열: String

문자열은 작은따옴표(`'`)나 큰따옴표(`"`)로 감쌉니다. 특히 유용한 기능은 문자열 보간(string interpolation)입니다. `$변수명` 또는 `${표현식}` 형태로 문자열 안에 값을 바로 끼워 넣을 수 있습니다.

```dart
void main() {
  var name = '민지';
  var age = 25;
  print('$name님은 $age살입니다.'); // 민지님은 25살입니다.
  print('내년이면 ${age + 1}살이 되네요.'); // 내년이면 26살이 되네요.
}
```

### 참/거짓: bool

`bool`은 `true`와 `false` 두 값만 가지는 타입입니다. 5장 제어문에서 조건 분기의 핵심 재료로 다시 등장합니다.

```dart
void main() {
  bool isRaining = false;
  print(isRaining); // false
}
```

### 컬렉션 맛보기: List, Map, Set

여러 개의 값을 하나로 묶어 다뤄야 할 때는 컬렉션을 사용합니다. 자세한 내용은 13장에서 다루지만, 여기서는 존재만 짚어둡니다.

```dart
void main() {
  // List: 순서가 있는 목록
  var fruits = ['사과', '바나나', '포도'];

  // Map: 키와 값의 짝
  var scores = {'수학': 90, '영어': 85};

  // Set: 중복이 없는 집합
  var uniqueNumbers = {1, 2, 3};

  print(fruits[0]); // 사과
  print(scores['수학']); // 90
  print(uniqueNumbers.contains(2)); // true
}
```

## 타입 추론

지금까지 예제에서 `var name = '민지';`처럼 타입을 명시하지 않고도 문제없이 동작했습니다. Dart는 대입되는 값을 보고 변수의 타입을 스스로 추론합니다. `name`은 문자열이 대입되었으므로 컴파일러가 내부적으로 `String` 타입으로 확정합니다. 이후 `name = 10;`처럼 다른 타입의 값을 넣으려 하면 오류가 발생합니다. 즉 `var`는 "타입이 없다"는 뜻이 아니라 "타입을 내가 쓰지 않아도 컴파일러가 알아서 정해준다"는 뜻입니다.

```dart
void main() {
  var name = '민지'; // String으로 추론됨
  // name = 10; // 오류: String 타입에 int를 넣을 수 없음
}
```

타입을 명시적으로 적을지, `var`로 추론에 맡길지는 팀의 스타일에 따라 다릅니다. 다만 값이 무엇인지 이름만으로 짐작하기 어려운 경우에는 타입을 직접 적어주는 편이 코드를 읽는 사람에게 친절합니다.

## null이 될 수 있는 타입 살짝 엿보기

Dart의 모든 타입 뒤에는 `?`를 붙일 수 있습니다. 예를 들어 `int`는 반드시 정수 값을 가져야 하지만, `int?`는 정수 값을 가질 수도 있고 값이 아예 없는 상태인 `null`을 가질 수도 있습니다.

```dart
void main() {
  int? maybeAge; // 아직 값이 없음, null로 초기화됨
  print(maybeAge); // null

  maybeAge = 30;
  print(maybeAge); // 30
}
```

`?` 없이 선언한 `int age;`는 반드시 값을 가져야 하고, `null`을 대입할 수 없습니다. 이렇게 "이 변수가 null일 수 있는가"를 타입 시스템이 미리 검사해 주는 것이 Dart의 특징인 sound null safety입니다. 지금은 `?`가 붙으면 "값이 없을 수도 있다"는 표시라는 것만 기억해두세요. 자세한 규칙과 활용법은 8장에서 본격적으로 다룹니다.

## 형변환: 타입을 오가는 법

프로그램을 짜다 보면 정수를 문자열로, 문자열을 정수로 바꿔야 하는 순간이 자주 생깁니다. 사용자가 입력한 나이는 항상 문자열로 들어오지만, 계산을 하려면 숫자로 바꿔야 하는 식입니다.

### 다른 타입을 문자열로: toString()

거의 모든 값은 `toString()` 메서드를 가지고 있어서 문자열로 바꿀 수 있습니다.

```dart
void main() {
  int score = 95;
  String scoreText = score.toString();
  print('점수는 $scoreText점입니다.'); // 점수는 95점입니다.
}
```

사실 문자열 보간을 쓸 때는 `toString()`이 자동으로 호출되므로, `'점수는 $score점입니다.'`라고만 써도 결과는 같습니다.

### 문자열을 숫자로: parse

```dart
void main() {
  String input = '42';
  int number = int.parse(input);
  print(number + 8); // 50

  String priceText = '19.99';
  double price = double.parse(priceText);
  print(price * 2); // 39.98
}
```

`int.parse`나 `double.parse`는 문자열이 숫자 형식이 아니면 예외를 던집니다. 예를 들어 `int.parse('사과')`는 프로그램을 멈추게 만들 수 있습니다. 이런 상황에 안전하게 대응하고 싶다면 `int.tryParse`를 사용합니다. 이 메서드는 변환에 실패하면 예외 대신 `null`을 돌려줍니다.

```dart
void main() {
  String input = '사과';
  int? number = int.tryParse(input);
  print(number); // null, 예외가 발생하지 않음
}
```

`tryParse`의 결과 타입이 `int?`인 이유가 바로 여기 있습니다. 변환이 실패할 수 있다는 것을 타입 자체가 알려주는 것입니다. 이 값을 실제로 안전하게 다루는 여러 방법은 8장에서 자세히 설명합니다.

### 정수와 실수 사이

```dart
void main() {
  double pi = 3.14;
  int truncated = pi.toInt(); // 소수점 버림: 3
  int rounded = pi.round(); // 반올림: 3

  int wholeNumber = 7;
  double asDouble = wholeNumber.toDouble(); // 7.0

  print('$truncated $rounded $asDouble');
}
```

## 요약

- `var`는 재할당 가능한 일반 변수이고, `final`은 한 번만 대입되는 런타임 상수, `const`는 컴파일타임에 값이 확정되는 상수입니다.
- Dart의 기본 타입에는 `int`, `double`, `String`, `bool`이 있고, 상위 타입 `num`으로 정수와 실수를 함께 다룰 수 있습니다.
- `List`, `Map`, `Set` 같은 컬렉션은 여러 값을 하나로 묶어 다루며, 자세한 내용은 13장에서 다룹니다.
- `var`로 선언해도 타입이 사라지는 것이 아니라, 대입된 값을 보고 컴파일러가 타입을 추론할 뿐입니다.
- 타입 뒤에 `?`를 붙이면 그 변수가 `null`을 가질 수 있다는 뜻이며, 이 개념은 8장 sound null safety에서 자세히 다룹니다.
- `toString()`으로 다른 값을 문자열로, `int.parse`/`double.parse`로 문자열을 숫자로 바꿀 수 있으며, 실패할 가능성이 있다면 `tryParse`로 안전하게 처리합니다.

## 연습문제

1. `var`, `final`, `const`로 각각 변수를 하나씩 선언하고, 그 차이를 주석으로 설명해 보세요.
2. 사용자의 이름과 나이를 각각 `String`과 `int` 변수에 담고, 문자열 보간을 이용해 "OO님은 XX살입니다."라는 문장을 출력하는 프로그램을 작성하세요.
3. 문자열 `'123'`과 `'abc'`를 각각 `int.tryParse`로 변환해 보고, 결과가 어떻게 다른지 출력해 확인하세요.
4. `double` 값 `9.7`을 `toInt()`와 `round()`로 각각 변환했을 때 결과가 어떻게 다른지 비교해 보세요.
5. `int? quantity;`라고 선언한 뒤 아무 값도 대입하지 않고 출력하면 어떤 값이 나오는지 실행해 확인하고, 왜 그런 결과가 나오는지 설명해 보세요.
