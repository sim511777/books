## 들어가며

3장에서 변수와 자료형을 배웠으니, 이제 그 값들을 가지고 무언가를 계산하고 판단할 차례다. 연산자(operator)는 값들을 조합해서 새로운 값을 만들어내는 기호다. `1 + 2`처럼 익숙한 산술 연산부터, 두 값을 비교하는 관계 연산자, 조건을 조합하는 논리 연산자까지는 다른 언어를 조금이라도 다뤄본 사람에게는 낯설지 않을 것이다. 이번 장에서는 이런 기본 연산자를 정리하고, Dart에서 특히 자주 쓰이는 null 관련 연산자를 살짝 맛본 뒤, Dart만의 독특한 문법인 캐스케이드 연산자까지 살펴본다.

## 산술 연산자

산술 연산자는 숫자를 계산하는 데 쓰인다. `+`, `-`, `*`, `/`는 익숙하지만, Dart에는 나눗셈과 관련해서 조금 더 알아둘 것이 있다.

```dart
void main() {
  int a = 17;
  int b = 5;

  print(a + b); // 22
  print(a - b); // 12
  print(a * b); // 85
  print(a / b); // 3.4  (일반 나눗셈, 항상 double을 반환)
  print(a ~/ b); // 3   (정수 나눗셈, 소수점 버림)
  print(a % b); // 2    (나머지)
}
```

`/`는 두 정수를 나누더라도 결과를 항상 `double`로 돌려준다. 정수끼리 나눈 몫만 정수로 얻고 싶다면 `~/`를 사용한다. 이 기호는 "정수 나눗셈(integer division)"을 뜻하며, 소수점 이하를 버린 정수 몫을 돌려준다. `%`는 나머지를 구하는 연산자다.

값을 1씩 늘리거나 줄이는 상황이 잦다 보니, Dart는 증감 연산자 `++`와 `--`도 제공한다.

```dart
void main() {
  int count = 0;

  count++; // count = count + 1과 같음
  print(count); // 1

  int x = 5;
  print(x++); // 5: 먼저 값을 반환한 뒤 증가시킴 (후위)
  print(x); // 6

  int y = 5;
  print(++y); // 6: 먼저 증가시킨 뒤 값을 반환함 (전위)
}
```

`x++`처럼 변수 뒤에 붙이면(후위, postfix) 원래 값을 먼저 사용한 다음 증가시키고, `++y`처럼 변수 앞에 붙이면(전위, prefix) 먼저 증가시킨 값을 사용한다. 이 둘을 혼동하면 예상과 다른 결과가 나올 수 있으니, 값을 바로 출력하거나 다른 변수에 대입하는 경우에는 위치에 주의해야 한다.

복합 대입 연산자(`+=`, `-=`, `*=`, `/=` 등)도 자주 쓰인다. `score += 10;`은 `score = score + 10;`과 같은 뜻이며, "기존 값에 무언가를 적용해서 다시 저장한다"는 패턴을 짧게 표현한다.

## 관계 연산자

관계 연산자는 두 값을 비교해서 그 결과를 `bool` 값(`true` 또는 `false`)으로 돌려준다. 5장 제어문에서 조건을 판단할 때 바로 이 결과가 쓰인다.

```dart
void main() {
  int age = 20;

  print(age == 20); // true : 같다
  print(age != 20); // false: 다르다
  print(age > 18); // true : 크다
  print(age < 18); // false: 작다
  print(age >= 20); // true : 크거나 같다
  print(age <= 19); // false: 작거나 같다
}
```

주의할 점은 `==`가 숫자나 문자열처럼 값 자체를 비교할 때는 기대한 대로 동작하지만, 직접 만든 클래스의 인스턴스를 비교할 때는 별도의 설정이 없으면 "같은 객체를 가리키는가"만 확인한다는 것이다. 이 부분은 9장 클래스와 객체에서 `==` 연산자를 직접 재정의하는 방법과 함께 다시 설명한다.

## 논리 연산자

논리 연산자는 여러 개의 `bool` 값을 조합해서 하나의 `bool` 값을 만든다.

```dart
void main() {
  bool isAdult = true;
  bool hasTicket = false;

  print(isAdult && hasTicket); // false: 둘 다 참이어야 참
  print(isAdult || hasTicket); // true : 하나라도 참이면 참
  print(!isAdult); // false: 참/거짓을 뒤집음
}
```

`&&`(AND)는 두 조건이 모두 참일 때만 참이고, `||`(OR)는 둘 중 하나라도 참이면 참이다. `!`(NOT)는 뒤에 오는 값의 참/거짓을 뒤집는다. 이 세 연산자는 5장에서 조건문을 여러 개 엮을 때 반복해서 등장한다.

한 가지 유용한 특성은 `&&`와 `||`가 **단축 평가(short-circuit evaluation)**를 한다는 점이다. `a && b`에서 `a`가 이미 `false`라면 `b`는 평가할 필요조차 없으므로 곧바로 `false`가 되고, `b` 부분은 실행되지 않는다. 마찬가지로 `a || b`에서 `a`가 `true`면 `b`는 확인하지 않는다.

```dart
bool checkAndLog(bool value, String label) {
  print('$label 검사됨');
  return value;
}

void main() {
  // 앞쪽이 false이므로 뒤쪽은 검사되지 않는다 ("뒤쪽 검사됨"이 출력되지 않음)
  if (checkAndLog(false, '앞쪽') && checkAndLog(true, '뒤쪽')) {
    print('통과');
  }
}
```

이 성질은 뒤쪽 조건이 앞쪽 조건에 의존할 때 유용하다. 예를 들어 어떤 값이 null이 아닌지 먼저 확인하고, null이 아닐 때만 그 값의 속성을 살펴보는 식의 코드에서 자연스럽게 쓰인다.

## null과 관련된 연산자 살짝 엿보기

Dart는 null이 될 수 있는 값을 다루기 위한 전용 연산자를 몇 가지 제공한다. sound null safety의 본격적인 규칙은 8장에서 다루지만, 여기서는 표현식을 짧게 만들어주는 연산자로서 미리 접해보자.

### ?? — null 병합 연산자

`??`는 왼쪽 값이 `null`이 아니면 그 값을 그대로 쓰고, `null`이면 오른쪽 값을 대신 쓴다.

```dart
void main() {
  String? nickname; // 아직 값이 없음, null 상태
  String displayName = nickname ?? '익명';
  print(displayName); // 익명

  nickname = '토끼';
  print(nickname ?? '익명'); // 토끼
}
```

"이 값이 있으면 쓰고, 없으면 기본값을 쓴다"는 패턴을 한 줄로 표현할 수 있어서 매우 자주 쓰인다.

### ??= — null일 때만 대입

`??=`는 왼쪽 변수가 현재 `null`일 때만 오른쪽 값을 대입한다. 이미 값이 있다면 그대로 둔다.

```dart
void main() {
  String? nickname;
  nickname ??= '익명'; // nickname이 null이므로 대입됨
  print(nickname); // 익명

  nickname ??= '다른이름'; // 이미 값이 있으므로 대입되지 않음
  print(nickname); // 익명
}
```

"값이 없을 때만 기본값을 채워 넣는다"는 상황에 딱 맞는 연산자다.

### ?. — 조건부 멤버 접근

`?.`는 어떤 값이 `null`일 수도 있는 상황에서, 그 값이 `null`이 아닐 때만 뒤에 이어지는 멤버(속성이나 메서드)에 접근한다. 값이 `null`이면 예외를 던지는 대신 그냥 결과가 `null`이 된다.

```dart
void main() {
  String? name;
  print(name?.length); // null: name이 null이므로 length에 접근하지 않고 null을 반환
  print(name?.toUpperCase()); // null

  name = '다트';
  print(name?.length); // 2
}
```

`name.length`처럼 `?` 없이 바로 접근했다면 `name`이 `null`인 경우 프로그램이 예외를 던지며 멈췄을 것이다. `?.`는 이런 상황을 안전하게 피해가는 방법이다. `??`, `??=`, `?.`는 서로 자연스럽게 어울려 쓰이는 경우가 많다. 이 세 연산자를 포함해 null을 다루는 전체 그림은 8장에서 완성된다.

## 캐스케이드 연산자: ..

캐스케이드(cascade) 연산자 `..`는 Dart의 독특한 문법 중 하나로, 같은 객체에 대해 여러 메서드나 속성 설정을 연속으로 호출할 때 그 객체의 이름을 매번 반복해서 적지 않아도 되게 해준다.

다음과 같이 `StringBuffer`라는 문자열 조립용 객체를 다룬다고 해보자. 캐스케이드 없이 쓰면 매번 변수 이름을 반복해야 한다.

```dart
void main() {
  var buffer = StringBuffer();
  buffer.write('안녕, ');
  buffer.write('Dart');
  buffer.write('!');
  print(buffer.toString()); // 안녕, Dart!
}
```

캐스케이드를 쓰면 `buffer`를 한 번만 언급하고 나머지는 `..`으로 이어 붙일 수 있다.

```dart
void main() {
  var buffer = StringBuffer()
    ..write('안녕, ')
    ..write('Dart')
    ..write('!');
  print(buffer.toString()); // 안녕, Dart!
}
```

`..write(...)`는 "바로 앞의 결과가 아니라, 캐스케이드가 시작된 그 객체에 대해 이 메서드를 호출한다"는 뜻이다. 즉 세 번의 `write` 호출은 모두 같은 `buffer` 객체를 대상으로 한다. 일반적인 메서드 체이닝(예: `a.b().c()`)에서는 `b()`가 반환한 값에 `c()`를 호출하는 것이지만, 캐스케이드는 각 호출의 반환값을 무시하고 원래 객체 자신에게 계속 이어서 호출한다는 점이 다르다.

클래스 인스턴스를 만들고 여러 속성을 한꺼번에 설정할 때도 캐스케이드가 유용하다.

```dart
class Person {
  String name = '';
  int age = 0;

  void greet() {
    print('안녕하세요, $name입니다. $age살입니다.');
  }
}

void main() {
  var person = Person()
    ..name = '민지'
    ..age = 25
    ..greet();
}
```

`Person()`으로 인스턴스를 만든 뒤, `..name = '민지'`로 이름을 설정하고, `..age = 25`로 나이를 설정하고, `..greet()`으로 메서드까지 호출한다. 이 모든 동작이 하나의 표현식 안에서 같은 `person` 객체를 대상으로 이루어진다. 클래스와 인스턴스에 대한 자세한 내용은 9장에서 다루므로, 지금은 "캐스케이드는 같은 객체에 여러 동작을 연달아 적용할 때 코드를 깔끔하게 만들어주는 문법"이라는 정도로 이해하면 충분하다.

만약 캐스케이드 대상이 될 값이 `null`일 수 있다면, `?..`을 사용해서 값이 `null`이 아닐 때만 캐스케이드가 실행되도록 할 수 있다.

```dart
void main() {
  Person? maybePerson;
  maybePerson
    ?..name = '민지'
    ..age = 25;
  // maybePerson이 null이므로 아무 일도 일어나지 않는다
}
```

## 연산자 우선순위

지금까지 살펴본 연산자를 한 식 안에 섞어 쓰면, 어떤 연산자가 먼저 계산되는지가 결과를 결정한다. 예를 들어 `2 + 3 * 4`는 `*`가 `+`보다 먼저 계산되어 `20`이 아니라 `14`가 된다. 산술 연산자 안에서는 `*`, `/`, `~/`, `%`가 `+`, `-`보다 먼저 계산되고, 관계 연산자는 논리 연산자보다 먼저 계산되는 식으로 Dart도 대부분의 언어와 비슷한 우선순위 규칙을 따른다.

이런 우선순위를 전부 외울 필요는 없다. 계산 순서가 헷갈릴 때는 소괄호 `()`로 원하는 순서를 명확히 감싸주는 것이 가장 안전하고, 코드를 읽는 사람에게도 의도를 분명히 전달할 수 있다.

```dart
void main() {
  // 괄호로 순서를 명확히 표현
  print((2 + 3) * 4); // 20
  print(2 + (3 * 4)); // 14
}
```

Dart 연산자의 전체 우선순위 표는 부록에 정리해두었으니, 복잡한 식을 만나 순서가 궁금할 때 참고하면 된다.

## 요약

- 산술 연산자에는 `+`, `-`, `*`, `/`(항상 double 반환), `~/`(정수 나눗셈), `%`(나머지)가 있고, `++`/`--`는 전위와 후위에 따라 값을 사용하는 시점이 다르다.
- 관계 연산자(`==`, `!=`, `>`, `<`, `>=`, `<=`)는 비교 결과를 `bool`로 반환하며, 5장의 조건문에서 핵심적으로 쓰인다.
- 논리 연산자(`&&`, `||`, `!`)는 `bool` 값을 조합하며, `&&`와 `||`는 단축 평가로 불필요한 뒤쪽 평가를 건너뛴다.
- `??`(null 병합), `??=`(null일 때만 대입), `?.`(조건부 멤버 접근)는 null을 다루는 표현식을 짧게 만들어주며, 자세한 규칙은 8장에서 다룬다.
- 캐스케이드 연산자 `..`는 같은 객체에 대해 여러 메서드/속성 설정을 연달아 적용하는 Dart 고유의 문법이며, `?..`으로 null 안전하게 사용할 수도 있다.
- 연산자를 섞어 쓸 때 계산 순서가 헷갈리면 괄호로 명확히 감싸는 것이 안전하며, 전체 우선순위 표는 부록에서 확인할 수 있다.

## 연습문제

1. 정수 `29`를 `7`로 나눈 일반 나눗셈 결과, 정수 나눗셈(`~/`) 결과, 나머지(`%`) 결과를 각각 출력해보라.
2. `int x = 10;`으로 시작해서 `print(x++)`와 `print(++x)`를 각각 실행했을 때 출력되는 값이 왜 다른지 설명해보라.
3. 두 개의 `bool` 변수를 만들어 `&&`와 `||`의 단축 평가를 직접 관찰할 수 있는 예제를 작성해보라(힌트: 함수를 호출하면서 출력문을 넣어본다).
4. `String? city;` 변수에 대해 `??`를 사용해 값이 없을 때 `'알수없음'`을 출력하는 코드와, `??=`를 사용해 기본값을 채워 넣는 코드를 각각 작성해보라.
5. 이름(`name`)과 점수(`score`) 속성을 가진 간단한 클래스를 만들고, 캐스케이드 연산자로 인스턴스를 생성하면서 두 속성을 설정한 뒤 결과를 출력하는 메서드까지 한 번에 호출해보라.
