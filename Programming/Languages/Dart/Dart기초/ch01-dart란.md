# 1장. Dart란 무엇인가

## 들어가며

새로운 프로그래밍 언어를 배우기 전에 가장 먼저 던져야 할 질문은 "이 언어는 왜 만들어졌고, 어디에 강점이 있는가"이다. Dart는 2011년 구글이 발표한 언어로, 처음에는 웹 애플리케이션을 더 빠르고 안정적으로 만들기 위한 목적으로 설계되었다. 이후 언어와 도구 체인이 꾸준히 개선되면서, 지금은 모바일과 데스크톱, 웹을 아우르는 클라이언트 애플리케이션 개발용 언어로 자리잡았다. 이 장에서는 Dart가 어떤 특징을 가진 언어인지, 어디에 쓰이는지, 다른 언어와 비교했을 때 무엇이 다른지, 그리고 이 책을 학습하기 위해 무엇을 준비해야 하는지 살펴본다.

## Dart의 핵심 특징

### 정적 타입 언어

Dart는 정적 타입(static type) 언어다. 변수와 함수의 타입이 컴파일 시점에 결정되고 검사된다는 뜻이다. 예를 들어 다음 코드를 보자.

```dart
// 정수형 변수 age를 선언
int age = 30;

// age에 문자열을 대입하면 컴파일 오류가 발생한다
// age = "서른"; // 오류: 타입이 일치하지 않음
```

정적 타입 검사는 프로그램을 실행하기 전에 많은 실수를 잡아준다. 타입 오류는 실행 중에 갑자기 터지는 대신, 코드를 작성하는 시점이나 컴파일하는 시점에 미리 드러난다. 변수와 자료형에 대한 자세한 내용은 3장에서 다룬다.

동시에 Dart는 타입 추론(type inference)을 지원해서, 매번 타입을 명시하지 않아도 된다.

```dart
// var로 선언하면 대입된 값을 보고 타입을 추론한다
var name = "홍길동"; // String으로 추론됨
```

### sound null safety

Dart의 가장 중요한 특징 중 하나는 sound null safety(null 안전성)다. null 안전성이 적용된 Dart 코드에서는, 타입 시스템이 어떤 변수가 null이 될 수 있는지 없는지를 컴파일 시점에 명확히 구분한다.

```dart
// 이 변수는 null을 가질 수 없다
String name = "다트";

// 물음표를 붙이면 null을 허용하는 타입이 된다
String? nickname;
```

이 특성 덕분에 "null 값에 접근해서 발생하는 예외"라는, 여러 언어에서 골치를 앓게 하는 문제의 상당 부분을 컴파일 시점에 미리 막을 수 있다. null 안전성은 이 책 전체에서 반복해서 등장하는 개념이며, 8장에서 본격적으로 다룬다.

### 클라이언트 최적화 언어

Dart는 스스로를 "클라이언트 최적화(client-optimized) 언어"라고 소개한다. 이는 서버나 커맨드라인 도구를 만들 수 없다는 뜻이 아니라, 사용자와 직접 상호작용하는 화면, 즉 UI를 가진 애플리케이션을 빠르고 매끄럽게 만드는 데 특히 초점을 맞춰 설계되었다는 의미다. 이를 위해 Dart는 두 가지 실행 방식을 함께 지원한다.

- 개발 중에는 JIT(Just-In-Time) 컴파일로 코드를 빠르게 반복 실행하고, 코드를 수정하면 실행 중인 애플리케이션에 즉시 반영하는 핫 리로드(hot reload) 같은 기능을 지원한다.
- 배포할 때는 AOT(Ahead-Of-Time) 컴파일로 미리 네이티브 코드로 변환해서, 실행 속도가 빠르고 시작 시간이 짧은 결과물을 만든다.

이 두 실행 방식의 차이는 2장에서 직접 확인해 본다.

## Flutter와 Dart, 그리고 이 책의 초점

Dart를 언급할 때 빠지지 않고 함께 등장하는 이름이 바로 Flutter다. Flutter는 구글이 만든 UI 프레임워크로, Dart 언어 위에서 동작하며 하나의 코드베이스로 모바일(Android, iOS), 웹, 데스크톱(Windows, macOS, Linux) 애플리케이션을 만들 수 있게 해준다. 실제로 많은 개발자가 Dart라는 이름을 처음 접하는 계기는 Flutter다.

하지만 이 책은 Flutter 책이 아니다. Flutter는 Dart 위에 얹힌 프레임워크일 뿐이고, 그 프레임워크를 제대로 다루기 위해서는 먼저 Dart 언어 자체를 튼튼하게 이해하고 있어야 한다. 변수와 자료형, 제어문과 반복문, 함수, 클래스와 상속, 제네릭, 비동기 프로그래밍 같은 개념은 Flutter뿐 아니라 서버 프로그램이나 커맨드라인 도구를 작성할 때도 똑같이 필요하다. 그래서 이 책은 처음부터 끝까지 Dart 언어 자체에 집중하고, Flutter의 위젯이나 UI 구성 요소는 다루지 않는다. 이 책을 마친 뒤에 Flutter를 배우면, 위젯의 문법이 아니라 그 뒤에 숨은 언어의 동작 원리를 이해하면서 훨씬 수월하게 진행할 수 있을 것이다.

## Dart는 어디에 쓰이는가

Dart는 애초에 클라이언트 애플리케이션을 겨냥해 설계되었기 때문에, 활용 분야도 그 방향으로 넓게 퍼져 있다.

- **모바일 앱**: Flutter를 통해 Android와 iOS 네이티브 앱을 하나의 코드로 만든다.
- **웹 앱**: Dart 코드를 JavaScript로 컴파일하거나(웹 컴파일러), Flutter Web을 통해 브라우저에서 실행되는 앱을 만든다.
- **데스크톱 앱**: Flutter Desktop을 통해 Windows, macOS, Linux용 앱을 빌드한다.
- **서버 및 커맨드라인 도구**: Dart SDK만으로도 커맨드라인 프로그램이나 간단한 서버를 작성할 수 있다. 실제로 이 책에서 작성하는 모든 예제는 별도의 프레임워크 없이 Dart SDK만으로 실행된다.

## 다른 언어와의 비교

Dart를 처음 접하는 사람은 대체로 Java나 JavaScript 경험이 있는 경우가 많다. 간단히 비교해보면 Dart의 위치를 가늠하기 쉽다.

Java와 비교하면, Dart는 문법이 훨씬 간결하다. 세미콜론으로 문장을 끝내고 중괄호로 블록을 감싸는 기본 골격은 비슷하지만, Dart는 `var`를 통한 타입 추론, 간결한 화살표 함수(`=>`) 문법, 문자열 안에 변수를 바로 삽입하는 문자열 보간(string interpolation) 등을 지원해서 같은 내용을 더 짧게 표현할 수 있다. 또한 Java는 참조형에 대해 기본적으로 null을 허용하지만, Dart는 sound null safety를 통해 이를 원천적으로 제어한다.

JavaScript와 비교하면, 가장 큰 차이는 타입 시스템이다. JavaScript는 동적 타입 언어라서 변수의 타입이 실행 중에 자유롭게 바뀔 수 있지만, Dart는 정적 타입 언어라서 컴파일 시점에 타입이 고정되고 검사된다. 문법적으로는 JavaScript(특히 최신 문법인 ES6 이후)와 닮은 부분이 많아서, JavaScript에 익숙한 사람은 Dart의 문법을 비교적 빠르게 받아들이는 편이다.

정리하면, Dart는 "Java만큼 안전하고 구조적이면서, JavaScript만큼 간결하고 유연한" 지점을 지향하는 언어라고 볼 수 있다.

## 개발 환경 준비하기

이 책의 예제를 직접 실행해보려면 Dart SDK가 필요하다. Dart SDK는 공식 웹사이트(dart.dev)에서 운영체제에 맞는 설치 방법을 안내한다. Windows에서는 다음과 같은 방법으로 설치할 수 있다.

- Chocolatey 같은 패키지 관리자를 사용하는 방법
- 공식 사이트에서 SDK 압축 파일을 내려받아 압축을 풀고 환경 변수 `PATH`에 경로를 등록하는 방법

설치가 끝나면 터미널에서 버전을 확인해 정상적으로 설치되었는지 검증한다.

```
dart --version
```

버전 정보가 출력되면 준비가 끝난 것이다. 코드 편집기는 Visual Studio Code에 Dart 확장을 설치해서 사용하는 방법을 추천하는데, 문법 강조와 자동 완성, 오류 표시를 지원해서 학습 초반에 큰 도움이 된다. 물론 어떤 텍스트 에디터를 쓰든 `dart` 명령어만 있으면 이 책의 모든 예제를 따라 할 수 있다.

## 이 책의 학습 방향

이 책은 총 18개 장으로 구성되어 있으며, 크게 세 흐름으로 나눌 수 있다. 먼저 2장부터 8장까지는 변수, 연산자, 제어문, 반복문, 함수, null 안전성처럼 어떤 언어를 배우든 반드시 통과해야 하는 기초 문법을 다룬다. 이어서 9장부터 14장까지는 클래스와 객체, 상속과 믹스인, 인터페이스와 추상 클래스, 제네릭, 컬렉션, 확장 메서드 등 Dart의 객체지향적 특징과 타입 시스템을 깊이 있게 살핀다. 마지막으로 15장부터 18장까지는 퓨처와 async/await, 스트림 같은 비동기 프로그래밍, 그리고 패키지 생태계와 좋은 코드 작성 습관을 다루며 실전 감각을 키운다.

각 장은 이전 장에서 배운 내용을 바탕으로 이어지므로, 순서대로 읽고 직접 코드를 실행해보는 것을 권장한다. 특히 2장에서는 여러분이 작성한 첫 Dart 프로그램이 실제로 어떻게 실행되는지, 그 과정을 구체적으로 살펴본다.

## 요약

- Dart는 구글이 만든 정적 타입 언어로, sound null safety를 통해 null로 인한 오류를 컴파일 시점에 방지한다.
- Dart는 클라이언트 최적화 언어로서, 개발 중에는 JIT 컴파일로 빠르게 반복하고 배포 시에는 AOT 컴파일로 네이티브 성능을 낸다.
- Flutter는 Dart 위에서 동작하는 UI 프레임워크이지만, 이 책은 Flutter가 아니라 Dart 언어 자체에 집중한다.
- Dart는 모바일, 웹, 데스크톱 앱은 물론 커맨드라인 도구와 서버 프로그램 작성에도 쓰인다.
- Java보다 간결하고, JavaScript보다 타입 안전성이 높은 지점을 지향하는 언어다.
- 학습을 시작하려면 Dart SDK를 설치하고 `dart --version`으로 설치를 확인한다.

## 연습문제

1. sound null safety가 무엇을 의미하는지, 그리고 이것이 왜 프로그램의 안정성에 도움이 되는지 자신의 언어로 설명해보라.
2. JIT 컴파일과 AOT 컴파일의 차이를 설명하고, 각각이 어떤 상황에 더 적합한지 생각해보라.
3. Dart와 Flutter의 관계를 한 문장으로 정리해보라.
4. 자신이 알고 있는 다른 언어(Java, JavaScript, Python 등) 하나를 골라, Dart와의 공통점과 차이점을 각각 두 가지씩 적어보라.
5. 자신의 컴퓨터에 Dart SDK를 설치하고 `dart --version` 명령을 실행해 결과를 확인해보라.
