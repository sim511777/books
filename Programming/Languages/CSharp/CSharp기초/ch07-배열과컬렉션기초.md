# 7장. 배열과 컬렉션 기초

지금까지 우리는 `int`, `double`, `string` 같은 변수 하나에 값 하나를 담아 다뤘습니다. 하지만 실제 프로그램에서는 "학생 30명의 점수", "장바구니에 담긴 상품 목록"처럼 여러 개의 값을 한꺼번에 다뤄야 하는 경우가 훨씬 많습니다. 이번 장에서는 여러 값을 하나의 변수처럼 묶어서 다루는 가장 기본적인 두 가지 도구, 배열(Array)과 `List<T>`를 살펴봅니다.

## 배열이란 무엇인가

배열은 같은 자료형의 값을 여러 개 나란히 저장하는 자료구조입니다. 각 값은 고유한 번호(인덱스, Index)를 가지며, 이 번호를 이용해 원하는 값에 바로 접근할 수 있습니다. C#에서 배열의 인덱스는 항상 0부터 시작합니다.

```csharp
// int형 값 5개를 담을 수 있는 배열 선언
int[] scores = new int[5];

scores[0] = 90;
scores[1] = 85;
scores[2] = 77;
scores[3] = 92;
scores[4] = 68;

Console.WriteLine(scores[2]); // 77
```

`new int[5]`는 "int형 값을 5개 담을 수 있는 상자를 만들어라"는 뜻입니다. 이렇게 만들어진 배열의 각 요소는 자료형의 기본값(정수는 0, `bool`은 `false`, 참조형은 `null`)으로 초기화됩니다.

값을 이미 알고 있다면 선언과 동시에 초기화할 수도 있습니다.

```csharp
int[] scores = { 90, 85, 77, 92, 68 };
string[] fruits = new string[] { "사과", "바나나", "포도" };

// 배열 크기는 대괄호 안에 넣지 않고, 원소 개수로 자동 결정된다
Console.WriteLine(fruits.Length); // 3
```

배열의 전체 크기는 `Length` 속성으로 확인합니다. 배열은 인덱스가 0부터 `Length - 1`까지라는 점을 항상 기억해야 합니다. 그 범위를 벗어난 인덱스에 접근하면 `IndexOutOfRangeException`이 발생하며 프로그램이 종료됩니다.

```csharp
int[] numbers = { 1, 2, 3 };
Console.WriteLine(numbers[3]); // 실행 시점 오류: 인덱스 0, 1, 2만 유효
```

배열 전체를 순회할 때는 `for`문이나 `foreach`문을 씁니다. 6장에서 배운 반복문이 여기서 본격적으로 쓰이는 셈입니다.

```csharp
int[] scores = { 90, 85, 77, 92, 68 };

for (int i = 0; i < scores.Length; i++)
{
    Console.WriteLine($"{i}번째 점수: {scores[i]}");
}

// 인덱스가 필요 없다면 foreach가 더 간결하다
foreach (int score in scores)
{
    Console.WriteLine(score);
}
```

`foreach`는 인덱스를 신경 쓸 필요가 없어 편리하지만, 순회 중에 요소의 값을 바꾸는 용도로는 쓸 수 없습니다. 값을 수정해야 한다면 인덱스 기반의 `for`문을 사용해야 합니다.

## 다차원 배열 간단히 살펴보기

지금까지 다룬 배열은 값이 한 줄로 늘어선 1차원 배열입니다. 표나 격자처럼 행과 열이 있는 데이터를 표현할 때는 2차원 배열을 사용합니다.

```csharp
// 3행 2열짜리 2차원 배열
int[,] grid = new int[3, 2];

grid[0, 0] = 1;
grid[0, 1] = 2;
grid[1, 0] = 3;
grid[1, 1] = 4;
grid[2, 0] = 5;
grid[2, 1] = 6;

for (int row = 0; row < 3; row++)
{
    for (int col = 0; col < 2; col++)
    {
        Console.Write($"{grid[row, col]} ");
    }
    Console.WriteLine();
}
```

콤마(`,`)로 차원을 구분한다는 점이 핵심입니다. 실무에서는 3차원 이상의 배열을 쓸 일이 드물고, 대부분 2차원까지만 사용합니다. 지금 단계에서는 "행과 열로 구성된 데이터도 배열로 표현할 수 있다"는 정도만 기억해 두면 충분합니다.

## 배열의 한계: 고정된 크기

배열은 한번 크기를 정하면 그 크기를 바꿀 수 없습니다. 예를 들어 처음에 5명분의 점수를 담을 배열을 만들었는데, 나중에 학생이 3명 더 들어왔다고 해서 배열을 늘릴 수는 없습니다.

```csharp
int[] scores = new int[5];
// scores에 6번째 값을 추가하고 싶다면?
// scores[5] = 100; // 오류! 인덱스 범위를 벗어남
```

이럴 때 흔히 쓰는 방법은 더 큰 배열을 새로 만들고 기존 값을 복사하는 것입니다.

```csharp
int[] oldScores = { 90, 85, 77, 92, 68 };
int[] newScores = new int[oldScores.Length + 1];

Array.Copy(oldScores, newScores, oldScores.Length);
newScores[oldScores.Length] = 100;
```

동작은 하지만, 값을 추가할 때마다 이런 코드를 반복해서 작성하는 것은 번거롭고 실수하기도 쉽습니다. "크기가 미리 정해지지 않은, 늘었다 줄었다 하는 목록"이 필요할 때는 배열보다 더 편리한 도구가 있습니다. 바로 `List<T>`입니다.

## List&lt;T&gt;로 동적 컬렉션 다루기

`List<T>`는 배열과 비슷하게 같은 자료형의 값을 여러 개 담지만, 필요할 때마다 크기가 자동으로 늘어나거나 줄어듭니다. `T`는 담을 자료형을 나타내는 자리로, 이런 형태를 제네릭(Generic)이라고 부르며 13장에서 자세히 다룹니다. 지금은 `List<int>`는 정수를 담는 리스트, `List<string>`은 문자열을 담는 리스트라고만 이해해도 충분합니다.

```csharp
using System.Collections.Generic;

List<int> scores = new List<int>();

scores.Add(90);
scores.Add(85);
scores.Add(77);

Console.WriteLine(scores.Count); // 3 (배열의 Length와 같은 역할)
Console.WriteLine(scores[1]);    // 85, 인덱스 접근은 배열과 동일
```

`List<T>`도 초기값을 넣어 바로 만들 수 있습니다.

```csharp
List<string> fruits = new List<string> { "사과", "바나나", "포도" };
```

배열과 달리 `List<T>`는 요소를 추가하고 제거하는 메서드를 제공합니다.

```csharp
List<string> cart = new List<string>();

cart.Add("키보드");
cart.Add("마우스");
cart.Add("모니터");

cart.Remove("마우스");      // 값으로 제거
cart.RemoveAt(0);           // 인덱스로 제거

foreach (string item in cart)
{
    Console.WriteLine(item);
}

Console.WriteLine($"남은 상품 수: {cart.Count}");
```

`Add`는 리스트 끝에 값을 추가하고, `Remove`는 지정한 값을 처음 발견한 위치에서 제거하며, `RemoveAt`은 인덱스로 지정한 위치의 값을 제거합니다. 배열의 `Length`에 해당하는 것이 `List<T>`에서는 `Count` 속성입니다.

값이 리스트에 들어 있는지 확인하려면 `Contains`를, 특정 값의 위치를 찾으려면 `IndexOf`를 사용합니다.

```csharp
List<int> numbers = new List<int> { 10, 20, 30 };

if (numbers.Contains(20))
{
    Console.WriteLine("20이 리스트에 있습니다.");
}

int index = numbers.IndexOf(30);
Console.WriteLine($"30의 위치: {index}"); // 2
```

## 배열과 List&lt;T&gt;, 무엇을 언제 쓸까

두 자료구조를 언제 골라야 할지 고민된다면 다음 기준을 참고하면 됩니다.

- 크기가 프로그램 실행 중에 절대 바뀌지 않는다는 것이 확실하다면 배열이 더 가볍고 성능상 유리합니다. 예를 들어 "요일 이름 7개"처럼 개수가 고정된 데이터가 그렇습니다.
- 값을 추가하거나 제거하는 일이 자주 일어난다면 `List<T>`가 훨씬 편리합니다. 실무 코드에서는 배열보다 `List<T>`를 쓰는 경우가 압도적으로 많습니다.
- 배열은 `int[] arr`처럼 표기가 간단하고, `List<T>`는 `Add`, `Remove`, `Contains`처럼 풍부한 메서드를 함께 제공한다는 점도 차이입니다.

두 자료구조는 서로 변환할 수도 있습니다.

```csharp
int[] array = { 1, 2, 3 };
List<int> list = new List<int>(array); // 배열 -> 리스트
int[] backToArray = list.ToArray();    // 리스트 -> 배열
```

## 요약

- 배열은 같은 자료형의 값을 고정된 개수만큼 담는 자료구조이며, 인덱스는 0부터 시작한다.
- 배열의 크기는 `new T[개수]`로 정하며, 한번 정해지면 바꿀 수 없다. `Length` 속성으로 크기를 확인한다.
- 2차원 배열은 `T[,] arr = new T[행, 열]` 형태로 선언하며, 표 형태의 데이터를 표현할 때 사용한다.
- `List<T>`는 크기가 자동으로 늘어나고 줄어드는 컬렉션으로, `Add`, `Remove`, `RemoveAt`, `Contains` 등의 메서드와 `Count` 속성을 제공한다.
- 크기가 고정된 데이터는 배열, 자주 변하는 목록은 `List<T>`가 적합하다.
- `List<T>`의 `T`는 제네릭이라는 개념이며, 13장에서 더 자세히 다룬다. 다양한 컬렉션 종류와 데이터를 다루는 강력한 도구인 LINQ는 14장에서 본격적으로 배운다.

2. 문자열 배열에 담긴 이름 목록을 `foreach`문으로 순회하며, 각 이름의 길이(`Length`)를 함께 출력하시오.
3. 빈 `List<int>`를 만들고 1부터 10까지의 짝수를 `Add`로 추가한 뒤, `Count`와 모든 원소를 출력하시오.
4. `List<string>`에 담긴 장바구니 목록에서 특정 상품을 `Remove`로 제거하고, 제거 전후의 `Count`를 비교해 출력하시오.
5. 3행 3열의 2차원 배열을 만들어 1부터 9까지의 값을 채우고, 이중 `for`문으로 표 형태로 출력하시오.
