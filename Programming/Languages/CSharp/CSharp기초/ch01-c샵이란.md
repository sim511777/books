# 1장. C#이란 무엇인가

[◀ 이전: 목차](00-목차.md) | [📖 목차](00-목차.md) | [다음: 2장. 첫 프로그램과 빌드 과정 ▶](ch02-첫프로그램과빌드과정.md)

---

프로그래밍을 처음 배우든, 이미 다른 언어를 다뤄본 경험이 있든, 새로운 언어를 시작할 때 가장 먼저 던져야 할 질문은 "이 언어는 어떤 문제를 풀기 위해 만들어졌는가"입니다. C#(발음은 "씨샵")은 2000년 마이크로소프트가 .NET 플랫폼과 함께 내놓은 언어로, 지금은 웹 서버부터 게임, 모바일 앱, 클라우드 서비스까지 폭넓게 쓰이는 범용 언어로 자리 잡았습니다. 이 장에서는 C#이 어떤 성격의 언어인지, 어디에 쓰이는지, 그리고 이 책을 읽어나가기 위해 어떤 준비가 필요한지를 정리합니다.

## .NET 위에서 동작하는 언어

C#은 혼자 존재하는 언어가 아닙니다. C# 코드는 컴파일러를 통해 IL(중간 언어, Intermediate Language)이라는 형태로 변환되고, 이 IL을 .NET 런타임이 실행합니다. 이 실행 구조에 대해서는 2장에서 그림과 함께 자세히 다루지만, 지금 단계에서 기억할 점은 하나입니다. C# 언어 자체는 문법과 규칙의 집합일 뿐이고, 실제로 프로그램을 돌리는 것은 .NET이라는 플랫폼이라는 것입니다.

이 구조 덕분에 C#은 여러 운영체제에서 동작합니다. 예전에는 .NET이 Windows에서만 돌아갔지만, 지금의 .NET(과거 .NET Core라고 불렸던 버전 계열)은 Windows, macOS, Linux를 모두 지원합니다. 즉 맥이나 리눅스를 쓰는 개발자도 아무 문제 없이 C#으로 개발할 수 있습니다.

## 정적 타입, 객체지향, 그리고 함수형 요소

C#의 성격을 세 가지 키워드로 요약하면 다음과 같습니다.

**정적 타입 언어**라는 점이 첫 번째입니다. 변수를 선언할 때 그 변수가 담을 값의 자료형이 컴파일 시점에 정해집니다. 자료형이 맞지 않는 값을 넣으려 하면 프로그램을 실행하기도 전에 컴파일러가 오류를 잡아냅니다. 이는 Python이나 JavaScript처럼 실행 중에 타입이 결정되는 동적 타입 언어와 대조되는 특징입니다. 정적 타입은 초반에 코드를 조금 더 엄격하게 쓰게 만들지만, 그 대가로 실수를 일찍 발견하고 큰 프로그램에서도 어떤 함수가 어떤 타입을 주고받는지 명확히 알 수 있다는 이점을 줍니다.

**객체지향 언어**라는 점이 두 번째입니다. C#의 모든 코드는 클래스(class) 안에 존재합니다. 데이터와 그 데이터를 다루는 동작을 객체(object)라는 단위로 묶어서 설계하는 방식이며, 이 책의 9장 클래스와 객체, 10장 상속과 다형성에서 본격적으로 다룰 핵심 주제입니다.

**함수형 요소가 꾸준히 도입되고 있다**는 점이 세 번째입니다. C#은 원래 순수한 객체지향 언어로 시작했지만, 버전이 올라가면서 람다 식, LINQ(데이터를 함수형 스타일로 조회하는 기능), 패턴 매칭, 레코드 타입처럼 함수형 언어의 아이디어를 적극적으로 받아들였습니다. 이런 기능들은 14장 컬렉션과 LINQ에서 자세히 만나게 됩니다. 즉 C#은 하나의 패러다임에 고정되지 않고, 실용적으로 여러 스타일을 섞어 쓸 수 있는 언어로 진화해 왔습니다.

## C#은 어디에 쓰이는가

C#의 활용 범위는 생각보다 넓습니다.

- **웹 백엔드**: ASP.NET Core를 사용하면 웹 API 서버나 웹 애플리케이션을 C#으로 만들 수 있습니다. 대규모 서비스의 백엔드로도 널리 쓰이며, 성능과 생산성 면에서 꾸준히 평가받는 조합입니다.
- **게임 개발**: Unity 엔진의 스크립팅 언어가 C#입니다. 모바일 게임부터 콘솔, PC 게임까지 Unity로 만들어진 수많은 게임의 게임 로직이 C#으로 작성되어 있습니다.
- **데스크톱 애플리케이션**: WPF, WinForms, 최근에는 MAUI 같은 프레임워크로 Windows용 데스크톱 프로그램을, MAUI를 통해 크로스플랫폼 앱도 만들 수 있습니다.
- **클라우드와 서버 인프라**: Azure를 비롯한 클라우드 환경에서 C#/.NET은 1급 시민으로 지원되며, 마이크로서비스, 서버리스 함수 등에도 널리 쓰입니다.

이렇게 여러 분야에서 쓰이다 보니 "C#을 배우면 어디에 쓸 수 있나요?"라는 질문에는 "거의 모든 곳"이라고 답할 수 있을 정도입니다.

## 다른 언어와 비교해보기

이미 다른 언어를 접해본 독자라면 비교를 통해 감을 잡는 것이 빠릅니다.

**Java와 비교**하면 C#은 태생부터 Java와 매우 닮아 있습니다. 둘 다 정적 타입 객체지향 언어이고, 소스 코드를 중간 언어로 컴파일한 뒤 런타임이 이를 실행하는 구조를 취합니다. Java는 JVM과 바이트코드를, C#은 .NET 런타임과 IL을 사용한다는 점만 다를 뿐 개념적으로는 거의 같습니다. Java 문법에 익숙하다면 C#의 클래스 선언, 메서드 정의, 예외 처리 문법 대부분이 낯설지 않게 느껴질 것입니다. 다만 C#은 속성(property), 델리게이트(delegate), LINQ처럼 Java에는 없거나 늦게 추가된 문법적 편의 기능을 다수 갖추고 있습니다.

**Python과 비교**하면 차이가 더 두드러집니다. Python은 동적 타입 언어이고 들여쓰기로 코드 블록을 구분하지만, C#은 정적 타입이며 중괄호 `{}`로 블록을 구분하고 문장 끝에 세미콜론 `;`을 붙입니다. Python으로 먼저 프로그래밍을 배운 독자라면 처음에는 "타입을 왜 이렇게 꼼꼼히 적어야 하나" 싶을 수 있지만, 프로그램이 커질수록 정적 타입의 장점을 체감하게 됩니다. 반대로 변수 하나를 선언하는 데도 자료형을 명시해야 하는 것이 번거롭게 느껴질 수 있는데, 이 책의 3장 변수와 자료형에서 다룰 `var` 키워드를 사용하면 타입 추론을 통해 그 번거로움을 상당 부분 줄일 수 있습니다.

## 개발 환경 준비하기

C# 코드를 작성하고 실행하려면 두 가지가 필요합니다.

**첫째, .NET SDK입니다.** SDK는 Software Development Kit의 줄임말로, C# 컴파일러와 `dotnet` 명령줄 도구, 그리고 프로그램 실행에 필요한 런타임을 포함한 도구 모음입니다. .NET 공식 웹사이트에서 현재 장기 지원(LTS) 버전을 내려받아 설치하면 됩니다. 설치가 끝나면 터미널(명령 프롬프트나 PowerShell)에서 다음 명령으로 설치가 잘 되었는지 확인할 수 있습니다.

```csharp
// 터미널에 입력하는 명령이며, C# 코드는 아닙니다.
// dotnet --version
```

**둘째, 코드를 작성할 도구, 즉 IDE나 에디터입니다.** 대표적인 선택지는 다음과 같습니다.

- **Visual Studio**: 마이크로소프트가 만든 통합 개발 환경으로, C#/.NET 개발에 가장 기능이 풍부합니다. Windows에서 주로 사용되며 무료로 쓸 수 있는 Community 버전이 있습니다.
- **Visual Studio Code**: 가볍고 빠른 에디터로, C# 확장 기능을 설치하면 자동 완성, 디버깅 등을 지원합니다. Windows, macOS, Linux 어디서나 동일하게 쓸 수 있습니다.
- **JetBrains Rider**: 유료 IDE지만 다른 JetBrains 제품(IntelliJ 등)에 익숙한 개발자에게 인기가 많습니다.

이 책의 예제는 어떤 도구를 쓰든 동일하게 동작하도록 표준 C# 문법과 `dotnet` 명령줄 도구를 기준으로 설명합니다. 어떤 IDE를 선택하든 상관없으니, 평소 익숙한 에디터가 있다면 그것을 그대로 사용해도 됩니다.

## 이 책을 읽어나가는 방향

이 책은 총 18개 장으로 구성되어 있으며, 크게 세 단계로 나눌 수 있습니다. 1장부터 6장까지는 변수, 연산자, 제어문, 반복문처럼 프로그래밍의 가장 기본이 되는 문법을 다룹니다. 7장부터 12장까지는 배열, 메서드, 클래스, 상속처럼 C#을 객체지향적으로 사용하는 방법을 다룹니다. 13장부터 18장까지는 제네릭, LINQ, 예외 처리, 델리게이트와 이벤트, 비동기 프로그래밍처럼 실무에서 자주 마주치는 조금 더 고급스러운 주제와 좋은 코드를 쓰는 습관을 다룹니다.

프로그래밍을 처음 접하는 독자는 순서대로 차근차근 따라가면서 직접 코드를 입력하고 실행해보는 것을 권합니다. 다른 언어 경험이 있는 독자는 앞부분을 빠르게 훑고 C# 고유의 문법(속성, 델리게이트, LINQ 등)에 조금 더 시간을 투자하는 것이 효율적입니다. 어느 쪽이든 코드를 눈으로만 읽지 말고 반드시 직접 타이핑해서 실행해보길 바랍니다. 다음 장에서는 바로 그 첫걸음, 즉 첫 C# 프로그램을 작성하고 실행하는 과정을 다룹니다.

## 요약

- C#은 마이크로소프트가 만든 정적 타입 객체지향 언어로, .NET 플랫폼 위에서 동작합니다.
- C# 코드는 컴파일되어 IL(중간 언어)로 변환된 뒤 .NET 런타임이 이를 실행합니다.
- C#은 객체지향을 기본으로 하지만 람다 식, LINQ 등 함수형 요소도 적극적으로 받아들이고 있습니다.
- 웹 백엔드(ASP.NET Core), 게임(Unity), 데스크톱(WPF/MAUI), 클라우드 등 활용 분야가 매우 넓습니다.
- Java와는 구조적으로 유사하고, Python과는 정적 타입 여부와 블록 구분 방식에서 큰 차이가 있습니다.
- 개발을 시작하려면 .NET SDK와 코드 에디터(Visual Studio, VS Code, Rider 등) 중 하나가 필요합니다.

## 연습문제

1. .NET 공식 웹사이트에서 현재 제공되는 .NET SDK의 최신 LTS(장기 지원) 버전이 몇 버전인지 확인해보세요.
2. 자신의 컴퓨터에 .NET SDK를 설치한 뒤, 터미널에서 `dotnet --version` 명령을 실행해 설치된 버전을 확인해보세요.
3. C#이 정적 타입 언어라는 것과 Python이 동적 타입 언어라는 것의 차이를, 자신이 이해한 말로 3줄 이내로 설명해보세요.
4. ASP.NET Core, Unity, WPF/MAUI 중 하나를 골라 인터넷에서 간단히 검색해보고, 그 기술이 어떤 종류의 프로그램을 만드는 데 쓰이는지 한 문단으로 정리해보세요.
5. 자신이 사용할 코드 에디터(Visual Studio, VS Code, Rider 중 하나)를 정하고 설치해보세요. 어떤 것을 선택했는지, 그 이유는 무엇인지 적어보세요.
