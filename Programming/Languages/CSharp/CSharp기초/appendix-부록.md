본문에서 다룬 내용 중 실무에서 자주 찾아보게 되는 것들을 표와 목록 형태로 모아둔 참고 자료입니다. 새로운 개념을 설명하는 장이 아니므로, 코드를 작성하다가 "이 메서드 이름이 뭐였지", "우선순위가 어떻게 되지" 싶을 때 펼쳐보는 용도로 사용하면 됩니다.

## 1. 자주 쓰는 타입/메서드 치트시트

### string

| 멤버 | 설명 | 예시 |
|---|---|---|
| `Length` | 문자열 길이(속성) | `"hello".Length` → `5` |
| `Substring(start, length)` | 부분 문자열 추출 | `"hello".Substring(1, 3)` → `"ell"` |
| `IndexOf(value)` | 값이 처음 나오는 위치, 없으면 -1 | `"hello".IndexOf("l")` → `2` |
| `Contains(value)` | 포함 여부 | `"hello".Contains("ell")` → `true` |
| `StartsWith(value)` / `EndsWith(value)` | 시작/끝 일치 여부 | `"hello".StartsWith("he")` → `true` |
| `Replace(old, new)` | 문자열 치환 | `"hello".Replace("l", "L")` → `"heLLo"` |
| `Trim()` / `TrimStart()` / `TrimEnd()` | 앞뒤 공백(또는 지정 문자) 제거 | `"  hi  ".Trim()` → `"hi"` |
| `ToUpper()` / `ToLower()` | 대소문자 변환 | `"Hi".ToUpper()` → `"HI"` |
| `Split(구분자)` | 구분자로 나눈 배열 | `"a,b,c".Split(',')` → `["a","b","c"]` |
| `string.Join(구분자, 목록)` | 배열/컬렉션을 하나의 문자열로 결합 | `string.Join(", ", list)` |
| `string.IsNullOrEmpty(s)` | null이거나 빈 문자열인지 검사 | `string.IsNullOrEmpty("")` → `true` |
| `string.IsNullOrWhiteSpace(s)` | null, 빈 문자열, 공백만인지 검사 | `string.IsNullOrWhiteSpace("  ")` → `true` |
| `$"{a} + {b}"` | 문자열 보간(interpolation) | `$"합계: {total}"` |
| `string.Format(형식, 값)` | 형식 문자열로 조합 | `string.Format("{0}살", age)` |

### Math

| 멤버 | 설명 | 예시 |
|---|---|---|
| `Math.Abs(x)` | 절댓값 | `Math.Abs(-5)` → `5` |
| `Math.Pow(x, y)` | 거듭제곱 | `Math.Pow(2, 10)` → `1024` |
| `Math.Sqrt(x)` | 제곱근 | `Math.Sqrt(9)` → `3` |
| `Math.Max(a, b)` / `Math.Min(a, b)` | 두 값 중 최대/최소 | `Math.Max(3, 7)` → `7` |
| `Math.Round(x)` | 가장 가까운 정수로 반올림 | `Math.Round(3.6)` → `4` |
| `Math.Floor(x)` / `Math.Ceiling(x)` | 내림 / 올림 | `Math.Floor(3.6)` → `3` |
| `Math.PI` | 원주율 상수 | `3.14159...` |

### Console

| 멤버 | 설명 |
|---|---|
| `Console.WriteLine(값)` | 줄바꿈을 포함해 출력 |
| `Console.Write(값)` | 줄바꿈 없이 출력 |
| `Console.ReadLine()` | 한 줄의 입력을 문자열로 읽기 |
| `Console.ReadKey()` | 키 하나를 누를 때까지 대기 |
| `Console.ForegroundColor` / `Console.BackgroundColor` | 콘솔 글자/배경 색 지정 |
| `Console.Clear()` | 콘솔 화면 지우기 |

## 2. LINQ 메서드 요약표 (14장 총정리)

14장에서 다룬 LINQ 메서드 중 실무에서 가장 자주 쓰이는 것들을 모았습니다. 아래 예시는 모두 `List<int> numbers = new List<int> { 3, 1, 4, 1, 5, 9 };`를 기준으로 합니다.

| 메서드 | 역할 | 예시 |
|---|---|---|
| `Where(조건)` | 조건을 만족하는 요소만 걸러냄 | `numbers.Where(n => n > 3)` |
| `Select(변환)` | 각 요소를 다른 값으로 변환 | `numbers.Select(n => n * 2)` |
| `OrderBy(기준)` / `OrderByDescending(기준)` | 오름차순/내림차순 정렬 | `numbers.OrderBy(n => n)` |
| `GroupBy(기준)` | 기준값에 따라 그룹으로 묶기 | `numbers.GroupBy(n => n % 2)` |
| `Sum()` / `Sum(변환)` | 합계 | `numbers.Sum()` → `23` |
| `Average()` | 평균 | `numbers.Average()` |
| `Max()` / `Min()` | 최댓값/최솟값 | `numbers.Max()` → `9` |
| `Count()` / `Count(조건)` | 개수 | `numbers.Count(n => n > 3)` → `2` |
| `Any(조건)` | 조건을 만족하는 요소가 하나라도 있는지 | `numbers.Any(n => n > 8)` → `true` |
| `All(조건)` | 모든 요소가 조건을 만족하는지 | `numbers.All(n => n > 0)` → `true` |
| `First()` / `FirstOrDefault()` | 첫 요소(없으면 예외/기본값) | `numbers.FirstOrDefault(n => n > 100)` → `0` |
| `Single()` / `SingleOrDefault()` | 조건을 만족하는 요소가 정확히 하나일 때 그 값 | `numbers.SingleOrDefault(n => n == 9)` |
| `Distinct()` | 중복 제거 | `numbers.Distinct()` → `3,1,4,5,9` |
| `Take(n)` / `Skip(n)` | 앞에서 n개 취하기 / n개 건너뛰기 | `numbers.Take(2)` → `3,1` |
| `ToList()` / `ToArray()` | 결과를 `List<T>`/배열로 변환 | `numbers.Where(n => n > 3).ToList()` |
| `Contains(값)` | 특정 값 포함 여부 | `numbers.Contains(4)` → `true` |

메서드 여러 개를 이어서(체이닝) 사용하면 "필터링 → 변환 → 정렬"처럼 여러 단계를 한 문장으로 표현할 수 있습니다.

```csharp
var result = numbers
    .Where(n => n > 1)
    .OrderByDescending(n => n)
    .Select(n => n * 10)
    .ToList();
```

## 3. 연산자 우선순위표 (4장 총정리)

숫자가 작을수록(표에서 위쪽일수록) 먼저 계산됩니다. 같은 우선순위의 연산자가 여러 번 나오면 대부분 왼쪽에서 오른쪽 순서로 계산되며, 대입 연산자와 삼항 연산자만 오른쪽에서 왼쪽으로 계산됩니다.

| 우선순위 | 연산자 | 설명 |
|---|---|---|
| 1 (높음) | `()`, `.`, `?.`, `[]`, `++`(후위), `--`(후위) | 괄호, 멤버 접근, 인덱서, 후위 증감 |
| 2 | `+`(단항), `-`(단항), `!`, `~`, `++`(전위), `--`(전위), `(형)값` | 부호, 논리/비트 NOT, 전위 증감, 형 변환 |
| 3 | `*`, `/`, `%` | 곱셈, 나눗셈, 나머지 |
| 4 | `+`, `-` | 덧셈, 뺄셈(문자열 연결 포함) |
| 5 | `<<`, `>>` | 비트 시프트 |
| 6 | `<`, `>`, `<=`, `>=`, `is`, `as` | 비교, 형 검사/변환 |
| 7 | `==`, `!=` | 같음, 다름 비교 |
| 8 | `&` | 비트 AND |
| 9 | `^` | 비트 XOR |
| 10 | `\|` | 비트 OR |
| 11 | `&&` | 논리 AND |
| 12 | `\|\|` | 논리 OR |
| 13 | `??` | null 병합 연산자 |
| 14 | `?:` | 삼항(조건) 연산자 |
| 15 (낮음) | `=`, `+=`, `-=`, `*=`, `/=`, `%=` 등 | 대입 및 복합 대입 |

헷갈리기 쉬운 조합은 괄호로 명시적으로 묶는 것이 안전합니다. 예를 들어 `a + b == c && d`처럼 여러 종류의 연산자가 한 문장에 섞이면, 우선순위를 정확히 외우고 있더라도 다른 사람이 코드를 읽을 때는 오해하기 쉽습니다. `(a + b) == c && d`처럼 의도를 드러내는 괄호를 추가하는 습관이 장기적으로 더 안전합니다.

## 4. 더 공부하고 싶을 때 참고할 자료 유형

이 책에서 다루지 못한 세부 사항이나 새로운 기능을 확인하고 싶을 때는 아래와 같은 유형의 자료를 찾아보는 것이 좋습니다. 특정 책이나 강의를 나열하는 대신, 어떤 "종류"의 자료가 어떤 상황에 유용한지를 정리합니다.

- **공식 언어/플랫폼 문서**: C# 언어 자체의 문법 사양이나 .NET에서 제공하는 클래스와 메서드의 정확한 동작을 확인하고 싶을 때 가장 신뢰할 수 있는 출처입니다. 메서드 이름과 함께 검색하면 매개변수, 반환값, 예외 조건, 사용 예제를 확인할 수 있습니다.
- **API 브라우저/레퍼런스**: 특정 클래스나 메서드가 어느 네임스페이스에 속하는지, 어떤 오버로드(같은 이름의 여러 메서드)가 존재하는지를 확인할 때 유용합니다. 이 책에서 다룬 `string`, `Math`, `List<T>`, `Task` 같은 타입도 실제로는 이보다 훨씬 많은 멤버를 갖고 있습니다.
- **릴리스 노트와 언어 버전 안내**: C#은 매년 새로운 버전이 나오며 새 문법이 추가됩니다. 지금 사용하는 .NET 버전이 어떤 문법을 지원하는지 확인하려면 버전별 릴리스 노트를 살펴보는 것이 정확합니다.
- **커뮤니티 질의응답과 이슈 저장소**: 특정 에러 메시지를 그대로 검색하면, 같은 문제를 겪은 다른 개발자의 질문과 답변을 찾을 수 있는 경우가 많습니다. 오픈소스로 공개된 라이브러리라면 이슈 저장소에서 비슷한 사례나 알려진 제한사항을 확인할 수도 있습니다.
- **샘플 코드가 포함된 저장소**: 어떤 기능을 "어떻게 실전에서 조합해 쓰는지"는 문서만으로 감이 잘 안 잡힐 때가 많습니다. 공개된 예제 프로젝트를 직접 내려받아 실행해보고 코드를 하나씩 바꿔보는 것이 감을 잡는 데 효과적입니다.

자료의 형태가 무엇이든, 검색한 내용을 그대로 복사해 쓰기보다는 왜 그렇게 동작하는지 스스로 설명할 수 있을 때까지 작은 예제로 직접 실험해보는 과정이 결국 실력으로 남습니다.
