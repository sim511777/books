프로그램이 커지면 같은 코드를 여러 곳에서 반복해서 쓰게 되는 경우가 많습니다. 예를 들어 "두 수의 평균을 구하는 계산"을 프로그램 곳곳에서 필요로 한다면, 그 계산을 매번 새로 적는 대신 이름을 붙여 하나로 묶어두고 필요할 때마다 불러 쓰는 편이 훨씬 효율적입니다. 이렇게 특정 작업을 이름으로 묶어 두는 단위를 C#에서는 메서드(Method)라고 부릅니다. (다른 언어에서는 흔히 함수, Function이라고도 부르는데, C#에서는 클래스 안에 정의되는 것이 기본이므로 메서드라는 이름을 주로 씁니다.)

## 메서드 정의와 호출

메서드는 다음과 같은 형태로 정의합니다.

```csharp
static int Add(int a, int b)
{
    int result = a + b;
    return result;
}
```

- `static`은 이 메서드가 특정 객체 없이도 호출될 수 있다는 뜻입니다. 9장에서 클래스와 객체를 배우면 `static`이 없는 메서드도 다루게 됩니다.
- `int`는 이 메서드가 반환하는 값의 자료형입니다. 반환값이 없다면 `void`를 씁니다.
- `Add`는 메서드 이름이며, PascalCase로 짓는 것이 C#의 관례입니다.
- `(int a, int b)`는 매개변수(Parameter) 목록입니다. 메서드를 호출할 때 전달하는 값을 담는 변수입니다.
- `return`문은 메서드를 즉시 종료하며 지정한 값을 호출한 곳으로 돌려줍니다.

정의한 메서드는 이름과 괄호로 호출합니다.

```csharp
int sum = Add(3, 5); // 8
Console.WriteLine(sum);
```

이때 `3`과 `5`처럼 호출할 때 실제로 넘기는 값을 인수(Argument)라고 부릅니다. 매개변수와 인수는 자주 혼용되지만, 메서드를 정의할 때 적는 것이 매개변수, 호출할 때 넘기는 실제 값이 인수라는 차이를 기억해 두면 좋습니다.

반환값이 필요 없는 작업은 `void`로 선언합니다.

```csharp
static void PrintGreeting(string name)
{
    Console.WriteLine($"안녕하세요, {name}님!");
    // 반환할 값이 없으므로 return문이 없거나, return;만 쓴다
}

PrintGreeting("지수");
```

## 매개변수와 반환값

메서드는 매개변수를 여러 개 받을 수 있고, 매개변수가 하나도 없을 수도 있습니다.

```csharp
static double GetAverage(int a, int b, int c)
{
    return (a + b + c) / 3.0;
}

static string GetCurrentGreeting()
{
    return "환영합니다!";
}
```

반환값은 반드시 메서드 선언에 적은 자료형과 일치해야 합니다. 아무 값도 돌려주지 않으면서 `int`처럼 반환형을 지정하면 컴파일 오류가 발생합니다.

한 가지 값 이상을 돌려주고 싶다면 튜플(Tuple)을 활용할 수 있습니다.

```csharp
static (int Min, int Max) FindMinMax(int[] numbers)
{
    int min = numbers[0];
    int max = numbers[0];

    foreach (int n in numbers)
    {
        if (n < min) min = n;
        if (n > max) max = n;
    }

    return (min, max);
}

var result = FindMinMax(new int[] { 4, 8, 1, 9, 3 });
Console.WriteLine($"최소값: {result.Min}, 최대값: {result.Max}");
```

## 메서드 오버로딩

같은 이름의 메서드를 매개변수의 개수나 자료형을 다르게 하여 여러 개 정의할 수 있습니다. 이를 오버로딩(Overloading)이라고 합니다. 호출할 때 전달하는 인수에 맞춰 컴파일러가 알맞은 버전을 자동으로 골라줍니다.

```csharp
static int Add(int a, int b)
{
    return a + b;
}

static double Add(double a, double b)
{
    return a + b;
}

static int Add(int a, int b, int c)
{
    return a + b + c;
}

Console.WriteLine(Add(1, 2));       // int 버전 호출, 3
Console.WriteLine(Add(1.5, 2.5));   // double 버전 호출, 4.0
Console.WriteLine(Add(1, 2, 3));    // 매개변수 3개 버전 호출, 6
```

오버로딩은 비슷한 작업을 이름은 그대로 유지하면서 다양한 입력 형태에 대응하고 싶을 때 유용합니다. 다만 반환형만 다르고 매개변수 목록이 완전히 같은 경우는 오버로딩으로 인정되지 않으니 주의해야 합니다.

## ref, out, in 매개변수 수정자

기본적으로 C#의 매개변수는 값이 복사되어 전달됩니다. 메서드 안에서 매개변수를 바꿔도 호출한 쪽의 원래 변수는 영향을 받지 않습니다.

```csharp
static void TryDouble(int x)
{
    x = x * 2;
}

int number = 5;
TryDouble(number);
Console.WriteLine(number); // 5, 그대로다
```

호출한 쪽의 변수를 실제로 바꾸고 싶다면 `ref` 수정자를 씁니다. 이 경우 인수로 넘기는 변수에도 `ref`를 함께 적어야 하며, 넘기기 전에 반드시 값이 초기화되어 있어야 합니다.

```csharp
static void DoubleValue(ref int x)
{
    x = x * 2;
}

int number = 5;
DoubleValue(ref number);
Console.WriteLine(number); // 10
```

`out`은 `ref`와 비슷하게 호출한 쪽의 변수를 바꾸지만, 메서드 안에서 반드시 값을 할당해야 한다는 점이 다릅니다. 메서드가 값 하나 이상을 "돌려받아야" 할 때 주로 사용합니다. 대표적인 예가 `int.TryParse`입니다.

```csharp
static bool TryDivide(int a, int b, out int result)
{
    if (b == 0)
    {
        result = 0;
        return false;
    }

    result = a / b;
    return true;
}

if (TryDivide(10, 2, out int quotient))
{
    Console.WriteLine($"결과: {quotient}");
}
else
{
    Console.WriteLine("0으로 나눌 수 없습니다.");
}
```

`in`은 `ref`처럼 값을 참조로 전달하지만, 메서드 안에서 그 값을 바꾸지 못하도록 막습니다. 큰 구조체를 복사 없이 넘기면서도 실수로 값을 변경하는 것을 방지하고 싶을 때 사용합니다. 12장에서 구조체를 배우면 `in`이 왜 유용한지 더 분명하게 느낄 수 있습니다.

```csharp
static double GetArea(in double radius)
{
    // radius = 10; // 컴파일 오류: in 매개변수는 수정할 수 없다
    return Math.PI * radius * radius;
}
```

## 기본값 매개변수

매개변수에 기본값을 지정해 두면, 호출할 때 해당 인수를 생략할 수 있습니다.

```csharp
static void PrintMessage(string message, int repeatCount = 1)
{
    for (int i = 0; i < repeatCount; i++)
    {
        Console.WriteLine(message);
    }
}

PrintMessage("안녕");           // repeatCount는 기본값 1
PrintMessage("안녕", 3);        // repeatCount는 3
```

기본값이 있는 매개변수는 반드시 매개변수 목록의 뒤쪽에 위치해야 합니다. 매개변수가 여러 개이고 일부만 지정하고 싶다면 이름을 명시하는 방법(named argument)도 유용합니다.

```csharp
static void CreateUser(string name, int age = 20, string city = "서울")
{
    Console.WriteLine($"{name}, {age}세, {city}");
}

CreateUser("민준");
CreateUser("서연", city: "부산"); // age는 기본값, city만 지정
```

## 지역 함수

메서드 안에서만 사용할 작은 보조 메서드가 필요할 때는 지역 함수(Local Function)를 정의할 수 있습니다. 지역 함수는 자신을 감싸고 있는 메서드 안에서만 호출할 수 있고, 바깥 메서드의 변수를 그대로 참조할 수 있다는 특징이 있습니다.

```csharp
static int SumOfSquares(int n)
{
    int Square(int x) // 지역 함수: SumOfSquares 안에서만 쓰인다
    {
        return x * x;
    }

    int total = 0;
    for (int i = 1; i <= n; i++)
    {
        total += Square(i);
    }

    return total;
}

Console.WriteLine(SumOfSquares(3)); // 1+4+9 = 14
```

지역 함수는 특정 메서드 하나를 위해서만 존재하는 짧은 계산 로직을 별도의 클래스 메서드로 분리하지 않고도 깔끔하게 정리할 수 있게 해줍니다. 코드가 그 메서드 밖에서는 쓰일 일이 없다는 것을 이름 그대로 드러내는 효과도 있습니다.

## 요약

- 메서드는 특정 작업을 이름으로 묶어 재사용할 수 있게 해주는 단위이며, `반환형 이름(매개변수)` 형태로 정의한다.
- 매개변수는 메서드 정의에 적는 변수, 인수는 호출할 때 실제로 넘기는 값이다.
- 같은 이름의 메서드를 매개변수 구성만 다르게 여러 개 정의하는 것을 오버로딩이라 한다.
- `ref`는 호출한 쪽 변수를 참조로 전달해 메서드 안에서 값을 바꿀 수 있게 하고, `out`은 메서드가 값을 반드시 채워서 돌려주도록 하며, `in`은 참조로 전달하되 값 변경을 막는다.
- 매개변수에 기본값을 지정하면 호출 시 해당 인수를 생략할 수 있다.
- 지역 함수는 특정 메서드 안에서만 쓰이는 작은 보조 메서드를 정의하는 방법이다.
- 지금까지는 메서드를 `static`으로만 다뤘지만, 9장에서 클래스와 객체를 배우면 객체마다 동작이 달라지는 인스턴스 메서드를 본격적으로 다루게 된다.

## 연습문제

1. 두 정수를 매개변수로 받아 더 큰 값을 반환하는 `Max` 메서드를 작성하고, 세 개의 정수를 받는 오버로드도 함께 작성하시오.
2. `ref` 매개변수를 이용해 두 변수의 값을 서로 바꾸는(swap) 메서드를 작성하시오.
3. 문자열을 정수로 변환하되 변환에 실패하면 `false`를 반환하는 메서드를 `out` 매개변수를 활용해 작성하시오.
4. 이름과 인사말(기본값 "안녕하세요")을 매개변수로 받아 인사 문구를 출력하는 메서드를 기본값 매개변수를 이용해 작성하시오.
5. 정수 배열을 매개변수로 받아, 지역 함수를 이용해 배열의 평균에서 벗어난 정도(편차)를 계산하고 그 결과를 출력하는 메서드를 작성하시오.
