## 값 타입을 다시 떠올려 보기

3장에서 자료형을 값 타입(value type)과 참조 타입(reference type)으로 나누어 설명했습니다. `int`, `double`, `bool` 같은 기본 자료형은 값 타입이어서, 변수에 다른 변수를 대입하면 값이 그대로 복사됩니다. 반대로 9장에서 배운 `class`로 만든 객체는 참조 타입이어서, 변수에는 객체의 위치(참조)만 저장되고 대입은 그 참조를 복사하는 것에 불과합니다.

이번 장에서는 사용자가 직접 값 타입을 정의할 수 있는 `struct`와, 이름이 붙은 정수 집합을 표현하는 `enum`을 다룹니다. 둘 다 클래스에 비하면 소박한 도구처럼 보이지만, 적절한 자리에 쓰면 코드를 훨씬 안전하고 읽기 쉽게 만들어 줍니다.

## 구조체(struct) 정의하기

구조체는 문법적으로 클래스와 매우 비슷합니다. 필드, 속성(11장), 메서드, 생성자를 모두 가질 수 있습니다. 다른 점은 오직 하나, `class` 대신 `struct` 키워드를 쓴다는 것과, 그 결과로 값 타입이 된다는 것입니다.

```csharp
public struct Point2D
{
    public int X { get; }
    public int Y { get; }

    public Point2D(int x, int y)
    {
        X = x;
        Y = y;
    }

    public double DistanceFromOrigin()
    {
        return Math.Sqrt(X * X + Y * Y);
    }
}
```

## class와 struct의 차이: 복사 동작으로 확인하기

말로 설명하는 것보다 실제 동작을 보는 것이 가장 명확합니다. 같은 모양을 가진 `class` 버전과 `struct` 버전을 각각 만들어서 대입했을 때 어떤 차이가 생기는지 비교해 보겠습니다.

```csharp
public class PointClass
{
    public int X;
    public int Y;
}

public struct PointStruct
{
    public int X;
    public int Y;
}
```

```csharp
// 참조 타입: 대입은 "같은 객체를 가리키는 것"
PointClass classA = new PointClass { X = 1, Y = 1 };
PointClass classB = classA;
classB.X = 99;
Console.WriteLine(classA.X);   // 99 — classA와 classB는 같은 객체를 가리킨다

// 값 타입: 대입은 "값을 통째로 복사하는 것"
PointStruct structA = new PointStruct { X = 1, Y = 1 };
PointStruct structB = structA;
structB.X = 99;
Console.WriteLine(structA.X);  // 1 — structB는 별개의 복사본이라 structA는 영향을 받지 않는다
```

`classB.X = 99;`를 실행하면 `classA.X`도 함께 바뀝니다. `classA`와 `classB`가 힙(heap)에 있는 같은 객체를 가리키는 서로 다른 이름일 뿐이기 때문입니다. 반면 `structB.X = 99;`는 `structB`라는 독립된 복사본만 바꾸고, `structA`는 원래 값을 그대로 유지합니다. 메서드에 인자로 넘길 때도 마찬가지 원리가 적용되어서, 구조체를 매개변수로 받는 메서드 안에서 값을 바꾸어도 호출한 쪽의 원본에는 영향이 없습니다.

## 구조체를 쓰기에 적합한 상황

이 복사 동작 때문에 구조체는 아무 데나 쓰기 좋은 도구는 아닙니다. 다음 조건을 함께 만족할 때 구조체가 좋은 선택이 됩니다.

- **크기가 작다**: 필드 몇 개 정도의 작은 데이터. 구조체는 대입/전달될 때마다 통째로 복사되므로, 필드가 많으면 복사 비용이 커집니다.
- **불변(immutable)에 가깝다**: 한 번 만들어지면 값이 잘 바뀌지 않는 데이터. `Point2D`처럼 좌표, 색상, 금액처럼 "그 자체가 값"인 개념이 대표적입니다.
- **독립적인 복사가 자연스럽다**: "같은 것을 참조한다"는 개념보다 "각자 자기 값을 가진다"는 개념이 더 어울리는 경우입니다.

.NET 표준 라이브러리에서도 `DateTime`, `TimeSpan`, `decimal` 같은 형식은 모두 구조체입니다. 이들은 하나같이 "값 그 자체가 의미를 갖는" 작은 데이터라는 공통점이 있습니다. 반대로 여러 속성을 가지고 상태가 계속 바뀌는 `Person`, `BankAccount`(9~10장 예제) 같은 객체는 클래스로 만드는 것이 자연스럽습니다.

## 열거형(enum): 이름 붙은 정수

특정 값 중 하나만 가질 수 있는 상태를 표현할 때, `int` 상수를 여러 개 나열하는 방법도 있지만 그보다 훨씬 안전하고 읽기 좋은 방법이 `enum`입니다.

```csharp
public enum OrderStatus
{
    Pending,     // 0
    Shipped,     // 1
    Delivered,   // 2
    Cancelled    // 3
}
```

특별히 지정하지 않으면 첫 번째 멤버가 0, 그다음부터 1씩 증가한 정수가 자동으로 배정됩니다. `enum`이 겉보기에는 이름표가 붙은 새로운 종류의 값처럼 보이지만, 내부적으로는 그냥 `int`(정확히는 지정한 정수형)라는 사실을 기억해 두면 이후 동작을 이해하기 쉽습니다.

```csharp
OrderStatus status = OrderStatus.Shipped;
int rawValue = (int)status;
Console.WriteLine(rawValue);   // 1

OrderStatus fromNumber = (OrderStatus)2;
Console.WriteLine(fromNumber);   // Delivered
```

값을 직접 지정할 수도 있습니다.

```csharp
public enum HttpStatusGroup
{
    Success = 200,
    ClientError = 400,
    ServerError = 500
}
```

5장에서 배운 `switch`문과 함께 쓰면 상태에 따른 분기를 명확하게 표현할 수 있습니다.

```csharp
static string Describe(OrderStatus status)
{
    switch (status)
    {
        case OrderStatus.Pending:
            return "주문이 접수되었습니다.";
        case OrderStatus.Shipped:
            return "배송이 시작되었습니다.";
        case OrderStatus.Delivered:
            return "배송이 완료되었습니다.";
        case OrderStatus.Cancelled:
            return "주문이 취소되었습니다.";
        default:
            return "알 수 없는 상태입니다.";
    }
}
```

`bool`로 상태를 표현하려 했다면 "취소되었는가"만 표현할 수 있지만, `int` 상수로 표현하려 했다면 `0`, `1`, `2`, `3`이 각각 무엇을 뜻하는지 코드만 봐서는 알기 어렵습니다. `enum`은 이 두 문제를 모두 해결하면서, `Describe` 함수처럼 값을 다루는 코드에서도 실수를 줄여줍니다.

## [Flags]: 여러 값을 동시에 담는 열거형

보통의 `enum`은 값 하나만 선택하는 상황에 어울립니다. 하지만 "읽기 권한과 쓰기 권한을 동시에 가진다"처럼 여러 값을 동시에 표현하고 싶을 때는 `[Flags]` 특성을 붙인 열거형을 사용합니다. 이때는 각 멤버의 값을 2의 거듭제곱(1, 2, 4, 8, ...)으로 지정해서, 비트 연산으로 조합할 수 있게 만드는 것이 관례입니다.

```csharp
[Flags]
public enum FilePermission
{
    None = 0,
    Read = 1,
    Write = 2,
    Execute = 4
}
```

```csharp
// | 연산자로 여러 권한을 하나로 합친다
FilePermission permission = FilePermission.Read | FilePermission.Write;

// & 연산자로 특정 권한이 포함되어 있는지 검사한다
bool canWrite = (permission & FilePermission.Write) == FilePermission.Write;
Console.WriteLine(canWrite);          // True
Console.WriteLine(permission);        // Read, Write
```

`[Flags]`를 붙이면 `Console.WriteLine(permission)`처럼 출력할 때도 `Read, Write`처럼 조합된 이름을 사람이 읽기 좋은 형태로 보여준다는 실용적인 장점도 있습니다. 4장에서 다룬 비트 연산자(`|`, `&`)가 여기서 실제로 쓰이는 모습을 볼 수 있습니다.

## 구조체와 열거형을 함께 쓰기

구조체 안에 열거형 필드를 두면 "작은 값 하나에 상태까지 함께 담는" 표현이 자연스러워집니다.

```csharp
public struct Temperature
{
    public double Degrees { get; }
    public TemperatureUnit Unit { get; }

    public Temperature(double degrees, TemperatureUnit unit)
    {
        Degrees = degrees;
        Unit = unit;
    }
}

public enum TemperatureUnit
{
    Celsius,
    Fahrenheit
}
```

`Temperature`는 값 두 개(온도, 단위)로만 이루어진 작고 불변인 데이터이므로 구조체로 적합하고, 단위는 정해진 두 가지 중 하나이므로 열거형으로 적합합니다. 이렇게 각 도구를 "그 특성이 잘 맞는 자리"에 배치하는 감각이 쌓이면, 이후 13장에서 배울 제네릭이나 14장의 컬렉션을 설계할 때도 값 타입과 참조 타입, 그리고 상태를 어떻게 표현할지에 대한 판단이 훨씬 수월해집니다.

## 요약

- `struct`는 값 타입이고 `class`는 참조 타입입니다. 구조체는 대입/전달 시 값이 복사되고, 클래스는 참조가 복사됩니다.
- 구조체는 필드 수가 적고 불변에 가까운 작은 데이터(좌표, 금액, 시간 등)를 표현할 때 적합합니다.
- `enum`은 이름이 붙은 정수 집합으로, 실제로는 `int` 값이며 캐스팅으로 정수와 자유롭게 오갈 수 있습니다.
- `enum`은 `switch`문과 함께 쓰면 상태에 따른 분기를 명확하고 안전하게 표현할 수 있습니다.
- `[Flags]` 열거형은 값을 2의 거듭제곱으로 지정해 비트 연산자로 여러 값을 동시에 조합할 수 있게 해줍니다.

## 연습문제

1. `class`로 만든 좌표 형식과 `struct`로 만든 좌표 형식을 각각 만들어 변수에 대입한 뒤, 하나를 수정했을 때 다른 변수가 영향을 받는지 여부를 직접 코드로 확인해 보세요.
2. 요일을 표현하는 `enum Weekday`를 정의하고, 오늘이 평일인지 주말인지 판단하는 함수를 `switch`문으로 작성해 보세요.
3. `enum Season { Spring, Summer, Fall, Winter }`을 정의하고, 정수 0~3을 각각 `Season` 값으로 캐스팅해서 출력해 보세요.
4. `[Flags]`를 붙인 `DaysOfWeek` 열거형(예: Monday = 1, Tuesday = 2, Wednesday = 4, ...)을 만들고, 월/수/금을 조합한 값을 만들어 특정 요일이 포함되어 있는지 검사하는 코드를 작성해 보세요.
5. 화폐 금액과 통화 단위를 함께 담는 `Money` 구조체를 설계해 보세요. 통화 단위는 `enum Currency`로 표현하고, 두 `Money` 값을 더하는 메서드도 함께 구현해 보세요.
