# 4장. 연산자와 표현식

[◀ 이전: 3장. 변수와 자료형](ch03-변수와자료형.md) | [📖 목차](00-목차.md) | [다음: 5장. 제어문 ▶](ch05-제어문.md)

---

3장에서 변수에 값을 담는 법을 배웠다면, 이제는 그 값들을 가지고 실제로 무언가를 계산하고 판단할 차례다. **연산자(operator)**는 하나 이상의 값(피연산자, operand)을 받아 새로운 값을 만들어내는 도구이고, 연산자와 피연산자가 결합된 결과물을 **표현식(expression)**이라 부른다. `3 + 4`도 표현식이고, `age >= 18`도 표현식이다. 이번 장에서는 C#이 제공하는 연산자들을 하나씩 살펴보고, C#만의 개성이 강하게 드러나는 null 관련 연산자들도 함께 다룬다.

## 산술 연산자

가장 기본적인 사칙연산과 나머지 연산이다.

```csharp
int a = 17;
int b = 5;

Console.WriteLine(a + b); // 22, 더하기
Console.WriteLine(a - b); // 12, 빼기
Console.WriteLine(a * b); // 85, 곱하기
Console.WriteLine(a / b); // 3, 나누기
Console.WriteLine(a % b); // 2, 나머지
```

여기서 초보자가 자주 놓치는 부분이 정수 나눗셈이다. `int`끼리 나누면 결과도 `int`이므로 소수점 이하는 그대로 버려진다.

```csharp
int x = 7;
int y = 2;
Console.WriteLine(x / y); // 3 (3.5가 아님!)

double result = x / y;        // 3 (여전히 정수 나눗셈이 먼저 실행됨)
double result2 = (double)x / y; // 3.5 (피연산자 중 하나를 미리 double로 변환)
```

`x / y`는 두 피연산자가 모두 `int`이기 때문에 나눗셈 자체가 정수 연산으로 처리된 뒤에야 그 결과가 `double`로 대입된다. 소수 결과를 얻으려면 나눗셈이 일어나기 전에 피연산자 중 하나를 `double`로 캐스팅해야 한다. 형변환에 대한 자세한 내용은 3장 변수와 자료형을 참고한다.

## 관계 연산자와 논리 연산자

관계 연산자는 두 값을 비교해서 `bool` 값(`true` 또는 `false`)을 만든다.

```csharp
int age = 20;

Console.WriteLine(age == 18); // false, 같다
Console.WriteLine(age != 18); // true, 다르다
Console.WriteLine(age > 18);  // true, 크다
Console.WriteLine(age < 18);  // false, 작다
Console.WriteLine(age >= 20); // true, 크거나 같다
Console.WriteLine(age <= 19); // false, 작거나 같다
```

논리 연산자는 `bool` 값들을 조합해서 더 복잡한 조건을 만든다.

```csharp
bool isAdult = age >= 18;
bool hasTicket = true;

Console.WriteLine(isAdult && hasTicket); // AND: 둘 다 true여야 true
Console.WriteLine(isAdult || hasTicket); // OR: 하나라도 true면 true
Console.WriteLine(!isAdult);             // NOT: true/false를 뒤집음
```

`&&`와 `||`는 **단축 평가(short-circuit evaluation)**를 한다는 점이 중요하다. `A && B`에서 `A`가 이미 `false`라면 전체 결과가 `false`로 확정되므로 `B`는 평가조차 하지 않는다. 마찬가지로 `A || B`에서 `A`가 `true`면 `B`를 평가하지 않는다.

```csharp
string? name = null;

// name이 null이면 뒤의 name.Length는 실행되지 않아 예외가 나지 않는다
if (name != null && name.Length > 0)
{
    Console.WriteLine("이름이 있습니다");
}
```

이 단축 평가 덕분에 앞쪽 조건으로 null 여부를 먼저 걸러내는 습관이 안전한 코드를 만든다. 단축 평가를 하지 않는 `&`, `|`도 존재하지만, 일상적인 조건 판단에는 거의 항상 `&&`, `||`를 쓴다. `&`, `|`는 바로 다음에 살펴볼 비트 연산자로서의 역할이 더 크다.

## 비트 연산자

비트 연산자는 정수를 이진수로 놓고 비트 단위로 연산한다. 플래그(flag) 조합이나 저수준 처리에서 쓰인다.

```csharp
int flagA = 0b_0001; // 1
int flagB = 0b_0010; // 2

int combined = flagA | flagB; // 비트 OR: 0011 (3), 두 플래그를 합침
int intersect = flagA & flagB; // 비트 AND: 0000 (0), 공통 비트만 남김
int flipped = ~flagA;          // 비트 NOT: 모든 비트를 반전
int xorResult = flagA ^ flagB; // 비트 XOR: 서로 다른 비트만 1

int shiftedLeft = flagA << 2;  // 왼쪽으로 2비트 이동: 0100 (4)
int shiftedRight = flagB >> 1; // 오른쪽으로 1비트 이동: 0001 (1)
```

입문 단계에서는 비트 연산자를 매일 쓰지는 않지만, `enum`에 `[Flags]` 속성을 붙여 여러 옵션을 하나의 값으로 조합할 때(12장 구조체와 열거형) 비트 OR(`|`)가 등장하므로 개념만은 기억해 두는 것이 좋다.

## 증감 연산자

변수의 값을 1만큼 늘리거나 줄이는 연산자다. `++`, `--`는 변수 앞에 붙이는 전위형과 뒤에 붙이는 후위형이 있는데, 이 둘은 "증가된 값을 언제 반환하느냐"가 다르다.

```csharp
int count = 5;

int a = count++; // 후위: 먼저 현재 값(5)을 a에 대입한 뒤 count를 6으로 증가
Console.WriteLine($"a = {a}, count = {count}"); // a = 5, count = 6

int b = ++count; // 전위: 먼저 count를 7로 증가시킨 뒤 그 값을 b에 대입
Console.WriteLine($"b = {b}, count = {count}"); // b = 7, count = 7
```

단독으로 한 줄에 쓸 때는 `count++;`이든 `++count;`이든 결과는 같지만, 다른 표현식 안에서 값을 사용하면서 동시에 증감할 때는 전위/후위의 차이가 실제 결과를 바꾸므로 주의해야 한다. 반복문에서 `for (int i = 0; i < 10; i++)`처럼 쓰는 관용구는 6장 반복문에서 자세히 다룬다.

## 대입 연산자와 복합 대입

`=`는 값을 대입하는 연산자이고, 산술 연산과 대입을 한 번에 처리하는 복합 대입 연산자들도 있다.

```csharp
int total = 10;
total += 5;  // total = total + 5;와 동일, 결과 15
total -= 3;  // 12
total *= 2;  // 24
total /= 4;  // 6
total %= 4;  // 2
```

## null 조건 연산자: C#다운 특징

여기까지는 다른 언어에서도 낯설지 않은 연산자였다면, 이제부터 소개할 세 연산자는 C#이 null을 다루는 방식의 개성을 잘 보여준다. 참조 타입 변수가 `null`일 수 있다는 사실은 3장에서 다뤘는데, 이 연산자들은 null 검사를 짧고 안전하게 표현하도록 도와준다.

### null 조건 연산자 `?.`

객체가 `null`일 수도 있는 상태에서 그 멤버에 접근하고 싶을 때, 매번 `if (obj != null)`로 감싸는 대신 `?.`를 쓸 수 있다. `obj`가 `null`이면 뒤의 멤버 접근을 건너뛰고 전체 표현식이 그냥 `null`이 되며, 예외가 발생하지 않는다.

```csharp
class Person
{
    public string? Nickname;
}

Person? person = null;

// 기존 방식
string? result1;
if (person != null)
{
    result1 = person.Nickname;
}
else
{
    result1 = null;
}

// null 조건 연산자를 쓴 방식 (위와 동일한 의미)
string? result2 = person?.Nickname;

Console.WriteLine(result2 ?? "값 없음"); // "값 없음"
```

`person`이 `null`이 아니었다면 `person?.Nickname`은 평범한 `person.Nickname`과 똑같이 동작한다. 메서드 호출을 이어서 연결(체이닝)할 때도 유용하다.

```csharp
// person이 null이거나, Address가 null이어도 예외 없이 전체가 null이 됨
string? city = person?.Address?.City;
```

### null 병합 연산자 `??`

`??`는 왼쪽 값이 `null`이면 오른쪽 값을 대신 사용하는 연산자다. "이 값이 없으면 이 기본값을 써라"는 뜻이다. 방금 예제에서 이미 한 번 사용했다.

```csharp
string? nickname = null;
string displayName = nickname ?? "익명 사용자";
Console.WriteLine(displayName); // "익명 사용자"

int? score = 85;
int finalScore = score ?? 0; // score가 있으므로 85
```

`?.`와 `??`는 짝을 이뤄 자주 함께 쓰인다.

```csharp
string city = person?.Address?.City ?? "알 수 없음";
```

이 한 줄은 "person이 null이거나 Address가 null이면 City를 읽으려 하지 말고, 최종적으로 값이 없다면 '알 수 없음'을 써라"는 로직을 표현한다. 전통적인 방식이라면 여러 줄의 null 검사 `if`문이 필요했을 코드다.

### null 병합 대입 연산자 `??=`

`??=`는 "왼쪽 변수가 현재 `null`일 때만" 오른쪽 값을 대입한다. 이미 값이 있다면 아무 일도 하지 않는다.

```csharp
string? title = null;
title ??= "제목 없음"; // title이 null이었으므로 대입됨
Console.WriteLine(title); // "제목 없음"

title ??= "다른 제목"; // title이 이미 값이 있으므로 대입되지 않음
Console.WriteLine(title); // "제목 없음"
```

이 연산자는 값이 아직 설정되지 않았을 때만 기본값이나 지연 초기화 값을 채워 넣는 상황에서 유용하다. 예를 들어 캐시된 목록이 없을 때만 새로 만드는 경우에 자주 쓰인다.

```csharp
List<string>? cachedNames = null;
cachedNames ??= new List<string>();
cachedNames.Add("지민");
```

리스트와 컬렉션에 대해서는 7장 배열과 컬렉션 기초, 14장 컬렉션과 LINQ에서 더 깊이 다룬다.

## 연산자 우선순위

한 표현식에 여러 연산자가 섞여 있으면, C#은 정해진 우선순위에 따라 어떤 연산을 먼저 계산할지 결정한다. 예를 들어 곱셈과 나눗셈은 더하기와 빼기보다 먼저 계산되고, 관계 연산자는 논리 연산자보다 먼저 계산된다.

```csharp
int result = 3 + 4 * 2;       // 곱셈이 먼저: 3 + 8 = 11
bool check = 5 > 3 && 2 < 4;   // 관계 연산이 먼저: true && true = true
```

모든 연산자의 우선순위를 외울 필요는 없다. 우선순위가 헷갈리는 상황에서는 괄호 `()`로 계산 순서를 명확하게 표시하는 것이 가장 안전하고, 코드를 읽는 사람에게도 의도가 분명하게 전달된다.

```csharp
int result = 3 + (4 * 2); // 괄호로 의도를 명확히 표현
```

연산자별 정확한 우선순위 표는 부록에서 전체 목록으로 정리해 둔다.

## 요약

- 산술 연산자에서 정수 나눗셈은 소수점을 버리므로, 소수 결과가 필요하면 나누기 전에 피연산자를 `double` 등으로 캐스팅해야 한다.
- 관계 연산자는 비교 결과를 `bool`로 만들고, 논리 연산자 `&&`, `||`는 단축 평가를 통해 불필요한 평가와 null 관련 예외를 피할 수 있게 해 준다.
- 비트 연산자는 정수를 비트 단위로 다루며, 플래그 조합 같은 특수한 상황에서 쓰인다.
- 전위 증감(`++count`)과 후위 증감(`count++`)은 증가된 값을 반환하는 시점이 다르다.
- `?.`(null 조건), `??`(null 병합), `??=`(null 병합 대입)는 C#이 null을 다루는 대표적인 문법으로, null 검사를 짧고 안전하게 표현한다.
- 연산자 우선순위가 헷갈릴 때는 괄호를 사용해 계산 순서를 명확히 하는 것이 가장 안전하다. 전체 우선순위 표는 부록을 참고한다.

