# VS Code로 구축하는 C++ 개발환경

[다음: 1장. 이 강좌의 목표와 전체 그림 ▶](ch01-이강좌의목표와전체그림.md)

---

C++ 문법이 아니라 C++ "개발환경"을 처음부터 끝까지 구축하는 실전 강좌입니다. GCC 컴파일러,
VS Code 에디터, CMake 빌드 시스템, Ninja 빌드 실행기, vcpkg 패키지 관리자를 하나씩 설치하고
서로 연결하는 방법을 다루며, 디버깅·정적 분석·테스트·크로스플랫폼 배포까지 실전 프로젝트
구성으로 마무리합니다.

각 장은 개념 설명, 실습 명령어, 설정 파일 예제, 요약, 연습문제로 구성되어 있으며, 필요한
곳에는 이해를 돕는 다이어그램을 함께 실었습니다.
