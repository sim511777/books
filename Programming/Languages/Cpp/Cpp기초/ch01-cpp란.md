# 1장. C++란 무엇인가

## 들어가며

C++는 1979년 벨 연구소의 비야네 스트로우스트룹(Bjarne Stroustrup)이 C언어에 클래스 개념을 얹어 만든 언어에서 출발했다. 처음 이름은 "C with Classes"였고, 이후 여러 차례의 표준화를 거쳐 오늘날의 C++로 발전했다. 흥미로운 점은 40년이 넘는 시간이 지난 지금도 C++가 게임 엔진, 데이터베이스, 운영체제, 금융 거래 시스템처럼 성능이 절대적으로 중요한 영역에서 여전히 1순위로 선택되는 언어라는 사실이다. 이 장에서는 C++가 어떤 언어인지, 왜 지금도 배울 가치가 있는지, 그리고 앞으로 이 책을 어떤 순서로 공부하면 좋을지 살펴본다.

## C++와 C의 관계

C++는 C언어의 상위 집합(superset)에 가깝게 설계되었다. 실제로 C로 작성된 코드는 아주 일부 예외를 제외하면 대부분 C++ 컴파일러로도 컴파일된다. C++는 C의 문법과 저수준 메모리 제어 능력을 그대로 물려받으면서, 여기에 클래스, 템플릿, 예외 처리, 네임스페이스 같은 고수준 기능을 추가했다.

이 관계를 이해하는 것이 중요한 이유는, C++를 배운다는 것이 "C의 모든 것 + 객체지향과 제네릭 프로그래밍"을 배우는 것과 비슷하기 때문이다. 예를 들어 C에서는 구조체(struct)에 데이터만 담을 수 있었지만, C++의 클래스는 데이터와 그 데이터를 다루는 함수를 하나로 묶을 수 있다.

```cpp
// C 스타일: 데이터와 함수가 분리되어 있음
struct Point {
    int x;
    int y;
};

void print_point(const Point& p) {
    // 참조(reference)는 9장에서 자세히 다룬다
    // p.x, p.y를 출력
}

// C++ 스타일: 데이터와 동작을 하나의 클래스로 묶음
class Point2D {
public:
    int x;
    int y;

    void print() const {
        // this가 가리키는 객체의 x, y를 출력
    }
};
```

클래스와 객체에 대한 본격적인 내용은 10장에서 다루므로, 지금은 "C++가 C보다 더 많은 도구를 제공한다"는 감각만 잡으면 된다.

## 저수준 접근과 고수준 추상화의 공존

C++의 가장 큰 특징은 저수준 하드웨어 제어와 고수준 추상화를 동시에 지원한다는 점이다. 한쪽 극단에는 포인터로 메모리 주소를 직접 다루고 비트 연산으로 하드웨어 레지스터를 조작하는 코드가 있고, 반대쪽 극단에는 표준 템플릿 라이브러리(STL)의 컨테이너와 알고리즘을 이용해 파이썬처럼 간결하게 데이터를 처리하는 코드가 있다. 같은 언어 안에서 이 둘을 자유롭게 넘나들 수 있다는 것이 C++가 다른 언어와 구별되는 지점이다.

```cpp
#include <vector>
#include <algorithm>

int find_max(const std::vector<int>& numbers) {
    // STL 알고리즘을 사용한 고수준 코드
    return *std::max_element(numbers.begin(), numbers.end());
}
```

포인터와 메모리 관리는 8장과 9장에서, 표준 컨테이너는 14장에서 본격적으로 다룬다. 지금은 C++가 "저수준으로 내려갈 수도 있고, 고수준에 머물 수도 있는" 유연한 언어라는 점만 기억해 두자.

## 정적 타입과 성능

C++는 정적 타입(static typing) 언어다. 변수의 자료형이 컴파일 시점에 결정되며, 컴파일러는 이 정보를 이용해 오류를 미리 잡아내고 최적화된 기계어 코드를 생성한다. 자바스크립트나 파이썬처럼 실행 중에 자료형을 확인하는 동적 타입 언어와 비교하면, C++는 실행 시점의 타입 검사 비용이 거의 없다.

또한 C++는 컴파일러가 소스 코드를 직접 기계어로 번역하는 컴파일 언어(compiled language)다. 자바나 C#처럼 가상 머신 위에서 바이트코드를 실행하는 방식이 아니라, 운영체제와 CPU가 바로 실행할 수 있는 실행 파일을 만든다. 이 두 가지 특성, 즉 정적 타입과 네이티브 컴파일이 결합되어 C++는 실행 속도와 메모리 사용량 측면에서 매우 예측 가능하고 효율적인 성능을 낸다.

변수와 자료형에 대한 자세한 내용은 3장에서 다루며, 컴파일 과정 자체는 2장에서 살펴본다.

## C++의 활용 분야

C++가 실제로 어디에 쓰이는지 알면 왜 지금도 배울 가치가 있는지 체감할 수 있다.

- **게임 엔진**: 언리얼 엔진(Unreal Engine)을 비롯한 대부분의 상업용 게임 엔진은 C++로 작성된다. 프레임마다 수천~수만 개의 객체를 계산해야 하는 실시간 렌더링 환경에서는 메모리와 CPU를 세밀하게 제어할 수 있는 언어가 필수적이다.
- **시스템 프로그래밍**: 운영체제 커널의 일부, 데이터베이스 엔진, 웹 브라우저(크롬, 파이어폭스), 컴파일러 자체가 C++로 만들어진다. 하드웨어에 가깝게 접근하면서도 복잡한 소프트웨어 구조를 관리해야 하는 영역이다.
- **임베디드 시스템**: 자동차 제어 장치, 로봇, IoT 기기처럼 메모리와 처리 능력이 제한된 환경에서도 C++는 가비지 컬렉터 없이 예측 가능한 자원 관리를 할 수 있어 널리 사용된다.
- **금융 및 고빈도 거래**: 마이크로초 단위의 지연 시간이 수익에 직결되는 거래 시스템에서도 C++의 성능이 요구된다.

## 다른 언어와의 비교

**C와 비교**하면, C++는 클래스를 통한 캡슐화, 템플릿을 통한 제네릭 프로그래밍, 예외 처리를 통한 오류 관리, 표준 라이브러리 컨테이너 등을 추가로 제공한다. C가 "절차 중심으로 최소한의 추상화만 제공하는 언어"라면, C++는 "그 위에 여러 프로그래밍 패러다임을 얹어 대규모 소프트웨어를 더 안전하고 체계적으로 작성할 수 있게 한 언어"라고 볼 수 있다.

**Java와 비교**하면, 둘 다 클래스 기반 객체지향 언어이고 문법도 비슷한 부분이 많지만 근본적인 차이가 있다. 자바는 가상 머신(JVM) 위에서 실행되며 가비지 컬렉터가 자동으로 메모리를 회수한다. C++는 프로그래머가 직접(또는 9장에서 배울 RAII 기법과 15장의 스마트 포인터를 통해) 메모리 해제를 책임진다. 이 때문에 C++는 자바보다 더 세밀한 성능 튜닝이 가능하지만, 동시에 메모리 관리 실수로 인한 버그의 위험도 더 크다. 이 책의 목표 중 하나는 이러한 위험을 안전하게 다루는 현대적인 C++ 작성법을 익히는 것이다.

## 개발 환경 준비하기

C++로 프로그램을 작성하려면 세 가지가 필요하다.

1. **컴파일러**: 소스 코드를 기계어로 번역하는 프로그램이다. 대표적으로 GCC의 `g++`, LLVM 기반의 `clang++`, 마이크로소프트의 MSVC가 있다. 이 책에서는 여러 플랫폼에서 널리 쓰이는 `g++`를 기준으로 예제를 설명한다.
2. **텍스트 에디터 또는 통합 개발 환경(IDE)**: Visual Studio Code, CLion, Visual Studio 등을 사용할 수 있다. 처음에는 문법 강조와 자동 완성 기능만 있어도 충분하다.
3. **빌드 도구**: 프로젝트가 커지면 `make`나 `CMake` 같은 빌드 도구로 여러 소스 파일의 컴파일과 링크 과정을 자동화한다. 이 책의 앞부분에서는 단일 파일을 직접 컴파일하는 방법부터 시작한다.

컴파일러 설치 여부는 터미널에서 다음처럼 확인할 수 있다.

```bash
g++ --version
```

버전 정보가 출력되면 준비가 끝난 것이다. 실제로 첫 프로그램을 작성하고 빌드하는 전체 과정은 2장에서 단계별로 다룬다.

## 학습 방향

이 책은 다음과 같은 순서로 구성된다. 먼저 2장부터 7장까지는 변수, 연산자, 제어문, 반복문, 함수 등 C++의 기본 문법을 다진다. 이 부분은 C를 배운 적이 있다면 빠르게 지나갈 수 있다. 8장과 9장에서는 배열, 포인터, 참조, 그리고 C++ 고유의 자원 관리 기법인 RAII를 배운다. 10장부터 13장까지는 클래스, 상속, 다형성, 연산자 오버로딩, 템플릿 등 C++의 핵심인 객체지향과 제네릭 프로그래밍을 다룬다. 14장 이후에는 STL 컨테이너, 스마트 포인터, 예외 처리, 이동 시맨틱스처럼 실무에서 매일 쓰는 현대적인 도구들을 익히고, 마지막 18장에서는 좋은 C++ 코드를 작성하는 습관을 정리한다.

## 요약

- C++는 C언어를 기반으로 클래스, 템플릿, 예외 처리 등 고수준 기능을 추가한 언어다.
- 저수준 메모리 제어와 고수준 추상화를 하나의 언어 안에서 함께 사용할 수 있다는 점이 C++의 핵심 강점이다.
- 정적 타입과 네이티브 컴파일 방식 덕분에 실행 속도와 메모리 사용을 예측 가능하게 제어할 수 있다.
- 게임 엔진, 시스템 프로그래밍, 임베디드, 금융 시스템 등 성능이 중요한 분야에서 여전히 널리 쓰인다.
- Java와 달리 가비지 컬렉터가 없으며, 메모리 관리는 프로그래머의 책임이다(9장, 15장에서 안전하게 다루는 법을 배운다).
- 컴파일러(`g++` 등), 에디터, 빌드 도구만 준비되면 바로 학습을 시작할 수 있다.

## 연습문제

1. C++가 C의 "상위 집합에 가깝다"는 말이 어떤 의미인지 자신의 말로 설명해 보라.
2. C++가 저수준 접근과 고수준 추상화를 동시에 지원한다는 것이 실제 개발에서 어떤 장점을 주는지 예를 들어 설명해 보라.
3. 정적 타입 언어와 동적 타입 언어의 차이를 조사하고, 각각의 장단점을 두 가지씩 적어 보라.
4. C++가 가비지 컬렉터를 제공하지 않는다는 사실이 왜 "장점이 될 수도 있고 위험이 될 수도 있는지" 설명해 보라.
5. 자신의 컴퓨터에 `g++` 또는 `clang++`가 설치되어 있는지 확인하고, 버전 정보를 캡처하거나 기록해 보라.
