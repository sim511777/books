# 6장. 반복문

---

5장에서는 조건에 따라 실행 경로를 한 번 선택하는 방법을 배웠습니다. 하지만 "1부터 100까지 더하기", "사용자가 올바른 값을 입력할 때까지 다시 물어보기", "배열의 모든 원소를 검사하기"처럼 같은 동작을 여러 번 반복해야 하는 경우가 훨씬 많습니다. 이 장에서는 C++이 제공하는 네 가지 반복문인 `while`, `do-while`, `for`, 그리고 범위 기반 `for`를 다룹니다.

## while문

`while`문은 조건이 `true`인 동안 블록을 계속 반복 실행합니다. 조건은 반복을 시작하기 전에 먼저 검사되므로, 처음부터 조건이 `false`이면 블록은 한 번도 실행되지 않습니다.

```cpp
#include <iostream>

int main() {
    int count = 1;

    while (count <= 5) {
        std::cout << count << " ";
        count = count + 1;  // 조건을 언젠가 false로 만들어야 무한 루프를 피할 수 있다
    }
    std::cout << '\n';

    return 0;
}
```

이 코드는 `1 2 3 4 5`를 출력합니다. `while`문에서 가장 흔한 실수는 반복 변수(`count`)를 갱신하는 코드를 빠뜨리는 것입니다. 그러면 조건이 영원히 `true`로 남아 프로그램이 멈추지 않는 무한 루프에 빠집니다. 물론 무한 루프가 항상 버그는 아닙니다. 서버 프로그램이나 게임 루프처럼 의도적으로 `while (true) { ... }` 형태를 쓰고 내부에서 `break`로 빠져나가는 경우도 많습니다.

`while`문은 반복 횟수를 미리 알 수 없고, 특정 조건이 만족될 때까지 계속해야 하는 상황에 잘 맞습니다. 예를 들어 사용자가 올바른 입력을 줄 때까지 반복해서 물어보는 코드입니다.

```cpp
int number = 0;
std::cout << "1에서 10 사이의 정수를 입력하세요: ";
std::cin >> number;

while (number < 1 || number > 10) {
    std::cout << "잘못된 값입니다. 다시 입력하세요: ";
    std::cin >> number;
}

std::cout << "입력값: " << number << '\n';
```

## do-while문

`do-while`문은 `while`문과 거의 같지만, 조건 검사를 블록 실행 이후에 합니다. 즉 블록이 최소 한 번은 반드시 실행됩니다.

```cpp
int number;

do {
    std::cout << "1에서 10 사이의 정수를 입력하세요: ";
    std::cin >> number;
} while (number < 1 || number > 10);

std::cout << "입력값: " << number << '\n';
```

이 코드는 앞의 `while` 예제와 결과는 비슷하지만, "값을 입력받는 동작" 자체를 조건 검사 전에 최소 한 번 수행한다는 점이 다릅니다. 메뉴를 한 번 보여준 뒤 사용자가 종료를 선택할 때까지 반복하는 프로그램처럼, "일단 한 번은 실행하고 그 결과를 보고 계속할지 정한다"는 상황에 `do-while`이 자연스럽습니다. 다만 실무에서는 `while`에 비해 훨씬 적게 쓰이며, `do-while`이 어색하게 느껴진다면 `while (true)`와 `break`의 조합으로 바꿔 쓰는 경우도 많습니다.

`do-while`문 끝의 세미콜론(`;`)을 빠뜨리기 쉬우니 주의하세요. `while (조건);` 형태로 반드시 세미콜론을 붙여야 합니다.

## for문

반복 횟수를 미리 알고 있거나, 반복 변수를 초기화·검사·갱신하는 세 단계가 명확할 때는 `for`문이 가장 널리 쓰입니다.

```cpp
for (int i = 1; i <= 5; i = i + 1) {
    std::cout << i << " ";
}
std::cout << '\n';
```

`for`문의 괄호 안은 세 부분으로 나뉩니다.

- **초기화식** (`int i = 1`): 반복을 시작하기 전 딱 한 번 실행됩니다. 여기서 선언한 `i`는 `for`문 블록 안에서만 유효합니다.
- **조건식** (`i <= 5`): 매 반복 시작 전에 검사되며, `false`가 되면 반복이 끝납니다.
- **증감식** (`i = i + 1`): 블록 실행이 끝난 뒤마다 실행됩니다. `i++`처럼 증감 연산자(4장)를 쓰는 것이 더 관용적입니다.

앞서 `while`문으로 작성했던 "1부터 5까지 출력"은 사실 `for`문으로 표현하는 것이 더 자연스럽습니다. 반복 변수, 시작 조건, 종료 조건, 증감 방식이 한곳에 모여 있어서 코드를 읽을 때 "이 반복이 몇 번 도는지"를 한눈에 파악할 수 있기 때문입니다. 반대로 반복 횟수가 조건에 따라 유동적이라면 `while`문이 더 어울립니다.

`for`문은 감소 방향으로도 쓸 수 있고, 여러 변수를 동시에 다룰 수도 있습니다.

```cpp
for (int i = 10; i > 0; i = i - 2) {
    std::cout << i << " ";
}
std::cout << '\n';  // 10 8 6 4 2

for (int i = 0, j = 10; i < j; i = i + 1, j = j - 1) {
    std::cout << "(" << i << ", " << j << ") ";
}
std::cout << '\n';
```

## 범위 기반 for문

C++11부터는 배열이나 컨테이너의 모든 원소를 처음부터 끝까지 순회하는 전용 문법인 범위 기반 `for`문이 추가되었습니다.

```cpp
int scores[5] = {90, 85, 77, 100, 63};

for (int score : scores) {
    std::cout << score << " ";
}
std::cout << '\n';
```

`for (int score : scores)`는 "`scores`의 각 원소를 순서대로 하나씩 꺼내 `score`에 담아 블록을 실행하라"는 뜻입니다. 인덱스를 직접 다루지 않으므로 `for (int i = 0; i < 5; i++) { ... scores[i] ... }`처럼 인덱스 범위를 잘못 계산해 배열 경계를 벗어나는 실수(8장에서 다룰 버퍼 오버런 문제)를 원천적으로 줄여줍니다.

원소를 수정하고 싶다면 참조(9장에서 자세히 다룹니다)를 사용해 `auto&`로 받습니다.

```cpp
for (int& score : scores) {
    score = score + 5;  // 모든 점수에 5점 가산
}
```

여기서 `int&` 대신 `int`로 받으면 원소의 복사본만 수정하는 셈이 되어 원본 배열은 그대로 남습니다. 원소 타입이 길거나 복잡할 때는 `auto`를 함께 써서 `for (const auto& score : scores)`처럼 타입 추론과 불필요한 복사 방지를 동시에 얻는 관용구가 자주 쓰입니다. 이 표현은 8장에서 배열을 본격적으로 다루고 14장에서 `std::vector` 같은 STL 컨테이너를 배울 때 가장 많이 사용하게 될 형태이니, 지금은 "컨테이너의 모든 원소를 순회할 때는 이 문법을 쓴다"는 정도로 기억해두면 충분합니다.

## break와 continue

반복문 안에서 흐름을 제어하는 두 키워드가 있습니다. `break`는 반복문을 즉시 종료하고, `continue`는 현재 반복만 건너뛰고 다음 반복으로 넘어갑니다.

```cpp
// 1부터 20까지 중 처음으로 7의 배수를 만나면 멈춘다
for (int i = 1; i <= 20; i = i + 1) {
    if (i % 7 == 0) {
        std::cout << "7의 배수 발견: " << i << '\n';
        break;
    }
}

// 1부터 10까지 중 짝수만 출력한다
for (int i = 1; i <= 10; i = i + 1) {
    if (i % 2 != 0) {
        continue;  // 홀수면 아래 출력 코드를 건너뛰고 다음 i로
    }
    std::cout << i << " ";
}
std::cout << '\n';
```

`break`와 `continue`는 코드를 짧게 만들어주지만 남용하면 반복문 하나에서 흐름이 여러 갈래로 튀어 읽기 어려워질 수 있습니다. 조건이 복잡해지면 조건식 자체를 명확한 이름의 변수나 함수로 뽑아내는 것도 좋은 방법입니다.

## 중첩 반복문

반복문 안에 또 다른 반복문을 넣을 수 있습니다. 구구단이나 표 형태의 데이터를 다룰 때 자주 나타나는 형태입니다.

```cpp
// 구구단 2단부터 4단까지 출력
for (int table = 2; table <= 4; table = table + 1) {
    for (int i = 1; i <= 9; i = i + 1) {
        std::cout << table << " x " << i << " = " << table * i << '\n';
    }
    std::cout << "----\n";
}
```

바깥쪽 반복문이 한 번 도는 동안 안쪽 반복문은 처음부터 끝까지 전부 실행됩니다. 즉 바깥쪽이 3번, 안쪽이 매번 9번이면 전체 출력 줄 수는 3 x 9 = 27줄입니다. 중첩이 깊어질수록 이런 계산이 헷갈리기 쉬우므로, 반복 변수 이름을 `i`, `j`처럼 짧게만 쓰기보다는 `table`, `row`, `col`처럼 의미를 담은 이름을 쓰는 것이 특히 중첩 반복문에서 도움이 됩니다.

중첩 반복문 안에서 `break`는 자신을 감싸고 있는 가장 안쪽 반복문 하나만 종료시킨다는 점도 기억해야 합니다.

```cpp
bool found = false;
int target = 5;

for (int row = 0; row < 3 && !found; row = row + 1) {
    for (int col = 0; col < 3; col = col + 1) {
        if (row * 3 + col == target) {
            std::cout << "찾음: (" << row << ", " << col << ")\n";
            found = true;
            break;  // 안쪽 for문만 종료된다
        }
    }
}
```

안쪽 `break`만으로는 바깥쪽 반복이 계속되므로, 위 코드처럼 `found`라는 플래그 변수를 두어 바깥쪽 반복문의 조건에도 반영해야 두 반복문을 모두 빠져나올 수 있습니다. 함수 안에서라면 `return`으로 함수 전체를 즉시 빠져나가는 방법이 더 간단할 때도 많습니다.

## 요약

- `while`문은 조건을 먼저 검사하고, `do-while`문은 블록을 최소 한 번 실행한 뒤 조건을 검사합니다.
- `for`문은 초기화·조건·증감을 한곳에 모아 반복 횟수가 명확한 상황에 적합합니다.
- 범위 기반 `for`문(`for (auto& x : container)`)은 배열과 STL 컨테이너를 순회하는 표준 관용구이며, 인덱스 오류를 줄여줍니다.
- `break`는 반복문을 즉시 종료하고, `continue`는 현재 반복만 건너뜁니다.
- 중첩 반복문에서 `break`는 가장 안쪽 반복문만 종료시키므로, 여러 겹을 한 번에 빠져나오려면 플래그 변수나 함수의 `return`을 활용해야 합니다.

## 연습문제

1. `while`문을 사용해 1부터 100까지의 합을 구하는 프로그램을 작성하세요.
2. `do-while`문을 사용해 사용자로부터 "y" 또는 "n"을 입력받고, 그 외의 값이 입력되면 다시 물어보는 프로그램을 작성하세요.
3. `for`문으로 5x5 크기의 별(`*`) 사각형을 출력하는 프로그램을 작성하고, 이를 중첩 `for`문으로 확장해 삼각형 모양으로도 출력해보세요.
4. 정수 배열을 하나 선언하고, 범위 기반 `for`문으로 모든 원소의 합과 평균을 구하는 코드를 작성하세요. (평균을 구할 때는 참조 없이 값으로 순회해도 충분합니다.)
5. 1부터 100까지의 수 중 3의 배수이거나 5의 배수인 수만 출력하되, 두 조건을 모두 만족하는 수(즉 15의 배수)는 `continue`로 건너뛰고 별도로 개수를 세어 마지막에 출력하는 프로그램을 작성하세요.
