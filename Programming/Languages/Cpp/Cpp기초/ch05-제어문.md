지금까지 작성한 프로그램은 위에서 아래로 한 줄씩 순서대로 실행되는 것이 전부였습니다. 하지만 실제 프로그램은 상황에 따라 다른 동작을 해야 합니다. 로그인한 사용자의 나이가 19세 이상인지 확인하거나, 입력한 점수에 따라 학점을 매기거나, 재고가 남았는지 검사하는 일 모두 "조건에 따라 다른 길을 선택"하는 문제입니다. 이 장에서는 4장에서 배운 비교 연산자와 논리 연산자의 결과(`bool` 값)를 이용해 프로그램의 실행 흐름을 분기시키는 방법을 다룹니다.

## if문

`if`문은 가장 단순한 제어문입니다. 괄호 안의 조건식이 `true`이면 뒤따르는 블록을 실행하고, `false`이면 건너뜁니다.

```cpp
#include <iostream>

int main() {
    int temperature = 30;

    if (temperature >= 28) {
        std::cout << "무더운 날씨입니다.\n";
    }

    std::cout << "프로그램 종료\n";
    return 0;
}
```

조건식은 반드시 `bool`로 평가될 수 있는 표현식이어야 합니다. `if (temperature)`처럼 정수를 직접 쓰면 0이 아닌 값은 모두 `true`로 취급되므로, 의도한 비교인지 헷갈릴 수 있습니다. 가독성을 위해서는 `if (temperature != 0)`처럼 비교 연산자를 명시하는 습관을 들이는 것이 좋습니다.

블록이 한 줄뿐이면 중괄호를 생략할 수도 있지만, 이 책에서는 항상 중괄호를 사용하기를 권장합니다. 나중에 코드를 수정하며 줄을 추가했을 때 중괄호가 없으면 의도치 않게 조건에 걸리지 않는 코드가 되는 실수가 아주 흔하기 때문입니다.

## if-else와 else if 사슬

조건이 거짓일 때 실행할 코드는 `else`로 지정합니다.

```cpp
int score = 72;

if (score >= 60) {
    std::cout << "합격\n";
} else {
    std::cout << "불합격\n";
}
```

여러 조건을 순서대로 검사하려면 `else if`를 연결합니다. 학점을 매기는 예제를 봅시다.

```cpp
int score = 85;
char grade;

if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';
} else if (score >= 70) {
    grade = 'C';
} else if (score >= 60) {
    grade = 'D';
} else {
    grade = 'F';
}

std::cout << "학점: " << grade << '\n';
```

`else if` 사슬은 위에서부터 순서대로 검사되며, 처음으로 `true`가 되는 조건의 블록만 실행되고 나머지는 검사조차 하지 않습니다. 그래서 조건 순서가 중요합니다. 만약 `score >= 60`을 맨 위에 두면 90점을 받은 학생도 곧바로 D 이상의 조건에 걸려 "합격"류의 판정만 나오고 A, B, C를 구분할 기회를 잃습니다. 범위를 좁혀가는 조건은 항상 더 좁은(또는 더 엄격한) 조건을 먼저 배치해야 합니다.

## switch문

비교 대상이 하나의 변수이고, 그 변수가 정수형이나 열거형(enum)처럼 몇 가지 정해진 값 중 하나일 때는 `switch`문이 `else if` 사슬보다 의도를 더 명확히 드러냅니다.

```cpp
int day_of_week = 3;

switch (day_of_week) {
    case 1:
        std::cout << "월요일\n";
        break;
    case 2:
        std::cout << "화요일\n";
        break;
    case 3:
        std::cout << "수요일\n";
        break;
    case 6:
    case 7:
        std::cout << "주말입니다.\n";
        break;
    default:
        std::cout << "잘못된 값입니다.\n";
        break;
}
```

`switch`문에서 조심해야 할 부분은 `break`입니다. C++의 `case`는 기본적으로 다음 `case`로 흘러 내려가는(fall-through) 동작을 합니다. `break`를 쓰지 않으면 해당 `case`를 실행한 뒤에도 아래 `case`의 코드가 계속 실행됩니다. 위 예제의 `case 6:`과 `case 7:`처럼 여러 값을 같은 처리로 묶을 때는 이 fall-through를 의도적으로 활용하지만, 그 외의 경우에는 실수로 `break`를 빠뜨리지 않도록 주의해야 합니다. `default`는 어떤 `case`에도 해당하지 않을 때 실행되며, 반드시 있어야 하는 것은 아니지만 예상치 못한 값을 걸러내는 방어 코드로서 넣어두는 습관이 좋습니다.

switch문은 부동소수점이나 문자열(`std::string`)에는 사용할 수 없습니다. 정수, 문자, `enum`/`enum class`(11장에서 다시 다룹니다)만 가능합니다.

## 삼항 연산자

간단한 조건에 따라 값을 하나 고르기만 할 때는 `if-else` 블록 전체를 쓰는 대신 삼항 연산자 `조건 ? 참일때값 : 거짓일때값`을 사용할 수 있습니다.

```cpp
int a = 10, b = 20;
int max_value = (a > b) ? a : b;

std::cout << "더 큰 값: " << max_value << '\n';
```

삼항 연산자는 값을 만들어내는 표현식이므로, 변수 초기화나 함수 호출의 인자 자리에 바로 끼워 넣을 수 있다는 장점이 있습니다.

```cpp
std::cout << "결과: " << (score >= 60 ? "합격" : "불합격") << '\n';
```

다만 조건이나 값 계산이 복잡해지면 삼항 연산자를 중첩해서 쓰지 않는 것이 좋습니다.

```cpp
// 가독성이 떨어지는 예: 어떤 조건이 어떤 결과와 짝지어지는지 한눈에 보기 어렵다.
char grade = (score >= 90) ? 'A' : (score >= 80) ? 'B' : (score >= 70) ? 'C' : 'F';
```

이런 코드는 동작은 하지만 읽는 사람이 우선순위를 다시 계산해야 합니다. 조건이 세 개 이상으로 늘어나면 앞서 본 `else if` 사슬로 바꾸는 편이 훨씬 명확합니다. 삼항 연산자는 "값을 하나 고르는" 아주 단순한 상황에만 쓰는 것이 원칙입니다.

## 중첩 조건문과 가독성

실제 코드에서는 조건문 안에 또 조건문이 들어가는 중첩 구조가 자주 나타납니다.

```cpp
int age = 17;
bool has_parent_consent = true;

if (age >= 18) {
    std::cout << "입장 가능\n";
} else {
    if (has_parent_consent) {
        std::cout << "보호자 동의로 입장 가능\n";
    } else {
        std::cout << "입장 불가\n";
    }
}
```

이 코드는 정확히 동작하지만, 들여쓰기가 깊어질수록 조건들 사이의 관계를 파악하기가 점점 어려워집니다. 조건이 3~4단계로 중첩되면 특히 심해집니다. 이런 경우 논리 연산자(4장)로 조건을 합쳐서 중첩 단계를 줄일 수 있습니다.

```cpp
if (age >= 18 || has_parent_consent) {
    std::cout << "입장 가능\n";
} else {
    std::cout << "입장 불가\n";
}
```

함수(7장에서 자세히 배웁니다) 안에서는 "조건에 맞지 않으면 즉시 반환한다"는 이른 반환(early return) 패턴도 중첩을 줄이는 데 효과적입니다.

```cpp
#include <string>

std::string check_admission(int age, bool has_parent_consent) {
    if (age >= 18) {
        return "입장 가능";
    }
    if (has_parent_consent) {
        return "보호자 동의로 입장 가능";
    }
    return "입장 불가";
}
```

각 조건을 처리한 뒤 바로 함수를 빠져나가므로 `else`가 전혀 필요 없고, 조건들이 나란히 놓여 비교하기도 쉽습니다. 조건문이 복잡해질 것 같으면 "이 조건들을 하나의 논리식으로 합칠 수 있는가", "일찍 반환해서 중첩을 없앨 수 있는가"를 항상 먼저 고민해보기 바랍니다. 이 습관은 18장에서 다룰 좋은 코드 작성 원칙과도 직접 연결됩니다.

## 요약

- `if`, `else if`, `else`는 `bool` 조건에 따라 실행 경로를 분기시키며, `else if` 사슬은 위에서부터 검사하므로 좁은 조건을 먼저 배치해야 합니다.
- `switch`문은 하나의 정수/열거형 변수를 여러 상수 값과 비교할 때 적합하며, fall-through를 막으려면 각 `case`에 `break`를 잊지 말아야 합니다.
- 삼항 연산자 `조건 ? A : B`는 값을 하나 고르는 단순한 상황에만 쓰고, 중첩해서 쓰면 가독성이 떨어집니다.
- 중첩된 조건문은 논리 연산자로 합치거나 이른 반환 패턴을 사용해 들여쓰기 단계를 줄이는 것이 좋습니다.
- 중괄호를 항상 사용하는 습관은 이후 코드 수정 시 발생하는 실수를 줄여줍니다.

## 연습문제

1. 정수 하나를 입력받아 짝수인지 홀수인지, 그리고 양수/음수/0인지를 함께 출력하는 프로그램을 작성하세요.
2. 월(1~12)을 입력받아 `switch`문으로 해당 월이 속한 계절(봄/여름/가을/겨울)을 출력하는 프로그램을 작성하세요. 잘못된 값이 입력되면 `default`에서 오류 메시지를 출력하세요.
3. 세 정수를 입력받아 그중 가장 큰 값을 삼항 연산자만으로 구하는 코드를 작성하세요. (힌트: 삼항 연산자를 두 번만 사용하면 충분합니다.)
4. 나이와 학생 여부(bool)를 입력받아 영화 요금을 결정하는 코드를 중첩 `if`로 작성한 뒤, 논리 연산자와 이른 반환을 사용한 버전으로 다시 작성하고 두 버전을 비교해보세요.
5. `case`의 `break`를 실수로 빠뜨렸을 때 어떤 결과가 나오는지 직접 코드를 작성해 확인하고, 왜 그런 결과가 나오는지 설명해보세요.
