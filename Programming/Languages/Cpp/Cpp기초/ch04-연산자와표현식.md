# 4장. 연산자와 표현식

3장에서는 값을 담는 변수와 자료형을 배웠습니다. 이번 장에서는 그 값들을 가지고 실제로 무언가를 계산하는 **연산자(operator)**와, 연산자와 값이 결합되어 하나의 값을 만들어내는 **표현식(expression)**을 알아봅니다. C++는 C의 연산자 체계를 거의 그대로 물려받았지만, 12장에서 배우게 될 연산자 오버로딩을 통해 사용자가 만든 타입에도 연산자의 의미를 새로 정의할 수 있다는 점이 C와 크게 다른 부분입니다. 이번 장에서는 우선 기본 타입에 대한 연산자의 동작을 정확히 이해하는 데 집중합니다.

## 산술 연산자

가장 기본적인 연산자는 사칙연산과 나머지 연산입니다.

```cpp
#include <iostream>

int main() {
    int a = 17;
    int b = 5;

    std::cout << "a + b = " << a + b << std::endl;   // 22
    std::cout << "a - b = " << a - b << std::endl;   // 12
    std::cout << "a * b = " << a * b << std::endl;   // 85
    std::cout << "a / b = " << a / b << std::endl;   // 3 (정수 나눗셈)
    std::cout << "a % b = " << a % b << std::endl;   // 2 (나머지)
    return 0;
}
```

여기서 가장 중요한 함정은 **정수 나눗셈**입니다. `int`를 `int`로 나누면 결과도 `int`이므로 소수점 이하는 그대로 버려집니다. 3장에서 살펴본 것처럼, 실수 결과를 원한다면 피연산자 중 하나를 `static_cast<double>`로 명시적으로 변환해야 합니다.

```cpp
double avg = static_cast<double>(a) / b;   // 3.4
```

`%` 연산자는 정수형에만 사용할 수 있으며, `double`이나 `float`에는 적용되지 않습니다(실수의 나머지를 구하려면 `<cmath>`의 `std::fmod`를 사용합니다). 또한 음수가 포함된 나머지 연산의 결과는 C++11부터 표준화되었는데, 나눗셈의 결과가 0을 향해 잘리도록(truncation toward zero) 정해져 있어서 `-7 % 3`은 `-1`이 됩니다.

## 관계 연산자와 논리 연산자

값을 비교하고 조건을 조합할 때는 관계 연산자와 논리 연산자를 사용합니다. 이 연산자들의 결과는 모두 `bool` 타입입니다.

```cpp
int x = 10;
int y = 20;

bool is_equal = (x == y);       // false
bool is_less = (x < y);          // true
bool is_greater_eq = (x >= y);  // false

bool both = (x < y) && (y > 0);   // 논리 AND
bool either = (x < 0) || (y > 0);  // 논리 OR
bool negated = !is_equal;          // 논리 NOT, true
```

`==`(같음)와 `=`(대입)을 혼동하지 않도록 주의해야 합니다. `if (x = 5)`처럼 실수로 대입을 쓰면, 컴파일러가 경고를 낼 수는 있지만 문법적으로는 유효한 코드이기 때문에 컴파일이 되어버립니다. 이런 문제는 5장에서 배울 `if`문에서도 흔히 발생하는 실수이니 미리 기억해 두면 좋습니다.

논리 연산자 `&&`와 `||`는 **단축 평가(short-circuit evaluation)**를 수행합니다. 즉 `&&`의 왼쪽이 `false`이면 오른쪽은 평가하지 않고 바로 `false`를 반환하며, `||`의 왼쪽이 `true`이면 오른쪽을 평가하지 않고 바로 `true`를 반환합니다. 이 성질은 실무에서 자주 활용됩니다.

```cpp
int* ptr = nullptr;
// ptr이 nullptr이면 뒤의 조건은 평가되지 않아 안전함
if (ptr != nullptr && *ptr > 0) {
    std::cout << "양수입니다." << std::endl;
}
```

포인터와 `nullptr`은 8장과 9장에서 자세히 다루므로, 지금은 단축 평가가 왜 유용한지 감을 잡는 정도로 충분합니다.

## 비트 연산자

정수를 이진수로 다룰 때 사용하는 비트 연산자도 C++에 존재합니다.

```cpp
unsigned int a = 0b1010;   // 10
unsigned int b = 0b0110;   //  6

std::cout << (a & b) << std::endl;   // AND: 0b0010 = 2
std::cout << (a | b) << std::endl;   // OR:  0b1110 = 14
std::cout << (a ^ b) << std::endl;   // XOR: 0b1100 = 12
std::cout << (~a) << std::endl;      // NOT: 비트 반전
std::cout << (a << 1) << std::endl;   // 왼쪽 시프트: 0b10100 = 20
std::cout << (a >> 1) << std::endl;   // 오른쪽 시프트: 0b0101 = 5
```

비트 연산자는 논리 연산자와 겉모습이 비슷하지만(`&` vs `&&`, `|` vs `||`) 전혀 다른 일을 합니다. 논리 연산자는 `bool` 값 전체를 다루고, 비트 연산자는 정수의 각 비트를 다룹니다. 이 두 종류를 혼동하면 찾기 어려운 버그로 이어지므로 항상 구분해서 사용해야 합니다.

## 대입 연산자와 복합 대입 연산자

값을 변수에 저장하는 `=` 외에도, 연산과 대입을 한 번에 처리하는 복합 대입 연산자들이 있습니다.

```cpp
int score = 10;
score += 5;    // score = score + 5;  -> 15
score -= 3;    // -> 12
score *= 2;    // -> 24
score /= 4;    // -> 6
score %= 4;    // -> 2

int flags = 0b0011;
flags &= 0b0010;
flags |= 0b0100;
flags ^= 0b0001;
```

복합 대입 연산자는 코드를 짧게 만들 뿐 아니라, 12장에서 사용자 정의 타입에 연산자를 오버로딩할 때도 `+=` 같은 연산자를 함께 정의해 두면 일관성 있는 사용 경험을 제공할 수 있습니다.

## 증감 연산자: 전위와 후위

값을 1씩 늘리거나 줄이는 `++`, `--`는 사용 위치에 따라 동작이 달라집니다.

```cpp
int i = 5;
int a = ++i;   // 전위(prefix): i를 먼저 6으로 증가시킨 뒤 그 값을 a에 대입 -> a = 6, i = 6
int j = 5;
int b = j++;   // 후위(postfix): j의 현재 값 5를 b에 먼저 대입한 뒤 j를 6으로 증가 -> b = 5, j = 6
```

전위 증감은 "먼저 바꾸고 그 결과를 사용"하고, 후위 증감은 "원래 값을 먼저 사용하고 나서 바꾸는" 차이가 있습니다. 두 연산 모두 최종적으로 변수의 값은 6이 되지만, 표현식 전체의 값이 다르다는 점이 핵심입니다. 이 차이는 6장에서 배울 반복문에서 `for (int i = 0; i < n; ++i)`처럼 자주 등장하므로 정확히 이해해 두는 것이 중요합니다. 일반적으로 반복문의 증감처럼 결과 값을 따로 쓰지 않는 경우에는 전위 증감(`++i`)을 사용하는 것이 관례이며, 사용자 정의 타입에서는 성능상으로도 전위 증감이 약간 더 유리한 경우가 많습니다(이는 12장, 17장에서 더 자세히 다룰 내용입니다).

## 조건 연산자(삼항 연산자)

`if`-`else`를 표현식 하나로 압축할 수 있는 조건 연산자 `?:`도 있습니다.

```cpp
int a = 10;
int b = 20;
int max_value = (a > b) ? a : b;    // a가 b보다 크면 a, 아니면 b -> 20
```

이 연산자는 조건에 따라 두 값 중 하나를 "선택하는 표현식"이라는 점에서, 문장 단위로 분기하는 `if`문(5장)과는 성격이 다릅니다. 짧은 값 선택에는 유용하지만, 조건이 복잡해지면 가독성이 떨어지므로 남용하지 않는 것이 좋습니다.

## 연산자 우선순위와 결합 방향

한 표현식에 여러 연산자가 섞여 있으면, 어떤 연산을 먼저 계산할지가 결과에 큰 영향을 줍니다. 예를 들어 다음 표현식을 봅시다.

```cpp
int result = 2 + 3 * 4;      // 곱셈이 더하기보다 우선순위가 높아 14
int result2 = (2 + 3) * 4;   // 괄호로 우선순위를 바꿔 20
bool cond = 1 < 2 && 3 > 2;   // 관계 연산자가 논리 연산자보다 우선순위가 높아
                                 // (1 < 2) && (3 > 2)로 해석됨 -> true
```

C++의 연산자는 산술, 비트, 관계, 논리, 대입 등 종류에 따라 세밀한 우선순위 규칙과, 왼쪽에서 오른쪽(left-to-right) 또는 오른쪽에서 왼쪽(right-to-left)으로 계산하는 결합 방향(associativity)을 가지고 있습니다. 예를 들어 대입 연산자는 오른쪽에서 왼쪽으로 결합하기 때문에 `a = b = 5;`는 `a = (b = 5);`로 해석되어 `b`와 `a`가 모두 5가 됩니다.

모든 연산자의 우선순위 표를 외울 필요는 없습니다. 실무에서는 우선순위가 헷갈릴 만한 상황이라면 주저 없이 괄호를 사용해 의도를 명확히 드러내는 것이 훨씬 안전하고, 코드를 읽는 사람에게도 친절한 방법입니다. 전체 연산자 우선순위 표는 이 책의 부록에서 확인할 수 있으니, 헷갈릴 때마다 참고하시기 바랍니다.

## 표현식이란 무엇인가

지금까지 살펴본 연산자들이 피연산자와 결합되어 만들어지는 것이 바로 표현식입니다. 표현식은 평가되면 항상 하나의 값(과 타입)을 만들어냅니다.

```cpp
int x = 5;
int y = (x + 3) * 2 - 1;   // 전체가 하나의 표현식이며, 평가 결과는 15
```

표현식은 값을 만들어내는 것에 그치지만, `;`을 붙여 완성한 `y = ...;` 같은 것은 하나의 **문장(statement)**이 됩니다. 이 구분은 5장과 6장에서 제어문과 반복문을 배울 때 다시 등장합니다. 제어문은 표현식의 값(대개 `bool`로 변환된 값)을 이용해 프로그램의 흐름을 결정하기 때문입니다.

## 앞으로 배울 것: 연산자를 직접 정의하기

지금까지 다룬 연산자들은 모두 `int`, `double`, `bool`처럼 언어에 내장된 기본 타입에 대해 정의되어 있는 것들입니다. 그런데 10장에서 클래스를 배우고 나면, 우리가 직접 만든 타입(예를 들어 좌표를 나타내는 `Point`나 분수를 나타내는 `Fraction`)에 대해서도 `+`, `==`, `<<` 같은 연산자가 자연스럽게 동작하도록 만들고 싶어질 것입니다. C++는 이것을 가능하게 해주는 **연산자 오버로딩(operator overloading)**이라는 기능을 제공합니다. 12장에서는 이 기능을 이용해 사용자 정의 타입끼리 `+`로 더하거나 `<<`로 출력하는 방법을 배우게 됩니다. 지금 이 장에서 배운 연산자의 기본 문법과 의미를 정확히 알아두면, 12장에서 "왜 이런 문법으로 연산자를 새로 정의하는지"를 훨씬 쉽게 이해할 수 있습니다.

## 요약

이번 장에서는 C++의 다양한 연산자들을 살펴보았습니다. 산술 연산자에서는 정수 나눗셈이 소수점을 버린다는 점과, 실수 결과를 얻으려면 `static_cast`로 형변환해야 한다는 점이 중요했습니다. 관계 연산자와 논리 연산자는 모두 `bool` 값을 만들어내며, `&&`와 `||`는 단축 평가를 수행합니다. 비트 연산자는 논리 연산자와 기호가 비슷하지만 완전히 다른 동작을 하므로 구분해서 사용해야 합니다. 복합 대입 연산자는 연산과 대입을 한 번에 처리해 코드를 간결하게 만들며, 전위/후위 증감 연산자는 값이 언제 바뀌는지에 따라 표현식의 결과가 달라집니다. 여러 연산자가 섞인 표현식에서는 우선순위와 결합 방향이 결과를 결정하므로, 헷갈릴 때는 괄호를 적극적으로 사용하는 것이 안전합니다. 마지막으로, 이 장에서 배운 연산자들은 모두 기본 타입에 대한 것이었지만, 12장에서는 우리가 만든 클래스에도 이런 연산자의 의미를 직접 정의하는 연산자 오버로딩을 배우게 됩니다. 다음 장에서는 이 연산자들이 만들어내는 조건 값을 이용해 프로그램의 흐름을 분기시키는 제어문을 알아보겠습니다.

   ```cpp
   int i = 3;
   ```
