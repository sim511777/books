## 배열의 한계를 다시 떠올려 보기

8장에서 배열을 배우면서 두 가지 불편함을 이미 느꼈을 것입니다. 첫째, 배열의 크기는 선언할 때 고정되어야 하고, 프로그램을 실행하는 도중에 늘리거나 줄일 수 없습니다. 둘째, 배열 자체는 자신의 크기를 기억하지 못하기 때문에 `int scores[10]`을 함수에 넘기면 그 함수는 배열의 길이를 별도로 전달받아야만 알 수 있습니다.

```cpp
int scores[5] = {90, 85, 100, 70, 60};
// scores.length() 같은 건 없다. 크기를 따로 관리해야 한다.
```

13장에서 배운 템플릿은 바로 이런 문제를 해결하는 도구입니다. C++ 표준 라이브러리는 템플릿으로 미리 만들어 둔 다양한 자료구조를 제공하는데, 이를 통틀어 **STL(Standard Template Library)** 이라고 부릅니다. 이번 장에서는 그중 가장 자주 쓰이는 네 가지, `std::vector`, `std::string`, `std::map`, `std::set`을 살펴봅니다.

## std::vector: 크기가 자유로운 배열

`std::vector<T>`는 배열과 같은 역할을 하면서도 원소를 추가할 때마다 크기가 자동으로 늘어나는 컨테이너입니다. `<vector>` 헤더를 포함하면 사용할 수 있습니다.

```cpp
#include <vector>
#include <iostream>

int main() {
    std::vector<int> scores;   // 처음에는 비어 있다.

    scores.push_back(90);      // 뒤에 원소 추가
    scores.push_back(85);
    scores.push_back(100);

    std::cout << "원소 개수: " << scores.size() << '\n';
    std::cout << "첫 번째 점수: " << scores[0] << '\n';
    std::cout << "안전하게 접근: " << scores.at(1) << '\n';
}
```

`push_back`은 벡터 끝에 새 원소를 추가합니다. `size()`는 현재 저장된 원소 개수를 반환하며, 배열과 달리 이 값을 따로 들고 다닐 필요가 없습니다. 원소에 접근할 때는 배열처럼 `scores[0]`을 쓸 수도 있고, `scores.at(1)`처럼 범위를 벗어나면 예외를 던져 주는 안전한 방법을 쓸 수도 있습니다(예외는 16장에서 자세히 다룹니다). `{90, 85, 100}`처럼 초기값을 바로 넣어 선언하는 것도 가능합니다.

```cpp
std::vector<int> temps = {23, 25, 21, 19};
```

벡터는 `pop_back()`으로 마지막 원소를 제거하거나, `empty()`로 비어 있는지 확인하는 등 다양한 멤버 함수를 제공합니다. 8장의 배열이 "크기가 정해진 상자"였다면, 벡터는 "필요할 때마다 스스로 커지는 상자"라고 생각하면 됩니다.

## std::string: 문자 배열 대신 쓰는 문자열

3장에서 문자열을 다룰 때 C 스타일 문자 배열(`char name[20]`)의 불편함을 겪어 보았을 것입니다. 크기를 미리 정해야 하고, 문자열을 합치거나 비교하려면 별도의 함수를 호출해야 합니다. `std::string`은 이런 문제를 해결하는, 문자를 원소로 갖는 컨테이너입니다.

```cpp
#include <string>
#include <iostream>

int main() {
    std::string first_name = "eunji";
    std::string last_name = "kim";

    std::string full_name = last_name + " " + first_name;  // + 로 결합
    std::cout << full_name << '\n';
    std::cout << "길이: " << full_name.length() << '\n';

    if (full_name.find("eunji") != std::string::npos) {
        std::cout << "이름을 찾았다.\n";
    }

    std::string first_word = full_name.substr(0, 3);  // 앞 3글자
    std::cout << first_word << '\n';
}
```

`+` 연산자로 문자열을 이어 붙이고, `==`로 비교할 수 있으며, `length()`(또는 `size()`)로 길이를 얻습니다. `find`는 부분 문자열의 위치를 찾아 주고, 찾지 못하면 `std::string::npos`라는 특별한 값을 반환합니다. `substr(위치, 길이)`는 일부분을 잘라낸 새 문자열을 만들어 줍니다. 사실 `std::string`도 문자(`char`)를 저장하는 컨테이너의 일종이어서, 뒤에서 배울 반복자로 한 글자씩 순회할 수도 있습니다.

## std::map: 키와 값의 짝

`std::map<K, V>`는 13장에서 만들어 본 `Pair<K, V>`처럼 키와 값을 짝지어 저장하지만, 여러 쌍을 저장하면서 키로 값을 빠르게 찾아내는 데 특화된 컨테이너입니다. 내부적으로 키는 항상 정렬된 상태로 유지됩니다.

```cpp
#include <map>
#include <iostream>
#include <string>

int main() {
    std::map<std::string, int> age_of;

    age_of["minjun"] = 17;      // 없으면 새로 추가, 있으면 값을 덮어씀
    age_of["seoyeon"] = 16;
    age_of.insert({"jihoo", 18});

    std::cout << age_of["minjun"] << '\n';

    auto it = age_of.find("seoyeon");
    if (it != age_of.end()) {
        std::cout << it->first << "의 나이: " << it->second << '\n';
    }
}
```

`map`은 `[]` 연산자로 키에 해당하는 값을 읽거나 쓸 수 있습니다. 다만 존재하지 않는 키에 `[]`로 접근하면 자동으로 그 키가 기본값과 함께 새로 만들어진다는 점을 주의해야 합니다. 단순히 있는지 확인만 하고 싶다면 `find`를 사용하는 편이 안전합니다. `find`는 찾은 위치(반복자)를 반환하며, 찾지 못하면 `end()`와 같은 값을 반환합니다.

## std::set: 중복 없는 값의 모음

`std::set<T>`는 값 하나만 저장한다는 점에서 `map`과 다르지만, 원리는 비슷합니다. 같은 값을 두 번 넣어도 하나만 남고, 저장된 값은 항상 정렬됩니다.

```cpp
#include <set>
#include <iostream>

int main() {
    std::set<int> unique_ids;

    unique_ids.insert(3);
    unique_ids.insert(1);
    unique_ids.insert(3);   // 이미 있으므로 무시됨
    unique_ids.insert(2);

    std::cout << "원소 개수: " << unique_ids.size() << '\n';  // 3

    if (unique_ids.find(2) != unique_ids.end()) {
        std::cout << "2가 존재한다.\n";
    }
}
```

명단에서 중복을 제거하거나, 어떤 값이 이미 등장했는지 빠르게 확인해야 할 때 `set`이 유용합니다.

## 반복자와 범위 기반 for문

지금까지 각 컨테이너를 개별 함수로 다뤘지만, 컨테이너에 담긴 모든 원소를 순서대로 훑어보려면 **반복자(iterator)** 라는 개념이 필요합니다. 반복자는 컨테이너 안의 한 위치를 가리키는 객체로, 9장에서 배운 포인터와 비슷하게 동작합니다. `begin()`은 첫 원소를, `end()`는 "마지막 원소 다음" 위치를 가리키는 반복자를 반환합니다.

```cpp
std::vector<int> temps = {23, 25, 21, 19};

for (auto it = temps.begin(); it != temps.end(); ++it) {
    std::cout << *it << ' ';   // *it 로 현재 위치의 값을 얻는다.
}
```

이 코드는 정확히 동작하지만 매번 반복자를 손으로 다루는 일은 번거롭습니다. 6장에서 배운 범위 기반 for문(`for (auto x : container)`)은 사실 내부적으로 정확히 이 `begin()`/`end()` 반복자를 사용해서 동작하는 문법입니다. 즉, 범위 기반 for문은 반복자를 감춰 주는 더 편리한 표현일 뿐입니다.

```cpp
for (int t : temps) {
    std::cout << t << ' ';
}

for (const auto& [name, age] : age_of) {   // map은 {키, 값} 쌍으로 순회
    std::cout << name << ": " << age << '\n';
}

for (char c : full_name) {   // string도 문자 단위로 순회 가능
    std::cout << c;
}
```

`map`을 순회하면 각 원소가 `std::pair<const K, V>` 형태로 나오므로, 구조분해 선언(`auto& [name, age]`)을 쓰면 키와 값을 바로 분리해서 받을 수 있어 편리합니다. `vector`, `string`, `set`, `map` 모두 같은 방식으로 순회할 수 있다는 점이 반복자 개념의 힘입니다. 컨테이너의 내부 구조는 서로 다르지만, `begin()`과 `end()`를 갖춘 이상 똑같은 문법으로 다룰 수 있는 것입니다.

## 어떤 컨테이너를 언제 쓸까

네 가지 컨테이너는 각각 뚜렷한 용도가 있습니다.

- **순서가 있고 인덱스로 접근할 자료의 목록**이 필요하면 `std::vector`를 쓴다. 대부분의 경우 배열 대신 기본으로 선택하는 컨테이너다.
- **문자로 이루어진 텍스트**를 다룬다면 `std::string`을 쓴다.
- **이름이나 식별자 같은 키로 값을 찾아야** 한다면 `std::map`을 쓴다. 예를 들어 학생 이름으로 점수를 찾는 경우다.
- **중복을 자동으로 제거하면서 존재 여부만 빠르게 확인**하고 싶다면 `std::set`을 쓴다.

무엇을 쓸지 고민될 때는 "이 데이터에 순서가 중요한가, 키로 검색해야 하는가, 중복이 허용되는가"라는 세 가지 질문을 던져 보면 대체로 답이 나옵니다. 15장에서 다룰 스마트 포인터나 17장의 이동 시맨틱스도 결국 이런 컨테이너들이 메모리를 안전하고 효율적으로 관리하도록 뒷받침하는 개념이므로, 지금 익힌 벡터와 맵 사용법은 이후 장에서도 계속 등장합니다.

## 요약

- `std::vector`는 크기가 자동으로 늘어나는 배열로, 8장 배열의 크기 고정 문제를 해결한다.
- `std::string`은 문자를 담는 컨테이너로, `+`, `find`, `substr` 등 문자열 조작에 특화된 메서드를 제공한다.
- `std::map`은 키-값 쌍을 저장하며 키로 값을 빠르게 검색할 때 사용한다.
- `std::set`은 중복을 허용하지 않는 값의 모음으로, 존재 여부 확인과 중복 제거에 적합하다.
- 반복자는 컨테이너의 한 위치를 가리키는 객체이며, 6장의 범위 기반 for문은 내부적으로 `begin()`/`end()` 반복자를 사용한다.

## 연습문제

1. 정수를 입력받아 `std::vector<int>`에 계속 추가하다가, 사용자가 음수를 입력하면 멈추고 지금까지 입력된 값의 합과 평균을 출력하는 프로그램을 작성하시오.
2. `std::string`으로 문장을 입력받아, 공백을 기준으로 단어 개수를 세는 프로그램을 작성하시오. (힌트: `find`와 `substr`을 반복 사용한다.)
3. 학생 이름과 점수를 `std::map<std::string, int>`에 5명 저장한 뒤, 범위 기반 for문으로 전체 목록을 "이름: 점수" 형식으로 출력하시오.
4. 정수 배열에서 중복된 값을 제거한 목록을 얻고 싶을 때 `std::set`을 활용하는 방법을 설명하고, 실제로 `{4, 2, 4, 1, 2, 5}`를 중복 없이 정렬된 형태로 출력하는 코드를 작성하시오.
5. `std::vector<int>`를 반복자를 이용한 `for` 문과 범위 기반 `for` 문 두 가지 방식으로 각각 순회하는 코드를 작성하고, 두 방식이 내부적으로 어떻게 연결되는지 설명하시오.
