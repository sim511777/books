지금까지 작성한 프로그램은 `main` 함수 하나에 모든 코드를 담았습니다. 프로그램이 조금만 복잡해져도 이런 방식은 금방 한계에 부딪힙니다. 같은 계산을 여러 번 반복해야 한다면 코드를 그대로 복사해 붙여넣어야 하고, 나중에 로직을 수정할 때는 복사한 곳마다 빠짐없이 고쳐야 합니다. **함수(function)**는 이런 문제를 해결하기 위한 도구입니다. 반복되는 작업을 이름이 붙은 하나의 단위로 묶어두면, 필요할 때마다 그 이름을 불러 사용할 수 있습니다.

## 함수란 무엇인가

함수는 특정 작업을 수행하는 코드 블록에 이름을 붙인 것입니다. 입력값(매개변수)을 받아 어떤 처리를 하고, 결과값(반환값)을 돌려줄 수 있습니다. 수학에서 `f(x) = x * x`라는 함수가 입력 `x`를 받아 `x*x`를 돌려주는 것과 비슷한 개념입니다.

함수를 사용하면 다음과 같은 장점이 있습니다.

- **재사용성**: 한 번 작성한 코드를 여러 곳에서 호출해 사용할 수 있습니다.
- **가독성**: `main` 함수가 짧아지고, 함수 이름만으로 무슨 일을 하는지 짐작할 수 있습니다.
- **유지보수**: 로직을 수정할 때 함수 내부만 고치면 되므로 실수가 줄어듭니다.

## 함수 정의와 호출

함수를 정의하는 기본 형식은 다음과 같습니다.

```cpp
반환형 함수이름(매개변수 목록) {
    // 함수 본문
    return 반환값;
}
```

간단한 예를 보겠습니다.

```cpp
#include <iostream>

// 두 정수를 더해서 반환하는 함수
int add(int a, int b) {
    int result = a + b;
    return result;
}

int main() {
    int sum = add(3, 4);  // add 함수를 호출
    std::cout << "합계: " << sum << std::endl;
    return 0;
}
```

`add`라는 이름의 함수는 `int` 타입 매개변수 `a`, `b`를 받아 `int` 타입 값을 반환합니다. `main` 함수에서 `add(3, 4)`처럼 함수 이름 뒤에 괄호를 붙여 **호출(call)**하면, 괄호 안의 값이 매개변수에 전달되고 함수 본문이 실행됩니다.

함수는 반드시 사용하기 전에 컴파일러에게 그 존재를 알려야 합니다. 작은 프로그램에서는 함수를 사용하는 위치보다 위에 정의해두면 되지만, 여러 함수가 서로를 호출하거나 파일이 커지면 **함수 선언(declaration)**을 미리 해두고 정의는 나중에 두는 방식을 씁니다.

```cpp
int add(int a, int b);  // 선언(프로토타입): 본문 없이 형태만 알려줌

int main() {
    std::cout << add(1, 2) << std::endl;
    return 0;
}

int add(int a, int b) {  // 정의: 실제 동작을 구현
    return a + b;
}
```

선언은 함수의 "이름표"만 미리 붙여두는 것이고, 정의는 실제 내용을 채우는 것입니다. 헤더 파일을 나눠 프로젝트를 구성할 때는 이 구분이 매우 중요해지는데, 이 내용은 2장에서 다룬 빌드 과정과도 맞닿아 있습니다.

## 매개변수와 반환값

함수는 0개 이상의 매개변수를 받을 수 있고, 반환값이 없을 수도 있습니다. 반환값이 없는 함수는 반환형으로 `void`를 씁니다.

```cpp
// 반환값이 없는 함수: 화면에 출력만 하고 끝난다
void print_greeting(std::string name) {
    std::cout << name << "님, 안녕하세요!" << std::endl;
    // return;  void 함수는 return을 생략해도 되고, 값 없이 return만 써도 된다
}
```

함수 안에서 선언한 변수는 그 함수가 끝나면 사라집니다. 이를 변수의 **지역성(local scope)**이라고 부릅니다. `add` 함수 안의 `result`는 `add`가 끝나는 순간 소멸하며, `main`에서는 `result`라는 이름에 접근할 수 없습니다.

지금까지 본 예제들은 매개변수로 값을 넘길 때 **값에 의한 전달(pass by value)** 방식을 사용했습니다. 즉 `add(3, 4)`를 호출하면 `3`과 `4`라는 값이 복사되어 매개변수 `a`, `b`에 각각 저장됩니다. 함수 내부에서 `a`나 `b`를 바꾸더라도 호출한 쪽의 원본 변수에는 아무 영향이 없습니다.

```cpp
void try_to_change(int x) {
    x = 100;  // 이 변경은 복사본에만 적용된다
}

int main() {
    int value = 5;
    try_to_change(value);
    std::cout << value << std::endl;  // 여전히 5가 출력된다
    return 0;
}
```

만약 함수가 원본 변수 자체를 바꾸도록 하려면 어떻게 해야 할까요? 이때 필요한 것이 **참조에 의한 전달(pass by reference)**입니다. 참조는 9장에서 자세히 다루지만, 지금은 값에 의한 전달이 "복사본을 넘기는 것"이라는 점만 기억해두면 충분합니다. 참조를 사용하면 복사 없이 원본 변수를 직접 다룰 수 있어, 큰 데이터를 다룰 때 성능상 이점도 얻게 됩니다.

## 함수 오버로딩

C++에서는 같은 이름의 함수를 매개변수의 개수나 타입이 다르게 여러 개 정의할 수 있습니다. 이를 **함수 오버로딩(function overloading)**이라고 합니다.

```cpp
int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}

int add(int a, int b, int c) {
    return a + b + c;
}
```

컴파일러는 함수를 호출할 때 넘겨준 인자의 타입과 개수를 보고 어떤 `add`를 호출할지 자동으로 결정합니다. `add(1, 2)`는 첫 번째 `add`를, `add(1.5, 2.5)`는 두 번째 `add`를, `add(1, 2, 3)`은 세 번째 `add`를 호출합니다. 오버로딩 덕분에 "정수를 더한다"와 "실수를 더한다"처럼 개념적으로 같은 동작을 하나의 이름으로 표현할 수 있습니다.

단, 반환형만 다르고 매개변수 목록이 완전히 같은 함수는 오버로딩으로 인정되지 않습니다. 컴파일러는 호출 시점에 인자만 보고 함수를 구별하기 때문입니다.

## 기본값 매개변수

함수를 선언할 때 매개변수에 **기본값(default argument)**을 지정할 수 있습니다. 호출할 때 해당 인자를 생략하면 기본값이 사용됩니다.

```cpp
// height를 생략하면 기본값 10이 사용된다
int calculate_area(int width, int height = 10) {
    return width * height;
}

int main() {
    std::cout << calculate_area(5) << std::endl;      // 5 * 10 = 50
    std::cout << calculate_area(5, 3) << std::endl;    // 5 * 3 = 15
    return 0;
}
```

기본값은 매개변수 목록의 뒤쪽부터 채워야 합니다. 즉 기본값이 있는 매개변수 뒤에 기본값이 없는 매개변수가 올 수 없습니다.

```cpp
// 잘못된 예: 컴파일 오류
// int wrong(int a = 1, int b);

// 올바른 예
int correct(int a, int b = 1);
```

## 인라인 함수 간단 소개

함수를 호출하면 실제로는 프로그램 실행 흐름이 함수 코드로 "점프"했다가 다시 돌아오는 비용이 발생합니다. 아주 짧고 자주 호출되는 함수라면 이 비용이 상대적으로 부담이 될 수 있습니다. `inline` 키워드는 컴파일러에게 "이 함수를 호출하는 대신 호출 지점에 코드를 그대로 펼쳐 넣어도 좋다"는 힌트를 줍니다.

```cpp
inline int square(int x) {
    return x * x;
}
```

`inline`은 강제 명령이 아니라 권고 사항이며, 최신 컴파일러는 `inline` 표시가 없어도 필요하다고 판단하면 스스로 함수를 인라인 처리하기도 합니다. 지금 단계에서는 "짧은 함수를 반복 호출할 때 호출 비용을 줄이는 방법이 있다"는 개념만 기억해두면 충분합니다. 성능을 본격적으로 다루는 내용은 이후 장에서 더 넓은 맥락으로 다시 만나게 됩니다.

## 요약

이 장에서는 함수의 기본 개념을 살펴보았습니다. 함수는 코드를 이름 붙은 단위로 묶어 재사용성과 가독성을 높여줍니다. 함수는 선언과 정의로 나눌 수 있으며, 매개변수를 통해 값을 받고 `return`으로 결과를 돌려줍니다. 매개변수는 기본적으로 값에 의한 전달 방식으로 동작해 호출자의 원본 데이터를 바꾸지 못하는데, 이는 9장에서 배울 참조 전달과 대조적입니다. 같은 이름의 함수를 여러 형태로 정의하는 함수 오버로딩과, 인자를 생략할 수 있게 하는 기본값 매개변수는 함수 사용을 더 유연하게 만들어 줍니다. 마지막으로 `inline` 키워드를 통해 짧은 함수의 호출 비용을 줄이는 방법도 간단히 살펴보았습니다.

## 연습문제

1. 두 개의 `double` 값을 받아 더 큰 값을 반환하는 `get_max` 함수를 작성하세요.
2. 매개변수로 정수 배열의 시작 주소 대신, 정수 세 개를 받아 평균을 반환하는 함수 `average`를 오버로딩으로 두 개(정수 두 개용, 정수 세 개용) 작성해보세요.
3. `void greet(std::string name = "손님")` 함수를 작성하고, 인자를 생략했을 때와 전달했을 때 각각 호출해 결과를 확인하세요.
4. 값에 의한 전달을 사용하는 함수에서 매개변수 값을 바꿔도 호출자의 변수가 바뀌지 않는 것을 직접 코드로 확인하고, 왜 그런 결과가 나오는지 설명해보세요.
5. 함수 선언과 정의를 분리해 작성하고, `main` 함수보다 뒤에 정의를 두어도 정상적으로 컴파일되는지 확인해보세요.
