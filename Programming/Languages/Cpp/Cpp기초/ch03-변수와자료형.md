# 3장. 변수와 자료형

앞 장에서 우리는 첫 C++ 프로그램을 작성하고 빌드하는 과정을 살펴보았습니다. 이제 프로그램이 데이터를 어떻게 담고 다루는지, 그 가장 기본적인 단위인 **변수(variable)**와 **자료형(type)**을 알아볼 차례입니다. C++는 정적 타입 언어이기 때문에, 변수가 어떤 종류의 값을 담을지 컴파일 시점에 결정됩니다. 이 점을 이해하는 것이 앞으로 배울 모든 문법의 토대가 됩니다.

## 변수란 무엇인가

변수는 메모리의 한 조각에 이름을 붙여 놓은 것입니다. 프로그램이 실행되는 동안 그 이름을 통해 값을 저장하고, 읽고, 바꿀 수 있습니다. C++에서 변수를 선언하려면 자료형과 이름을 함께 적습니다.

```cpp
#include <iostream>

int main() {
    int age;          // 선언만 한 상태, 값은 정해지지 않음(초기화되지 않음)
    age = 25;          // 대입으로 값을 넣음

    int score = 90;    // 선언과 동시에 초기화

    std::cout << "age: " << age << ", score: " << score << std::endl;
    return 0;
}
```

여기서 주의할 점이 있습니다. `int age;`처럼 선언만 하고 초기화하지 않으면 `age`에는 쓰레기 값(이전에 그 메모리에 남아 있던 임의의 값)이 들어 있습니다. C++는 지역 변수를 자동으로 0으로 초기화해 주지 않기 때문에, 초기화하지 않은 변수를 읽으면 정의되지 않은 동작(undefined behavior)이 발생할 수 있습니다. 습관적으로 변수를 선언할 때 바로 초기화하는 것이 좋습니다.

## 초기화 방법 여러 가지

C++는 변수를 초기화하는 방법이 한 가지가 아닙니다. 오래된 C 스타일부터 C++11 이후 등장한 중괄호 초기화까지 여러 형태가 존재합니다.

```cpp
int a = 10;        // 대입식 초기화 (복사 초기화)
int b(10);         // 함수 스타일(직접) 초기화
int c{10};          // 중괄호 초기화 (C++11, uniform initialization)
int d{};            // 중괄호로 0 초기화
```

이 중에서 중괄호 초기화(`{}`)는 실수로 값이 깎이는 좁아지는 변환(narrowing conversion)을 막아준다는 장점이 있습니다. 예를 들어 다음 코드는 컴파일 오류 또는 경고를 냅니다.

```cpp
int e{3.14};   // 오류: double 값 3.14를 int로 좁히는 초기화는 허용되지 않음
int f = 3.14;   // 컴파일은 되지만 소수점 아래가 잘려서 3이 됨 (경고만 나올 수 있음)
```

이런 이유로 많은 C++ 프로그래머들이 새 코드에서는 중괄호 초기화를 권장합니다. 다만 익숙하지 않다면 처음에는 `=` 초기화로 시작해도 무방하니, 스타일에 너무 얽매이지 않아도 됩니다.

## 기본 자료형과 크기

C++가 기본으로 제공하는 자료형(built-in type, fundamental type)들은 크게 정수, 부동소수점, 문자, 불(bool) 계열로 나뉩니다.

| 자료형 | 설명 | 대표적인 크기(플랫폼에 따라 다름) |
|---|---|---|
| `bool` | 참/거짓 | 1바이트 |
| `char` | 문자 하나 | 1바이트 |
| `int` | 정수 | 보통 4바이트 |
| `short` | 짧은 정수 | 보통 2바이트 |
| `long` | 긴 정수 | 4바이트 또는 8바이트 |
| `long long` | 더 긴 정수 (C++11) | 보통 8바이트 |
| `float` | 단정도 부동소수점 | 보통 4바이트 |
| `double` | 배정도 부동소수점 | 보통 8바이트 |

여기서 "보통"이라는 표현을 쓴 이유는, C++ 표준이 각 타입의 정확한 바이트 수를 강제하지 않기 때문입니다. 표준은 다만 최소한의 크기 관계(예: `sizeof(short) <= sizeof(int) <= sizeof(long) <= sizeof(long long)`)만 보장합니다. 실제 크기는 컴파일러와 플랫폼에 따라 달라질 수 있으므로, 직접 확인해 보는 습관이 중요합니다.

```cpp
#include <iostream>

int main() {
    std::cout << "bool: " << sizeof(bool) << " bytes" << std::endl;
    std::cout << "char: " << sizeof(char) << " bytes" << std::endl;
    std::cout << "int: " << sizeof(int) << " bytes" << std::endl;
    std::cout << "long: " << sizeof(long) << " bytes" << std::endl;
    std::cout << "long long: " << sizeof(long long) << " bytes" << std::endl;
    std::cout << "float: " << sizeof(float) << " bytes" << std::endl;
    std::cout << "double: " << sizeof(double) << " bytes" << std::endl;
    return 0;
}
```

`sizeof` 연산자는 특정 타입이나 변수가 차지하는 바이트 수를 알려줍니다. 정확한 크기가 중요한 상황(예: 파일 포맷, 네트워크 프로토콜)에서는 `<cstdint>` 헤더의 `int32_t`, `uint64_t`처럼 크기가 고정된 타입을 사용하는 편이 안전합니다.

### 부호 있는(signed) 정수와 부호 없는(unsigned) 정수

정수형에는 `signed`(음수 허용)와 `unsigned`(0 이상만 표현) 버전이 있습니다. `int`는 기본적으로 `signed`입니다.

```cpp
unsigned int count = 10;   // 음수를 저장할 수 없음
int balance = -50;          // 음수 가능
```

`unsigned` 타입에서 0보다 더 작은 값을 빼면 값이 아주 큰 양수로 "돌아 나가는" 현상(underflow)이 벌어질 수 있으니 주의가 필요합니다.

```cpp
unsigned int x = 0;
x = x - 1;   // x는 -1이 아니라 4294967295 (unsigned int가 4바이트인 경우) 가 됨
```

## `char`와 문자

`char`는 문자 하나를 담는 정수 타입입니다. 문자는 내부적으로 아스키(ASCII) 코드 값 같은 정수로 저장됩니다.

```cpp
char grade = 'A';
std::cout << grade << std::endl;         // A 출력
std::cout << (int)grade << std::endl;     // 65 출력 (아스키 코드)
```

## `bool`: C++에서는 진짜 타입이다

C 언어를 배운 적이 있다면 `bool`이 없어서 `int`로 참/거짓을 표현했던 경험이 있을 것입니다(C99 이후에는 `_Bool`이 추가되긴 했지만 역사적으로 `int`를 많이 썼습니다). C++는 언어 설계 초기부터 `bool`을 **독립적인 진짜 자료형**으로 두었습니다. `bool` 변수는 `true` 또는 `false` 두 값만 가지며, 이는 리터럴이자 키워드입니다.

```cpp
bool is_valid = true;
bool has_error = false;

if (is_valid) {
    std::cout << "유효합니다." << std::endl;
}
```

물론 다른 정수 타입과 `bool` 사이에는 변환이 존재합니다. 0은 `false`로, 0이 아닌 값은 `true`로 변환되며, 반대로 `bool`을 정수로 쓰면 `true`는 1, `false`는 0이 됩니다.

```cpp
int n = 5;
bool b = n;         // n이 0이 아니므로 b는 true
int result = b + 3;  // true는 1이므로 result는 4
```

하지만 이런 변환은 편의를 위한 것일 뿐, `bool`이 `int`의 별명(alias)인 것은 아닙니다. `bool`은 `sizeof(bool)`이 별도로 정의되고, 함수 오버로딩(13장의 템플릿, 7장의 함수를 배우고 나면 더 명확해집니다)에서도 `int`와 구분되는 독립된 타입으로 취급됩니다. 이 차이는 나중에 11장, 12장에서 클래스와 연산자를 다룰 때 타입 시스템의 중요성을 이해하는 데에도 도움이 됩니다.

## `const`로 상수 만들기

값이 바뀌지 않아야 하는 변수는 `const`로 선언합니다. `const`가 붙은 변수는 반드시 선언 시점에 초기화해야 하며, 이후에는 값을 바꿀 수 없습니다.

```cpp
const double pi = 3.14159;
const int max_users = 100;

// pi = 3.0;   // 오류: const 변수는 수정할 수 없음
```

`const`는 단순히 "상수"라는 의미를 넘어, 코드를 읽는 사람과 컴파일러 모두에게 "이 값은 바뀌지 않는다"는 약속을 전달하는 중요한 도구입니다. 함수의 매개변수나 참조(9장에서 자세히 다룹니다)에도 `const`를 붙여서 실수로 값이 바뀌는 것을 막을 수 있습니다.

## `auto`: 타입을 컴파일러에게 맡기기

C++11부터는 `auto` 키워드를 사용해 변수의 자료형을 컴파일러가 초기값으로부터 추론하게 할 수 있습니다.

```cpp
auto x = 10;         // int로 추론됨
auto y = 3.14;        // double로 추론됨
auto name = "Alice";  // const char*로 추론됨
auto flag = true;     // bool로 추론됨
```

`auto`는 타입이 없다는 뜻이 아닙니다. 컴파일 시점에 여전히 구체적인 타입이 결정되며, 단지 그 타입을 우리가 직접 적지 않아도 될 뿐입니다. `auto`는 특히 타입 이름이 길고 복잡한 경우(예: 14장에서 배울 STL 컨테이너의 반복자 타입)에 코드를 훨씬 간결하게 만들어 줍니다. 다만 `auto`를 쓸 때는 반드시 초기값이 있어야 하며, 초기값이 없으면 컴파일러가 추론할 근거가 없어 오류가 됩니다.

```cpp
auto z;   // 오류: 초기값이 없어 타입을 추론할 수 없음
```

## 형변환: 암시적 변환과 명시적 변환

서로 다른 자료형 사이의 값을 주고받으면 형변환(type conversion)이 일어납니다. C++에서는 이를 크게 암시적 변환과 명시적 변환으로 나눕니다.

### 암시적 변환

컴파일러가 별도의 지시 없이도 자동으로 수행하는 변환입니다.

```cpp
int i = 10;
double d = i;    // int -> double, 정보 손실 없이 자동 변환
double e = 3.9;
int f = e;         // double -> int, 소수점 아래가 잘려서 f는 3 (정보 손실 발생)
```

암시적 변환은 편리하지만, `double`을 `int`로 넣을 때처럼 정보가 손실되는 경우 컴파일러가 경고를 낼 수 있고, 이를 놓치면 버그로 이어지기 쉽습니다.

### 명시적 변환: `static_cast`

의도한 변환임을 코드에 분명히 드러내고 싶을 때는 `static_cast`를 사용합니다. C 스타일의 `(int)e` 같은 캐스트도 여전히 동작하지만, C++에서는 `static_cast`가 더 안전하고 의도가 분명하기 때문에 권장됩니다.

```cpp
double e = 3.9;
int f = static_cast<int>(e);   // 명시적으로 잘라내는 변환임을 드러냄

int total = 7;
int count = 2;
double average = static_cast<double>(total) / count;  // 3.5 (정수 나눗셈이 아니라 실수 나눗셈)
```

마지막 예시처럼, 정수를 정수로 나누면 소수점이 버려진 정수 나눗셈이 됩니다(`7 / 2`는 `3`). 이를 피하려면 나눗셈 전에 피연산자 중 하나를 `double`로 명시적으로 변환해야 합니다. 이 부분은 4장에서 산술 연산자를 다룰 때 다시 살펴보겠습니다.

`static_cast` 외에도 `dynamic_cast`, `const_cast`, `reinterpret_cast` 같은 캐스트가 있지만, 이들은 클래스 상속(11장)이나 포인터(8장)를 배운 뒤에 다루는 것이 자연스럽습니다. 지금은 값의 종류를 바꾸는 가장 일반적인 도구인 `static_cast`만 기억해도 충분합니다.

## 요약

이번 장에서는 C++ 프로그램의 가장 기본적인 구성 요소인 변수와 자료형을 살펴보았습니다. 변수는 선언과 동시에 초기화하는 습관을 들이는 것이 중요하며, C++11 이후에는 중괄호 초기화가 좁아지는 변환을 막아주는 안전한 방법으로 자리 잡았습니다. `int`, `double`, `char`처럼 익숙한 기본 타입들의 크기는 플랫폼에 따라 달라질 수 있으므로 `sizeof`로 직접 확인하는 습관이 필요합니다. 특히 C++의 `bool`은 C의 관습적인 정수 대체품이 아니라 `true`/`false` 두 값만 갖는 독립된 진짜 자료형이라는 점을 기억해야 합니다. `const`는 값이 바뀌지 않음을 보장하는 도구이고, `auto`는 컴파일러에게 타입 추론을 맡기는 편의 기능입니다. 마지막으로 형변환에는 컴파일러가 자동으로 처리하는 암시적 변환과, `static_cast`로 의도를 분명히 드러내는 명시적 변환이 있다는 점을 배웠습니다. 다음 장에서는 이렇게 선언한 변수들을 가지고 실제로 연산을 수행하는 연산자와 표현식을 알아보겠습니다.

## 연습문제

1. `int`, `double`, `char`, `bool` 각각의 변수를 선언하고 `sizeof`를 이용해 자신의 컴퓨터에서 각 타입이 몇 바이트인지 출력하는 프로그램을 작성하세요.
2. 다음 코드에서 컴파일 오류가 발생하는 줄을 찾고, 그 이유를 설명하세요.
   ```cpp
   int a{3.5};
   double b = 3.5;
   int c = b;
   ```
3. `unsigned int` 변수에 0을 대입한 뒤 1을 빼면 어떤 값이 나오는지 예측하고, 실제로 프로그램을 작성해 확인해 보세요. 왜 이런 결과가 나오는지 설명하세요.
4. `auto`를 사용해 정수 리터럴, 실수 리터럴, 문자열 리터럴을 각각 변수에 저장하고, `typeid(변수).name()` (헤더 `<typeinfo>` 필요)을 이용해 추론된 타입을 확인해 보세요.
5. 두 정수 `7`과 `2`를 나눈 결과를 (1) 정수 나눗셈으로, (2) `static_cast`를 이용한 실수 나눗셈으로 각각 출력하는 프로그램을 작성하고 결과의 차이를 설명하세요.
