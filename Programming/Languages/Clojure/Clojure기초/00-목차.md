프로그래밍 경험은 있지만 함수형 언어나 Lisp 계열은 처음 접하는 사람을 위한 Clojure 입문서입니다.
S-표현식과 기본 문법부터 불변 자료구조, 시퀀스와 고차 함수, 매크로, 동시성 모델, Java 상호운용까지
Clojure의 핵심 개념을 순서대로 다룹니다.

각 장은 개념 설명, REPL 예제, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는 이해를 돕는
다이어그램을 함께 실었습니다.

## 학습 방법 제안

1. Clojure는 REPL로 배우는 언어입니다. 각 장의 예제 코드를 직접 REPL에 입력하며 결과를 확인하세요.
2. 장 끝의 연습문제를 REPL에서 바로 풀어보면서 이해도를 점검하세요.
3. 막히는 부분이 있다면 해당 장을 다시 읽거나, 관련된 이전/이후 장을 함께 참고하세요.
4. 18장까지 마친 뒤에는 부록의 치트시트를 필요할 때마다 참조용으로 활용하세요.
