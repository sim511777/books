지금까지 우리는 필요할 때마다 표준 라이브러리 함수를 하나씩 꺼내 썼습니다. 5장 입출력 기초에서는 `printf`와 `scanf`를, 10장 문자열에서는 `strlen`이나 `strcpy`를, 14장 동적 메모리 할당에서는 `malloc`과 `free`를 배웠습니다. C 언어 자체는 문법이 매우 작은 언어이지만, 이렇게 표준 라이브러리가 제공하는 방대한 함수들 덕분에 실전에서 쓸 만한 프로그램을 효율적으로 작성할 수 있습니다.

이번 장에서는 지금까지 흩어져 있던 표준 라이브러리 지식을 헤더 파일(header file) 단위로 정리하고, 아직 다루지 않았던 유용한 함수들을 소개합니다. 표준 라이브러리 전체를 외울 필요는 없습니다. "이런 헤더에 이런 기능이 있었지"라는 지도를 머릿속에 그려 두면, 실제로 필요할 때 문서를 찾아보는 속도가 훨씬 빨라집니다.

## 17.1 표준 라이브러리란 무엇인가

C 표준 라이브러리는 C 언어 표준(ANSI C, ISO C 등)에 정의되어 있는 함수, 매크로, 자료형의 모음입니다. 컴파일러가 표준을 따른다면 운영체제나 하드웨어와 무관하게 이 라이브러리에 정의된 함수들을 동일한 방식으로 사용할 수 있습니다. `#include` 전처리기 지시문으로 필요한 헤더 파일을 포함시키면, 해당 헤더가 선언하고 있는 함수들을 코드에서 호출할 수 있게 됩니다. 헤더 파일과 `#include`의 동작 원리 자체는 16장 전처리기와 매크로에서 자세히 설명했으므로, 이 장에서는 각 헤더가 "무엇을 제공하는가"에 집중합니다.

자주 쓰이는 표준 헤더를 한눈에 정리하면 다음과 같습니다.

| 헤더 파일 | 주요 기능 | 대표 함수/매크로 |
|---|---|---|
| `stdio.h` | 표준 입출력, 파일 입출력 | `printf`, `scanf`, `fopen`, `sprintf` |
| `stdlib.h` | 문자열-숫자 변환, 동적 메모리, 난수, 프로세스 제어 | `atoi`, `malloc`, `rand`, `qsort`, `exit` |
| `string.h` | 문자열과 메모리 블록 처리 | `strlen`, `strcpy`, `memcpy`, `strstr` |
| `math.h` | 수학 함수 | `sqrt`, `pow`, `floor`, `sin` |
| `ctype.h` | 문자 분류와 변환 | `isdigit`, `isalpha`, `toupper` |
| `time.h` | 날짜와 시간 처리 | `time`, `clock`, `strftime` |
| `assert.h` | 실행 중 조건 검증 | `assert` |
| `limits.h`, `float.h` | 정수/실수 자료형의 한계값 | `INT_MAX`, `DBL_MAX` |

이 중 `assert.h`, `limits.h`, `float.h`는 코드 품질과 밀접한 관련이 있어 18장 좋은 C 코드 작성 습관에서 함께 다루고, 정수와 실수 자료형의 구체적인 크기와 범위는 부록의 표를 참고하시기 바랍니다. 이번 장에서는 나머지 여섯 개 헤더를 중심으로 살펴봅니다.

## 17.2 stdio.h: 표준 입출력

`stdio.h`의 `printf`, `scanf`는 5장 입출력 기초에서, 파일을 다루는 `fopen`, `fclose`, `fprintf`, `fgets` 등은 15장 파일 입출력에서 이미 자세히 다뤘습니다. 여기서는 그때 소개하지 않았던 두 가지 실용적인 함수를 추가로 살펴봅니다.

### sprintf와 snprintf: 문자열로 서식화하기

`printf`가 화면에 출력한다면, `sprintf`는 같은 서식 규칙을 그대로 사용하되 결과를 화면 대신 문자 배열에 써 넣습니다. 숫자와 문자열을 조합해 하나의 문자열을 만들어야 할 때 자주 사용합니다.

```c
#include <stdio.h>

int main(void)
{
    char message[50];
    int score = 87;

    // "점수: 87점" 이라는 문자열을 buffer에 만들어 넣는다
    sprintf(message, "점수: %d점", score);
    printf("%s\n", message);

    return 0;
}
```

문제는 `sprintf`가 `message` 배열의 크기를 전혀 신경 쓰지 않는다는 점입니다. 서식화된 결과가 배열 크기보다 길면 배열 경계를 넘어서 메모리를 덮어씁니다. 이런 위험 때문에 실무에서는 배열의 크기를 함께 전달하는 `snprintf`를 사용하는 것이 안전합니다.

```c
#include <stdio.h>

int main(void)
{
    char message[10];

    // message의 크기(10)를 넘지 않도록 잘라서 채운다
    snprintf(message, sizeof(message), "점수: %d점", 12345);
    printf("%s\n", message);   // 배열 크기를 넘는 부분은 잘린다

    return 0;
}
```

`sizeof(message)`처럼 배열 자체의 크기를 넘겨주면, 배열 크기가 바뀌어도 코드를 함께 고칠 필요가 없어 안전합니다. 가능하면 `sprintf`보다 `snprintf`를 사용하는 습관을 들이는 것이 좋습니다.

### perror: 오류 원인 출력하기

`fopen`처럼 실패할 수 있는 함수를 호출했을 때, 실패 원인을 사람이 읽을 수 있는 문장으로 출력해 주는 함수가 `perror`입니다.

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("존재하지않는파일.txt", "r");

    if (fp == NULL) {
        perror("파일 열기 실패");   // 예: 파일 열기 실패: No such file or directory
        return 1;
    }

    fclose(fp);
    return 0;
}
```

`perror`는 전달한 문자열 뒤에 콜론과 함께 운영체제가 알려 주는 실제 오류 원인을 덧붙여 출력합니다. 파일이 없는지, 접근 권한이 없는지 등을 별도로 분기하지 않아도 원인을 바로 확인할 수 있어 디버깅에 유용합니다.

## 17.3 stdlib.h: 범용 유틸리티

`stdlib.h`는 이름 그대로 "표준 유틸리티"를 모아 놓은 헤더입니다. 동적 메모리 할당 함수인 `malloc`, `calloc`, `realloc`, `free`는 14장 동적 메모리 할당에서 자세히 다뤘으므로 이 장에서는 반복하지 않고, 그 외의 대표 기능인 문자열-숫자 변환, 난수 생성, 정렬을 살펴봅니다.

### 문자열을 숫자로 변환하기

사용자 입력이나 파일에서 읽은 값은 대개 문자열 형태입니다. 이를 계산에 사용하려면 숫자로 변환해야 하는데, `atoi`(ASCII to integer)와 `atof`(ASCII to float)가 가장 간단한 방법입니다.

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char price_text[] = "15000";
    char rate_text[] = "3.5";

    int price = atoi(price_text);     // 문자열 -> int
    double rate = atof(rate_text);    // 문자열 -> double

    printf("가격: %d원, 이율: %.1f%%\n", price, rate);

    return 0;
}
```

`atoi`와 `atof`는 사용법이 간단하지만, 변환에 실패해도 오류를 알려 주지 않고 조용히 0을 반환한다는 약점이 있습니다. `"abc"`를 `atoi`에 넘기면 몇 번째 글자가 잘못됐는지 알 방법 없이 그냥 0이 반환됩니다. 변환 성공 여부를 확인해야 하는 코드라면 `strtol`(string to long)이나 `strtod`(string to double)처럼 실패 지점을 알려 주는 함수를 사용하는 편이 안전합니다.

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char input[] = "1200원";
    char *end_ptr;

    long value = strtol(input, &end_ptr, 10);  // 10진수로 변환

    printf("변환된 값: %ld\n", value);
    printf("변환이 멈춘 위치: \"%s\"\n", end_ptr);  // "원" 부터 남는다

    if (end_ptr == input) {
        printf("숫자를 하나도 읽지 못했습니다.\n");
    }

    return 0;
}
```

`strtol`은 변환에 성공한 부분까지의 값을 반환하고, `end_ptr`을 통해 "숫자가 아닌 부분이 어디서부터 시작되는지"를 알려 줍니다. `end_ptr`이 `input`과 같은 주소를 가리킨다면 단 한 글자도 숫자로 변환하지 못했다는 뜻입니다.

### rand와 srand: 난수 생성하기

`rand` 함수는 0부터 `RAND_MAX`(대개 32767 이상의 값) 사이의 의사 난수(pseudo-random number)를 반환합니다.

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void)
{
    srand((unsigned int)time(NULL));   // 현재 시각으로 난수 씨앗(seed) 초기화

    for (int i = 0; i < 5; i++) {
        int dice = rand() % 6 + 1;   // 1~6 사이의 값으로 변환
        printf("주사위: %d\n", dice);
    }

    return 0;
}
```

`rand`가 만들어 내는 수열은 사실 완전히 무작위가 아니라, 내부적으로 정해진 규칙에 따라 계산되는 "난수처럼 보이는" 수열입니다. 이 규칙의 시작점을 정하는 것이 `srand`에 넘기는 씨앗값(seed)입니다. 씨앗값이 같으면 항상 같은 수열이 나오기 때문에, 프로그램을 실행할 때마다 다른 결과를 얻으려면 `time(NULL)`처럼 매번 달라지는 값을 씨앗으로 사용합니다. `srand`는 프로그램 전체에서 한 번만 호출하면 충분하며, 반복문 안에서 매번 호출하면 오히려 같은 값이 반복될 수 있습니다.

`rand() % 6`처럼 나머지 연산자로 범위를 좁히는 방법은 간단하지만 통계적으로 완벽하게 균등하지는 않습니다. 게임이나 간단한 예제 수준에서는 무리가 없지만, 정밀한 확률이 중요한 프로그램(암호학적 용도 등)에는 `rand`를 사용해서는 안 되며, 운영체제가 제공하는 별도의 안전한 난수 생성 방법을 찾아야 합니다.

### qsort: 범용 정렬 함수

`qsort`는 배열의 자료형과 무관하게 동작하는 범용 정렬 함수입니다. 배열의 시작 주소, 원소 개수, 원소 하나의 크기, 그리고 두 원소를 비교하는 방법을 알려 주는 함수(비교 함수)를 전달하면, `qsort`가 내부적으로 빠른 정렬 알고리즘을 이용해 배열을 정렬해 줍니다.

```c
#include <stdio.h>
#include <stdlib.h>

// 두 int를 비교하는 함수: a가 작으면 음수, 같으면 0, 크면 양수를 반환
int compare_int(const void *a, const void *b)
{
    int num_a = *(const int *)a;
    int num_b = *(const int *)b;

    return num_a - num_b;
}

int main(void)
{
    int scores[] = { 88, 45, 92, 67, 100, 73 };
    int count = sizeof(scores) / sizeof(scores[0]);

    qsort(scores, count, sizeof(int), compare_int);

    printf("정렬 결과: ");
    for (int i = 0; i < count; i++) {
        printf("%d ", scores[i]);
    }
    printf("\n");

    return 0;
}
```

비교 함수의 매개변수가 `const void *`인 이유는, `qsort`가 어떤 자료형의 배열이든 다룰 수 있도록 설계되었기 때문입니다. `void *`는 12장 포인터 응용에서 다룬 범용 포인터로, 실제 사용할 때는 원래 자료형의 포인터로 형 변환(`(const int *)`)한 뒤 역참조해야 합니다. 비교 함수가 "a가 b보다 작으면 음수, 크면 양수, 같으면 0"이라는 규칙만 지킨다면, 구조체 배열이나 문자열 배열도 동일한 방식으로 정렬할 수 있습니다.

### exit과 abort: 프로그램 즉시 종료하기

`main` 함수가 아닌 다른 함수 안에서 프로그램을 즉시 종료해야 할 때 `exit`을 사용합니다. `exit(0)`은 정상 종료를, `exit(1)`처럼 0이 아닌 값은 비정상 종료를 셸에 알려 줍니다. 이는 `main`에서 `return`으로 값을 반환하는 것과 사실상 같은 효과를 냅니다.

```c
#include <stdio.h>
#include <stdlib.h>

void check_input(int value)
{
    if (value < 0) {
        fprintf(stderr, "오류: 음수는 허용되지 않습니다.\n");
        exit(1);   // 프로그램을 즉시 종료
    }
}

int main(void)
{
    check_input(-5);
    printf("이 문장은 실행되지 않습니다.\n");

    return 0;
}
```

`abort`도 프로그램을 즉시 종료하지만, 정상적인 종료 절차(파일 닫기, 정리 작업 등)를 건너뛰고 비정상 종료 신호를 발생시킨다는 점에서 `exit`과 다릅니다. 일반적인 오류 처리에는 `exit`을, 복구할 수 없는 심각한 내부 오류(assert 실패 등)를 알릴 때는 `abort`가 사용된다고 이해하면 됩니다.

## 17.4 string.h: 문자열과 메모리 블록 다루기

`strlen`, `strcpy`, `strncpy`, `strcat`, `strcmp` 같은 기본적인 문자열 함수는 10장 문자열에서 이미 상세히 다뤘습니다. 여기서는 그때 다루지 않았던, 문자열 검색과 메모리 블록을 직접 다루는 함수들을 소개합니다.

| 함수 | 기능 |
|---|---|
| `strchr(s, c)` | 문자열 `s`에서 문자 `c`가 처음 나오는 위치를 찾는다 |
| `strstr(s, sub)` | 문자열 `s` 안에서 부분 문자열 `sub`가 처음 나오는 위치를 찾는다 |
| `strtok(s, delim)` | 문자열 `s`를 구분자 `delim` 기준으로 잘라낸다 |
| `memcpy(dst, src, n)` | `src`의 `n`바이트를 `dst`로 그대로 복사한다 |
| `memset(dst, c, n)` | `dst`의 `n`바이트를 모두 문자 `c`로 채운다 |
| `memmove(dst, src, n)` | `memcpy`와 같지만 두 영역이 겹쳐도 안전하다 |

### strstr로 부분 문자열 찾기

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char sentence[] = "C 언어는 배우기 재미있는 언어입니다.";
    char *found = strstr(sentence, "재미있는");

    if (found != NULL) {
        printf("찾은 위치부터 출력: %s\n", found);
    } else {
        printf("찾지 못했습니다.\n");
    }

    return 0;
}
```

`strstr`은 찾고자 하는 부분 문자열이 시작되는 위치의 포인터를 반환하고, 찾지 못하면 `NULL`을 반환합니다. 반환값이 원본 문자열의 어느 지점을 "가리키는" 포인터라는 점에서, 11장 포인터 기초에서 배운 포인터와 배열의 관계를 다시 확인할 수 있는 좋은 예입니다.

### strtok으로 문자열 분리하기

CSV 형식의 데이터처럼 구분자로 나뉜 문자열을 처리할 때 `strtok`을 사용합니다.

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char csv_line[] = "사과,바나나,포도,딸기";
    char *token = strtok(csv_line, ",");   // 첫 번째 호출은 대상 문자열을 넘긴다

    while (token != NULL) {
        printf("과일: %s\n", token);
        token = strtok(NULL, ",");   // 이후 호출은 NULL을 넘겨야 이어서 처리한다
    }

    return 0;
}
```

`strtok`은 원본 문자열(`csv_line`)을 직접 수정하면서 구분자 자리에 `'\0'`을 채워 넣는 방식으로 동작합니다. 그래서 문자열 리터럴처럼 수정할 수 없는 문자열에는 사용할 수 없으며, 원본이 훼손되어도 괜찮은 배열에만 사용해야 합니다. 또한 첫 호출에서는 대상 문자열을 넘기고, 이어지는 호출에서는 `NULL`을 넘겨야 직전에 처리하던 위치부터 이어서 잘라낸다는 독특한 사용법을 기억해야 합니다.

### memcpy와 memset: 메모리 블록 다루기

`strcpy`가 문자열(`'\0'`으로 끝나는 문자 배열) 전용이라면, `memcpy`는 자료형에 상관없이 지정한 바이트 수만큼 메모리를 그대로 복사합니다.

```c
#include <stdio.h>
#include <string.h>

struct point {
    int x;
    int y;
};

int main(void)
{
    struct point p1 = { 3, 7 };
    struct point p2;

    memcpy(&p2, &p1, sizeof(struct point));   // 구조체 전체를 통째로 복사
    printf("p2 = (%d, %d)\n", p2.x, p2.y);

    int buffer[5];
    memset(buffer, 0, sizeof(buffer));   // 배열 전체를 0으로 초기화

    for (int i = 0; i < 5; i++) {
        printf("%d ", buffer[i]);
    }
    printf("\n");

    return 0;
}
```

`memset`은 배열이나 구조체를 특정 값(주로 0)으로 빠르게 초기화할 때 자주 사용됩니다. 13장 구조체, 공용체, 열거형에서 다룬 구조체를 통째로 복사하거나 초기화할 때 특히 유용합니다. 다만 `memset`의 두 번째 인자는 `int`형이지만 실제로는 각 바이트에 그 값의 하위 1바이트만 채워지므로, 0이나 -1처럼 모든 바이트가 같은 값이 되는 경우가 아니라면 예상과 다른 결과가 나올 수 있다는 점에 주의해야 합니다.

## 17.5 math.h: 수학 함수

`math.h`는 제곱근, 거듭제곱, 삼각함수 등 수학 계산에 필요한 함수들을 제공합니다. 대부분의 함수는 `double`형을 받아 `double`형을 반환합니다.

| 함수 | 기능 | 예시 |
|---|---|---|
| `sqrt(x)` | 제곱근 | `sqrt(16.0)` → `4.0` |
| `pow(x, y)` | x의 y제곱 | `pow(2.0, 10.0)` → `1024.0` |
| `fabs(x)` | 실수의 절댓값 | `fabs(-3.5)` → `3.5` |
| `floor(x)` | 소수점 이하를 버림(내림) | `floor(3.9)` → `3.0` |
| `ceil(x)` | 소수점 이하를 올림 | `ceil(3.1)` → `4.0` |
| `sin(x)`, `cos(x)`, `tan(x)` | 삼각함수(라디안 단위) | `sin(0.0)` → `0.0` |
| `log(x)`, `log10(x)` | 자연로그, 상용로그 | `log10(100.0)` → `2.0` |

```c
#include <stdio.h>
#include <math.h>

int main(void)
{
    double a = 3.0;
    double b = 4.0;

    double hypotenuse = sqrt(pow(a, 2) + pow(b, 2));   // 피타고라스 정리
    printf("빗변의 길이: %.2f\n", hypotenuse);

    double x = 2.7;
    printf("floor(%.1f) = %.1f, ceil(%.1f) = %.1f\n", x, floor(x), x, ceil(x));

    return 0;
}
```

### 컴파일 시 -lm 옵션이 필요한 이유

`math.h`를 사용하는 코드를 GCC나 Clang으로 컴파일할 때, 일부 플랫폼에서는 링크 단계에서 수학 라이브러리를 명시적으로 지정해야 합니다.

```
gcc program.c -o program -lm
```

`-lm`은 "math 라이브러리를 링크하라"는 의미입니다. 2장 첫 프로그램과 빌드 과정에서 설명했듯, 컴파일은 소스 코드를 기계어로 바꾸는 컴파일 단계와, 여러 기계어 조각들을 하나의 실행 파일로 합치는 링크 단계로 나뉩니다. 표준 입출력 함수들은 기본적으로 링크되는 라이브러리에 포함되어 있지만, 수학 함수는 별도의 라이브러리 파일로 분리되어 있는 경우가 많아 이렇게 옵션을 따로 지정해야 합니다. (컴파일러와 운영체제에 따라 `-lm` 없이도 동작하는 경우가 있지만, 습관적으로 붙여 주면 이식성 문제를 피할 수 있습니다.)

## 17.6 ctype.h: 문자 분류와 변환

`ctype.h`는 문자 하나가 숫자인지, 알파벳인지, 공백인지를 판별하거나 대소문자를 변환하는 함수를 제공합니다. 사용자 입력을 검증하거나 문자열을 한 글자씩 순회하며 처리할 때 자주 사용됩니다.

| 함수 | 기능 |
|---|---|
| `isdigit(c)` | 숫자(`0`~`9`)인지 판별 |
| `isalpha(c)` | 알파벳인지 판별 |
| `isalnum(c)` | 알파벳 또는 숫자인지 판별 |
| `isspace(c)` | 공백류 문자(스페이스, 탭, 개행 등)인지 판별 |
| `isupper(c)`, `islower(c)` | 대문자/소문자인지 판별 |
| `toupper(c)` | 소문자를 대문자로 변환 |
| `tolower(c)` | 대문자를 소문자로 변환 |

```c
#include <stdio.h>
#include <ctype.h>
#include <string.h>

int main(void)
{
    char password[] = "abc123";
    int has_digit = 0;
    int has_alpha = 0;

    for (int i = 0; i < (int)strlen(password); i++) {
        if (isdigit((unsigned char)password[i])) {
            has_digit = 1;
        }
        if (isalpha((unsigned char)password[i])) {
            has_alpha = 1;
        }
    }

    if (has_digit && has_alpha) {
        printf("영문과 숫자를 모두 포함하고 있습니다.\n");
    } else {
        printf("영문과 숫자를 모두 포함해야 합니다.\n");
    }

    return 0;
}
```

`isdigit`이나 `isalpha` 같은 함수에 문자를 넘길 때는 `(unsigned char)`로 형 변환해 주는 것이 안전합니다. `char`가 플랫폼에 따라 음수 값을 가질 수 있는데, 이 함수들은 음수 값을 넘겨받으면 정의되지 않은 동작을 일으킬 수 있기 때문입니다. 3장 변수와 자료형에서 다룬 `char`의 부호 문제를 떠올려 보면 이 관례가 왜 필요한지 이해할 수 있습니다.

```c
#include <stdio.h>
#include <ctype.h>

int main(void)
{
    char text[] = "Hello, World!";

    for (int i = 0; text[i] != '\0'; i++) {
        text[i] = (char)toupper((unsigned char)text[i]);
    }

    printf("%s\n", text);   // HELLO, WORLD!

    return 0;
}
```

## 17.7 time.h: 날짜와 시간 다루기

`time.h`는 현재 시각을 얻거나, 프로그램의 실행 시간을 측정하거나, 날짜를 사람이 읽기 좋은 형태로 서식화하는 함수를 제공합니다.

### time과 difftime: 현재 시각과 경과 시간

`time` 함수는 1970년 1월 1일 자정(UTC)을 기준으로 현재까지 흐른 초 단위 시간을 `time_t`형으로 반환합니다.

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    time_t now = time(NULL);   // 현재 시각을 얻는다

    printf("현재 시각(초 단위 타임스탬프): %ld\n", (long)now);
    printf("사람이 읽을 수 있는 형태: %s", ctime(&now));   // ctime은 문자열 끝에 개행을 포함한다

    return 0;
}
```

두 시각의 차이를 구할 때는 `difftime`을 사용합니다. `time_t`끼리 직접 뺄셈을 해도 대부분의 플랫폼에서는 문제없이 동작하지만, `difftime`을 사용하면 항상 초 단위의 `double` 값을 이식성 있게 얻을 수 있습니다.

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    time_t start = time(NULL);

    // 시간이 걸리는 작업을 흉내 내기 위한 반복문
    long sum = 0;
    for (long i = 0; i < 300000000L; i++) {
        sum += i;
    }

    time_t end = time(NULL);
    printf("걸린 시간: %.0f초\n", difftime(end, start));

    return 0;
}
```

### clock: 더 정밀한 실행 시간 측정

`time`은 초 단위로만 시간을 측정하기 때문에 짧은 시간이 걸리는 작업을 측정하기에는 정밀도가 부족합니다. `clock` 함수는 프로그램이 CPU를 사용한 시간을 더 세밀한 단위로 반환하며, `CLOCKS_PER_SEC`으로 나누면 초 단위로 환산할 수 있습니다.

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    clock_t start = clock();

    double total = 0.0;
    for (int i = 0; i < 10000000; i++) {
        total += i * 0.5;
    }

    clock_t end = clock();
    double elapsed = (double)(end - start) / CLOCKS_PER_SEC;

    printf("계산 결과: %.1f\n", total);
    printf("걸린 시간: %.4f초\n", elapsed);

    return 0;
}
```

### strftime: 날짜를 원하는 형식으로 출력하기

`localtime`으로 `time_t` 값을 연/월/일/시/분/초로 나눈 `struct tm` 구조체를 얻은 뒤, `strftime`을 이용하면 원하는 형식의 문자열로 서식화할 수 있습니다.

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    time_t now = time(NULL);
    struct tm *local = localtime(&now);   // time_t를 연/월/일 등으로 분해

    char buffer[64];
    strftime(buffer, sizeof(buffer), "%Y년 %m월 %d일 %H시 %M분", local);

    printf("%s\n", buffer);

    return 0;
}
```

`strftime`의 서식 지정자는 `printf`와 비슷하게 `%`로 시작하지만 의미가 다릅니다. `%Y`는 4자리 연도, `%m`은 월, `%d`는 일, `%H`는 시(24시간제), `%M`은 분을 나타냅니다. 로그 파일에 시각을 기록하거나 사용자에게 날짜를 보기 좋게 보여줄 때 유용하게 쓰입니다.

## 17.8 헤더를 찾아보는 습관

이번 장에서 소개한 함수들은 표준 라이브러리의 극히 일부입니다. 실무에서는 "이런 기능이 표준 라이브러리에 이미 있지 않을까?"라고 먼저 의심해 보는 습관이 중요합니다. 문자열을 다루다 막히면 `string.h`를, 숫자 계산이 필요하면 `math.h`를, 시간이 필요하면 `time.h`를 먼저 살펴보십시오. 이미 검증되고 최적화된 표준 함수를 두고 비슷한 기능을 직접 처음부터 구현하는 것은 시간 낭비일 뿐 아니라 버그의 원인이 되기 쉽습니다.

각 함수의 정확한 매개변수 순서나 반환값, 예외적인 동작(예: 실패 시 무엇을 반환하는지)은 컴파일러 매뉴얼이나 C 표준 문서를 통해 확인하는 습관을 들이는 것이 좋습니다. 이에 대해서는 부록에서 조금 더 자세히 안내합니다.

## 요약

- C 표준 라이브러리는 `stdio.h`, `stdlib.h`, `string.h`, `math.h`, `ctype.h`, `time.h` 등 기능별로 나뉜 헤더 파일들로 구성된다.
- `stdio.h`의 `snprintf`는 `sprintf`보다 안전하게 문자열을 서식화하며, `perror`는 실패 원인을 사람이 읽기 좋은 형태로 알려준다.
- `stdlib.h`는 `atoi`/`strtol` 같은 문자열-숫자 변환, `rand`/`srand`를 이용한 난수 생성, `qsort`를 이용한 범용 정렬, `exit`을 이용한 즉시 종료 기능을 제공한다.
- `string.h`는 `strstr`, `strtok` 같은 문자열 검색/분리 함수와, `memcpy`, `memset`처럼 자료형에 상관없이 메모리 블록을 다루는 함수를 제공한다.
- `math.h`의 함수를 사용할 때는 컴파일 시 `-lm` 옵션이 필요할 수 있다.
- `ctype.h`의 문자 분류/변환 함수에 문자를 넘길 때는 `(unsigned char)`로 형 변환하는 것이 안전하다.
- `time.h`는 `time`, `clock`으로 시간을 측정하고, `strftime`으로 날짜를 원하는 형식으로 서식화할 수 있게 해 준다.
