프로그램을 작성하다 보면 같은 작업을 여러 번 되풀이해야 하는 경우가 자주 생깁니다. 화면에 별을 열 줄 찍는다거나, 1부터 100까지 더한다거나, 사용자가 올바른 값을 입력할 때까지 계속 물어보는 것들이 대표적인 예입니다. 이런 반복 작업을 매번 똑같은 코드를 복사해서 붙여넣는 방식으로 처리한다면 코드는 금방 지저분해지고, 반복 횟수가 바뀔 때마다 코드를 통째로 고쳐야 합니다.

C 언어는 이런 문제를 해결하기 위해 세 가지 반복문(loop statement)을 제공합니다. `while`, `do-while`, `for`가 그것입니다. 세 가지 모두 "조건이 참인 동안 특정 문장을 반복 실행한다"는 본질은 같지만, 조건을 검사하는 시점과 코드를 작성하는 방식에 차이가 있습니다. 이번 장에서는 이 세 반복문의 문법과 각각이 어울리는 상황, 반복을 중간에 제어하는 `break`와 `continue`, 그리고 반복문을 중첩해서 사용하는 방법까지 다룹니다.

## while문

`while`문은 가장 단순한 형태의 반복문입니다. 괄호 안의 조건식이 참(0이 아닌 값)인 동안 중괄호 블록을 계속 실행합니다.

```c
while (조건식) {
    // 반복 실행할 문장들
}
```

핵심은 **조건을 먼저 검사하고 나서** 블록을 실행한다는 점입니다. 즉 처음부터 조건이 거짓이면 블록은 단 한 번도 실행되지 않습니다. 예제를 보겠습니다.

```c
#include <stdio.h>

int main(void) {
    int count = 1;

    // count가 5 이하인 동안 반복
    while (count <= 5) {
        printf("반복 %d번째\n", count);
        count = count + 1;  // 반드시 조건이 변하는 코드가 있어야 한다
    }

    printf("반복이 끝났습니다.\n");
    return 0;
}
```

이 프로그램은 `count`가 1부터 5까지 증가하면서 총 다섯 번 메시지를 출력합니다. 여기서 눈여겨볼 부분은 `count = count + 1;` 문장입니다. 반복문 안에서 조건식에 사용되는 변수를 변화시키는 코드가 없다면, 조건은 영원히 참으로 남아 무한히 반복하게 됩니다. 이는 뒤에서 다시 살펴볼 흔한 실수 중 하나입니다.

`while`문은 **반복 횟수를 미리 알 수 없고, 어떤 조건이 만족될 때까지 계속 반복해야 하는 상황**에 특히 잘 어울립니다. 예를 들어 사용자가 올바른 값을 입력할 때까지 반복해서 물어보는 코드를 생각해 봅시다.

```c
#include <stdio.h>

int main(void) {
    int number = 0;

    printf("1에서 10 사이의 수를 입력하세요: ");
    scanf("%d", &number);

    while (number < 1 || number > 10) {
        printf("범위를 벗어났습니다. 다시 입력하세요: ");
        scanf("%d", &number);
    }

    printf("입력하신 수는 %d입니다.\n", number);
    return 0;
}
```

이 예제처럼 "몇 번 반복할지"보다 "어떤 조건이 될 때까지 반복할지"가 중요한 경우에는 `while`문이 자연스러운 선택입니다.

## do-while문

`while`문은 조건을 먼저 검사하기 때문에 블록이 한 번도 실행되지 않을 수 있습니다. 하지만 상황에 따라서는 "일단 한 번은 실행하고 나서 조건을 검사하고 싶다"는 경우가 있습니다. 이럴 때 사용하는 것이 `do-while`문입니다.

```c
do {
    // 반복 실행할 문장들
} while (조건식);
```

`do-while`문은 블록을 먼저 실행한 다음 조건을 검사하므로, **블록이 최소 한 번은 반드시 실행됩니다**. 문장 끝에 세미콜론을 붙여야 한다는 점도 잊지 말아야 합니다.

메뉴를 반복해서 보여주는 프로그램은 `do-while`문이 딱 어울리는 대표적인 예입니다. 메뉴는 최소 한 번은 보여줘야 사용자가 무엇을 선택할지 알 수 있기 때문입니다.

```c
#include <stdio.h>

int main(void) {
    int choice;

    do {
        printf("\n--- 메뉴 ---\n");
        printf("1. 새 파일\n");
        printf("2. 파일 열기\n");
        printf("0. 종료\n");
        printf("선택: ");
        scanf("%d", &choice);

        if (choice == 1) {
            printf("새 파일을 만듭니다.\n");
        } else if (choice == 2) {
            printf("파일을 엽니다.\n");
        } else if (choice != 0) {
            printf("잘못된 선택입니다.\n");
        }
    } while (choice != 0);

    printf("프로그램을 종료합니다.\n");
    return 0;
}
```

`while`문과 `do-while`문의 차이를 그림으로 정리하면 다음과 같습니다.

```
while문                       do-while문
  ┌─────────┐                  ┌─────────┐
  │ 조건 검사 │◄──┐             │  블록 실행 │◄──┐
  └────┬────┘   │             └────┬────┘   │
     참 │        │                참 │        │
       ▼        │                  ▼        │
  ┌─────────┐   │             ┌─────────┐   │
  │  블록 실행 │───┘             │ 조건 검사 │───┘
  └─────────┘                  └─────────┘
     거짓 → 종료                   거짓 → 종료
```

조건을 검사하는 순서만 다를 뿐인데도 "최소 한 번 실행 보장 여부"라는 중요한 차이가 생긴다는 점을 기억해 두면 좋습니다.

## for문

`for`문은 반복 횟수가 명확하게 정해져 있을 때 가장 널리 쓰이는 반복문입니다. 초기화, 조건 검사, 증감이라는 반복에 필요한 세 가지 요소를 한 줄에 모아서 작성할 수 있기 때문에 코드가 간결해집니다.

```c
for (초기화식; 조건식; 증감식) {
    // 반복 실행할 문장들
}
```

동작 순서는 다음과 같습니다.

1. 반복을 시작하기 전에 **초기화식**을 딱 한 번 실행한다.
2. **조건식**을 검사한다. 거짓이면 반복문을 즉시 빠져나간다.
3. 조건식이 참이면 블록을 실행한다.
4. **증감식**을 실행한다.
5. 2번으로 돌아간다.

앞서 보았던 `while`문 예제를 `for`문으로 바꿔보면 다음과 같습니다.

```c
#include <stdio.h>

int main(void) {
    // 초기화: i = 1, 조건: i <= 5, 증감: i++
    for (int i = 1; i <= 5; i++) {
        printf("반복 %d번째\n", i);
    }

    printf("반복이 끝났습니다.\n");
    return 0;
}
```

`while`문으로 작성했을 때보다 반복을 제어하는 세 요소(초기화, 조건, 증감)가 한눈에 들어온다는 장점이 있습니다. 반복 횟수가 정해져 있는 상황, 예를 들어 "배열의 모든 원소를 처음부터 끝까지 훑어본다"거나 "1부터 100까지의 합을 구한다" 같은 작업에는 `for`문이 가장 자연스러운 선택입니다.

```c
#include <stdio.h>

int main(void) {
    int sum = 0;

    for (int i = 1; i <= 100; i++) {
        sum += i;  // sum = sum + i 와 동일
    }

    printf("1부터 100까지의 합은 %d입니다.\n", sum);
    return 0;
}
```

`for`문의 세 요소는 모두 생략이 가능합니다. 예를 들어 `for (;;)`처럼 세 부분을 모두 비워두면 무한 반복문이 되는데, 이는 뒤에서 다시 다룹니다. 다만 세미콜론 두 개는 생략할 수 없다는 점에 유의해야 합니다.

### while문과 for문, 언제 무엇을 쓸까

- 반복 횟수가 미리 정해져 있고 카운터 변수로 관리한다면 `for`문이 코드를 더 명확하게 보여줍니다.
- 반복을 언제 멈출지 조건에 따라 결정되고 반복 횟수를 예측하기 어렵다면 `while`문이 자연스럽습니다.
- 무조건 한 번은 실행해야 하는 로직(메뉴 출력, 입력값 검증 등)이라면 `do-while`문을 고려합니다.

이는 절대적인 규칙이 아니라 관례에 가깝습니다. 실제로 세 반복문은 서로 바꿔 쓸 수 있는 경우가 대부분이며, 어떤 것을 쓰든 코드의 의도가 잘 드러나는 쪽을 선택하면 됩니다.

## break와 continue

반복문 안에서 조건에 따라 반복을 즉시 끝내거나, 이번 반복만 건너뛰고 다음 반복으로 넘어가고 싶을 때가 있습니다. C 언어는 이를 위해 `break`와 `continue`라는 두 가지 키워드를 제공합니다.

### break: 반복문을 즉시 빠져나가기

`break`문을 만나면 현재 실행 중인 반복문(가장 안쪽의 `while`, `do-while`, `for`, 또는 `switch`문)을 즉시 빠져나갑니다. 특정 값을 찾으면 더 이상 반복할 필요가 없는 검색 상황에서 자주 사용합니다.

```c
#include <stdio.h>

int main(void) {
    int numbers[10] = {4, 8, 15, 16, 23, 42, 7, 3, 9, 1};
    int target = 23;
    int found_index = -1;

    for (int i = 0; i < 10; i++) {
        if (numbers[i] == target) {
            found_index = i;
            break;  // 찾았으니 더 볼 필요 없이 반복문 종료
        }
    }

    if (found_index != -1) {
        printf("%d를 %d번째 위치에서 찾았습니다.\n", target, found_index);
    } else {
        printf("찾지 못했습니다.\n");
    }

    return 0;
}
```

`break`가 없었다면 이미 값을 찾은 뒤에도 나머지 원소들을 불필요하게 계속 검사했을 것입니다. 배열은 9장에서 자세히 다루므로 지금은 "값들이 순서대로 늘어서 있는 목록" 정도로 이해해도 충분합니다.

### continue: 이번 반복만 건너뛰기

`continue`문은 `break`와 달리 반복문 자체를 끝내지 않습니다. 대신 현재 반복의 나머지 부분을 건너뛰고 곧바로 다음 반복(조건 검사 또는 증감식)으로 넘어갑니다.

```c
#include <stdio.h>

int main(void) {
    // 1부터 20까지의 수 중 짝수만 출력
    for (int i = 1; i <= 20; i++) {
        if (i % 2 != 0) {
            continue;  // 홀수면 아래 printf를 건너뛰고 다음 반복으로
        }
        printf("%d ", i);
    }
    printf("\n");

    return 0;
}
```

`continue`를 만나면 `for`문에서는 증감식(`i++`)이 실행된 뒤 다시 조건을 검사합니다. `while`문이나 `do-while`문에서는 곧바로 조건식 검사로 넘어간다는 점이 다르므로, `while`문에서 `continue`를 사용할 때는 조건 변수를 증감시키는 코드가 `continue`보다 앞에 있는지 반드시 확인해야 합니다. 그렇지 않으면 무한 반복에 빠질 수 있습니다.

```c
#include <stdio.h>

int main(void) {
    int i = 0;

    while (i < 10) {
        i++;  // continue보다 먼저 와야 무한 반복을 피할 수 있다
        if (i % 3 == 0) {
            continue;
        }
        printf("%d ", i);
    }
    printf("\n");

    return 0;
}
```

## 중첩 반복문

반복문 안에 또 다른 반복문을 넣는 것을 중첩 반복문(nested loop)이라고 합니다. 바깥쪽 반복이 한 번 진행될 때마다 안쪽 반복이 처음부터 끝까지 통째로 실행됩니다. 표 형태의 데이터를 다루거나 2차원 형태의 출력을 만들 때 매우 자주 사용되는 패턴입니다.

### 예제 1: 구구단 출력

```c
#include <stdio.h>

int main(void) {
    for (int dan = 2; dan <= 9; dan++) {
        printf("=== %d단 ===\n", dan);
        for (int i = 1; i <= 9; i++) {
            printf("%d x %d = %d\n", dan, i, dan * i);
        }
        printf("\n");
    }

    return 0;
}
```

바깥쪽 `for`문은 단(2단부터 9단까지)을 순회하고, 안쪽 `for`문은 각 단에서 곱하는 수(1부터 9까지)를 순회합니다. 바깥쪽이 한 번 돌 때마다 안쪽은 9번씩 통째로 실행되므로, 전체적으로는 8 × 9 = 72번의 곱셈이 이루어집니다.

### 예제 2: 별 찍기

중첩 반복문으로 도형을 그리는 연습은 반복문의 동작 원리를 눈으로 확인하기에 좋은 방법입니다.

```c
#include <stdio.h>

int main(void) {
    int height = 5;

    // 직각삼각형 모양으로 별 찍기
    for (int row = 1; row <= height; row++) {
        for (int col = 1; col <= row; col++) {
            printf("*");
        }
        printf("\n");
    }

    return 0;
}
```

실행 결과는 다음과 같습니다.

```
*
**
***
****
*****
```

바깥쪽 반복문의 `row` 값이 커질수록 안쪽 반복문이 별을 찍는 횟수도 함께 늘어나는 구조입니다. 이번에는 이중 반복문을 응용해서 피라미드 모양을 만들어 보겠습니다. 각 줄에 공백과 별을 적절히 섞어서 찍으면 됩니다.

```c
#include <stdio.h>

int main(void) {
    int height = 5;

    for (int row = 1; row <= height; row++) {
        // 왼쪽 공백 출력
        for (int space = 1; space <= height - row; space++) {
            printf(" ");
        }
        // 별 출력 (줄마다 2개씩 늘어남)
        for (int star = 1; star <= 2 * row - 1; star++) {
            printf("*");
        }
        printf("\n");
    }

    return 0;
}
```

```
    *
   ***
  *****
 *******
*********
```

이처럼 세 개의 반복문을 나란히 사용하기도 하고, 반복문을 서로 중첩시키기도 하면서 원하는 출력 패턴을 조립해 나가는 것이 중첩 반복문을 다루는 핵심 감각입니다.

### 중첩 반복문에서 break의 범위

중요한 점 하나는, `break`는 **자신을 감싸고 있는 가장 안쪽 반복문 하나만** 빠져나간다는 것입니다. 바깥쪽 반복문까지 한 번에 종료시키지는 않습니다.

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 3; j++) {
            if (j == 2) {
                break;  // 안쪽 for문만 빠져나감
            }
            printf("i=%d, j=%d\n", i, j);
        }
    }

    return 0;
}
```

이 코드는 `j`가 2가 되는 순간 안쪽 반복문만 종료되고, 바깥쪽 `i`에 대한 반복은 계속됩니다. 만약 두 반복문을 동시에 빠져나가고 싶다면, 별도의 플래그(flag) 변수를 두어 조건을 검사하거나, 함수로 분리한 뒤 `return`으로 빠져나가는 방식을 흔히 사용합니다. 함수와 `return`에 대해서는 8장 함수에서 자세히 다룹니다.

```c
#include <stdio.h>

int main(void) {
    int stop = 0;  // 두 반복문을 모두 빠져나가기 위한 플래그

    for (int i = 1; i <= 3 && !stop; i++) {
        for (int j = 1; j <= 3; j++) {
            if (i == 2 && j == 2) {
                stop = 1;
                break;
            }
            printf("i=%d, j=%d\n", i, j);
        }
    }

    return 0;
}
```

## 무한 루프와 흔한 실수

반복문의 조건이 절대로 거짓이 되지 않아 영원히 반복이 끝나지 않는 것을 무한 루프(infinite loop)라고 합니다. 무한 루프는 의도적으로 만들 때도 있지만, 대부분은 실수로 발생합니다.

### 의도적인 무한 루프

서버 프로그램처럼 프로그램이 계속 실행되면서 사용자의 요청을 기다려야 하는 경우에는 의도적으로 무한 루프를 사용하고, 내부에서 `break`나 `return`으로 빠져나가는 조건을 따로 둡니다.

```c
#include <stdio.h>

int main(void) {
    int input;

    for (;;) {  // 조건이 없으므로 항상 참 -> 무한 반복
        printf("숫자를 입력하세요 (0을 입력하면 종료): ");
        scanf("%d", &input);

        if (input == 0) {
            break;
        }
        printf("입력한 값: %d\n", input);
    }

    printf("프로그램을 종료합니다.\n");
    return 0;
}
```

`while (1) { ... }`도 같은 목적으로 흔히 사용되는 관용적인 표현입니다.

### 흔한 실수 1: 조건 변수를 갱신하지 않음

```c
int i = 0;
while (i < 10) {
    printf("%d\n", i);
    // i++;  이 줄을 깜빡하면 i는 영원히 0으로 남아 무한 반복된다
}
```

반복문을 작성할 때는 항상 "이 조건이 언젠가는 거짓이 될 수 있는가?"를 스스로 점검하는 습관을 들이는 것이 좋습니다.

### 흔한 실수 2: 대입 연산자와 비교 연산자를 혼동함

```c
int i = 0;
while (i = 1) {   // 비교 == 대신 대입 = 을 사용한 실수
    printf("i는 항상 1입니다.\n");
    // i가 계속 1로 대입되며 조건은 항상 참이 되어 무한 반복
}
```

`i == 1`이라고 써야 할 자리에 `i = 1`이라고 쓰면, 이 표현식은 비교가 아니라 대입이 되어 버립니다. C 언어에서 대입식 `i = 1`의 값은 대입된 값인 1이므로, 조건은 언제나 참이 되어 무한 루프에 빠집니다. 이런 실수는 코드를 눈으로 여러 번 봐도 놓치기 쉬우므로 조건문을 작성할 때 항상 `==`와 `=`을 구분해서 확인하는 습관이 중요합니다. 이 부분은 4장 연산자와 표현식에서도 다룬 내용입니다.

### 흔한 실수 3: for문의 세미콜론을 잘못 찍음

```c
for (int i = 0; i < 5; i++);  // 여기서 세미콜론으로 문장이 끝나버림
{
    printf("%d\n", i);  // 컴파일 오류: i는 for문 밖에서 보이지 않는다
}
```

`for`문 뒤에 실수로 세미콜론을 붙이면 반복할 내용이 빈 문장(`;`)이 되어버려, 정작 뒤따르는 중괄호 블록은 반복문과 아무 상관없이 딱 한 번만 실행되는 별개의 블록이 됩니다. 이 실수는 컴파일 오류가 나지 않는 경우도 있어 발견하기 까다로우므로 주의가 필요합니다.

### 무한 루프 예방 체크리스트

- 반복문 안에서 조건식에 사용된 변수가 실제로 변화하는지 확인한다.
- 비교에는 `==`, 대입에는 `=`을 사용했는지 확인한다.
- `for`문, `while`문 뒤에 실수로 세미콜론을 붙이지 않았는지 확인한다.
- 의도적으로 무한 루프를 사용할 때는 반드시 내부에 `break`나 `return`으로 빠져나갈 수 있는 조건을 마련한다.

## 요약

- `while`문은 조건을 먼저 검사한 뒤 블록을 실행하며, 조건이 처음부터 거짓이면 한 번도 실행되지 않는다.
- `do-while`문은 블록을 먼저 실행한 뒤 조건을 검사하므로 최소 한 번은 실행이 보장된다.
- `for`문은 초기화식, 조건식, 증감식을 한곳에 모아 작성하며, 반복 횟수가 명확할 때 특히 적합하다.
- `break`는 가장 안쪽 반복문을 즉시 종료시키고, `continue`는 현재 반복만 건너뛰고 다음 반복으로 넘어간다.
- 중첩 반복문은 바깥쪽이 한 번 진행될 때마다 안쪽 반복문 전체가 실행되는 구조이며, 구구단이나 별 찍기처럼 2차원적인 패턴을 만들 때 유용하다.
- `break`는 자신을 감싼 가장 안쪽 반복문만 벗어나므로, 여러 겹의 반복문을 한꺼번에 빠져나가려면 플래그 변수나 함수 분리를 활용해야 한다.
- 무한 루프는 조건 변수를 갱신하지 않거나, `==`을 써야 할 곳에 `=`을 쓰거나, `for`/`while` 뒤에 세미콜론을 잘못 붙이는 실수에서 자주 발생한다.

2. `do-while`문을 사용하여 사용자가 "y" 또는 "n"을 입력할 때까지 계속 입력을 받는 프로그램을 작성하시오. (문자 입력은 `scanf("%c", &ch);` 형태를 사용해 봅니다.)
3. 중첩 `for`문을 사용하여 다음과 같은 역삼각형 모양을 출력하는 프로그램을 작성하시오.
   ```
   *****
   ****
   ***
   **
   *
   ```
4. 1부터 100까지의 정수 중에서 3의 배수는 건너뛰고(`continue` 사용), 짝수를 만나면 반복을 즉시 종료하는(`break` 사용) 프로그램을 작성하고, 각 단계에서 출력되는 값을 관찰해 보시오.

   ```c
   int i = 10;

   {

   }
   ```
