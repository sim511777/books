3장에서는 값을 담는 그릇인 변수와 자료형을 배웠다. 이제 그 값들을 서로 조합하고 계산하는 도구인 연산자(operator)를 알아볼 차례다. 연산자는 값과 값 사이의 관계를 정의하는 기호이며, 연산자와 피연산자(operand)가 모여 만들어지는 것이 표현식(expression)이다. 이번 장에서는 산술, 관계, 논리, 비트, 대입, 증감 연산자를 차례로 살펴보고, 연산자 우선순위와 결합법칙, 그리고 `sizeof` 연산자까지 다룬다. 마지막에는 표현식과 문장(statement)이 어떻게 다른지 정리하며 마무리한다.

## 표현식과 문장

먼저 용어부터 명확히 하고 시작하자. 표현식(expression)은 값을 만들어 내는 코드 조각이다. `3 + 4`, `x * y`, `a > b` 모두 계산되어 하나의 값으로 환원되는 표현식이다. 반면 문장(statement)은 프로그램이 수행할 하나의 동작 단위이며, 대개 세미콜론(`;`)으로 끝난다.

```c
int x = 3 + 4;   // "3 + 4"는 표현식, 세미콜론이 붙은 전체 줄은 문장이다.
x + 1;           // 이것도 문법적으로는 문장이지만, 계산 결과를 버리므로 의미가 없다.
```

두 번째 줄처럼 표현식 뒤에 세미콜론만 붙이면 그 자체로 하나의 문장(표현식 문장, expression statement)이 된다. 다만 `x + 1`의 결과를 어디에도 저장하지 않았으므로 계산은 이루어지되 그 값은 그냥 버려진다. 실제 프로그램에서는 이런 코드를 거의 쓰지 않지만, "표현식은 값이고 문장은 동작"이라는 구분을 이해하는 데 도움이 된다. 이 장에서 다루는 모든 연산자는 결국 표현식을 만들기 위한 재료이며, 그 표현식이 대입문이나 `if`문 등과 결합해 실제 문장을 이룬다.

## 산술 연산자

산술 연산자는 우리가 수학 시간에 배운 사칙연산과 나머지 연산을 그대로 제공한다.

| 연산자 | 의미 |
|---|---|
| `+` | 덧셈 |
| `-` | 뺄셈 |
| `*` | 곱셈 |
| `/` | 나눗셈 |
| `%` | 나머지 (모듈로) |

```c
#include <stdio.h>

int main(void) {
    int a = 17;
    int b = 5;

    printf("덧셈: %d\n", a + b);
    printf("뺄셈: %d\n", a - b);
    printf("곱셈: %d\n", a * b);
    printf("나눗셈: %d\n", a / b);   // 정수 나눗셈이므로 소수점 이하는 버려진다.
    printf("나머지: %d\n", a % b);

    return 0;
}
```

3장에서도 언급했듯이, 두 피연산자가 모두 정수형이면 `/`는 정수 나눗셈을 수행해 소수점 이하를 버린다. 실수 나눗셈이 필요하다면 피연산자 중 하나 이상을 `double`이나 `float`으로 만들어야 한다.

```c
#include <stdio.h>

int main(void) {
    int total = 17;
    int count = 5;

    double average = (double)total / count;   // 캐스팅으로 실수 나눗셈을 유도한다.
    printf("평균: %f\n", average);             // 3.400000

    return 0;
}
```

나머지 연산자 `%`는 정수형끼리만 사용할 수 있고, `float`이나 `double`에는 적용할 수 없다. 나머지 연산은 짝수/홀수 판별이나 순환하는 값(예: 요일 계산)을 다룰 때 매우 유용하다.

```c
#include <stdio.h>

int main(void) {
    int number = 7;

    if (number % 2 == 0) {
        printf("%d는 짝수입니다.\n", number);
    } else {
        printf("%d는 홀수입니다.\n", number);
    }

    return 0;
}
```

`if`와 `else`의 자세한 사용법은 6장 제어문에서 다루므로, 여기서는 `%` 연산자가 어떻게 쓰이는지에만 집중하자. 또한 음수를 포함한 나머지 연산의 부호는 나뉘는 수(피제수)의 부호를 따른다는 점도 기억해 두면 좋다. 예를 들어 `-7 % 2`는 `-1`이 된다.

## 대입 연산자

대입 연산자 `=`는 오른쪽 표현식의 값을 왼쪽 변수에 저장한다. C는 여기에 더해 "계산과 대입을 한 번에 처리하는" 복합 대입 연산자를 제공한다.

| 연산자 | 의미 | 풀어 쓴 예 |
|---|---|---|
| `+=` | 더한 뒤 대입 | `a += 3` → `a = a + 3` |
| `-=` | 뺀 뒤 대입 | `a -= 3` → `a = a - 3` |
| `*=` | 곱한 뒤 대입 | `a *= 3` → `a = a * 3` |
| `/=` | 나눈 뒤 대입 | `a /= 3` → `a = a / 3` |
| `%=` | 나머지 구한 뒤 대입 | `a %= 3` → `a = a % 3` |

```c
#include <stdio.h>

int main(void) {
    int balance = 10000;

    balance += 5000;    // 입금
    printf("입금 후: %d\n", balance);

    balance -= 3000;    // 출금
    printf("출금 후: %d\n", balance);

    balance *= 2;        // 두 배로 불어남
    printf("두 배 후: %d\n", balance);

    return 0;
}
```

복합 대입 연산자는 단순히 타이핑을 줄여 주는 것을 넘어, 변수 이름을 두 번 쓰지 않아도 되므로 긴 변수 이름을 다룰 때 실수를 줄여 준다.

## 증감 연산자: ++와 --

값을 1씩 늘리거나 줄이는 연산은 매우 자주 쓰이기 때문에 C는 전용 연산자를 제공한다. `++`는 값을 1 증가시키고, `--`는 1 감소시킨다. 이들은 변수 앞에 붙이는 전위(prefix) 형태와 뒤에 붙이는 후위(postfix) 형태로 나뉘며, 두 형태는 "다른 표현식과 함께 쓰였을 때" 동작이 달라진다.

```c
#include <stdio.h>

int main(void) {
    int a = 5;
    int b = 5;

    int prefix_result = ++a;    // a를 먼저 6으로 증가시킨 뒤 그 값을 대입한다.
    int postfix_result = b++;   // b의 원래 값 5를 먼저 대입한 뒤 b를 6으로 증가시킨다.

    printf("a = %d, prefix_result = %d\n", a, prefix_result);     // a = 6, prefix_result = 6
    printf("b = %d, postfix_result = %d\n", b, postfix_result);   // b = 6, postfix_result = 5

    return 0;
}
```

단독으로 한 줄에 `count++;`처럼 쓰일 때는 전위든 후위든 결과가 같으므로 크게 신경 쓸 필요가 없다. 하지만 다른 연산이나 대입과 뒤섞어 사용하면 코드가 읽기 어려워지고, 어떤 순서로 부작용(side effect)이 일어나는지 헷갈리기 쉽다.

```c
int i = 0;
int array_like_value = i++ + i++;   // 이런 코드는 절대 작성하지 말 것!
```

C 표준은 한 표현식 안에서 같은 변수를 두 번 이상 수정하면서 그 결과를 다시 사용하는 경우, 정확히 어떤 순서로 평가되는지 보장하지 않는다. 이런 코드는 컴파일러나 최적화 옵션에 따라 다른 결과를 낼 수 있으므로, 증감 연산자는 되도록 독립된 한 줄의 문장으로 사용하는 것이 안전하다. 반복문에서의 활용법은 7장 제어문 - 반복문에서 자연스럽게 다시 등장한다.

## 관계 연산자

관계 연산자는 두 값을 비교해서 참(1) 또는 거짓(0)을 만들어 낸다. C에는 원래 전용 논리형(boolean)이 없어서, 관계 연산과 논리 연산의 결과는 그냥 정수 0과 1로 표현된다.

| 연산자 | 의미 |
|---|---|
| `==` | 같다 |
| `!=` | 다르다 |
| `<` | 작다 |
| `>` | 크다 |
| `<=` | 작거나 같다 |
| `>=` | 크거나 같다 |

```c
#include <stdio.h>

int main(void) {
    int a = 10;
    int b = 20;

    printf("a == b : %d\n", a == b);   // 0 (거짓)
    printf("a != b : %d\n", a != b);   // 1 (참)
    printf("a < b  : %d\n", a < b);    // 1 (참)

    return 0;
}
```

여기서 자주 발생하는 실수 하나를 짚고 넘어가자. 같은지 비교할 때는 `==`를 써야 하는데, 실수로 대입 연산자 `=`를 쓰면 비교가 아니라 대입이 일어나 버그의 원인이 된다.

```c
int a = 5;

if (a = 10) {    // 의도는 비교였겠지만 실제로는 a에 10을 대입해 버린다.
    printf("항상 참으로 들어온다\n");
}
```

`a = 10`은 대입 표현식이며, 그 결과값(10)이 0이 아니므로 `if` 조건은 항상 참으로 평가된다. 이 실수는 컴파일러가 경고를 띄워 주는 경우가 많으니, 컴파일 시 경고 메시지를 꼼꼼히 확인하는 습관이 중요하다. `if`문의 자세한 동작 방식은 6장 제어문 - 조건문에서 다룬다. 참고로 C99 이후에는 `<stdbool.h>` 헤더를 포함하면 `bool`, `true`, `false`라는 이름을 사용할 수 있는데, 이는 6장에서 조금 더 소개한다.

## 논리 연산자

논리 연산자는 여러 개의 참/거짓 조건을 조합할 때 사용한다.

| 연산자 | 의미 |
|---|---|
| `&&` | 논리 AND (둘 다 참이어야 참) |
| `\|\|` | 논리 OR (하나라도 참이면 참) |
| `!` | 논리 NOT (참/거짓을 뒤집는다) |

```c
#include <stdio.h>

int main(void) {
    int age = 25;
    int has_ticket = 1;    // 1은 참, 0은 거짓을 의미하는 관례적 표현

    if (age >= 18 && has_ticket) {
        printf("입장 가능합니다.\n");
    }

    if (age < 10 || age > 65) {
        printf("할인 대상입니다.\n");
    } else {
        printf("일반 요금입니다.\n");
    }

    printf("has_ticket의 반대: %d\n", !has_ticket);   // 0

    return 0;
}
```

논리 연산자에서 반드시 알아 두어야 할 특성이 단락 평가(short-circuit evaluation)다. `&&`는 왼쪽 피연산자가 거짓이면 오른쪽은 아예 계산하지 않고 즉시 거짓으로 결론짓는다. 마찬가지로 `||`는 왼쪽이 참이면 오른쪽을 계산하지 않는다.

```c
#include <stdio.h>

int main(void) {
    int denominator = 0;
    int numerator = 10;

    // denominator가 0이므로 앞 조건이 거짓이 되어 뒤의 나눗셈은 절대 실행되지 않는다.
    if (denominator != 0 && numerator / denominator > 1) {
        printf("나눗셈 결과가 1보다 큽니다.\n");
    } else {
        printf("나눗셈을 건너뛰었습니다.\n");
    }

    return 0;
}
```

이 특성 덕분에 0으로 나누기 같은 위험한 연산을 조건문 안에서 안전하게 미리 걸러낼 수 있다. 단락 평가는 실무에서 매우 자주 활용되는 관용구이므로 꼭 기억해 두자.

## 비트 연산자

비트 연산자는 값을 이진수(비트) 단위로 다룬다. 하드웨어를 직접 제어하거나, 여러 개의 참/거짓 옵션을 하나의 정수에 압축해서 저장하는 플래그(flag) 기법에 자주 쓰인다.

| 연산자 | 의미 |
|---|---|
| `&` | 비트 AND |
| `\|` | 비트 OR |
| `^` | 비트 XOR |
| `~` | 비트 NOT (모든 비트를 뒤집음) |
| `<<` | 왼쪽 시프트 |
| `>>` | 오른쪽 시프트 |

```c
#include <stdio.h>

int main(void) {
    unsigned int a = 12;    // 이진수로 1100
    unsigned int b = 10;    // 이진수로 1010

    printf("a & b = %u\n", a & b);    // 1000 -> 8
    printf("a | b = %u\n", a | b);    // 1110 -> 14
    printf("a ^ b = %u\n", a ^ b);    // 0110 -> 6
    printf("~a    = %u\n", ~a);       // a의 모든 비트를 뒤집는다.
    printf("a << 2 = %u\n", a << 2);  // 왼쪽으로 2칸 이동, 값이 4배가 된다.
    printf("a >> 2 = %u\n", a >> 2);  // 오른쪽으로 2칸 이동, 값이 4분의 1이 된다.

    return 0;
}
```

비트 연산자는 여러 개의 켜짐/꺼짐 옵션을 하나의 정수 변수로 관리하는 비트마스크(bit mask) 기법에서 진가를 발휘한다.

```c
#include <stdio.h>

#define FLAG_READ    (1 << 0)   // 0001
#define FLAG_WRITE   (1 << 1)   // 0010
#define FLAG_EXECUTE (1 << 2)   // 0100

int main(void) {
    unsigned int permissions = FLAG_READ | FLAG_WRITE;   // 읽기, 쓰기 권한을 켠다.

    if (permissions & FLAG_WRITE) {
        printf("쓰기 권한이 있습니다.\n");
    }

    if (!(permissions & FLAG_EXECUTE)) {
        printf("실행 권한은 없습니다.\n");
    }

    return 0;
}
```

`&`(비트 AND, 두 값을 취급)와 `&&`(논리 AND, 두 조건을 취급)를 혼동하지 않도록 주의해야 한다. 마찬가지로 `|`와 `||`도 서로 다른 연산자다. `#define`으로 만든 `FLAG_READ` 같은 매크로 상수의 동작 원리는 16장 전처리기와 매크로에서 자세히 설명한다.

## 연산자 우선순위와 결합법칙

한 표현식에 여러 연산자가 섞여 있으면, C는 정해진 우선순위(precedence)에 따라 어떤 연산을 먼저 계산할지 결정한다. 예를 들어 곱셈과 나눗셈은 덧셈과 뺄셈보다 먼저 계산된다는 것은 수학 시간에 배운 것과 같다.

```c
int result = 2 + 3 * 4;    // 곱셈이 먼저 계산되어 result는 14가 된다.
```

우선순위가 같은 연산자가 여러 개 나열되면, 결합법칙(associativity)이 어느 방향으로 묶어서 계산할지를 정한다. 대부분의 산술 연산자는 왼쪽에서 오른쪽으로 묶이지만, 대입 연산자(`=`)나 단항 연산자는 오른쪽에서 왼쪽으로 묶인다.

```c
int a, b, c;
a = b = c = 10;    // 대입 연산자는 오른쪽에서 왼쪽으로 묶이므로 c, b, a 순서로 10이 대입된다.
```

모든 연산자의 우선순위를 외우려고 애쓸 필요는 없다. 실무에서는 우선순위가 헷갈릴 만한 표현식에는 괄호를 명시적으로 사용해서 코드를 읽는 사람(미래의 자신을 포함해서)이 계산 순서를 한눈에 알 수 있도록 작성하는 것이 훨씬 좋은 습관이다.

```c
// 우선순위를 외워야만 이해되는 코드
int value = a + b << 2 & c;

// 괄호로 의도를 명확히 드러낸 코드
int value = (a + b) << 2 & c;
```

전체 연산자의 우선순위와 결합법칙을 정리한 표는 부록의 "연산자 우선순위표"에서 확인할 수 있다.

## sizeof 연산자

`sizeof`는 어떤 자료형이나 변수, 표현식이 메모리에서 차지하는 바이트 수를 알려 주는 연산자다. 함수처럼 괄호를 쓰지만 실제로는 컴파일 시점에 계산되는 연산자이며, 결과는 `size_t`라는 부호 없는 정수형으로 반환된다.

```c
#include <stdio.h>

int main(void) {
    int number = 10;

    printf("int 자료형 크기: %zu\n", sizeof(int));
    printf("number 변수 크기: %zu\n", sizeof(number));
    printf("double 자료형 크기: %zu\n", sizeof(double));

    return 0;
}
```

`sizeof`는 배열 전체의 크기를 구하고, 그 값을 요소 하나의 크기로 나누어 배열에 들어 있는 요소 개수를 계산하는 관용구로도 널리 쓰인다.

```c
#include <stdio.h>

int main(void) {
    int scores[5] = { 90, 85, 100, 70, 95 };

    // 배열 전체 크기를 요소 하나의 크기로 나누어 개수를 구한다.
    size_t element_count = sizeof(scores) / sizeof(scores[0]);

    printf("배열 요소 개수: %zu\n", element_count);

    return 0;
}
```

배열을 선언하고 다루는 자세한 방법은 9장 배열에서 본격적으로 다루므로, 지금은 `sizeof`가 이런 식으로도 활용된다는 정도만 기억해 두면 된다. `sizeof`는 실행 중이 아니라 컴파일 시점에 크기가 계산되므로, 실행 속도에 전혀 부담을 주지 않는다는 것도 장점이다.

## 요약

- 표현식은 값을 만들어 내는 코드 조각이고, 문장은 세미콜론으로 끝나는 하나의 실행 단위다.
- 산술 연산자(`+ - * / %`)에서 정수 나눗셈은 소수점을 버리며, `%`는 정수형에만 사용할 수 있다.
- 복합 대입 연산자(`+= -= *= /= %=`)는 계산과 대입을 한 번에 처리해 코드를 간결하게 만든다.
- 증감 연산자(`++ --`)는 전위와 후위의 평가 시점이 다르므로, 다른 연산과 뒤섞어 쓰지 않는 것이 안전하다.
- 관계 연산자(`== != < > <= >=`)와 논리 연산자(`&& || !`)는 참(1)/거짓(0)을 만들며, `&&`와 `||`는 단락 평가로 불필요한 계산을 건너뛴다.
- 비트 연산자(`& | ^ ~ << >>`)는 값을 이진수 단위로 다루며, 플래그나 권한 관리 같은 비트마스크 기법에 자주 쓰인다.
- 연산자 우선순위와 결합법칙에 따라 계산 순서가 정해지지만, 헷갈릴 여지가 있다면 괄호를 사용해 의도를 명확히 하는 것이 좋다. 자세한 표는 부록에 있다.
- `sizeof` 연산자는 컴파일 시점에 자료형이나 변수의 크기를 바이트 단위로 알려 주며, 배열 요소 개수를 구하는 데도 활용된다.

## 연습문제

1. 두 정수를 입력받는 대신 코드 안에 직접 값을 대입한 뒤(`a = 13`, `b = 4`), 사칙연산과 나머지 연산 결과를 모두 출력하는 프로그램을 작성하라. 나눗셈 결과와 나머지 결과가 왜 그런 값이 나오는지 한국어 주석으로 설명하라.

2. 정수 변수 `count`를 0으로 초기화한 뒤, 전위 증가 연산자와 후위 증가 연산자를 각각 사용하는 두 개의 독립된 문장을 작성하고, 매 단계마다 `count`의 값을 출력해 두 방식의 차이를 눈으로 확인하라.

3. 단락 평가의 효과를 확인할 수 있는 예제를 작성하라. 배열 인덱스가 범위를 벗어나는지 먼저 검사한 뒤 `&&`로 배열 값을 확인하는 조건문을 만들어라 (배열은 9장에서 자세히 다루지만, 이 문제에서는 `int numbers[3] = {1, 2, 3};`과 같은 형태만 사용하면 된다).

4. 정수형 변수 하나에 세 가지 권한(읽기, 쓰기, 삭제)을 비트 플래그로 저장하고, 비트 연산자를 이용해 특정 권한을 켜고, 끄고, 검사하는 코드를 각각 작성하라.

5. `sizeof`를 이용해 여러분의 컴퓨터에서 `char`, `short`, `int`, `long`, `float`, `double`의 크기를 모두 출력하는 프로그램을 작성하고, 부록의 "자료형 크기 표"와 비교해 차이가 있는지 확인하라.
