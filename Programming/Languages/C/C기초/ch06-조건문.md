지금까지 작성한 프로그램은 위에서 아래로 문장을 순서대로 실행하는 것이 전부였습니다. 하지만 실제 프로그램은 상황에 따라 서로 다른 동작을 해야 하는 경우가 훨씬 많습니다. 로그인한 사용자의 권한에 따라 다른 화면을 보여 주거나, 입력값이 유효한 범위인지 검사하거나, 시험 점수에 따라 학점을 매기는 일들이 모두 "조건에 따른 분기"에 해당합니다. 이 장에서는 C 언어가 제공하는 조건 분기 도구인 `if`, `if-else`, `switch`, 그리고 조건 표현식(삼항 연산자)을 다룹니다.

## 6.1 프로그램의 흐름을 제어한다는 것

조건문은 "이 조건이 참이면 이 문장을 실행하고, 아니면 저 문장을 실행한다"는 규칙을 코드로 표현하는 수단입니다. 조건 자체는 4장 연산자와 표현식에서 다룬 관계 연산자(`==`, `!=`, `<`, `>`, `<=`, `>=`)와 논리 연산자(`&&`, `||`, `!`)로 만든 표현식입니다. C 언어에서는 이 조건 표현식의 값이 0이면 거짓, 0이 아니면 참으로 취급됩니다.

```c
int score = 85;

score >= 60;   // 이 표현식 자체의 값은 1(참) 또는 0(거짓)
```

이 조건 표현식을 어떻게 활용해서 실행 흐름을 나누는지가 이번 장의 핵심입니다.

## 6.2 if 문

`if` 문은 가장 기본적인 조건문으로, 조건이 참일 때만 지정된 문장(또는 블록)을 실행합니다. 조건이 거짓이면 그 블록은 그냥 건너뜁니다.

```c
#include <stdio.h>

int main(void)
{
    int temperature = 35;

    if (temperature >= 33) {
        printf("폭염 경보를 발령합니다.\n");
    }

    printf("현재 기온: %d도\n", temperature);

    return 0;
}
```

`if` 다음의 소괄호 안에는 반드시 조건 표현식이 와야 하며, 그 뒤에 실행할 문장을 중괄호 `{}`로 묶습니다. 실행할 문장이 단 하나뿐이면 중괄호를 생략할 수도 있지만, 나중에 문장을 추가할 때 실수하기 쉬우므로 이 책에서는 항상 중괄호를 붙이는 방식을 권장합니다.

```c
// 중괄호를 생략한 경우 - 문법적으로는 가능하지만 위험할 수 있음
if (temperature >= 33)
    printf("폭염 경보를 발령합니다.\n");
```

중괄호 없이 작성했다가 나중에 두 번째 문장을 추가하면, 그 문장은 `if`의 영향을 받지 않고 항상 실행되어 의도와 다르게 동작합니다.

```c
if (temperature >= 33)
    printf("폭염 경보를 발령합니다.\n");
    printf("외출을 자제하세요.\n");  // 들여쓰기와 달리 실제로는 항상 실행됨!
```

## 6.3 if-else 문

조건이 거짓일 때 실행할 문장도 함께 지정하고 싶다면 `else`를 사용합니다.

```c
#include <stdio.h>

int main(void)
{
    int number;

    printf("정수를 입력하세요: ");
    scanf("%d", &number);

    if (number % 2 == 0) {
        printf("%d는 짝수입니다.\n", number);
    } else {
        printf("%d는 홀수입니다.\n", number);
    }

    return 0;
}
```

`if`의 조건이 참이면 첫 번째 블록만 실행되고 `else` 블록은 건너뜁니다. 반대로 조건이 거짓이면 `else` 블록만 실행됩니다. 두 블록이 동시에 실행되는 경우는 없습니다.

## 6.4 else if 사슬

세 가지 이상의 경우를 나누어야 할 때는 `else if`를 이어서 사용합니다. 시험 점수로 학점을 매기는 예제를 살펴보겠습니다.

```text
                              ( 시작 )
                                 |
                                 v
                         < 점수 >= 90 ? >
                          |          \
                        거짓          참
                          |            \
                          v             v
                 < 점수 >= 80 ? >   +--------+
                  |          \     | A 학점  |
                거짓          참    +--------+
                  |            \        |
                  v             v       |
           +--------------+ +--------+  |
           | C 학점 (else) | | B 학점 |  |
           +--------------+ +--------+  |
                  |              |      |
                  +------+-------+------+
                         |
                         v
                     ( 종료 )
```

```c
#include <stdio.h>

int main(void)
{
    int score;
    char grade;

    printf("점수를 입력하세요: ");
    scanf("%d", &score);

    if (score >= 90) {
        grade = 'A';
    } else if (score >= 80) {
        grade = 'B';
    } else if (score >= 70) {
        grade = 'C';
    } else if (score >= 60) {
        grade = 'D';
    } else {
        grade = 'F';
    }

    printf("점수 %d의 학점은 %c입니다.\n", score, grade);

    return 0;
}
```

여기서 중요한 점은 조건을 검사하는 순서입니다. 위에서부터 순서대로 조건을 검사하다가 처음으로 참이 되는 조건을 만나면 그 블록만 실행하고 나머지 `else if`와 `else`는 모두 건너뜁니다. 만약 조건 순서를 반대로 `score >= 60`을 가장 먼저 검사한다면, 90점을 받은 학생도 조건이 참이 되어 곧바로 'D'로 분류되고 맙니다. 따라서 범위를 좁혀 가며 판단할 때는 더 좁은(또는 더 극단적인) 조건을 먼저 검사하는 순서가 중요합니다.

## 6.5 중첩 조건문

`if` 블록 안에 또 다른 `if`를 넣을 수 있습니다. 이를 중첩 조건문이라고 부르며, 여러 조건을 동시에 만족해야 하는 상황을 표현할 때 사용합니다.

```c
#include <stdio.h>

int main(void)
{
    int age;
    int has_ticket;

    printf("나이를 입력하세요: ");
    scanf("%d", &age);
    printf("티켓 소지 여부를 입력하세요(1: 있음, 0: 없음): ");
    scanf("%d", &has_ticket);

    if (age >= 18) {
        if (has_ticket == 1) {
            printf("입장 가능합니다.\n");
        } else {
            printf("티켓을 구매해야 합니다.\n");
        }
    } else {
        printf("보호자 동반이 필요합니다.\n");
    }

    return 0;
}
```

위 코드는 `age >= 18 && has_ticket == 1`처럼 논리 연산자로 합쳐서 하나의 `if`로도 쓸 수 있습니다. 하지만 조건이 거짓일 때 서로 다른 메시지("티켓 필요"와 "보호자 동반 필요")를 구분해서 보여 주려면, 이렇게 중첩된 형태가 더 명확할 때도 많습니다. 다만 중첩이 서너 단계 이상 깊어지면 코드를 읽기 어려워지므로, 아래처럼 조건을 논리 연산자로 정리하거나 조기에 처리를 끝내는 방식을 고려하는 것이 좋습니다.

```c
// 나쁜 예: 중첩이 깊어 조건을 한눈에 파악하기 어려움
if (a > 0) {
    if (b > 0) {
        if (c > 0) {
            printf("모두 양수입니다.\n");
        }
    }
}

// 개선한 예: 논리 연산자로 조건을 한 번에 표현
if (a > 0 && b > 0 && c > 0) {
    printf("모두 양수입니다.\n");
}
```

함수 안에서는 조건에 맞지 않는 경우를 먼저 걸러내고 곧바로 `return`으로 빠져나오는 "조기 반환" 방식으로 중첩을 줄이기도 합니다. 이 기법은 8장 함수에서 함수의 흐름 제어를 다룰 때 다시 살펴보겠습니다.

## 6.6 switch-case 문

하나의 변수 값이 여러 정수(또는 문자) 상수 중 어느 것과 일치하는지에 따라 분기하고 싶을 때는 `switch` 문이 `else if` 사슬보다 더 깔끔한 경우가 많습니다.

```c
#include <stdio.h>

int main(void)
{
    int weekday;

    printf("요일 번호를 입력하세요(1~7): ");
    scanf("%d", &weekday);

    switch (weekday) {
    case 1:
        printf("월요일입니다.\n");
        break;
    case 2:
        printf("화요일입니다.\n");
        break;
    case 3:
        printf("수요일입니다.\n");
        break;
    case 4:
        printf("목요일입니다.\n");
        break;
    case 5:
        printf("금요일입니다.\n");
        break;
    case 6:
    case 7:
        printf("주말입니다.\n");
        break;
    default:
        printf("올바른 요일 번호가 아닙니다.\n");
        break;
    }

    return 0;
}
```

`switch (weekday)`는 `weekday`의 값과 일치하는 `case` 레이블로 실행을 곧바로 이동시킵니다. `case 6:`과 `case 7:`을 연달아 써 놓고 그 사이에 아무 문장도 넣지 않으면, 두 값 모두 그 아래에 있는 같은 처리 코드(`printf("주말입니다.\n")`)로 흘러 들어갑니다. 이런 식으로 여러 값을 같은 처리로 묶을 수 있습니다.

### break의 역할

`case` 블록 끝에 있는 `break`는 `switch` 문을 빠져나가는 역할을 합니다. `break`를 빠뜨리면 실행 흐름이 다음 `case`로 그대로 이어져 내려가는데, 이를 폴스루(fall-through)라고 부릅니다.

```c
switch (weekday) {
case 1:
    printf("월요일입니다.\n");
    // break가 없으므로 계속 아래로 흘러 내려감
case 2:
    printf("화요일입니다.\n");
    break;
default:
    printf("그 외 요일입니다.\n");
}
```

`weekday`가 1이면 "월요일입니다."와 "화요일입니다."가 모두 출력됩니다. 이는 대부분의 경우 의도한 동작이 아니므로, 각 `case` 끝에 `break`를 넣는 것을 잊지 않아야 합니다. 앞서 6번과 7번을 묶었던 것처럼 폴스루를 의도적으로 활용하는 경우도 있지만, 그럴 때는 실수가 아니라 의도임을 나타내기 위해 주석을 남겨 두는 것이 좋은 습관입니다.

```c
case 6:
    // 폴스루 의도: 6번과 7번을 같은 처리로 묶음
case 7:
    printf("주말입니다.\n");
    break;
```

### default의 역할

`default`는 어떤 `case`와도 일치하지 않을 때 실행되는 블록으로, `if-else` 사슬의 마지막 `else`와 같은 역할을 합니다. `default`는 없어도 문법 오류는 아니지만, 예상하지 못한 값이 들어왔을 때를 대비해 넣어 두는 것이 안전합니다. `default`는 반드시 마지막에 있어야 하는 것은 아니지만 관례적으로 맨 뒤에 둡니다.

### switch 문의 제약

`switch`의 조건식과 각 `case`의 값은 정수 계열 타입(정수, 문자, 열거형)이어야 합니다. 실수나 문자열은 `switch`의 `case` 값으로 쓸 수 없습니다. 문자열을 비교해서 분기하고 싶다면 `else if` 사슬과 문자열 비교 함수를 사용해야 하며, 이는 10장 문자열에서 다룹니다.

```c
char grade = 'B';

switch (grade) {
case 'A':
    printf("우수합니다.\n");
    break;
case 'B':
    printf("양호합니다.\n");
    break;
default:
    printf("더 노력해 봅시다.\n");
    break;
}
```

## 6.7 조건 표현식(삼항 연산자) ?:

간단한 조건에 따라 두 값 중 하나를 선택하는 경우에는, `if-else` 대신 조건 표현식(삼항 연산자)을 사용해 한 줄로 표현할 수 있습니다. 문법은 `조건 ? 참일때값 : 거짓일때값` 형태입니다.

```c
#include <stdio.h>

int main(void)
{
    int a = 7, b = 3;
    int max;

    max = (a > b) ? a : b;   // a가 b보다 크면 a, 아니면 b

    printf("더 큰 값: %d\n", max);

    return 0;
}
```

위 코드는 다음의 `if-else` 문과 완전히 같은 의미입니다.

```c
if (a > b) {
    max = a;
} else {
    max = b;
}
```

조건 표현식은 값을 만들어 내는 표현식이므로, `printf`의 인자 자리처럼 값이 필요한 곳 어디에나 바로 끼워 넣을 수 있다는 장점이 있습니다.

```c
int n = 4;

printf("%d는 %s입니다.\n", n, (n % 2 == 0) ? "짝수" : "홀수");
```

다만 조건 표현식을 중첩해서 여러 개 이어 붙이면 코드가 급격히 읽기 어려워집니다.

```c
// 지나치게 압축된 예 - 가독성이 떨어짐
char grade = (score >= 90) ? 'A' : (score >= 80) ? 'B' : (score >= 70) ? 'C' : 'F';
```

이런 경우에는 앞서 본 `else if` 사슬을 사용하는 편이 코드를 읽는 사람에게 훨씬 친절합니다. 조건 표현식은 "값을 하나 고르는" 간단한 상황에 사용하고, 실행할 문장 자체가 여러 개이거나 조건이 복잡하다면 `if-else`를 사용하는 것이 좋은 기준이 됩니다.

## 6.8 가독성을 높이는 팁

조건문은 프로그램의 논리를 표현하는 핵심 도구인 만큼, 몇 가지 습관만으로도 코드의 가독성이 크게 달라집니다.

- **중괄호를 항상 사용합니다.** 실행할 문장이 하나뿐이어도 중괄호를 생략하지 않으면, 나중에 문장을 추가하다가 생기는 실수를 예방할 수 있습니다.
- **조건 순서를 신중히 정합니다.** `else if` 사슬에서는 더 좁거나 더 우선순위가 높은 조건을 먼저 검사해야 합니다.
- **중첩은 최소화합니다.** 여러 조건을 논리 연산자로 합칠 수 있다면 합치고, 함수 안에서는 조기 반환으로 중첩 단계를 줄이는 방법을 고려합니다.
- **폴스루는 명시적으로 표시합니다.** `switch`에서 의도적으로 `break`를 생략한다면 반드시 주석을 남겨 다른 사람(그리고 미래의 자신)이 실수로 여기지 않도록 합니다.
- **삼항 연산자는 짧고 단순하게 유지합니다.** 값 하나를 고르는 용도로만 쓰고, 여러 조건을 중첩하지 않습니다.

## 요약

- `if`는 조건이 참일 때만 블록을 실행하며, `if-else`는 참/거짓에 따라 서로 다른 블록을 실행합니다.
- `else if`를 연결하면 세 가지 이상의 경우를 순서대로 검사할 수 있으며, 조건 검사 순서가 결과에 영향을 줍니다.
- 중첩 조건문은 여러 조건을 동시에 만족해야 할 때 사용하지만, 지나치게 깊어지면 논리 연산자나 조기 반환으로 단순화하는 것이 좋습니다.
- `switch`는 정수 계열 값 하나를 여러 상수와 비교해 분기할 때 사용하며, `case` 끝에 `break`를 넣지 않으면 다음 `case`로 실행이 흘러 내려가는 폴스루가 발생합니다.
- `default`는 어떤 `case`와도 일치하지 않을 때 실행되는 블록으로, `switch`에서도 안전장치 역할을 합니다.
- 조건 표현식(`?:`)은 간단한 값 선택을 한 줄로 표현할 때 유용하지만, 중첩해서 사용하면 가독성이 떨어지므로 주의해야 합니다.

## 연습문제

1. 정수 세 개를 입력받아 그중 가장 큰 값을 출력하는 프로그램을 `if-else`만으로 작성하세요.
2. 1번 문제를 조건 표현식(`?:`)만 사용해서 다시 작성해 보세요.
3. 월(1~12)을 정수로 입력받아 해당 월이 몇 계절에 속하는지(봄/여름/가을/겨울) 출력하는 프로그램을 `switch` 문으로 작성하세요. (12, 1, 2월은 겨울, 3~5월은 봄과 같은 방식으로 나누어 봅니다.)
4. 세 변수 `a`, `b`, `c`에 삼각형의 세 변의 길이가 주어졌을 때, 삼각형이 성립하는지(각 변이 나머지 두 변의 합보다 작은지)와 성립한다면 정삼각형/이등변삼각형/일반삼각형 중 무엇인지 판별하는 프로그램을 작성하세요. 중첩 조건문을 사용하되, 3단계를 넘지 않도록 구성해 보세요.
5. 정수 하나를 입력받아 `switch` 문으로 그 값이 짝수인지 홀수인지 출력하는 프로그램을 작성하세요. (힌트: `switch (n % 2)`처럼 나머지 연산 결과를 조건식으로 사용할 수 있습니다.)
