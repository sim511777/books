프로그램은 결국 데이터를 받아서 가공하고 결과를 내놓는 작업이다. 그 데이터를 잠시 붙잡아 두는 그릇이 바로 변수(variable)이고, 그 그릇의 모양과 크기를 결정하는 것이 자료형(data type)이다. 2장에서 첫 프로그램을 컴파일하고 실행해 보았다면, 이번 장에서는 그 프로그램 안에서 실제로 값을 다루는 방법을 배운다. C 언어는 Python이나 JavaScript와 달리 변수를 사용하기 전에 "이 변수는 어떤 종류의 값을 담을 것인가"를 미리 못 박아 두어야 한다. 이 특징이 처음에는 번거롭게 느껴질 수 있지만, 실제로는 프로그램이 메모리를 얼마나 사용할지, 어떤 연산이 가능한지를 컴파일 단계에서 미리 점검해 주는 안전장치 역할을 한다.

## 변수란 무엇인가

변수는 값을 저장하기 위해 이름을 붙인 메모리 공간이다. 컴퓨터의 메모리는 수많은 칸으로 이루어진 거대한 서랍장과 비슷한데, 각 칸은 고유한 번지(주소)를 가지고 있다. 우리가 `age`라는 변수를 선언하면, 컴파일러는 정수를 저장할 수 있는 크기의 서랍 칸을 하나 확보하고, 이후 코드에서 `age`라는 이름으로 그 칸에 접근할 수 있게 해 준다. 프로그래머는 매번 복잡한 주소를 외울 필요 없이 의미 있는 이름으로 값을 다루면 된다.

```c
#include <stdio.h>

int main(void) {
    int age;          // 정수를 저장할 변수를 선언만 한다.
    age = 25;         // 나중에 값을 대입한다.

    printf("나이: %d\n", age);

    return 0;
}
```

위 코드에서 `int age;`는 "정수형 값을 저장할 `age`라는 이름의 공간을 만들어 달라"는 선언(declaration)이다. `age = 25;`는 그 공간에 25라는 값을 채워 넣는 대입(assignment)이다. 이렇게 선언과 대입을 분리할 수도 있고, 다음처럼 한 번에 처리할 수도 있다.

## 변수의 선언과 초기화

변수를 선언과 동시에 값을 넣어 주는 것을 초기화(initialization)라고 한다. 문법은 다음과 같다.

```c
자료형 변수이름 = 초깃값;
```

```c
#include <stdio.h>

int main(void) {
    int score = 90;          // 선언과 동시에 초기화
    double pi = 3.14159;     // 실수형 변수 초기화
    char grade = 'A';        // 문자형 변수 초기화

    printf("점수: %d, 원주율: %f, 학점: %c\n", score, pi, grade);

    return 0;
}
```

같은 자료형의 변수 여러 개를 한 줄에서 콤마로 구분해 선언할 수도 있다.

```c
int x = 1, y = 2, z = 3;   // 세 변수를 한 번에 선언 및 초기화
int width, height;         // 초기화 없이 두 변수만 선언
```

주의할 점은, 초기화하지 않은 지역 변수는 쓰레기 값(garbage value)을 담고 있다는 것이다. C는 변수를 자동으로 0으로 채워 주지 않는다(다만 프로그램 전역에 선언된 변수는 자동으로 0으로 초기화된다). 따라서 값을 대입하기 전에 지역 변수를 읽으면 예측할 수 없는 동작이 발생할 수 있으므로, 가능하면 선언과 동시에 초기화하는 습관을 들이는 것이 좋다.

```c
int total;                 // 아직 값이 정해지지 않았다.
printf("%d\n", total);     // 위험: total은 쓰레기 값을 가지고 있을 수 있다.
```

변수 이름을 지을 때는 몇 가지 규칙과 관례를 따라야 한다. 이름은 영문자나 밑줄(`_`)로 시작해야 하며, 숫자로 시작할 수 없다. 대소문자를 구분하므로 `Score`와 `score`는 서로 다른 변수다. 이 책에서는 `total_score`, `user_name`처럼 단어를 밑줄로 이어 붙이는 snake_case 표기를 사용한다. 또한 `int`, `if`, `while`처럼 C 언어가 이미 사용하고 있는 키워드는 변수 이름으로 쓸 수 없다.

변수를 어디에 선언하느냐에 따라 그 변수가 유효한 범위, 즉 스코프(scope)가 달라진다. 함수 안에서 선언한 변수는 그 함수 안에서만 사용할 수 있는데, 이 내용은 8장 함수에서 자세히 다룬다. 지금은 우선 `main` 함수 안에서 변수를 자유롭게 선언하고 사용하는 데 집중하자.

## 기본 자료형

C는 저장할 값의 종류에 따라 여러 가지 기본 자료형을 제공한다. 크게 정수를 담는 정수형, 소수점이 있는 값을 담는 실수형, 문자를 담는 문자형으로 나눌 수 있다.

### 정수형: int, short, long

정수형은 소수점이 없는 값을 저장한다. 가장 기본이 되는 것은 `int`이며, 필요에 따라 크기를 줄이거나 늘릴 수 있는 `short`와 `long`이 있다.

```c
#include <stdio.h>

int main(void) {
    short small_number = 100;
    int normal_number = 100000;
    long big_number = 10000000000L;      // 큰 정수에는 L 접미사를 붙인다.
    long long huge_number = 9000000000000LL;

    printf("%hd, %d, %ld, %lld\n", small_number, normal_number, big_number, huge_number);

    return 0;
}
```

### 문자형: char

`char`는 문자 하나를 저장하는 자료형이지만, 실제로는 1바이트 크기의 작은 정수로 취급된다. 문자는 작은따옴표로 감싸며, 내부적으로는 ASCII 코드값(정수)이 저장된다. ASCII 코드표는 부록에서 확인할 수 있다.

```c
#include <stdio.h>

int main(void) {
    char first_letter = 'A';

    printf("문자로 출력: %c\n", first_letter);
    printf("정수로 출력: %d\n", first_letter);   // 65가 출력된다.

    return 0;
}
```

### 실수형: float, double

소수점이 있는 값은 `float`(단정도)과 `double`(배정도)으로 표현한다. `double`이 `float`보다 더 정밀한 값을 표현할 수 있어서 특별한 이유가 없다면 실수 계산에는 `double`을 기본으로 사용하는 것이 좋다.

```c
#include <stdio.h>

int main(void) {
    float short_pi = 3.14159f;     // float 리터럴에는 f 접미사를 붙인다.
    double long_pi = 3.14159265358979;

    printf("float: %f\n", short_pi);
    printf("double: %lf\n", long_pi);

    return 0;
}
```

### unsigned와 signed: 부호의 유무

정수형 앞에 `unsigned`를 붙이면 음수를 포기하는 대신 0과 양수만으로 표현 범위를 두 배 넓힐 수 있다. 아무것도 붙이지 않으면 기본적으로 `signed`, 즉 음수와 양수를 모두 표현하는 자료형이 된다.

```c
#include <stdio.h>

int main(void) {
    unsigned int positive_only = 4000000000U;   // 큰 양수, U 접미사 사용
    signed int can_be_negative = -100;

    printf("%u\n", positive_only);
    printf("%d\n", can_be_negative);

    return 0;
}
```

### 자료형의 크기와 범위

각 자료형이 차지하는 메모리 크기(바이트 수)는 C 표준이 정확한 값을 강제하지 않고 "최소 이 정도는 되어야 한다"는 하한선만 정해 둔다. 그래서 실제 크기는 컴파일러와 운영체제, CPU 아키텍처에 따라 달라질 수 있다. 아래 표는 오늘날 널리 쓰이는 64비트 환경(예: 64비트 Windows나 리눅스에서 GCC로 컴파일한 경우)에서 흔히 볼 수 있는 값이며, 절대적인 기준이 아니라는 점을 기억해 두자.

| 자료형 | 일반적인 크기 | 대략적인 범위 (부호 있음) |
|---|---|---|
| char | 1바이트 | -128 ~ 127 |
| short | 2바이트 | -32,768 ~ 32,767 |
| int | 4바이트 | 약 -21억 ~ 21억 |
| long | 4바이트 또는 8바이트 | 플랫폼에 따라 다름 |
| long long | 8바이트 | 약 -922경 ~ 922경 |
| float | 4바이트 | 약 ±3.4 × 10^38 (유효자릿수 약 6~7자리) |
| double | 8바이트 | 약 ±1.7 × 10^308 (유효자릿수 약 15~16자리) |

정확한 크기가 궁금하다면 직접 확인하는 것이 가장 확실하다. `sizeof` 연산자를 사용하면 되는데, 자세한 사용법은 4장 연산자와 표현식에서 다루지만 여기서 미리 맛보기로 살펴보자.

```c
#include <stdio.h>

int main(void) {
    printf("char 크기: %zu바이트\n", sizeof(char));
    printf("int 크기: %zu바이트\n", sizeof(int));
    printf("double 크기: %zu바이트\n", sizeof(double));

    return 0;
}
```

`sizeof`가 반환하는 값은 `size_t`라는 자료형이며, 이를 출력할 때는 `%zu` 서식 지정자를 사용한다. 자료형의 정확한 크기와 범위를 정리한 표는 부록의 "자료형 크기 표"에서 다시 확인할 수 있다.

## 상수: 리터럴과 const

지금까지 코드에 직접 등장한 `25`, `3.14159`, `'A'` 같은 값들을 리터럴(literal) 상수라고 부른다. 리터럴은 그 자체로 값을 나타내며, 접미사를 붙여서 자료형을 명시할 수 있다. 정수 리터럴에는 `U`(unsigned), `L`(long), `LL`(long long)을, 실수 리터럴에는 `f`(float)를 붙인다.

```c
int a = 42;         // 그냥 쓰면 int로 해석된다.
long b = 42L;       // long 리터럴
unsigned c = 42U;   // unsigned 리터럴
float d = 3.14f;    // float 리터럴, 접미사가 없으면 double로 해석된다.
```

값이 한 번 정해지면 프로그램 실행 중에 절대 바뀌지 않아야 하는 경우도 있다. 이럴 때는 변수 선언 앞에 `const` 키워드를 붙인다.

```c
#include <stdio.h>

int main(void) {
    const double tax_rate = 0.1;    // 세율은 프로그램 도중 변하지 않는다.
    double price = 10000;
    double total = price + price * tax_rate;

    printf("총액: %.0f원\n", total);

    // tax_rate = 0.2;   // 이 줄의 주석을 풀면 컴파일 오류가 발생한다.

    return 0;
}
```

`const`가 붙은 변수에 값을 다시 대입하려고 하면 컴파일러가 오류를 낸다. 이는 실수로 값을 바꾸는 것을 막아 주는 안전장치다.

한편 C에는 `#define`을 사용해서 상수처럼 보이는 것을 만드는 방법도 있다.

```c
#define TAX_RATE 0.1
```

`const`와 `#define`은 비슷해 보이지만 근본적으로 다르다. `const`는 실제 자료형을 가진 변수이고, `#define`은 컴파일 전에 텍스트를 단순히 치환하는 전처리기(preprocessor) 지시문이다. 둘의 차이와 각각의 장단점은 16장 전처리기와 매크로에서 자세히 다룬다. 지금은 "값이 바뀌지 않아야 하는 값은 `const`나 `#define`으로 표시해 코드의 의도를 분명히 한다" 정도로만 기억해 두자.

## 형변환

서로 다른 자료형의 값을 함께 연산하거나 대입할 때, C는 값을 다른 자료형으로 자동으로 바꾸어 준다. 이를 형변환(type conversion)이라 하며, 컴파일러가 알아서 처리해 주는 암시적 형변환과 프로그래머가 직접 지시하는 명시적 형변환(캐스팅)으로 나뉜다.

### 암시적 형변환

크기가 작은 자료형의 값이 더 큰 자료형과 함께 연산되면, 작은 쪽이 큰 쪽에 맞춰 자동으로 변환된다.

```c
#include <stdio.h>

int main(void) {
    int count = 5;
    double average = 2.5;
    double result = count + average;   // count가 double로 자동 변환된 뒤 더해진다.

    printf("결과: %f\n", result);

    return 0;
}
```

반대로 큰 자료형의 값을 작은 자료형 변수에 대입하면 정보가 손실될 수 있다.

```c
#include <stdio.h>

int main(void) {
    double pi = 3.14159;
    int truncated = pi;    // 소수점 이하가 그냥 잘려 나간다.

    printf("truncated: %d\n", truncated);   // 3이 출력된다.

    return 0;
}
```

이런 대입은 컴파일러가 경고를 띄우기도 하지만 오류로 처리하지는 않는다. 그만큼 프로그래머가 자료형 사이의 관계를 스스로 파악하고 있어야 한다.

### 명시적 형변환 (캐스팅)

프로그래머가 "이 값을 이 자료형으로 취급해 달라"고 직접 지시하는 것이 명시적 형변환, 흔히 캐스팅(casting)이라고 부르는 방법이다. 괄호 안에 원하는 자료형을 적어서 표현한다.

```c
#include <stdio.h>

int main(void) {
    int total_score = 87;
    int student_count = 5;

    // 정수끼리 나누면 정수 결과만 남아 소수점이 사라진다.
    double wrong_average = total_score / student_count;
    printf("잘못된 평균: %f\n", wrong_average);   // 17.000000

    // 나눗셈 전에 하나를 double로 캐스팅하면 실수 나눗셈이 이루어진다.
    double correct_average = (double)total_score / student_count;
    printf("올바른 평균: %f\n", correct_average);  // 17.400000

    return 0;
}
```

위 예제는 형변환을 제대로 이해하지 못했을 때 자주 발생하는 실수를 보여 준다. `total_score / student_count`는 두 피연산자가 모두 `int`이므로 나눗셈도 정수 나눗셈으로 처리되어 소수점 이하가 통째로 사라진다. `(double)total_score`처럼 둘 중 하나만 캐스팅해도 나머지 피연산자가 암시적으로 `double`로 변환되면서 원하는 실수 나눗셈 결과를 얻을 수 있다.

캐스팅은 실수를 정수로 바꿀 때도 자주 쓰인다.

```c
#include <stdio.h>

int main(void) {
    double price = 1999.99;
    int rounded_down = (int)price;   // 소수점 이하를 버린다 (반올림이 아니다).

    printf("%d\n", rounded_down);    // 1999

    return 0;
}
```

`(int)`로 캐스팅하면 반올림이 아니라 소수점 이하를 그냥 잘라 버린다는 점에 유의해야 한다. 실수를 반올림해서 정수로 바꾸고 싶다면 `<math.h>`의 `round` 함수 등을 활용해야 하는데, 이런 표준 라이브러리 함수들은 17장 표준 라이브러리 둘러보기에서 폭넓게 다룬다.

## 변수는 메모리에 어떻게 저장되는가

지금까지 변수를 다루면서 "변수 이름"과 "그 안에 담긴 값"만 이야기했지만, 실제로 컴퓨터 내부에서는 각 변수가 메모리의 특정 주소에 자리를 잡고, 자료형에 따라 정해진 크기(바이트 수)만큼의 공간을 차지한다. `int`는 보통 4바이트, `char`는 1바이트를 차지하는 식이다. 변수 이름은 사람이 이해하기 쉽도록 컴파일러가 붙여 주는 별명일 뿐이고, 실제 기계어 코드는 메모리 주소를 통해 값을 읽고 쓴다.

```text
              변수 이름 - 메모리 주소 - 값의 관계

   age (int, 4바이트)      height (float, 4바이트)     grade (char, 1바이트)
          |                        |                          |
          v                        v                          v
   +-----+-----+-----+     +-----+-----+-----+           +---------+
   |     |  25 |     |     |     |175.5|     |           |   'A'   |
   +-----+-----+-----+     +-----+-----+-----+           +---------+
   주소: 0x1000           주소: 0x1004                 주소: 0x1008

   ------------------------------------------------------------->
                  메모리 주소가 증가하는 방향

   변수 이름은 프로그래머가 값에 붙인 별명이고, 실제로 컴파일러는 정해진
   메모리 주소를 통해 값을 찾아간다. 각 자료형은 저장에 필요한 바이트 수
   (칸의 개수)가 다르며, 실제 주소 값은 프로그램을 실행할 때마다 달라질 수 있다.
```

위 그림에서 `age`, `height`, `grade` 세 변수는 서로 다른 메모리 주소에 위치하며, 각자의 자료형 크기에 맞는 칸을 차지하고 있다. 이 관계를 이해하면 11장 포인터 기초에서 배울 "포인터는 메모리 주소를 저장하는 변수"라는 개념을 훨씬 자연스럽게 받아들일 수 있다. 지금 단계에서는 변수가 이름뿐 아니라 실제로는 메모리상의 위치와 크기를 가진 실체라는 점만 기억해 두면 충분하다.

## 요약

- 변수는 값을 저장하기 위해 이름을 붙인 메모리 공간이며, 사용하기 전에 자료형을 지정해서 선언해야 한다.
- 선언과 동시에 값을 넣는 것을 초기화라 하며, 초기화하지 않은 지역 변수는 예측할 수 없는 쓰레기 값을 가질 수 있다.
- 정수형(`int`, `short`, `long`, `long long`), 문자형(`char`), 실수형(`float`, `double`)이 기본 자료형이며, `unsigned`를 붙이면 음수 대신 더 넓은 양수 범위를 표현한다.
- 자료형의 크기와 범위는 플랫폼에 따라 달라질 수 있으며, 정확한 크기는 `sizeof` 연산자로 직접 확인할 수 있다.
- 리터럴에는 `U`, `L`, `LL`, `f` 같은 접미사로 자료형을 명시할 수 있고, 값이 바뀌지 않아야 하면 `const`를 사용한다. `#define`과의 차이는 16장에서 다룬다.
- 서로 다른 자료형이 섞이면 암시적 형변환이 자동으로 일어나며, `(자료형)값` 형태의 캐스팅으로 명시적 형변환을 지시할 수 있다. 특히 정수 나눗셈과 실수 나눗셈의 차이는 실무에서 자주 실수하는 지점이다.
- 변수는 실제 메모리상에서 이름이 아니라 주소를 통해 접근되며, 자료형에 따라 차지하는 바이트 수가 다르다.

## 연습문제

1. `int`, `char`, `double` 자료형의 변수를 각각 하나씩 선언하고 초기화한 뒤, `sizeof` 연산자를 이용해 각 변수가 차지하는 바이트 수를 화면에 출력하는 프로그램을 작성하라.

2. 정수형 변수 두 개(`a = 7`, `b = 2`)를 선언하고, 정수 나눗셈 결과와 캐스팅을 이용한 실수 나눗셈 결과를 각각 출력하는 프로그램을 작성하라. 두 결과가 왜 다른지 코드 안에 한국어 주석으로 설명하라.

3. 섭씨 온도를 저장하는 `double` 변수를 선언하고 값을 대입한 뒤, 화씨 온도로 변환하는 공식(화씨 = 섭씨 × 9 / 5 + 32)을 이용해 계산한 값을 출력하는 프로그램을 작성하라. 계산 과정에서 정수 나눗셈으로 인한 오류가 생기지 않도록 주의하라.

4. `const`로 선언한 상수 변수에 값을 다시 대입하는 코드를 작성해 보고, 컴파일 시 어떤 오류 메시지가 나타나는지 확인하라. 그 뒤 오류가 나는 줄을 주석 처리하여 정상적으로 컴파일되게 고쳐라.

5. `unsigned int` 변수에 `-1`을 대입한 뒤 `%u` 서식으로 출력해 보고, 왜 매우 큰 양수가 출력되는지 자신의 말로 설명하는 주석을 코드에 작성하라.
