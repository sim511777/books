Python이나 Java 같은 언어를 먼저 접한 사람이라면 문자열이 별도의 전용 자료형(`str`, `String`)으로 제공되는 것에 익숙할 것입니다. 하지만 C 언어에는 문자열이라는 독립된 자료형이 존재하지 않습니다. C에서 문자열은 그저 문자(`char`)들을 담은 배열이며, 그 끝을 나타내기 위한 특별한 규칙이 하나 추가되어 있을 뿐입니다.

이번 장에서는 C 언어에서 문자열이 실제로 어떻게 표현되는지, 문자열을 다루는 표준 함수들은 무엇이 있는지, 그리고 문자열을 입출력할 때 흔히 발생하는 버퍼 오버플로우 문제를 어떻게 피할 수 있는지 살펴봅니다. 이 장은 9장 배열에서 배운 내용을 그대로 확장한 것이므로, 배열 개념이 아직 낯설다면 9장을 먼저 복습하고 오는 것을 권합니다.

## C에서 문자열이란 무엇인가

C 언어에서 문자열은 `char`형 배열이며, 문자열의 끝에는 반드시 널 종료 문자(null terminator)라고 부르는 특별한 문자 `'\0'`이 붙습니다. 이 문자는 값이 0인 문자이며, 화면에 아무것도 출력되지 않는 "여기서 문자열이 끝난다"는 표시입니다.

예를 들어 "HI"라는 세 글자가 아닌 두 글자짜리 문자열을 저장하려면, 실제로는 3칸짜리 `char` 배열이 필요합니다.

```c
char greeting[3] = {'H', 'I', '\0'};
```

메모리 상에서는 다음과 같이 저장됩니다.

```
인덱스:  0    1    2
값:     'H'  'I'  '\0'
```

이 널 문자가 왜 중요한지는 문자열을 처리하는 표준 함수들의 동작을 보면 명확해집니다. `strlen`, `printf`의 `%s`, `strcpy` 같은 함수들은 모두 "배열이 몇 바이트인지"를 알지 못한 채로, 그저 앞에서부터 문자를 하나씩 읽어 나가다가 `'\0'`을 만나면 "여기까지가 문자열이구나"라고 판단합니다. 즉 널 종료 문자가 없다면 이 함수들은 문자열이 어디서 끝나는지 알 방법이 없어서, 메모리의 엉뚱한 영역까지 계속 읽어 나가는 심각한 오류를 일으킵니다.

## 문자열 리터럴과 초기화

큰따옴표로 둘러싼 문자들의 나열을 문자열 리터럴(string literal)이라고 합니다. 컴파일러는 문자열 리터럴을 만나면 그 내용 뒤에 자동으로 `'\0'`을 붙여줍니다.

```c
char greeting[3] = {'H', 'I', '\0'};   // 방법 1: 문자를 하나씩 나열
char greeting2[] = "HI";               // 방법 2: 문자열 리터럴 사용 (더 간편함)
```

`"HI"`는 눈에 보이는 글자 수가 2개이지만, 컴파일러는 널 종료 문자까지 포함해 크기 3짜리 배열을 만듭니다. 크기를 생략하면 컴파일러가 리터럴의 길이(+1)에 맞춰 자동으로 배열 크기를 정해 줍니다.

크기를 직접 지정할 때는 널 종료 문자를 위한 공간까지 고려해야 합니다.

```c
char name[10] = "Kim";   // 'K','i','m','\0' 이후 6바이트는 0으로 채워짐
```

주의할 점은, 배열이 한 번 선언된 뒤에는 `=` 연산자로 문자열 전체를 다시 대입할 수 없다는 것입니다.

```c
char name[10];
name = "Kim";   // 오류! 배열에는 통째로 대입할 수 없다
```

이미 선언된 배열의 내용을 바꾸려면 뒤에서 배울 `strcpy` 함수를 사용하거나, 인덱스로 문자를 하나씩 대입해야 합니다.

```c
char name[10];
strcpy(name, "Kim");   // strcpy 함수를 이용한 대입
```

## 문자열 출력과 입력

### printf로 문자열 출력하기

문자열을 출력할 때는 `%s` 서식 지정자를 사용합니다. `printf`는 주어진 주소부터 시작해서 `'\0'`을 만날 때까지 문자를 하나씩 출력합니다.

```c
#include <stdio.h>

int main(void) {
    char name[] = "홍길동";
    printf("이름: %s\n", name);
    return 0;
}
```

### scanf로 문자열 입력받기와 그 위험성

`scanf`의 `%s`로도 문자열을 입력받을 수 있지만, 여기에는 심각한 문제가 있습니다. `%s`는 공백을 만날 때까지 입력을 계속 읽어 들이는데, 입력받을 배열의 크기를 넘어서더라도 이를 검사하지 않습니다.

```c
#include <stdio.h>

int main(void) {
    char name[10];
    printf("이름을 입력하세요: ");
    scanf("%s", name);   // & 없이 배열 이름 그대로 전달 (배열은 이미 주소처럼 동작)
    printf("입력한 이름: %s\n", name);
    return 0;
}
```

만약 사용자가 10글자가 넘는 문자열을 입력하면, `name` 배열의 공간을 넘어서 다른 변수나 프로그램의 중요한 메모리 영역까지 덮어써 버립니다. 이런 현상을 버퍼 오버플로우(buffer overflow)라고 하며, 프로그램이 예측 불가능하게 동작하거나 심각한 보안 취약점으로 이어질 수 있는 대표적인 문제입니다. 이 위험성 때문에 `scanf("%s", ...)`는 실무에서는 가급적 피하는 것이 좋습니다.

### fgets로 안전하게 입력받기

`fgets` 함수는 최대로 읽어 들일 글자 수를 인자로 지정할 수 있어서, 배열의 크기를 넘어서는 입력을 방지할 수 있습니다.

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char line[10];

    printf("문장을 입력하세요: ");
    fgets(line, sizeof(line), stdin);   // 최대 sizeof(line) - 1 글자까지만 읽음

    // fgets는 개행 문자('\n')까지 함께 저장하므로 필요하면 제거한다
    line[strcspn(line, "\n")] = '\0';

    printf("입력한 내용: %s\n", line);
    return 0;
}
```

`fgets(line, sizeof(line), stdin)`은 표준 입력(`stdin`)에서 최대 `sizeof(line) - 1`개의 문자를 읽고, 마지막에 자동으로 `'\0'`을 붙여줍니다. 즉 아무리 긴 문장을 입력해도 `line` 배열의 크기를 넘어서지 않는다는 것이 보장됩니다. `strcspn(line, "\n")`은 `line`에서 `'\n'`이 처음 나타나는 위치를 찾아 주는 함수로, 이를 이용해 `fgets`가 남겨 놓은 개행 문자를 널 문자로 바꿔서 제거하는 관용적인 방법입니다.

### 절대 사용하면 안 되는 함수: gets

과거 C 표준에는 `gets`라는 함수도 있었지만, 이 함수는 입력받을 배열의 크기를 전혀 알 수 없는 구조여서 버퍼 오버플로우를 원천적으로 막을 방법이 없습니다. 이러한 이유로 `gets`는 C11 표준에서 완전히 제거되었으며, 어떤 상황에서도 사용해서는 안 되는 함수입니다. 문자열을 한 줄 입력받아야 한다면 항상 `fgets`를 사용하세요.

## 표준 문자열 함수 (string.h)

C 표준 라이브러리는 `<string.h>` 헤더 파일에 문자열을 다루는 다양한 함수를 제공합니다. 이 함수들은 모두 "문자열은 `'\0'`으로 끝난다"는 규칙에 의존해서 동작합니다. 17장 표준 라이브러리 둘러보기에서 더 폭넓은 라이브러리를 다루지만, 문자열 함수는 사용 빈도가 매우 높으므로 여기서 자세히 소개합니다.

### strlen: 문자열의 길이 구하기

`strlen`은 `'\0'`을 제외한 문자의 개수, 즉 눈에 보이는 문자열의 길이를 반환합니다.

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char word[] = "programming";
    printf("길이: %zu\n", strlen(word));   // 11
    return 0;
}
```

`strlen`의 반환형은 부호 없는 정수형인 `size_t`이므로, `printf`에서는 `%zu` 서식을 사용하는 것이 정확합니다.

### strcpy와 strncpy: 문자열 복사

`strcpy(dest, src)`는 `src` 문자열 전체(널 문자 포함)를 `dest`로 복사합니다.

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char src[] = "Hello";
    char dest[20];

    strcpy(dest, src);
    printf("복사된 문자열: %s\n", dest);   // Hello

    return 0;
}
```

문제는 `strcpy`도 `dest`의 크기를 전혀 검사하지 않는다는 점입니다. `src`가 `dest`보다 크면 역시 버퍼 오버플로우가 발생합니다. 이를 막기 위한 안전한 대안이 `strncpy`이며, 복사할 최대 글자 수를 지정할 수 있습니다.

```c
char dest[10];
strncpy(dest, src, sizeof(dest) - 1);   // 최대 9글자만 복사
dest[sizeof(dest) - 1] = '\0';          // 널 종료를 직접 보장해 주어야 안전하다
```

`strncpy`는 지정한 개수만큼 복사할 문자가 없으면 널 문자를 자동으로 채워 주지만, 반대로 `src`가 지정한 개수보다 길면 널 문자를 붙이지 않을 수도 있습니다. 그래서 위 예제처럼 마지막 자리에 직접 `'\0'`을 넣어 주는 습관을 들이는 것이 안전합니다.

### strcat와 strncat: 문자열 이어 붙이기

`strcat(dest, src)`는 `dest` 문자열의 끝에 `src` 문자열을 이어 붙입니다.

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char message[30] = "Hello, ";
    strcat(message, "world!");
    printf("%s\n", message);   // Hello, world!
    return 0;
}
```

`strcat` 역시 `dest`의 남은 공간을 검사하지 않으므로, `dest` 배열은 두 문자열을 합친 결과와 널 문자까지 담을 수 있을 만큼 충분히 커야 합니다. 안전한 버전인 `strncat`은 이어 붙일 최대 글자 수를 지정할 수 있습니다.

```c
char message[30] = "Hello, ";
strncat(message, "world! this is a very long text", sizeof(message) - strlen(message) - 1);
```

### strcmp: 문자열 비교

두 문자열이 같은지 비교할 때 `==` 연산자를 사용하면 안 됩니다. 배열 이름은 사실상 주소이므로 `==`는 문자열의 내용이 아니라 주소를 비교하게 되어, 원하는 결과를 얻을 수 없습니다. 대신 `strcmp` 함수를 사용해야 합니다.

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char password[] = "1234";
    char input[] = "1234";

    if (strcmp(password, input) == 0) {
        printf("비밀번호가 일치합니다.\n");
    } else {
        printf("비밀번호가 일치하지 않습니다.\n");
    }

    return 0;
}
```

`strcmp`는 두 문자열이 완전히 같으면 `0`을 반환하고, 사전순으로 첫 번째 문자열이 더 앞서면 음수를, 더 뒤에 있으면 양수를 반환합니다. "같다 = 0"이라는 점이 직관과 다소 다르므로 처음에는 헷갈리기 쉽지만, if 조건에서는 항상 `== 0`으로 비교한다는 것을 기억하면 됩니다. 앞 n글자만 비교하는 `strncmp`도 함께 알아 두면 유용합니다.

### 그 밖에 알아 두면 좋은 함수들

`<string.h>`에는 이 밖에도 유용한 함수가 많습니다. 자주 쓰이는 몇 가지만 간단히 소개합니다.

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char text[] = "hello, world";

    char *comma = strchr(text, ',');       // 문자 ','가 처음 나오는 위치를 찾음
    printf("%s\n", comma);                 // ", world"

    char *found = strstr(text, "world");   // 부분 문자열 "world"의 시작 위치를 찾음
    printf("%s\n", found);                 // "world"

    return 0;
}
```

`strchr`은 특정 문자를 찾고, `strstr`은 특정 부분 문자열을 찾습니다. 두 함수 모두 찾지 못하면 `NULL`을 반환하므로, 반환값을 사용하기 전에 `NULL`인지 확인하는 습관이 필요합니다. 이 함수들이 반환하는 포인터의 정확한 의미는 11장 포인터 기초를 배운 뒤 다시 보면 더 명확하게 이해될 것입니다.

## 버퍼 오버플로우 정리

이번 장에서 여러 번 강조했듯, C의 문자열 함수 대부분은 대상 배열의 크기를 스스로 검사하지 않습니다. 아래 표는 위험한 함수와 그 안전한 대안을 정리한 것입니다.

| 상황 | 위험한 방법 | 권장하는 방법 |
|---|---|---|
| 한 줄 입력받기 | `gets`, `scanf("%s", ...)` | `fgets` |
| 문자열 복사 | `strcpy` | `strncpy` + 널 문자 직접 보장 |
| 문자열 이어 붙이기 | `strcat` | `strncat` + 남은 공간 계산 |

공통된 원칙은 하나입니다. 항상 "이 배열의 크기는 몇 바이트인가"를 먼저 생각하고, 그 크기를 넘어서지 않도록 함수에 명시적으로 알려주어야 한다는 것입니다.

## 예제: 회문(팰린드롬) 검사

문자열을 앞에서 읽으나 뒤에서 읽으나 같은 단어를 회문(palindrome)이라고 합니다. 예를 들어 "level", "reviver" 같은 단어가 회문입니다. 배열 인덱스를 양쪽 끝에서부터 좁혀 오면서 비교하면 간단히 검사할 수 있습니다.

```c
#include <stdio.h>
#include <string.h>

int is_palindrome(const char *str) {
    int left = 0;
    int right = strlen(str) - 1;

    while (left < right) {
        if (str[left] != str[right]) {
            return 0;   // 다른 문자가 발견되면 회문이 아니다
        }
        left++;
        right--;
    }

    return 1;   // 끝까지 모두 같았다면 회문이다
}

int main(void) {
    char word[100];

    printf("단어를 입력하세요: ");
    fgets(word, sizeof(word), stdin);
    word[strcspn(word, "\n")] = '\0';   // fgets가 남긴 개행 문자 제거

    if (is_palindrome(word)) {
        printf("\"%s\"는 회문입니다.\n", word);
    } else {
        printf("\"%s\"는 회문이 아닙니다.\n", word);
    }

    return 0;
}
```

`left`는 문자열의 맨 앞을, `right`는 맨 뒤를 가리키며, 두 인덱스가 서로를 향해 좁혀 오면서 각 위치의 문자를 비교합니다. 하나라도 다르면 즉시 회문이 아니라고 판단하고, 두 인덱스가 서로 마주칠 때까지 모두 같았다면 회문이라고 판단합니다.

## 예제: 문자열 뒤집기

배열의 원소를 직접 다루는 연습으로, 문자열을 제자리에서(추가 배열 없이) 뒤집는 함수도 만들어 보겠습니다.

```c
#include <stdio.h>
#include <string.h>

void reverse_string(char *str) {
    int left = 0;
    int right = strlen(str) - 1;

    while (left < right) {
        char temp = str[left];
        str[left] = str[right];
        str[right] = temp;
        left++;
        right--;
    }
}

int main(void) {
    char text[] = "Hello, World!";

    reverse_string(text);
    printf("%s\n", text);   // !dlroW ,olleH

    return 0;
}
```

이 함수는 배열 안의 값을 직접 맞바꾸는 방식으로 동작하므로, 새로운 배열을 따로 만들지 않고도 문자열을 뒤집을 수 있습니다. 이런 "두 인덱스를 양 끝에서 좁혀 오는" 패턴은 문자열과 배열 문제에서 매우 자주 활용되니 익혀 두면 좋습니다.

## 요약

- C 언어에는 전용 문자열 자료형이 없으며, 문자열은 `char` 배열에 값을 저장하고 끝에 널 종료 문자 `'\0'`을 붙이는 방식으로 표현됩니다.
- 문자열 리터럴 `"..."`을 이용해 배열을 초기화하면 컴파일러가 널 문자를 자동으로 붙여 줍니다. 단, 배열이 선언된 이후에는 `=`로 문자열 전체를 다시 대입할 수 없습니다.
- 문자열을 출력할 때는 `%s`, 안전하게 한 줄을 입력받을 때는 `fgets`를 사용합니다. `scanf("%s", ...)`와 `gets`는 버퍼 오버플로우 위험이 있어 피해야 합니다.
- `<string.h>`가 제공하는 `strlen`, `strcpy`/`strncpy`, `strcat`/`strncat`, `strcmp` 등의 함수는 모두 널 종료 문자에 의존해서 동작하며, 대상 배열의 크기를 스스로 검사하지 않으므로 크기를 직접 관리해 주어야 합니다.
- 두 문자열이 같은지 비교할 때는 `==`가 아니라 반드시 `strcmp`를 사용해야 하며, `strcmp`는 같을 때 `0`을 반환합니다.
- 배열의 양 끝에서 인덱스를 좁혀 오는 패턴은 회문 검사, 문자열 뒤집기 등 다양한 문자열 문제에서 유용하게 쓰입니다.

## 연습문제

1. 사용자에게 문자열을 입력받아(`fgets` 사용), 그 문자열에 포함된 알파벳 개수, 숫자 개수, 공백 개수를 각각 세어 출력하는 프로그램을 작성하세요. (힌트: `<ctype.h>`의 `isalpha`, `isdigit`, `isspace` 함수를 활용할 수 있습니다.)
2. `strcpy`를 사용하지 않고, 직접 반복문으로 문자를 하나씩 복사하는 나만의 문자열 복사 함수 `my_strcpy(char *dest, const char *src)`를 작성하세요.
3. 표준 함수 `strlen`을 사용하지 않고 문자열의 길이를 직접 계산하는 함수 `my_strlen(const char *str)`을 작성한 뒤, 표준 `strlen`의 결과와 비교해 같은 값이 나오는지 확인하세요.
4. 문장을 입력받아 그 문장에 포함된 단어의 개수를 세어 출력하는 프로그램을 작성하세요. (단어는 공백으로 구분된다고 가정합니다.)
5. 크기가 5인 `char` 배열에 `strcpy`로 6글자 이상의 문자열을 복사하려고 시도하는 코드를 작성해 보고, 어떤 문제가 발생할 수 있는지 주석으로 설명한 뒤, 같은 동작을 `strncpy`를 이용해 안전하게 고쳐 보세요.
