11장 포인터 기초에서 포인터가 무엇이고 어떻게 선언하고 역참조하는지 살펴보았습니다. 이번 장에서는 그 지식을 실제로 활용하는 방법을 다룹니다. 배열과 포인터가 왜 그렇게 비슷하게 동작하는지, 함수에 값을 전달할 때 원본을 직접 수정하려면 어떻게 해야 하는지, 그리고 포인터의 포인터와 함수 포인터라는 조금 더 고급 개념까지 순서대로 살펴보겠습니다. 이 장의 내용은 9장 배열과 8장 함수에서 배운 내용을 포인터의 관점에서 다시 조명하는 작업이기도 하므로, 필요하다면 두 장을 함께 참고하시기 바랍니다.

## 12.1 배열과 포인터의 관계

9장 배열에서 배열은 같은 자료형의 값을 연속된 메모리 공간에 나란히 저장하는 자료구조라고 배웠습니다. 그런데 C에서는 배열의 이름을 대부분의 문맥에서 "배열의 첫 번째 원소의 주소"로 취급합니다. 즉, 배열 이름은 마치 포인터처럼 동작합니다.

```c
#include <stdio.h>

int main(void) {
    int scores[5] = {90, 85, 77, 92, 68};

    printf("scores의 값(주소로 해석됨): %p\n", (void *)scores);
    printf("&scores[0]:              %p\n", (void *)&scores[0]);

    return 0;
}
```

이 프로그램을 실행하면 `scores`와 `&scores[0]`이 정확히 같은 주소를 출력합니다. 이것은 배열 이름 `scores`가 배열 전체를 대표하는 동시에, 배열의 첫 원소를 가리키는 주소값으로도 취급된다는 뜻입니다.

이 성질 덕분에 배열의 원소를 포인터를 이용해서도 접근할 수 있습니다.

```c
#include <stdio.h>

int main(void) {
    int scores[5] = {90, 85, 77, 92, 68};
    int *p = scores;   // p는 scores[0]의 주소를 가리킨다 (= &scores[0])

    printf("p가 가리키는 값: %d\n", *p);          // scores[0]과 같음
    printf("배열 표기법: %d\n", scores[0]);

    printf("*(p + 1): %d\n", *(p + 1));           // scores[1]과 같음
    printf("scores[1]: %d\n", scores[1]);

    return 0;
}
```

실행 결과는 다음과 같습니다.

```
p가 가리키는 값: 90
배열 표기법: 90
*(p + 1): 85
scores[1]: 85
```

여기서 `p + 1`이 단순히 주소값에 1을 더한 것이 아니라는 점을 주의 깊게 봐야 합니다. `p`는 `int *`형 포인터이므로, `p + 1`은 "메모리 주소에 1을 더한 값"이 아니라 "int 하나의 크기(보통 4바이트)만큼 다음 원소로 이동한 주소"를 의미합니다. 이를 **포인터 연산(pointer arithmetic)**이라고 부르며, 포인터가 가리키는 자료형의 크기를 기준으로 자동으로 계산됩니다.

```c
#include <stdio.h>

int main(void) {
    int arr[3] = {10, 20, 30};
    int *p = arr;

    printf("p:     %p\n", (void *)p);
    printf("p + 1: %p\n", (void *)(p + 1));
    printf("p + 2: %p\n", (void *)(p + 2));

    return 0;
}
```

출력을 보면 `p`, `p + 1`, `p + 2`의 주소값이 정확히 `sizeof(int)`(보통 4)만큼씩 증가하는 것을 확인할 수 있습니다. 이것이 `double *` 포인터라면 `sizeof(double)`(보통 8)만큼씩 증가합니다. 이처럼 포인터 연산은 포인터가 가리키는 자료형을 고려해서 자동으로 계산되므로, 프로그래머는 바이트 단위를 직접 계산할 필요 없이 "다음 원소로 이동"이라는 개념으로 다룰 수 있습니다.

배열 표기법 `arr[i]`와 포인터 표기법 `*(arr + i)`는 사실상 완전히 동일한 코드로 컴파일됩니다.

```c
arr[i];        // 이것과
*(arr + i);    // 이것은 항상 같은 값을 나타낸다
```

다만 배열 이름과 포인터 변수 사이에는 중요한 차이도 있습니다. 배열 이름은 그 자체를 다른 주소로 재대입할 수 없는 상수와 같은 성격을 가지지만, 포인터 변수는 다른 주소를 다시 대입할 수 있습니다.

```c
int arr[3] = {1, 2, 3};
int *p = arr;

p = p + 1;     // 가능: p는 변수이므로 다른 주소를 가리키게 할 수 있다
// arr = arr + 1;  // 오류: 배열 이름 자체는 재대입할 수 없다
```

## 12.2 함수에 포인터를 전달하기 (call by reference 흉내)

8장 함수에서 함수를 호출할 때 인자를 전달하는 방식을 배웠습니다. C에서 함수에 일반 변수를 그대로 넘기면, 그 변수의 **값이 복사**되어 함수 안으로 전달됩니다. 이를 **값에 의한 전달(call by value)**이라고 부릅니다. 이 방식에서는 함수 내부에서 매개변수의 값을 바꿔도 호출한 쪽의 원본 변수에는 아무 영향이 없습니다.

```c
#include <stdio.h>

void try_to_double(int n) {
    n = n * 2;   // 복사본 n의 값만 바뀐다
}

int main(void) {
    int num = 5;
    try_to_double(num);
    printf("num의 값: %d\n", num);   // 여전히 5

    return 0;
}
```

만약 함수가 호출한 쪽의 실제 변수 값을 바꾸도록 만들고 싶다면, 변수의 값이 아니라 **그 변수의 주소**를 전달해야 합니다. 함수 쪽에서는 그 주소를 포인터 매개변수로 받아서 역참조로 원본을 직접 수정합니다. C에는 다른 언어처럼 "참조에 의한 전달(call by reference)" 문법이 따로 있는 것은 아니지만, 포인터를 이용해서 사실상 같은 효과를 낼 수 있습니다.

```c
#include <stdio.h>

void double_it(int *n) {
    *n = *n * 2;   // n이 가리키는 원본 변수를 직접 수정
}

int main(void) {
    int num = 5;
    double_it(&num);   // num의 주소를 전달
    printf("num의 값: %d\n", num);   // 10

    return 0;
}
```

이 원리를 이용하면 함수 하나로 여러 값을 동시에 "반환"하는 효과도 낼 수 있습니다. C의 함수는 `return`으로 값을 하나만 반환할 수 있지만, 포인터 매개변수를 여러 개 사용하면 여러 결과를 한꺼번에 돌려줄 수 있습니다.

```c
#include <stdio.h>

// 두 수를 나눈 몫과 나머지를 동시에 구해서 돌려주는 함수
void divide(int dividend, int divisor, int *quotient, int *remainder) {
    *quotient = dividend / divisor;
    *remainder = dividend % divisor;
}

int main(void) {
    int q, r;

    divide(17, 5, &q, &r);
    printf("17 / 5 = 몫 %d, 나머지 %d\n", q, r);

    return 0;
}
```

실행 결과는 다음과 같습니다.

```
17 / 5 = 몫 4, 나머지 1
```

이런 방식은 표준 라이브러리에서도 자주 쓰입니다. 예를 들어 `scanf` 함수가 변수 앞에 `&`를 붙여서 호출하는 이유도 바로 이것입니다. `scanf`는 함수 내부에서 사용자가 입력한 값을 여러분이 지정한 변수의 실제 메모리 위치에 직접 써넣어야 하므로, 값이 아니라 주소를 받아야 합니다.

```c
int age;
scanf("%d", &age);   // age의 주소를 전달해야 scanf가 그 위치에 값을 쓸 수 있다
```

배열을 함수의 인자로 넘길 때는 이미 배열 이름 자체가 주소로 취급되므로, 별도로 `&`를 붙이지 않아도 함수 안에서 원본 배열의 원소를 직접 수정할 수 있습니다.

```c
#include <stdio.h>

// 배열의 모든 원소를 2배로 만드는 함수
void double_all(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        arr[i] = arr[i] * 2;   // 원본 배열의 원소를 직접 수정
    }
}

int main(void) {
    int numbers[4] = {1, 2, 3, 4};

    double_all(numbers, 4);

    for (int i = 0; i < 4; i++) {
        printf("%d ", numbers[i]);
    }
    printf("\n");   // 2 4 6 8

    return 0;
}
```

여기서 매개변수 `int arr[]`는 사실 `int *arr`과 완전히 동일하게 취급됩니다. C 컴파일러는 함수의 매개변수로 선언된 배열 표기법을 자동으로 포인터로 변환하기 때문입니다. 이 내용은 9장 배열에서 배열을 함수 인자로 넘길 때 배열 전체가 복사되지 않는다고 설명한 부분과 정확히 같은 원리입니다.

## 12.3 포인터의 포인터 (이중 포인터)

포인터 변수도 메모리에 저장되는 하나의 변수이므로, 그 포인터 변수의 주소를 저장하는 또 다른 포인터를 만들 수 있습니다. 이를 **이중 포인터(double pointer)** 또는 **포인터의 포인터**라고 부르며, `**`로 선언합니다.

```c
#include <stdio.h>

int main(void) {
    int num = 42;
    int *p = &num;      // p는 num을 가리키는 포인터
    int **pp = &p;       // pp는 p를 가리키는 포인터(포인터의 포인터)

    printf("num:   %d\n", num);
    printf("*p:    %d\n", *p);      // num과 같음
    printf("**pp:  %d\n", **pp);    // p를 한 번 역참조하면 p의 값(주소)이 나오고,
                                     // 한 번 더 역참조하면 num의 값이 나온다

    return 0;
}
```

`pp`는 `p`의 주소를 저장하고 있으므로, `*pp`는 `p`의 값(즉 num의 주소)이 되고, `**pp`는 그 주소를 한 번 더 역참조한 값, 즉 `num`의 값이 됩니다. 화살표로 표현하면 `pp → p → num` 순서로 두 단계를 거쳐 원래 값에 도달하는 셈입니다.

이중 포인터가 실제로 유용하게 쓰이는 대표적인 경우는 함수 안에서 포인터 자체의 값(즉 어떤 주소를 가리키는지)을 바꾸고 싶을 때입니다. 앞서 12.2절에서 본 것처럼 포인터를 함수에 넘기면 포인터가 가리키는 대상은 바꿀 수 있지만, 포인터 자신이 다른 곳을 가리키게 하려면 포인터의 주소, 즉 이중 포인터를 넘겨야 합니다.

```c
#include <stdio.h>

// p가 가리키는 대상을 num2로 바꾸고 싶다면 이중 포인터가 필요하다
void redirect(int **pp, int *new_target) {
    *pp = new_target;   // p 자신의 값을 바꾼다
}

int main(void) {
    int num1 = 1, num2 = 2;
    int *p = &num1;

    printf("변경 전 *p: %d\n", *p);   // 1

    redirect(&p, &num2);              // p의 주소를 넘겨야 p 자체를 바꿀 수 있다

    printf("변경 후 *p: %d\n", *p);   // 2

    return 0;
}
```

이중 포인터는 14장 동적 메모리 할당에서 함수 안에서 동적으로 할당한 메모리의 주소를 호출한 쪽에 돌려주어야 할 때도 자주 등장하므로, 지금 개념을 확실히 익혀 두면 나중에 큰 도움이 됩니다.

## 12.4 함수 포인터 소개

지금까지는 포인터가 변수를 가리키는 경우만 살펴보았습니다. 그런데 C에서는 함수 역시 메모리의 어느 위치(코드 영역)에 저장되어 있으므로, 함수의 주소를 저장하는 포인터도 만들 수 있습니다. 이를 **함수 포인터(function pointer)**라고 부릅니다.

함수 포인터를 선언하는 문법은 처음 보면 조금 낯설게 느껴질 수 있습니다.

```c
반환형 (*포인터이름)(매개변수 자료형들);
```

간단한 예를 통해 살펴보겠습니다.

```c
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int subtract(int a, int b) {
    return a - b;
}

int main(void) {
    // int를 반환하고 int 두 개를 매개변수로 받는 함수를 가리키는 포인터
    int (*operation)(int, int);

    operation = add;              // add 함수의 주소를 저장 (함수 이름은 그 자체로 주소처럼 취급된다)
    printf("add 결과: %d\n", operation(3, 4));   // 7

    operation = subtract;         // 이제 subtract 함수를 가리키도록 재대입
    printf("subtract 결과: %d\n", operation(3, 4));   // -1

    return 0;
}
```

배열 이름이 배열의 주소로 취급되는 것처럼, 함수 이름도 그 함수가 저장된 코드의 주소로 취급됩니다. 따라서 `operation = add;`처럼 `&`를 붙이지 않고도 함수의 주소를 포인터 변수에 대입할 수 있습니다.

함수 포인터가 유용한 이유는, 상황에 따라 실행할 함수를 실행 중에 바꿔 끼울 수 있기 때문입니다. 예를 들어 사용자가 선택한 연산에 따라 다른 함수를 호출하고 싶을 때, 매번 `if-else`로 분기하는 대신 함수 포인터 배열을 사용할 수 있습니다.

```c
#include <stdio.h>

int add(int a, int b) { return a + b; }
int subtract(int a, int b) { return a - b; }
int multiply(int a, int b) { return a * b; }

int main(void) {
    // 함수 포인터를 원소로 갖는 배열
    int (*operations[3])(int, int) = {add, subtract, multiply};
    const char *names[3] = {"덧셈", "뺄셈", "곱셈"};

    for (int i = 0; i < 3; i++) {
        printf("%s 결과: %d\n", names[i], operations[i](10, 3));
    }

    return 0;
}
```

실행 결과는 다음과 같습니다.

```
덧셈 결과: 13
뺄셈 결과: 7
곱셈 결과: 30
```

함수 포인터는 표준 라이브러리에서도 자주 활용됩니다. 대표적으로 `<stdlib.h>`의 정렬 함수 `qsort`는 "어떻게 비교할지"를 함수 포인터로 전달받아서, 정렬 기준을 호출하는 쪽에서 자유롭게 정할 수 있게 해 줍니다. 이런 활용법은 17장 표준 라이브러리 둘러보기에서 더 자세히 다룰 예정이므로, 지금은 "함수도 주소를 가지며, 그 주소를 변수처럼 저장하고 전달할 수 있다"는 개념만 확실히 이해하고 넘어가면 충분합니다.

## 요약

- 배열 이름은 대부분의 문맥에서 배열 첫 원소의 주소로 취급되며, 이 때문에 배열 표기법 `arr[i]`와 포인터 표기법 `*(arr + i)`은 완전히 동일하게 동작한다.
- 포인터에 정수를 더하는 포인터 연산은 바이트 단위가 아니라 가리키는 자료형의 크기를 기준으로 계산된다.
- 함수에 변수의 값만 넘기면(call by value) 원본을 바꿀 수 없지만, 변수의 주소를 넘기고 포인터 매개변수로 받아서 역참조하면 원본을 직접 수정할 수 있다.
- 배열을 함수 인자로 넘기면 이미 주소가 전달되는 것이므로, 함수 안에서 배열의 원소를 수정하면 원본 배열이 그대로 변경된다.
- 이중 포인터(`**`)는 포인터 변수 자체의 주소를 저장하며, 함수 안에서 포인터가 가리키는 대상 자체를 바꾸고 싶을 때 사용한다.
- 함수 포인터는 함수의 주소를 저장하는 변수로, 실행 중에 호출할 함수를 바꿔 끼우거나 함수를 다른 함수의 인자로 전달할 때 사용한다.

## 연습문제

1. 정수 배열 `int arr[5] = {3, 6, 9, 12, 15};`를 선언하고, 포인터 변수 하나만 사용해서(배열 표기법 `arr[i]`를 쓰지 않고) 모든 원소를 출력하는 프로그램을 작성하시오.

2. 두 개의 `int` 변수 `a`와 `b`의 값을 서로 맞바꾸는 함수 `void swap(int *a, int *b)`를 작성하고, `main` 함수에서 호출해서 실제로 값이 바뀌는지 확인하시오.

3. 정수 배열과 배열의 길이를 인자로 받아, 배열 안의 최댓값과 최솟값을 포인터 매개변수를 통해 동시에 돌려주는 함수 `void find_min_max(int arr[], int size, int *min, int *max)`를 작성하시오.

4. 이중 포인터를 사용해서, 함수 안에서 포인터가 가리키는 변수 자체를 다른 변수로 바꾸는 예제를 작성하시오. (12.3절의 `redirect` 예제를 참고하되, 스스로 다른 변수 이름과 시나리오로 다시 작성해 볼 것.)

5. `int`형 두 매개변수를 받아 `int`를 반환하는 함수 세 개(예: 더하기, 최댓값 구하기, 최솟값 구하기)를 작성하고, 함수 포인터 배열을 이용해 사용자가 입력한 번호에 따라 해당 연산을 수행하는 간단한 계산기 프로그램을 작성하시오.
