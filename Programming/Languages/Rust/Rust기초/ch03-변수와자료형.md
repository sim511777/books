2장에서 첫 Rust 프로그램을 작성하고 빌드하는 과정을 살펴봤습니다. 이제부터는 실제로 프로그램의 내용을 채워나가는 데 필요한 재료, 즉 변수와 자료형을 다룹니다. Rust의 변수는 다른 언어와 사뭇 다른 철학을 가지고 있는데, 그 철학을 이해하는 것이 이 장의 핵심입니다.

## 3.1 `let`으로 변수 선언하기

Rust에서 변수는 `let` 키워드로 선언합니다.

```rust
fn main() {
    let age = 30;
    println!("나이: {}", age);
}
```

`let age = 30;`은 `age`라는 이름에 정수 30을 묶어주는(bind) 문장입니다. 다른 언어에서 흔히 보는 `int age = 30;` 같은 선언과 겉모습은 비슷하지만, Rust에서는 아주 중요한 차이가 하나 있습니다. 바로 **변수가 기본적으로 불변(immutable)**이라는 점입니다.

## 3.2 불변이 기본값인 이유

다음 코드를 컴파일해 보면 어떻게 될까요?

```rust
fn main() {
    let age = 30;
    age = 31; // 오류!
    println!("나이: {}", age);
}
```

컴파일러는 이렇게 알려줍니다.

```text
error[E0384]: cannot assign twice to immutable variable `age`
```

한 번 값을 묶은 변수는 재할당할 수 없습니다. 처음 배우는 사람에게는 불편하게 느껴질 수 있지만, 이것은 Rust가 의도적으로 선택한 설계입니다. 값이 바뀌지 않는다는 사실이 코드에 드러나 있으면, 그 변수를 사용하는 다른 코드를 읽을 때 "이 값이 중간에 바뀌었을 리 없다"고 안심할 수 있습니다. 이런 안정성은 프로그램이 커질수록, 그리고 8장에서 다룰 소유권 규칙과 맞물릴수록 큰 힘을 발휘합니다.

물론 값이 바뀌어야 하는 경우도 당연히 있습니다. 그럴 때는 `mut` 키워드를 붙여 명시적으로 "이 변수는 가변입니다"라고 선언합니다.

```rust
fn main() {
    let mut age = 30;
    println!("올해 나이: {}", age);
    age = 31;
    println!("내년 나이: {}", age);
}
```

`mut`가 붙은 코드를 볼 때마다 "이 변수는 나중에 값이 바뀔 수 있다"는 신호를 받을 수 있다는 점이 이 설계의 장점입니다. 반대로 `mut`가 없는 변수는 선언 이후로 절대 바뀌지 않는다고 믿고 읽어도 됩니다.

## 3.3 기본 자료형: 정수와 부동소수점

Rust는 정적 타입 언어라서, 모든 변수는 컴파일 시점에 타입이 결정됩니다. 가장 자주 쓰는 타입은 정수와 부동소수점입니다.

### 정수형

정수형은 부호가 있는지(signed) 없는지(unsigned), 그리고 크기가 몇 비트인지에 따라 이름이 붙습니다.

| 크기 | 부호 있음 | 부호 없음 |
|------|-----------|-----------|
| 8비트  | `i8`  | `u8`  |
| 16비트 | `i16` | `u16` |
| 32비트 | `i32` | `u32` |
| 64비트 | `i64` | `u64` |
| 128비트 | `i128` | `u128` |
| 아키텍처 종속 | `isize` | `usize` |

부호 있는 정수(`i` 계열)는 음수와 양수를 모두 표현하고, 부호 없는 정수(`u` 계열)는 0 이상의 값만 표현합니다. 예를 들어 `u8`은 0부터 255까지, `i8`은 -128부터 127까지 표현할 수 있습니다.

타입을 명시하지 않고 정수 리터럴을 쓰면 Rust는 기본적으로 `i32`를 선택합니다.

```rust
fn main() {
    let x = 42; // 타입을 쓰지 않으면 i32로 추론
    let y: u8 = 255; // 명시적으로 u8 지정
    let z: i64 = 9_000_000_000;
    println!("{x}, {y}, {z}");
}
```

숫자 리터럴에 밑줄(`_`)을 넣어 자릿수를 구분할 수 있습니다. `9_000_000_000`은 `9000000000`과 같은 값이지만 훨씬 읽기 좋습니다.

`usize`와 `isize`는 조금 특별한데, 크기가 실행 환경(32비트 또는 64비트 컴퓨터)에 따라 달라집니다. 이 타입은 주로 배열이나 컬렉션의 인덱스, 길이를 나타낼 때 쓰이며, 10장에서 슬라이스를 다룰 때 다시 만나게 됩니다.

### 부동소수점형

소수를 표현할 때는 `f32`와 `f64`를 사용합니다. `f64`가 기본 타입이며, 정밀도가 더 높습니다.

```rust
fn main() {
    let pi = 3.14159; // f64로 추론
    let ratio: f32 = 0.5;
    println!("{pi}, {ratio}");
}
```

## 3.4 불리언과 문자

불리언 타입 `bool`은 `true`와 `false` 두 값만 가집니다.

```rust
fn main() {
    let is_active = true;
    let has_error: bool = false;
    println!("{is_active}, {has_error}");
}
```

`char`는 문자 하나를 나타내는 타입입니다. 다른 언어의 `char`가 보통 1바이트인 것과 달리, Rust의 `char`는 유니코드 스칼라 값을 표현하기 위해 항상 4바이트를 차지합니다. 그래서 한글이나 이모지도 문제없이 담을 수 있습니다.

```rust
fn main() {
    let letter = 'A';
    let hangul = '가';
    let emoji = '🦀';
    println!("{letter} {hangul} {emoji}");
}
```

`char` 리터럴은 항상 홑화살괄호가 아닌 작은따옴표(`'`)로 감쌉니다. 겹따옴표(`"`)로 감싸면 이는 문자열이 되며, 문자열은 10장에서 슬라이스와 함께 자세히 다룹니다.

## 3.5 튜플: 서로 다른 타입을 하나로

튜플은 서로 다른 타입의 값 여러 개를 하나로 묶는 자료형입니다. 길이가 고정되어 있어서, 한 번 정한 요소 개수는 바꿀 수 없습니다.

```rust
fn main() {
    let person: (&str, i32, bool) = ("지훈", 28, true);
    println!("이름: {}", person.0);
    println!("나이: {}", person.1);
    println!("활성 상태: {}", person.2);
}
```

`.0`, `.1`, `.2`처럼 점과 인덱스로 각 요소에 접근합니다. 튜플은 여러 값을 한꺼번에 반환하고 싶을 때도 자주 쓰입니다. 이 부분은 7장에서 함수의 반환값을 다룰 때 다시 살펴봅니다.

패턴을 이용해 튜플을 한 번에 여러 변수로 풀어낼(destructuring) 수도 있습니다.

```rust
fn main() {
    let point = (3, 7);
    let (x, y) = point;
    println!("x = {x}, y = {y}");
}
```

## 3.6 배열: 같은 타입의 고정 길이 목록

배열은 튜플과 달리 같은 타입의 값들만 담을 수 있지만, 마찬가지로 길이가 고정됩니다. 요소 개수가 프로그램 실행 중에 바뀌는 목록이 필요하다면 16장에서 다루는 `Vec`을 사용해야 합니다.

```rust
fn main() {
    let scores: [i32; 5] = [90, 85, 100, 70, 95];
    println!("첫 번째 점수: {}", scores[0]);
    println!("배열 길이: {}", scores.len());

    // 같은 값으로 초기화한 배열
    let zeros = [0; 3]; // [0, 0, 0]과 동일
    println!("{:?}", zeros);
}
```

`[i32; 5]`는 "`i32` 타입 값 다섯 개로 이루어진 배열"이라는 뜻입니다. 배열의 크기는 타입의 일부이므로, `[i32; 5]`와 `[i32; 3]`은 서로 다른 타입으로 취급됩니다.

배열의 범위를 벗어난 인덱스에 접근하면 어떻게 될까요?

```rust
fn main() {
    let scores = [90, 85, 100];
    println!("{}", scores[10]); // 실행 시 panic!
}
```

컴파일은 되지만 실행하면 프로그램이 panic을 일으키며 종료됩니다. Rust는 이런 실수를 조용히 넘기지 않고 즉시 알려주는 쪽을 택합니다. 이런 실행 시점 오류를 다루는 방법은 15장 에러 처리에서 더 깊이 다룹니다.

## 3.7 타입 추론과 명시적 타입 표기

지금까지 예제에서 보았듯, Rust 컴파일러는 대부분의 경우 우변의 값이나 이후 사용 방식을 보고 변수의 타입을 스스로 추론합니다. 그래서 매번 타입을 적을 필요는 없습니다.

```rust
fn main() {
    let count = 10; // i32로 추론됨
    let name = "루스트"; // &str로 추론됨
}
```

하지만 추론이 애매한 경우, 예를 들어 문자열을 숫자로 변환할 때는 타입을 반드시 명시해야 합니다.

```rust
fn main() {
    let parsed: i32 = "42".parse().expect("숫자가 아닙니다");
    println!("{parsed}");
}
```

`parse()` 메서드는 여러 숫자 타입으로 변환할 수 있어서, 결과를 어떤 변수에 담을지 컴파일러가 알아야만 어떤 타입으로 변환할지 결정할 수 있습니다. 이럴 때 `let parsed: i32 = ...`처럼 콜론(`:`) 뒤에 타입을 적어주면 컴파일러의 판단을 돕게 됩니다.

## 3.8 형변환: `as` 키워드

서로 다른 숫자 타입 간에 값을 변환하려면 `as` 키워드를 사용합니다.

```rust
fn main() {
    let big: i64 = 1000;
    let small = big as i32; // i64 -> i32
    let float_val = small as f64; // i32 -> f64
    let truncated = 3.9_f64 as i32; // 소수점 버림 -> 3

    println!("{small}, {float_val}, {truncated}");
}
```

`as`는 편리하지만 주의할 점이 있습니다. 큰 타입을 작은 타입으로 변환할 때 값이 범위를 벗어나면 정보가 잘려나갑니다.

```rust
fn main() {
    let large: i32 = 300;
    let narrowed = large as u8; // 300은 u8 범위(0~255)를 벗어남
    println!("{narrowed}"); // 44가 출력됨 (300 % 256)
}
```

이런 손실이 항상 명확하게 드러나지는 않으므로, 값의 범위가 확실하지 않을 때는 `as`보다 `TryFrom`처럼 실패를 명시적으로 알려주는 방법을 쓰는 편이 안전합니다. 이 내용은 15장 에러 처리에서 다시 다룹니다.

## 3.9 섀도잉: 같은 이름을 다시 선언하기

Rust에는 섀도잉(shadowing)이라는 독특한 개념이 있습니다. 같은 이름으로 `let`을 다시 사용하면, 이전 변수를 덮어쓰는(shadow) 새로운 변수가 만들어집니다.

```rust
fn main() {
    let x = 5;
    let x = x + 1; // 이전 x를 사용해 새로운 x를 만듦
    let x = x * 2;
    println!("x = {x}"); // 12
}
```

이것은 `mut`와 전혀 다른 개념입니다. `mut`는 같은 변수의 값을 바꾸는 것이고, 섀도잉은 같은 이름의 새로운 변수를 만드는 것입니다. 심지어 섀도잉을 이용하면 타입도 바꿀 수 있습니다.

```rust
fn main() {
    let input = "   42   ";
    let input = input.trim(); // &str -> &str (공백 제거)
    let input: i32 = input.parse().unwrap(); // &str -> i32
    println!("{input}");
}
```

같은 이름 `input`을 계속 재사용하면서도, 매 단계마다 서로 다른 타입과 값을 갖게 됩니다. 문자열을 다듬고 파싱하는 과정을 거칠 때 `input_trimmed`, `input_parsed`처럼 이름을 계속 바꾸지 않아도 되어 코드가 간결해집니다. 섀도잉은 블록 스코프 안에서만 유효하며, 블록이 끝나면 원래 스코프의 변수가 다시 보입니다.

```rust
fn main() {
    let y = 1;
    {
        let y = y + 10;
        println!("내부 블록의 y: {y}"); // 11
    }
    println!("바깥 블록의 y: {y}"); // 1
}
```

## 요약

이 장에서는 Rust 변수와 자료형의 기초를 살펴봤습니다. `let`으로 변수를 선언하면 기본적으로 불변이며, 값을 바꾸려면 `mut`를 명시해야 합니다. 정수형은 부호와 크기에 따라 `i8`부터 `u128`까지 다양하게 나뉘고, 부동소수점형은 `f32`와 `f64`가 있습니다. `bool`과 `char`는 각각 참/거짓과 유니코드 문자 하나를 표현합니다. 튜플은 서로 다른 타입을, 배열은 같은 타입을 고정된 길이로 묶습니다. 컴파일러는 대부분의 타입을 추론하지만 필요할 때는 명시적으로 표기할 수 있고, `as`로 타입 간 변환도 가능합니다. 마지막으로 섀도잉을 이용하면 같은 이름을 재사용하면서 값과 타입을 단계적으로 바꿀 수 있습니다. 다음 장에서는 이런 값들을 가지고 실제로 연산을 수행하는 연산자와 표현식을 배웁니다.
