지금까지는 변수 하나에 값 하나를 담아 다뤘습니다. 하지만 현실의 데이터는 대개 여러 값이 한 묶음으로 의미를 갖습니다. 예를 들어 "사각형"을 표현하려면 너비와 높이가 함께 있어야 하고, "사용자"를 표현하려면 이름, 나이, 이메일이 함께 있어야 합니다. Rust는 이런 묶음을 만들기 위한 도구로 `struct`(구조체)를 제공합니다. 이번 장에서는 구조체를 정의하고 인스턴스를 만드는 방법, 필드에 접근하는 방법, 그리고 구조체에 동작을 붙이는 메서드와 연관 함수를 다룹니다.

## 구조체 정의와 인스턴스 생성

구조체는 `struct` 키워드로 정의하며, 이름은 관례상 파스칼 케이스(`PascalCase`)를 사용합니다. 각 필드는 이름과 타입을 가집니다.

```rust
// 사각형을 표현하는 구조체
struct Rectangle {
    width: u32,
    height: u32,
}

fn main() {
    // 필드 이름: 값 형태로 인스턴스를 생성한다
    let rect = Rectangle {
        width: 30,
        height: 50,
    };

    println!("너비: {}, 높이: {}", rect.width, rect.height);
}
```

구조체 정의는 값의 "모양"을 선언하는 것일 뿐이고, 실제 값을 채워야 인스턴스가 만들어집니다. 필드 순서는 정의와 다르게 적어도 되지만, 이름은 정확히 일치해야 합니다.

필드 값이 담긴 변수 이름이 필드 이름과 같다면 축약해서 쓸 수 있습니다.

```rust
fn build_rectangle(width: u32, height: u32) -> Rectangle {
    // width: width, height: height 를 축약
    Rectangle { width, height }
}
```

값을 바꾸고 싶다면 인스턴스 전체를 `mut`으로 선언해야 합니다. 구조체는 필드 단위가 아니라 인스턴스 단위로 가변성을 가집니다.

```rust
fn main() {
    let mut rect = Rectangle { width: 30, height: 50 };
    rect.width = 40; // rect가 mut이므로 필드 수정 가능
}
```

기존 인스턴스의 일부 필드만 바꾼 새 인스턴스를 만들 때는 구조체 갱신 문법(struct update syntax)을 사용할 수 있습니다.

```rust
fn main() {
    let rect1 = Rectangle { width: 30, height: 50 };
    // width만 바꾼 새 인스턴스, 나머지는 rect1에서 가져온다
    let rect2 = Rectangle { width: 60, ..rect1 };
}
```

## 메서드: impl 블록과 &self

구조체는 데이터만 담을 뿐, 그 자체로는 동작을 갖지 않습니다. 구조체에 동작을 붙이려면 `impl`(implementation) 블록 안에 함수를 정의합니다. 이런 함수를 메서드(method)라고 부르며, 첫 매개변수로 `self`를 받는다는 점이 일반 함수와 다릅니다.

```rust
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    // &self: 인스턴스를 읽기 전용으로 빌려온다
    fn area(&self) -> u32 {
        self.width * self.height
    }

    fn is_square(&self) -> bool {
        self.width == self.height
    }
}

fn main() {
    let rect = Rectangle { width: 30, height: 50 };

    // 메서드는 점(.) 문법으로 호출한다
    println!("면적: {}", rect.area());
    println!("정사각형인가? {}", rect.is_square());
}
```

`&self`는 8장과 9장에서 배운 빌림(borrowing)을 그대로 메서드에 적용한 것입니다. `area` 메서드는 사각형의 값을 읽기만 하므로 소유권을 가져올 필요가 없고, `&self`로 참조만 빌려오면 충분합니다. 만약 `self`(참조 없이)를 받았다면 메서드를 호출할 때마다 인스턴스의 소유권이 이동해 버려서, 호출 이후에는 원래 변수를 더 이상 쓸 수 없게 됩니다. 대부분의 메서드는 인스턴스를 읽기만 하므로 `&self`가 기본적인 선택입니다.

필드 값을 바꾸는 메서드는 `&mut self`를 받아야 합니다.

```rust
impl Rectangle {
    // &mut self: 인스턴스를 가변으로 빌려와 필드를 수정한다
    fn double_width(&mut self) {
        self.width *= 2;
    }
}

fn main() {
    let mut rect = Rectangle { width: 30, height: 50 };
    rect.double_width();
    println!("바뀐 너비: {}", rect.width);
}
```

여기서 `rect`가 `mut`으로 선언되어 있어야 `&mut self`를 받는 메서드를 호출할 수 있습니다. 9장에서 살펴본 "가변 참조는 동시에 하나만 존재할 수 있다"는 규칙이 메서드 호출에도 그대로 적용됩니다. 즉 `&self`를 받는 메서드는 여러 번 동시에 호출해도 안전하지만, `&mut self`를 받는 메서드는 다른 참조가 없는 상태에서만 호출할 수 있습니다.

메서드는 매개변수를 추가로 받을 수도 있습니다.

```rust
impl Rectangle {
    // 다른 사각형을 완전히 포함할 수 있는지 검사
    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width >= other.width && self.height >= other.height
    }
}

fn main() {
    let big = Rectangle { width: 30, height: 50 };
    let small = Rectangle { width: 10, height: 20 };

    println!("포함 가능? {}", big.can_hold(&small));
}
```

## 연관 함수: Self::new 관용구

`impl` 블록에는 `self`를 받지 않는 함수도 정의할 수 있습니다. 이런 함수를 연관 함수(associated function)라고 부릅니다. 연관 함수는 인스턴스가 아니라 타입 자체에 속한 함수이므로, `타입이름::함수이름` 형태로 호출합니다.

가장 흔한 사용처는 생성자입니다. Rust에는 다른 언어의 `new` 키워드 같은 것이 없지만, 관례적으로 `new`라는 이름의 연관 함수를 만들어 인스턴스 생성 로직을 캡슐화합니다.

```rust
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    // 연관 함수: self를 받지 않으므로 Rectangle::new(...) 형태로 호출한다
    fn new(width: u32, height: u32) -> Self {
        Self { width, height }
    }

    // 특별한 경우를 위한 또 다른 연관 함수
    fn square(size: u32) -> Self {
        Self { width: size, height: size }
    }

    fn area(&self) -> u32 {
        self.width * self.height
    }
}

fn main() {
    let rect = Rectangle::new(30, 50);
    let sq = Rectangle::square(20);

    println!("rect 면적: {}, sq 면적: {}", rect.area(), sq.area());
}
```

`Self`(대문자로 시작)는 현재 `impl` 블록이 구현 대상으로 하는 타입, 즉 `Rectangle`을 가리키는 별칭입니다. 타입 이름을 반복해서 적지 않아도 되므로 편리하고, 나중에 구조체 이름을 바꾸더라도 `impl` 블록 안의 코드는 그대로 유지됩니다. `new`는 특별한 키워드가 아니라 관례일 뿐이라는 점도 기억해 두세요. 하나의 구조체에 목적에 따라 여러 연관 함수를 두어도 전혀 문제가 없습니다.

같은 구조체에 대해 여러 개의 `impl` 블록을 두는 것도 가능합니다. 큰 구조체의 메서드를 성격별로 나누어 정리할 때 유용합니다.

## 튜플 구조체와 유닛 구조체

모든 구조체가 이름을 가진 필드를 필요로 하는 것은 아닙니다. 필드 이름 없이 타입만으로 값을 묶고 싶다면 튜플 구조체(tuple struct)를 사용합니다.

```rust
// 필드 이름 없이 타입만 나열한다
struct Point(i32, i32);
struct Color(u8, u8, u8);

fn main() {
    let origin = Point(0, 0);
    let black = Color(0, 0, 0);

    // 필드 접근은 .0, .1, .2 처럼 인덱스로 한다
    println!("x: {}, y: {}", origin.0, origin.1);
    println!("R: {}", black.0);
}
```

튜플 구조체는 값의 의미를 타입 이름으로 표현하고 싶지만, 필드 각각에 이름을 붙일 필요는 없을 때 적합합니다. `Point`와 `Color`는 둘 다 세 개의 정수를 담지만, 서로 다른 타입이므로 실수로 섞어 쓸 일이 없습니다.

필드가 하나도 없는 구조체, 즉 유닛 구조체(unit-like struct)도 정의할 수 있습니다.

```rust
// 데이터 없이 어떤 동작(트레이트)만 표현하고 싶을 때 사용
struct AlwaysEqual;

fn main() {
    let _marker = AlwaysEqual;
}
```

유닛 구조체는 지금 당장은 쓸 일이 적어 보이지만, 13장에서 트레이트를 다룰 때 "데이터는 필요 없지만 특정 동작을 구현하고 싶은 타입"을 표현하는 데 유용하게 쓰입니다.

## 요약

이번 장에서는 여러 값을 의미 있는 단위로 묶는 `struct`를 배웠습니다. 이름 있는 필드로 구조체를 정의하고 `구조체이름 { 필드: 값 }` 형태로 인스턴스를 만들며, 필드 축약 문법과 구조체 갱신 문법으로 코드를 간결하게 쓸 수 있었습니다. `impl` 블록 안에서 `&self`를 받는 메서드로 읽기 전용 동작을, `&mut self`를 받는 메서드로 필드를 수정하는 동작을 정의했는데, 이는 9장에서 배운 참조와 빌림 규칙이 그대로 이어지는 것입니다. 또한 `self`를 받지 않는 연관 함수로 `Self::new` 같은 생성자 관용구를 만드는 법을 살펴보았고, 필드 이름이 필요 없는 튜플 구조체와 데이터가 전혀 없는 유닛 구조체도 소개했습니다. 다음 장에서는 구조체와는 다른 방식으로 데이터를 표현하는 열거형(`enum`)과, 그 값을 분기해서 다루는 `match` 표현식을 배웁니다.
