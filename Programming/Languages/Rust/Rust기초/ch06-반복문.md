# 6장. 반복문

같은 작업을 여러 번 반복해야 하는 경우는 프로그래밍에서 매우 흔하다. Rust는 반복을 위해 `loop`, `while`, `for`라는 세 가지 문법을 제공하며, 이 중 `loop`는 다른 언어에는 잘 없는 독특한 특징을 가지고 있다. 이번 장에서는 각각의 반복문을 살펴보고, 반복을 제어하는 `break`와 `continue`, 그리고 중첩된 반복문을 다루는 레이블(label) 문법까지 알아본다.

## loop: 무한 반복과 값 반환

`loop`는 조건 없이 무한히 반복하는 가장 단순한 반복문이다. 반복을 멈추려면 명시적으로 `break`를 호출해야 한다.

```rust
fn main() {
    let mut count = 0;

    loop {
        count += 1;
        println!("반복 횟수: {count}");

        if count == 3 {
            break;
        }
    }
}
```

이 코드는 `count`가 3이 될 때까지 반복하고, `break`를 만나면 반복문을 빠져나온다. 조건 없이 시작하는 반복문이 필요할 때, 예를 들어 사용자 입력을 계속 받다가 특정 조건에서만 멈추고 싶은 경우에 `loop`가 자연스럽다.

`loop`의 진짜 흥미로운 부분은 5장에서 이야기한 "표현식으로서의 제어문" 개념이 여기서도 이어진다는 점이다. `break` 뒤에 값을 붙이면, 그 값이 `loop` 전체의 결과값이 된다.

```rust
fn main() {
    let mut count = 0;

    let result = loop {
        count += 1;

        if count == 10 {
            break count * 2;
        }
    };

    println!("결과: {result}"); // 결과: 20
}
```

이것은 Rust에만 있는 독특한 특징이다. 다른 언어의 `while (true) { ... }`는 값을 만들어내지 않는 순수한 명령문이지만, Rust의 `loop`는 `break value;`를 통해 계산 결과를 밖으로 꺼낼 수 있는 표현식이다. 재시도 로직처럼 "성공할 때까지 반복하고, 성공한 결과를 변수에 담고 싶다"는 상황에서 이 문법이 특히 유용하다.

```rust
fn main() {
    let mut attempt = 0;

    let value = loop {
        attempt += 1;
        let simulated_result = attempt * attempt;

        if simulated_result > 20 {
            break simulated_result;
        }
    };

    println!("{attempt}번째 시도에서 값 {value}를 얻었습니다");
}
```

## while: 조건이 참인 동안 반복

조건을 매번 검사하면서 반복하고 싶다면 `while`이 더 어울린다. `loop`와 달리 `while`은 값을 반환하지 않는 순수한 반복문이다.

```rust
fn main() {
    let mut countdown = 5;

    while countdown > 0 {
        println!("{countdown}...");
        countdown -= 1;
    }

    println!("발사!");
}
```

`while` 역시 조건식에 괄호가 필요 없고, 조건은 반드시 `bool` 타입이어야 한다는 규칙이 `if`와 동일하게 적용된다. `loop`와 `while`을 구분하는 기준은 단순하다. 반복을 시작하기 전에 이미 멈출 조건을 알고 있다면 `while`을, 반복 도중에 어떤 이벤트가 발생해야 멈추는 구조라면 `loop`와 `break`의 조합을 사용하는 것이 코드의 의도를 더 명확히 드러낸다.

## for: 범위와 컬렉션 순회

가장 많이 쓰이는 반복문은 `for`다. Rust의 `for`는 "반복자(iterator)"를 순회하는 방식으로 동작하는데, 반복자라는 개념 자체는 16장 컬렉션에서 더 깊이 다루고, 여기서는 우선 익숙한 두 가지 사용법에 집중한다.

먼저 범위(range)를 순회하는 방법이다.

```rust
fn main() {
    for number in 0..10 {
        println!("숫자: {number}");
    }
}
```

`0..10`은 0부터 9까지, 즉 끝값을 포함하지 않는 범위를 만든다. 끝값까지 포함하려면 `0..=10`처럼 `..=`를 사용한다.

```rust
fn main() {
    for number in 0..=10 {
        println!("숫자: {number}"); // 0부터 10까지 출력
    }
}
```

`for`의 또 다른 핵심 용도는 배열이나 벡터 같은 컬렉션을 순회하는 것이다.

```rust
fn main() {
    let fruits = ["사과", "바나나", "포도"];

    for fruit in fruits {
        println!("과일: {fruit}");
    }
}
```

각 요소에 대한 참조가 필요할 때는 `.iter()`를, 인덱스와 값을 함께 얻고 싶을 때는 `.enumerate()`를 함께 쓰는 경우가 많다.

```rust
fn main() {
    let fruits = ["사과", "바나나", "포도"];

    for (index, fruit) in fruits.iter().enumerate() {
        println!("{index}번째 과일: {fruit}");
    }
}
```

`while`을 이용해 인덱스를 직접 증가시키며 컬렉션을 순회할 수도 있지만, `for`를 쓰는 편이 훨씬 안전하고 간결하다. 인덱스를 손으로 관리하다 보면 범위를 벗어나는 실수를 하기 쉬운데, `for`는 그런 실수 자체를 원천적으로 없애준다. 이 안전성은 8장에서 다룰 소유권 시스템과도 연결되는 Rust의 일관된 설계 철학이다.

## break와 continue

세 반복문 모두에서 `break`는 반복을 즉시 종료하고, `continue`는 현재 반복을 건너뛰고 다음 반복으로 넘어간다.

```rust
fn main() {
    for number in 0..10 {
        if number % 2 != 0 {
            continue; // 홀수는 건너뛴다
        }

        if number > 6 {
            break; // 6을 넘으면 반복을 끝낸다
        }

        println!("짝수: {number}");
    }
}
```

이 코드는 0, 2, 4, 6만 출력한다. 홀수를 만나면 `continue`로 그 이후 코드를 건너뛰고, 6보다 큰 짝수(8)를 만나기 전에 `break`로 전체 반복을 멈춘다.

## 레이블을 이용한 중첩 루프 제어

반복문이 중첩되어 있을 때 `break`나 `continue`는 기본적으로 가장 안쪽 반복문에만 영향을 준다. 바깥쪽 반복문까지 제어하고 싶다면 레이블(label)을 사용한다. 레이블은 `'이름:` 형태로 작성하며, 반복문 앞에 붙인다.

```rust
fn main() {
    'outer: for x in 0..5 {
        for y in 0..5 {
            if x * y > 6 {
                println!("x={x}, y={y}에서 바깥 루프를 종료합니다");
                break 'outer;
            }

            println!("x={x}, y={y}");
        }
    }
}
```

`break 'outer;`는 안쪽 `for`가 아니라 `'outer` 레이블이 붙은 바깥쪽 `for`를 종료시킨다. 레이블이 없었다면 `break`는 안쪽 반복문만 멈추고 바깥쪽 반복문은 계속 실행되었을 것이다. `continue`에도 같은 방식으로 레이블을 붙일 수 있다.

```rust
fn main() {
    'rows: for row in 0..3 {
        for col in 0..3 {
            if col == 1 {
                continue 'rows; // 바깥 for(rows)의 다음 반복으로 넘어간다
            }
            println!("row={row}, col={col}");
        }
    }
}
```

레이블은 이중 for 루프로 2차원 격자를 탐색하다가 특정 조건을 만나면 전체 탐색을 즉시 중단해야 하는 경우(예: 격자에서 목표 값을 찾으면 더 이상 찾을 필요가 없는 탐색 알고리즘)에 특히 유용하다. 레이블 없이 같은 동작을 구현하려면 별도의 `bool` 플래그 변수를 두고 매 반복마다 검사해야 하는데, 레이블을 쓰면 그런 우회 없이 의도를 직접 표현할 수 있다.

## 요약

- `loop`는 무한 반복문이며, `break value;`로 반복문 자체를 값을 반환하는 표현식으로 만들 수 있다는 점이 Rust의 독특한 특징이다.
- `while`은 조건이 참인 동안만 반복하며, 시작 전에 종료 조건을 알고 있는 경우에 적합하다.
- `for`는 범위(`0..10`, `0..=10`)나 배열·벡터 같은 컬렉션을 순회할 때 사용하며, 인덱스를 직접 관리하는 것보다 안전하다.
- `break`는 반복을 종료하고 `continue`는 현재 반복만 건너뛰며, 둘 다 레이블(`'label:`)을 붙여 중첩된 바깥쪽 반복문까지 제어할 수 있다.
- 컬렉션을 순회하는 반복자의 더 깊은 원리는 16장에서 다시 다룬다.

## 연습문제

1. `loop`와 `break value;`를 사용해 1부터 시작해서 누적 합이 100을 처음 넘는 순간의 합계를 반환하는 코드를 작성하라.
2. 같은 문제를 `while`을 이용해 다시 작성하고, 두 코드의 가독성을 비교해 보라.
3. `for` 문과 `0..=20` 범위를 사용해 3의 배수만 출력하되, `continue`를 이용해 3의 배수가 아닌 수를 건너뛰는 코드를 작성하라.
4. 5x5 격자를 이중 `for` 루프로 순회하면서, 두 좌표의 합이 6이 되는 첫 번째 지점을 찾으면 레이블을 이용해 바깥쪽 루프까지 즉시 종료하는 코드를 작성하라.
5. 문자열 벡터를 `.iter().enumerate()`로 순회하며 인덱스와 값을 함께 출력하는 코드를 작성하고, `enumerate()`를 쓰지 않고 같은 결과를 얻으려면 어떻게 해야 하는지 설명하라.
