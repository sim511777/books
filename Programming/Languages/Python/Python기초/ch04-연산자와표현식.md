3장. 변수와 자료형에서 값을 담는 방법을 배웠다면, 이번 장에서는 그 값들을 조합해서 새로운 값을 만들어내는 방법을 다룬다. 값과 연산자가 결합된 것을 표현식(expression)이라 부르는데, `3 + 4`, `age >= 18`, `"a" in "apple"` 모두 표현식이다. Python이 제공하는 연산자를 종류별로 살펴보자.

## 산술 연산자

산술 연산자는 숫자를 계산하는 데 쓰인다. 기본적인 사칙연산 외에 Python만의 독특한 연산자 몇 가지도 함께 살펴본다.

| 연산자 | 의미 | 예시 | 결과 |
|---|---|---|---|
| `+` | 덧셈 | `7 + 3` | `10` |
| `-` | 뺄셈 | `7 - 3` | `4` |
| `*` | 곱셈 | `7 * 3` | `21` |
| `/` | 나눗셈 | `7 / 3` | `2.3333333333333335` |
| `//` | 정수 나눗셈(몫) | `7 // 3` | `2` |
| `%` | 나머지 | `7 % 3` | `1` |
| `**` | 거듭제곱 | `7 ** 3` | `343` |

```python
>>> 7 / 3
2.3333333333333335
>>> 7 // 3
2
>>> 7 % 3
1
>>> 7 ** 3
343
```

`/`는 나눈 결과가 정수로 딱 떨어지더라도 항상 `float`를 반환한다는 점을 기억해두자.

```python
>>> 10 / 2
5.0
```

### 정수 나눗셈 //

`//`는 나눗셈의 몫에서 소수점 이하를 버린 정수를 돌려준다. 다만 "버림"이 아니라 정확히는 "내림"이라는 점에 주의해야 한다. 음수가 섞이면 두 개념의 결과가 달라진다.

```python
>>> 7 // 2
3
>>> -7 // 2
-4
```

`-7 // 2`는 `-3`이 아니라 `-4`다. 수학적으로 `-7 / 2 = -3.5`인데, `//`는 이 값보다 작거나 같은 가장 큰 정수(음의 무한대 방향으로 내림)를 반환하기 때문이다. 소수점을 단순히 잘라내는 것과 헷갈리지 않도록 주의하자. 소수점을 잘라내고 싶다면 `int(-7 / 2)`처럼 명시적으로 형변환하면 된다.

```python
>>> int(-7 / 2)
-3
```

### 나머지 %

`%`는 나눗셈의 나머지를 구한다. 짝수·홀수 판별처럼 어떤 값이 배수인지 확인할 때 흔히 사용한다.

```python
>>> 10 % 2
0
>>> 11 % 2
1
>>> -7 % 3
2
```

나머지 연산도 정수 나눗셈과 마찬가지로, 결과의 부호가 나누는 수(오른쪽 피연산자)의 부호를 따른다. `-7 % 3`이 `-1`이 아니라 `2`인 이유다. 이 규칙은 `a == (a // b) * b + (a % b)`라는 등식이 항상 성립하도록 설계되어 있다.

### 거듭제곱 **

`**`는 거듭제곱을 계산한다. 지수에 음수나 소수를 사용할 수도 있다.

```python
>>> 2 ** 10
1024
>>> 2 ** 0.5
1.4142135623730951
>>> 2 ** -1
0.5
```

`2 ** 0.5`는 2의 제곱근을, `2 ** -1`은 2의 역수(1/2)를 계산한 것과 같다. 제곱근 계산을 자주 한다면 `math.sqrt()` 함수를 쓰는 편이 더 명확하다. `math` 모듈은 17장. 표준 라이브러리와 패키지 관리에서 다룬다.

## 비교 연산자

비교 연산자는 두 값을 비교해서 그 결과를 `bool` 값(`True` 또는 `False`)으로 돌려준다.

| 연산자 | 의미 |
|---|---|
| `==` | 같다 |
| `!=` | 다르다 |
| `>` | 크다 |
| `<` | 작다 |
| `>=` | 크거나 같다 |
| `<=` | 작거나 같다 |

```python
>>> 3 == 3.0
True
>>> 3 != 4
True
>>> "apple" == "Apple"
False
>>> 10 >= 10
True
```

`3 == 3.0`이 `True`인 점을 눈여겨보자. `==`는 자료형이 완전히 같은지가 아니라, 값이 같은지를 비교한다. 정수 `3`과 실수 `3.0`은 타입은 다르지만 값으로서는 같다고 판단된다. 반면 문자열 비교는 대소문자를 구분하므로 `"apple"`과 `"Apple"`은 다른 값이다.

Python은 비교 연산자를 연쇄적으로 이어 쓸 수 있다는 점이 다른 언어와 구별되는 특징이다.

```python
>>> age = 25
>>> 18 <= age < 65
True
```

`18 <= age < 65`는 `18 <= age and age < 65`와 정확히 같은 뜻이다. 두 개의 비교를 각각 쓰고 `and`로 연결하는 것보다 훨씬 읽기 좋다.

## 논리 연산자

논리 연산자는 `bool` 값(혹은 진리값 검사를 거친 값)을 조합할 때 사용한다. Python은 `&&`, `||`, `!` 대신 영어 단어 `and`, `or`, `not`을 그대로 사용한다.

```python
>>> is_adult = True
>>> has_ticket = False
>>> is_adult and has_ticket
False
>>> is_adult or has_ticket
True
>>> not is_adult
False
```

`and`와 `or`는 실제로는 `bool` 값만 반환하는 것이 아니라, 피연산자로 주어진 객체 자체를 반환한다는 점이 Python의 독특한 특징이다.

```python
>>> "" or "기본값"
'기본값'
>>> "사용자입력" or "기본값"
'사용자입력'
>>> 0 and "실행 안 됨"
0
>>> 3 and "실행됨"
'실행됨'
```

`or`는 왼쪽 피연산자가 참으로 취급되면 왼쪽 값을, 그렇지 않으면 오른쪽 값을 반환한다. `and`는 반대로 왼쪽 피연산자가 거짓으로 취급되면 왼쪽 값을, 그렇지 않으면 오른쪽 값을 반환한다. 이 성질을 이용해서 값이 비어 있을 때 기본값을 지정하는 관용적인 표현이 자주 쓰인다.

```python
>>> user_nickname = ""
>>> display_name = user_nickname or "익명"
>>> display_name
'익명'
```

또한 Python의 `and`, `or`는 결과를 확정할 수 있으면 오른쪽 피연산자를 아예 평가하지 않는다. 이를 단락 평가(short-circuit evaluation)라 부른다.

```python
>>> def noisy_true():
...     print("noisy_true 호출됨")
...     return True
...
>>> False and noisy_true()
False
```

`False and noisy_true()`에서는 왼쪽이 이미 거짓이므로 전체 결과가 거짓임이 확정되고, 오른쪽의 `noisy_true()`는 아예 호출되지 않는다. 그래서 "noisy_true 호출됨"이라는 문구가 출력되지 않았다. 이 특성은 다음처럼 오류를 방지하는 코드에서 유용하게 쓰인다.

```python
>>> numbers = []
>>> len(numbers) > 0 and numbers[0] > 10
False
```

`numbers`가 빈 리스트라서 `numbers[0]`에 접근하면 오류가 나겠지만, `len(numbers) > 0`이 이미 거짓이므로 뒤쪽은 평가되지 않아 오류 없이 안전하게 `False`를 얻는다. 함수를 정의하는 방법은 9장. 함수에서 자세히 배운다.

## 멤버십 연산자: in, not in

멤버십 연산자는 어떤 값이 컬렉션(문자열, 리스트, 튜플, 딕셔너리, 셋 등) 안에 들어있는지를 확인한다.

```python
>>> fruits = ["사과", "바나나", "포도"]
>>> "바나나" in fruits
True
>>> "수박" in fruits
False
>>> "수박" not in fruits
True
```

문자열에도 그대로 사용할 수 있으며, 이 경우 부분 문자열이 포함되어 있는지를 확인한다.

```python
>>> "gram" in "Python programming"
True
>>> "GRAM" in "Python programming"
False
```

멤버십 검사도 대소문자를 구분한다. 리스트와 튜플, 딕셔너리와 셋을 다루는 자세한 방법은 6장. 리스트와 튜플, 7장. 딕셔너리와 셋에서 각각 다룬다.

## 신원 연산자: is, is not — ==와의 차이

`is`와 `is not`은 두 이름이 완전히 동일한 객체를 가리키는지 확인하는 신원 연산자다. 3장에서 살펴본 `id()`를 이용한 비교를 더 읽기 좋게 표현한 것이라고 볼 수 있다. 실제로 `a is b`는 내부적으로 `id(a) == id(b)`와 동등하다.

```python
>>> a = [1, 2, 3]
>>> b = [1, 2, 3]
>>> a == b
True
>>> a is b
False
>>> c = a
>>> a is c
True
```

`a`와 `b`는 내용이 똑같은 리스트이므로 `==`로 비교하면 `True`가 나온다. 하지만 이 둘은 메모리에 각각 따로 만들어진, 서로 다른 객체이므로 `is`로 비교하면 `False`가 나온다. 반면 `c = a`로 이름표만 하나 더 붙인 `c`는 `a`와 완전히 같은 객체이므로 `is`가 `True`를 반환한다.

정리하면 다음과 같다.

- `==`: 두 값의 내용이 같은지를 비교한다. (값 비교)
- `is`: 두 이름이 같은 객체를 가리키는지를 비교한다. (신원 비교)

대부분의 경우 우리가 궁금한 것은 "값이 같은가"이므로 `==`를 사용해야 한다. `is`는 주로 다음 두 경우에 사용하는 것이 관례다.

1. `None`과 비교할 때: `None`은 프로그램 전체에서 단 하나만 존재하는 특별한 객체이므로 `if x is None:`처럼 쓰는 것이 관례다.
2. `True`, `False`와 비교할 때: `if is_ready is True:`보다는 `if is_ready:`처럼 값 자체를 조건으로 쓰는 것이 더 Python다운 표현이지만, 굳이 명시적으로 비교해야 한다면 `is`를 사용한다.

```python
>>> result = None
>>> if result is None:
...     print("결과가 없습니다")
...
결과가 없습니다
```

`is`를 값 비교에 잘못 사용하면 예상치 못한 결과를 만날 수 있다.

```python
>>> x = 1000
>>> y = 1000
>>> x == y
True
>>> x is y
False
```

`x`와 `y`는 값으로는 같지만, `1000`이라는 정수는 Python이 캐싱해서 재사용하는 작은 정수 범위(-5 ~ 256)를 벗어나므로 서로 다른 객체로 만들어졌다. 이런 이유로 값을 비교할 때는 반드시 `==`를 사용해야 하며, `is`를 값 비교 용도로 쓰는 것은 흔한 실수 중 하나다.

## 연산자 우선순위

한 표현식에 여러 연산자가 섞여 있을 때, 어떤 연산이 먼저 계산되는지를 결정하는 규칙이 연산자 우선순위다.

```python
>>> 2 + 3 * 4
14
>>> (2 + 3) * 4
20
>>> 10 - 2 ** 2
6
>>> 2 ** 3 ** 2
512
```

`2 + 3 * 4`는 곱셈이 덧셈보다 먼저 계산되어 `14`가 된다. `10 - 2 ** 2`도 거듭제곱이 뺄셈보다 먼저 계산되어 `10 - 4 = 6`이 된다. `2 ** 3 ** 2`처럼 거듭제곱이 연이어 나오면 오른쪽에서 왼쪽으로 계산되어 `2 ** (3 ** 2)`, 즉 `2 ** 9 = 512`가 된다는 점도 기억해두자. 대부분의 다른 연산자는 왼쪽에서 오른쪽으로 계산된다.

일반적으로 산술 연산자가 비교 연산자보다 먼저 계산되고, 비교 연산자가 논리 연산자보다 먼저 계산된다.

```python
>>> 3 + 2 > 4 and 1 < 2
True
```

위 표현식은 `((3 + 2) > 4) and (1 < 2)`로 계산되어 `True`가 된다.

연산자 우선순위를 모두 외우려 하기보다는, 의도가 헷갈릴 수 있는 상황에서는 괄호를 적극적으로 사용해서 계산 순서를 명확히 드러내는 편이 훨씬 안전하고 읽기 좋다.

```python
>>> (3 + 2) > 4 and (1 < 2)
True
```

Python의 전체 연산자 우선순위 표는 부록 "자주 쓰는 내장 함수/문자열 메서드 치트시트"에서 한눈에 볼 수 있도록 정리해두었으니 필요할 때 참고하자.

## 복합 대입 연산자

변수의 현재 값을 바탕으로 새로운 값을 만들어 같은 변수에 다시 대입하는 상황은 매우 흔하다.

```python
>>> count = 0
>>> count = count + 1
>>> count
1
```

Python은 이런 패턴을 짧게 쓸 수 있도록 복합 대입 연산자를 제공한다.

| 연산자 | 의미 | 같은 표현 |
|---|---|---|
| `+=` | 더한 값을 대입 | `x = x + y` |
| `-=` | 뺀 값을 대입 | `x = x - y` |
| `*=` | 곱한 값을 대입 | `x = x * y` |
| `/=` | 나눈 값을 대입 | `x = x / y` |
| `//=` | 정수 나눗셈 값을 대입 | `x = x // y` |
| `%=` | 나머지 값을 대입 | `x = x % y` |
| `**=` | 거듭제곱 값을 대입 | `x = x ** y` |

```python
>>> count = 0
>>> count += 1
>>> count += 1
>>> count
2
>>> total = 100
>>> total -= 30
>>> total
70
>>> price = 1000
>>> price *= 1.1
>>> price
1100.0000000000002
```

복합 대입 연산자는 단순히 타이핑을 줄여주는 것을 넘어, "이 변수의 값을 갱신한다"는 의도를 코드에서 더 분명하게 드러내는 역할도 한다.

가변 객체인 리스트에 `+=`를 사용할 때는 조금 다른 점을 알아둘 필요가 있다.

```python
>>> numbers = [1, 2, 3]
>>> original_id = id(numbers)
>>> numbers += [4]
>>> numbers
[1, 2, 3, 4]
>>> id(numbers) == original_id
True
```

리스트에 `+=`를 사용하면 `numbers = numbers + [4]`처럼 새로운 리스트를 만드는 대신, 기존 리스트 객체 자체를 제자리에서 수정한다. `id()`가 변하지 않은 것이 그 증거다. 반면 정수나 문자열 같은 불변 객체는 애초에 객체 자체를 수정할 방법이 없으므로, `+=`를 사용하면 항상 새로운 객체가 만들어지고 이름표가 그쪽으로 옮겨진다. 가변과 불변의 차이는 6장. 리스트와 튜플에서 더 깊이 다룬다.

## 요약

- 산술 연산자에는 사칙연산 외에 정수 나눗셈 `//`, 나머지 `%`, 거듭제곱 `**`이 있다. 음수가 섞이면 `//`와 `%`의 결과 부호가 직관과 다를 수 있으므로 주의한다.
- 비교 연산자 `==`, `!=`, `>`, `<`, `>=`, `<=`는 값을 비교해 `bool`을 반환하며, `18 <= age < 65`처럼 연쇄적으로 이어 쓸 수 있다.
- 논리 연산자 `and`, `or`, `not`은 단순히 `True`/`False`만 반환하는 것이 아니라 피연산자 자체를 반환하며, 단락 평가를 통해 필요한 경우 오른쪽 피연산자를 평가하지 않는다.
- 멤버십 연산자 `in`, `not in`은 값이 컬렉션에 포함되어 있는지 확인한다.
- 신원 연산자 `is`, `is not`은 두 이름이 같은 객체를 가리키는지 확인한다. 값이 같은지를 확인할 때는 `==`를, `None`과 비교할 때는 관례적으로 `is`를 사용한다.
- 연산자 우선순위에 따라 계산 순서가 정해지지만, 헷갈릴 여지가 있다면 괄호로 명확하게 표현하는 것이 좋다. 자세한 우선순위 표는 부록을 참고한다.
- 복합 대입 연산자(`+=`, `-=` 등)는 변수 값을 갱신하는 코드를 간결하게 만들어준다. 가변 객체에 `+=`를 사용하면 새 객체를 만들지 않고 기존 객체를 제자리에서 수정한다.

## 연습문제

1. 정수 `a`와 `b`가 주어졌을 때, `a`를 `b`로 나눈 몫과 나머지를 각각 `//`와 `%`로 구하고, `a == (a // b) * b + (a % b)`가 항상 성립하는지 여러 값(음수 포함)으로 확인하라.

2. 다음 표현식들의 결과를 계산 순서까지 손으로 먼저 예측한 뒤, 실제로 실행해서 확인하라.

   ```python
   3 + 4 * 2 ** 2
   (3 + 4) * 2 ** 2
   10 > 5 and 3 < 1 or not False
   ```

3. `is`와 `==`의 차이를 설명하고, 두 리스트 `[1, 2, 3]`을 각각 다른 변수에 대입했을 때 `==`와 `is`의 결과가 왜 다른지 `id()`를 이용해 보여라.

4. 사용자로부터 문자열을 입력받아, 그 값이 비어 있으면 `"손님"`을, 비어 있지 않으면 입력값을 그대로 사용하는 코드를 `or` 연산자의 단락 평가 특성을 이용해 한 줄로 작성하라.

5. 나이(`age`)와 회원 등급(`membership`, "일반" 또는 "VIP")이 주어졌을 때, "나이가 19세 이상"이고 "VIP 회원이거나 나이가 60세 이상"인 경우에만 할인 혜택을 받을 수 있는 조건식을 논리 연산자와 괄호를 이용해 작성하라.
