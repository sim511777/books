프로그램이 다루는 데이터 중 가장 자주 마주치는 것은 아마도 문자열(string)일 것입니다. 사용자의 이름을 입력받거나, 파일에서 읽은 텍스트를 처리하거나, 화면에 결과를 출력할 때 우리는 늘 문자열을 다룹니다. 3장에서 문자열이 `str`이라는 자료형이라는 것을 간단히 살펴보았다면, 이번 장에서는 문자열을 실제로 자유자재로 다루는 방법을 본격적으로 배웁니다.

## 5.1 문자열 리터럴 만들기

Python에서 문자열을 만드는 방법은 여러 가지가 있습니다. 어떤 방식을 쓰든 결과로 만들어지는 것은 똑같은 `str` 객체이지만, 상황에 따라 더 편리한 표기법이 다릅니다.

### 작은따옴표와 큰따옴표

Python은 작은따옴표(`'`)와 큰따옴표(`"`) 중 어느 것을 써도 문자열을 만들 수 있습니다. 두 방식에 기능적인 차이는 없으며, 어느 것을 선택할지는 대체로 취향과 상황의 문제입니다.

```python
>>> name = 'Ada'
>>> greeting = "안녕하세요"
>>> type(name)
<class 'str'>
>>> type(greeting)
<class 'str'>
```

두 표기법을 함께 알아두면 유용한 경우가 있습니다. 문자열 안에 따옴표 자체를 포함해야 할 때입니다. 문자열 안에 작은따옴표가 들어가야 한다면 큰따옴표로 감싸는 편이 편리하고, 반대의 경우도 마찬가지입니다.

```python
>>> quote = "그는 'Hello, world!'라고 말했다."
>>> print(quote)
그는 'Hello, world!'라고 말했다.
>>> sentence = 'she said "wow"'
>>> print(sentence)
she said "wow"
```

물론 뒤에서 배울 이스케이프 문자를 쓰면 같은 종류의 따옴표 안에서도 따옴표를 표현할 수 있지만, 위 방식이 더 읽기 편할 때가 많습니다.

### 삼중따옴표: 여러 줄 문자열

문자열이 여러 줄에 걸쳐 있어야 한다면 작은따옴표나 큰따옴표를 세 개 연속으로 써서 만드는 삼중따옴표 문자열을 사용합니다. `'''`와 `"""` 모두 사용할 수 있습니다.

```python
>>> poem = """봄이 오면
... 꽃이 피고
... 새가 운다"""
>>> print(poem)
봄이 오면
꽃이 피고
새가 운다
```

삼중따옴표 문자열은 줄바꿈을 그대로 포함하기 때문에 여러 줄짜리 텍스트를 작성할 때 편리합니다. 또한 삼중따옴표 안에서는 작은따옴표나 큰따옴표를 이스케이프 없이 자유롭게 사용할 수 있습니다.

```python
>>> message = '''그가 "괜찮아"라고 말했지만 나는 'really?'라고 되물었다.'''
>>> print(message)
그가 "괜찮아"라고 말했지만 나는 'really?'라고 되물었다.
```

삼중따옴표 문자열은 함수나 클래스의 docstring(문서화 문자열)을 작성할 때도 널리 쓰입니다. docstring은 9장 함수와 12장 클래스와 객체지향 기초에서 자세히 다룹니다.

```python
def add(a, b):
    """두 수 a와 b를 더한 값을 반환한다."""
    return a + b
```

### 이스케이프 문자

문자열 안에 줄바꿈이나 탭처럼 키보드로 직접 표현하기 어려운 문자를 넣거나, 문자열을 감싸는 것과 같은 종류의 따옴표를 문자열 내부에 넣고 싶을 때는 백슬래시(`\`)로 시작하는 이스케이프 문자를 사용합니다.

| 이스케이프 문자 | 의미 |
|---|---|
| `\n` | 줄바꿈 |
| `\t` | 탭 |
| `\\` | 백슬래시 문자 자체 |
| `\'` | 작은따옴표 |
| `\"` | 큰따옴표 |
| `\r` | 캐리지 리턴 |
| `\0` | 널 문자 |

```python
>>> print("첫째 줄\n둘째 줄")
첫째 줄
둘째 줄
>>> print("이름\t나이")
이름	나이
>>> path = "C:\\Users\\ada"
>>> print(path)
C:\Users\ada
>>> print('it\'s python')
it's python
```

Windows 경로처럼 백슬래시가 많이 등장하는 문자열을 다룰 때는 이스케이프 문자를 매번 신경 쓰기가 번거롭습니다. 이럴 때는 문자열 앞에 `r`을 붙인 raw 문자열(원시 문자열)을 사용하면 백슬래시를 이스케이프 문자로 해석하지 않고 있는 그대로 취급합니다.

```python
>>> path = r"C:\Users\ada\Documents"
>>> print(path)
C:\Users\ada\Documents
```

raw 문자열은 정규표현식을 다룰 때도 자주 사용됩니다. 정규표현식 자체가 백슬래시를 많이 사용하기 때문입니다. 이 내용은 17장 표준 라이브러리와 패키지 관리에서 `re` 모듈을 소개할 때 다시 언급하겠습니다.

## 5.2 인덱싱: 문자 하나 꺼내기

문자열은 문자들이 순서대로 나열된 시퀀스(sequence)입니다. 각 문자에는 위치를 나타내는 번호, 즉 인덱스(index)가 매겨져 있고, 대괄호(`[]`) 안에 인덱스를 넣어 특정 위치의 문자를 꺼낼 수 있습니다. Python의 인덱스는 항상 0부터 시작한다는 점을 꼭 기억해야 합니다.

```python
>>> word = "Python"
>>> word[0]
'P'
>>> word[1]
'y'
>>> word[5]
'n'
```

`word`는 6개의 문자로 이루어져 있으므로 인덱스는 0부터 5까지 사용할 수 있습니다. 범위를 벗어난 인덱스를 사용하면 `IndexError` 예외가 발생합니다. 예외에 관한 자세한 내용은 11장 예외 처리에서 다룹니다.

```python
>>> word[6]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: string index out of range
```

### 음수 인덱스

Python의 편리한 점 중 하나는 음수 인덱스를 지원한다는 것입니다. 음수 인덱스는 문자열의 끝에서부터 위치를 셉니다. `-1`은 마지막 문자, `-2`는 마지막에서 두 번째 문자를 가리킵니다.

```python
>>> word = "Python"
>>> word[-1]
'n'
>>> word[-2]
'o'
>>> word[-6]
'P'
```

문자열 끝부분의 문자를 꺼내고 싶을 때 전체 길이를 계산할 필요 없이 `-1`, `-2`처럼 바로 접근할 수 있어 매우 유용합니다. 인덱스와 음수 인덱스의 대응 관계는 다음과 같습니다.

```
문자:     P    y    o    t    h    n
양수 인덱스: 0    1    2    3    4    5
음수 인덱스: -6   -5   -4   -3   -2   -1
```

## 5.3 슬라이싱: 문자열 일부분 잘라내기

인덱싱이 문자 하나를 꺼내는 것이라면, 슬라이싱(slicing)은 문자열의 연속된 일부분을 잘라내는 방법입니다. `문자열[시작:끝]` 형태로 사용하며, 시작 인덱스는 포함되고 끝 인덱스는 포함되지 않는다는 점이 중요합니다.

```python
>>> word = "Python"
>>> word[0:2]
'Py'
>>> word[2:6]
'thon'
>>> word[2:]
'thon'
>>> word[:2]
'Py'
>>> word[:]
'Python'
```

시작 인덱스를 생략하면 처음부터, 끝 인덱스를 생략하면 끝까지를 의미합니다. `word[:]`처럼 둘 다 생략하면 문자열 전체를 복사한 새로운 문자열을 얻습니다.

### 슬라이싱에 step(간격) 지정하기

슬라이싱에는 세 번째 값으로 간격(step)을 지정할 수도 있습니다. `문자열[시작:끝:간격]` 형태입니다.

```python
>>> word = "Python"
>>> word[0:6:2]
'Pto'
>>> word[::2]
'Pto'
>>> word[1::2]
'yhn'
```

간격에 음수를 사용하면 문자열을 거꾸로 순회합니다. 이 성질을 이용하면 문자열을 뒤집는 짧은 코드를 만들 수 있습니다.

```python
>>> word = "Python"
>>> word[::-1]
'nohtyP'
```

### 음수 인덱스와 슬라이싱

슬라이싱에서도 음수 인덱스를 자유롭게 사용할 수 있습니다.

```python
>>> word = "Python"
>>> word[-3:]
'hon'
>>> word[:-3]
'Pyt'
>>> word[-4:-1]
'tho'
```

### 범위를 벗어난 슬라이싱은 안전하다

인덱싱과 달리 슬라이싱은 범위를 벗어난 인덱스를 지정해도 오류가 발생하지 않습니다. Python이 알아서 가능한 범위로 잘라줍니다.

```python
>>> word = "Python"
>>> word[2:100]
'thon'
>>> word[-100:3]
'Pyt'
```

이 성질 덕분에 문자열의 길이를 정확히 몰라도 "앞의 최대 3글자만" 같은 코드를 안전하게 작성할 수 있습니다.

## 5.4 f-string으로 문자열 포매팅하기

변수의 값을 다른 텍스트와 섞어서 출력해야 하는 경우는 매우 흔합니다. 예전에는 문자열을 `+`로 이어 붙이는 방식을 많이 썼지만, 값의 자료형이 문자열이 아니면 먼저 `str()`로 변환해야 하는 번거로움이 있었습니다.

```python
>>> name = "Ada"
>>> age = 28
>>> print("이름: " + name + ", 나이: " + str(age))
이름: Ada, 나이: 28
```

Python 3.6부터 도입된 f-string(포맷 문자열 리터럴)을 사용하면 훨씬 간결하고 읽기 쉽게 같은 결과를 만들 수 있습니다. 문자열 앞에 `f`를 붙이고, 중괄호(`{}`) 안에 표현식을 넣으면 그 값이 문자열 안에 그대로 삽입됩니다.

```python
>>> name = "Ada"
>>> age = 28
>>> print(f"이름: {name}, 나이: {age}")
이름: Ada, 나이: 28
```

중괄호 안에는 변수뿐 아니라 연산이 포함된 표현식도 넣을 수 있습니다.

```python
>>> price = 1200
>>> quantity = 3
>>> print(f"총 금액: {price * quantity}원")
총 금액: 3600원
```

함수 호출 결과를 넣는 것도 가능합니다.

```python
>>> name = "ada lovelace"
>>> print(f"이름(대문자): {name.upper()}")
이름(대문자): ADA LOVELACE
```

### 포맷 스펙: 소수점 자리수와 정렬

f-string은 중괄호 안에 콜론(`:`)을 붙여 값을 어떤 형식으로 표시할지 세밀하게 지정하는 포맷 스펙(format spec)을 지원합니다. 가장 자주 쓰이는 것은 실수의 소수점 자릿수를 지정하는 방법입니다.

```python
>>> pi = 3.14159265
>>> print(f"원주율: {pi:.2f}")
원주율: 3.14
>>> print(f"원주율: {pi:.4f}")
원주율: 3.1416
```

`.2f`는 "소수점 아래 2자리까지 표시하는 고정 소수점(fixed-point) 표기"라는 뜻입니다. 숫자를 특정 너비에 맞춰 정렬할 수도 있습니다.

```python
>>> for i in range(1, 4):
...     print(f"{i:3d}번째 항목")
...
  1번째 항목
  2번째 항목
  3번째 항목
```

`{i:3d}`는 정수를 최소 3칸의 너비로 오른쪽 정렬해 표시합니다. 문자열은 `<`, `>`, `^`로 왼쪽/오른쪽/가운데 정렬을 지정할 수 있습니다.

```python
>>> print(f"[{'hi':<10}]")
[hi        ]
>>> print(f"[{'hi':>10}]")
[        hi]
>>> print(f"[{'hi':^10}]")
[    hi    ]
```

숫자를 천 단위 구분 기호와 함께 표시하거나 백분율로 표시하는 것도 가능합니다.

```python
>>> big_number = 1234567
>>> print(f"{big_number:,}")
1,234,567
>>> ratio = 0.8532
>>> print(f"{ratio:.1%}")
85.3%
```

### 디버깅에 유용한 `=` 지정자

Python 3.8부터는 f-string 안에서 `{변수=}` 형태를 쓰면 변수 이름과 값을 함께 출력해주어 디버깅할 때 매우 편리합니다.

```python
>>> width = 10
>>> height = 5
>>> print(f"{width=}, {height=}")
width=10, height=5
```

### 다른 포매팅 방식도 있다: `.format()`과 `%`

f-string이 등장하기 전에는 `str.format()` 메서드와 `%` 연산자를 이용한 포매팅이 널리 쓰였습니다. 오래된 코드나 다른 사람의 코드를 읽다 보면 여전히 마주칠 수 있으므로 형태만 간단히 알아두면 좋습니다.

```python
>>> "이름: {}, 나이: {}".format(name, age)
'이름: Ada, 나이: 28'
>>> "이름: %s, 나이: %d" % (name, age)
'이름: Ada, 나이: 28'
```

새로운 코드를 작성할 때는 가독성이 좋고 표현식을 직접 사용할 수 있는 f-string을 사용하는 것을 권장합니다. 이 책의 나머지 부분에서도 문자열 포매팅에는 기본적으로 f-string을 사용합니다.

## 5.5 자주 쓰는 문자열 메서드

문자열은 다양한 메서드를 제공합니다. 여기서는 실무에서 특히 자주 쓰이는 메서드들을 살펴봅니다. 문자열 메서드가 반환하는 것은 항상 새로운 문자열이나 다른 자료형의 값이며, 원본 문자열은 절대 바뀌지 않는다는 점을 기억해두세요(이는 5.6절에서 다시 설명합니다).

### 대소문자 변환: upper, lower, title, capitalize

```python
>>> s = "Hello, World!"
>>> s.upper()
'HELLO, WORLD!'
>>> s.lower()
'hello, world!'
>>> s.title()
'Hello, World!'
>>> "hello world".capitalize()
'Hello world'
```

`upper()`와 `lower()`는 각각 모든 문자를 대문자와 소문자로 바꿉니다. `title()`은 각 단어의 첫 글자만 대문자로 만들고, `capitalize()`는 문자열 전체의 첫 글자만 대문자로 만듭니다.

### 공백 제거: strip, lstrip, rstrip

사용자 입력이나 파일에서 읽은 텍스트에는 불필요한 공백이나 줄바꿈이 앞뒤에 붙어 있는 경우가 많습니다. `strip()` 계열 메서드로 이를 제거할 수 있습니다.

```python
>>> raw = "   hello world   \n"
>>> raw.strip()
'hello world'
>>> raw.lstrip()
'hello world   \n'
>>> raw.rstrip()
'   hello world'
```

`strip()`은 양쪽, `lstrip()`은 왼쪽, `rstrip()`은 오른쪽의 공백 문자(스페이스, 탭, 줄바꿈 등)를 제거합니다. 인자로 문자를 지정하면 공백 대신 해당 문자들을 제거할 수도 있습니다.

```python
>>> "==제목==".strip("=")
'제목'
```

### 분리와 결합: split과 join

`split()`은 문자열을 특정 구분자를 기준으로 나누어 리스트로 만듭니다. 인자를 생략하면 공백(스페이스, 탭, 줄바꿈 등 연속된 공백 문자 전체)을 기준으로 나눕니다.

```python
>>> sentence = "Python is fun"
>>> sentence.split()
['Python', 'is', 'fun']
>>> csv_line = "apple,banana,cherry"
>>> csv_line.split(",")
['apple', 'banana', 'cherry']
```

`join()`은 `split()`과 반대로, 리스트(혹은 다른 반복 가능한 객체)에 담긴 문자열들을 하나의 문자열로 이어 붙입니다. 이때 `join()`은 구분자로 사용할 문자열이 메서드를 호출하는 주체가 됩니다.

```python
>>> words = ["Python", "is", "fun"]
>>> " ".join(words)
'Python is fun'
>>> fruits = ["apple", "banana", "cherry"]
>>> ", ".join(fruits)
'apple, banana, cherry'
```

리스트에 대해서는 6장 리스트와 튜플에서 자세히 배우게 되지만, `split()`과 `join()`은 문자열과 리스트를 오가는 대표적인 통로이므로 미리 익혀두면 유용합니다.

### 치환: replace

`replace(old, new)`는 문자열 안의 `old`를 모두 `new`로 바꾼 새 문자열을 반환합니다.

```python
>>> s = "Hello, World!"
>>> s.replace("World", "Python")
'Hello, Python!'
>>> "banana".replace("a", "o")
'bonono'
```

세 번째 인자로 바꿀 횟수를 제한할 수도 있습니다.

```python
>>> "banana".replace("a", "o", 1)
'bonana'
```

### 검색: find, index, count, in

문자열 안에서 특정 부분 문자열을 찾을 때는 `find()`, `index()`, 그리고 `in` 연산자를 사용합니다.

```python
>>> s = "Hello, World!"
>>> s.find("World")
7
>>> s.find("Python")
-1
>>> "World" in s
True
>>> "Python" in s
False
```

`find()`는 찾는 문자열이 처음 등장하는 인덱스를 반환하고, 찾지 못하면 `-1`을 반환합니다. `index()`도 동일하게 동작하지만 찾지 못하면 `-1` 대신 `ValueError` 예외를 발생시킨다는 차이가 있습니다.

```python
>>> s.index("Python")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ValueError: substring not found
```

값이 있는지 없는지만 확인하고 싶다면 `in` 연산자를 사용하는 것이 가장 간결하고 Python다운(pythonic) 방법입니다. 특정 부분 문자열이 몇 번 등장하는지 세려면 `count()`를 사용합니다.

```python
>>> "banana".count("a")
3
```

### 접두사/접미사 검사: startswith, endswith

파일 확장자를 검사하거나 특정 접두사로 시작하는지 확인할 때 유용합니다.

```python
>>> filename = "report.pdf"
>>> filename.endswith(".pdf")
True
>>> filename.startswith("report")
True
>>> filename.endswith((".pdf", ".docx"))
True
```

`endswith()`와 `startswith()`는 튜플을 인자로 넘기면 그중 하나라도 일치하는지 검사할 수 있습니다. 튜플에 대해서는 6장에서 자세히 다룹니다.

### 내용 검사 메서드: isdigit, isalpha, isupper 등

문자열이 특정 조건을 만족하는지 검사하는 `is`로 시작하는 메서드들도 자주 사용됩니다.

```python
>>> "12345".isdigit()
True
>>> "abc123".isdigit()
False
>>> "abcde".isalpha()
True
>>> "abc123".isalnum()
True
>>> "HELLO".isupper()
True
>>> "   ".isspace()
True
```

이 메서드들은 사용자 입력을 검증할 때 특히 유용합니다. 예를 들어 사용자가 입력한 문자열이 숫자로만 이루어졌는지 확인한 뒤에 `int()`로 변환하면 더 안전한 코드를 작성할 수 있습니다.

```python
>>> user_input = "42"
>>> if user_input.isdigit():
...     number = int(user_input)
...     print(f"입력한 숫자: {number}")
... else:
...     print("숫자만 입력해주세요.")
...
입력한 숫자: 42
```

### 문자열 정렬 채우기: zfill, center

숫자를 자릿수에 맞춰 0으로 채우거나 텍스트를 가운데 정렬할 때 사용합니다.

```python
>>> "7".zfill(3)
'007'
>>> "42".zfill(5)
'00042'
>>> "제목".center(10, "-")
'----제목----'
```

## 5.6 문자열은 불변(immutable)이다

문자열을 다룰 때 반드시 기억해야 할 중요한 성질이 있습니다. 바로 문자열은 불변(immutable) 자료형이라는 것입니다. 한 번 만들어진 문자열 객체의 내용은 절대로 바꿀 수 없습니다. 인덱싱으로 특정 위치의 문자를 직접 바꾸려고 하면 오류가 발생합니다.

```python
>>> word = "Python"
>>> word[0] = "J"
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'str' object does not support item assignment
```

그렇다면 앞서 살펴본 `upper()`나 `replace()` 같은 메서드는 문자열을 "바꾸는" 것이 아닌가 궁금할 수 있습니다. 사실 이 메서드들은 원본 문자열을 수정하는 것이 아니라, 원본은 그대로 둔 채 변경된 내용을 담은 완전히 새로운 문자열 객체를 만들어 반환합니다.

```python
>>> original = "hello"
>>> changed = original.upper()
>>> print(original)
hello
>>> print(changed)
HELLO
```

`original.upper()`를 호출해도 `original` 변수가 가리키는 문자열 자체는 전혀 바뀌지 않습니다. 대신 `"HELLO"`라는 새로운 문자열 객체가 만들어지고, 그 결과를 `changed`라는 새 변수에 담아야만 사용할 수 있습니다. 초보자들이 자주 하는 실수 중 하나가 다음과 같이 반환값을 저장하지 않고 원본이 바뀌었을 것이라고 착각하는 것입니다.

```python
>>> name = "ada"
>>> name.upper()  # 반환값을 어디에도 저장하지 않음
'ADA'
>>> print(name)   # name은 여전히 소문자 그대로
ada
```

원본을 바꾼 것처럼 사용하려면 다음과 같이 결과를 다시 같은 변수에 대입해야 합니다.

```python
>>> name = "ada"
>>> name = name.upper()
>>> print(name)
ADA
```

문자열이 불변이라는 성질은 `id()` 함수로도 확인할 수 있습니다. `id()`는 객체의 고유한 식별값을 반환하는데, 문자열을 "변경"하는 연산을 수행하면 항상 다른 `id`를 가진 새로운 객체가 만들어집니다.

```python
>>> s = "hello"
>>> id(s)
2214540051888
>>> s = s + " world"
>>> id(s)
2214540123056
```

두 `id` 값이 서로 다르다는 것은 `s + " world"`가 기존 문자열을 수정한 것이 아니라 완전히 새로운 문자열 객체를 만들었다는 뜻입니다.

### 왜 문자열은 불변으로 설계되었을까?

문자열이 불변이라는 설계는 여러 실질적인 장점을 가져다줍니다. 먼저, 값이 절대 바뀌지 않는다는 보장이 있으면 여러 변수가 같은 문자열 객체를 공유하더라도 안심하고 사용할 수 있습니다. 또한 불변 객체는 딕셔너리의 키나 셋의 원소로 사용할 수 있는데, 이는 7장 딕셔너리와 셋에서 다시 살펴볼 내용입니다. 마지막으로, 값이 변하지 않는다는 특성 덕분에 Python 내부적으로 같은 내용의 문자열을 재사용하는 최적화도 가능해집니다.

반대로 6장에서 배울 리스트는 가변(mutable) 자료형으로, 한 번 만든 뒤에도 내용을 자유롭게 바꿀 수 있습니다. 문자열과 리스트의 이러한 차이는 앞으로 자료형을 선택할 때 계속 염두에 두어야 할 중요한 기준이 됩니다.

## 요약

- 문자열은 작은따옴표, 큰따옴표, 삼중따옴표로 만들 수 있으며, 삼중따옴표는 여러 줄 문자열이나 docstring 작성에 유용합니다.
- `\n`, `\t`와 같은 이스케이프 문자로 특수 문자를 표현하며, `r"..."` 형태의 raw 문자열은 백슬래시를 그대로 취급합니다.
- 인덱싱(`s[i]`)으로 문자 하나를, 슬라이싱(`s[시작:끝:간격]`)으로 부분 문자열을 얻을 수 있습니다. 음수 인덱스는 끝에서부터 위치를 셉니다.
- f-string(`f"{표현식}"`)을 사용하면 표현식의 값을 문자열에 간결하게 삽입할 수 있고, `:.2f`와 같은 포맷 스펙으로 표시 형식을 세밀하게 조정할 수 있습니다.
- `split()`, `join()`, `strip()`, `replace()`, `upper()`/`lower()`, `find()` 등 다양한 문자열 메서드가 있으며, 이들은 모두 새로운 문자열을 반환합니다.
- 문자열은 불변(immutable) 자료형이므로 한 번 만들어진 문자열의 내용은 바꿀 수 없고, 메서드 호출 결과는 반드시 변수에 다시 저장해야 합니다.
