## 이 장에서 다루는 내용

지금까지 우리는 Python 언어 자체의 문법을 익혀 왔다. 그런데 실제로 쓸모 있는 프로그램을 만들려면 언어 문법만으로는 부족하다. 파일 경로를 다루고, 현재 시각을 구하고, 난수를 뽑고, 데이터를 세어 보는 등의 작업이 필요한데, 이런 기능을 매번 직접 만들 필요는 없다. Python은 설치하는 순간부터 방대한 **표준 라이브러리(standard library)** 를 함께 제공하며, 여기에 없는 기능은 전 세계 개발자들이 공개한 외부 패키지를 설치해서 가져다 쓸 수 있다.

이 장에서는 다음 세 가지를 다룬다.

1. 실무에서 자주 마주치는 표준 라이브러리 모듈들을 훑어본다.
2. `pip`으로 외부 패키지를 설치하고 관리하는 방법을 익힌다.
3. 프로젝트마다 독립된 환경을 유지해 주는 가상환경(virtual environment)의 필요성과 사용법을 배운다.

모듈을 가져와서 쓰는 기본 문법 자체는 14장(모듈과 패키지)에서 이미 다루었으므로, 여기서는 "무엇을, 왜 쓰는가"에 집중한다. 컴프리헨션과 제너레이터의 기본 개념은 10장에서 다루었으므로, `itertools`처럼 제너레이터와 맞닿아 있는 모듈을 이해하는 데 도움이 될 것이다.

## 표준 라이브러리란

Python을 설치하면 인터프리터와 함께 수백 개의 모듈이 딸려 온다. 이들을 통틀어 표준 라이브러리라고 부른다. 표준 라이브러리는 별도의 설치 과정 없이 `import` 한 줄이면 바로 사용할 수 있다는 것이 가장 큰 장점이다. "Python은 배터리가 포함되어 있다(batteries included)"라는 말이 있을 정도로, 파일 압축, 날짜 계산, 네트워크 통신, 정규 표현식 등 웬만한 기본 작업은 표준 라이브러리만으로 처리할 수 있다.

아래 표는 실무에서 특히 자주 쓰이는 모듈을 간단히 정리한 것이다.

| 모듈 | 주요 용도 |
|---|---|
| `os` | 운영체제 기능 접근 — 파일 경로, 환경 변수, 디렉터리 목록 |
| `sys` | 인터프리터 자체와 관련된 정보 — 명령줄 인자, 종료 코드 |
| `datetime` | 날짜와 시간 표현 및 계산 |
| `math` | 삼각함수, 로그, 제곱근 등 수학 함수 |
| `random` | 난수 생성, 무작위 선택과 섞기 |
| `collections` | 리스트·딕셔너리를 보완하는 특수 컨테이너 |
| `itertools` | 반복(iteration)을 위한 효율적인 도구 모음 |

하나씩 살펴보자.

### os — 운영체제와 상호작용하기

`os` 모듈은 파일 시스템이나 환경 변수처럼 운영체제가 제공하는 자원에 접근할 때 사용한다.

```python
import os

# 현재 작업 디렉터리 확인
현재_경로 = os.getcwd()
print(현재_경로)

# 여러 경로 조각을 운영체제에 맞는 구분자로 합치기
파일_경로 = os.path.join("data", "reports", "2026.csv")
print(파일_경로)  # Windows에서는 data\reports\2026.csv

# 특정 경로가 실제로 존재하는지 확인
if os.path.exists(파일_경로):
    print("파일이 존재합니다.")
else:
    print("파일을 찾을 수 없습니다.")
```

`os.path.join`을 쓰면 Windows와 macOS/Linux의 경로 구분자(`\` 대 `/`) 차이를 신경 쓰지 않아도 된다는 점이 중요하다. 문자열을 직접 `+`로 이어 붙이는 것보다 항상 이 방식을 권장한다.

> 참고: 최근에는 `os.path` 대신 객체지향 방식의 `pathlib.Path`를 사용하는 코드도 많아지고 있다. 두 방식 모두 널리 쓰이므로, 기존 코드를 읽을 때를 대비해 `os.path`도 익혀 두는 것이 좋다.

### sys — 인터프리터 정보와 실행 환경

`sys` 모듈은 Python 인터프리터 자체를 제어하거나 그 정보를 조회할 때 사용한다.

```python
import sys

# 현재 사용 중인 Python 버전 확인
print(sys.version)

# 명령줄에서 프로그램에 전달된 인자 목록
# 예: python script.py hello 123 를 실행하면
# sys.argv는 ['script.py', 'hello', '123']이 된다
print(sys.argv)

# 특정 조건에서 프로그램을 즉시 종료하고 종료 코드를 지정
if len(sys.argv) < 2:
    print("사용법: python script.py <파일명>")
    sys.exit(1)
```

`sys.argv`는 커맨드라인 도구를 만들 때 특히 유용하다. 사용자가 프로그램 실행 시 넘긴 값을 읽어서 동작을 바꿀 수 있기 때문이다.

### datetime — 날짜와 시간 다루기

`datetime` 모듈은 날짜와 시간을 객체로 표현하고 계산할 수 있게 해 준다.

```python
from datetime import datetime, timedelta

# 현재 날짜와 시각
지금 = datetime.now()
print(지금)  # 예: 2026-08-07 14:30:12.345678

# 원하는 형식의 문자열로 변환
print(지금.strftime("%Y년 %m월 %d일"))

# 날짜 계산 - 7일 뒤 날짜 구하기
일주일_뒤 = 지금 + timedelta(days=7)
print(일주일_뒤.strftime("%Y-%m-%d"))
```

`timedelta`는 "며칠 뒤", "몇 시간 전"처럼 시간 간격을 표현하는 객체다. `datetime` 객체끼리 더하거나 뺄 때 함께 사용한다.

### math — 수학 함수 모음

`math` 모듈은 사칙연산으로는 부족한 다양한 수학 함수를 제공한다.

```python
import math

print(math.sqrt(16))       # 4.0, 제곱근
print(math.floor(3.7))     # 3, 내림
print(math.ceil(3.2))      # 4, 올림
print(math.pi)             # 3.141592653589793
```

4장(연산자와 표현식)에서 배운 `**` 연산자로도 제곱근(`16 ** 0.5`)을 구할 수 있지만, `math.sqrt`가 의도를 더 명확히 드러내고 부동소수점 오차 측면에서도 더 안정적이다.

### random — 무작위성이 필요할 때

`random` 모듈은 게임, 시뮬레이션, 테스트 데이터 생성 등에서 무작위성이 필요할 때 사용한다.

```python
import random

print(random.randint(1, 6))          # 1부터 6까지 정수 중 하나 (주사위)
print(random.choice(["가위", "바위", "보"]))  # 리스트에서 무작위로 하나 선택

숫자들 = [1, 2, 3, 4, 5]
random.shuffle(숫자들)                # 리스트 순서를 무작위로 섞음 (원본 변경)
print(숫자들)
```

`random.shuffle`은 리스트가 가변(mutable) 객체이기 때문에 원본을 직접 바꾼다는 점에 유의하자. 가변 객체와 불변(immutable) 객체의 차이는 6장과 7장에서 다룬 내용을 참고하면 된다.

> 주의: `random` 모듈이 생성하는 난수는 암호학적으로 안전하지 않다. 비밀번호나 보안 토큰을 만들어야 한다면 `secrets` 모듈을 사용해야 한다.

### collections — 리스트와 딕셔너리를 보완하는 컨테이너

`collections` 모듈은 6장과 7장에서 배운 리스트, 딕셔너리로는 다소 번거로운 작업을 간결하게 처리해 주는 특수 컨테이너를 제공한다. 그중 가장 자주 쓰이는 두 가지가 `Counter`와 `defaultdict`다.

`Counter`는 항목의 개수를 세는 데 특화된 딕셔너리다.

```python
from collections import Counter

단어들 = ["사과", "바나나", "사과", "포도", "바나나", "사과"]
개수 = Counter(단어들)
print(개수)                    # Counter({'사과': 3, '바나나': 2, '포도': 1})
print(개수.most_common(2))     # [('사과', 3), ('바나나', 2)] - 가장 많은 2개
```

직접 딕셔너리로 개수를 세려면 `if 키 in 딕셔너리` 검사와 초기화 코드를 매번 작성해야 하지만, `Counter`는 이 과정을 한 줄로 끝내 준다.

`defaultdict`는 존재하지 않는 키에 접근할 때 `KeyError`를 발생시키는 대신, 미리 정해 둔 기본값을 자동으로 만들어 준다.

```python
from collections import defaultdict

# 일반 딕셔너리라면 각 그룹의 첫 항목을 넣기 전에
# 리스트가 있는지 매번 확인해야 한다
학생_그룹 = defaultdict(list)
학생_그룹["1반"].append("민준")
학생_그룹["1반"].append("서연")
학생_그룹["2반"].append("지훈")

print(학생_그룹)
# defaultdict(<class 'list'>, {'1반': ['민준', '서연'], '2반': ['지훈']})
```

`defaultdict(list)`는 "키가 없으면 빈 리스트를 기본값으로 만들어라"는 뜻이다. 11장에서 배운 예외 처리로 `KeyError`를 매번 잡는 것보다 훨씬 깔끔한 해법이 된다.

### itertools — 반복을 위한 도구 상자

`itertools`는 반복 가능한(iterable) 객체를 다루는 다양한 도구를 제공하는 모듈이다. 10장에서 배운 제너레이터 개념과 밀접하게 관련되어 있으며, 내부적으로 대부분의 함수가 제너레이터를 반환하기 때문에 메모리를 효율적으로 사용한다. 여기서는 간단히 맛만 보기로 한다.

```python
import itertools

# 여러 개의 리스트를 하나의 흐름처럼 이어서 순회
for 항목 in itertools.chain([1, 2], [3, 4], [5]):
    print(항목, end=" ")   # 1 2 3 4 5
print()

# 순열(permutations) - 순서를 고려한 조합
for 순서 in itertools.permutations(["A", "B", "C"], 2):
    print(순서)
# ('A', 'B') ('A', 'C') ('B', 'A') ('B', 'C') ('C', 'A') ('C', 'B')
```

`itertools`에는 이 외에도 `combinations`, `product`, `groupby` 등 유용한 함수가 많다. 데이터를 조합하거나 그룹으로 묶는 작업이 잦아진다면 `itertools` 공식 문서를 살펴볼 가치가 있다.

## pip으로 외부 패키지 설치하기

표준 라이브러리만으로 부족할 때는 다른 개발자들이 만들어 공개한 **패키지**를 가져다 쓸 수 있다. 이런 외부 패키지들은 주로 파이썬 패키지 저장소에 올라와 있으며, `pip`이라는 도구로 설치한다. `pip`은 Python을 설치하면 기본으로 함께 설치되는 패키지 관리 도구다.

```powershell
# 패키지 설치
pip install requests

# 특정 버전을 지정해서 설치
pip install requests==2.31.0

# 설치된 패키지 목록 확인
pip list

# 패키지 제거
pip uninstall requests
```

패키지를 설치한 뒤에는 14장에서 배운 것과 동일하게 `import`로 가져와 사용하면 된다.

```python
import requests

response = requests.get("https://example.com")
print(response.status_code)
```

### requirements.txt로 패키지 목록 관리하기

여러 사람이 함께 작업하거나, 같은 프로젝트를 다른 컴퓨터에서 다시 실행해야 할 때 "이 프로젝트가 어떤 패키지들을 필요로 하는지"를 정확히 공유할 방법이 필요하다. 이때 관례적으로 사용하는 파일이 `requirements.txt`다.

```
requests==2.31.0
beautifulsoup4==4.12.3
pandas>=2.0.0
```

현재 환경에 설치된 패키지 목록을 이 형식 그대로 파일에 저장하려면 다음 명령을 사용한다.

```powershell
pip freeze > requirements.txt
```

그리고 다른 컴퓨터나 새로운 환경에서 이 파일에 적힌 패키지를 한 번에 설치하려면 다음과 같이 한다.

```powershell
pip install -r requirements.txt
```

`requirements.txt`는 특별한 문법이 있는 것이 아니라 "패키지 이름과 버전을 한 줄에 하나씩 적어 둔 텍스트 파일"이라는 약속일 뿐이다. 하지만 이 단순한 파일 덕분에 협업자 간에 "내 컴퓨터에서는 되는데 네 컴퓨터에서는 안 된다"는 문제를 상당히 줄일 수 있다.

## 가상환경이 필요한 이유

여러 프로젝트를 진행하다 보면 프로젝트마다 필요한 패키지의 버전이 다른 경우가 생긴다. 예를 들어 프로젝트 A는 `requests` 2.31 버전이 필요하고, 프로젝트 B는 3.0 버전이 필요하다고 하자. 컴퓨터 전체에 패키지를 하나만 설치할 수 있다면, 두 프로젝트를 동시에 만족시킬 방법이 없다.

**가상환경(virtual environment)** 은 이 문제를 해결한다. 프로젝트마다 독립된 Python 실행 환경(그리고 그 환경에 설치되는 패키지 목록)을 따로 두는 것이다. 가상환경을 사용하면

- 프로젝트별로 서로 다른 패키지 버전을 충돌 없이 사용할 수 있고,
- 시스템 전체에 설치된 Python 환경을 어지럽히지 않으며,
- `requirements.txt`와 함께 사용하면 "이 프로젝트에 정확히 어떤 패키지가 필요한지"를 완벽하게 재현할 수 있다.

Python은 `venv`라는 가상환경 도구를 표준 라이브러리로 기본 제공한다. 별도의 설치가 필요 없다.

### venv 생성하고 활성화하기

프로젝트 폴더에서 다음 명령으로 가상환경을 만든다. `myenv`는 가상환경 폴더의 이름으로, 원하는 이름을 자유롭게 붙일 수 있다.

```powershell
python -m venv myenv
```

이 명령을 실행하면 `myenv`라는 폴더가 생기고, 그 안에 독립된 Python 실행 파일과 패키지 저장 공간이 만들어진다.

가상환경을 만들었다면 이를 **활성화**해야 실제로 사용할 수 있다. 활성화 명령은 운영체제마다 다르다.

```powershell
# Windows (PowerShell)
myenv\Scripts\Activate.ps1
```

```bash
# macOS / Linux
source myenv/bin/activate
```

활성화에 성공하면 터미널 프롬프트 앞에 `(myenv)`처럼 가상환경 이름이 표시된다. 이 상태에서 `pip install`로 설치하는 모든 패키지는 시스템 전체가 아니라 `myenv` 안에만 설치된다.

작업을 마치고 가상환경에서 빠져나오려면 다음 명령을 입력한다.

```powershell
deactivate
```

### 실전 흐름 정리

새 프로젝트를 시작할 때 일반적으로는 다음 순서를 따른다.

```powershell
# 1. 프로젝트 폴더로 이동한 뒤 가상환경 생성
python -m venv venv

# 2. 가상환경 활성화
venv\Scripts\Activate.ps1

# 3. 필요한 패키지 설치
pip install requests pandas

# 4. 현재 패키지 목록을 requirements.txt로 저장 (버전 관리에 포함)
pip freeze > requirements.txt

# (다른 컴퓨터에서 이 프로젝트를 받았다면)
# python -m venv venv 로 가상환경을 만들고 활성화한 뒤
pip install -r requirements.txt
```

이 흐름을 습관화해 두면 협업이나 배포 과정에서 발생하는 "환경 차이로 인한 오류"를 크게 줄일 수 있다.

## 요약

- Python은 `os`, `sys`, `datetime`, `math`, `random`, `collections`, `itertools` 등 방대한 표준 라이브러리를 기본으로 제공하며, 대부분의 기본적인 작업은 별도 설치 없이 처리할 수 있다.
- `os`는 파일 경로와 운영체제 자원에, `sys`는 인터프리터 정보와 명령줄 인자에, `datetime`은 날짜·시간 계산에, `math`는 수학 함수에, `random`은 무작위성이 필요할 때 사용한다.
- `collections`의 `Counter`는 항목 개수 세기를, `defaultdict`는 존재하지 않는 키에 대한 기본값 처리를 간결하게 해결해 준다.
- `itertools`는 제너레이터 기반의 효율적인 반복 도구를 제공한다.
- 표준 라이브러리에 없는 기능은 `pip install`로 외부 패키지를 설치해서 사용할 수 있다.
- `requirements.txt`는 프로젝트가 필요로 하는 패키지와 버전을 기록해 두는 관례적인 파일로, `pip freeze`와 `pip install -r`로 만들고 재현한다.
- 가상환경(venv)은 프로젝트마다 독립된 패키지 설치 공간을 제공해서 버전 충돌 문제를 막아 준다. `python -m venv`로 생성하고, 운영체제에 맞는 명령으로 활성화한 뒤 사용한다.

## 연습문제

1. `collections.Counter`를 사용해서 문자열 `"abracadabra"`에 각 알파벳이 몇 번씩 등장하는지 세고, 가장 많이 등장한 알파벳 상위 3개를 출력하는 프로그램을 작성해 보자.
2. `datetime` 모듈을 사용해서 사용자가 입력한 생년월일(예: `"2000-01-01"`)을 받아, 오늘 날짜를 기준으로 태어난 지 며칠이 지났는지 계산하는 프로그램을 작성해 보자. (문자열을 날짜로 변환할 때는 `datetime.strptime`을 검색해 보자.)
3. `random.choice`와 `while` 문을 조합해서, 컴퓨터가 1부터 100 사이의 숫자를 무작위로 정하고 사용자가 맞힐 때까지 "더 큰 수입니다"/"더 작은 수입니다" 힌트를 주는 숫자 맞히기 게임을 만들어 보자.
4. 새 폴더를 만들고 그 안에서 가상환경을 생성한 뒤 활성화해 보자. 아무 패키지나 하나 설치하고 `pip freeze`로 `requirements.txt` 파일을 만든 다음, 가상환경을 비활성화(`deactivate`)하고 다시 활성화해서 설치한 패키지가 그대로 남아 있는지 확인해 보자.
5. `defaultdict(int)`와 일반 딕셔너리를 각각 사용해서, 리스트 안의 숫자별 등장 횟수를 세는 코드를 두 가지 방식으로 작성하고 코드의 길이와 가독성을 비교해 보자.
