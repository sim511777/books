## 들어가며

지금까지 작성한 프로그램은 실행이 끝나는 순간 그 결과가 모두 사라졌습니다. 변수에 담아둔 값도, 계산 결과도, 프로그램이 종료되면 메모리에서 함께 지워집니다. 하지만 실제로 쓸모 있는 프로그램 대부분은 결과를 어딘가에 남겨두고, 다음에 실행될 때 그 결과를 다시 불러와야 합니다. 설정값을 저장하거나, 로그를 기록하거나, 사용자가 입력한 데이터를 보관하는 일이 모두 여기에 해당합니다.

이번 장에서는 Python 프로그램이 컴퓨터의 저장 장치에 있는 파일을 읽고 쓰는 방법을 다룹니다. 텍스트 파일을 다루는 기본기부터 시작해서, 구조화된 데이터를 저장할 때 널리 쓰이는 `json` 모듈, 그리고 표 형태의 데이터를 다루는 `csv` 모듈까지 차례로 살펴보겠습니다.

## open() 함수와 파일 모드

### 기본 사용법

Python에서 파일을 다루는 출발점은 내장 함수 `open()`입니다. `open()`은 파일의 경로를 받아서 그 파일과 연결된 "파일 객체"를 돌려줍니다. 이후의 읽기, 쓰기 작업은 모두 이 파일 객체를 통해 이루어집니다.

먼저 텍스트 파일 하나를 직접 만들어보겠습니다. 다음 코드를 실행하면 현재 디렉터리에 `greeting.txt`라는 파일이 새로 생깁니다.

```python
file = open("greeting.txt", "w", encoding="utf-8")
file.write("안녕하세요, Python!\n")
file.close()
```

`open()`에 전달한 세 인자를 하나씩 살펴보면 다음과 같습니다.

- `"greeting.txt"`: 열고자 하는 파일의 경로입니다. 현재 작업 디렉터리를 기준으로 한 상대 경로를 사용했습니다.
- `"w"`: 파일 모드입니다. `"w"`는 "write", 즉 쓰기 모드를 뜻합니다.
- `encoding="utf-8"`: 파일에 텍스트를 어떤 문자 인코딩으로 저장할지 지정합니다.

작업이 끝난 뒤에는 반드시 `file.close()`를 호출해서 파일을 닫아주어야 합니다. 파일을 닫지 않으면 운영체제가 파일에 걸어둔 자원을 계속 점유하게 되고, 특히 쓰기 작업의 경우 버퍼에 남아 있던 내용이 실제 디스크에 반영되지 않을 수도 있습니다. 하지만 매번 `close()`를 잊지 않고 호출하는 것은 생각보다 번거롭고 실수하기도 쉽습니다. 이 문제를 깔끔하게 해결하는 방법은 잠시 뒤 `with`문에서 다루겠습니다.

### 파일 모드의 종류

`open()`의 두 번째 인자인 모드 문자열은 파일을 어떤 용도로 열 것인지를 결정합니다. 자주 쓰이는 모드는 다음과 같습니다.

| 모드 | 의미 | 파일이 없을 때 | 파일이 있을 때 |
|---|---|---|---|
| `"r"` | 읽기 (기본값) | `FileNotFoundError` 발생 | 내용을 처음부터 읽음 |
| `"w"` | 쓰기 | 새로 생성 | 기존 내용을 모두 지우고 새로 씀 |
| `"a"` | 추가(append) | 새로 생성 | 기존 내용 뒤에 이어서 씀 |
| `"x"` | 배타적 생성 | 새로 생성 | `FileExistsError` 발생 |

여기에 파일을 다루는 형식을 지정하는 문자를 뒤에 붙일 수 있습니다.

- `"t"`: 텍스트 모드(기본값). 문자열로 읽고 씁니다.
- `"b"`: 바이너리 모드. 이미지, 압축 파일처럼 텍스트가 아닌 데이터를 다룰 때 `bytes`로 읽고 씁니다.

예를 들어 `"rb"`는 "읽기 + 바이너리" 모드이고, `"wt"`는 "쓰기 + 텍스트" 모드인데, `"t"`는 기본값이라 생략하고 그냥 `"w"`라고만 써도 같은 뜻입니다. 이 책에서는 대부분 텍스트 파일만 다루므로 `"r"`, `"w"`, `"a"` 세 가지 모드가 주로 등장합니다.

`"w"` 모드는 기존 내용을 완전히 덮어쓴다는 점을 특히 주의해야 합니다. 로그 파일처럼 기존 기록을 유지한 채 내용을 이어붙이고 싶다면 `"a"` 모드를 사용해야 합니다.

```python
# "a" 모드는 파일 끝에 내용을 추가한다
log_file = open("activity.log", "a", encoding="utf-8")
log_file.write("사용자가 로그인했습니다.\n")
log_file.close()

# 같은 코드를 다시 실행해도 기존 줄은 지워지지 않고 새 줄이 추가된다
log_file = open("activity.log", "a", encoding="utf-8")
log_file.write("사용자가 파일을 업로드했습니다.\n")
log_file.close()
```

### 인코딩을 명시하는 습관

`encoding="utf-8"`을 항상 명시적으로 적는 습관을 들이는 것을 권장합니다. `encoding` 인자를 생략하면 운영체제의 기본 인코딩을 사용하는데, Windows에서는 이 기본값이 `cp949`나 `euc-kr` 같은 한글 환경 인코딩인 경우가 많습니다. 같은 코드를 macOS나 Linux에서 실행하면 기본 인코딩이 대부분 `utf-8`이기 때문에, 인코딩을 생략한 코드는 운영체제에 따라 한글이 깨지거나 오류가 나는 골치 아픈 문제를 일으킬 수 있습니다. `encoding="utf-8"`을 항상 명시하면 이런 환경 차이를 원천적으로 피할 수 있습니다.

## with문으로 안전하게 파일 다루기

### close()를 잊어버리면 생기는 문제

앞서 만든 예제처럼 `open()`과 `close()`를 한 쌍으로 사용하는 방식은 문제가 하나 있습니다. 두 호출 사이에서 예외가 발생하면 `close()`가 실행되지 못한 채 함수가 끝나버릴 수 있다는 점입니다.

```python
file = open("data.txt", "w", encoding="utf-8")
result = 10 / 0  # 여기서 예외가 발생하면
file.close()  # 이 줄은 실행되지 않는다
```

11장 예외 처리에서 배운 `try`, `finally`를 이용하면 이 문제를 해결할 수 있지만, 파일을 열 때마다 매번 `try`/`finally`를 작성하는 것은 번거롭습니다. Python은 이런 "열었으면 반드시 닫아야 하는" 자원을 다루기 위해 `with`문이라는 전용 문법을 제공합니다.

### with문 사용하기

```python
with open("greeting.txt", "w", encoding="utf-8") as file:
    file.write("안녕하세요, Python!\n")

# with 블록을 벗어나는 순간 file은 이미 자동으로 닫혀 있다
print(file.closed)
```

```
True
```

`with open(...) as file:` 구문은 파일을 열고, 그 결과를 `file`이라는 이름에 연결한 뒤, 들여쓰기된 블록이 끝나는 순간 파일을 자동으로 닫아줍니다. 블록 안에서 예외가 발생하더라도 파일은 확실하게 닫히기 때문에, `close()` 호출을 깜빡할 걱정이 없습니다.

```python
try:
    with open("data.txt", "w", encoding="utf-8") as file:
        file.write("일부 내용")
        raise ValueError("예상치 못한 오류")
except ValueError as error:
    print(f"오류 발생: {error}")
    # 이 시점에도 file은 이미 닫혀 있다
```

```
오류 발생: 예상치 못한 오류
```

이후로 이 책의 모든 파일 처리 예제는 `with`문을 기본으로 사용합니다. `open()`과 `close()`를 직접 짝지어 쓰는 방식은 되도록 피하고, 파일을 다룰 때는 항상 `with`문을 먼저 떠올리는 것이 좋은 습관입니다.

`with`문이 이렇게 "자동으로 뒷정리를 해주는" 동작을 어떻게 구현하는지 궁금할 수 있습니다. 그 원리는 "컨텍스트 매니저"라는 개념에 있으며, 파일 객체가 내부적으로 `__enter__`와 `__exit__`라는 특별한 메서드를 구현하고 있기 때문에 가능한 일입니다. 이 동작 원리와, 여러분이 직접 컨텍스트 매니저를 만드는 방법은 16장 데코레이터와 컨텍스트 매니저에서 자세히 다룹니다. 지금은 "`with`문을 쓰면 파일이 알아서 안전하게 닫힌다"는 사실만 기억해두면 충분합니다.

## 텍스트 파일 읽기

실습을 위해 먼저 여러 줄로 이루어진 텍스트 파일을 하나 만들어보겠습니다.

```python
with open("poem.txt", "w", encoding="utf-8") as file:
    file.write("봄이 오면\n")
    file.write("꽃이 피고\n")
    file.write("새가 운다\n")
```

### read(): 파일 전체를 하나의 문자열로

`read()`는 파일 전체 내용을 하나의 문자열로 읽어옵니다.

```python
>>> with open("poem.txt", "r", encoding="utf-8") as file:
...     content = file.read()
...
>>> content
'봄이 오면\n꽃이 피고\n새가 운다\n'
>>> print(content)
봄이 오면
꽃이 피고
새가 운다
```

`read()`는 파일 크기가 아주 크지 않을 때 편리합니다. 반면 수 기가바이트에 이르는 대용량 파일을 통째로 `read()`로 읽으면 메모리를 그만큼 많이 차지하게 되므로 주의해야 합니다.

### readline(): 한 줄씩 읽기

`readline()`은 호출할 때마다 파일에서 딱 한 줄씩만 읽어옵니다. 줄 끝의 개행 문자(`\n`)도 함께 포함되어 반환됩니다.

```python
>>> with open("poem.txt", "r", encoding="utf-8") as file:
...     first_line = file.readline()
...     second_line = file.readline()
...
>>> first_line
'봄이 오면\n'
>>> second_line
'꽃이 피고\n'
```

파일의 끝에 도달한 뒤 `readline()`을 다시 호출하면 빈 문자열 `""`을 반환합니다. 이를 이용해 while 반복문으로 파일을 끝까지 읽는 방식도 가능하지만, 아래에서 소개할 `for` 반복문 방식이 훨씬 간결합니다.

### readlines(): 모든 줄을 리스트로

`readlines()`는 파일의 모든 줄을 각각의 원소로 갖는 리스트를 반환합니다.

```python
>>> with open("poem.txt", "r", encoding="utf-8") as file:
...     lines = file.readlines()
...
>>> lines
['봄이 오면\n', '꽃이 피고\n', '새가 운다\n']
>>> len(lines)
3
```

각 줄 끝에 `\n`이 그대로 붙어 있는 점에 유의합니다. 실제로 줄 내용을 활용할 때는 6장 리스트와 튜플에서 배운 리스트 컴프리헨션과 5장 문자열 다루기에서 배운 `strip()` 메서드를 함께 사용해 개행 문자를 제거하는 경우가 많습니다.

```python
>>> cleaned_lines = [line.strip() for line in lines]
>>> cleaned_lines
['봄이 오면', '꽃이 피고', '새가 운다']
```

### 파일 객체를 직접 순회하기

파일 객체는 그 자체로 이터러블(iterable)입니다. 즉, `for` 반복문으로 파일 객체를 직접 순회하면 한 줄씩 읽어올 수 있습니다. 이 방식은 `readlines()`처럼 모든 줄을 한꺼번에 메모리에 올리지 않고 한 줄씩 순차적으로 처리하기 때문에, 큰 파일을 다룰 때 특히 효율적입니다.

```python
with open("poem.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
```

```
봄이 오면
꽃이 피고
새가 운다
```

파일의 내용을 한 줄씩 처리해야 하는 대부분의 상황에서는 이 방식을 가장 먼저 고려하는 것이 좋습니다.

## 텍스트 파일 쓰기

### write(): 문자열 하나 쓰기

`write()`는 문자열 하나를 파일에 씁니다. `print()`와 달리 개행 문자를 자동으로 추가해주지 않으므로, 줄을 바꾸고 싶다면 `\n`을 직접 넣어야 합니다.

```python
with open("numbers.txt", "w", encoding="utf-8") as file:
    file.write("하나\n")
    file.write("둘\n")
    file.write("셋")  # 마지막 줄은 개행 없이 마무리
```

`write()`는 실제로 파일에 쓴 문자 수를 반환합니다.

```python
>>> with open("count_test.txt", "w", encoding="utf-8") as file:
...     written = file.write("파이썬")
...
>>> written
3
```

### writelines(): 문자열의 리스트를 한 번에 쓰기

`writelines()`는 문자열로 이루어진 리스트(또는 다른 이터러블)를 받아서 각 원소를 순서대로 파일에 씁니다. 이름 때문에 오해하기 쉬운데, `writelines()`는 줄바꿈을 자동으로 넣어주지 않습니다. 각 문자열 끝에 `\n`을 직접 포함시켜야 줄이 구분됩니다.

```python
fruits = ["사과\n", "바나나\n", "체리\n"]

with open("fruits.txt", "w", encoding="utf-8") as file:
    file.writelines(fruits)
```

```python
>>> with open("fruits.txt", "r", encoding="utf-8") as file:
...     print(file.read())
...
사과
바나나
체리
```

### print()의 file 인자로 파일에 출력하기

지금까지 화면에 출력할 때만 사용해온 `print()` 함수는 사실 `file`이라는 키워드 인자를 가지고 있습니다. 이 인자에 파일 객체를 넘겨주면, 화면 대신 그 파일에 내용을 씁니다. `print()`는 `write()`와 달리 자동으로 줄바꿈을 추가해주기 때문에 편리한 경우가 많습니다.

```python
with open("report.txt", "w", encoding="utf-8") as file:
    print("=== 실행 결과 ===", file=file)
    print("성공:", 42, file=file)
    print("실패:", 3, file=file)
```

```python
>>> with open("report.txt", "r", encoding="utf-8") as file:
...     print(file.read())
...
=== 실행 결과 ===
성공: 42
실패: 3
```

간단한 로그나 보고서 형식의 파일을 만들 때는 `write()`를 여러 번 호출하며 `\n`을 신경 쓰는 것보다 `print(..., file=file)`을 사용하는 편이 코드를 더 읽기 쉽게 만들어주는 경우가 많습니다.

## json 모듈로 데이터 저장하고 불러오기

지금까지는 순수한 텍스트만 파일에 저장했습니다. 하지만 실제 프로그램에서는 딕셔너리나 리스트처럼 구조를 가진 데이터를 그대로 저장했다가 나중에 다시 불러오고 싶은 경우가 훨씬 많습니다. 7장 딕셔너리와 셋에서 배운 딕셔너리를 예로 들어보겠습니다.

```python
>>> user = {"name": "김민준", "age": 28, "is_active": True}
```

이 딕셔너리를 그냥 `str(user)`로 바꿔서 파일에 저장할 수도 있지만, 나중에 파일에서 읽어온 문자열을 다시 딕셔너리로 되돌리는 안전한 방법이 마땅치 않습니다. 이럴 때 사용하는 것이 JSON(JavaScript Object Notation)이라는 데이터 형식이고, Python은 이를 다루기 위한 `json` 모듈을 표준 라이브러리로 제공합니다. JSON은 프로그래밍 언어에 상관없이 널리 쓰이는 데이터 교환 형식이어서, 다른 언어로 작성된 프로그램과 데이터를 주고받을 때도 유용합니다.

### json.dump()로 파일에 저장하기

```python
import json

user = {"name": "김민준", "age": 28, "is_active": True}

with open("user.json", "w", encoding="utf-8") as file:
    json.dump(user, file, ensure_ascii=False, indent=2)
```

`json.dump(객체, 파일객체, ...)`는 첫 번째 인자로 받은 Python 객체를 JSON 형식으로 변환해서, 두 번째 인자로 받은 파일 객체에 직접 씁니다.

- `ensure_ascii=False`: 기본값(`True`)을 그대로 두면 한글 같은 아스키 문자가 아닌 글자를 `\uXXXX` 형태의 이스케이프 코드로 바꿔버립니다. `False`로 지정하면 한글이 그대로 저장되어 파일을 열어보기 훨씬 편합니다.
- `indent=2`: 들여쓰기 폭을 지정해서 사람이 읽기 좋은 형태로 저장합니다. 생략하면 한 줄로 압축된 형태로 저장됩니다.

생성된 `user.json` 파일을 열어보면 다음과 같은 내용이 담겨 있습니다.

```json
{
  "name": "김민준",
  "age": 28,
  "is_active": true
}
```

Python의 `True`가 JSON에서는 소문자 `true`로 바뀐 점에 주목합니다. JSON은 Python 고유의 문법이 아니라 별도의 데이터 형식이기 때문에, Python과 JSON 사이에는 다음과 같은 대응 관계가 있습니다.

| Python | JSON |
|---|---|
| `dict` | object (`{ }`) |
| `list`, `tuple` | array (`[ ]`) |
| `str` | string |
| `int`, `float` | number |
| `True` / `False` | `true` / `false` |
| `None` | `null` |

### json.load()로 파일에서 불러오기

저장해둔 JSON 파일은 `json.load()`로 다시 Python 객체로 되살릴 수 있습니다.

```python
>>> import json
>>> with open("user.json", "r", encoding="utf-8") as file:
...     loaded_user = json.load(file)
...
>>> loaded_user
{'name': '김민준', 'age': 28, 'is_active': True}
>>> type(loaded_user)
<class 'dict'>
```

파일에 저장했던 딕셔너리가 원래 모습 그대로 복원된 것을 확인할 수 있습니다. `json.dump()`와 `json.load()` 한 쌍이면 딕셔너리나 리스트, 그리고 그 안에 중첩된 구조까지 손쉽게 파일로 저장하고 불러올 수 있습니다.

```python
>>> settings = {
...     "theme": "dark",
...     "font_size": 14,
...     "recent_files": ["main.py", "utils.py"],
... }
>>> with open("settings.json", "w", encoding="utf-8") as file:
...     json.dump(settings, file, ensure_ascii=False, indent=2)
...
>>> with open("settings.json", "r", encoding="utf-8") as file:
...     restored = json.load(file)
...
>>> restored["recent_files"]
['main.py', 'utils.py']
```

### dumps()와 loads(): 파일이 아닌 문자열로 변환하기

`json` 모듈은 파일 대신 문자열을 다루는 함수도 함께 제공합니다. 이름 끝에 `s`가 붙은 `json.dumps()`와 `json.loads()`가 그것입니다.

```python
>>> import json
>>> data = {"language": "Python", "version": 3}
>>> json_text = json.dumps(data, ensure_ascii=False)
>>> json_text
'{"language": "Python", "version": 3}'
>>> type(json_text)
<class 'str'>
>>> json.loads(json_text)
{'language': 'Python', 'version': 3}
```

`dump`/`load`는 파일과 직접 주고받고, `dumps`/`loads`는 문자열과 주고받는다고 기억해두면 이름을 헷갈리지 않습니다. 네트워크로 데이터를 주고받거나 데이터베이스에 텍스트로 저장해야 하는 상황처럼, 파일이 아니라 문자열 형태의 JSON이 필요할 때 `dumps`와 `loads`를 사용합니다.

## csv 모듈 살펴보기

표 형태의 데이터, 즉 여러 행과 열로 이루어진 데이터를 텍스트로 저장할 때 널리 쓰이는 형식이 CSV(Comma-Separated Values)입니다. 각 줄이 하나의 행을 나타내고, 값들은 쉼표로 구분됩니다. 엑셀에서 "CSV로 저장하기"를 선택했을 때 만들어지는 파일이 바로 이 형식입니다. Python은 `csv` 모듈로 이 형식을 손쉽게 다룰 수 있게 해줍니다.

### csv.writer로 파일 쓰기

```python
import csv

rows = [
    ["이름", "점수"],
    ["김민준", 92],
    ["이서연", 88],
]

with open("scores.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)
    writer.writerows(rows)
```

`csv.writer(file)`은 파일 객체를 감싸서 CSV 전용 쓰기 객체를 만들어줍니다. `writerows()`는 여러 행을 한 번에 쓰고, 한 행씩 쓰고 싶다면 `writerow()`를 사용합니다. `open()`에 넘긴 `newline=""` 옵션은 운영체제에 따라 줄바꿈 문자가 중복으로 처리되는 것을 막기 위한 관례적인 설정으로, CSV 파일을 다룰 때는 항상 함께 적어주는 것이 좋습니다.

### csv.reader로 파일 읽기

```python
>>> import csv
>>> with open("scores.csv", "r", encoding="utf-8", newline="") as file:
...     reader = csv.reader(file)
...     for row in reader:
...         print(row)
...
['이름', '점수']
['김민준', '92']
['이서연', '88']
```

`csv.reader`가 반환하는 각 행은 문자열로 이루어진 리스트입니다. 숫자처럼 보이는 `'92'`도 문자열이라는 점에 유의해야 합니다. 실제 계산에 사용하려면 4장 연산자와 표현식에서 다룬 것처럼 `int()`나 `float()`로 직접 변환해주어야 합니다.

### csv.DictReader로 헤더를 키로 사용하기

첫 번째 줄이 열 제목(헤더)인 CSV 파일이라면, `csv.DictReader`를 사용해 각 행을 딕셔너리 형태로 읽어올 수 있어 훨씬 편리합니다.

```python
>>> import csv
>>> with open("scores.csv", "r", encoding="utf-8", newline="") as file:
...     reader = csv.DictReader(file)
...     for row in reader:
...         print(row)
...
{'이름': '김민준', '점수': '92'}
{'이름': '이서연', '점수': '88'}
```

첫 줄에 있던 `"이름"`, `"점수"`가 자동으로 각 딕셔너리의 키가 되었습니다. 데이터의 열이 많아질수록 인덱스 번호(`row[0]`, `row[1]`)보다 이름으로 값을 꺼내는(`row["이름"]`) 방식이 코드를 훨씬 이해하기 쉽게 만들어줍니다. CSV는 이 책에서 깊이 다루지는 않지만, 표 형태의 데이터를 다뤄야 할 때 `csv` 모듈이 존재한다는 사실만 기억해두어도 충분히 도움이 될 것입니다.

## 요약

- `open(경로, 모드, encoding=...)`으로 파일 객체를 얻으며, 모드에는 읽기(`"r"`), 쓰기(`"w"`), 추가(`"a"`) 등이 있습니다.
- Windows와 다른 운영체제 사이의 문제를 피하려면 `encoding="utf-8"`을 항상 명시하는 것이 좋습니다.
- `with open(...) as file:` 구문을 사용하면 블록이 끝날 때 파일이 자동으로 닫혀서, `close()`를 잊어버리는 실수를 방지할 수 있습니다. 이 동작 원리는 16장에서 다루는 컨텍스트 매니저에 기반합니다.
- 텍스트를 읽을 때는 `read()`(전체를 문자열로), `readline()`(한 줄씩), `readlines()`(모든 줄을 리스트로), `for line in file`(한 줄씩 순회) 중 상황에 맞는 방법을 선택합니다.
- 텍스트를 쓸 때는 `write()`, `writelines()`, 또는 `print(..., file=file)`을 사용할 수 있습니다.
- `json` 모듈의 `dump`/`load`는 파일과, `dumps`/`loads`는 문자열과 Python 객체를 서로 변환해줍니다. 딕셔너리나 리스트 같은 구조화된 데이터를 저장할 때 특히 유용합니다.
- `csv` 모듈은 표 형태의 데이터를 다루기 위한 `writer`, `reader`, `DictReader` 등을 제공합니다.
