지금까지 6장에서 살펴본 리스트와 튜플은 데이터를 순서대로 나열해서 관리하는 자료형이었습니다. 그런데 현실의 데이터는 순서보다 "이름"으로 찾는 경우가 훨씬 많습니다. 예를 들어 학생의 성적을 관리할 때 "3번째 값"보다는 "김철수의 점수"로 접근하는 편이 훨씬 자연스럽습니다. 이런 요구를 해결해 주는 자료형이 바로 **딕셔너리(dict)** 입니다.

또한 데이터 안에 중복이 있는지 확인하거나, 두 데이터 집합 사이의 공통점과 차이점을 찾아야 할 때는 **셋(set)** 이 훨씬 편리합니다. 이번 장에서는 이 두 가지 자료형을 자세히 다룹니다.

## 딕셔너리란 무엇인가

딕셔너리는 **키(key)** 와 **값(value)** 을 한 쌍으로 묶어서 저장하는 자료형입니다. 영어 사전에서 단어(키)를 찾으면 그 뜻(값)이 나오는 것과 비슷한 구조라서 "딕셔너리"라는 이름이 붙었습니다.

```python
>>> student = {"name": "김하늘", "age": 20, "major": "컴퓨터공학"}
>>> student
{'name': '김하늘', 'age': 20, 'major': '컴퓨터공학'}
>>> type(student)
<class 'dict'>
```

리스트가 `[]`(대괄호)를 쓰는 것과 달리 딕셔너리는 `{}`(중괄호)를 사용하며, 각 항목은 `키: 값` 형태로 작성하고 항목 사이는 쉼표로 구분합니다.

### 딕셔너리를 만드는 여러 방법

```python
>>> empty_dict = {}
>>> empty_dict
{}
>>> also_empty = dict()
>>> also_empty
{}

# 키워드 인자 형태로 만들기 (키가 문자열일 때만 가능)
>>> colors = dict(red="빨강", green="초록", blue="파랑")
>>> colors
{'red': '빨강', 'green': '초록', 'blue': '파랑'}

# (키, 값) 튜플의 리스트로부터 만들기
>>> pairs = [("a", 1), ("b", 2), ("c", 3)]
>>> dict(pairs)
{'a': 1, 'b': 2, 'c': 3}
```

파이썬 3.7 버전부터는 딕셔너리에 항목을 넣은 **순서가 그대로 유지**됩니다. 예전에는 딕셔너리의 순서를 신뢰할 수 없었지만, 요즘 파이썬에서는 입력한 순서대로 항목이 저장되고 순회됩니다.

### 딕셔너리 키의 조건

딕셔너리의 키에는 아무 값이나 올 수 없습니다. 키는 반드시 **불변(immutable)** 자료형이어야 합니다. 문자열, 정수, 실수, 튜플(단, 튜플 안에 가변 자료형이 없어야 함)은 키로 쓸 수 있지만, 리스트나 딕셔너리처럼 **가변(mutable)** 자료형은 키로 사용할 수 없습니다.

```python
>>> valid_dict = {("x", "y"): "좌표", 1: "일", 3.14: "원주율"}
>>> valid_dict
{('x', 'y'): '좌표', 1: '일', 3.14: '원주율'}

>>> invalid_dict = {[1, 2]: "리스트를 키로"}
Traceback (most recent call last):
  ...
TypeError: unhashable type: 'list'
```

리스트는 원소를 바꿀 수 있는 가변 자료형이기 때문에 "해시(hash)"라는 고유한 값을 계산할 수 없어서 키로 쓸 수 없습니다. 반면 값(value)에는 어떤 자료형이든 자유롭게 올 수 있으며, 리스트나 다른 딕셔너리를 값으로 넣는 것도 전혀 문제없습니다.

```python
>>> company = {
...     "이름": "파이썬상사",
...     "직원": ["철수", "영희", "민수"],
...     "주소": {"시": "서울", "구": "강남구"},
... }
>>> company["직원"]
['철수', '영희', '민수']
>>> company["주소"]["구"]
'강남구'
```

## 값에 접근하기

### 대괄호로 접근하기

딕셔너리에서 값을 꺼내려면 키를 대괄호 안에 적습니다.

```python
>>> student = {"name": "김하늘", "age": 20, "major": "컴퓨터공학"}
>>> student["name"]
'김하늘'
>>> student["age"]
20
```

존재하지 않는 키로 접근하면 `KeyError` 예외가 발생합니다. 예외 처리에 대해서는 11장(예외 처리)에서 자세히 다루지만, 지금은 이런 상황이 있다는 것만 기억해 둡시다.

```python
>>> student["phone"]
Traceback (most recent call last):
  ...
KeyError: 'phone'
```

### get() 메서드로 안전하게 접근하기

`KeyError` 걱정 없이 값을 꺼내고 싶다면 `get()` 메서드를 사용합니다. 키가 없을 때 예외를 일으키는 대신 `None`이나 지정한 기본값을 돌려줍니다.

```python
>>> student.get("name")
'김하늘'
>>> student.get("phone")
>>> print(student.get("phone"))
None
>>> student.get("phone", "등록되지 않음")
'등록되지 않음'
```

### 값 추가하기와 수정하기

딕셔너리에 새 키를 대입하면 항목이 추가되고, 이미 있는 키에 값을 대입하면 그 값이 수정됩니다.

```python
>>> student = {"name": "김하늘", "age": 20}
>>> student["major"] = "컴퓨터공학"   # 새 항목 추가
>>> student
{'name': '김하늘', 'age': 20, 'major': '컴퓨터공학'}
>>> student["age"] = 21               # 기존 값 수정
>>> student
{'name': '김하늘', 'age': 21, 'major': '컴퓨터공학'}
```

### 항목 삭제하기

`del` 문이나 `pop()` 메서드로 항목을 삭제할 수 있습니다. `pop()`은 삭제하면서 그 값을 반환한다는 점이 다릅니다.

```python
>>> student = {"name": "김하늘", "age": 21, "major": "컴퓨터공학"}
>>> del student["age"]
>>> student
{'name': '김하늘', 'major': '컴퓨터공학'}

>>> major = student.pop("major")
>>> major
'컴퓨터공학'
>>> student
{'name': '김하늘'}

# 없는 키를 pop할 때 기본값을 주면 안전하게 처리 가능
>>> student.pop("age", "정보 없음")
'정보 없음'
```

### 키 존재 여부 확인하기

`in` 연산자로 특정 키가 딕셔너리에 있는지 확인할 수 있습니다. 4장(연산자와 표현식)에서 배운 `in` 연산자가 딕셔너리에서는 기본적으로 **키**를 기준으로 동작합니다.

```python
>>> student = {"name": "김하늘", "age": 21}
>>> "name" in student
True
>>> "phone" in student
False
>>> "phone" not in student
True
```

## 딕셔너리의 주요 메서드

### keys(), values(), items()

딕셔너리 전체를 훑어보고 싶을 때 자주 쓰는 세 가지 메서드입니다.

```python
>>> scores = {"국어": 90, "영어": 85, "수학": 95}
>>> scores.keys()
dict_keys(['국어', '영어', '수학'])
>>> scores.values()
dict_values([90, 85, 95])
>>> scores.items()
dict_items([('국어', 90), ('영어', 85), ('수학', 95)])
```

`keys()`, `values()`, `items()`는 리스트가 아니라 각각 `dict_keys`, `dict_values`, `dict_items`라는 특수한 "뷰(view)" 객체를 반환합니다. 이 뷰 객체는 원본 딕셔너리와 실시간으로 연동되어 있어서, 딕셔너리가 바뀌면 뷰도 자동으로 바뀝니다.

```python
>>> keys_view = scores.keys()
>>> keys_view
dict_keys(['국어', '영어', '수학'])
>>> scores["과학"] = 88
>>> keys_view
dict_keys(['국어', '영어', '수학', '과학'])
```

리스트가 정말 필요하다면 `list()`로 감싸면 됩니다.

```python
>>> list(scores.keys())
['국어', '영어', '수학', '과학']
```

### update()로 여러 항목 한꺼번에 갱신하기

`update()`는 다른 딕셔너리(또는 키-값 쌍의 목록)를 받아서 기존 딕셔너리를 갱신합니다. 같은 키가 있으면 값을 덮어쓰고, 없으면 새로 추가합니다.

```python
>>> scores = {"국어": 90, "영어": 85}
>>> scores.update({"영어": 92, "수학": 95})
>>> scores
{'국어': 90, '영어': 92, '수학': 95}

# 키워드 인자로도 가능
>>> scores.update(과학=88)
>>> scores
{'국어': 90, '영어': 92, '수학': 95, '과학': 88}
```

파이썬 3.9 이상에서는 `|=` 연산자로도 같은 작업을 할 수 있고, `|` 연산자는 두 딕셔너리를 합친 새 딕셔너리를 만들어 줍니다.

```python
>>> defaults = {"color": "흰색", "size": "M"}
>>> options = {"size": "L"}
>>> merged = defaults | options
>>> merged
{'color': '흰색', 'size': 'L'}
```

### setdefault()로 키가 없을 때만 값 채우기

`setdefault()`는 키가 있으면 그 값을 반환하고, 없으면 지정한 기본값으로 새 항목을 만든 뒤 그 값을 반환합니다. 항목을 "여러 개 모아서" 관리할 때 특히 유용합니다.

```python
>>> word_groups = {}
>>> words = ["사과", "바나나", "수박", "바다", "사자"]
>>> for word in words:
...     first_char = word[0]
...     word_groups.setdefault(first_char, []).append(word)
...
>>> word_groups
{'사': ['사과', '사자'], '바': ['바나나', '바다'], '수': ['수박']}
```

### clear()와 copy()

```python
>>> scores = {"국어": 90, "영어": 85}
>>> backup = scores.copy()
>>> scores.clear()
>>> scores
{}
>>> backup
{'국어': 90, '영어': 85}
```

`copy()`는 얕은 복사(shallow copy)를 수행합니다. 즉, 딕셔너리 자체는 새로 만들어지지만 값으로 들어 있는 리스트나 딕셔너리 같은 가변 객체는 원본과 공유됩니다. 이 개념은 6장(리스트와 튜플)에서 리스트를 복사할 때도 등장했던 내용과 동일합니다.

## 딕셔너리 순회 패턴

딕셔너리를 `for` 문으로 순회하는 방법은 여러 가지가 있습니다. 각 방법이 언제 편리한지 함께 살펴보겠습니다.

### 키만 순회하기

`for` 문에 딕셔너리를 그대로 넣으면 기본적으로 키를 순회합니다.

```python
>>> prices = {"사과": 1500, "바나나": 800, "수박": 15000}
>>> for fruit in prices:
...     print(fruit)
...
사과
바나나
수박
```

이는 `for fruit in prices.keys():`와 동일하게 동작하지만, 관례적으로는 `.keys()`를 생략하는 경우가 더 많습니다.

### 값만 순회하기

```python
>>> for price in prices.values():
...     print(price)
...
1500
800
15000

>>> total = 0
>>> for price in prices.values():
...     total += price
...
>>> total
17300
```

### 키와 값을 함께 순회하기

가장 많이 쓰는 패턴입니다. `items()`가 반환하는 (키, 값) 튜플을 두 변수로 바로 풀어서 받습니다.

```python
>>> for fruit, price in prices.items():
...     print(f"{fruit}: {price}원")
...
사과: 1500원
바나나: 800원
수박: 15000원
```

### 실전 예제: 딕셔너리로 빈도수 세기

문자열에 등장한 각 문자의 개수를 세는 예제로 딕셔너리의 힘을 확인해 봅시다.

```python
>>> text = "banana"
>>> counter = {}
>>> for char in text:
...     if char in counter:
...         counter[char] += 1
...     else:
...         counter[char] = 1
...
>>> counter
{'b': 1, 'a': 3, 'n': 2}
```

위 코드는 `get()`을 사용하면 더 짧게 쓸 수 있습니다.

```python
>>> counter = {}
>>> for char in text:
...     counter[char] = counter.get(char, 0) + 1
...
>>> counter
{'b': 1, 'a': 3, 'n': 2}
```

참고로 표준 라이브러리의 `collections.Counter`를 쓰면 이런 빈도수 계산을 단 한 줄로 처리할 수 있습니다. 이 내용은 17장(표준 라이브러리와 패키지 관리)에서 다시 다룹니다.

### 딕셔너리 컴프리헨션 살짝 맛보기

리스트에 컴프리헨션이 있듯이 딕셔너리에도 비슷한 문법이 있습니다. 자세한 내용은 10장(컴프리헨션과 제너레이터)에서 배우지만, 여기서는 딕셔너리를 순회하며 새 딕셔너리를 만드는 감각만 잡아 둡시다.

```python
>>> prices = {"사과": 1500, "바나나": 800, "수박": 15000}
>>> discounted = {fruit: int(price * 0.9) for fruit, price in prices.items()}
>>> discounted
{'사과': 1350, '바나나': 720, '수박': 13500}
```

## 셋(set)이란 무엇인가

셋은 **중복을 허용하지 않고 순서가 없는** 자료형입니다. 수학 시간에 배운 "집합" 개념을 그대로 프로그래밍으로 옮겨왔다고 생각하면 됩니다.

```python
>>> fruits = {"사과", "바나나", "수박"}
>>> fruits
{'수박', '바나나', '사과'}
>>> type(fruits)
<class 'set'>
```

출력 결과의 순서가 입력한 순서와 다를 수 있다는 점에 주의하세요. 셋은 순서를 보장하지 않습니다.

### 셋 만들기

```python
>>> numbers = {1, 2, 3, 2, 1}
>>> numbers
{1, 2, 3}
```

중복된 값을 넣어도 자동으로 하나만 남습니다. 이 특성 덕분에 셋은 **중복 제거**에 매우 자주 쓰입니다.

```python
>>> names = ["철수", "영희", "철수", "민수", "영희"]
>>> unique_names = set(names)
>>> unique_names
{'영희', '철수', '민수'}
```

빈 셋을 만들 때는 주의할 점이 있습니다. `{}`는 빈 딕셔너리를 만들기 때문에, 빈 셋은 반드시 `set()`으로 만들어야 합니다.

```python
>>> empty = {}
>>> type(empty)
<class 'dict'>
>>> real_empty_set = set()
>>> type(real_empty_set)
<class 'set'>
```

셋도 딕셔너리의 키와 마찬가지로 **불변(immutable)** 객체만 원소로 담을 수 있습니다. 그래서 리스트는 셋의 원소가 될 수 없지만, 튜플은 가능합니다.

```python
>>> valid_set = {(1, 2), (3, 4)}
>>> invalid_set = {[1, 2], [3, 4]}
Traceback (most recent call last):
  ...
TypeError: unhashable type: 'list'
```

### 셋에 원소 추가하고 제거하기

```python
>>> fruits = {"사과", "바나나"}
>>> fruits.add("수박")
>>> fruits
{'수박', '바나나', '사과'}

>>> fruits.add("사과")   # 이미 있는 원소를 추가해도 변화 없음
>>> fruits
{'수박', '바나나', '사과'}

>>> fruits.remove("바나나")
>>> fruits
{'수박', '사과'}

>>> fruits.remove("포도")   # 없는 원소를 remove하면 예외 발생
Traceback (most recent call last):
  ...
KeyError: '포도'

>>> fruits.discard("포도")  # discard는 없어도 예외를 일으키지 않음
```

## 집합 연산

셋의 진짜 매력은 수학의 집합 연산을 코드로 그대로 표현할 수 있다는 점입니다. 두 반의 학생 명단으로 예를 들어보겠습니다.

```python
>>> class_a = {"철수", "영희", "민수", "지훈"}
>>> class_b = {"영희", "수진", "민수", "하늘"}
```

### 합집합 (union)

두 셋을 모두 합친 결과입니다. `|` 연산자나 `union()` 메서드를 사용합니다.

```python
>>> class_a | class_b
{'철수', '영희', '민수', '지훈', '수진', '하늘'}
>>> class_a.union(class_b)
{'철수', '영희', '민수', '지훈', '수진', '하늘'}
```

### 교집합 (intersection)

두 셋에 공통으로 들어 있는 원소만 남깁니다. `&` 연산자나 `intersection()` 메서드를 사용합니다.

```python
>>> class_a & class_b
{'영희', '민수'}
>>> class_a.intersection(class_b)
{'영희', '민수'}
```

두 반 모두에 속한, 즉 "양쪽 수업을 다 듣는 학생"을 찾을 때 유용합니다.

### 차집합 (difference)

한 셋에는 있지만 다른 셋에는 없는 원소만 남깁니다. `-` 연산자나 `difference()` 메서드를 사용합니다.

```python
>>> class_a - class_b
{'철수', '지훈'}
>>> class_b - class_a
{'수진', '하늘'}
```

`class_a - class_b`는 "A반에만 있고 B반에는 없는 학생", 즉 A반 전용 학생을 뜻합니다. 뺄셈처럼 방향에 따라 결과가 달라진다는 점을 기억하세요.

### 대칭차집합 (symmetric difference)

두 셋 중 어느 한쪽에만 속한 원소, 즉 공통 원소를 제외한 나머지를 모두 모읍니다. `^` 연산자나 `symmetric_difference()` 메서드를 사용합니다.

```python
>>> class_a ^ class_b
{'철수', '지훈', '수진', '하늘'}
```

"두 반 중 한쪽에만 속한 학생"을 뜻하며, `(class_a | class_b) - (class_a & class_b)`와 동일한 결과입니다.

### 부분집합과 상위집합 확인

```python
>>> small = {"철수", "영희"}
>>> class_a
{'철수', '영희', '민수', '지훈'}
>>> small.issubset(class_a)
True
>>> class_a.issuperset(small)
True
>>> small <= class_a
True
```

### 집합 연산 요약표

| 연산 | 연산자 | 메서드 | 의미 |
|------|--------|--------|------|
| 합집합 | `\|` | `union()` | 둘 중 하나라도 속한 원소 |
| 교집합 | `&` | `intersection()` | 둘 다 속한 원소 |
| 차집합 | `-` | `difference()` | 왼쪽에만 속한 원소 |
| 대칭차집합 | `^` | `symmetric_difference()` | 한쪽에만 속한 원소 |

## 실전 감각: 언제 리스트 대신 딕셔너리·셋을 쓸까

리스트, 딕셔너리, 셋은 서로 대체할 수 있는 경우가 많지만, 상황에 따라 성능 차이가 매우 크게 날 수 있습니다.

### 조회(검색) 성능의 차이

리스트에서 특정 값이 있는지 확인하려면 `in` 연산자가 처음부터 끝까지 하나씩 비교합니다. 원소가 100만 개인 리스트라면 최악의 경우 100만 번 비교해야 할 수도 있습니다. 반면 딕셔너리와 셋은 "해시(hash)"라는 방식을 이용해 데이터를 저장하기 때문에, 원소 개수와 거의 무관하게 거의 즉시 결과를 알 수 있습니다.

```python
>>> big_list = list(range(1_000_000))
>>> big_set = set(big_list)
>>> 999_999 in big_list   # 리스트: 끝까지 하나씩 비교할 수 있음 (느림)
True
>>> 999_999 in big_set    # 셋: 해시로 즉시 확인 (빠름)
True
```

두 코드 모두 결과는 `True`로 같지만, 데이터가 많아질수록 셋을 사용한 쪽이 압도적으로 빠릅니다. "이 값이 안에 들어 있는가?"를 자주 확인해야 하는 코드라면 리스트보다 셋이나 딕셔너리의 키를 활용하는 것이 좋습니다.

### 선택 기준 정리

- **순서가 중요하고 중복을 허용해야 한다** → 리스트 (6장 참고)
- **이름(키)으로 값을 찾아야 한다**, 예를 들어 "이름 → 전화번호" 같은 연결 관계를 표현해야 한다 → 딕셔너리
- **중복 제거가 필요하다**, 또는 **속해 있는지 여부만 빠르게 확인**하면 된다, 또는 **집합 연산(합집합·교집합 등)** 이 필요하다 → 셋
- **값은 바뀌지 않고 순서만 있으면 된다** → 튜플 (6장 참고)

예를 들어 웹사이트 방문자 100만 명 중에서 이미 방문한 적 있는 사용자인지 확인하는 기능을 리스트로 구현하면 사용자가 많아질수록 눈에 띄게 느려지지만, 셋으로 구현하면 사용자 수가 늘어나도 응답 속도가 거의 일정하게 유지됩니다. 이런 차이는 데이터 양이 적을 때는 티가 나지 않다가, 실제 서비스 규모로 커지면 프로그램의 성패를 가르는 중요한 요소가 됩니다.

## 요약

- 딕셔너리는 키-값 쌍을 저장하는 자료형으로, 키를 통해 값에 빠르게 접근할 수 있습니다. 키는 반드시 불변 자료형이어야 합니다.
- `get()`은 키가 없어도 예외 없이 기본값을 반환하고, `pop()`은 값을 꺼내면서 삭제하며, `setdefault()`는 키가 없을 때만 기본값을 채워 넣습니다.
- `keys()`, `values()`, `items()`는 딕셔너리를 순회하는 세 가지 기본 방법이며, 특히 `items()`로 키와 값을 동시에 받는 패턴이 가장 많이 쓰입니다.
- 셋은 중복을 허용하지 않고 순서가 없는 자료형으로, `set()`으로 만들며 빈 셋은 `{}`가 아니라 `set()`으로 만들어야 합니다.
- 셋은 합집합(`|`), 교집합(`&`), 차집합(`-`), 대칭차집합(`^`) 같은 집합 연산을 지원합니다.
- 딕셔너리와 셋은 내부적으로 해시를 이용하기 때문에 리스트보다 조회 속도가 훨씬 빠릅니다. 데이터 검색이나 중복 확인이 잦은 작업에는 리스트보다 딕셔너리·셋을 우선 고려하세요.
