지금까지 작성한 코드는 위에서 아래로 한 줄씩 순서대로 실행되는 것이 전부였습니다. 하지만 실제 프로그램은 "조건에 따라 다른 동작을 하거나", "같은 작업을 여러 번 반복"해야 하는 경우가 대부분입니다. 이번 장에서는 프로그램의 실행 흐름을 제어하는 핵심 도구인 **조건문**과 **반복문**을 배웁니다.

## if 조건문

### 기본 형태

`if` 문은 조건이 참(True)일 때만 특정 코드를 실행합니다. 조건은 4장(연산자와 표현식)에서 배운 비교 연산자나 논리 연산자로 만든 표현식입니다.

```python
>>> age = 20
>>> if age >= 18:
...     print("성인입니다.")
...
성인입니다.
```

파이썬은 중괄호 `{}`로 블록을 구분하는 다른 언어와 달리, **들여쓰기**로 코드 블록을 구분합니다. 이 책의 스타일 가이드에 맞춰 항상 4칸 들여쓰기를 사용합니다. 들여쓰기가 일관되지 않으면 `IndentationError`가 발생하므로 주의해야 합니다.

```python
>>> if age >= 18:
...    print("들여쓰기가 다르면")
...      print("오류가 발생합니다")
  File "<stdin>", line 3
    print("오류가 발생합니다")
    ^
IndentationError: unexpected indent
```

### if-else

조건이 거짓(False)일 때 실행할 코드를 `else` 절에 작성할 수 있습니다.

```python
>>> age = 15
>>> if age >= 18:
...     print("성인입니다.")
... else:
...     print("미성년자입니다.")
...
미성년자입니다.
```

### if-elif-else

조건이 여러 개일 때는 `elif`(else if의 줄임말)를 사용합니다. 조건은 위에서부터 순서대로 검사되며, 참인 첫 번째 블록만 실행되고 나머지는 검사조차 하지 않습니다.

```python
>>> score = 85
>>> if score >= 90:
...     grade = "A"
... elif score >= 80:
...     grade = "B"
... elif score >= 70:
...     grade = "C"
... else:
...     grade = "F"
...
>>> grade
'B'
```

`elif`는 필요한 만큼 여러 번 쓸 수 있고, `else`는 생략할 수도 있습니다. 다만 `else`는 항상 마지막에 하나만 올 수 있습니다.

### 조건식 안에서 자주 하는 실수

파이썬에서는 대입 연산자 `=`와 비교 연산자 `==`을 헷갈리면 안 됩니다.

```python
>>> x = 5
>>> if x = 5:        # 실수로 =을 사용
  File "<stdin>", line 1
    if x = 5:
         ^
SyntaxError: invalid syntax
```

다행히 파이썬은 `if` 문에서 `=`를 쓰면 바로 문법 오류를 내주기 때문에 이런 실수를 실행 전에 잡을 수 있습니다.

### 참으로 취급되는 값, 거짓으로 취급되는 값

`if` 문의 조건에는 꼭 `True`/`False`가 아니어도 다른 값을 넣을 수 있습니다. 파이썬은 다음 값들을 거짓(False)으로 취급합니다.

- `False`, `None`
- 숫자 `0`, `0.0`
- 빈 문자열 `""`, 빈 리스트 `[]`, 빈 튜플 `()`, 빈 딕셔너리 `{}`, 빈 셋 `set()`

그 외의 값은 모두 참(True)으로 취급됩니다.

```python
>>> name = ""
>>> if name:
...     print(f"안녕하세요, {name}님")
... else:
...     print("이름이 입력되지 않았습니다.")
...
이름이 입력되지 않았습니다.

>>> items = ["사과", "바나나"]
>>> if items:
...     print(f"{len(items)}개의 항목이 있습니다.")
...
2개의 항목이 있습니다.
```

이런 특성 덕분에 `if len(items) > 0:` 대신 `if items:`처럼 간결하게 쓰는 경우가 많습니다. 다만 가독성을 해치지 않는 선에서 사용하는 것이 좋습니다.

### 삼항 표현식 (조건부 표현식)

간단한 if-else를 한 줄로 줄여 쓰는 문법도 있습니다. `값1 if 조건 else 값2` 형태로 씁니다.

```python
>>> age = 20
>>> status = "성인" if age >= 18 else "미성년자"
>>> status
'성인'
```

이 표현식은 값을 계산해서 대입할 때 유용하지만, 조건이 복잡해지면 오히려 가독성이 떨어지므로 간단한 경우에만 사용하는 것이 좋습니다.

## while 반복문

`while` 문은 조건이 참인 동안 코드 블록을 계속 반복 실행합니다.

```python
>>> count = 1
>>> while count <= 5:
...     print(count)
...     count += 1
...
1
2
3
4
5
```

`while` 문을 쓸 때 가장 조심해야 할 것은 **조건이 언젠가는 거짓이 되도록 만드는 것**입니다. 위 예제에서 `count += 1`을 빼먹으면 `count`가 영원히 1에 머물러 조건이 항상 참이 되고, 프로그램이 멈추지 않는 **무한 루프**에 빠집니다.

```python
>>> count = 1
>>> while count <= 5:
...     print(count)
... # count를 증가시키는 코드를 깜빡하면 무한히 1만 출력됩니다.
```

무한 루프에 빠졌을 때는 터미널에서 `Ctrl+C`를 눌러 강제로 종료할 수 있습니다. 반대로 의도적으로 무한 루프를 만들고 내부에서 `break`로 빠져나오는 패턴도 자주 사용합니다(뒤에서 다룹니다).

### while의 실전 예제: 사용자 입력 검증

```python
>>> user_input = ""
>>> while user_input != "종료":
...     user_input = input("명령을 입력하세요 (종료하려면 '종료' 입력): ")
...     print(f"입력한 값: {user_input}")
...
```

이처럼 "언제 끝날지 미리 알 수 없고, 특정 조건이 만족될 때까지 반복해야 하는" 상황에는 `for`보다 `while`이 더 자연스럽습니다.

## for 반복문

`for` 문은 리스트, 튜플, 문자열, 딕셔너리처럼 **순회 가능한(iterable) 객체**의 원소를 하나씩 꺼내며 반복합니다. "반복 횟수를 미리 알고 있거나, 어떤 컬렉션의 모든 원소를 처리해야 할 때" 가장 자주 사용합니다.

```python
>>> fruits = ["사과", "바나나", "수박"]
>>> for fruit in fruits:
...     print(fruit)
...
사과
바나나
수박
```

문자열도 문자를 하나씩 순회할 수 있습니다. 문자열에 대한 자세한 내용은 5장(문자열 다루기)을 참고하세요.

```python
>>> for char in "파이썬":
...     print(char)
...
파
이
썬
```

### range()로 숫자 반복하기

정해진 횟수만큼 반복하고 싶을 때는 `range()` 함수를 자주 사용합니다. `range()`는 리스트가 아니라 필요할 때마다 숫자를 하나씩 만들어내는 특수한 객체이지만, `for` 문에서는 리스트처럼 사용할 수 있습니다.

```python
>>> for i in range(5):
...     print(i)
...
0
1
2
3
4
```

`range(5)`는 0부터 4까지, 즉 5개의 숫자를 만들어냅니다. `range(n)`은 항상 `n`을 포함하지 않는다는 점에 주의하세요.

`range()`는 시작값, 끝값, 증가값을 지정할 수도 있습니다.

```python
>>> for i in range(2, 7):        # 2부터 6까지
...     print(i)
...
2
3
4
5
6

>>> for i in range(0, 10, 2):    # 0부터 9까지, 2씩 증가
...     print(i)
...
0
2
4
6
8

>>> for i in range(10, 0, -2):   # 10부터 1까지, 2씩 감소
...     print(i)
...
10
8
6
4
2
```

### 딕셔너리와 셋 순회하기

`for` 문으로 딕셔너리와 셋도 순회할 수 있습니다. 딕셔너리 순회의 다양한 패턴(`keys()`, `values()`, `items()`)은 7장(딕셔너리와 셋)에서 이미 자세히 다뤘으므로, 여기서는 간단히 복습만 합니다.

```python
>>> scores = {"국어": 90, "영어": 85}
>>> for subject, score in scores.items():
...     print(f"{subject}: {score}점")
...
국어: 90점
영어: 85점

>>> unique_numbers = {1, 2, 3}
>>> for number in unique_numbers:
...     print(number)
...
1
2
3
```

### enumerate()로 인덱스와 값을 함께 얻기

리스트를 순회하면서 인덱스가 필요한 경우가 많습니다. 이때 `range(len(...))`을 쓰는 대신 `enumerate()`를 사용하면 훨씬 간결하고 파이썬다운(pythonic) 코드가 됩니다.

```python
>>> fruits = ["사과", "바나나", "수박"]

# 권장하지 않는 방식
>>> for i in range(len(fruits)):
...     print(i, fruits[i])
...
0 사과
1 바나나
2 수박

# 권장하는 방식
>>> for i, fruit in enumerate(fruits):
...     print(i, fruit)
...
0 사과
1 바나나
2 수박
```

`enumerate()`에 시작 번호를 지정할 수도 있습니다.

```python
>>> for i, fruit in enumerate(fruits, start=1):
...     print(f"{i}번째: {fruit}")
...
1번째: 사과
2번째: 바나나
3번째: 수박
```

### zip()으로 여러 시퀀스를 함께 순회하기

두 개 이상의 리스트를 나란히 짝지어 순회하고 싶을 때는 `zip()`을 사용합니다.

```python
>>> names = ["철수", "영희", "민수"]
>>> scores = [85, 92, 78]
>>> for name, score in zip(names, scores):
...     print(f"{name}: {score}점")
...
철수: 85점
영희: 92점
민수: 78점
```

`zip()`은 가장 짧은 시퀀스를 기준으로 멈춘다는 점도 기억해 두면 좋습니다.

## break와 continue

### break: 반복문 즉시 종료

`break`는 반복문을 즉시 멈추고 빠져나갑니다. 특정 조건을 만족하는 순간 더 이상 반복할 필요가 없을 때 사용합니다.

```python
>>> numbers = [3, 7, 2, 9, 4, 11, 6]
>>> for number in numbers:
...     if number > 8:
...         print(f"{number}을(를) 찾았습니다. 반복을 멈춥니다.")
...         break
...     print(f"{number} 확인 중...")
...
3 확인 중...
7 확인 중...
2 확인 중...
9을(를) 찾았습니다. 반복을 멈춥니다.
```

9를 만난 순간 `break`가 실행되어 이후의 11, 6은 검사하지 않고 반복문을 즉시 종료합니다.

### continue: 이번 반복만 건너뛰기

`continue`는 반복문을 끝내지 않고, 현재 반복만 건너뛴 뒤 다음 반복으로 넘어갑니다.

```python
>>> for number in range(1, 11):
...     if number % 2 != 0:    # 홀수는 건너뛰기
...         continue
...     print(number)
...
2
4
6
8
10
```

### break와 continue를 while 문에서 사용하기

```python
>>> count = 0
>>> while True:               # 의도적인 무한 루프
...     count += 1
...     if count == 3:
...         continue
...     if count > 5:
...         break
...     print(count)
...
1
2
4
5
```

이처럼 `while True:`로 무한 루프를 만들고 내부에서 `break`로 종료 조건을 판단하는 패턴은 "반복을 몇 번 할지 미리 알 수 없지만, 특정 상황이 되면 멈춰야 하는" 경우에 매우 자주 사용됩니다.

## 반복문의 else 절 (파이썬 고유의 특징)

파이썬의 `for`와 `while` 문에는 다른 언어에서는 찾아보기 힘든 독특한 문법이 있습니다. 바로 반복문에도 `else` 절을 붙일 수 있다는 점입니다.

**반복문의 `else` 절은 반복이 `break` 없이 정상적으로 끝까지 끝났을 때만 실행됩니다.** 반대로 반복 중간에 `break`로 빠져나오면 `else` 절은 실행되지 않습니다.

이 문법은 "리스트 전체를 검사했지만 원하는 것을 찾지 못했을 때"와 같은 상황을 표현하는 데 유용합니다. 소수(prime number)를 찾는 예제로 살펴보겠습니다.

```python
>>> number = 17
>>> for i in range(2, number):
...     if number % i == 0:
...         print(f"{number}은(는) {i}로 나누어 떨어지므로 소수가 아닙니다.")
...         break
... else:
...     print(f"{number}은(는) 소수입니다.")
...
17은(는) 소수입니다.
```

```python
>>> number = 15
>>> for i in range(2, number):
...     if number % i == 0:
...         print(f"{number}은(는) {i}로 나누어 떨어지므로 소수가 아닙니다.")
...         break
... else:
...     print(f"{number}은(는) 소수입니다.")
...
15은(는) 3로 나누어 떨어지므로 소수가 아닙니다.
```

17은 2부터 16까지 어떤 수로도 나누어 떨어지지 않아서 `break`가 한 번도 실행되지 않았고, 그 결과 `for`의 `else` 절이 실행되어 "소수입니다"가 출력되었습니다. 반면 15는 3으로 나누어 떨어져서 `break`가 실행되었고, 그 결과 `else` 절은 건너뛰었습니다.

이 문법이 익숙하지 않다면 "`else`는 `if`가 아니라 `break`와 짝을 이룬다"고 기억하면 이해하기 쉽습니다. 즉 "break가 한 번도 발생하지 않고 반복이 끝나면 else를 실행하라"는 뜻입니다.

`while` 문에도 똑같은 방식으로 `else` 절을 쓸 수 있습니다.

```python
>>> target = 5
>>> numbers = [2, 8, 1, 9, 3]
>>> index = 0
>>> while index < len(numbers):
...     if numbers[index] == target:
...         print(f"{target}을(를) {index}번 인덱스에서 찾았습니다.")
...         break
...     index += 1
... else:
...     print(f"{target}을(를) 찾지 못했습니다.")
...
5을(를) 찾지 못했습니다.
```

실무에서는 반복문의 `else` 절 대신, 찾았는지 여부를 나타내는 변수(플래그)를 따로 두거나 함수의 `return`을 활용하는 방식도 많이 쓰입니다. `return`을 이용한 방식은 9장(함수)에서 자세히 배웁니다. 다만 반복문의 `else` 절은 파이썬의 고유한 특징이므로, 다른 사람이 작성한 코드를 읽을 때 당황하지 않도록 반드시 알아 두어야 합니다.

## 중첩 반복문

반복문 안에 또 다른 반복문을 넣는 것을 **중첩 반복문**이라고 합니다. 표(table) 형태의 데이터를 다루거나, 두 리스트의 모든 조합을 살펴봐야 할 때 자주 사용합니다.

### 구구단 출력하기

```python
>>> for dan in range(2, 4):
...     print(f"--- {dan}단 ---")
...     for i in range(1, 10):
...         print(f"{dan} x {i} = {dan * i}")
...
--- 2단 ---
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
2 x 4 = 8
2 x 5 = 10
2 x 6 = 12
2 x 7 = 14
2 x 8 = 16
2 x 9 = 18
--- 3단 ---
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
3 x 6 = 18
3 x 7 = 21
3 x 8 = 24
3 x 9 = 27
```

바깥쪽 `for` 문이 한 번 반복될 때마다 안쪽 `for` 문이 처음부터 끝까지 전부 실행됩니다. 그래서 위 코드는 바깥쪽 2번, 안쪽 각각 9번, 총 18번의 곱셈을 수행합니다.

### 별 찍기 패턴

중첩 반복문을 연습할 때 자주 등장하는 예제입니다.

```python
>>> for row in range(1, 6):
...     print("*" * row)
...
*
**
***
****
*****
```

```python
>>> for row in range(1, 6):
...     for col in range(row):
...         print("*", end="")
...     print()
...
*
**
***
****
*****
```

두 번째 코드는 `print()`의 `end` 매개변수를 이용해 줄바꿈 없이 별을 이어 붙이고, 안쪽 반복이 끝난 뒤 `print()`를 한 번 더 호출해 줄을 바꾸는 방식입니다. `print()` 함수의 다양한 옵션은 5장(문자열 다루기)에서도 다룬 바 있습니다.

### 중첩 반복문에서 break의 범위

중요한 점 하나는, `break`는 **자신을 감싸고 있는 가장 안쪽 반복문만** 종료시킨다는 것입니다. 바깥쪽 반복문까지 한 번에 종료시키지는 않습니다.

```python
>>> for i in range(1, 4):
...     for j in range(1, 4):
...         if j == 2:
...             break
...         print(f"i={i}, j={j}")
...
i=1, j=1
i=2, j=1
i=3, j=1
```

`j == 2`가 될 때마다 안쪽 `for` 문만 멈추고, 바깥쪽 `for` 문은 계속 다음 `i` 값으로 진행합니다. 만약 바깥쪽 반복문까지 한꺼번에 멈추고 싶다면, 반복문을 함수로 감싸서 `return`으로 빠져나오거나(9장 함수 참고), 별도의 플래그 변수를 두어 바깥쪽에서도 조건을 검사하는 방식을 사용해야 합니다.

```python
>>> found = False
>>> for i in range(1, 4):
...     for j in range(1, 4):
...         if i == 2 and j == 2:
...             found = True
...             break
...     if found:
...         break
...
>>> print(f"멈춘 지점: i={i}, j={j}")
멈춘 지점: i=2, j=2
```

### 실전 예제: 두 리스트의 모든 조합 만들기

```python
>>> colors = ["빨강", "파랑"]
>>> sizes = ["S", "M", "L"]
>>> for color in colors:
...     for size in sizes:
...         print(f"{color} {size}")
...
빨강 S
빨강 M
빨강 L
파랑 S
파랑 M
파랑 L
```

이런 "모든 조합"을 만드는 작업은 컴프리헨션 문법으로 더 간결하게 표현할 수도 있는데, 이는 10장(컴프리헨션과 제너레이터)에서 자세히 다룹니다.

## pass 문

가끔은 문법상 코드 블록이 필요하지만 아직 내용을 작성하지 않았거나, 의도적으로 아무 동작도 하지 않게 하고 싶을 때가 있습니다. 이럴 때 `pass` 문을 사용합니다.

```python
>>> for i in range(5):
...     if i == 3:
...         pass    # 나중에 여기에 처리할 코드를 작성할 예정
...     else:
...         print(i)
...
0
1
2
4
```

`pass`는 "아무것도 하지 않는다"는 뜻의 자리표시자(placeholder)로, 코드의 뼈대를 먼저 잡아둘 때 유용합니다. 클래스나 함수를 아직 구현하지 않았을 때도 자주 등장하며, 이 내용은 9장(함수)과 12장(클래스와 객체지향 기초)에서 다시 만나게 됩니다.

## 요약

- `if`/`elif`/`else`로 조건에 따라 다른 코드를 실행할 수 있으며, 파이썬은 들여쓰기로 코드 블록을 구분합니다.
- 빈 문자열, 빈 컬렉션, `0`, `None`, `False`는 조건문에서 거짓으로 취급되고, 그 외의 값은 대체로 참으로 취급됩니다.
- `while` 문은 조건이 참인 동안 반복하며, 종료 조건을 반드시 챙겨야 무한 루프를 피할 수 있습니다.
- `for` 문은 리스트, 문자열, 딕셔너리, `range()` 등 순회 가능한 객체를 하나씩 처리하며, `enumerate()`와 `zip()`으로 더 편리하게 순회할 수 있습니다.
- `break`는 반복문을 즉시 종료하고, `continue`는 현재 반복만 건너뛰고 다음으로 넘어갑니다.
- 반복문의 `else` 절은 파이썬 고유의 문법으로, `break` 없이 반복이 정상 종료되었을 때만 실행됩니다.
- 중첩 반복문에서 `break`는 가장 안쪽 반복문만 종료시킨다는 점에 유의해야 합니다.
