## 들어가며

이 책을 펼친 여러분은 아마도 두 부류 중 하나일 것입니다. 프로그래밍이라는 것을 태어나서 처음 시작하는 사람이거나, 이미 C나 Java, JavaScript 같은 언어를 다뤄본 적이 있어서 "이번엔 Python을 배워볼까" 하고 마음먹은 사람입니다. 이 책은 두 부류의 독자를 모두 염두에 두고 쓰였습니다. 프로그래밍이 처음이라면 컴퓨터에게 일을 시키는 방법 자체를 차근차근 익히게 될 것이고, 다른 언어 경험이 있다면 그 지식을 Python이라는 새로운 도구에 빠르게 옮겨 담게 될 것입니다.

1장에서는 코드를 한 줄도 쓰지 않습니다. 대신 Python이 어떤 언어이고, 왜 이렇게 널리 쓰이는지, 그리고 이 책을 어떻게 읽어나가면 좋을지를 먼저 이야기합니다. 목적지를 알아야 길을 잃지 않는 법입니다.

## Python의 정체성

Python은 1991년 네덜란드의 프로그래머 귀도 반 로섬(Guido van Rossum)이 처음 발표한 프로그래밍 언어입니다. 이후 30년이 넘는 시간 동안 꾸준히 발전해서, 지금은 전 세계에서 가장 많이 사용되는 언어 중 하나로 자리 잡았습니다. Python이라는 이름은 파충류 뱀과는 관계가 없고, 반 로섬이 좋아했던 영국의 코미디 그룹 "몬티 파이썬(Monty Python)"에서 따온 것으로 알려져 있습니다. Python 관련 문서나 튜토리얼에 종종 뱀 로고나 유머러스한 예제가 등장하는 것도 이런 배경과 무관하지 않습니다.

Python을 한마디로 정의하자면 "인터프리터 방식으로 실행되는, 동적 타이핑을 사용하는 범용 프로그래밍 언어"라고 할 수 있습니다. 이 문장에 담긴 세 가지 특징을 하나씩 풀어보겠습니다.

### 인터프리터 언어라는 것

C나 Java 같은 언어로 작성한 코드는 실행되기 전에 먼저 컴파일이라는 과정을 거칩니다. 컴파일러가 사람이 작성한 소스 코드를 컴퓨터가 직접 실행할 수 있는 기계어(또는 중간 형태의 바이트코드)로 통째로 번역해두고, 그 결과물을 실행하는 방식입니다.

Python은 이와 달리 인터프리터라는 프로그램이 소스 코드를 한 줄씩 읽어가며 즉시 해석하고 실행합니다. 코드를 작성하고 바로 실행 결과를 확인할 수 있다는 뜻입니다. 이 방식 덕분에 Python은 실험적으로 코드를 짜보거나, 작은 스크립트를 빠르게 작성하는 데 아주 유리합니다. 다만 한 줄씩 해석하는 과정이 추가로 필요하다 보니, 미리 컴파일해둔 프로그램에 비해 실행 속도가 느린 경우가 많다는 점도 함께 알아두는 것이 좋습니다. 이 부분은 2장 첫 프로그램과 실행 방법에서 실제로 코드를 실행해보면서 다시 살펴보겠습니다.

### 동적 타이핑이라는 것

C나 Java에서는 변수를 사용하기 전에 그 변수가 정수인지, 문자열인지, 실수인지를 먼저 선언해야 합니다. 이런 방식을 정적 타이핑이라고 부릅니다.

```python
# Python에서는 변수의 타입을 미리 선언하지 않는다
number = 10
number = "이제는 문자열"
number = [1, 2, 3]
```

Python에서는 위 코드처럼 같은 변수에 정수를 담았다가, 문자열을 담았다가, 다시 리스트를 담아도 아무런 문제가 없습니다. 변수는 그저 값이 어디에 있는지를 가리키는 이름표일 뿐이고, 타입은 변수가 아니라 실제 값이 가지고 있는 성질이기 때문입니다. 이를 동적 타이핑이라고 부릅니다. 이 개념은 3장 변수와 자료형에서 훨씬 자세히 다루게 됩니다.

동적 타이핑은 코드를 짧고 유연하게 만들어주지만, 동시에 실행하기 전까지는 타입 관련 오류를 발견하기 어렵다는 단점도 있습니다. 장점과 단점이 동전의 양면처럼 붙어 있는 것이죠.

### 간결한 문법

다음은 "1부터 5까지의 숫자를 출력하라"는 동일한 작업을 Java와 Python으로 각각 작성한 것입니다.

```java
// Java로 작성한 경우 (참고용, 실행하지 않습니다)
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

```python
# 같은 작업을 Python으로 작성한 경우
for i in range(1, 6):
    print(i)
```

세미콜론도 없고, 중괄호도 없고, 변수의 타입을 선언하지도 않습니다. Python은 처음 설계될 때부터 "사람이 읽기 쉬운 코드"를 최우선 가치로 삼았습니다. 코드는 한 번 작성되고 나면 그보다 훨씬 더 여러 번 읽히기 마련이므로, 읽기 쉬운 코드가 결국 유지보수하기 쉬운 코드라는 철학이 Python 전체에 깔려 있습니다.

이러한 철학은 Python 커뮤니티에서 "Python의 선(禪)"이라는 애칭으로 불리는 20개의 짧은 원칙들로 정리되어 전해져 내려옵니다. 이 원칙들을 직접 인용하지는 않겠지만, 핵심만 요약하면 다음과 같습니다.

- 명확하고 단순한 코드가 복잡하고 영리한 코드보다 낫다.
- 하나의 문제를 해결하는 방법은 가급적 하나의 명확한 방식으로 존재하는 것이 좋다.
- 가독성은 코드의 품질을 가늠하는 매우 중요한 기준이다.

실제로 Python 인터프리터를 실행한 뒤 `import this`라는 코드를 입력하면 이 원칙들의 원문을 직접 확인할 수 있습니다. 여러분이 Python에 익숙해질수록 이 문장들이 왜 이렇게 쓰였는지 점점 공감하게 될 것입니다.

## 범용 언어로서의 Python

Python은 특정 분야에 국한되지 않는 범용 프로그래밍 언어입니다. "범용"이라는 말은 이론적인 수사가 아니라, 실제로 다양한 분야에서 Python이 주력 도구로 쓰이고 있다는 사실을 가리킵니다.

- **웹 개발**: Django, Flask 같은 웹 프레임워크를 이용해 웹사이트와 API 서버를 구축합니다.
- **데이터 분석과 과학 계산**: pandas, NumPy 같은 라이브러리로 대량의 데이터를 분석하고, Matplotlib 등으로 시각화합니다.
- **인공지능과 머신러닝**: PyTorch, TensorFlow 등 대부분의 주요 딥러닝 프레임워크가 Python을 기본 인터페이스로 제공합니다.
- **자동화와 스크립팅**: 반복적인 파일 정리, 엑셀 작업, 웹 크롤링 등 일상적인 업무 자동화에 널리 쓰입니다.
- **교육**: 문법이 간결해서 프로그래밍을 처음 배우는 사람들에게 첫 언어로 자주 추천됩니다.

한 가지 언어로 이렇게 폭넓은 영역을 다룰 수 있다는 것은 큰 강점입니다. 웹 개발을 배우다가 데이터 분석 쪽으로 관심이 옮겨가도, 새로운 언어를 처음부터 배울 필요 없이 익숙한 문법 위에서 새로운 라이브러리만 익히면 되기 때문입니다.

물론 만능은 아닙니다. 인터프리터 방식으로 동작하는 특성상 매우 낮은 수준의 하드웨어 제어나 극도로 빠른 연산 속도가 요구되는 영역(예: 운영체제 커널, 게임 엔진의 핵심 연산부, 임베디드 펌웨어)에서는 C, C++, Rust 같은 언어가 여전히 더 적합합니다. Python은 종종 이런 언어로 작성된 고성능 라이브러리를 "얇게 감싸서" 편리하게 사용하는 역할을 맡습니다. NumPy나 PyTorch가 내부적으로 C/C++로 작성된 연산 엔진을 Python 인터페이스로 감싸고 있는 것이 대표적인 예입니다.

## 다른 언어와 비교했을 때의 위치

프로그래밍 언어를 처음 접한다면 아래 표가 크게 와닿지 않을 수 있지만, 다른 언어를 다뤄본 독자라면 Python의 위치를 가늠하는 데 도움이 될 것입니다.

| 항목 | C | Java | Python |
|---|---|---|---|
| 실행 방식 | 컴파일 후 기계어 실행 | 컴파일 후 가상 머신에서 실행 | 인터프리터가 직접 해석·실행 |
| 타이핑 | 정적 타이핑 | 정적 타이핑 | 동적 타이핑 |
| 변수 선언 | 타입 명시 필요 | 타입 명시 필요 | 타입 명시 불필요 |
| 실행 속도 | 매우 빠름 | 빠름 | 상대적으로 느림 |
| 코드 작성 속도 | 상대적으로 느림 | 보통 | 빠름 |
| 주요 강점 | 하드웨어 근접 제어, 성능 | 대규모 시스템, 플랫폼 독립성 | 개발 생산성, 학습 곡선 |

이 표에서 중요한 것은 어떤 언어가 절대적으로 우월하다는 결론이 아닙니다. 언어마다 설계 목표가 다르고, 그 목표에 맞는 트레이드오프를 선택했다는 점입니다. Python은 "실행 속도"보다 "개발자가 코드를 작성하고 이해하는 속도"에 더 큰 비중을 둔 언어입니다. 사람의 시간이 컴퓨터의 시간보다 비싼 경우가 많은 오늘날의 소프트웨어 개발 환경에서, 이 선택은 Python을 대단히 실용적인 언어로 만들어 주었습니다.

## 개발 환경 준비하기

이제 Python을 실제로 사용하기 위한 준비물을 알아보겠습니다.

### Python 인터프리터 설치

Python 코드를 실행하려면 컴퓨터에 Python 인터프리터가 설치되어 있어야 합니다. 인터프리터란 앞서 설명했듯이 소스 코드를 읽어서 실제로 실행해주는 프로그램입니다. 공식 홈페이지(python.org)에서 운영체제에 맞는 설치 파일을 내려받아 설치할 수 있습니다.

Windows 사용자라면 설치 과정에서 "Add Python to PATH"라는 체크박스를 반드시 선택해야 합니다. 이 옵션을 체크해야 명령 프롬프트나 PowerShell 어디서든 `python`이라는 명령어로 인터프리터를 실행할 수 있습니다. macOS나 Linux는 대부분 Python이 기본으로 설치되어 있거나, 패키지 관리자(Homebrew, apt 등)를 통해 손쉽게 설치할 수 있습니다.

설치가 끝났다면 터미널(또는 명령 프롬프트)에서 다음 명령으로 설치를 확인합니다.

```
$ python --version
Python 3.12.4
```

이 책은 Python 3 계열을 기준으로 작성되었습니다. Python은 한때 2 계열과 3 계열이 공존하던 시기가 있었지만, 2020년 이후로 2 계열의 공식 지원이 종료되었으므로 지금 새로 배운다면 무조건 3 계열을 사용하면 됩니다.

### 인터프리터를 사용하는 두 가지 방식

Python 인터프리터는 크게 두 가지 방식으로 사용할 수 있습니다.

1. **스크립트 실행**: `.py` 확장자를 가진 파일에 코드를 작성해두고, `python 파일명.py` 명령으로 한 번에 실행하는 방식입니다.
2. **대화형 모드(REPL)**: 터미널에 `python`만 입력하면 `>>>`라는 프롬프트가 나타나고, 한 줄씩 코드를 입력하면서 즉시 결과를 확인할 수 있는 방식입니다. REPL은 "Read-Eval-Print Loop"의 줄임말로, 입력을 읽고(Read), 평가하고(Eval), 결과를 출력하고(Print), 이 과정을 반복한다(Loop)는 뜻입니다.

두 방식의 구체적인 사용법과 차이는 2장 첫 프로그램과 실행 방법에서 실습을 통해 자세히 다룹니다.

### 에디터와 IDE 선택

코드를 작성할 도구도 필요합니다. 몇 가지 선택지를 소개합니다.

- **VS Code**: 가볍고 확장 기능이 풍부한 무료 에디터로, Python 확장을 설치하면 자동 완성, 오류 표시, 디버깅 기능을 모두 사용할 수 있습니다. 처음 시작하는 독자에게 가장 무난하게 추천되는 선택지입니다.
- **PyCharm**: JetBrains에서 만든 Python 전용 IDE(통합 개발 환경)로, 대규모 프로젝트에 유용한 기능이 많습니다. 무료인 Community 버전으로도 학습에는 충분합니다.
- **IDLE**: Python을 설치하면 함께 따라오는 아주 단순한 편집기입니다. 별도 설치 없이 바로 사용할 수 있어 첫 실습용으로 나쁘지 않습니다.
- **Jupyter Notebook**: 코드와 실행 결과, 설명 텍스트를 하나의 문서에 섞어서 작성할 수 있는 도구로, 데이터 분석 분야에서 특히 많이 쓰입니다.

어떤 도구를 쓰든 이 책의 예제 코드를 따라 하는 데는 문제가 없습니다. 처음에는 도구 선택에 너무 많은 시간을 쓰지 말고, 익숙한 것 하나를 골라 바로 시작하는 것을 권합니다.

- 12장부터 16장까지는 클래스와 객체지향, 모듈, 파일 입출력, 데코레이터 등 조금 더 큰 프로그램을 구성하는 방법을 다룹니다.
- 17장과 18장은 표준 라이브러리 활용과 좋은 코드 작성 습관을 다루며 책을 마무리합니다.

각 장에는 반드시 실행 가능한 예제 코드와 실습 문제가 포함되어 있습니다. 코드는 눈으로만 읽지 말고 직접 입력해서 실행해보길 권합니다. 특히 대화형 인터프리터(REPL)를 옆에 띄워두고, 책에서 소개하는 코드를 한 줄씩 따라 입력해보는 습관을 들이면 학습 속도가 훨씬 빨라집니다. 프로그래밍은 읽어서 이해하는 지식이 아니라, 손으로 익히는 기술에 가깝기 때문입니다.

그럼 이제 본격적으로 첫 번째 Python 프로그램을 작성하러 가보겠습니다.

## 요약

- Python은 귀도 반 로섬이 1991년에 발표한 프로그래밍 언어이며, 현재 가장 널리 쓰이는 언어 중 하나입니다.
- Python은 소스 코드를 한 줄씩 해석해 실행하는 인터프리터 언어이며, 변수의 타입을 미리 선언하지 않는 동적 타이핑 언어입니다.
- Python은 실행 속도보다 코드의 가독성과 개발 생산성을 중요하게 여기는 설계 철학을 가지고 있습니다.
- Python은 웹 개발, 데이터 분석, 인공지능, 자동화 등 매우 다양한 분야에서 범용적으로 사용됩니다.
- C, Java 같은 정적 타이핑 컴파일 언어와 비교하면 실행 속도는 느리지만 개발 속도가 빠르다는 트레이드오프를 가지고 있습니다.
- Python 코드를 실행하려면 인터프리터를 설치해야 하며, 스크립트 실행과 대화형 모드(REPL)라는 두 가지 실행 방식을 제공합니다.
- 에디터는 VS Code, PyCharm, IDLE, Jupyter Notebook 등 다양한 선택지가 있으며, 처음에는 익숙한 도구 하나로 시작하면 충분합니다.
