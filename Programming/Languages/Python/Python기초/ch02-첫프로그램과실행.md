## 들어가며

1장에서는 Python이 어떤 언어인지, 그리고 어떻게 설치하는지를 살펴보았습니다. 이번 장에서는 드디어 직접 코드를 작성하고 실행해봅니다. 프로그래밍 언어를 처음 배울 때 가장 먼저 작성하는 프로그램은 관례적으로 화면에 "Hello, World!"라는 문구를 출력하는 프로그램입니다. 이 짧은 프로그램을 통해 코드를 작성하는 방법, 실행하는 방법, 그리고 Python 특유의 문법적 특징인 들여쓰기까지 한 번에 살펴보겠습니다.

## 첫 번째 프로그램: Hello, World!

에디터를 열고 다음 코드를 입력해 `hello.py`라는 이름으로 저장합니다. 파일 이름의 확장자 `.py`는 이 파일이 Python 소스 코드임을 나타냅니다.

```python
# hello.py
print("Hello, World!")
```

이 프로그램은 딱 한 줄로 이루어져 있습니다. 이 한 줄이 하는 일을 뜯어보겠습니다.

- `print`는 Python이 기본으로 제공하는 함수입니다. 함수는 특정한 일을 수행하도록 미리 정의된 코드 묶음이며, 함수에 대한 자세한 내용은 9장 함수에서 다룹니다. `print` 함수의 역할은 괄호 안에 전달된 내용을 화면(정확히는 표준 출력)에 출력하는 것입니다.
- `("Hello, World!")`는 `print` 함수에 전달하는 인자입니다. 큰따옴표로 감싸인 `"Hello, World!"`는 문자열이라는 자료형이며, 문자 그대로의 데이터를 표현합니다. 문자열은 5장 문자열 다루기에서 본격적으로 다룹니다.
- 문장 끝에 세미콜론(`;`)이 없습니다. Java나 C, JavaScript에 익숙한 독자라면 어색하게 느껴질 수 있지만, Python에서는 한 줄이 끝나면 그것이 곧 하나의 문장(statement)의 끝을 의미합니다. 세미콜론을 아예 쓸 수 없는 것은 아니지만, 관례적으로 사용하지 않습니다.

이제 이 코드를 실행해 보겠습니다.

## 방법 1: 스크립트 파일로 실행하기

터미널(Windows라면 명령 프롬프트나 PowerShell)을 열고, `hello.py` 파일이 저장된 폴더로 이동한 뒤 다음 명령을 입력합니다.

```
$ python hello.py
Hello, World!
```

`python`이라는 명령 뒤에 실행하고 싶은 파일 이름을 적어주면, Python 인터프리터가 그 파일을 처음부터 끝까지 읽으면서 실행합니다. 화면에 `Hello, World!`가 출력되었다면 성공입니다.

> 참고: 운영체제나 설치 방식에 따라 `python` 대신 `python3`이라는 명령을 사용해야 하는 경우도 있습니다. `python --version` 명령으로 먼저 확인해보고, 동작하지 않으면 `python3 --version`을 시도해 보세요.

이렇게 `.py` 파일을 저장해두고 명령으로 실행하는 방식을 **스크립트 실행**이라고 부릅니다. 실제로 여러 줄로 이루어진 프로그램을 작성하고, 나중에 다시 실행하거나 다른 사람과 공유하려면 이 방식을 사용하게 됩니다.

## 방법 2: 대화형 인터프리터(REPL) 사용하기

이번에는 파일을 만들지 않고, 터미널에 `python`만 입력해 보겠습니다.

```
$ python
Python 3.12.4 (main, Jun  7 2024, 12:00:00)
Type "help", "copyright", "credits" or "license" for more information.
>>>
```

`>>>`라는 프롬프트가 나타났다면 대화형 인터프리터, 즉 REPL(Read-Eval-Print Loop)에 진입한 것입니다. 이 상태에서는 코드를 한 줄 입력할 때마다 Python이 그 줄을 즉시 해석하고, 실행하고, 결과가 있다면 바로 화면에 보여줍니다.

```python
>>> print("Hello, World!")
Hello, World!
>>> 1 + 2
3
>>> name = "파이썬"
>>> name
'파이썬'
```

몇 가지 주목할 점이 있습니다.

- `print("Hello, World!")`를 입력하니 스크립트 실행과 동일하게 문구가 출력되었습니다.
- `1 + 2`처럼 `print`를 쓰지 않고 값만 입력해도 REPL은 그 결과를 자동으로 보여줍니다. 이것은 REPL만의 편의 기능이며, `.py` 파일을 스크립트로 실행할 때는 이렇게 자동으로 값이 출력되지 않습니다.
- `name = "파이썬"`처럼 변수에 값을 대입하는 문장은 결과값이 없으므로 아무것도 출력되지 않습니다. 그다음 줄에서 `name`만 입력하니 저장된 값이 출력됩니다.

REPL을 종료하려면 `exit()`를 입력하거나, `Ctrl + Z`를 누른 뒤 Enter(Windows), 또는 `Ctrl + D`(macOS, Linux)를 누르면 됩니다.

### 두 실행 방식의 비교

| 구분 | 스크립트 실행 | 대화형 인터프리터(REPL) |
|---|---|---|
| 실행 명령 | `python 파일명.py` | `python` |
| 코드 저장 여부 | 파일에 저장됨, 재사용 가능 | 저장되지 않음, 종료 시 사라짐 |
| 용도 | 완성된 프로그램, 공유용 프로그램 작성 | 간단한 실험, 문법 확인, 디버깅 |
| 결과 출력 | `print` 등으로 명시해야 출력됨 | 값만 입력해도 자동으로 출력됨 |

이 책의 예제 대부분은 스크립트 파일로 작성하는 것을 기본으로 하지만, 짧은 개념을 확인할 때는 `>>>` 프롬프트로 시작하는 REPL 예시도 함께 보여드립니다. 여러분도 책을 읽다가 궁금한 표현이 나오면 REPL을 열어서 바로 확인해보는 습관을 들이길 권합니다.

아래 그림은 지금까지 설명한 실행 흐름을 정리한 것입니다. 소스 코드가 인터프리터에 의해 한 줄씩 해석되어 실행되고, 그 결과가 화면에 나타나는 과정을 보여줍니다.

```text
                       Python 소스 코드 실행 흐름

  +----------------------+        +---------------------------------+        +----------------------+
  |      소스 코드        |        |        Python 인터프리터          |        |       실행 결과        |
  |      hello.py         |        |                                   |        |      터미널 화면        |
  |----------------------|        |  +-----------------------------+  |        |----------------------|
  | name = "파이썬"       | -----> |  | (1) 문법 분석 (해석)          |  |        | 안녕, 파이썬           |
  | print(                |  한줄씩 |  +-----------------------------+  | 결과   |                      |
  |   f"안녕, {name}")    |  읽음  |               |                   | 전달  |                      |
  +----------------------+        |               v                   | ---->  +----------------------+
                                   |  +-----------------------------+  |
                                   |  | (2) 한 줄 즉시 실행           |  |
                                   |  +-----------------------------+  |
                                   |               |                   |
                                   |     (다음 줄로 이동해 반복,        |
                                   |      화살표가 다시 (1)로 순환)     |
                                   +---------------------------------+
                                                  |
                                                  | (문법 오류 발생 시, 점선)
                                                  v
                          문법 오류가 있으면 그 줄에서 즉시 멈추고
                          에러 메시지를 출력합니다 (Traceback)

  컴파일 언어처럼 전체를 먼저 번역하지 않고,
  인터프리터가 코드를 한 줄씩 해석하며 그 자리에서 바로 실행합니다.
```

## Python은 한 줄씩 해석하며 실행된다

위 그림에서 보듯이, Python 인터프리터는 소스 코드 전체를 미리 기계어로 번역해두지 않습니다. 대신 코드를 위에서 아래로 순서대로 읽어 내려가면서, 한 줄(정확히는 하나의 문장)을 해석하고 그 자리에서 바로 실행한 다음, 다음 줄로 넘어갑니다.

이 특징을 직접 확인해 보겠습니다. 다음과 같은 파일을 작성해봅니다.

```python
# order.py
print("첫 번째 줄")
print("두 번째 줄")
print(1 / 0)  # 0으로 나누는 오류가 있는 줄
print("이 줄은 실행되지 않는다")
```

이 파일을 실행하면 어떤 일이 벌어질까요?

```
$ python order.py
첫 번째 줄
두 번째 줄
Traceback (most recent call last):
  File "order.py", line 4, in <module>
    print(1 / 0)
          ~~^~~
ZeroDivisionError: division by zero
```

첫 번째 줄과 두 번째 줄은 정상적으로 출력되었지만, 세 번째 줄에서 0으로 나누는 오류가 발생하자 인터프리터는 그 즉시 실행을 멈추고 오류 메시지(Traceback)를 출력했습니다. 그리고 그 아래에 있던 `print("이 줄은 실행되지 않는다")`는 아예 실행되지 못했습니다.

만약 Python이 전체 코드를 미리 컴파일하는 언어였다면, 이런 종류의 오류(실행 중에야 발생하는 오류)는 컴파일 시점이 아니라 마찬가지로 실행 중에 발견되었겠지만, 문법 자체가 잘못된 경우라면 이야기가 다릅니다. 문법 오류는 인터프리터가 각 줄을 실행하기 직전에 검사하기 때문에, 프로그램을 실행하자마자 곧바로 드러납니다. 예외 상황을 프로그램 안에서 직접 처리하는 방법은 11장 예외 처리에서 자세히 배우게 됩니다.

## 들여쓰기는 장식이 아니라 문법이다

Python을 처음 접하는 사람들이 가장 낯설어하는 부분 중 하나가 바로 들여쓰기(indentation)입니다. C나 Java에서는 중괄호(`{}`)로 코드 블록의 범위를 표시하고, 들여쓰기는 그저 사람이 보기 편하라고 넣는 장식에 불과합니다. 즉 들여쓰기를 하지 않아도 프로그램은 똑같이 동작합니다.

Python은 다릅니다. 들여쓰기 자체가 코드 블록을 구분하는 문법 요소입니다. 조건문, 반복문, 함수 정의 등 하나의 덩어리로 묶여야 하는 코드는 반드시 같은 수준으로 들여쓰기 되어야 합니다. 다음 예제를 보겠습니다.

```python
# 조건에 따라 다른 문구를 출력하는 예제
age = 20

if age >= 18:
    print("성인입니다.")
    print("투표를 할 수 있습니다.")
else:
    print("미성년자입니다.")

print("프로그램을 종료합니다.")
```

```
$ python age_check.py
성인입니다.
투표를 할 수 있습니다.
프로그램을 종료합니다.
```

`if age >= 18:` 아래에 있는 두 줄은 4칸 들여쓰기가 되어 있습니다. 이 두 줄은 `age >= 18`이라는 조건이 참일 때만 실행되는 하나의 블록입니다. 반면 마지막의 `print("프로그램을 종료합니다.")`는 들여쓰기가 없으므로 조건과 상관없이 항상 실행됩니다. 조건문에 대한 자세한 내용은 8장 제어문에서 다룹니다.

이 책에서는 공백 4칸을 들여쓰기의 기본 단위로 사용합니다. 이는 Python 커뮤니티에서 널리 통용되는 PEP 8이라는 스타일 가이드가 권장하는 방식이기도 합니다. 탭(Tab)과 공백을 섞어서 사용하면 오류가 발생할 수 있으므로, 에디터의 설정에서 Tab 키를 누르면 공백 4칸이 입력되도록 맞춰두는 것이 좋습니다. 대부분의 Python 전용 에디터는 기본값으로 이렇게 설정되어 있습니다.

들여쓰기 수준이 어긋나면 어떤 일이 벌어지는지도 직접 확인해보겠습니다.

```python
# 잘못된 들여쓰기 예제 (일부러 오류를 낸 코드)
if age >= 18:
    print("성인입니다.")
      print("투표를 할 수 있습니다.")
```

```
  File "bad_indent.py", line 4
    print("투표를 할 수 있습니다.")
    ^
IndentationError: unexpected indent
```

두 번째 `print` 문이 첫 번째 `print` 문보다 더 깊이 들여쓰기 되어 있어서 `IndentationError`가 발생했습니다. 같은 블록에 속한 코드는 반드시 들여쓰기 수준이 동일해야 한다는 점을 꼭 기억해두기 바랍니다.

## 흔한 초보자 실수와 대처법

Python을 처음 배울 때 자주 마주치는 실수들을 미리 정리해두면, 실제로 오류를 만났을 때 훨씬 침착하게 대응할 수 있습니다.

### 1. 들여쓰기가 일관되지 않음

```python
def greet():
    print("안녕하세요")
   print("반갑습니다")  # 앞줄보다 한 칸 덜 들여쓰기됨
```

같은 블록 안의 코드는 들여쓰기 폭이 정확히 일치해야 합니다. 에디터에서 공백이 보이지 않아 눈으로는 같아 보여도 실제로는 다를 수 있으므로, 에디터의 "공백 표시" 기능을 켜두거나 Tab과 Space를 섞어 쓰지 않는 것이 좋습니다.

### 2. 대소문자를 구분하지 못함

```python
>>> Name = "파이썬"
>>> print(name)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'name' is not defined
```

Python은 대문자와 소문자를 서로 다른 문자로 취급합니다. `Name`과 `name`은 완전히 다른 변수입니다. 변수나 함수의 이름을 지을 때 이 책의 스타일 가이드대로 소문자와 밑줄로 이루어진 `snake_case`(예: `user_name`)를 일관되게 사용하면 이런 실수를 크게 줄일 수 있습니다.

### 3. 괄호나 따옴표를 짝지어 닫지 않음

```python
>>> print("안녕하세요)
  File "<stdin>", line 1
    print("안녕하세요)
          ^
SyntaxError: unterminated string literal
```

문자열을 여는 따옴표와 닫는 따옴표의 짝이 맞지 않으면 `SyntaxError`가 발생합니다. 괄호나 따옴표는 열었으면 반드시 닫아야 한다는 점을 기억해두고, 오류 메시지에 표시된 줄 번호 주변을 먼저 확인하는 습관을 들이면 좋습니다.

### 4. print를 함수처럼 괄호와 함께 쓰지 않음

오래된 Python 2 관련 자료를 참고하다 보면 `print "Hello"`처럼 괄호 없이 쓰는 코드를 보게 될 수 있습니다. 이는 Python 2의 문법이며, Python 3에서는 `print`가 함수이므로 반드시 `print("Hello")`처럼 괄호를 함께 사용해야 합니다.

```
>>> print "Hello"
  File "<stdin>", line 1
    print "Hello"
    ^^^^^^^^^^^^^
SyntaxError: Missing parentheses in call to 'print'. Did you mean print(...)?
```

다행히 Python 3의 인터프리터는 이런 흔한 실수에 대해 친절하게도 "괄호를 빼먹은 것 같다"는 힌트까지 함께 보여줍니다. 오류 메시지를 두려워하지 말고 꼼꼼히 읽는 습관을 들이는 것이 실력 향상의 지름길입니다.

### 오류 메시지를 읽는 요령

Python이 출력하는 오류 메시지(Traceback)는 처음엔 복잡해 보이지만, 사실 세 가지 정보만 확인하면 됩니다.

1. 오류가 발생한 파일과 줄 번호 (`File "order.py", line 4`)
2. 오류가 발생한 코드의 실제 내용
3. 마지막 줄에 나오는 오류의 종류와 메시지 (`ZeroDivisionError: division by zero`)

Traceback을 위에서부터 읽으려 하지 말고, 항상 **맨 아래 줄**부터 읽는 습관을 들이길 권합니다. 맨 아래 줄에 어떤 종류의 오류인지와 그 이유가 요약되어 있고, 그 위로 올라가면서 오류가 어느 파일, 어느 줄에서 시작되었는지를 추적할 수 있습니다.

## 정리하며

이번 장에서는 `print` 함수 하나로 이루어진 짧은 프로그램을 통해 Python 코드를 실행하는 두 가지 방법(스크립트 실행과 REPL)을 비교해보았고, Python이 코드를 한 줄씩 해석하며 실행한다는 점, 그리고 들여쓰기가 단순한 스타일이 아니라 문법의 일부라는 점을 확인했습니다. 다음 장인 3장 변수와 자료형에서는 오늘 잠깐 등장했던 변수와 문자열을 비롯해, Python이 다루는 다양한 자료형을 본격적으로 살펴보겠습니다.

## 요약

- `print()` 함수는 괄호 안에 전달된 값을 화면에 출력하는, Python이 기본으로 제공하는 함수입니다.
- `.py` 파일에 코드를 작성하고 `python 파일명.py` 명령으로 실행하는 방식을 스크립트 실행이라고 합니다.
- 터미널에 `python`만 입력하면 나타나는 `>>>` 프롬프트를 대화형 인터프리터(REPL)라고 하며, 한 줄씩 입력하는 즉시 결과를 확인할 수 있습니다.
- Python 인터프리터는 소스 코드를 위에서 아래로 한 줄씩 해석하며 즉시 실행하고, 오류가 발생한 줄에서 실행을 멈추고 Traceback을 출력합니다.
- Python에서는 들여쓰기가 코드 블록을 구분하는 문법 요소이며, 같은 블록에 속한 코드는 반드시 동일한 폭으로 들여쓰기 되어야 합니다. 이 책에서는 공백 4칸을 기본 단위로 사용합니다.
- Python은 대소문자를 구분하므로 `Name`과 `name`은 서로 다른 변수로 취급됩니다.
- 오류 메시지(Traceback)는 맨 아래 줄부터 읽으면 오류의 종류와 원인을 가장 빠르게 파악할 수 있습니다.
