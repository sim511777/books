지금까지는 숫자나 문자열처럼 값 하나를 담는 자료형을 다루었습니다. 하지만 실제 프로그램에서는 여러 개의 값을 하나로 묶어서 다루어야 하는 경우가 훨씬 많습니다. 장바구니에 담긴 상품 목록, 학생들의 성적, 게시판의 글 목록 등이 모두 그런 예입니다. 이번 장에서는 여러 값을 순서대로 모아 담는 가장 기본적인 자료구조인 리스트(list)와 튜플(tuple)을 배웁니다.

## 6.1 리스트란 무엇인가

리스트는 여러 개의 값을 순서대로 담을 수 있는 자료형입니다. 대괄호(`[]`) 안에 값을 쉼표로 구분해서 나열하면 리스트를 만들 수 있습니다.

```python
>>> fruits = ["사과", "바나나", "포도"]
>>> numbers = [10, 20, 30, 40, 50]
>>> empty_list = []
>>> type(fruits)
<class 'list'>
```

리스트는 5장에서 다룬 문자열과 마찬가지로 시퀀스(sequence) 자료형이므로, 문자열에서 배운 인덱싱과 슬라이싱을 거의 그대로 사용할 수 있습니다. 다만 리스트는 서로 다른 자료형의 값을 섞어서 담을 수 있다는 점이 문자열과 다릅니다.

```python
>>> mixed = ["Ada", 28, True, 3.14]
>>> print(mixed)
['Ada', 28, True, 3.14]
```

리스트 안에 리스트를 넣어 중첩된 구조를 만들 수도 있습니다. 이런 구조는 표나 격자 형태의 데이터를 표현할 때 자주 쓰입니다.

```python
>>> matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
>>> matrix[0]
[1, 2, 3]
>>> matrix[0][1]
2
```

## 6.2 인덱싱과 슬라이싱

리스트의 인덱싱과 슬라이싱 규칙은 5장 문자열 다루기에서 배운 것과 동일합니다. 인덱스는 0부터 시작하며, 음수 인덱스는 끝에서부터 위치를 셉니다.

```python
>>> numbers = [10, 20, 30, 40, 50]
>>> numbers[0]
10
>>> numbers[2]
30
>>> numbers[-1]
50
>>> numbers[-2]
40
```

슬라이싱도 `리스트[시작:끝:간격]` 형태로 동일하게 사용합니다.

```python
>>> numbers = [10, 20, 30, 40, 50]
>>> numbers[1:3]
[20, 30]
>>> numbers[:3]
[10, 20, 30]
>>> numbers[2:]
[30, 40, 50]
>>> numbers[::2]
[10, 30, 50]
>>> numbers[::-1]
[50, 40, 30, 20, 10]
```

다음 그림은 리스트의 양수/음수 인덱스와 슬라이싱 범위가 어떻게 대응하는지를 보여줍니다.

```text
 numbers = [10, 20, 30, 40, 50]

 boundary:    0     1     2     3     4     5
              |     |     |     |     |     |
 value:       | 10  | 20  | 30  | 40  | 50  |
              |     |     |     |     |     |
 index(+):       0     1     2     3     4
 index(-):      -5    -4    -3    -2    -1

 numbers[1:3]  -> boundary 1 ~ boundary 3 -> [20, 30]
 numbers[:3]   -> boundary 0 ~ boundary 3 -> [10, 20, 30]
 numbers[2:]   -> boundary 2 ~ boundary 5 -> [30, 40, 50]
```

그림에서 볼 수 있듯이 슬라이싱의 경계는 원소와 원소 "사이"를 가리킨다고 생각하면 이해하기 쉽습니다. `numbers[1:3]`은 인덱스 1이 가리키는 경계부터 인덱스 3이 가리키는 경계까지, 즉 `20`과 `30` 두 원소를 포함합니다.

### 리스트는 가변(mutable)이다

문자열과 결정적으로 다른 점은 리스트가 가변(mutable) 자료형이라는 것입니다. 즉 리스트를 만든 뒤에도 특정 인덱스의 값을 직접 바꿀 수 있습니다.

```python
>>> numbers = [10, 20, 30, 40, 50]
>>> numbers[0] = 100
>>> print(numbers)
[100, 20, 30, 40, 50]
```

슬라이스에 값을 대입해서 여러 원소를 한꺼번에 바꾸는 것도 가능합니다.

```python
>>> numbers = [10, 20, 30, 40, 50]
>>> numbers[1:3] = [200, 300]
>>> print(numbers)
[10, 200, 300, 40, 50]
```

## 6.3 리스트의 주요 메서드

리스트는 원소를 추가하고, 제거하고, 정렬하는 다양한 메서드를 제공합니다. 하나씩 살펴보겠습니다.

### 원소 추가하기: append, insert, extend

`append()`는 리스트의 맨 끝에 값을 하나 추가합니다.

```python
>>> fruits = ["사과", "바나나"]
>>> fruits.append("포도")
>>> print(fruits)
['사과', '바나나', '포도']
```

`insert(index, value)`는 원하는 위치에 값을 끼워 넣습니다. 지정한 인덱스 자리에 새 값이 들어가고, 기존 값들은 뒤로 밀려납니다.

```python
>>> fruits = ["사과", "바나나", "포도"]
>>> fruits.insert(1, "딸기")
>>> print(fruits)
['사과', '딸기', '바나나', '포도']
```

리스트 여러 개를 하나로 합칠 때는 `extend()`를 사용합니다. `append()`와 헷갈리기 쉬운데, `append()`는 인자로 받은 값 자체를 원소 하나로 추가하는 반면, `extend()`는 인자로 받은 반복 가능한 객체의 원소들을 하나씩 풀어서 추가합니다.

```python
>>> a = [1, 2, 3]
>>> b = [4, 5]
>>> a.append(b)
>>> print(a)
[1, 2, 3, [4, 5]]
>>> a = [1, 2, 3]
>>> a.extend(b)
>>> print(a)
[1, 2, 3, 4, 5]
```

`a.append(b)`는 리스트 `b` 자체를 하나의 원소로 그대로 넣기 때문에 결과에 리스트 안에 리스트가 들어간 형태가 되지만, `a.extend(b)`는 `b`의 원소인 `4`와 `5`를 각각 풀어서 추가합니다. `a + b`처럼 `+` 연산자로 두 리스트를 이어 붙이는 것도 `extend()`와 비슷한 효과를 내지만, `+`는 새로운 리스트를 만들어 반환하고 `extend()`는 원본 리스트 자체를 바꾼다는 차이가 있습니다.

### 원소 제거하기: remove, pop, clear, del

`remove(value)`는 지정한 값과 일치하는 첫 번째 원소를 찾아 제거합니다.

```python
>>> fruits = ["사과", "바나나", "포도", "바나나"]
>>> fruits.remove("바나나")
>>> print(fruits)
['사과', '포도', '바나나']
```

같은 값이 여러 번 등장하더라도 `remove()`는 가장 먼저 발견되는 하나만 제거합니다. 만약 리스트에 없는 값을 `remove()`로 지우려고 하면 `ValueError`가 발생합니다.

`pop()`은 지정한 인덱스의 원소를 리스트에서 제거하면서 동시에 그 값을 반환합니다. 인덱스를 생략하면 마지막 원소를 꺼냅니다.

```python
>>> fruits = ["사과", "바나나", "포도"]
>>> last = fruits.pop()
>>> print(last, fruits)
포도 ['사과', '바나나']
>>> first = fruits.pop(0)
>>> print(first, fruits)
사과 ['바나나']
```

`pop()`은 값을 반환하기 때문에, 스택(stack)처럼 마지막에 넣은 것을 꺼내 쓰는 자료구조를 흉내 낼 때 유용하게 쓰입니다. 리스트 전체를 비우려면 `clear()`를 사용합니다.

```python
>>> fruits = ["사과", "바나나", "포도"]
>>> fruits.clear()
>>> print(fruits)
[]
```

특정 인덱스나 슬라이스를 삭제하는 데는 `del` 문을 사용할 수도 있습니다. `del`은 메서드가 아니라 Python의 문법 요소입니다.

```python
>>> numbers = [10, 20, 30, 40, 50]
>>> del numbers[0]
>>> print(numbers)
[20, 30, 40, 50]
>>> del numbers[1:3]
>>> print(numbers)
[20, 50]
```

### 검색과 개수: index, count, in

문자열과 마찬가지로 리스트에도 특정 값을 찾는 메서드가 있습니다.

```python
>>> fruits = ["사과", "바나나", "포도", "바나나"]
>>> fruits.index("포도")
2
>>> fruits.count("바나나")
2
>>> "사과" in fruits
True
>>> "수박" in fruits
False
```

`index()`는 값이 리스트에 없으면 `ValueError`를 발생시키므로, 존재 여부만 확인하고 싶다면 `in` 연산자를 먼저 쓰는 것이 안전합니다.

### 정렬과 순서 뒤집기: sort, sorted, reverse

리스트를 정렬할 때는 `sort()` 메서드와 내장 함수 `sorted()` 두 가지를 사용할 수 있는데, 이 둘의 차이를 명확히 이해하는 것이 중요합니다.

```python
>>> numbers = [3, 1, 4, 1, 5, 9, 2, 6]
>>> numbers.sort()
>>> print(numbers)
[1, 1, 2, 3, 4, 5, 6, 9]
```

`sort()`는 리스트 자체의 내용을 정렬된 순서로 바꾸고, 반환값은 `None`입니다. 즉 원본 리스트를 직접 수정(in-place)하는 메서드입니다. 반면 내장 함수 `sorted()`는 원본은 그대로 둔 채 정렬된 새로운 리스트를 만들어 반환합니다.

```python
>>> numbers = [3, 1, 4, 1, 5, 9, 2, 6]
>>> result = sorted(numbers)
>>> print(result)
[1, 1, 2, 3, 4, 5, 6, 9]
>>> print(numbers)
[3, 1, 4, 1, 5, 9, 2, 6]
```

다음 코드는 흔히 저지르는 실수를 보여줍니다.

```python
>>> numbers = [3, 1, 2]
>>> numbers = numbers.sort()
>>> print(numbers)
None
```

`sort()`의 반환값은 `None`이므로, 이 값을 다시 `numbers`에 대입하면 리스트 자체가 사라지고 `None`만 남게 됩니다. `sort()`는 반환값을 사용하지 말고 그 자체로 호출해야 하며, 정렬된 새 리스트가 필요하다면 `sorted()`를 사용해야 합니다.

`sort()`와 `sorted()` 모두 `reverse=True`를 키워드 인자로 넘기면 내림차순으로 정렬할 수 있고, `key` 인자에 함수를 넘기면 정렬 기준을 직접 지정할 수 있습니다. 이 내용은 9장 함수에서 함수를 값으로 다루는 방법을 배운 뒤 더 깊이 활용할 수 있습니다.

```python
>>> words = ["banana", "kiwi", "apple", "fig"]
>>> sorted(words, key=len)
['kiwi', 'fig', 'apple', 'banana']
>>> sorted(words, reverse=True)
['kiwi', 'fig', 'banana', 'apple']
```

리스트의 순서를 정렬 기준 없이 단순히 뒤집기만 하고 싶다면 `reverse()` 메서드를 사용합니다.

```python
>>> numbers = [1, 2, 3, 4, 5]
>>> numbers.reverse()
>>> print(numbers)
[5, 4, 3, 2, 1]
```

`sort()`와 마찬가지로 `reverse()`도 원본 리스트를 직접 수정하고 `None`을 반환합니다.

### 길이 구하기: len

리스트에 담긴 원소의 개수를 셀 때는 내장 함수 `len()`을 사용합니다.

```python
>>> fruits = ["사과", "바나나", "포도"]
>>> len(fruits)
3
```

## 6.4 튜플이란 무엇인가

튜플(tuple)은 리스트와 매우 비슷하게 여러 값을 순서대로 담는 자료형이지만, 결정적인 차이가 하나 있습니다. 바로 튜플은 한 번 만들어지면 내용을 바꿀 수 없는 불변(immutable) 자료형이라는 것입니다. 튜플은 대괄호 대신 소괄호(`()`)로 만듭니다.

```python
>>> point = (3, 5)
>>> colors = ("빨강", "초록", "파랑")
>>> type(point)
<class 'tuple'>
```

튜플도 리스트처럼 인덱싱과 슬라이싱을 지원합니다.

```python
>>> point = (3, 5)
>>> point[0]
3
>>> colors = ("빨강", "초록", "파랑")
>>> colors[1:]
('초록', '파랑')
```

하지만 리스트와 달리 원소를 바꾸거나 추가, 삭제할 수 없습니다.

```python
>>> point = (3, 5)
>>> point[0] = 10
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'tuple' object does not support item assignment
```

### 원소가 하나인 튜플 만들기

원소가 하나뿐인 튜플을 만들 때는 주의가 필요합니다. 단순히 소괄호로 값 하나를 감싸는 것만으로는 튜플이 되지 않고, 반드시 값 뒤에 쉼표(`,`)를 붙여야 합니다.

```python
>>> not_a_tuple = (5)
>>> type(not_a_tuple)
<class 'int'>
>>> real_tuple = (5,)
>>> type(real_tuple)
<class 'tuple'>
```

`(5)`는 그냥 숫자 `5`를 괄호로 감싼 표현식일 뿐입니다. 튜플을 만드는 것은 괄호가 아니라 쉼표라는 점을 기억해야 합니다. 실제로 괄호를 아예 생략하고 쉼표만으로도 튜플을 만들 수 있습니다.

```python
>>> point = 3, 5
>>> type(point)
<class 'tuple'>
```

### 튜플 언패킹

튜플의 각 원소를 여러 변수에 한 번에 나누어 담는 것을 언패킹(unpacking)이라고 합니다.

```python
>>> point = (3, 5)
>>> x, y = point
>>> print(x, y)
3 5
```

언패킹은 두 변수의 값을 맞바꿀 때도 아주 우아하게 사용할 수 있습니다.

```python
>>> a, b = 1, 2
>>> a, b = b, a
>>> print(a, b)
2 1
```

`a, b = b, a`는 내부적으로 `(b, a)`라는 튜플을 먼저 만든 뒤 이를 `a`, `b`에 다시 언패킹하는 방식으로 동작합니다. 함수가 여러 값을 반환할 때도 튜플과 언패킹이 널리 활용되는데, 이 내용은 9장 함수에서 자세히 다룹니다.

### 튜플을 사용하는 이유

리스트도 여러 값을 담을 수 있는데 굳이 불변인 튜플을 사용하는 이유가 궁금할 수 있습니다. 몇 가지 실질적인 이유가 있습니다.

첫째, 값이 바뀌지 않아야 하는 데이터를 표현할 때 튜플을 쓰면 의도가 명확해집니다. 예를 들어 위도와 경도를 나타내는 좌표 `(37.5665, 126.9780)`는 두 값이 항상 짝을 이루고 도중에 바뀌어서는 안 되는 값이므로 튜플로 표현하는 것이 자연스럽습니다.

둘째, 불변이기 때문에 딕셔너리의 키나 셋의 원소로 사용할 수 있습니다(리스트는 가변이므로 불가능합니다). 이는 7장 딕셔너리와 셋에서 다시 다룰 내용입니다.

```python
>>> locations = {(37.5665, 126.9780): "서울", (35.1796, 129.0756): "부산"}
>>> print(locations[(37.5665, 126.9780)])
서울
```

셋째, 튜플은 리스트보다 가볍고 약간 더 빠르게 동작하며, 실수로 값이 바뀌는 것을 원천적으로 막아주기 때문에 코드의 안전성을 높여줍니다. 함수가 여러 개의 값을 묶어 반환할 때 관용적으로 튜플이 사용되는 것도 이런 이유 때문입니다.

## 6.5 얕은 복사와 참조: 흔히 하는 실수

리스트를 복사할 때 초보자가 가장 자주 부딪히는 함정이 있습니다. 다음 코드를 살펴보겠습니다.

```python
>>> original = [1, 2, 3]
>>> copy = original
>>> copy.append(4)
>>> print(original)
[1, 2, 3, 4]
>>> print(copy)
[1, 2, 3, 4]
```

`copy`만 바꿨는데 `original`까지 함께 바뀌어버렸습니다. 이는 `copy = original`이 리스트의 내용을 복사한 것이 아니라, `original`이 가리키고 있는 바로 그 리스트 객체를 `copy`도 함께 가리키도록 만들었기 때문입니다. 즉 `original`과 `copy`는 서로 다른 이름일 뿐, 메모리 상에서는 완전히 동일한 하나의 리스트 객체를 참조(reference)하고 있는 것입니다. `id()` 함수로 이를 직접 확인할 수 있습니다.

```python
>>> original = [1, 2, 3]
>>> copy = original
>>> id(original) == id(copy)
True
```

이는 3장 변수와 자료형에서 살펴본 것처럼 Python의 변수가 값 자체를 담는 상자가 아니라 객체를 가리키는 이름표에 가깝기 때문에 벌어지는 일입니다. 숫자나 문자열은 불변이기 때문에 이런 문제가 잘 드러나지 않지만, 가변인 리스트에서는 이 성질이 실질적인 문제로 이어집니다.

### 진짜 복사본 만들기: 얕은 복사

리스트의 내용을 정말로 복사한, 독립적인 새 리스트를 만들려면 다음과 같은 방법을 사용할 수 있습니다.

```python
>>> original = [1, 2, 3]
>>> copy1 = original.copy()
>>> copy2 = original[:]
>>> copy3 = list(original)
>>> copy1.append(4)
>>> print(original)
[1, 2, 3]
>>> print(copy1)
[1, 2, 3, 4]
```

`copy()` 메서드, 전체 슬라이싱(`[:]`), `list()` 생성자 모두 원본과 독립된 새 리스트를 만듭니다. 이렇게 새 리스트의 원소를 바꿔도 원본에는 영향을 주지 않습니다.

그런데 이 복사는 어디까지나 얕은 복사(shallow copy)라는 점에 주의해야 합니다. 얕은 복사는 리스트라는 "겉 껍데기"만 새로 만들 뿐, 그 안에 들어 있는 원소가 가변 객체(예: 리스트)라면 그 내부 객체까지는 복사하지 않고 여전히 같은 객체를 참조합니다.

```python
>>> original = [[1, 2], [3, 4]]
>>> copy = original.copy()
>>> copy[0].append(99)
>>> print(original)
[[1, 2, 99], [3, 4]]
>>> print(copy)
[[1, 2, 99], [3, 4]]
```

`copy`라는 바깥쪽 리스트는 `original`과 별개의 객체이지만, 그 안에 들어 있는 `[1, 2]`라는 내부 리스트는 여전히 `original`과 `copy`가 동일한 객체를 가리키고 있습니다. 그래서 `copy[0]`에 원소를 추가했을 뿐인데 `original[0]`까지 함께 바뀌어버린 것입니다.

이렇게 리스트 안에 리스트가 들어 있는 것처럼 중첩된 가변 객체까지 완전히 독립적으로 복사하려면 표준 라이브러리의 `copy` 모듈이 제공하는 `deepcopy()`를 사용해야 합니다.

```python
>>> import copy
>>> original = [[1, 2], [3, 4]]
>>> deep_copy = copy.deepcopy(original)
>>> deep_copy[0].append(99)
>>> print(original)
[[1, 2], [3, 4]]
>>> print(deep_copy)
[[1, 2, 99], [3, 4]]
```

`deepcopy()`는 중첩된 모든 가변 객체를 재귀적으로 복사하기 때문에, 이번에는 `original`이 전혀 영향을 받지 않습니다. 모듈을 가져오는 `import` 문법은 14장 모듈과 패키지에서 자세히 다룹니다.

리스트를 함수의 인자로 넘길 때도 같은 원리가 적용됩니다. Python은 리스트와 같은 가변 객체를 함수에 전달할 때 객체에 대한 참조를 전달하므로, 함수 안에서 리스트의 내용을 바꾸면 함수 밖의 원본 리스트에도 그 변화가 그대로 반영됩니다. 이 내용은 9장 함수에서 인자 전달 방식을 다룰 때 다시 자세히 짚어보겠습니다.

## 6.6 리스트와 튜플, 무엇을 언제 쓸까

리스트와 튜플 모두 여러 값을 순서대로 담는다는 공통점이 있지만, 선택 기준은 비교적 명확합니다. 데이터의 개수가 늘어나거나 줄어들 수 있고, 내용을 계속 바꿔가며 사용해야 한다면 리스트가 적합합니다. 반면 값의 목록이 한번 정해지면 바뀌지 않아야 하거나, 서로 다른 의미를 가진 값들을 고정된 개수로 묶어서 표현하는 경우(예: 이름과 나이의 쌍, x와 y 좌표)에는 튜플이 더 알맞은 선택입니다.

```python
>>> shopping_cart = ["우유", "빵"]        # 계속 추가/제거될 수 있는 목록 → 리스트
>>> shopping_cart.append("계란")
>>> rgb_color = (255, 0, 0)               # 항상 세 값으로 고정된 의미 단위 → 튜플
```

이 둘의 차이는 7장 딕셔너리와 셋에서 배우게 될 딕셔너리, 셋과 함께 Python의 대표적인 컬렉션 자료형을 이루며, 이후 8장 제어문에서 `for` 반복문과 결합해 매우 자주 활용됩니다.

## 요약

- 리스트(`[]`)는 여러 값을 순서대로 담는 가변(mutable) 자료형으로, 인덱싱과 슬라이싱 규칙은 문자열과 동일합니다.
- `append()`, `insert()`, `extend()`로 원소를 추가하고, `remove()`, `pop()`, `del`로 원소를 제거합니다.
- `sort()`는 원본 리스트를 직접 정렬하고 `None`을 반환하며, `sorted()`는 원본을 그대로 둔 채 정렬된 새 리스트를 반환합니다.
- 튜플(`()`)은 리스트와 비슷하지만 불변(immutable)이며, 원소가 하나인 튜플은 `(5,)`처럼 반드시 쉼표를 붙여야 합니다. 값의 짝을 고정해서 표현하거나 딕셔너리의 키로 사용할 때 적합합니다.
- `copy = original`은 값을 복사하는 것이 아니라 같은 객체를 함께 참조하게 만들 뿐입니다. 독립된 복사본이 필요하면 `.copy()`, `[:]`, `list()`를 사용하고, 중첩된 가변 객체까지 완전히 분리하려면 `copy.deepcopy()`를 사용해야 합니다.
- 데이터가 계속 변하면 리스트를, 값의 구성이 고정되어 있으면 튜플을 사용하는 것이 일반적인 선택 기준입니다.
