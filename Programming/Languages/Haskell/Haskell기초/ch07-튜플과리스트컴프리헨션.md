6장에서는 리스트를 다루는 기본기를 익혔습니다. 이번 장에서는 리스트와 자주 비교되는 또 다른 자료구조인 **튜플(tuple)**을 소개하고, 리스트를 훨씬 짧고 선언적으로 만들어 내는 **리스트 컴프리헨션(list comprehension)** 문법을 배웁니다.

## 튜플이란 무엇인가

리스트는 "같은 타입의 값을 몇 개든" 담을 수 있는 자료구조입니다. 반대로 튜플은 "정해진 개수의 값을, 서로 다른 타입이라도" 담을 수 있는 자료구조입니다. 이 차이가 튜플과 리스트를 구분하는 핵심입니다.

```haskell
ghci> point = (3, 4)
ghci> :type point
point :: (Num a, Num b) => (a, b)

ghci> person = ("승훈", 30, True)
ghci> :type person
person :: ([Char], Integer, Bool)
```

`point`는 숫자 두 개를 담은 **2-튜플(pair)**이고, `person`은 이름·나이·활동여부를 담은 **3-튜플(triple)**입니다. 리스트와 달리 튜플은 각 위치(position)마다 의미와 타입이 고정되어 있습니다. 그래서 튜플의 타입은 `(Num a, Num b) => (a, b)`처럼 괄호 안에 각 원소의 타입을 나란히 적어서 표현합니다.

리스트와 튜플의 차이를 표로 정리하면 다음과 같습니다.

| | 리스트 | 튜플 |
|---|---|---|
| 원소 개수 | 가변적 | 고정 (타입에 새겨짐) |
| 원소 타입 | 모두 같아야 함 | 각각 달라도 됨 |
| 타입 표기 | `[Int]` | `(Int, Bool, String)` |

원소 개수가 타입에 새겨진다는 점이 중요합니다. `(Int, Int)`와 `(Int, Int, Int)`는 원소 개수가 다르므로 **완전히 다른 타입**입니다. 반면 `[Int]`는 원소가 0개든 100개든 똑같이 `[Int]` 타입입니다.

```haskell
ghci> :type (1, 2)
(1, 2) :: (Num a, Num b) => (a, b)
ghci> :type (1, 2, 3)
(1, 2, 3) :: (Num a, Num b, Num c) => (a, b, c)
```

## 튜플의 원소 꺼내기

2-튜플에는 첫 번째와 두 번째 원소를 꺼내는 `fst`, `snd` 함수가 기본으로 제공됩니다.

```haskell
ghci> fst point
3
ghci> snd point
4
```

하지만 `fst`, `snd`는 정확히 2-튜플에만 쓸 수 있습니다. 3-튜플 이상에서는 4장에서 배운 **패턴 매칭**으로 원소를 꺼내는 것이 일반적입니다.

```haskell
-- 3-튜플에서 이름만 꺼내는 함수
getName :: (String, Int, Bool) -> String
getName (name, _, _) = name

ghci> getName person
"승훈"
```

`let` 바인딩이나 함수 인자에서도 튜플을 곧바로 분해할 수 있습니다.

```haskell
ghci> let (x, y) = point
ghci> x
3
ghci> y
4
```

## 튜플은 언제 쓰는가

튜플은 "서로 관련 있지만 성격이 다른 값 몇 개를 임시로 묶어서" 주고받을 때 유용합니다. 대표적인 예가 함수 하나가 **여러 값을 동시에 반환**해야 할 때입니다.

```haskell
-- 리스트를 훑어 최솟값과 최댓값을 한 번에 구한다
minMax :: [Int] -> (Int, Int)
minMax xs = (minimum xs, maximum xs)

ghci> minMax [4, 1, 7, 3, 9, 2]
(1, 9)
```

`zip` 함수는 두 리스트를 짝지어 튜플의 리스트로 만들어 주는 대표적인 예입니다.

```haskell
ghci> zip [1, 2, 3] "abc"
[(1, 'a'), (2, 'b'), (3, 'c')]
```

여기서 결과의 타입은 `[(Int, Char)]`, 즉 **튜플의 리스트**입니다. 리스트는 같은 타입의 원소를 여러 개 담고, 그 원소 하나하나가 튜플이라는 점에서 두 자료구조가 자연스럽게 결합되는 모습을 볼 수 있습니다.

## 리스트 컴프리헨션 기초 문법

리스트 컴프리헨션은 수학에서 집합을 정의할 때 쓰는 `{x² | x ∈ ℕ, x가 짝수}` 같은 표기법에서 영감을 받은 문법입니다. Haskell에서는 다음처럼 씁니다.

```haskell
ghci> [x * 2 | x <- [1..10], even x]
[4, 8, 12, 16, 20]
```

이 표현은 세 부분으로 나뉩니다.

- `x * 2` — 결과 리스트에 담길 **출력 식(output expression)**
- `x <- [1..10]` — 값을 하나씩 뽑아 오는 **생성자(generator)**
- `even x` — 통과한 값만 남기는 **조건(guard/filter)**

즉 "`[1..10]`에서 `x`를 하나씩 꺼내되, `even x`를 만족하는 것만 골라서 `x * 2`를 계산해 모아라"라는 뜻입니다. 이는 `map`과 `filter`를 조합한 것과 동일한 결과를 냅니다.

```haskell
ghci> map (* 2) (filter even [1..10])
[4, 8, 12, 16, 20]
```

두 표현이 같은 일을 하지만, 리스트 컴프리헨션은 "무엇을 뽑고, 무엇을 걸러내고, 무엇을 계산할지"를 한 줄에 선언적으로 담아내므로 읽기가 더 직관적일 때가 많습니다.

## 여러 생성자와 여러 조건 조합하기

생성자는 쉼표로 여러 개 나열할 수 있고, 조건도 여러 개 나열할 수 있습니다. 생성자가 두 개 이상이면 마치 중첩 for-루프처럼 동작합니다.

```haskell
ghci> [(x, y) | x <- [1, 2, 3], y <- [4, 5]]
[(1,4),(1,5),(2,4),(2,5),(3,4),(3,5)]
```

바깥쪽 생성자인 `x`가 한 번 고정될 때마다 안쪽 생성자 `y`가 전부 순회됩니다. 여기에 조건을 추가하면 원하는 조합만 남길 수 있습니다.

```haskell
-- 피타고라스 세 쌍(a² + b² = c²)을 c가 20 이하인 범위에서 찾기
ghci> [(a, b, c) | c <- [1..20], b <- [1..c], a <- [1..b], a*a + b*b == c*c]
[(3,4,5),(6,8,10),(5,12,13),(9,12,15),(8,15,17),(12,16,20)]
```

조건은 여러 개를 쉼표로 이어 붙일 수도 있습니다.

```haskell
-- 1부터 50 사이에서 3의 배수이면서 5의 배수가 아닌 수
ghci> [x | x <- [1..50], x `mod` 3 == 0, x `mod` 5 /= 0]
[3,6,9,12,18,21,24,27,33,36,39,42,48]
```

## 리스트 컴프리헨션과 문자열

문자열은 `Char`의 리스트이므로, 리스트 컴프리헨션을 그대로 문자열 처리에 쓸 수 있습니다.

```haskell
-- 문자열에서 대문자만 골라내기
ghci> import Data.Char (isUpper)
ghci> [c | c <- "Hello World From Haskell", isUpper c]
"HWFH"
```

## 튜플과 리스트 컴프리헨션 함께 쓰기

두 개념은 함께 쓰일 때 특히 강력합니다. 예를 들어 이름과 점수 리스트에서 통과한 사람의 이름만 뽑아내는 코드를 봅시다.

```haskell
scores :: [(String, Int)]
scores = [("민지", 88), ("도윤", 45), ("하은", 92), ("서준", 59)]

-- 60점 이상인 사람의 이름만 추출
passed :: [(String, Int)] -> [String]
passed xs = [name | (name, score) <- xs, score >= 60]

ghci> passed scores
["민지","하은"]
```

여기서 생성자 `(name, score) <- xs`는 튜플의 리스트를 순회하며 **각 튜플을 즉시 패턴 매칭으로 분해**합니다. 튜플로 데이터를 묶고, 리스트 컴프리헨션으로 필요한 것만 뽑아내는 흐름은 이후 9장 고차 함수와 10장 커스텀 데이터 타입에서도 계속 등장하는 패턴입니다.

## 요약

- 튜플은 정해진 개수의 값을 서로 다른 타입으로 묶는 자료구조이며, 원소 개수가 타입 자체에 포함됩니다. 리스트는 같은 타입의 값을 가변 개수로 담습니다.
- 2-튜플은 `fst`, `snd`로 원소를 꺼낼 수 있고, 3-튜플 이상은 패턴 매칭으로 분해하는 것이 일반적입니다.
- `zip` 같은 함수는 두 리스트를 튜플의 리스트로 결합해, 튜플과 리스트가 함께 쓰이는 대표적인 예를 보여줍니다.
- 리스트 컴프리헨션 `[출력식 | 생성자, 조건, ...]`은 `map`과 `filter`의 조합을 선언적으로 표현하는 문법입니다.
- 생성자를 여러 개 나열하면 중첩 순회가 되고, 조건은 쉼표로 여러 개 이어 붙일 수 있습니다.
- 문자열도 `Char`의 리스트이므로 리스트 컴프리헨션으로 자연스럽게 처리할 수 있습니다.

## 연습문제

1. `(String, Int, Int)` 형태로 학생의 이름, 국어 점수, 수학 점수를 담은 튜플의 리스트를 만들고, 두 점수의 평균이 70 이상인 학생의 이름만 리스트 컴프리헨션으로 뽑아내는 함수를 작성하세요.
2. `[1..100]`에서 리스트 컴프리헨션을 사용해 완전제곱수(1, 4, 9, 16, ...)만 골라내는 표현을 작성하세요.
3. 두 개의 정수 리스트 `xs`, `ys`를 받아 모든 `(x, y)` 조합 중 `x + y`가 짝수인 쌍만 반환하는 함수를 리스트 컴프리헨션으로 작성하세요.
4. `zip3` 함수를 GHCi에서 실험해 보고, 세 개의 리스트를 3-튜플의 리스트로 묶는 방식을 확인해 보세요. 리스트의 길이가 서로 다를 때는 어떻게 동작하나요?
5. 문자열 리스트 `["apple", "kiwi", "banana", "fig"]`에서 리스트 컴프리헨션으로 길이가 4 이하인 단어만 뽑아 `(단어, 길이)` 튜플의 리스트로 만드는 함수를 작성하세요.
