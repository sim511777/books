지금까지 작성한 코드는 대부분 `main` 함수 안에 모든 로직을 몰아넣은 형태였습니다. 프로그램이 조금만 커져도 이런 방식은 금방 한계에 부딪힙니다. 같은 계산을 여러 곳에서 반복해야 하거나, 코드의 의미 단위를 나눠서 이름을 붙이고 싶을 때 필요한 도구가 바로 함수(function)입니다.

함수는 입력을 받아 어떤 작업을 수행하고 결과를 돌려주는, 이름이 붙은 코드 묶음입니다. Go의 함수는 다른 언어와 비슷한 점도 많지만, 여러 값을 한 번에 반환할 수 있다는 점, 함수 자체를 값처럼 다룰 수 있다는 점에서 뚜렷한 개성을 가지고 있습니다. 이번 장에서는 함수를 정의하고 호출하는 기본 문법부터 시작해서, Go다운 함수 사용법인 다중 반환값, 가변 인자, 클로저까지 차례로 살펴봅니다.

## 함수 정의와 호출

Go에서 함수는 `func` 키워드로 정의합니다. 매개변수 목록 뒤에 반환 타입을 적고, 중괄호 안에 함수의 본문을 작성합니다.

```go
package main

import "fmt"

// add는 정수 두 개를 더해서 반환한다
func add(a int, b int) int {
	return a + b
}

func main() {
	result := add(3, 4)
	fmt.Println(result) // 7
}
```

함수 이름 뒤 괄호 안에는 매개변수(parameter)를, 그 뒤에는 반환 타입을 적습니다. `add(a int, b int) int`는 "`int` 타입 `a`와 `int` 타입 `b`를 받아 `int`를 반환하는 함수"라는 뜻입니다.

매개변수의 타입이 연달아 같으면 마지막 타입 하나만 남기고 생략할 수 있습니다.

```go
// a int, b int를 아래처럼 줄여 쓸 수 있다
func add(a, b int) int {
	return a + b
}
```

반환값이 필요 없는 함수는 반환 타입 자리를 아예 비워둡니다.

```go
func greet(name string) {
	fmt.Println(name + "님, 안녕하세요.")
}
```

### 매개변수는 값으로 전달된다

Go는 함수를 호출할 때 인자를 항상 값으로 전달합니다. 즉 매개변수는 호출한 쪽이 넘긴 값의 **복사본**입니다. 함수 안에서 매개변수를 수정해도 호출한 쪽의 변수에는 영향이 없습니다.

```go
func increment(n int) {
	n++ // n은 복사본이라 여기서 바꿔도 원본은 그대로다
}

func main() {
	x := 10
	increment(x)
	fmt.Println(x) // 10, 바뀌지 않았다
}
```

다만 7장(배열과 슬라이스)에서 다뤘듯이 슬라이스나, 이번 장 뒤에 이어지는 8장(맵과 구조체)에서 다룰 맵을 매개변수로 넘기면 이야기가 조금 달라집니다. 슬라이스나 맵 자체는 값으로 복사되지만, 그 값이 내부적으로 가리키는 데이터는 원본과 공유되기 때문입니다. 원본을 함수 안에서 직접 수정하고 싶을 때 포인터를 사용하는 방법은 9장(포인터)에서 자세히 다룹니다.

## 여러 개의 반환값

Go 함수의 가장 두드러진 특징은 값을 여러 개 동시에 반환할 수 있다는 점입니다. 다른 많은 언어에서는 값 하나만 반환할 수 있어서, 값과 함께 성공 여부나 부가 정보를 돌려주려면 튜플이나 객체로 감싸야 합니다. Go는 이런 감싸기 없이 반환 타입을 괄호로 묶어 나열하기만 하면 됩니다.

```go
package main

import "fmt"

// divide는 몫과 나머지를 함께 반환한다
func divide(a, b int) (int, int) {
	quotient := a / b
	remainder := a % b
	return quotient, remainder
}

func main() {
	q, r := divide(17, 5)
	fmt.Println(q, r) // 3 2
}
```

호출하는 쪽에서는 `q, r := divide(17, 5)`처럼 반환값의 개수만큼 변수를 나열해서 한 번에 받습니다. 반환값 중 일부가 필요 없다면 5장(제어문)에서 `for range`와 함께 잠깐 언급했던 밑줄(`_`, blank identifier)로 무시할 수 있습니다.

```go
q, _ := divide(17, 5) // 나머지는 버린다
fmt.Println(q)        // 3
```

### (결과, error) 관용구 예고

다중 반환값이 실전에서 가장 많이 쓰이는 형태는 마지막 반환값으로 오류(error)를 함께 돌려주는 패턴입니다. 표준 라이브러리 전반에서 이 형태를 볼 수 있습니다.

```go
n, err := strconv.Atoi("42")
if err != nil {
	fmt.Println("변환 실패:", err)
	return
}
fmt.Println(n)
```

Go에는 예외(exception) 처리 구문이 따로 없습니다. 대신 오류가 날 수 있는 함수는 마지막 반환값으로 `error` 타입 값을 함께 돌려주고, 호출한 쪽은 `if err != nil`로 그 값을 즉시 검사하는 것이 관용적인 스타일입니다. 이 패턴과 `error` 타입 자체를 만드는 방법은 11장(에러 처리)에서 본격적으로 다룹니다. 지금은 "여러 값을 반환하는 문법이 Go의 오류 처리 방식을 뒷받침하는 토대가 된다"는 정도만 기억해 두면 충분합니다.

## 이름 있는 반환값

반환값에도 매개변수처럼 이름을 붙일 수 있습니다. 이렇게 이름을 붙인 반환값은 함수 본문 맨 위에서 미리 선언된 변수처럼 취급되며, 제로 값으로 초기화된 채 시작합니다.

```go
package main

import "fmt"

// rectangleInfo는 넓이와 둘레를 이름 있는 반환값으로 돌려준다
func rectangleInfo(width, height float64) (area, perimeter float64) {
	area = width * height
	perimeter = 2 * (width + height)
	return // 이름 붙은 반환값을 그대로 반환한다(naked return)
}

func main() {
	a, p := rectangleInfo(3, 4)
	fmt.Println(a, p) // 12 14
}
```

`return`문에 아무 값도 적지 않으면 현재 이름 있는 반환값들이 그대로 반환됩니다. 이를 네이키드 리턴(naked return)이라고 부릅니다.

이름 있는 반환값은 두 가지 장점이 있습니다. 첫째, 함수 시그니처만 보고도 각 반환값이 무엇을 의미하는지 알 수 있어 문서 역할을 합니다. 둘째, `defer`와 결합했을 때(12장에서 다룹니다) 반환값을 함수가 끝나기 직전에 조정할 수 있게 해줍니다.

다만 네이키드 리턴을 남용하면 오히려 코드를 읽기 어렵게 만들 수 있습니다. 함수가 길어지고 `return`이 여러 곳에 흩어져 있다면, 각 `return` 시점에 이름 있는 반환값들이 어떤 값을 가지고 있는지 한눈에 파악하기 어려워지기 때문입니다. 짧은 함수에서 의도를 분명히 하고 싶을 때 이름만 붙이고, 실제 반환은 `return area, perimeter`처럼 값을 명시하는 편이 대체로 더 안전합니다.

## 가변 인자 함수

몇 개가 들어올지 미리 알 수 없는 인자를 받고 싶을 때는 매개변수 타입 앞에 `...`을 붙입니다. 이런 매개변수를 가변 인자(variadic parameter)라고 합니다. 사실 `fmt.Println`이 인자를 몇 개든 받을 수 있는 것도 바로 이 문법 덕분입니다.

```go
package main

import "fmt"

// sum은 int를 몇 개든 받아서 모두 더한다
func sum(nums ...int) int {
	total := 0
	for _, n := range nums {
		total += n
	}
	return total
}

func main() {
	fmt.Println(sum())        // 0
	fmt.Println(sum(1, 2))    // 3
	fmt.Println(sum(1, 2, 3)) // 6
}
```

함수 본문 안에서 `nums`는 평범한 `[]int` 슬라이스로 취급됩니다. 가변 인자는 함수 하나에 하나만 쓸 수 있고, 반드시 매개변수 목록의 맨 마지막에 와야 합니다.

```go
// label 뒤에 오는 값들을 가변 인자로 받는다
func describe(label string, nums ...int) {
	fmt.Println(label, nums)
}
```

이미 슬라이스로 가지고 있는 값을 가변 인자 함수에 통째로 넘기고 싶다면, 7장(배열과 슬라이스)의 `append`에서 본 것과 같은 `...` 펼치기 문법을 사용합니다.

```go
scores := []int{10, 20, 30}
fmt.Println(sum(scores...)) // 60, 슬라이스를 펼쳐서 전달
```

`scores...`가 없으면 `sum(scores)`는 컴파일되지 않습니다. `sum`은 `...int` 타입을 받는데 `scores` 자체는 `[]int` 슬라이스이지, 개별 `int` 값들이 아니기 때문입니다.

## 재귀 함수

Go 함수는 자기 자신을 다시 호출할 수 있습니다. 이런 함수를 재귀 함수(recursive function)라고 부릅니다. 반복되는 구조를 가진 문제(팩토리얼, 트리 순회 등)를 자연스럽게 표현할 때 유용합니다.

```go
package main

import "fmt"

// factorial은 n의 팩토리얼을 재귀로 계산한다
func factorial(n int) int {
	if n <= 1 {
		return 1 // 기저 조건(base case)
	}
	return n * factorial(n-1)
}

func main() {
	fmt.Println(factorial(5)) // 120
}
```

재귀 함수를 작성할 때는 반드시 재귀 호출을 멈추게 하는 기저 조건(base case)을 명확히 정의해야 합니다. 위 예제에서는 `n <= 1`이 그 역할을 합니다. 기저 조건이 없거나 잘못되면 함수 호출이 끝없이 이어지다가 스택 오버플로(stack overflow)로 프로그램이 강제 종료됩니다. 대부분의 반복 작업은 5장(제어문)에서 배운 `for`문으로도 표현할 수 있으므로, 재귀는 문제 자체가 재귀적인 구조(트리, 분할 정복 알고리즘 등)일 때 선택하는 것이 좋습니다.

## 함수는 값이다

Go에서 함수는 정수나 문자열처럼 하나의 값입니다. 함수를 변수에 담을 수 있고, 다른 함수의 인자로 넘길 수 있고, 함수에서 함수를 반환할 수도 있습니다. 이런 성질을 "함수가 일급 값(first-class value)이다"라고 표현합니다.

### 함수 타입과 변수

함수의 타입은 매개변수와 반환값의 형태로 결정됩니다. `func(int, int) int`는 "`int` 두 개를 받아 `int`를 반환하는 함수"라는 하나의 타입입니다.

```go
package main

import "fmt"

func add(a, b int) int { return a + b }
func mul(a, b int) int { return a * b }

func main() {
	var operation func(int, int) int // 함수 타입 변수 선언

	operation = add
	fmt.Println(operation(2, 3)) // 5

	operation = mul
	fmt.Println(operation(2, 3)) // 6
}
```

### 함수를 다른 함수의 인자로 전달하기

함수를 값으로 다룰 수 있다는 것은, 함수를 다른 함수의 매개변수로 넘길 수 있다는 뜻이기도 합니다. 이런 패턴은 "어떤 값을 다룰지"와 "그 값을 가지고 무엇을 할지"를 분리하고 싶을 때 유용합니다.

```go
package main

import "fmt"

// apply는 nums의 각 요소에 f를 적용한 새 슬라이스를 반환한다
func apply(nums []int, f func(int) int) []int {
	result := make([]int, len(nums))
	for i, n := range nums {
		result[i] = f(n)
	}
	return result
}

func square(n int) int { return n * n }

func main() {
	nums := []int{1, 2, 3, 4}
	fmt.Println(apply(nums, square)) // [1 4 9 16]
}
```

### 익명 함수

함수에 굳이 이름을 붙일 필요가 없다면, 이름 없이 그 자리에서 바로 함수를 정의하는 익명 함수(anonymous function)를 사용할 수 있습니다. 앞의 예제를 익명 함수로 바꿔 쓰면 다음과 같습니다.

```go
nums := []int{1, 2, 3, 4}
result := apply(nums, func(n int) int {
	return n * n
})
fmt.Println(result) // [1 4 9 16]
```

익명 함수는 변수에 담아 재사용할 수도 있고, 정의하자마자 바로 호출할 수도 있습니다. 정의와 동시에 호출하는 형태를 즉시 실행 함수(IIFE, Immediately Invoked Function Expression)라고 부르기도 합니다.

```go
double := func(n int) int { return n * 2 }
fmt.Println(double(21)) // 42

// 정의하자마자 바로 호출
result := func(a, b int) int {
	return a + b
}(3, 4)
fmt.Println(result) // 7
```

## 클로저: 함수가 주변 변수를 기억하는 방법

익명 함수는 자신이 정의된 위치를 둘러싼 변수들을 그대로 참조할 수 있습니다. 이렇게 함수가 자신을 둘러싼 환경의 변수를 붙잡고 있는 함수를 클로저(closure)라고 부릅니다.

```go
package main

import "fmt"

// makeCounter는 호출할 때마다 1씩 증가하는 카운터 함수를 반환한다
func makeCounter() func() int {
	count := 0
	return func() int {
		count++ // 바깥 함수의 지역 변수 count를 계속 참조한다
		return count
	}
}

func main() {
	counter := makeCounter()
	fmt.Println(counter()) // 1
	fmt.Println(counter()) // 2
	fmt.Println(counter()) // 3

	another := makeCounter() // 완전히 새로운 count를 가진 별개의 카운터
	fmt.Println(another())   // 1
}
```

`makeCounter`가 반환한 익명 함수는 `count`라는 지역 변수를 참조합니다. 보통이라면 `makeCounter`가 끝나는 순간 `count`도 함께 사라져야 할 것 같지만, 반환된 함수가 `count`를 계속 참조하고 있으므로 Go 런타임은 `count`를 메모리에 계속 살려둡니다. `counter`를 호출할 때마다 이 `count` 값이 유지된 채 1씩 증가합니다. `makeCounter`를 다시 호출해서 만든 `another`는 `counter`와 전혀 다른, 자신만의 독립된 `count`를 가집니다.

클로저는 상태를 캡슐화하고 싶을 때, 혹은 콜백 함수에 추가 정보를 함께 담아 넘기고 싶을 때 자주 사용됩니다.

```go
// 특정 배수인지 검사하는 함수를 만들어내는 함수
func isMultipleOf(base int) func(int) bool {
	return func(n int) bool {
		return n%base == 0
	}
}

func main() {
	isEven := isMultipleOf(2)
	isMultipleOf3 := isMultipleOf(3)

	fmt.Println(isEven(10))       // true
	fmt.Println(isMultipleOf3(10)) // false
}
```

### 반복문 변수를 캡처할 때 주의할 점

클로저를 반복문 안에서 만들 때는 반복 변수가 어떻게 캡처되는지 주의해야 합니다. Go 1.22 이전 버전에서는 `for`문의 반복 변수가 반복마다 새로 만들어지지 않고 하나의 변수를 계속 재사용했기 때문에, 클로저 여러 개가 모두 같은 변수를 참조해 예상과 다른 결과가 나오는 경우가 흔했습니다.

```go
funcs := make([]func(), 0, 3)
for i := 0; i < 3; i++ {
	funcs = append(funcs, func() {
		fmt.Println(i)
	})
}
for _, f := range funcs {
	f()
}
// Go 1.22 이상: 0 1 2가 출력된다 (반복마다 i가 새로 생성됨)
// Go 1.21 이하: 3 3 3이 출력된다 (모든 클로저가 같은 i를 공유)
```

Go 1.22부터는 언어 자체가 반복마다 새로운 `i`를 만들도록 바뀌었기 때문에 위 코드는 직관적으로 `0 1 2`를 출력합니다. 하지만 오래된 Go 버전으로 작성된 코드를 만나거나, 최신 버전이라도 의도를 명확히 하고 싶다면 반복문 안에서 변수를 새로 선언해 각 클로저가 자신만의 값을 갖도록 만드는 습관을 들이는 것이 안전합니다.

```go
for i := 0; i < 3; i++ {
	i := i // 이번 반복만의 새로운 지역 변수를 만든다
	funcs = append(funcs, func() {
		fmt.Println(i)
	})
}
```

## 요약

- 함수는 `func 이름(매개변수) 반환타입 { ... }` 형태로 정의하며, 인자는 항상 값으로(복사되어) 전달됩니다.
- Go 함수는 값을 여러 개 동시에 반환할 수 있습니다. 마지막 반환값으로 `error`를 함께 돌려주고 `if err != nil`로 검사하는 패턴은 11장(에러 처리)에서 자세히 다룹니다.
- 반환값에 이름을 붙이면(이름 있는 반환값) 함수의 의도를 문서처럼 드러낼 수 있고, `return`만 적는 네이키드 리턴이 가능해집니다. 다만 남용하면 가독성을 해칠 수 있습니다.
- 매개변수 타입 앞에 `...`을 붙이면 개수가 정해지지 않은 가변 인자를 받을 수 있고, 함수 안에서는 슬라이스로 취급됩니다.
- 함수는 일급 값이므로 변수에 담거나, 다른 함수의 인자·반환값으로 사용할 수 있습니다. 이름 없이 그 자리에서 정의하는 익명 함수도 가능합니다.
- 클로저는 자신을 둘러싼 변수를 계속 참조하는 함수입니다. 반복문 안에서 클로저를 만들 때는 반복 변수가 어떻게 캡처되는지(Go 버전에 따라 동작이 다름) 주의해야 합니다.
