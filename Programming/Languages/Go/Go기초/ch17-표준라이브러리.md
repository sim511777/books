Go는 "배터리 포함(batteries included)" 철학을 가진 언어입니다. 문자열 처리, 파일 입출력, 네트워크 통신, 암호화, JSON 처리 같은 실무에서 자주 필요한 기능 대부분을 별도의 외부 패키지 없이 표준 라이브러리만으로 해결할 수 있습니다. `go doc` 명령이나 [pkg.go.dev](https://pkg.go.dev)에서 언제든 문서를 찾아볼 수 있으니, 이번 장에서 모든 것을 외우려 하기보다는 "이런 상황에서는 이 패키지를 찾아보면 되는구나" 하는 지도를 그린다는 마음으로 읽어보시기 바랍니다.

표준 라이브러리는 수십 개의 패키지로 이루어져 있어서 전부 다루는 것은 불가능합니다. 이번 장에서는 거의 모든 Go 프로그램에서 마주치게 되는 패키지 몇 가지만 골라, 자주 쓰이는 함수를 표와 짧은 예제로 소개합니다. 에러 값을 다루는 방법은 11장과 12장에서, 파일과 표준 입출력을 다루는 방법은 16장에서 이미 자세히 살펴봤으므로 여기서는 겹치지 않는 범위에서 각 패키지의 얼굴만 익히고 넘어가겠습니다.

## 표준 라이브러리 지도

| 패키지 | 용도 | 이번 장 다루는 범위 |
|---|---|---|
| `fmt` | 형식화된 입출력 | `Sprintf` 서식 지정자 정리 |
| `strings` | 문자열 검사·가공 | 자주 쓰는 함수 모음 |
| `strconv` | 문자열 ↔ 다른 타입 변환 | 숫자 변환 함수 |
| `os` | 운영체제 자원 접근 | 환경 변수, 인자, 종료 코드 |
| `time` | 시간과 날짜 | 현재 시각, 기간, 서식 |
| `encoding/json` | JSON 인코딩/디코딩 | 구조체 ↔ JSON 변환 |
| `net/http` | HTTP 통신 | 클라이언트/서버 맛보기 |

## fmt: 형식화된 입출력

`fmt`는 아마 모든 Go 프로그램에서 가장 먼저 만나는 패키지일 것입니다. 지금까지 예제 곳곳에서 `fmt.Println`을 사용해 왔지만, 실무에서는 `Sprintf` 계열의 서식 지정자를 정확히 아는 것이 훨씬 중요합니다.

| 지정자 | 의미 |
|---|---|
| `%v` | 값을 기본 형식으로 출력 |
| `%+v` | 구조체 필드 이름까지 함께 출력 |
| `%#v` | Go 소스 코드 형태로 출력 |
| `%T` | 값의 타입 출력 |
| `%d`, `%s`, `%f` | 정수, 문자열, 실수 |
| `%t` | 불리언 |
| `%p` | 포인터 주소 |

```go
package main

import "fmt"

type User struct {
	Name string
	Age  int
}

func main() {
	u := User{Name: "지훈", Age: 28}

	fmt.Printf("%v\n", u)  // {지훈 28}
	fmt.Printf("%+v\n", u) // {Name:지훈 Age:28}
	fmt.Printf("%T\n", u)  // main.User

	s := fmt.Sprintf("이름: %s, 나이: %d", u.Name, u.Age)
	fmt.Println(s) // 이름: 지훈, 나이: 28
}
```

`Println`, `Printf`는 화면에 바로 출력하고, `Sprintf`는 출력하지 않고 문자열만 만들어 반환합니다. 로그 메시지나 에러 메시지를 조립할 때는 `Sprintf`를, 화면에 즉시 보여줄 때는 `Printf`를 사용한다고 구분해두면 편리합니다.

## strings: 문자열 다루기

문자열을 검사하고 가공하는 함수는 대부분 `strings` 패키지에 모여 있습니다.

| 함수 | 역할 |
|---|---|
| `strings.Contains(s, substr)` | 부분 문자열 포함 여부 |
| `strings.HasPrefix(s, prefix)` | 접두어 검사 |
| `strings.HasSuffix(s, suffix)` | 접미어 검사 |
| `strings.Split(s, sep)` | 구분자로 분리해 슬라이스로 |
| `strings.Join(slice, sep)` | 슬라이스를 구분자로 이어붙이기 |
| `strings.TrimSpace(s)` | 앞뒤 공백 제거 |
| `strings.ToUpper(s)`, `strings.ToLower(s)` | 대소문자 변환 |
| `strings.ReplaceAll(s, old, new)` | 전체 치환 |

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	csv := "  apple, banana, cherry  "

	trimmed := strings.TrimSpace(csv)
	items := strings.Split(trimmed, ",")

	for i, item := range items {
		items[i] = strings.TrimSpace(item)
	}

	fmt.Println(items)                 // [apple banana cherry]
	fmt.Println(strings.Join(items, " | ")) // apple | banana | cherry
}
```

긴 문자열을 반복해서 이어붙여야 한다면 `+` 연산자 대신 `strings.Builder`를 사용하는 것이 좋습니다. `+`로 문자열을 계속 이어붙이면 그때마다 새 문자열이 만들어져 복사 비용이 누적되지만, `Builder`는 내부 버퍼에 이어 써서 훨씬 효율적입니다.

```go
var b strings.Builder
for i := 0; i < 3; i++ {
	b.WriteString("go")
}
fmt.Println(b.String()) // gogogo
```

## strconv: 문자열과 다른 타입 간 변환

사용자 입력이나 파일에서 읽은 값은 대부분 문자열입니다. 이를 숫자나 불리언으로 바꾸거나 그 반대로 바꿀 때 `strconv`를 사용합니다.

| 함수 | 역할 |
|---|---|
| `strconv.Atoi(s)` | 문자열 → int |
| `strconv.Itoa(i)` | int → 문자열 |
| `strconv.ParseFloat(s, 64)` | 문자열 → float64 |
| `strconv.ParseBool(s)` | 문자열 → bool |
| `strconv.FormatInt(i, base)` | int64 → 지정한 진법의 문자열 |

```go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	n, err := strconv.Atoi("42")
	if err != nil {
		fmt.Println("변환 실패:", err)
		return
	}
	fmt.Println(n + 1) // 43

	s := strconv.Itoa(100)
	fmt.Println(s + "点") // 100点
}
```

`Atoi`가 반환하는 두 번째 값이 `error`라는 점을 눈여겨보시기 바랍니다. 숫자로 바꿀 수 없는 문자열("abc" 등)이 들어오면 `err`가 `nil`이 아니게 되므로, 11장에서 배운 `if err != nil` 관용구를 그대로 적용하면 됩니다.

## os: 운영체제와 상호작용

`os` 패키지는 프로그램이 실행되는 운영체제 환경과 상호작용하는 창구입니다. 파일을 열고 읽고 쓰는 자세한 내용은 16장에서 다뤘으므로, 여기서는 명령줄 인자와 환경 변수, 프로그램 종료만 짚고 넘어갑니다.

| 함수/변수 | 역할 |
|---|---|
| `os.Args` | 명령줄 인자 슬라이스 |
| `os.Getenv(key)` | 환경 변수 읽기 |
| `os.LookupEnv(key)` | 환경 변수 읽기(존재 여부 포함) |
| `os.Exit(code)` | 즉시 종료 코드와 함께 프로그램 종료 |

```go
package main

import (
	"fmt"
	"os"
)

func main() {
	fmt.Println("실행 파일:", os.Args[0])
	fmt.Println("전달된 인자:", os.Args[1:])

	if port, ok := os.LookupEnv("PORT"); ok {
		fmt.Println("PORT 환경 변수:", port)
	} else {
		fmt.Println("PORT 환경 변수가 설정되지 않았습니다")
	}
}
```

`os.Exit`는 `defer`로 예약된 함수를 실행하지 않고 즉시 프로그램을 종료시킵니다. 12장에서 다룬 `defer`의 정리 로직이 실행되지 않을 수 있으므로, 정말 프로그램을 즉시 끝내야 하는 상황(치명적인 설정 오류 등)이 아니라면 `main` 함수가 자연스럽게 끝나도록 흐름을 짜는 편이 안전합니다.

## time: 시간과 날짜

시간을 다루는 모든 기능은 `time` 패키지에 모여 있습니다.

| 함수/타입 | 역할 |
|---|---|
| `time.Now()` | 현재 시각(`time.Time`) 얻기 |
| `time.Since(t)` | `t`부터 지금까지 지난 시간(`time.Duration`) |
| `time.Sleep(d)` | 지정한 시간만큼 멈춤 |
| `t.Format(layout)` | 지정한 형식으로 문자열 변환 |
| `time.Parse(layout, s)` | 문자열을 `time.Time`으로 변환 |

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	start := time.Now()

	time.Sleep(10 * time.Millisecond)

	elapsed := time.Since(start)
	fmt.Println("걸린 시간:", elapsed)

	now := time.Now()
	fmt.Println(now.Format("2006-01-02 15:04:05")) // 예: 2026-08-07 13:00:00
}
```

Go의 시간 서식은 다른 언어처럼 `YYYY-MM-DD` 같은 기호를 쓰지 않고, `2006-01-02 15:04:05`라는 특정 기준 시각을 그대로 예시로 써서 형식을 표현합니다. 처음에는 낯설지만 "이 숫자들이 항상 연-월-일 시:분:초를 나타내는 기준값"이라고 외워두면 어떤 서식이든 이 패턴을 변형해서 만들 수 있습니다.

## encoding/json: JSON 인코딩과 디코딩

웹 API를 다루다 보면 구조체와 JSON 문자열을 서로 변환할 일이 매우 많습니다. `encoding/json` 패키지는 구조체 태그를 이용해 이 변환을 간단하게 만들어 줍니다.

| 함수 | 역할 |
|---|---|
| `json.Marshal(v)` | Go 값 → JSON 바이트 슬라이스 |
| `json.Unmarshal(data, &v)` | JSON 바이트 슬라이스 → Go 값 |
| `json.MarshalIndent(v, prefix, indent)` | 들여쓰기가 적용된 JSON 생성 |

```go
package main

import (
	"encoding/json"
	"fmt"
)

// json 태그로 필드와 JSON 키 이름을 연결한다
type Product struct {
	Name  string `json:"name"`
	Price int    `json:"price"`
}

func main() {
	p := Product{Name: "키보드", Price: 59000}

	data, err := json.Marshal(p)
	if err != nil {
		fmt.Println("인코딩 실패:", err)
		return
	}
	fmt.Println(string(data)) // {"name":"키보드","price":59000}

	var decoded Product
	jsonInput := []byte(`{"name":"마우스","price":29000}`)
	if err := json.Unmarshal(jsonInput, &decoded); err != nil {
		fmt.Println("디코딩 실패:", err)
		return
	}
	fmt.Printf("%+v\n", decoded) // {Name:마우스 Price:29000}
}
```

구조체 태그(`` `json:"name"` ``)는 10장에서 다룬 구조체 문법의 확장으로, Go 필드 이름(`Name`)과 JSON 키(`name`)가 다를 때 그 대응 관계를 알려줍니다. 태그를 생략하면 필드 이름을 그대로 JSON 키로 사용합니다.

## net/http 살짝 맛보기

`net/http`는 웹 서버와 클라이언트를 모두 만들 수 있는 강력한 패키지입니다. 본격적인 웹 프로그래밍은 이 책의 범위를 벗어나지만, 표준 라이브러리만으로 얼마나 적은 코드로 HTTP 통신을 할 수 있는지 감을 잡아보겠습니다.

```go
package main

import (
	"fmt"
	"net/http"
)

func handler(w http.ResponseWriter, r *http.Request) {
	fmt.Fprintln(w, "안녕하세요, Go 웹 서버입니다!")
}

func main() {
	http.HandleFunc("/", handler)
	fmt.Println("http://localhost:8080 에서 대기 중...")
	http.ListenAndServe(":8080", nil) // 실습 시 err 반환값을 확인하는 습관을 들이자
}
```

클라이언트 쪽에서 다른 서버에 요청을 보낼 때는 `http.Get`처럼 더 간단한 함수를 쓸 수 있습니다.

```go
resp, err := http.Get("https://example.com")
if err != nil {
	fmt.Println("요청 실패:", err)
	return
}
defer resp.Body.Close() // 12장에서 배운 defer로 자원 정리
fmt.Println("상태 코드:", resp.StatusCode)
```

외부 라이브러리 없이도 웹 서버와 클라이언트를 즉시 만들 수 있다는 점은 Go가 백엔드와 네트워크 프로그래밍 분야에서 널리 쓰이는 이유 중 하나입니다.

## 요약

- Go 표준 라이브러리는 대부분의 실무 요구를 외부 의존성 없이 해결할 수 있을 만큼 폭넓습니다. 모르는 기능이 필요하면 표준 라이브러리에 이미 있는지부터 확인하는 습관을 들이면 좋습니다.
- `fmt`는 서식화된 출력과 문자열 생성을, `strings`는 문자열 검사와 가공을, `strconv`는 문자열과 다른 타입 간 변환을 담당합니다.
- `os`는 명령줄 인자·환경 변수 같은 운영체제 자원에 접근하는 창구이며, 파일 입출력의 자세한 내용은 16장에서 다뤘습니다.
- `time`은 현재 시각, 경과 시간, 날짜 서식을 다루고, `encoding/json`은 구조체 태그를 이용해 Go 값과 JSON을 손쉽게 오갑니다.
- `net/http`는 표준 라이브러리만으로 HTTP 서버와 클라이언트를 만들 수 있게 해주며, 이는 Go가 네트워크 프로그래밍에 강한 이유 중 하나입니다.
- 이번 장에서 다루지 못한 패키지가 훨씬 많습니다. [pkg.go.dev](https://pkg.go.dev)에서 표준 라이브러리 전체 목록을 살펴보는 것을 추천합니다.
