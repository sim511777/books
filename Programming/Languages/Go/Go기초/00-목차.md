# Go 기초부터 응용까지

[다음: 1장. Go란 무엇인가 ▶](ch01-go란.md)

---

프로그래밍을 처음 접하는 사람과 다른 언어 경험자를 모두 아우르는 Go(Golang) 입문서입니다.
변수와 자료형 같은 기초 문법부터 슬라이스, 인터페이스, 에러 처리, 고루틴과 채널을 이용한
동시성 프로그래밍까지 Go의 핵심 개념을 순서대로 다룹니다.

각 장은 개념 설명, 예제 코드, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는 이해를 돕는
다이어그램을 함께 실었습니다.

## 학습 방법 제안

1. 각 장의 예제 코드를 직접 `go run`으로 실행하며 결과를 확인하세요.
2. 장 끝의 연습문제를 풀어보면서 이해도를 점검하세요.
3. 막히는 부분이 있다면 해당 장을 다시 읽거나, 관련된 이전/이후 장을 함께 참고하세요.
4. 18장까지 마친 뒤에는 부록의 치트시트를 필요할 때마다 참조용으로 활용하세요.
