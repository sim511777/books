# 5장. 제어문

[◀ 이전: 4장. 연산자와 표현식](ch04-연산자와표현식.md) | [📖 목차](00-목차.md) | [다음: 6장. 반복문 ▶](ch06-반복문.md)


프로그램은 대부분 위에서 아래로 순서대로 실행되지만, 그것만으로는 실제 문제를 풀 수 없습니다. 입력값에 따라 다른 계산을 해야 하거나, 특정 조건을 만족할 때만 어떤 동작을 수행해야 하는 경우가 훨씬 많습니다. 이런 "분기"를 표현하는 문법이 바로 제어문입니다.

3장에서 살펴본 `Bool` 타입과 4장에서 다룬 비교 연산자(`==`, `<`, `>=` 등)와 논리 연산자(`&&`, `||`, `!`)는 바로 이 장을 위한 준비 작업이었습니다. 조건문은 결국 `true` 또는 `false`로 평가되는 표현식을 이용해 실행 경로를 선택하는 것이기 때문입니다.

## 5.1 if 문의 기본 구조

가장 단순한 형태의 `if` 문은 조건이 참일 때만 코드 블록을 실행합니다.

```julia
age = 20

if age >= 18
    println("성인입니다.")
end
```

구조는 단순합니다. `if` 뒤에 `Bool` 값으로 평가되는 조건식을 쓰고, 조건이 참일 때 실행할 코드를 적은 뒤 `end`로 블록을 닫습니다. 파이썬처럼 들여쓰기가 문법적으로 강제되지는 않지만, 가독성을 위해 블록 안쪽은 4칸 들여쓰기를 하는 것이 관례입니다.

주의할 점은 조건식이 반드시 `Bool` 값이어야 한다는 것입니다. 다른 언어(C, JavaScript 등)에서는 정수 `0`이 거짓, 그 외의 값이 참으로 취급되는 경우가 많지만, Julia는 이런 암묵적 변환을 허용하지 않습니다.

```julia
x = 1

if x        # 오류 발생
    println("참")
end
```

```
ERROR: TypeError: non-boolean (Int64) used in boolean context
```

`x`가 0이 아니므로 참이라고 기대할 수 있지만, Julia는 `Int64` 값을 조건식 자리에 그대로 두는 것을 허용하지 않습니다. 조건은 항상 `x != 0`처럼 명시적으로 `Bool`을 만들어 써야 합니다. 이런 엄격함은 실수로 조건을 잘못 쓰는 것을 방지해 줍니다.

## 5.2 else로 대안 지정하기

조건이 거짓일 때 실행할 코드가 있다면 `else`를 사용합니다.

```julia
score = 65

if score >= 60
    println("합격입니다.")
else
    println("불합격입니다.")
end
```

`if` 블록과 `else` 블록 중 정확히 하나만 실행됩니다. 두 블록 모두 마지막에 `end`를 한 번만 쓰면 되고, `else` 다음에는 별도의 조건식을 쓰지 않습니다.

## 5.3 elseif로 여러 조건 연결하기

조건이 세 가지 이상으로 나뉠 때는 `elseif`를 사용해 연결할 수 있습니다.

```julia
score = 82

if score >= 90
    grade = "A"
elseif score >= 80
    grade = "B"
elseif score >= 70
    grade = "C"
else
    grade = "D"
end

println("학점: ", grade)
```

```
학점: B
```

`elseif`는 위에서부터 순서대로 조건을 검사하다가 처음으로 참이 되는 블록을 실행하고 나머지는 건너뜁니다. 위 예제에서 `score`가 82이므로 `score >= 90`은 거짓이지만 `score >= 80`은 참이 되어 `"B"`가 대입되고, 그 아래 `elseif`와 `else`는 검사조차 되지 않습니다.

`elseif`는 몇 개든 이어 붙일 수 있으며, `end`는 전체 `if`/`elseif`/`else` 연쇄를 통틀어 마지막에 딱 한 번만 씁니다. `else`는 생략할 수 있지만, 생략하면 어떤 조건도 만족하지 않을 때 아무 일도 일어나지 않습니다.

## 5.4 중첩 조건문

`if` 블록 안에 또 다른 `if` 블록을 넣을 수 있습니다. 조건이 여러 단계로 얽혀 있을 때 유용하지만, 너무 깊이 중첩하면 코드를 읽기 어려워지므로 가능하면 `elseif`나 논리 연산자로 조건을 평탄하게 정리하는 편이 좋습니다.

```julia
temperature = 28
humidity = 70

if temperature >= 30
    println("무더운 날씨입니다.")
else
    if humidity >= 60
        println("후텁지근한 날씨입니다.")
    else
        println("쾌적한 날씨입니다.")
    end
end
```

같은 로직을 다음처럼 조건을 합쳐서 중첩 없이 표현할 수도 있습니다.

```julia
if temperature >= 30
    println("무더운 날씨입니다.")
elseif humidity >= 60
    println("후텁지근한 날씨입니다.")
else
    println("쾌적한 날씨입니다.")
end
```

두 코드는 동일하게 동작하지만, 후자가 조건 사이의 관계를 한눈에 파악하기 쉽습니다. 일반적으로 중첩 단계가 2~3단계를 넘어가면 코드 구조를 다시 생각해 볼 신호로 받아들이는 것이 좋습니다.

## 5.5 if는 표현식이다

Julia에서 `if` 문은 단순한 "명령"이 아니라 **값을 반환하는 표현식**입니다. 이는 C, Java, Python 같은 언어와 뚜렷하게 구별되는 특징입니다. `if` 블록에서 마지막으로 평가된 값이 전체 `if` 표현식의 값이 됩니다.

```julia
x = 7

result = if x % 2 == 0
    "짝수"
else
    "홀수"
end

println(result)
```

```
홀수
```

이 성질 덕분에 조건에 따라 값을 고른 뒤 변수에 대입하는 코드를 다음처럼 간결하게 쓸 수 있습니다. `if`가 값을 반환한다는 사실을 모르면 아래처럼 변수를 미리 선언하고 각 분기에서 대입하는 방식으로 쓰기 쉽습니다.

```julia
# if의 반환값을 활용하지 않는 방식
local grade
score = 82
if score >= 90
    grade = "A"
elseif score >= 80
    grade = "B"
else
    grade = "C"
end
```

```julia
# if의 반환값을 바로 대입하는 방식
score = 82
grade = if score >= 90
    "A"
elseif score >= 80
    "B"
else
    "C"
end
```

두 코드는 결과가 같지만, 두 번째 방식은 "grade는 이 조건 분기의 결과다"라는 의도를 코드 구조 자체로 드러냅니다. 변수를 한 번만 대입하기 때문에 실수로 어느 분기에서 대입을 빠뜨리는 버그도 줄어듭니다.

만약 `else`가 없는 `if` 문에서 조건이 거짓이 되면 어떤 값이 반환될까요? 이때는 `nothing`이라는 특별한 값이 반환됩니다.

```julia
x = -3

result = if x > 0
    "양수"
end

println(result)
```

```
nothing
```

`nothing`은 "값이 없음"을 나타내는 Julia의 고유한 값으로, 뒤에서 다시 다루게 될 것입니다. 지금은 `else` 없는 `if`가 조건을 만족하지 못하면 `nothing`을 내놓는다는 것만 기억해 두면 충분합니다.

## 5.6 삼항 연산자

4장에서 잠깐 언급했던 삼항 연산자 `조건 ? 참일때값 : 거짓일때값`은 사실 `if`/`else`를 한 줄로 압축한 표현식입니다. 다음 두 코드는 완전히 동일하게 동작합니다.

```julia
x = 7

# if/else 버전
parity1 = if x % 2 == 0
    "짝수"
else
    "홀수"
end

# 삼항 연산자 버전
parity2 = x % 2 == 0 ? "짝수" : "홀수"

println(parity1 == parity2)   # true
```

삼항 연산자는 각 분기가 짧은 값 하나로 끝나는 경우에 특히 편리합니다. 예를 들어 절댓값을 계산하는 코드를 삼항 연산자로 쓰면 다음과 같습니다.

```julia
function absolute(x)
    return x >= 0 ? x : -x
end

println(absolute(-5))   # 5
println(absolute(3))    # 3
```

물음표(`?`)와 콜론(`:`) 앞뒤에는 반드시 공백을 넣어야 합니다. 공백이 없으면 파서가 다른 문법(타입 어노테이션이나 심벌)과 혼동하여 문법 오류가 발생합니다.

```julia
# 올바른 표기
y = x > 0 ? 1 : -1

# 오류가 나는 표기
y = x>0?1:-1
```

삼항 연산자를 중첩해서 여러 조건을 표현할 수도 있지만, 두 단계를 넘어가면 오히려 `if`/`elseif`/`else`를 쓰는 편이 읽기 좋습니다.

```julia
score = 82

grade = score >= 90 ? "A" :
        score >= 80 ? "B" :
        score >= 70 ? "C" : "D"

println(grade)   # B
```

이 정도의 중첩까지는 각 줄이 "점수 구간 하나"에 대응되어 그럭저럭 읽을 만하지만, 조건이 하나라도 더 늘어나면 앞서 배운 `elseif` 체인으로 바꾸는 것을 권장합니다. **간단한 이진 선택에는 삼항 연산자, 세 갈래 이상의 분기에는 if/elseif/else**라는 기준을 기억해 두면 좋습니다.

## 5.7 단락 평가를 이용한 조건부 실행

4장에서 `&&`(and)와 `||`(or)가 **단락 평가**(short-circuit evaluation)를 한다고 배웠습니다. 즉 `&&`는 왼쪽이 거짓이면 오른쪽을 아예 평가하지 않고, `||`는 왼쪽이 참이면 오른쪽을 평가하지 않습니다. 이 성질을 이용하면 `if` 문 없이도 조건부 실행을 표현할 수 있습니다.

```julia
x = 5

x > 0 && println("양수입니다.")
```

```
양수입니다.
```

`x > 0`이 참이므로 `&&`의 오른쪽인 `println(...)`이 평가(실행)됩니다. 반대로 `x`가 음수라면 왼쪽이 거짓이 되는 순간 전체 식이 거짓으로 확정되므로 오른쪽은 실행되지 않습니다.

```julia
x = -5

x > 0 && println("양수입니다.")   # 아무것도 출력되지 않음
```

이 관용구는 다음의 `if` 문과 동일하게 동작합니다.

```julia
if x > 0
    println("양수입니다.")
end
```

`||`를 이용하면 "조건이 거짓일 때만 실행"하는 관용구를 만들 수 있습니다. 흔한 예로, 값이 유효하지 않을 때 조기에 오류를 내는 방어적 코드에서 자주 쓰입니다.

```julia
function safe_sqrt(x)
    x >= 0 || error("음수는 처리할 수 없습니다: $x")
    return sqrt(x)
end

println(safe_sqrt(9))
```

```
3.0
```

```julia
safe_sqrt(-4)
```

```
ERROR: 음수는 처리할 수 없습니다: -4
```

`x >= 0`이 참이면 `||`는 왼쪽만으로 전체 식이 참임을 알 수 있으므로 오른쪽의 `error(...)`를 실행하지 않고 넘어갑니다. `x >= 0`이 거짓일 때만 오른쪽이 실행되어 예외를 발생시킵니다. (`error` 함수와 예외 처리는 14장에서 자세히 다룹니다.)

이런 단락 평가 관용구는 Julia 표준 라이브러리와 여러 패키지의 소스 코드에서도 흔히 볼 수 있을 만큼 널리 쓰이는 스타일입니다. 다만 오른쪽에 놓는 표현식은 값을 반환받아 쓰기보다는 `println`, `error`처럼 부수 효과(출력, 예외 발생 등)를 위해 호출하는 경우에 한정하는 것이 좋습니다. 조건에 따라 값을 고르는 목적이라면 앞서 배운 `if` 표현식이나 삼항 연산자가 의도를 더 명확하게 드러냅니다.

```julia
# 권장: 부수 효과를 위한 단락 평가
count > 0 && println("항목이 있습니다.")

# 권장: 값 선택에는 if 표현식 또는 삼항 연산자
label = count > 0 ? "있음" : "없음"
```

## 5.8 정리: 언제 무엇을 쓸까

지금까지 배운 조건부 실행 도구를 정리하면 다음과 같습니다.

| 상황 | 추천 문법 |
|---|---|
| 여러 줄의 코드를 조건에 따라 실행 | `if`/`elseif`/`else`/`end` |
| 조건에 따라 값을 골라 변수에 대입 | `if` 표현식 또는 삼항 연산자(간단한 경우) |
| 조건이 참일 때 한 줄만 실행 | `&&`를 이용한 단락 평가 |
| 조건이 거짓일 때 한 줄만 실행(주로 오류 처리) | `||`를 이용한 단락 평가 |
| 세 갈래 이상의 값 선택 | `if`/`elseif`/`else` 표현식 |

어떤 문법을 쓰든 동작은 결국 같은 논리로 귀결됩니다. 중요한 것은 코드를 읽는 사람이 조건과 결과의 관계를 가장 빠르게 파악할 수 있는 형태를 고르는 것입니다.

## 요약

- `if`/`elseif`/`else`/`end`로 조건에 따라 실행 경로를 분기합니다. 조건식은 반드시 `Bool` 값이어야 하며, Julia는 다른 타입을 조건 자리에서 암묵적으로 변환하지 않습니다.
- `elseif`는 여러 개를 이어 붙일 수 있고, 위에서부터 순서대로 검사하여 처음 참이 되는 블록만 실행합니다.
- Julia의 `if`는 **값을 반환하는 표현식**입니다. 블록의 마지막 값이 전체 `if`의 값이 되며, `else`가 없고 조건이 거짓이면 `nothing`이 반환됩니다.
- 삼항 연산자 `조건 ? 참값 : 거짓값`은 `if`/`else`를 한 줄로 줄인 표현식으로, 간단한 이진 선택에 적합합니다. `?`와 `:` 앞뒤에는 공백이 필요합니다.
- `&&`와 `||`의 단락 평가를 이용하면 `조건 && 실행문`, `조건 || 실행문` 형태로 짧은 조건부 실행을 표현할 수 있습니다. 값을 선택하는 목적보다는 부수 효과(출력, 오류 발생 등)를 위한 한 줄짜리 코드에 적합합니다.
- 중첩 `if`가 깊어지면 `elseif` 체인이나 조건 합성으로 평탄화하는 것이 가독성에 좋습니다.
