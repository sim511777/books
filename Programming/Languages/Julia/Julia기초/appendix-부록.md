## A.1 Julia 설치하기

### juliaup을 권장하는 이유

Julia를 설치하는 방법은 여러 가지가 있지만, 이 책에서는 **juliaup**을 이용한 설치를 권장합니다. juliaup은 Julia 버전을 설치하고 관리해 주는 공식 버전 관리 도구입니다. juliaup을 사용하면 다음과 같은 장점이 있습니다.

- 여러 버전의 Julia를 한 컴퓨터에 동시에 설치해 두고 필요에 따라 전환할 수 있습니다.
- 새 버전이 나왔을 때 명령어 한 줄로 업데이트할 수 있습니다.
- 운영체제별로 설치 경로나 환경변수를 직접 신경 쓰지 않아도 됩니다.

과거에는 julialang.org에서 운영체제에 맞는 설치 파일을 직접 내려받는 방식이 일반적이었지만, 최근에는 juliaup이 공식적으로 권장되는 설치 방법으로 자리 잡았습니다.

### Windows에서 설치하기

Windows에서는 Microsoft Store에서 "Julia"를 검색해 설치하는 방법이 가장 간단합니다. Microsoft Store 앱은 내부적으로 juliaup을 통해 배포됩니다.

Store를 사용하지 않는다면 PowerShell에서 다음 명령으로 설치할 수 있습니다.

```bash
winget install julia -s msstore
```

설치가 끝나면 새 터미널을 열고 다음 명령으로 정상 설치를 확인합니다.

```bash
julia --version
```

### macOS와 Linux에서 설치하기

macOS와 Linux에서는 터미널에서 다음 명령 한 줄로 juliaup을 설치할 수 있습니다.

```bash
curl -fsSL https://install.julialang.org | sh
```

설치 스크립트가 안내하는 대로 진행하면 juliaup과 최신 안정 버전의 Julia가 함께 설치됩니다. 설치가 끝나면 터미널을 새로 열거나 셸 설정 파일을 다시 불러온 뒤 다음 명령으로 확인합니다.

```bash
julia --version
```

### juliaup 기본 명령어

설치 이후 자주 쓰게 될 juliaup 명령어를 몇 가지 정리합니다.

| 명령어 | 설명 |
|---|---|
| `juliaup status` | 현재 설치된 Julia 버전 목록과 기본 버전을 확인합니다. |
| `juliaup update` | 설치된 채널(예: 최신 안정 버전)을 최신 상태로 업데이트합니다. |
| `juliaup add 1.10` | 특정 버전(예: 1.10)의 Julia를 추가로 설치합니다. |
| `juliaup default 1.10` | 기본으로 실행될 Julia 버전을 지정합니다. |

### 설치 확인

설치가 끝났다면 터미널에 `julia`라고 입력해 REPL이 정상적으로 열리는지 확인합니다. 2장에서 다룬 것처럼 `julia>` 프롬프트가 나타나면 정상적으로 설치된 것입니다.

```bash
julia
```

```
julia>
```

## A.2 이 책에서 사용한 주요 키워드·매크로 요약

이 책 전체에서 등장한 핵심 키워드와 매크로를 장별로 정리했습니다. 처음 등장한 장을 함께 표시했으니, 다시 살펴보고 싶을 때 참고하기 바랍니다.

| `if` / `elseif` / `else` / `end` | 조건 분기 | 5장 |
| `? :` | 삼항 연산자 | 5장 |

| `for` / `while` | 반복문 | 6장 |
| `break` / `continue` | 반복 제어 | 6장 |

| `return` | 함수 반환값 지정 | 7장 |
| `...` | 가변 인자(splat) | 7장 |
| `->` | 익명 함수(람다) 정의 | 7장 |

| `abstract type` | 추상 타입 정의 | 9장 |

| `macro` / `end` | 매크로 정의 | 15장 |
| `@` (매크로 호출 접두사) | 매크로 호출 | 15장 |
| `@time`, `@btime` | 실행 시간·메모리 측정 | 16장 |
| `@code_warntype` | 타입 안정성 점검 | 16장 |

## A.3 더 참고할 만한 공식 문서와 커뮤니티

Julia를 계속 공부하다 보면 이 책의 범위를 넘어서는 질문이 반드시 생깁니다. 그럴 때 찾아볼 만한 공식 자료와 커뮤니티의 이름을 소개합니다. (아래는 실제로 검색해 찾아갈 수 있는 이름과 주소이며, 클릭 가능한 링크가 아니라 텍스트 그대로 표기합니다.)

- **공식 웹사이트**: julialang.org — Julia 언어의 공식 홈페이지로, 다운로드, 뉴스, 생태계 소개 등을 확인할 수 있습니다.
- **공식 문서**: docs.julialang.org — 언어 레퍼런스와 표준 라이브러리 문서를 제공합니다. 함수 하나하나의 정확한 동작을 확인하고 싶을 때 가장 먼저 찾아봐야 할 곳입니다.
- **패키지 저장소**: JuliaHub와 Julia 패키지 레지스트리(General Registry) — 공개된 Julia 패키지를 검색하고 문서를 확인할 수 있습니다.
- **커뮤니티 포럼**: discourse.julialang.org (Julia Discourse) — 질문과 답변, 공지, 패키지 소개 글 등이 활발하게 올라오는 커뮤니티 포럼입니다.
- **실시간 채팅**: Julia Slack, Julia Zulip — 다른 사용자들과 실시간으로 질문을 주고받을 수 있는 채팅 커뮤니티입니다.
- **소스 코드 저장소**: github.com/JuliaLang/julia — Julia 언어 자체의 소스 코드가 공개된 저장소로, 이슈 트래커를 통해 버그 리포트나 기능 제안도 확인할 수 있습니다.

REPL의 도움말 모드(2장 참고)도 잊지 마세요. `?` 뒤에 함수나 매크로 이름을 입력하면 해당 문서를 즉시 확인할 수 있어, 온라인 문서만큼이나 자주 쓰게 될 도구입니다.

## A.4 다음 학습 단계

이 책을 마친 뒤 어떤 순서로 학습을 이어 가면 좋을지 간단히 제안합니다.

1. **표준 라이브러리 더 살펴보기**: `LinearAlgebra`, `Statistics`, `Random` 등 Julia에 기본 내장된 표준 라이브러리들을 하나씩 훑어보면서, 이 책에서 배운 타입 시스템과 다중 디스패치가 실제 라이브러리 코드에서 어떻게 쓰이는지 관찰해 보세요.
2. **작은 프로젝트 직접 만들어 보기**: 완벽한 설계보다는, 관심 있는 주제(간단한 계산기, 텍스트 처리 도구, 데이터 정리 스크립트 등)를 하나 골라 처음부터 끝까지 직접 만들어 보는 경험이 중요합니다. 13장에서 배운 패키지 구조를 실제로 적용해 보는 것도 좋습니다.
3. **관심 분야의 패키지 생태계 탐색하기**: 18장에서 언급한 `DataFrames.jl`, `Plots.jl`, `Flux.jl` 등 자신의 관심 분야에 맞는 패키지의 공식 문서와 튜토리얼을 따라가 보세요.
4. **다른 사람의 Julia 코드 읽어 보기**: GitHub에서 관심 있는 Julia 패키지의 소스 코드를 직접 읽어 보는 것은, 관용적인 코드 스타일과 다중 디스패치를 실전에서 어떻게 활용하는지 배우는 가장 좋은 방법 중 하나입니다.
5. **커뮤니티에 질문하고 답하기**: Julia Discourse나 Slack, Zulip 같은 커뮤니티에 직접 질문을 올려 보고, 나중에는 다른 사람의 질문에 답해 보는 것도 좋은 학습 방법입니다. Julia 커뮤니티는 초보자에게 친절하기로 잘 알려져 있습니다.

Julia는 배우기 쉬운 문법과, 깊이 파고들수록 드러나는 정교한 타입 시스템을 동시에 갖춘 언어입니다. 이 책이 그 여정의 첫걸음이 되었기를 바랍니다.
