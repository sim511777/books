# 3장. 변수와 자료형

[◀ 이전: 2장. 첫 프로그램과 REPL 환경](ch02-첫프로그램과REPL환경.md) | [📖 목차](00-목차.md) | [다음: 4장. 연산자와 표현식 ▶](ch04-연산자와표현식.md)


2장에서는 REPL을 열고 첫 코드를 실행해 보았습니다. 이번 장에서는 Julia 프로그램의 가장 작은 재료인 변수와 자료형을 다룹니다. 변수에 값을 담는 방법, Julia가 기본으로 제공하는 자료형들, 그리고 문자열을 다루는 유용한 기법인 문자열 보간까지 살펴봅니다.

## 3.1 변수 선언하기

Julia에서 변수를 만드는 방법은 아주 간단합니다. 변수 이름에 `=` 기호로 값을 대입하면 됩니다. 다른 언어처럼 타입을 미리 선언할 필요가 없습니다.

```julia
age = 25
height = 175.5
name = "홍길동"
is_student = true
```

이 코드를 REPL에 한 줄씩 입력하면 각 변수에 값이 저장된 것을 바로 확인할 수 있습니다.

```julia
julia> age = 25
25

julia> height = 175.5
175.5
```

Julia는 대입되는 값을 보고 스스로 적절한 타입을 결정합니다. 이를 **타입 추론(type inference)**이라고 부릅니다. `age`에는 정수 25가 들어갔으므로 `Int64` 타입이 되고, `height`에는 소수점이 있는 175.5가 들어갔으므로 `Float64` 타입이 됩니다.

변수 이름은 영문자, 한글, 숫자, 밑줄(`_`)로 구성할 수 있으며 숫자로 시작할 수 없습니다. 이 책에서는 함수와 변수 이름에 `snake_case`(단어를 밑줄로 연결하는 방식)를 사용합니다. 예를 들어 `student_count`, `total_price`처럼 씁니다.

```julia
julia> 학생수 = 10
10

julia> student_count = 10
10
```

한글 변수 이름도 문제없이 동작하지만, 이 책의 예제 코드는 다른 Julia 코드와의 일관성을 위해 영문 `snake_case`를 기본으로 사용합니다.

### 타입을 명시적으로 표기하기

타입을 직접 쓰지 않아도 되지만, 원한다면 `::` 기호를 사용해 변수의 타입을 명시적으로 지정할 수 있습니다.

```julia
julia> x::Int64 = 10
10

julia> y::Float64 = 3.14
3.14
```

이렇게 타입을 표기하면 해당 변수에는 지정한 타입의 값만 대입할 수 있습니다. 만약 타입이 맞지 않는 값을 대입하려 하면 Julia는 자동으로 변환을 시도하고, 변환이 불가능하면 오류를 냅니다.

```julia
julia> x::Int64 = 10
10

julia> x = 3.5
ERROR: InexactError: Int64(3.5)
```

3.5는 정수로 정확히 변환할 수 없기 때문에 오류가 발생했습니다. 반면 3.0처럼 소수부가 0인 값은 정수로 정확히 변환되므로 문제없이 대입됩니다.

```julia
julia> x = 3.0
3
```

일반적인 Julia 코드에서는 타입 표기 없이 변수를 사용하는 경우가 훨씬 많습니다. 타입 표기는 의도를 명확히 하고 싶을 때, 혹은 실수로 다른 타입의 값이 들어가는 것을 막고 싶을 때 사용합니다. 함수의 인자에 타입을 지정하는 방법은 7장과 9장에서 더 자세히 다룹니다.

## 3.2 typeof()로 타입 확인하기

변수나 값의 타입이 궁금할 때는 `typeof()` 함수를 사용합니다.

```julia
julia> typeof(25)
Int64

julia> typeof(175.5)
Float64

julia> typeof("홍길동")
String

julia> typeof(true)
Bool
```

앞으로 이 책에서 새로운 값이나 표현식을 만날 때마다 `typeof()`로 확인해 보는 습관을 들이면 Julia의 타입 시스템을 이해하는 데 큰 도움이 됩니다. 타입 시스템에 대한 본격적인 내용은 9장에서 다룹니다.

## 3.3 기본 자료형

Julia가 기본으로 제공하는 자료형들을 하나씩 살펴보겠습니다.

### 정수형: Int64

정수를 나타내는 기본 타입은 `Int64`입니다. 64비트 시스템에서는 정수 리터럴이 기본적으로 `Int64`로 처리됩니다.

```julia
julia> a = 100
100

julia> typeof(a)
Int64

julia> b = -42
-42

julia> typeof(b)
Int64
```

Julia는 `Int8`, `Int16`, `Int32`, `Int64`, `Int128`처럼 비트 크기가 다른 여러 정수 타입과, 음수를 표현하지 않는 `UInt8`, `UInt16` 등의 부호 없는 정수 타입도 제공합니다. 특별한 이유가 없다면 기본 타입인 `Int64`를 그대로 사용하면 됩니다.

### 실수형: Float64

소수점이 있는 숫자는 `Float64` 타입으로 표현됩니다.

```julia
julia> pi_approx = 3.14159
3.14159

julia> typeof(pi_approx)
Float64
```

정수와 실수를 함께 계산하면 결과는 자동으로 `Float64`가 됩니다.

```julia
julia> 3 + 0.5
3.5

julia> typeof(3 + 0.5)
Float64
```

### 논리형: Bool

`Bool` 타입은 `true`와 `false` 두 값만 가질 수 있으며, 조건문과 반복문에서 핵심적인 역할을 합니다.

```julia
julia> is_ready = true
true

julia> typeof(is_ready)
Bool

julia> 3 > 2
true

julia> typeof(3 > 2)
Bool
```

조건문에 대해서는 5장에서, 반복문에 대해서는 6장에서 자세히 다룹니다.

### 문자열: String

문자열은 큰따옴표(`"`)로 감싸서 표현합니다.

```julia
julia> greeting = "안녕하세요, Julia!"
"안녕하세요, Julia!"

julia> typeof(greeting)
String
```

작은따옴표(`'`)는 문자열이 아니라 다음에 설명할 `Char` 타입에 사용된다는 점에 주의해야 합니다.

여러 줄에 걸친 문자열은 세 개의 큰따옴표(`"""`)로 감쌀 수 있습니다.

```julia
julia> poem = """
       봄이 오면
       꽃이 핀다
       """
"봄이 오면\n꽃이 핀다\n"
```

### 문자: Char

`Char`는 문자 하나를 나타내는 타입으로, 작은따옴표로 감싸서 표현합니다.

```julia
julia> letter = 'A'
'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)

julia> typeof(letter)
Char

julia> hangul_char = '가'
'가': Unicode U+AC00 (category Lo: Letter, other)
```

`String`과 `Char`는 서로 다른 타입이므로 혼동하지 않도록 주의합니다. `"A"`는 `String`이고 `'A'`는 `Char`입니다.

```julia
julia> typeof("A")
String

julia> typeof('A')
Char
```

### Nothing과 nothing

`nothing`은 "값이 없음"을 나타내는 특별한 값으로, 타입은 `Nothing`입니다. 주로 함수가 의미 있는 반환값이 없을 때 사용됩니다.

```julia
julia> result = nothing
julia> typeof(result)
Nothing
```

REPL에서 `nothing`은 출력되지 않는다는 점도 알아 두면 좋습니다. 함수에서 `nothing`을 반환하는 상황은 7장에서 다시 설명합니다.

### Missing과 missing

`missing`은 "값이 존재하지 않거나 알 수 없음"을 나타내는 값으로, 타입은 `Missing`입니다. 통계나 데이터 처리에서 결측값을 표현할 때 주로 사용됩니다.

```julia
julia> score = missing
missing

julia> typeof(score)
Missing
```

`nothing`과 `missing`은 비슷해 보이지만 쓰임새가 다릅니다. `nothing`은 프로그래밍적으로 "값이 없는 상태"를 나타내고, `missing`은 데이터 관점에서 "값을 모른다"는 것을 나타냅니다. 예를 들어 설문조사에서 응답자가 나이를 적지 않았다면 그 값은 `nothing`이 아니라 `missing`으로 표현하는 것이 자연스럽습니다.

`missing`이 포함된 연산 결과는 대부분 `missing`이 됩니다.

```julia
julia> 1 + missing
missing

julia> missing == missing
missing
```

`missing == missing`의 결과조차 `missing`이라는 점이 흥미롭습니다. "알 수 없는 값"과 "알 수 없는 값"이 같은지는 역시 알 수 없다는 논리입니다.

## 3.4 정수와 실수 리터럴

Julia는 다양한 형태의 숫자 리터럴을 지원합니다.

```julia
julia> 1_000_000
1000000
```

밑줄(`_`)을 자릿수 구분자로 사용하면 큰 숫자를 읽기 쉽게 표현할 수 있습니다.

과학적 표기법도 사용할 수 있습니다.

```julia
julia> 1.5e3
1500.0

julia> 2e-2
0.02
```

16진수와 2진수 리터럴도 지원됩니다.

```julia
julia> 0xff
0xff

julia> typeof(0xff)
UInt8

julia> 0b1010
0x0a
```

## 3.5 문자열 보간

문자열 안에 변수의 값이나 표현식의 결과를 끼워 넣고 싶을 때는 **문자열 보간(string interpolation)**을 사용합니다. `$` 기호 뒤에 변수 이름이나 괄호로 감싼 표현식을 쓰면 됩니다.

```julia
julia> x = 5
5

julia> "$x는 $(x+1)보다 작다"
"5는 6보다 작다"
```

변수 하나만 넣을 때는 `$변수이름` 형태로 충분하지만, 연산이 포함된 표현식을 넣을 때는 반드시 괄호로 감싸서 `$(표현식)` 형태로 써야 합니다.

```julia
julia> name = "지민"
"지민"

julia> age = 20

julia> println("$name 님은 올해 $(age)살이고, 내년에는 $(age+1)살이 됩니다.")
지민 님은 올해 20살이고, 내년에는 21살이 됩니다.
```

문자열 보간은 `string()` 함수로 문자열을 이어 붙이는 것보다 훨씬 간결하고 읽기 쉬워서 실무 코드에서도 매우 자주 사용됩니다.

```julia
julia> width = 3
julia> height = 4
julia> println("가로 $width, 세로 $height인 직사각형의 넓이는 $(width*height)입니다.")
가로 3, 세로 4인 직사각형의 넓이는 12입니다.
```

## 3.6 1-based 인덱싱에 대한 짧은 안내

C, Java, Python 등 많은 언어는 배열이나 문자열의 첫 번째 요소를 인덱스 0으로 표현하는 **0-based 인덱싱**을 사용합니다. 반면 Julia는 첫 번째 요소를 인덱스 1로 표현하는 **1-based 인덱싱**을 사용합니다.

문자열에서 간단히 확인해 볼 수 있습니다.

```julia
julia> word = "Julia"
"Julia"

julia> word[1]
'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)

julia> word[5]
'a': ASCII/Unicode U+0061 (category Lu: Letter, uppercase)
```

`word[1]`이 첫 번째 문자인 `'J'`를 가리키는 것을 볼 수 있습니다. 0-based 인덱싱에 익숙한 사람이라면 처음에는 헷갈릴 수 있지만, 수학이나 통계에서 벡터의 첫 원소를 1번째 원소라고 부르는 관습과 일치하기 때문에 익숙해지면 오히려 자연스럽게 느껴집니다. 배열 인덱싱에 대한 자세한 내용은 8장에서 다룹니다.

## 요약

- Julia에서 변수는 `=`로 값을 대입해 만들며, 타입을 미리 선언하지 않아도 값에 따라 자동으로 타입이 정해집니다.
- 원한다면 `x::Int64 = 10`처럼 `::`로 타입을 명시적으로 표기할 수 있으며, 이 경우 다른 타입의 값이 대입되면 오류가 발생하거나 자동 변환이 시도됩니다.
- 기본 자료형으로는 정수 `Int64`, 실수 `Float64`, 논리값 `Bool`, 문자열 `String`, 문자 `Char`, 값 없음을 나타내는 `Nothing`/`nothing`, 결측값을 나타내는 `Missing`/`missing`이 있습니다.
- `typeof()` 함수로 어떤 값의 타입이든 확인할 수 있습니다.
- 숫자 리터럴은 밑줄 구분자, 과학적 표기법, 16진수/2진수 표기 등 다양한 형태로 쓸 수 있습니다.
- 문자열 보간 `"$변수"`, `"$(표현식)"`을 사용하면 문자열 안에 값을 간결하게 끼워 넣을 수 있습니다.
- Julia는 1-based 인덱싱을 사용하므로 첫 번째 요소의 인덱스는 0이 아니라 1입니다. 자세한 내용은 8장에서 다룹니다.
