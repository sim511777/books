# 8장. 배열과 브로드캐스팅

[◀ 이전: 7장. 함수](ch07-함수.md) | [📖 목차](00-목차.md) | [다음: 9장. 타입 시스템 기초 ▶](ch09-타입시스템기초.md)


7장에서 함수로 코드를 재사용하는 방법을 배웠다면, 이번 장에서는 여러 개의 값을 하나로 묶어 다루는 대표적인 자료구조인 **배열(array)**을 자세히 다룹니다. 배열은 데이터 처리, 수치 계산, 통계 등 거의 모든 Julia 프로그램에서 등장하는 핵심 자료구조입니다. 특히 Julia의 배열은 **브로드캐스팅(broadcasting)**이라는 강력한 문법과 결합되어, 반복문 없이도 짧고 빠른 코드를 작성할 수 있게 해줍니다.

## 8.1 배열 리터럴 만들기

배열은 대괄호 `[]` 안에 값을 쉼표로 나열해서 만듭니다.

```julia
numbers = [10, 20, 30, 40, 50]
fruits = ["사과", "바나나", "포도"]
mixed = [1, "둘", 3.0, true]   # 서로 다른 타입을 섞을 수도 있습니다

println(numbers)
println(typeof(numbers))   # Vector{Int64}
println(typeof(fruits))    # Vector{String}
println(typeof(mixed))     # Vector{Any}
```

같은 타입의 값만 넣으면 그 타입에 맞는 배열(`Vector{Int64}`, `Vector{String}` 등)이 만들어지고, 서로 다른 타입을 섞으면 무엇이든 담을 수 있는 `Vector{Any}`가 만들어집니다. `Vector{Any}`는 유연하지만 성능 면에서는 손해를 볼 수 있으므로, 가능하면 같은 타입의 값끼리 배열에 담는 것이 좋습니다(이 내용은 16장 성능 최적화에서 다시 다룹니다).

빈 배열은 `[]`로 만들 수 있지만, 어떤 타입을 담을지 명시하고 싶다면 `Int[]`, `String[]`처럼 타입을 앞에 붙입니다.

```julia
empty1 = []          # Any[]
empty2 = Int[]        # Vector{Int64}, 비어 있음
```

## 8.2 인덱싱: 1부터 시작한다는 것을 꼭 기억하세요

**Julia의 배열 인덱스는 1부터 시작합니다.** 파이썬, C, Java, JavaScript 등 많은 언어에서 인덱스가 0부터 시작하는 것과 다르므로 처음에는 특히 주의가 필요합니다.

```julia
fruits = ["사과", "바나나", "포도", "딸기"]

println(fruits[1])   # 사과  (첫 번째 원소, 0번째가 아닙니다!)
println(fruits[2])   # 바나나
println(fruits[4])   # 딸기
```

파이썬에서 `fruits[0]`으로 접근하던 습관대로 Julia에서 `fruits[0]`을 쓰면 오류가 발생합니다.

```julia
fruits[0]
# ERROR: BoundsError: attempt to access 4-element Vector{String} at index [0]
```

마지막 원소에 접근할 때는 배열의 길이를 나타내는 특별한 키워드 `end`를 사용합니다.

```julia
println(fruits[end])       # 딸기 (마지막 원소)
println(fruits[end - 1])   # 포도 (마지막에서 두 번째)
```

인덱스로 값을 바꿔 넣는 것도 동일한 방식으로 합니다.

```julia
fruits[1] = "오렌지"
println(fruits)   # ["오렌지", "바나나", "포도", "딸기"]
```

> **정리**: Julia는 1-based indexing을 사용합니다. 다른 언어에서 넘어온 경우 배열의 첫 원소는 `arr[1]`, 마지막 원소는 `arr[end]`라는 점을 꼭 기억해 두세요.

## 8.3 슬라이싱

콜론(`:`)을 이용하면 배열의 일부분을 잘라낸 새로운 배열(**슬라이스**)을 얻을 수 있습니다. `arr[시작:끝]`은 시작 인덱스부터 끝 인덱스까지(양 끝 모두 포함)를 의미합니다.

```julia
numbers = [10, 20, 30, 40, 50, 60]

println(numbers[2:4])     # [20, 30, 40]  2번째부터 4번째까지
println(numbers[1:3])     # [10, 20, 30]
println(numbers[4:end])   # [40, 50, 60]  4번째부터 끝까지
println(numbers[:])       # [10, 20, 30, 40, 50, 60]  전체 복사본
```

파이썬의 슬라이싱과 달리 끝 인덱스가 **포함된다**는 점도 함께 기억해 두면 좋습니다. 예를 들어 `numbers[2:4]`는 2, 3, 4번째 원소 세 개를 모두 포함합니다.

`시작:간격:끝` 형태로 일정 간격을 두고 원소를 뽑아낼 수도 있습니다.

```julia
println(numbers[1:2:end])   # [10, 30, 50]  하나씩 건너뛰며 선택
println(numbers[end:-1:1])  # [60, 50, 40, 30, 20, 10]  거꾸로 뒤집기
```

슬라이싱으로 얻은 결과는 원본과 독립된 **새로운 배열**입니다.

```julia
sub = numbers[2:4]
sub[1] = 999
println(sub)       # [999, 30, 40]
println(numbers)   # [10, 20, 30, 40, 50, 60]  원본은 그대로입니다
```

## 8.4 다차원 배열(행렬)

지금까지 다룬 배열은 원소가 한 줄로 늘어선 **벡터(vector)**, 즉 1차원 배열이었습니다. Julia는 행과 열로 이루어진 **행렬(matrix)**, 즉 2차원 배열도 기본적으로 지원합니다.

```julia
matrix = [1 2 3; 4 5 6; 7 8 9]   # 세미콜론으로 행을 구분
println(matrix)
```

```
3×3 Matrix{Int64}:
 1  2  3
 4  5  6
 7  8  9
```

행렬의 원소에 접근할 때는 `행, 열` 순서로 인덱스 두 개를 지정합니다(역시 1부터 시작합니다).

```julia
println(matrix[1, 1])   # 1  (1행 1열)
println(matrix[2, 3])   # 6  (2행 3열)
println(matrix[3, :])   # [7, 8, 9]  3행 전체
println(matrix[:, 1])   # [1, 4, 7]  1열 전체
```

`size` 함수로 행렬의 크기(행 수, 열 수)를 확인할 수 있습니다.

```julia
println(size(matrix))     # (3, 3)
println(size(matrix, 1))  # 3, 행의 개수
println(size(matrix, 2))  # 3, 열의 개수
```

다차원 배열을 다루는 자세한 내용(행렬 연산, 선형대수 등)은 이 책의 범위를 넘어서지만, 초기화할 때 유용한 함수 세 가지는 꼭 알아두면 좋습니다.

```julia
zeros_matrix = zeros(2, 3)    # 2행 3열, 모든 원소가 0.0인 행렬
ones_matrix = ones(3, 2)      # 3행 2열, 모든 원소가 1.0인 행렬
random_matrix = rand(2, 2)    # 2행 2열, 0과 1 사이의 난수로 채워진 행렬

println(zeros_matrix)
println(ones_matrix)
println(random_matrix)
```

`zeros`, `ones`, `rand`는 인자를 하나만 주면 1차원 배열(벡터)을 만들고, 인자를 두 개 주면 2차원 배열(행렬)을 만듭니다.

```julia
zeros(5)      # 길이 5인 벡터, 모두 0.0
ones(4)       # 길이 4인 벡터, 모두 1.0
rand(3)       # 길이 3인 벡터, 0~1 사이의 난수
```

## 8.5 배열 조작 함수들

배열의 크기를 바꾸거나 정렬하는 데 자주 쓰이는 함수들을 살펴보겠습니다. 이 함수들 중 상당수는 앞서 7장에서 배운 `!` 관례를 따릅니다.

```julia
numbers = [3, 1, 4, 1, 5]

println(length(numbers))   # 5, 원소 개수
```

`push!`는 배열의 끝에 원소를 추가하고, `pop!`은 배열의 끝에서 원소를 하나 꺼내면서 제거합니다.

```julia
push!(numbers, 9)
println(numbers)   # [3, 1, 4, 1, 5, 9]

last_value = pop!(numbers)
println(last_value)   # 9
println(numbers)      # [3, 1, 4, 1, 5]
```

`append!`는 다른 배열의 원소들을 통째로 덧붙입니다. 원소 하나를 넣는 `push!`와 달리 배열 자체를 이어 붙인다는 점이 다릅니다.

```julia
a = [1, 2, 3]
b = [4, 5, 6]
append!(a, b)
println(a)   # [1, 2, 3, 4, 5, 6]
println(b)   # [4, 5, 6]  b는 그대로입니다
```

정렬에는 `sort`와 `sort!`가 있습니다. 앞서 배운 관례대로, `sort`는 정렬된 새 배열을 반환하고 원본은 바꾸지 않으며, `sort!`는 원본 배열 자체를 정렬합니다.

```julia
numbers = [3, 1, 4, 1, 5, 9, 2, 6]

sorted_new = sort(numbers)
println(sorted_new)   # [1, 1, 2, 3, 4, 5, 6, 9]
println(numbers)      # [3, 1, 4, 1, 5, 9, 2, 6]  원본 그대로

sort!(numbers)
println(numbers)      # [1, 1, 2, 3, 4, 5, 6, 9]  원본이 정렬됨
```

내림차순으로 정렬하려면 `rev=true` 키워드 인자를 사용합니다.

```julia
println(sort(numbers, rev=true))   # [9, 6, 5, 4, 3, 2, 1, 1]
```

## 8.6 브로드캐스팅: 점(`.`) 하나로 반복문을 대신하기

배열의 모든 원소에 같은 연산을 적용하고 싶을 때, 반복문을 쓰지 않고도 처리할 수 있는 Julia만의 관용적인 문법이 바로 **브로드캐스팅(broadcasting)**입니다. 연산자나 함수 이름 앞뒤에 점(`.`)을 붙이면, 그 연산이 배열의 모든 원소에 대해 하나씩 적용됩니다.

가장 먼저 산술 연산자에 점을 붙이는 경우를 봅시다.

```julia
numbers = [1, 2, 3, 4, 5]

doubled = numbers .* 2
println(doubled)   # [2, 4, 6, 8, 10]

added = numbers .+ 10
println(added)     # [11, 12, 13, 14, 15]

squared = numbers .^ 2
println(squared)   # [1, 4, 9, 16, 25]
```

배열끼리도 같은 위치의 원소끼리 연산을 적용할 수 있습니다(단, 두 배열의 크기가 같아야 합니다).

```julia
a = [1, 2, 3]
b = [10, 20, 30]

println(a .+ b)   # [11, 22, 33]
println(a .* b)   # [10, 40, 90]
```

만약 점을 붙이지 않고 `numbers * 2`처럼 그냥 곱셈 연산자를 쓰면 어떻게 될까요? 배열과 스칼라(하나의 숫자)를 곱하는 것은 선형대수적으로도 자연스러운 연산이라 Julia에서 이 경우는 마침 정상적으로 동작합니다. 하지만 배열끼리의 `+`, `-`는 원소별로 자동 적용되지만, `*`는 벡터/행렬 곱셈으로 해석되기 때문에 크기가 맞지 않으면 오류가 발생합니다. 따라서 "원소별 연산"이라는 의도를 명확히 드러내려면 언제나 점을 붙이는 습관을 들이는 것이 안전합니다.

```julia
a = [1, 2, 3]
b = [10, 20, 30]

# a * b   # ERROR: 벡터끼리는 이런 곱셈이 정의되지 않습니다
println(a .* b)   # [10, 40, 90]  원소별 곱셈은 이렇게 씁니다
```

## 8.7 사용자 정의 함수에 브로드캐스팅 적용하기

브로드캐스팅의 진짜 강력함은 직접 만든 함수에도 그대로 적용된다는 점에 있습니다. 어떤 함수 `f`가 있을 때, `f.(배열)`이라고 쓰면 배열의 각 원소에 `f`를 하나씩 적용한 새 배열을 얻을 수 있습니다.

```julia
square(x) = x^2

numbers = [1, 2, 3, 4, 5]
result = square.(numbers)
println(result)   # [1, 4, 9, 16, 25]
```

`square`는 원래 숫자 하나를 받아 숫자 하나를 돌려주는 함수로 정의했을 뿐, 배열을 처리하도록 특별히 다시 작성하지 않았습니다. 그런데도 `square.(numbers)`라고 점만 붙이면 배열의 모든 원소에 자동으로 적용됩니다. 이것이 브로드캐스팅의 핵심입니다: **함수를 배열용으로 따로 만들 필요 없이, 스칼라 하나를 처리하는 함수를 그대로 배열 전체에 적용할 수 있습니다.**

인자를 여러 개 받는 함수도 마찬가지로 브로드캐스트할 수 있습니다.

```julia
add(x, y) = x + y

a = [1, 2, 3]
b = [10, 20, 30]
println(add.(a, b))   # [11, 22, 33]

# 배열과 스칼라를 함께 브로드캐스트할 수도 있습니다
println(add.(a, 100))   # [101, 102, 103]
```

조건문이 들어간 함수도 그대로 브로드캐스트됩니다.

```julia
function classify(n)
    if n < 0
        "음수"
    elseif n == 0
        "영"
    else
        "양수"
    end
end

numbers = [-3, 0, 5, -1, 8]
println(classify.(numbers))   # ["음수", "영", "양수", "음수", "양수"]
```

여러 개의 점 연산을 한 줄에 연달아 쓰면, Julia는 이를 하나로 **융합(fusion)**해서 중간 배열을 만들지 않고 한 번의 순회로 처리합니다. 예를 들어 `sqrt.(abs.(numbers) .+ 1)`은 배열을 세 번 순회하는 것처럼 보이지만, 실제로는 한 번의 순회 안에서 각 원소마다 `abs`, `+1`, `sqrt`를 연속으로 적용합니다.

```julia
numbers = [-4, 9, -16, 25]
result = sqrt.(abs.(numbers) .+ 1)
println(result)   # [2.23606797749979, 3.1622776601683795, 4.123105625617661, 5.0990195135927845]
```

## 8.8 왜 브로드캐스팅이 중요한 관용구인가

브로드캐스팅 없이 같은 작업을 하려면 다음처럼 반복문을 직접 작성해야 합니다.

```julia
numbers = [1, 2, 3, 4, 5]
result = similar(numbers)   # numbers와 같은 크기, 같은 타입의 빈 배열

for i in eachindex(numbers)
    result[i] = square(numbers[i])
end

println(result)   # [1, 4, 9, 16, 25]
```

이 코드는 정확히 동작하지만, `square.(numbers)` 한 줄에 비해 훨씬 장황합니다. 결과 배열을 미리 만들어야 하고, 인덱스를 신경 써야 하며, "이 반복문이 무엇을 하는지"는 코드를 끝까지 읽어야 알 수 있습니다. 반면 `square.(numbers)`는 "numbers의 각 원소에 square를 적용한다"는 의도를 코드 자체로 곧바로 드러냅니다.

브로드캐스팅이 Julia에서 특히 중요하게 취급되는 이유는 다음 두 가지입니다.

**첫째, 간결함입니다.** 반복문의 상용구(boilerplate)인 결과 배열 초기화, 인덱스 관리, 반복 범위 지정 등을 모두 생략할 수 있습니다. 여러 연산을 점으로 연결하면 데이터 처리 파이프라인을 한두 줄로 표현할 수 있습니다.

**둘째, 성능입니다.** 앞서 살펴본 것처럼 Julia는 연달아 쓰인 점 연산들을 하나로 융합해서, 중간 결과 배열을 여러 개 만들지 않고 단 한 번의 순회로 처리합니다. 게다가 Julia의 반복문 자체도 파이썬 같은 언어와 달리 이미 충분히 빠르기 때문에("반복문을 피해야 빠르다"는 다른 언어의 통념이 Julia에는 그대로 적용되지 않습니다), 브로드캐스팅은 속도를 위한 편법이 아니라 반복문만큼 빠르면서도 훨씬 읽기 쉬운 코드를 만드는 수단입니다.

이런 이유로 Julia 코드에서는 배열의 원소 하나하나에 어떤 연산을 적용해야 할 때, 직접 반복문을 작성하기보다 먼저 브로드캐스팅으로 표현할 수 있는지 생각해보는 것이 자연스러운 습관입니다. 다차원 배열을 다루는 브로드캐스팅의 더 정교한 규칙이나, 반복문과 브로드캐스팅의 성능을 실제로 비교하는 방법은 16장 성능 최적화 기초에서 다시 다룹니다.

## 요약

- 배열은 `[값1, 값2, ...]` 형태로 만들며, 인덱스는 `arr[1]`부터 시작합니다(0이 아닙니다). 마지막 원소는 `arr[end]`로 접근합니다.
- 슬라이싱 `arr[시작:끝]`은 시작과 끝 인덱스를 모두 포함하는 새로운 배열을 만듭니다. `시작:간격:끝`으로 간격을 지정할 수도 있습니다.
- 세미콜론으로 행을 구분해 `[1 2; 3 4]`처럼 행렬(2차원 배열)을 만들 수 있고, `matrix[행, 열]`로 원소에 접근합니다. `zeros`, `ones`, `rand`로 초기화된 배열/행렬을 손쉽게 만들 수 있습니다.
- `push!`, `pop!`, `append!`는 배열의 크기를 바꾸고, `sort`/`sort!`는 각각 새 배열을 반환/원본을 정렬합니다. `!`가 붙은 함수는 원본을 직접 수정한다는 7장의 관례를 그대로 따릅니다.
- 연산자나 함수 이름에 점(`.`)을 붙이면 배열의 모든 원소에 그 연산을 하나씩 적용하는 브로드캐스팅이 이루어집니다(`.+`, `.*`, `f.(배열)`).
- 브로드캐스팅은 반복문의 상용구를 없애 코드를 간결하게 만들고, 연속된 점 연산을 하나로 융합해 효율적으로 처리하는 Julia의 핵심 관용구입니다.

## 연습문제

1. 1부터 10까지의 정수를 담은 벡터를 만들고, 슬라이싱을 이용해 (1) 앞의 5개, (2) 뒤의 5개, (3) 짝수 번째 위치의 원소들만 각각 뽑아 출력해 보세요.
2. `zeros(3, 3)`으로 3×3 영행렬을 만든 다음, 인덱싱을 이용해 대각선 원소(`[1,1]`, `[2,2]`, `[3,3]`)를 모두 1로 바꾸는 코드를 작성해 보세요.
3. 정수 배열을 받아 각 원소가 소수(prime number)인지 아닌지 `true`/`false`로 판별하는 함수 `is_prime(n)`을 작성하고, 브로드캐스팅을 이용해 배열 전체에 대한 결과를 한 번에 구해 보세요.
4. 빈 배열에서 시작해 `push!`로 1부터 5까지의 제곱값을 하나씩 추가한 뒤, `pop!`으로 마지막 값을 꺼내 출력하고, 남은 배열도 출력해 보세요.
5. 섭씨 온도로 이루어진 배열 `celsius = [0, 10, 20, 30, 100]`을 화씨로 변환하는 함수 `to_fahrenheit(c) = c * 9/5 + 32`를 정의하고, 브로드캐스팅을 이용해 배열 전체를 변환한 결과를 반복문을 쓴 코드와 비교해 보세요.
