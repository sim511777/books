# 7장. 함수

[◀ 이전: 6장. 반복문](ch06-반복문.md) | [📖 목차](00-목차.md) | [다음: 8장. 배열과 브로드캐스팅 ▶](ch08-배열과브로드캐스팅.md)


지금까지는 REPL에 한두 줄씩 명령을 입력해가며 Julia의 기본 문법을 익혔습니다. 이제부터는 코드를 재사용 가능한 단위로 묶는 방법, 즉 **함수(function)**를 다룹니다. 함수는 특정 작업을 수행하는 코드 덩어리에 이름을 붙여두고, 필요할 때마다 그 이름을 불러 실행하는 수단입니다. 함수를 잘 쓰는 것은 곧 좋은 Julia 코드를 쓰는 것과 거의 같은 말이라고 해도 지나치지 않습니다.

## 7.1 함수를 정의하는 가장 기본적인 방법

Julia에서 함수를 정의하는 표준적인 형태는 `function` 키워드로 시작해서 `end`로 끝나는 블록입니다.

```julia
function greet(name)
    println("안녕하세요, $(name)님!")
end

greet("철수")
```

```
안녕하세요, 철수님!
```

`function greet(name) ... end` 사이에 있는 코드가 함수의 **본문(body)**입니다. `name`은 함수가 받는 **매개변수(parameter)**이고, `greet("철수")`처럼 함수를 호출할 때 넘기는 `"철수"`는 **인자(argument)**입니다. 이 둘을 구분해서 부르는 습관을 들이면 이후 함수 관련 설명을 읽을 때 훨씬 수월합니다.

함수는 마지막으로 평가된 표현식의 값을 자동으로 반환합니다. `return` 키워드를 명시적으로 쓸 수도 있습니다.

```julia
function square(x)
    return x^2
end

function cube(x)
    x^3   # return을 생략해도 마지막 값이 반환값이 됩니다
end

println(square(5))   # 25
println(cube(3))     # 27
```

일반적으로 함수 안에서 조건에 따라 일찍 빠져나가야 할 때는 `return`을 명시하고, 함수 끝에서 자연스럽게 값을 내놓을 때는 생략하는 것이 관례입니다.

```julia
function abs_value(x)
    if x < 0
        return -x
    end
    x
end

println(abs_value(-7))   # 7
println(abs_value(7))    # 7
```

값을 아무것도 반환하지 않는 함수는 `nothing`을 반환합니다. 화면에 무언가를 출력하기만 하는 `greet` 같은 함수가 대표적인 예입니다.

## 7.2 한 줄 함수 정의

함수 본문이 표현식 하나로 끝나는 간단한 경우에는 수학 함수를 쓰듯이 한 줄로 정의할 수 있습니다.

```julia
square(x) = x^2
add(x, y) = x + y
is_even(n) = n % 2 == 0

println(square(6))       # 36
println(add(3, 4))       # 7
println(is_even(10))     # true
```

이 문법은 `function ... end`로 쓴 것과 완전히 동일하게 동작하며, 단지 문법적으로 더 짧을 뿐입니다. 함수의 로직이 한 줄로 표현될 만큼 단순할 때 즐겨 사용하고, 본문이 여러 줄로 늘어나면 `function ... end` 형태로 바꾸는 것이 가독성 면에서 좋습니다.

## 7.3 여러 값을 반환하는 함수

Julia 함수는 여러 개의 값을 한 번에 반환할 수 있습니다. 내부적으로는 튜플(자세한 내용은 12장에서 다룹니다)로 값을 묶어서 반환하는 방식입니다.

```julia
function min_max(numbers)
    return minimum(numbers), maximum(numbers)
end

result = min_max([3, 1, 4, 1, 5, 9, 2, 6])
println(result)          # (1, 9)
println(typeof(result))  # Tuple{Int64, Int64}
```

반환된 튜플은 **구조분해 대입(destructuring assignment)**을 이용해 각각의 변수로 바로 받을 수 있습니다.

```julia
lo, hi = min_max([3, 1, 4, 1, 5, 9, 2, 6])
println("최솟값: $(lo), 최댓값: $(hi)")
```

```
최솟값: 1, 최댓값: 9
```

값이 세 개 이상이어도 동일하게 동작합니다.

```julia
function stats(numbers)
    return minimum(numbers), maximum(numbers), sum(numbers) / length(numbers)
end

lo, hi, avg = stats([2, 4, 6, 8])
println("최소=$(lo), 최대=$(hi), 평균=$(avg)")
```

```
최소=2, 최대=8, 평균=5.0
```

필요 없는 값은 밑줄 `_`로 받아서 무시할 수 있습니다.

```julia
_, hi, _ = stats([2, 4, 6, 8])
println(hi)   # 8
```

## 7.4 선택적 인자(기본값이 있는 인자)

함수를 정의할 때 매개변수에 기본값을 지정해두면, 호출할 때 그 인자를 생략할 수 있습니다. 이런 인자를 **선택적 인자(optional argument)**라고 부릅니다.

```julia
function power(base, exponent=2)
    base^exponent
end

println(power(3))       # 9  (exponent 생략 -> 기본값 2 사용)
println(power(3, 3))    # 27 (exponent를 3으로 지정)
```

기본값이 있는 매개변수는 기본값이 없는 매개변수보다 뒤에 와야 합니다. 여러 개의 선택적 인자를 둘 수도 있습니다.

```julia
function greet2(name, greeting="안녕하세요", punctuation="!")
    println("$(greeting), $(name)$(punctuation)")
end

greet2("영희")                     # 안녕하세요, 영희!
greet2("영희", "반갑습니다")        # 반갑습니다, 영희!
greet2("영희", "반갑습니다", "~")   # 반갑습니다, 영희~
```

## 7.5 키워드 인자

매개변수 목록에서 세미콜론(`;`) 뒤에 오는 인자는 **키워드 인자(keyword argument)**가 됩니다. 키워드 인자는 위치가 아니라 이름으로 값을 전달합니다.

```julia
function make_box(width, height; color="black", filled=false)
    println("가로=$(width), 세로=$(height), 색=$(color), 채움=$(filled)")
end

make_box(10, 20)
make_box(10, 20, color="red")
make_box(10, 20, color="blue", filled=true)
```

```
가로=10, 세로=20, 색=black, 채움=false
가로=10, 세로=20, 색=red, 채움=false
가로=10, 세로=20, 색=blue, 채움=true
```

`width`와 `height`는 순서대로 값을 전달하는 **위치 인자(positional argument)**이고, `color`와 `filled`는 반드시 `이름=값` 형태로 전달해야 하는 키워드 인자입니다. 순서를 바꿔서 `make_box(10, 20, filled=true, color="blue")`처럼 호출해도 문제없이 동작합니다. 키워드 인자의 순서는 중요하지 않기 때문입니다.

선택적 인자와 키워드 인자는 비슷해 보이지만 목적이 다릅니다. 선택적 인자는 함수의 핵심 동작에 관여하면서 순서로 구분되는 값에, 키워드 인자는 함수의 부가적인 옵션을 이름으로 명확히 밝히고 싶을 때 사용합니다. 인자가 여러 개인 함수를 만들 때, 이름 없이 순서만으로는 헷갈리기 쉬운 옵션들은 키워드 인자로 두는 것이 코드를 읽는 사람을 배려하는 방법입니다.

## 7.6 익명 함수

이름을 붙이지 않고 그 자리에서 바로 만들어 쓰는 함수를 **익명 함수(anonymous function)**라고 합니다. `매개변수 -> 표현식` 형태로 작성합니다.

```julia
square_anon = x -> x^2
println(square_anon(5))   # 25

println((x -> x^2)(7))    # 49, 정의하자마자 바로 호출
```

익명 함수는 다른 함수에 "잠깐 쓰고 버릴" 동작을 넘겨줄 때 특히 유용합니다. 예를 들어 `map`, `filter` 같은 고차 함수(함수를 인자로 받는 함수)와 함께 자주 쓰입니다.

```julia
numbers = [1, 2, 3, 4, 5]

squared = map(x -> x^2, numbers)
println(squared)          # [1, 4, 9, 16, 25]

evens = filter(x -> x % 2 == 0, numbers)
println(evens)            # [2, 4]
```

인자가 여러 개인 익명 함수는 괄호로 묶어서 작성합니다.

```julia
add_anon = (x, y) -> x + y
println(add_anon(3, 4))   # 7
```

## 7.7 파이프 연산자로 함수 체이닝하기

`|>`는 **파이프 연산자(pipe operator)**로, 왼쪽 값을 오른쪽 함수의 인자로 넘겨주는 역할을 합니다. `f(x)` 대신 `x |> f`라고 쓸 수 있습니다.

```julia
println(5 |> square)      # 25, square(5)와 동일
```

파이프 연산자의 진가는 여러 함수를 연속으로 적용할 때 드러납니다. 다음 두 코드는 완전히 같은 결과를 내지만, 파이프를 사용한 쪽이 "데이터가 처리되는 순서"를 왼쪽에서 오른쪽으로 그대로 읽을 수 있어 더 직관적입니다.

```julia
numbers = [-5, 3, -2, 8, -1]

# 중첩 호출 방식: 안쪽부터 읽어야 해서 순서를 파악하기 어렵습니다
result1 = sum(map(abs, numbers))

# 파이프 방식: 왼쪽에서 오른쪽으로 순서대로 읽힙니다
result2 = numbers |> x -> map(abs, x) |> sum

println(result1)   # 19
println(result2)   # 19
```

익명 함수와 함께 파이프를 연결하면 여러 단계의 데이터 처리를 하나의 흐름으로 표현할 수 있습니다.

```julia
result = [1, 2, 3, 4, 5, 6] |>
    x -> filter(is_even, x) |>
    x -> map(square, x) |>
    sum

println(result)   # 4 + 16 + 36 = 56
```

## 7.8 이름 관례: 함수 이름 끝의 `!`

Julia 표준 라이브러리를 보면 `push!`, `pop!`, `sort!`처럼 이름 끝에 느낌표(`!`)가 붙은 함수를 자주 만나게 됩니다. 이 느낌표는 문법적으로 특별한 의미를 가지는 것이 아니라(그냥 함수 이름의 일부일 뿐입니다), **이 함수가 인자로 받은 값을 그 자리에서 변경한다**는 것을 알려주는 Julia 커뮤니티의 강력한 관례입니다.

```julia
numbers = [3, 1, 4, 1, 5]

sorted_copy = sort(numbers)
println(sorted_copy)   # [1, 1, 3, 4, 5]
println(numbers)       # [3, 1, 4, 1, 5]  -> 원본은 그대로입니다

sort!(numbers)
println(numbers)       # [1, 1, 3, 4, 5]  -> 원본 자체가 정렬되었습니다
```

`sort`는 정렬된 **새 배열**을 만들어 반환하고 원본 `numbers`는 건드리지 않는 반면, `sort!`는 원본 배열의 내용을 직접 뒤바꿔서 정렬합니다. 배열에 원소를 추가하는 `push!`도 마찬가지입니다.

```julia
fruits = ["사과", "바나나"]
push!(fruits, "포도")
println(fruits)   # ["사과", "바나나", "포도"]
```

직접 함수를 만들 때도 이 관례를 따르는 것이 좋습니다. 인자를 변경하지 않고 새 값을 반환하는 함수는 평범한 이름을, 인자를 직접 변경하는 함수는 끝에 `!`를 붙인 이름을 사용하세요.

```julia
function double_values(arr)
    return [x * 2 for x in arr]   # 새 배열을 만들어 반환
end

function double_values!(arr)
    for i in eachindex(arr)
        arr[i] *= 2                # 원본 배열을 직접 수정
    end
    return arr
end

a = [1, 2, 3]
b = double_values(a)
println(a)   # [1, 2, 3]  변화 없음
println(b)   # [2, 4, 6]

double_values!(a)
println(a)   # [2, 4, 6]  원본이 바뀜
```

이 규칙 덕분에 코드를 읽는 사람은 함수 이름만 보고도 "이 함수를 호출하면 내가 넘긴 값이 바뀔 수 있겠구나"라고 미리 짐작할 수 있습니다. 배열을 다루는 다양한 `!` 함수들은 8장에서 더 자세히 살펴봅니다.

## 7.9 다중 디스패치 살짝 맛보기

Julia에서는 같은 이름의 함수를 인자의 **타입**에 따라 여러 버전으로 정의할 수 있습니다. 예를 들어 정수를 받았을 때와 문자열을 받았을 때 다르게 동작하는 `describe`라는 함수를 만들어 보겠습니다.

```julia
describe(x::Int) = println("$(x)는 정수입니다.")
describe(x::String) = println("\"$(x)\"는 문자열입니다.")
describe(x::Float64) = println("$(x)는 실수입니다.")

describe(42)        # 42는 정수입니다.
describe("hello")   # "hello"는 문자열입니다.
describe(3.14)       # 3.14는 실수입니다.
```

같은 이름 `describe`로 정의된 세 함수 중, Julia는 호출 시점에 실제로 넘어온 인자의 타입을 보고 그에 맞는 버전을 자동으로 선택해서 실행합니다. 이렇게 하나의 함수 이름 아래 타입별로 서로 다른 동작을 정의하고, 호출 시점에 가장 적합한 것을 골라 실행하는 방식을 **다중 디스패치(multiple dispatch)**라고 합니다. 여러분이 지금까지 사용해 온 `+`, `*`, `println` 같은 함수들도 사실은 내부적으로 숫자, 문자열, 배열 등 다양한 타입에 대해 각각 정의된 다중 디스패치 함수입니다. 다중 디스패치는 Julia 언어를 이해하는 데 있어 핵심적인 개념이며, 자세한 원리와 활용법은 10장에서 본격적으로 다룹니다.

## 요약

- 함수는 `function 이름(매개변수) ... end` 형태로 정의하며, 본문의 마지막 표현식 값이 자동으로 반환됩니다. `return`으로 명시적으로 반환할 수도 있습니다.
- 본문이 한 줄인 함수는 `이름(매개변수) = 표현식` 형태로 짧게 정의할 수 있습니다.
- 함수는 여러 값을 튜플로 묶어 반환할 수 있고, 호출하는 쪽에서는 `a, b = f(x)`처럼 구조분해 대입으로 받을 수 있습니다.
- 매개변수에 기본값을 지정하면 선택적 인자가 되어 호출 시 생략할 수 있습니다.
- 매개변수 목록에서 `;` 뒤에 오는 인자는 키워드 인자가 되며, 이름으로 값을 전달합니다.
- `매개변수 -> 표현식` 형태로 익명 함수를 만들 수 있으며, `map`, `filter` 같은 고차 함수와 함께 자주 쓰입니다.
- 파이프 연산자 `|>`는 왼쪽 값을 오른쪽 함수에 넘겨 여러 함수를 순서대로 연결(체이닝)할 때 코드를 읽기 쉽게 만들어 줍니다.
- 이름 끝에 `!`가 붙은 함수(`push!`, `sort!` 등)는 인자로 받은 값을 그 자리에서 직접 변경한다는 관례를 나타냅니다. 직접 함수를 작성할 때도 이 관례를 따르는 것이 좋습니다.
- 같은 이름의 함수를 인자 타입별로 여러 개 정의하고 호출 시점에 적합한 버전이 선택되는 것을 다중 디스패치라고 하며, 자세한 내용은 10장에서 다룹니다.

4. 배열의 원소들을 각각 두 배로 만드는 함수를, 원본을 바꾸지 않는 버전(`triple` 이름)과 원본을 직접 바꾸는 버전(`triple!` 이름)으로 각각 작성하고, 두 버전을 호출한 뒤 원본 배열이 어떻게 다른지 확인해 보세요.
5. 인자로 정수를 받으면 `"짝수"`/`"홀수"`를 판별해 출력하고, 문자열을 받으면 그 길이를 출력하는 `check` 함수를 다중 디스패치를 이용해 두 개의 메서드로 작성해 보세요.
