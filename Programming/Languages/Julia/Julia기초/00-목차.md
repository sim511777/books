# Julia 기초부터 응용까지

[다음: 1장. Julia란 무엇인가 ▶](ch01-Julia란무엇인가.md)

프로그래밍을 처음 접하는 사람과 다른 언어 경험자를 모두 아우르는 Julia 입문서입니다.
변수와 자료형 같은 기초 문법부터 Julia의 정체성이라 할 수 있는 타입 시스템과 다중 디스패치,
매크로, 성능 최적화, 병렬 프로그래밍까지 순서대로 다룹니다.

각 장은 개념 설명, 실행 예시, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는 이해를 돕는
다이어그램을 함께 실었습니다.
