# 8장. 배열과 해시

[◀ 이전: 7장. 메서드](ch07-메서드.md) | [📖 목차](00-목차.md) | [다음: 9장. 클래스와 객체 ▶](ch09-클래스와객체.md)


프로그램이 다루는 데이터는 대부분 하나가 아니라 여러 개입니다. 학생들의 성적, 장바구니에 담긴 상품, 도시별 인구수처럼 여러 값을 한데 묶어서 다뤄야 하는 경우가 훨씬 많습니다. Ruby는 이런 상황을 위해 **배열(Array)**과 **해시(Hash)**라는 두 가지 대표적인 컬렉션(collection) 자료 구조를 제공합니다.

배열은 값들을 순서대로 나열한 목록이고, 해시는 키(key)와 값(value)을 짝지어 저장하는 사전 같은 구조입니다. 이번 장에서는 두 자료 구조의 기본 사용법을 익히고, 이를 조합해서 간단한 성적부를 관리하는 예제까지 만들어 봅니다.

## 배열 리터럴

배열은 대괄호 `[]` 안에 값을 쉼표로 나열해서 만듭니다.

```ruby
numbers = [10, 20, 30, 40, 50]
fruits = ["사과", "바나나", "포도"]
mixed = [1, "둘", 3.0, true, nil]
```

배열에는 서로 다른 자료형의 값을 섞어 담을 수도 있습니다. `mixed`처럼 정수, 문자열, 실수, 불리언, `nil`이 한 배열에 함께 들어가는 것도 문법적으로는 아무 문제가 없습니다. 다만 실무에서는 같은 종류의 값을 담는 것이 코드를 이해하기 쉽게 만듭니다.

빈 배열은 `[]`로 만들 수 있습니다.

```ruby
empty = []
puts empty.length  # => 0
```

## 인덱싱

배열의 각 요소는 0부터 시작하는 **인덱스(index)**로 접근합니다.

```ruby
fruits = ["사과", "바나나", "포도"]

puts fruits[0]  # => 사과
puts fruits[1]  # => 바나나
puts fruits[2]  # => 포도
puts fruits[3]  # => nil (범위를 벗어나면 nil)
```

Ruby는 **음수 인덱스**도 지원합니다. `-1`은 마지막 요소, `-2`는 뒤에서 두 번째 요소를 가리킵니다.

```ruby
puts fruits[-1]  # => 포도 (마지막 요소)
puts fruits[-2]  # => 바나나
puts fruits[-4]  # => nil (범위를 벗어남)
```

음수 인덱스는 배열의 길이를 몰라도 "맨 뒤에서 몇 번째"라는 표현을 간결하게 할 수 있어서 자주 쓰입니다. 예를 들어 배열의 마지막 요소를 얻고 싶을 때 `fruits[fruits.length - 1]`이라고 쓰는 대신 `fruits[-1]`이라고 쓸 수 있습니다.

인덱스로 값을 대입하면 해당 위치의 요소가 바뀝니다.

```ruby
fruits[1] = "딸기"
puts fruits.inspect  # => ["사과", "딸기", "포도"]
```

## 슬라이싱

배열의 일부분을 잘라내는 것을 **슬라이싱(slicing)**이라고 합니다. `시작 인덱스, 길이` 형태나 `범위(Range)`를 사용합니다.

```ruby
numbers = [10, 20, 30, 40, 50]

puts numbers[1, 3].inspect    # => [20, 30, 40] (인덱스 1부터 3개)
puts numbers[0..2].inspect    # => [10, 20, 30] (인덱스 0부터 2까지, 끝 포함)
puts numbers[0...2].inspect   # => [10, 20]     (인덱스 0부터 2 미만까지, 끝 제외)
puts numbers[2..-1].inspect   # => [30, 40, 50] (인덱스 2부터 끝까지)
puts numbers[-2..-1].inspect  # => [40, 50]     (뒤에서 두 개)
```

`..`은 끝 인덱스를 포함하는 범위이고, `...`은 끝 인덱스를 포함하지 않는 범위입니다. 이 둘을 헷갈리면 요소가 하나 더 많거나 적게 잘리는 실수를 하기 쉬우므로 주의해야 합니다. 범위 안에 음수 인덱스를 섞어 쓸 수도 있다는 점도 함께 기억해 두면 유용합니다.

## 배열에 요소 추가/제거하기

배열은 크기가 고정되지 않아서, 언제든지 요소를 추가하거나 제거할 수 있습니다.

```ruby
stack = [1, 2, 3]

stack.push(4)       # 맨 뒤에 추가
puts stack.inspect  # => [1, 2, 3, 4]

stack << 5           # push와 동일한 기능, 연산자 형태
puts stack.inspect   # => [1, 2, 3, 4, 5]

last = stack.pop     # 맨 뒤 요소를 제거하고 반환
puts last            # => 5
puts stack.inspect   # => [1, 2, 3, 4]

first = stack.shift  # 맨 앞 요소를 제거하고 반환
puts first           # => 1
puts stack.inspect   # => [2, 3, 4]

stack.unshift(0)     # 맨 앞에 추가
puts stack.inspect   # => [0, 2, 3, 4]
```

이 네 가지 메서드의 역할을 정리하면 다음과 같습니다.

| 메서드 | 동작 | 위치 |
|---|---|---|
| `push` (또는 `<<`) | 요소 추가 | 맨 뒤 |
| `pop` | 요소 제거 후 반환 | 맨 뒤 |
| `unshift` | 요소 추가 | 맨 앞 |
| `shift` | 요소 제거 후 반환 | 맨 앞 |

`push`와 `pop`을 이용하면 배열을 **스택(stack, 후입선출)**처럼, `push`와 `shift`를 이용하면 **큐(queue, 선입선출)**처럼 사용할 수 있습니다.

`<<`는 `push`의 축약된 연산자 형태로, 여러 번 연결해서 쓸 수도 있습니다.

```ruby
queue = []
queue << "첫번째" << "두번째" << "세번째"
puts queue.inspect  # => ["첫번째", "두번째", "세번째"]
```

## 배열 안에 값이 있는지 확인하기

`include?` 메서드는 배열 안에 특정 값이 존재하는지 `true`/`false`로 알려줍니다. 7장에서 배운 것처럼 이름이 `?`로 끝나는 것에서 불리언을 반환한다는 것을 짐작할 수 있습니다.

```ruby
fruits = ["사과", "바나나", "포도"]

puts fruits.include?("바나나")  # => true
puts fruits.include?("수박")    # => false
```

## 정렬과 중복 제거

`sort`는 배열을 정렬한 새로운 배열을 반환합니다. 문자열 배열은 사전순으로, 숫자 배열은 크기순으로 정렬됩니다.

```ruby
numbers = [5, 3, 1, 4, 2]
puts numbers.sort.inspect   # => [1, 2, 3, 4, 5]
puts numbers.inspect        # => [5, 3, 1, 4, 2] (원본 유지)

names = ["철수", "영희", "민수"]
puts names.sort.inspect     # => ["민수", "영희", "철수"]
```

`sort`는 원본을 바꾸지 않고 정렬된 새 배열을 반환합니다. 원본 자체를 정렬하고 싶다면 7장에서 배운 관례에 따라 `sort!`를 사용합니다.

```ruby
numbers = [5, 3, 1, 4, 2]
numbers.sort!
puts numbers.inspect  # => [1, 2, 3, 4, 5] (원본이 정렬됨)
```

`uniq`는 중복된 요소를 제거한 새로운 배열을 반환합니다.

```ruby
scores = [90, 85, 90, 100, 85, 70]
puts scores.uniq.inspect  # => [90, 85, 100, 70]
```

`uniq` 역시 `uniq!`라는 파괴적 버전을 가지고 있습니다.

## 해시 리터럴

해시는 키와 값을 짝지어 저장하는 자료 구조로, 중괄호 `{}`를 사용합니다. 가장 기본적인 형태는 `=>` 기호로 키와 값을 연결하는 것입니다.

```ruby
scores = { "국어" => 90, "영어" => 85, "수학" => 100 }

puts scores["국어"]  # => 90
puts scores["영어"]  # => 85
```

키가 심볼(symbol)일 때는 더 짧은 축약형 문법을 사용할 수 있습니다. 심볼은 13장에서 자세히 다루지만, 지금은 `:이름`처럼 콜론이 붙은, 문자열과 비슷하지만 더 가벼운 식별자 정도로 이해하면 됩니다.

```ruby
# 심볼 키를 사용한 전통적인 방식
person = { :name => "지민", :age => 25 }

# 축약형 (실무에서 훨씬 널리 쓰인다)
person = { name: "지민", age: 25 }

puts person[:name]  # => 지민
puts person[:age]   # => 25
```

`key: value` 형태는 `:key => value`와 완전히 같은 의미이며, 7장에서 배운 키워드 인자(`name:`, `age:`)와 표기가 비슷한 것도 우연이 아닙니다. 실제로 메서드에 해시를 전달할 때 이 문법이 자연스럽게 연결됩니다.

존재하지 않는 키로 접근하면 `nil`이 반환됩니다.

```ruby
puts person[:city]  # => nil
```

키에 값을 대입하면 새로운 항목이 추가되거나 기존 항목이 갱신됩니다.

```ruby
person[:city] = "서울"
puts person.inspect  # => {:name=>"지민", :age=>25, :city=>"서울"}

person[:age] = 26
puts person.inspect  # => {:name=>"지민", :age=>26, :city=>"서울"}
```

## 해시 순회

해시의 모든 항목을 하나씩 처리할 때는 `each`를 사용합니다.

```ruby
person = { name: "지민", age: 25, city: "서울" }

person.each do |key, value|
  puts "#{key}: #{value}"
end
# => name: 지민
# => age: 25
# => city: 서울
```

`each`에 넘기는 블록은 키와 값을 순서대로 두 개의 매개변수로 받습니다. 블록에 대해서는 11장에서 본격적으로 다루지만, 지금은 `do`~`end` 사이의 코드가 해시의 각 항목마다 한 번씩 실행된다고 이해하면 충분합니다.

키만 필요하거나 값만 필요할 때는 `keys`와 `values`를 사용합니다.

```ruby
puts person.keys.inspect    # => [:name, :age, :city]
puts person.values.inspect  # => ["지민", 25, "서울"]
```

`keys`와 `values`는 각각 키와 값만 모아 배열로 반환하므로, 배열에서 배운 메서드들을 그대로 활용할 수 있습니다.

```ruby
if person.keys.include?(:age)
  puts "나이 정보가 있습니다"
end
```

## 배열과 해시를 함께 다루기: 간단한 성적부

배열과 해시는 함께 사용될 때 진가를 발휘합니다. 여러 학생의 정보를 각각 해시로 표현하고, 그 해시들을 배열에 담으면 하나의 성적부를 표현할 수 있습니다.

```ruby
students = [
  { name: "민준", scores: [90, 85, 100] },
  { name: "서연", scores: [70, 95, 80] },
  { name: "하준", scores: [100, 100, 90] }
]
```

`students`는 배열이고, 그 안의 각 요소는 이름과 점수 목록을 담은 해시입니다. 이 구조를 활용해서 각 학생의 평균 점수를 계산하고 출력하는 프로그램을 만들어 보겠습니다.

```ruby
def average(scores)
  total = 0
  scores.each { |score| total += score }
  total / scores.length.to_f
end

students.each do |student|
  avg = average(student[:scores])
  puts "#{student[:name]}의 평균 점수: #{avg.round(1)}점"
end
# => 민준의 평균 점수: 91.7점
# => 서연의 평균 점수: 81.7점
# => 하준의 평균 점수: 96.7점
```

전체 학생 중 평균이 가장 높은 학생을 찾아보는 것도 배열과 해시, 그리고 앞서 배운 메서드 정의를 조합하면 어렵지 않습니다.

```ruby
def top_student(students)
  best = nil
  best_avg = -1

  students.each do |student|
    avg = average(student[:scores])
    if avg > best_avg
      best = student
      best_avg = avg
    end
  end

  best
end

winner = top_student(students)
puts "1등: #{winner[:name]} (평균 #{average(winner[:scores]).round(1)}점)"
# => 1등: 하준 (평균 96.7점)
```

특정 과목(예를 들어 각 학생의 첫 번째 시험) 점수만 모아서 정렬하거나 중복을 제거하는 것도 이미 배운 메서드로 충분히 가능합니다.

```ruby
first_exam_scores = students.map { |student| student[:scores][0] }
puts first_exam_scores.inspect        # => [90, 70, 100]
puts first_exam_scores.sort.inspect   # => [70, 90, 100]
```

여기서 사용한 `map`이라는 메서드가 낯설게 느껴질 수 있습니다. `map`은 배열의 각 요소를 원하는 형태로 변환한 새 배열을 만들어주는 메서드로, `each`와 함께 Ruby에서 매우 자주 쓰입니다. 이처럼 배열이나 해시의 요소를 순회하면서 변환하거나(`map`), 조건에 맞는 것만 골라내거나(`select`), 하나의 값으로 누적시키는(`reduce`) 함수형 스타일의 메서드들은 12장 이터레이터와 Enumerable에서 본격적으로 다룹니다. 지금은 배열과 해시라는 그릇 자체의 구조와 기본 조작법을 익히는 데 집중하면 충분합니다.

## 요약

- 배열은 `[]`로 만들며, 순서가 있는 값의 목록이다. 인덱스는 0부터 시작하고, 음수 인덱스는 뒤에서부터 센다(`-1`은 마지막 요소).
- 슬라이싱은 `array[시작, 길이]`나 `array[범위]` 형태로 사용하며, `..`은 끝 인덱스를 포함하고 `...`은 포함하지 않는다.
- `push`/`<<`, `pop`, `shift`, `unshift`로 배열의 앞뒤에 요소를 추가하거나 제거할 수 있다.
- `include?`는 값의 존재 여부를, `sort`는 정렬된 새 배열을, `uniq`는 중복이 제거된 새 배열을 반환한다. 원본을 직접 바꾸려면 `sort!`, `uniq!`처럼 `!`가 붙은 버전을 사용한다.
- 해시는 `{}`로 만들며, 키와 값을 짝지어 저장한다. 심볼 키는 `key: value` 축약형으로 편리하게 표현할 수 있다.
- `each`로 해시를 순회하고, `keys`와 `values`로 키 또는 값만 배열로 뽑아낼 수 있다.
- 해시를 배열에 담으면 여러 레코드를 표현하는 간단한 데이터 구조(예: 성적부)를 만들 수 있다.
- `map`, `select`, `reduce` 같은 함수형 스타일의 메서드는 12장에서 더 깊이 다룬다.

2. 배열 `[10, 20, 30, 40, 50, 60]`에서 슬라이싱을 이용해 `[30, 40, 50]`만 잘라내는 두 가지 방법(`..`을 쓰는 방법과 `...`을 쓰는 방법)을 각각 작성하세요.
3. 빈 배열에서 시작해서 `push`(또는 `<<`)로 좋아하는 음식 3가지를 추가한 뒤, `pop`으로 마지막 항목을 꺼내 출력하는 코드를 작성하세요.
4. 심볼 키 축약형을 사용해 `title`, `author`, `price` 정보를 담은 책 해시를 만들고, `each`를 이용해 `"title: ..."` 형태로 모든 항목을 출력하세요.
5. 이번 장의 `students` 예제를 참고하여, 이름과 나이(`age`)를 가진 학생 4명의 배열을 만들고, 그중 나이가 가장 많은 학생의 이름을 출력하는 프로그램을 작성하세요.
