## Ruby 설치하기

2장에서 Ruby를 처음 설치하고 실행 환경을 갖췄지만, 운영체제나 상황에 따라 설치 방법이 조금씩 달라질 수 있습니다. 여기서는 플랫폼별 설치 방법을 조금 더 폭넓게 정리합니다.

### Windows

Windows에서 가장 간단한 방법은 **RubyInstaller**(공식 인스톨러)를 사용하는 것입니다. RubyInstaller 웹사이트에서 설치 파일을 내려받아 실행하면, Ruby 본체는 물론 대부분의 gem을 설치하는 데 필요한 빌드 도구(MSYS2 등)까지 함께 설정할 수 있습니다. 설치 마법사의 안내를 따라가면서 "MSYS2 and development toolchain 추가" 옵션을 선택해두면 이후 gem을 설치할 때 발생할 수 있는 문제를 줄일 수 있습니다.

설치가 끝나면 명령 프롬프트나 PowerShell에서 다음 명령으로 정상 설치를 확인합니다.

```bash
ruby -v
gem -v
```

### macOS

macOS에는 시스템 Ruby가 기본으로 들어 있는 경우가 많지만, 버전이 오래되었거나 시스템 영역을 직접 건드리는 것이 부담스러울 수 있어 별도의 Ruby를 설치해 사용하는 것이 일반적입니다. Homebrew 패키지 관리자를 사용해 다음과 같이 설치할 수 있습니다.

```bash
brew install ruby
```

또는 아래에서 소개할 rbenv 같은 버전 관리 도구를 통해 설치하는 방법도 널리 쓰입니다.

### Linux

대부분의 Linux 배포판은 패키지 관리자를 통해 Ruby를 제공합니다. 예를 들어 Ubuntu/Debian 계열에서는 다음과 같이 설치할 수 있습니다.

```bash
sudo apt update
sudo apt install ruby-full
```

다만 배포판의 공식 저장소에 포함된 Ruby 버전은 최신 버전보다 오래된 경우가 많으므로, 특정 버전을 정확히 맞춰 쓰고 싶다면 rbenv나 rvm 같은 버전 관리 도구를 함께 사용하는 것이 좋습니다.

### rbenv와 rvm: 여러 버전의 Ruby 관리하기

실무에서는 프로젝트마다 요구하는 Ruby 버전이 다른 경우가 흔합니다. 이런 상황을 위해 한 컴퓨터에 여러 버전의 Ruby를 설치해두고, 프로젝트별로 필요한 버전을 손쉽게 전환할 수 있게 해주는 **버전 관리 도구**들이 있습니다.

**rbenv**는 가볍고 단순한 구조를 지향하는 Ruby 버전 관리 도구입니다. 설치 후 원하는 버전을 설치하고 전역 또는 프로젝트 단위로 지정할 수 있습니다.

```bash
rbenv install 3.3.0
rbenv global 3.3.0      # 시스템 전체 기본 버전 지정
rbenv local 3.2.0       # 현재 프로젝트 폴더에서만 사용할 버전 지정
```

`rbenv local`을 실행하면 해당 폴더에 `.ruby-version`이라는 파일이 생기는데, 이 폴더 안에서 Ruby 명령을 실행할 때마다 rbenv가 이 파일을 확인해 자동으로 알맞은 버전으로 전환해줍니다.

**rvm**(Ruby Version Manager)은 rbenv보다 먼저 등장한 오래된 버전 관리 도구로, 버전 관리에 더해 격리된 gem 환경(gemset)까지 함께 관리해주는 등 더 많은 기능을 제공합니다.

```bash
rvm install 3.3.0
rvm use 3.3.0
```

rbenv와 rvm 중 어느 쪽을 선택해도 목적(여러 버전의 Ruby를 프로젝트별로 관리하는 것)은 같으므로, 처음 접한다면 상대적으로 구조가 단순한 rbenv부터 시작해보는 것도 좋은 방법입니다.

## 이 책에서 사용한 주요 메서드/키워드 요약

이 책 전반에서 등장한 핵심 키워드와 메서드를 장별로 간단히 정리했습니다. 각 항목의 자세한 설명은 해당 장을 참고하세요.

| 구분 | 이름 | 설명 | 관련 장 |
|---|---|---|---|
| 키워드 | `if` / `elsif` / `else` | 조건에 따라 분기 실행 | 5장 |
| 키워드 | `unless` | 부정 조건 분기 | 5장, 18장 |
| 키워드 | `case` / `when` | 여러 값에 대한 다중 분기 | 5장 |
| 키워드 | `while` / `until` | 조건이 참(또는 거짓)인 동안 반복 | 6장, 18장 |
| 메서드 | `times` / `each` / `upto` / `downto` | 정해진 횟수 또는 범위만큼 반복 | 6장, 12장 |
| 키워드 | `def` / `end` | 메서드 정의 | 7장 |
| 키워드 | `return` | 메서드 실행 중단 및 값 반환 | 7장, 18장 |
| 클래스 | `Array` | 순서가 있는 값들의 목록 | 8장 |
| 클래스 | `Hash` | 키-값 쌍의 모음 | 8장 |
| 키워드 | `class` / `end` | 클래스 정의 | 9장 |
| 메서드 | `initialize` | 객체 생성 시 자동 호출되는 초기화 메서드 | 9장 |
| 키워드 | `attr_accessor` / `attr_reader` / `attr_writer` | 인스턴스 변수에 대한 접근자 자동 생성 | 9장 |
| 키워드 | `<` (클래스 정의 시) | 클래스 상속 | 10장 |
| 키워드 | `module` / `include` / `extend` | 모듈 정의 및 믹스인 | 10장 |
| 문법 | `do ... end` / `{ ... }` | 블록 | 11장 |
| 클래스 | `Proc` / `Lambda`(`->`) | 블록을 객체로 저장 | 11장 |
| 키워드 | `yield` | 메서드 안에서 전달받은 블록 실행 | 11장 |
| 모듈 | `Enumerable` | `map`, `select`, `reduce` 등 순회 관련 메서드 제공 | 12장 |
| 메서드 | `map` / `select` / `reject` / `reduce` | 컬렉션 변환 및 집계 | 12장 |
| 클래스 | `Symbol` | 이름 자체를 가리키는 불변 값 | 13장 |
| 메서드 | `gsub` / `split` / `strip` 등 | 문자열 가공 | 13장 |
| 키워드 | `begin` / `rescue` / `ensure` / `raise` | 예외 처리 | 14장 |
| 문법 | 개방 클래스(재오픈) | 기존 클래스에 메서드 추가 | 15장 |
| 메서드 | `define_method` / `method_missing` | 실행 중 메서드를 동적으로 정의·처리 | 16장 |
| 명령 | `gem install` / `bundle install` | gem 설치 및 의존성 관리 | 17장 |
| 파일 | `Gemfile` / `Gemfile.lock` | 프로젝트 의존성 명세 및 버전 고정 | 17장 |
| 도구 | RuboCop / RSpec | 정적 분석 및 테스트 프레임워크 | 18장 |

## 더 참고할 자료

Ruby를 더 깊이 공부하고 싶을 때 참고할 만한 공식 문서와 커뮤니티를 이름 위주로 소개합니다.

- **ruby-lang.org**: Ruby 공식 웹사이트로, 언어 자체에 대한 공식 문서와 다운로드 안내를 제공합니다.
- **docs.ruby-lang.org**: Ruby 표준 라이브러리와 내장 클래스의 API 문서를 확인할 수 있는 공식 레퍼런스 사이트입니다.
- **rubygems.org**: 17장에서 다룬 RubyGems의 공식 저장소로, 배포된 gem을 검색하고 각 gem의 설명서를 확인할 수 있습니다.
- **rubyonrails.org**: Ruby on Rails 프레임워크의 공식 웹사이트입니다.
- **rspec.info**: RSpec 테스트 프레임워크의 공식 문서 사이트입니다.
- **rubocop.org**: RuboCop의 공식 문서 사이트로, 규칙 목록과 설정 방법을 확인할 수 있습니다.

이 밖에도 각종 개발자 커뮤니티나 질의응답 사이트에서 Ruby 관련 정보를 찾아볼 수 있습니다. 공식 문서를 우선적으로 참고하고, 궁금한 점은 커뮤니티에 질문하며 학습을 이어가는 습관을 들이면 좋습니다.

## 다음 학습 단계

이 책을 마친 뒤 무엇을 해야 할지 막막하다면, 다음과 같은 순서를 하나의 참고 경로로 삼아볼 수 있습니다.

1. **irb와 작은 스크립트로 계속 연습하기**: 새로 배운 개념은 짧은 코드로 직접 실행해보며 손에 익히는 것이 가장 확실합니다.
2. **작은 프로젝트 하나를 끝까지 만들어보기**: 할 일 목록 관리, 간단한 계산기, 텍스트 파일을 읽어 통계를 내는 프로그램 등 스스로 정한 작은 목표를 처음부터 끝까지 완성해보는 경험이 중요합니다.
3. **테스트 코드 작성 습관 들이기**: 18장에서 소개한 RSpec을 실제로 설치해보고, 자신이 만든 프로젝트에 테스트를 하나씩 추가해보세요.
4. **Ruby on Rails로 웹 애플리케이션 입문하기**: Ruby 문법에 어느 정도 익숙해졌다면, 그 지식을 실제 웹 서비스로 확장해볼 차례입니다.
5. **다른 사람의 코드 읽어보기**: RubyGems에 공개된 인기 gem의 소스 코드를 읽어보면, 실무에서 Ruby가 어떻게 쓰이는지 감각을 익힐 수 있습니다.

Ruby는 배우는 과정 자체가 즐겁도록 설계된 언어입니다. 이 책에서 다진 기초를 발판 삼아, 자신만의 속도로 다음 단계를 즐겁게 탐험해 나가시길 바랍니다.
