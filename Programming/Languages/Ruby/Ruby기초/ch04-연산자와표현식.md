# 4장. 연산자와 표현식

[◀ 이전: 3장. 변수와 자료형](ch03-변수와자료형.md) | [📖 목차](00-목차.md) | [다음: 5장. 제어문 ▶](ch05-제어문.md)


3장에서 변수와 자료형을 살펴보았으니, 이제 그 값들을 서로 조합하고 비교하는 방법을 알아볼 차례입니다. Ruby의 연산자는 다른 언어와 크게 다르지 않은 것들도 있지만, "모든 것이 객체"라는 철학이 연산자에도 스며들어 있어서 몇 가지는 눈여겨볼 만합니다.

## 산술 연산자

가장 기본적인 사칙연산부터 시작하겠습니다.

```ruby
puts 7 + 3   # 10
puts 7 - 3   # 4
puts 7 * 3   # 21
puts 7 / 3   # 2
puts 7 % 3   # 1
puts 7 ** 3  # 343
```

여기서 눈여겨볼 부분은 `7 / 3`의 결과입니다. 두 피연산자가 모두 Integer이면 Ruby는 나눗셈 결과에서 소수점 이하를 버리고 정수만 돌려줍니다. 소수점까지 포함한 결과를 얻고 싶다면 둘 중 하나 이상을 Float로 만들어야 합니다.

```ruby
puts 7 / 3       # 2  (정수 나눗셈)
puts 7.0 / 3     # 2.3333333333333335
puts 7 / 3.0     # 2.3333333333333335
puts 7.to_f / 3  # 2.3333333333333335
```

`%`는 나머지를 구하는 연산자이고, `**`는 거듭제곱을 계산합니다. 사실 이 산술 연산자들은 겉보기에만 특별한 기호일 뿐, 그 실체는 Integer나 Float 객체가 가진 평범한 메서드입니다.

```ruby
puts 7.+(3)   # 10
puts 7 + 3    # 10
```

두 표현은 완전히 같은 일을 합니다. `+`라는 이름의 메서드를 `7`이라는 객체에 대해 호출하면서 인자로 `3`을 넘긴 것이, 우리가 익숙한 `7 + 3` 표기법으로 나타난 것뿐입니다. 이 사실은 나중에 15장에서 클래스에 연산자를 직접 정의하는 방법을 배울 때 중요한 배경 지식이 됩니다.

## 비교 연산자

두 값을 비교해서 참 또는 거짓을 얻는 연산자들입니다.

```ruby
puts 5 == 5    # true
puts 5 != 3    # true
puts 5 > 3     # true
puts 5 < 3     # false
puts 5 >= 5    # true
puts 5 <= 4    # false
```

`==`는 값이 같은지를 비교하고, `!=`는 다른지를 비교합니다. 문자열끼리도 값(내용)이 같은지를 비교할 수 있습니다.

```ruby
puts "ruby" == "ruby"   # true
puts "ruby" == "Ruby"   # false (대소문자 구분)
```

## 논리 연산자

여러 조건을 조합할 때는 논리 연산자를 사용합니다.

```ruby
age = 20
has_ticket = true

puts age >= 18 && has_ticket   # true
puts age < 18 || has_ticket    # true
puts !has_ticket                # false
```

`&&`는 그리고(AND), `||`는 또는(OR), `!`는 부정(NOT)을 뜻합니다. Ruby에는 이와 별도로 `and`, `or`, `not`이라는 영어 단어 형태의 연산자도 존재합니다. 겉보기에는 같은 역할을 하는 것 같지만 우선순위가 크게 다릅니다.

```ruby
result = true && false   # && 가 = 보다 먼저 계산됨
puts result               # false

result2 = true and false  # = 이 and 보다 먼저 계산됨
puts result2                # true (result2에는 true만 대입됨)
```

두 번째 줄에서는 `and`의 우선순위가 대입 연산자 `=`보다 낮기 때문에, `result2 = true`가 먼저 계산되고 그 뒤에 `and false`가 이어지는 식으로 해석됩니다. 그 결과 `result2`에는 의도와 다르게 `true`만 담기게 됩니다. 이런 혼란을 피하기 위해 실무에서는 `and`, `or`, `not`보다 `&&`, `||`, `!`를 사용하는 것이 일반적인 관례입니다.

## 우주선 연산자 `<=>`

Ruby에는 다른 언어에서 흔히 볼 수 없는 독특한 비교 연산자가 하나 있습니다. 바로 `<=>`로, 생김새 때문에 흔히 **우주선 연산자(spaceship operator)**라고 부릅니다.

```ruby
puts (1 <=> 2)   # -1
puts (2 <=> 2)   # 0
puts (3 <=> 2)   # 1
```

우주선 연산자는 참/거짓 대신 세 가지 숫자 중 하나를 돌려줍니다. 왼쪽이 작으면 `-1`, 같으면 `0`, 크면 `1`입니다. 두 값을 비교할 수 없는 경우에는 `nil`을 돌려줍니다.

```ruby
puts (1 <=> "1")  # nil (정수와 문자열은 비교할 수 없음)
```

우주선 연산자는 단독으로 쓰이기보다, 정렬(sort) 기준을 정의할 때 그 진가를 발휘합니다.

```ruby
words = ["banana", "apple", "cherry"]
puts words.sort { |a, b| a <=> b }.inspect
# ["apple", "banana", "cherry"]
```

`sort` 메서드는 내부적으로 두 원소를 우주선 연산자로 비교하면서 순서를 정합니다. 나중에 직접 만든 클래스에 `<=>` 메서드를 정의하고 `Comparable` 모듈을 포함시키면, 그 클래스의 객체들도 `<`, `>`, `sort` 등을 자유롭게 사용할 수 있게 됩니다. 이 내용은 10장에서 모듈을 다루며 다시 살펴보겠습니다.

## 범위(Range)

일정 구간의 값을 하나의 객체로 다루고 싶을 때 사용하는 것이 Range입니다. Ruby에서는 `..`과 `...`이라는 두 가지 점 표기법으로 범위를 만듭니다. 둘의 차이는 오직 끝 값을 포함하느냐입니다.

```ruby
inclusive = (1..5)   # 1부터 5까지, 5를 포함
exclusive = (1...5)  # 1부터 5까지, 5는 제외

puts inclusive.to_a.inspect  # [1, 2, 3, 4, 5]
puts exclusive.to_a.inspect  # [1, 2, 3, 4]
```

점이 두 개(`..`)면 끝 값을 포함하고, 점이 세 개(`...`)면 끝 값을 제외한다고 기억하면 됩니다. 범위는 반복문에서 자주 쓰입니다.

```ruby
(1..3).each do |i|
  puts "#{i}번째 반복"
end
# 1번째 반복
# 2번째 반복
# 3번째 반복
```

`each`를 비롯한 반복 관련 내용은 6장과 12장에서 본격적으로 다룹니다. 범위는 숫자에만 국한되지 않고, 문자에도 사용할 수 있습니다.

```ruby
puts ("a".."e").to_a.inspect  # ["a", "b", "c", "d", "e"]
```

또한 `case` 문에서 값이 특정 구간에 속하는지 검사할 때도 범위가 유용하게 쓰입니다.

```ruby
score = 85

case score
when 90..100
  puts "A등급"
when 80...90
  puts "B등급"
else
  puts "C등급 이하"
end
# B등급
```

## 조건 표현식이 값을 반환한다

다른 언어를 먼저 배운 사람에게는 이 부분이 특히 인상 깊게 다가올 수 있습니다. Ruby에서는 `if`나 `case`가 단순히 흐름을 나누는 "문장(statement)"이 아니라, 자기 자신이 하나의 값으로 평가되는 "표현식(expression)"입니다. 즉 `if`, `case`의 실행 결과를 변수에 바로 담을 수 있습니다.

```ruby
age = 17

message = if age >= 20
            "성인입니다"
          elsif age >= 14
            "청소년입니다"
          else
            "어린이입니다"
          end

puts message  # 청소년입니다
```

`if` 블록 전체가 하나의 값처럼 취급되어, 조건에 맞게 선택된 분기의 마지막 표현식 결과가 그대로 `message`에 대입됩니다. `case` 문도 마찬가지로 동작합니다.

```ruby
grade = case score
        when 90..100 then "A"
        when 80...90 then "B"
        when 70...80 then "C"
        else "D 이하"
        end

puts grade
```

이런 성질 덕분에, 다른 언어라면 삼항 연산자(`condition ? a : b`)나 별도의 변수 선언과 대입을 여러 줄에 나눠 써야 했을 상황을 Ruby에서는 훨씬 간결하게 표현할 수 있습니다. 참고로 Ruby에도 삼항 연산자 `조건 ? 참일때값 : 거짓일때값`이 존재하며, 짧은 조건식에는 이 표기법도 널리 쓰입니다.

```ruby
status = age >= 20 ? "성인" : "미성년자"
puts status
```

메서드 안에서 `if`나 `case`가 마지막 표현식으로 등장하는 경우, 그 결과가 곧 메서드의 반환값이 되기도 합니다. 이 내용은 7장에서 메서드를 다룰 때 이어서 설명합니다.

## 안전 내비게이션 연산자 `&.`

3장에서 `nil`도 하나의 객체라는 점을 살펴보았습니다. 하지만 `nil`은 다른 객체들이 흔히 가지고 있는 메서드 대부분을 가지고 있지 않기 때문에, `nil`에 대고 임의의 메서드를 호출하면 오류가 발생합니다.

```ruby
user_name = nil
puts user_name.upcase
# NoMethodError: undefined method 'upcase' for nil:NilClass
```

이런 상황은 실무에서 자주 벌어집니다. 데이터베이스 조회 결과가 없거나, 사용자가 아직 값을 입력하지 않은 경우처럼 값이 `nil`일 가능성이 늘 존재하기 때문입니다. 예전에는 이런 상황을 다음처럼 방어적으로 처리해야 했습니다.

```ruby
if user_name != nil
  puts user_name.upcase
end
```

혹은 좀 더 Ruby다운 표현으로 아래처럼 쓰기도 했습니다.

```ruby
puts user_name.upcase if user_name
```

**안전 내비게이션 연산자(safe navigation operator)** `&.`는 이런 검사를 한 번에 처리해 줍니다. `.` 대신 `&.`으로 메서드를 호출하면, 호출하는 대상이 `nil`일 경우 메서드를 실행하지 않고 조용히 `nil`을 돌려줍니다.

```ruby
puts user_name&.upcase   # nil이 출력됨 (오류가 나지 않음)

user_name = "hana"
puts user_name&.upcase   # HANA
```

`&.`는 특히 여러 메서드를 연달아 호출하는 상황에서 진가를 발휘합니다.

```ruby
# user가 nil일 수도 있고, user.profile이 nil일 수도 있는 상황
address = user&.profile&.address
```

이 코드는 `user`가 `nil`이면 그 즉시 전체 표현식이 `nil`이 되고, `user`는 있지만 `profile`이 `nil`이면 역시 전체가 `nil`이 됩니다. 어느 단계에서도 오류 없이 안전하게 `nil`로 흘러갑니다. 다만 `&.`를 남용하면 정작 값이 없어서 생기는 문제를 발견하지 못하고 지나칠 수 있으므로, "이 값은 원래도 없을 수 있는 값인가"를 판단한 뒤에 사용하는 것이 좋습니다. 값이 없는 상황 자체를 프로그램의 오류로 다뤄야 할 때는 14장에서 다루는 예외 처리를 사용하는 편이 더 적절합니다.

## 병렬 대입

Ruby는 여러 변수에 값을 한 줄로 동시에 대입하는 문법을 지원합니다.

```ruby
a, b, c = 1, 2, 3
puts a  # 1
puts b  # 2
puts c  # 3
```

`=`의 왼쪽과 오른쪽에 각각 쉼표로 구분된 값들을 나열하면, 순서대로 짝을 지어 대입합니다. 이 문법이 실전에서 가장 빛나는 순간은 두 변수의 값을 맞바꿀 때입니다.

```ruby
a = 1
b = 2

a, b = b, a

puts a  # 2
puts b  # 1
```

다른 여러 언어에서는 두 변수의 값을 바꾸려면 임시 변수를 하나 더 만들어야 합니다.

```ruby
temp = a
a = b
b = temp
```

하지만 Ruby의 병렬 대입을 사용하면 오른쪽 `b, a`가 먼저 하나의 묶음으로 평가된 뒤에 왼쪽 `a, b`로 순서대로 배정되기 때문에, 임시 변수 없이 단 한 줄로 두 값을 맞바꿀 수 있습니다.

병렬 대입은 배열을 변수 여러 개로 풀어낼 때도 유용합니다.

```ruby
numbers = [10, 20, 30]
x, y, z = numbers

puts x  # 10
puts y  # 20
puts z  # 30
```

왼쪽 변수 개수와 오른쪽 값 개수가 맞지 않으면 어떻게 될까요? 남는 변수에는 `nil`이 채워지고, 남는 값은 버려집니다.

```ruby
p, q = 1, 2, 3
puts p  # 1
puts q  # 2
# 3은 버려짐

m, n, o = 1, 2
puts o.inspect  # nil
```

또한 변수 이름 앞에 별표(`*`)를 붙이면 "나머지 전부를 배열로 받아라"는 뜻이 됩니다.

```ruby
first, *rest = [1, 2, 3, 4, 5]
puts first        # 1
puts rest.inspect # [2, 3, 4, 5]
```

이런 식으로 값을 여러 변수에 나눠 담는 방식을 **구조 분해 대입(destructuring assignment)**이라고도 부르며, 배열이나 해시를 다룰 때 특히 자주 쓰입니다. 배열과 해시는 8장에서 자세히 배우고, 메서드의 인자를 받을 때 이런 별표 표기법을 활용하는 방법은 7장에서 이어서 설명합니다.

## 요약

- 산술 연산자(`+`, `-`, `*`, `/`, `%`, `**`)는 실제로는 숫자 객체가 가진 메서드이며, 정수끼리 나눗셈을 하면 소수점 이하가 버려집니다.
- 비교 연산자(`==`, `!=`, `>`, `<` 등)와 논리 연산자(`&&`, `||`, `!`)로 조건을 표현하며, `and`/`or`/`not`은 우선순위가 낮아 실무에서는 잘 쓰이지 않습니다.
- 우주선 연산자 `<=>`는 두 값의 크기를 `-1`, `0`, `1`로 비교하며, 정렬 기준을 정의할 때 활용됩니다.
- 범위(Range)는 `..`(끝 값 포함)과 `...`(끝 값 제외)로 만들며, 반복문이나 `case` 문에서 자주 쓰입니다.
- Ruby의 `if`, `case`는 문장이 아니라 표현식이므로 그 결과를 변수에 바로 대입할 수 있습니다.
- 안전 내비게이션 연산자 `&.`는 호출 대상이 `nil`일 때 오류 대신 `nil`을 돌려주어, 연쇄적인 메서드 호출을 안전하게 만듭니다.
- 병렬 대입(`a, b = b, a`)을 이용하면 임시 변수 없이 여러 변수의 값을 한 번에 바꾸거나 배열을 변수들로 풀어낼 수 있습니다.

## 연습문제

1. 정수 `17`과 `5`를 가지고 `+`, `-`, `*`, `/`, `%`, `**` 연산 결과를 각각 출력해 보세요. 그리고 `17 / 5`와 `17.0 / 5`의 결과가 왜 다른지 설명해 보세요.

2. 세 개의 숫자 `10`, `20`, `20`을 우주선 연산자로 두 개씩 비교해서 그 결과를 출력하는 코드를 작성해 보세요.

3. 나이(`age`)를 나타내는 변수를 하나 만들고, `if`를 표현식으로 사용해 "유아", "어린이", "청소년", "성인" 중 하나를 담은 문자열을 다른 변수에 대입하는 코드를 작성해 보세요.

4. 다음 코드가 오류 없이 실행되도록 안전 내비게이션 연산자를 사용해 고쳐 보세요.

   ```ruby
   product = nil
   puts product.name.upcase
   ```

5. 배열 `[1, 2, 3, 4, 5]`를 병렬 대입과 별표(`*`) 표기법을 이용해 "첫 번째 값", "두 번째 값", "나머지 값들(배열)" 세 변수로 나누어 담고 각각 출력해 보세요.
