# Git으로 배우는 버전 관리

[다음: 1장. Git이란 무엇인가 ▶](ch01-Git이란무엇인가.md)

---

분산 버전 관리 시스템 Git을 처음부터 실무 수준까지 다루는 입문서입니다. 특정 프로그래밍
언어에 종속되지 않으며, 모든 예제는 셸(터미널) 명령어로 진행됩니다. 스테이징과 커밋 같은
기초부터 브랜치, 병합과 충돌 해결, 원격 저장소와 GitHub, 히스토리 탐색과 되돌리기, rebase와
cherry-pick, stash, Pull Request와 코드 리뷰, 브랜치 전략, 태그와 릴리스, .gitignore, 서브모듈,
Git 내부 구조, Git Hooks, 실전 협업 시나리오까지 순서대로 다룹니다.

각 장은 개념 설명, 셸 명령어 예제, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는 이해를
돕는 다이어그램을 함께 실었습니다.

## 학습 방법 제안

1. 각 장의 명령어를 직접 터미널에 입력하며 결과를 눈으로 확인하세요. Git은 손으로 직접 시도해봐야 감이 잡히는 도구입니다.
2. 장 끝의 연습문제를 풀어보면서 이해도를 점검하세요.
3. 3~6장(스테이징/커밋, 브랜치, 병합, 원격 저장소)은 Git 전체의 근간이 되는 내용이므로 특히 꼼꼼히 읽어보세요.
4. `git reset --hard`, force push처럼 되돌리기 어려운 명령은 연습용 저장소에서 충분히 실습한 뒤 실제 프로젝트에 적용하세요.
5. 18장의 실전 프로젝트는 그동안 배운 내용을 종합하는 자리이니, 실제로 두 개의 로컬 저장소(또는 GitHub 저장소)를 만들어 시나리오를 따라 해보길 권합니다.
