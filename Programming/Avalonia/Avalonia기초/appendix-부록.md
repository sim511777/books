이 부록에서는 본문에서 자세히 다루지 않았던 개발 환경 설정 절차를 정리하고, 책 전체에서 사용한 주요 XAML 문법과 클래스를 표로 요약합니다. 마지막으로 앞으로 더 공부할 때 참고할 만한 자료와 다음 학습 단계를 안내합니다.

## 개발 환경 설정

### .NET SDK 설치

Avalonia 애플리케이션을 개발하려면 먼저 .NET SDK가 설치되어 있어야 합니다. .NET SDK는 Windows, macOS, Linux 모두를 위한 설치 프로그램을 제공하며, 공식 다운로드 페이지에서 운영체제에 맞는 설치 파일을 내려받아 설치할 수 있습니다. 설치가 끝난 뒤에는 터미널(또는 명령 프롬프트, PowerShell)에서 다음 명령으로 정상 설치 여부를 확인할 수 있습니다.

```bash
dotnet --version
```

이 명령이 설치된 .NET SDK의 버전을 출력하면 정상적으로 설치된 것입니다. 이 책에서 다루는 예제들은 특정 최신 버전에 종속적이지 않지만, 가능하면 각 시점의 최신 장기 지원(LTS) 버전을 사용하는 것을 권장합니다.

### Avalonia 프로젝트 템플릿 설치

.NET SDK 설치 후, Avalonia 프로젝트를 생성하기 위한 템플릿을 다음 명령으로 설치합니다.

```bash
dotnet new install Avalonia.Templates
```

설치가 끝나면 `dotnet new avalonia.app` 같은 명령으로 새 Avalonia 프로젝트를 만들 수 있습니다. 자세한 절차는 2장에서 다루었습니다.

### IDE 선택지

Avalonia 개발에 특정 IDE를 강제하지는 않지만, 커뮤니티에서 널리 쓰이는 선택지는 다음과 같습니다. 각 도구의 상세한 설치·설정 방법은 이 책의 범위를 벗어나므로 이름만 소개합니다.

- **Visual Studio** - Windows에서 널리 쓰이는 통합 개발 환경으로, Avalonia용 확장을 설치하면 XAML 미리보기와 IntelliSense 지원을 받을 수 있습니다.
- **JetBrains Rider** - Windows/macOS/Linux 모두를 지원하는 크로스플랫폼 .NET IDE로, Avalonia 플러그인을 통해 XAML 편집과 미리보기를 지원합니다.
- **Visual Studio Code + Avalonia 확장** - 가볍고 크로스플랫폼인 에디터인 VS Code에 Avalonia를 위한 확장을 설치하면 XAML 문법 강조와 미리보기 기능을 사용할 수 있습니다.

세 가지 모두 18장에서 다룬 디자인타임 미리보기(`d:DesignWidth`, `d:DataContext` 등)를 지원하므로, 어떤 도구를 선택하든 개발 편의성 측면에서 큰 차이는 없습니다. 자신에게 익숙한 운영체제와 편집 방식에 맞춰 선택하면 됩니다.

## 주요 XAML 문법 요약

이 책 전체에서 사용한 주요 XAML 문법을 정리하면 다음과 같습니다.

| 문법 | 설명 | 관련 장 |
|---|---|---|
| `xmlns="https://github.com/avaloniaui"` | Avalonia 기본 네임스페이스 선언 | 3장 |
| `x:Class` | 코드비하인드 클래스와 XAML을 연결 | 3장 |
| `{Binding PropertyName}` | ViewModel 속성과 컨트롤 속성을 연결하는 데이터 바인딩 | 7장 |
| `{Binding Command}` | 사용자 동작을 `ICommand`에 연결 | 9장 |
| `DataContext` | 바인딩의 기준이 되는 객체를 지정 | 7장, 8장 |
| `{StaticResource Key}` | 리소스 딕셔너리에 정의된 값을 참조 | 10장 |
| `{DynamicResource Key}` | 런타임에 값이 바뀔 수 있는 리소스를 참조(테마 전환 등) | 10장, 16장 |
| `Style`, `Selector` | 컨트롤 외양을 재사용 가능하게 정의 | 10장 |
| `ControlTemplate` | 컨트롤의 시각적 구조 자체를 재정의 | 11장 |
| `DataTemplate` | 데이터 객체를 화면에 표시할 형태로 매핑 | 11장, 14장 |
| `ItemsControl`, `ItemsSource` | 컬렉션을 화면에 목록 형태로 표시 | 14장 |
| `d:DesignWidth`, `d:DesignHeight` | 디자인타임 미리보기 캔버스 크기 지정 | 18장 |
| `d:DataContext`, `{d:DesignInstance}` | 디자인타임 전용 데이터 컨텍스트 지정 | 18장 |
| `mc:Ignorable="d"` | 디자인타임 전용 속성이 런타임에 무시되도록 선언 | 18장 |

## 주요 클래스/인터페이스 요약

| 이름 | 역할 | 관련 장 |
|---|---|---|
| `Application` | 애플리케이션 전역 상태와 리소스를 관리하는 진입점 클래스 | 2장 |
| `Window` | 데스크톱 최상위 창을 나타내는 클래스 | 2장, 15장 |
| `UserControl` | 재사용 가능한 화면 조각을 정의하는 기본 클래스 | 12장 |
| `TemplatedControl` | 템플릿을 통해 외양을 재정의할 수 있는 커스텀 컨트롤의 기반 클래스 | 13장 |
| `StyledProperty<T>` | Avalonia 속성 시스템에 등록되는 스타일 지정 가능한 속성 | 13장 |
| `INotifyPropertyChanged` | 속성 변경을 View에 알리기 위한 표준 인터페이스 | 7장, 8장 |
| `ICommand` | 버튼 클릭 등 사용자 동작을 ViewModel의 메서드에 연결하는 인터페이스 | 9장 |
| `ObservableCollection<T>` | 항목 추가/삭제가 자동으로 UI에 반영되는 컬렉션 | 14장 |
| `IDataTemplate` | ViewModel 타입에 대응하는 View를 결정하는 데 사용되는 인터페이스 | 11장, 15장 |

## 참고 자료

더 깊이 있는 내용이나 최신 정보가 필요할 때는 다음과 같은 공식·커뮤니티 자료를 참고할 수 있습니다. 실제 URL은 검색 엔진에서 이름으로 찾아 접속하는 것을 권장합니다(버전에 따라 주소 구조가 바뀔 수 있으므로).

- **avaloniaui.net** - Avalonia 공식 웹사이트로, 공식 문서와 튜토리얼, 다운로드 링크를 제공합니다.
- **Avalonia GitHub 저장소** - 소스 코드, 이슈 트래커, 릴리스 노트를 확인할 수 있습니다. 프레임워크 자체의 동작을 더 깊이 이해하고 싶을 때 소스 코드를 직접 살펴보는 것도 좋은 학습 방법입니다.
- **Avalonia 공식 커뮤니티 채팅(Discord 등)** - 다른 개발자들과 질문을 주고받거나 최신 동향을 파악할 수 있는 공간입니다.
- **.NET 공식 문서** - Avalonia 자체의 문서는 아니지만, C#과 .NET 런타임, `dotnet` CLI에 대한 배경 지식이 필요할 때 참고할 수 있습니다.
- **ReactiveUI, CommunityToolkit.Mvvm 공식 문서** - 18장에서 언급한 확장 라이브러리들의 상세한 사용법을 다룹니다.

## 다음 학습 단계 제안

이 책을 마친 후에는 다음과 같은 순서로 학습을 이어가는 것을 제안합니다.

1. **작은 프로젝트를 처음부터 끝까지 만들어보기**. 할 일 목록 관리, 간단한 메모 앱처럼 크지 않은 주제를 골라 2장부터 17장까지 배운 내용(프로젝트 생성, MVVM 구조, 데이터 바인딩, 스타일, 배포)을 처음부터 끝까지 적용해 보는 것이 가장 효과적인 복습입니다.
2. **CommunityToolkit.Mvvm 도입해보기**. 직접 작성했던 `INotifyPropertyChanged` 구현이나 커맨드 클래스를 소스 제너레이터 기반 라이브러리로 교체해 보면서, 같은 패턴이 라이브러리 차원에서 어떻게 더 간결하게 표현되는지 비교해 보세요.
3. **애니메이션과 트랜지션 시스템 살펴보기**. 정적인 화면에 익숙해졌다면, 상태 전환이나 목록 항목 추가/삭제에 시각적 효과를 더하는 방법을 익혀 사용자 경험을 다듬어 보세요.
4. **실제 배포까지 경험해보기**. 17장에서 다룬 `dotnet publish`로 자신이 만든 애플리케이션을 실제로 패키징하고, 가능하다면 다른 운영체제 환경(가상 머신 등)에서 실행해 보면서 크로스플랫폼 배포의 감각을 익히세요.
5. **오픈소스 Avalonia 프로젝트 코드 읽어보기**. 실제로 운영되는 Avalonia 기반 오픈소스 애플리케이션의 소스 코드를 읽어보면, 이 책에서 배운 패턴들이 실전 규모의 프로젝트에서 어떻게 조직되는지 감을 잡을 수 있습니다.

Avalonia는 계속 발전하고 있는 프레임워크이므로, 이 책에서 다지지 못한 세부 사항이나 새로운 기능은 공식 문서와 커뮤니티를 통해 꾸준히 따라가는 것이 좋습니다. 이 책에서 다진 XAML 문법과 데이터 바인딩, MVVM에 대한 이해는 앞으로 Avalonia가 어떻게 발전하더라도 흔들리지 않는 튼튼한 기반이 되어 줄 것입니다.
