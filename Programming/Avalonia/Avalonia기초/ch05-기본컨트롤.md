# 5장. 기본 컨트롤

[◀ 이전: 4장. 레이아웃 시스템](ch04-레이아웃시스템.md) | [📖 목차](00-목차.md) | [다음: 6장. 이벤트 처리 ▶](ch06-이벤트처리.md)


3장에서 XAML 문법을 익혔고, 4장에서는 컨트롤들을 화면에 배치하는 레이아웃 시스템을 배웠습니다. 이제 화면을 채울 실제 재료, 즉 컨트롤 자체를 다룰 차례입니다.

이번 장에서는 Avalonia가 기본으로 제공하는 컨트롤 중 가장 자주 쓰이는 것들을 살펴봅니다. 텍스트를 보여주거나 입력받는 컨트롤, 버튼류 컨트롤, 여러 항목 중 하나를 고르는 선택 컨트롤, 그리고 이미지를 표시하는 컨트롤입니다. 각 컨트롤이 어떤 상황에 쓰이는지, 그리고 자주 사용하는 속성이 무엇인지에 초점을 맞추고, 장 마지막에는 이 컨트롤들을 조합해 간단한 로그인 폼을 만들어 봅니다.

이 장에서 다루는 컨트롤들은 아직 코드비하인드에서 값을 직접 읽고 쓰는 방식으로 다룹니다. 값이 변할 때마다 자동으로 화면과 동기화되는 방법은 7장 데이터 바인딩에서, 각 컨트롤의 겉모습을 자유롭게 바꾸는 방법은 11장 컨트롤 템플릿에서 다룹니다.

## 5.1 텍스트를 다루는 컨트롤: TextBlock과 TextBox

가장 먼저 만나게 되는 컨트롤은 텍스트를 화면에 보여주는 `TextBlock`과, 사용자로부터 텍스트를 입력받는 `TextBox`입니다. 두 컨트롤은 이름은 비슷하지만 역할이 완전히 다릅니다. `TextBlock`은 읽기 전용이고, `TextBox`는 편집이 가능합니다.

### 5.1.1 TextBlock

`TextBlock`은 화면에 문자열을 표시하기만 하는, 가장 단순한 컨트롤입니다. 레이블, 안내 문구, 결과 출력 등 사용자가 직접 수정할 필요가 없는 텍스트에는 항상 `TextBlock`을 사용합니다.

```xml
<TextBlock Text="안녕하세요, Avalonia" />
```

`TextBlock`의 자주 쓰이는 속성은 다음과 같습니다.

| 속성 | 설명 |
|---|---|
| `Text` | 표시할 문자열 |
| `FontSize` | 글자 크기 |
| `FontWeight` | 글자 굵기 (`Normal`, `Bold` 등) |
| `Foreground` | 글자 색상 |
| `TextWrapping` | 줄바꿈 방식 (`NoWrap`, `Wrap`) |
| `TextTrimming` | 넘치는 텍스트를 자르는 방식 (`CharacterEllipsis` 등) |
| `TextAlignment` | 텍스트 정렬 (`Left`, `Center`, `Right`) |

예를 들어 긴 문장을 여러 줄로 자동 줄바꿈하면서 굵은 글씨로 강조하고 싶다면 다음과 같이 작성합니다.

```xml
<TextBlock Text="이 문장은 폭이 좁은 컨테이너 안에서 자동으로 줄바꿈됩니다."
           TextWrapping="Wrap"
           FontWeight="Bold"
           FontSize="16" />
```

`TextBlock`은 `Text` 속성 대신 인라인 콘텐츠로 여러 `Run`을 조합해 서로 다른 서식을 가진 텍스트를 한 줄에 섞어 쓸 수도 있지만, 입문 단계에서는 `Text` 속성만으로도 대부분의 상황을 충분히 다룰 수 있습니다.

### 5.1.2 TextBox

`TextBox`는 사용자가 직접 문자열을 입력하거나 수정할 수 있는 컨트롤입니다. 로그인 폼의 아이디 입력란, 검색창, 메모장 등 사용자 입력이 필요한 모든 곳에 쓰입니다.

```xml
<TextBox Watermark="아이디를 입력하세요" />
```

`TextBox`의 자주 쓰이는 속성은 다음과 같습니다.

| 속성 | 설명 |
|---|---|
| `Text` | 입력된 문자열 |
| `Watermark` | 입력값이 없을 때 흐리게 표시되는 안내 문구 |
| `PasswordChar` | 지정한 문자로 입력값을 가려서 표시(비밀번호 입력란에 사용) |
| `IsReadOnly` | `true`이면 편집 불가, 표시만 가능 |
| `AcceptsReturn` | `true`이면 Enter 키로 줄바꿈 허용(여러 줄 입력) |
| `MaxLength` | 입력 가능한 최대 문자 수 |
| `TextWrapping` | 여러 줄 입력 시 줄바꿈 방식 |

`Watermark`는 입력란이 비어 있을 때만 회색 안내 문구를 보여주고, 사용자가 타이핑을 시작하면 자동으로 사라집니다. 별도의 `TextBlock`을 겹쳐 놓지 않아도 되므로 검색창이나 입력 폼에서 매우 유용합니다.

비밀번호처럼 입력값을 가려야 하는 경우 `PasswordChar`를 지정합니다.

```xml
<TextBox Watermark="비밀번호를 입력하세요"
         PasswordChar="●" />
```

여러 줄을 입력받고 싶다면 `AcceptsReturn`을 `true`로 지정하고, 보기 좋게 표시하려면 `TextWrapping="Wrap"`과 함께 사용합니다.

```xml
<TextBox Watermark="문의 내용을 입력하세요"
         AcceptsReturn="True"
         TextWrapping="Wrap"
         Height="100" />
```

`TextBox`에 입력된 값을 코드비하인드에서 읽으려면 `Text` 속성을 직접 참조하면 됩니다. 예를 들어 `x:Name="UsernameBox"`로 이름을 붙인 `TextBox`가 있다면, 같은 뷰의 코드비하인드에서 `UsernameBox.Text`로 현재 입력값에 접근할 수 있습니다. 이 값이 바뀔 때마다 자동으로 다른 곳에 반영되도록 만드는 방법은 7장에서 데이터 바인딩을 배우면서 훨씬 간결하게 다시 다룹니다.

## 5.2 버튼류 컨트롤

사용자의 클릭이나 선택을 받아들이는 컨트롤들을 살펴봅니다. `Button`, `ToggleButton`, `CheckBox`, `RadioButton`은 모두 클릭 가능한 컨트롤이라는 공통점이 있는데, 실제로 `CheckBox`와 `RadioButton`은 `ToggleButton`을 상속해서 만들어진 컨트롤입니다.

### 5.2.1 Button

`Button`은 클릭 동작을 트리거하는 가장 기본적인 컨트롤입니다.

```xml
<Button Content="로그인" />
```

`Button`의 `Content` 속성은 문자열뿐 아니라 임의의 컨트롤을 담을 수 있습니다. 즉 버튼 안에 아이콘과 텍스트를 함께 넣는 것도 가능합니다.

```xml
<Button>
    <StackPanel Orientation="Horizontal" Spacing="6">
        <TextBlock Text="🔒" />
        <TextBlock Text="로그인" />
    </StackPanel>
</Button>
```

버튼 클릭에 반응하는 방법은 두 가지입니다. 하나는 `Click` 이벤트에 코드비하인드 메서드를 연결하는 방식이고, 다른 하나는 `Command` 속성에 `ICommand`를 바인딩하는 방식입니다. 이벤트를 연결하는 구체적인 방법은 6장에서, `Command`를 이용하는 방법은 9장에서 다룹니다. 지금은 `Button`이 클릭 가능한 컨트롤이라는 점과 `Content`로 내용을 채운다는 점만 기억해 두면 충분합니다.

### 5.2.2 ToggleButton

`ToggleButton`은 클릭할 때마다 켜짐/꺼짐 상태가 토글되는 버튼입니다. 툴바의 굵게/기울임 버튼처럼 On/Off 상태를 시각적으로 유지해야 하는 곳에 사용합니다.

```xml
<ToggleButton Content="굵게" />
```

`ToggleButton`의 핵심 속성은 현재 상태를 나타내는 `IsChecked`입니다. `IsChecked`는 `bool?`(nullable bool) 타입으로, `true`(켜짐), `false`(꺼짐), `null`(알 수 없음/중간 상태) 세 가지 값을 가질 수 있습니다. `IsThreeState`를 `true`로 설정하면 사용자가 클릭할 때마다 `false → true → null` 순서로 세 상태를 순환합니다.

```xml
<ToggleButton Content="일부 선택" IsThreeState="True" />
```

### 5.2.3 CheckBox

`CheckBox`는 옵션을 켜고 끄는 데 사용하는 익숙한 체크박스 컨트롤입니다. 앞서 언급했듯 `ToggleButton`을 상속하므로 `IsChecked`와 `IsThreeState` 속성을 그대로 물려받습니다.

```xml
<CheckBox Content="로그인 상태 유지" />
```

여러 개의 `CheckBox`는 서로 독립적으로 동작합니다. 즉 여러 항목을 동시에 체크할 수 있다는 점이 다음에 볼 `RadioButton`과의 가장 큰 차이입니다.

```xml
<StackPanel Spacing="4">
    <CheckBox Content="이메일 수신 동의" />
    <CheckBox Content="SMS 수신 동의" />
    <CheckBox Content="로그인 상태 유지" IsChecked="True" />
</StackPanel>
```

### 5.2.4 RadioButton

`RadioButton`은 여러 선택지 중 오직 하나만 고를 수 있게 해주는 컨트롤입니다. `CheckBox`와 마찬가지로 `IsChecked` 속성을 가지지만, 같은 그룹 안에서는 하나가 선택되면 나머지는 자동으로 선택 해제됩니다.

```xml
<StackPanel Spacing="4">
    <RadioButton Content="아이디로 로그인" IsChecked="True" />
    <RadioButton Content="이메일로 로그인" />
</StackPanel>
```

`RadioButton`의 그룹핑은 기본적으로 같은 부모 패널을 공유하는 것만으로 이루어집니다. 하지만 화면 레이아웃상 서로 다른 컨테이너에 흩어져 있는 `RadioButton`들을 하나의 그룹으로 묶고 싶을 때는 `GroupName` 속성을 사용합니다. `GroupName`이 같은 `RadioButton`들은 화면 어디에 위치하든 하나의 그룹으로 취급됩니다.

```xml
<StackPanel Orientation="Horizontal" Spacing="20">
    <StackPanel Spacing="4">
        <TextBlock Text="로그인 방식" FontWeight="Bold" />
        <RadioButton Content="아이디" GroupName="LoginType" IsChecked="True" />
        <RadioButton Content="이메일" GroupName="LoginType" />
    </StackPanel>
    <StackPanel Spacing="4">
        <TextBlock Text="테마" FontWeight="Bold" />
        <RadioButton Content="라이트" GroupName="Theme" IsChecked="True" />
        <RadioButton Content="다크" GroupName="Theme" />
    </StackPanel>
</StackPanel>
```

`GroupName`을 지정하지 않았다면 `LoginType` 그룹과 `Theme` 그룹의 `RadioButton`들이 부모 `StackPanel`이 다름에도 불구하고 서로 헷갈리지 않고 독립적으로 동작하는 이유를 이 예제에서 확인할 수 있습니다.

## 5.3 여러 항목 중에서 선택하기: ComboBox와 ListBox

여러 개의 항목을 나열하고 그중 하나(또는 여러 개)를 선택하게 하려면 `ComboBox`와 `ListBox`를 사용합니다. 두 컨트롤 모두 여러 개의 아이템을 다룬다는 공통점이 있지만, 화면에 보여지는 방식이 다릅니다.

### 5.3.1 ComboBox

`ComboBox`는 평소에는 선택된 항목 하나만 보이다가, 클릭하면 드롭다운 목록이 펼쳐지는 컨트롤입니다. 화면 공간을 절약하면서 여러 선택지 중 하나를 고르게 할 때 적합합니다.

가장 간단한 사용법은 `Items` 자리에 `ComboBoxItem` 여러 개를 직접 나열하는 것입니다.

```xml
<ComboBox SelectedIndex="0">
    <ComboBoxItem Content="한국어" />
    <ComboBoxItem Content="English" />
    <ComboBoxItem Content="日本語" />
</ComboBox>
```

또는 문자열 목록을 `ItemsSource`에 바인딩할 수도 있습니다. 이 경우 별도의 템플릿을 지정하지 않으면 각 항목은 `ToString()` 결과로 표시됩니다.

```xml
<ComboBox ItemsSource="{Binding Languages}"
          SelectedItem="{Binding SelectedLanguage}"
          PlaceholderText="언어 선택" />
```

여기서 `{Binding ...}` 구문은 아직 낯설 수 있는데, 값이 자동으로 연결된다는 정도로만 이해하고 넘어가도 좋습니다. 자세한 내용은 7장 데이터 바인딩에서 다룹니다. `ItemsSource`에 담긴 객체들을 원하는 모양으로 자유롭게 꾸미는 방법(예: 아이콘과 이름을 함께 표시하기)은 11장 데이터 템플릿에서 배웁니다.

`ComboBox`의 자주 쓰이는 속성은 다음과 같습니다.

| 속성 | 설명 |
|---|---|
| `ItemsSource` | 표시할 항목들의 컬렉션 |
| `SelectedItem` | 현재 선택된 항목 |
| `SelectedIndex` | 현재 선택된 항목의 인덱스 |
| `PlaceholderText` | 아무 항목도 선택되지 않았을 때 보여줄 안내 문구 |
| `IsDropDownOpen` | 드롭다운 목록이 펼쳐져 있는지 여부 |

### 5.3.2 ListBox

`ListBox`는 `ComboBox`와 달리 목록 전체가 항상 화면에 펼쳐진 상태로 보입니다. 여러 항목을 한눈에 비교하며 골라야 하거나, 목록 자체가 화면의 주요 콘텐츠일 때 적합합니다.

```xml
<ListBox SelectedIndex="0">
    <ListBoxItem Content="받은 편지함" />
    <ListBoxItem Content="보낸 편지함" />
    <ListBoxItem Content="휴지통" />
</ListBox>
```

`ComboBox`와 마찬가지로 `ItemsSource`를 사용할 수도 있고, `SelectionMode` 속성을 통해 다중 선택도 지원합니다.

```xml
<ListBox ItemsSource="{Binding Fruits}"
         SelectionMode="Multiple" />
```

| 속성 | 설명 |
|---|---|
| `ItemsSource` | 표시할 항목들의 컬렉션 |
| `SelectedItem` / `SelectedItems` | 현재 선택된 항목(들) |
| `SelectionMode` | `Single`, `Multiple`, `Toggle` 중 선택 |

지금은 `ListBox`에 문자열 몇 개를 나열하는 정도로만 다루지만, 실제 애플리케이션에서는 데이터베이스나 API에서 가져온 객체 목록을 보여주고, 항목 템플릿을 커스터마이즈하고, 선택된 항목에 따라 다른 화면을 보여주는 등 훨씬 풍부하게 활용됩니다. 이런 내용은 14장 리스트와 컬렉션 바인딩에서 본격적으로 다룹니다.

## 5.4 이미지 표시하기: Image 컨트롤

`Image` 컨트롤은 비트맵 이미지를 화면에 표시합니다. 로고, 아이콘, 프로필 사진 등을 보여줄 때 사용합니다.

프로젝트에 포함된 이미지 파일을 표시하는 가장 간단한 방법은 `Source` 속성에 애플리케이션 리소스 경로를 지정하는 것입니다. Avalonia 프로젝트에서 `Assets` 폴더에 넣은 파일은 기본적으로 `AvaloniaResource`로 빌드되므로, 다음과 같이 절대 경로 형식으로 바로 참조할 수 있습니다.

```xml
<Image Source="/Assets/logo.png"
       Width="120"
       Height="120" />
```

같은 이미지를 조금 더 명시적으로 `avares://` URI 스킴을 사용해 참조할 수도 있습니다. 이 스킴은 특정 어셈블리 안에 포함된 리소스를 가리킵니다.

```xml
<Image Source="avares://LoginApp/Assets/logo.png" />
```

`Image`가 자기 크기보다 큰 원본 이미지를 어떻게 맞춰 넣을지는 `Stretch` 속성으로 조절합니다.

| 값 | 설명 |
|---|---|
| `None` | 원본 크기 그대로 표시(넘치는 부분은 잘림) |
| `Fill` | 컨트롤 크기에 맞춰 가로세로 비율을 무시하고 채움 |
| `Uniform` | 비율을 유지하면서 컨트롤 안에 맞춤(기본값) |
| `UniformToFill` | 비율을 유지하면서 컨트롤을 꽉 채움(넘치는 부분은 잘림) |

```xml
<Image Source="/Assets/logo.png" Stretch="Uniform" Width="200" Height="100" />
```

이미지를 코드비하인드에서 동적으로 불러와야 할 때는 `AssetLoader`로 리소스 스트림을 열고 `Bitmap`을 생성해 `Source`에 대입합니다.

```csharp
using Avalonia.Media.Imaging;
using Avalonia.Platform;

var uri = new Uri("avares://LoginApp/Assets/logo.png");
using var stream = AssetLoader.Open(uri);
LogoImage.Source = new Bitmap(stream);
```

## 5.5 종합 예제: 로그인 폼 만들기

지금까지 배운 컨트롤들을 조합해서 실제로 동작하는 로그인 폼을 만들어 보겠습니다. 레이아웃은 4장에서 배운 `Grid`와 `StackPanel`을 사용합니다.

```xml
<Window xmlns="https://github.com/avaloniaui"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        x:Class="LoginApp.MainWindow"
        Title="로그인"
        Width="360" Height="420">
    <Border Padding="24">
        <StackPanel Spacing="12">

            <Image Source="/Assets/logo.png"
                   Width="80" Height="80"
                   HorizontalAlignment="Center" />

            <TextBlock Text="계정 로그인"
                       FontSize="20"
                       FontWeight="Bold"
                       HorizontalAlignment="Center" />

            <StackPanel Spacing="4">
                <TextBlock Text="로그인 방식" FontSize="12" Foreground="Gray" />
                <StackPanel Orientation="Horizontal" Spacing="16">
                    <RadioButton Content="아이디" GroupName="LoginType" IsChecked="True" />
                    <RadioButton Content="이메일" GroupName="LoginType" />
                </StackPanel>
            </StackPanel>

            <TextBox x:Name="UsernameBox"
                     Watermark="아이디 또는 이메일" />

            <TextBox x:Name="PasswordBox"
                     Watermark="비밀번호"
                     PasswordChar="●" />

            <ComboBox x:Name="LanguageBox"
                      SelectedIndex="0"
                      HorizontalAlignment="Stretch">
                <ComboBoxItem Content="한국어" />
                <ComboBoxItem Content="English" />
            </ComboBox>

            <CheckBox x:Name="RememberMeBox"
                      Content="로그인 상태 유지" />

            <Button x:Name="LoginButton"
                    Content="로그인"
                    HorizontalAlignment="Stretch"
                    HorizontalContentAlignment="Center" />

            <TextBlock x:Name="StatusText"
                       Foreground="Red"
                       TextWrapping="Wrap"
                       HorizontalAlignment="Center" />

        </StackPanel>
    </Border>
</Window>
```

이 예제는 로고 이미지, 안내 텍스트, 로그인 방식을 고르는 라디오 버튼, 아이디와 비밀번호 입력란, 언어를 고르는 콤보박스, 로그인 상태를 유지할지 정하는 체크박스, 그리고 로그인 버튼과 결과 메시지를 보여줄 텍스트블록까지 이번 장에서 배운 컨트롤을 거의 모두 담고 있습니다.

지금 이 화면은 버튼을 눌러도 아무 일도 일어나지 않습니다. `Button`의 `Click` 이벤트에 코드를 연결해서 `UsernameBox.Text`와 `PasswordBox.Text` 값을 검사하고 `StatusText.Text`에 결과를 표시하는 방법은 바로 다음 장인 6장 이벤트 처리에서 이어서 다룹니다.

## 요약

- `TextBlock`은 읽기 전용 텍스트를, `TextBox`는 편집 가능한 텍스트 입력란을 표현합니다. `TextBox`의 `Watermark`는 빈 입력란에 안내 문구를 보여주고, `PasswordChar`는 입력값을 가려서 표시합니다.
- `Button`, `ToggleButton`, `CheckBox`, `RadioButton`은 모두 클릭 가능한 컨트롤이며, `CheckBox`와 `RadioButton`은 `ToggleButton`을 상속해 `IsChecked` 속성을 공유합니다. `RadioButton`은 `GroupName`으로 그룹을 명시적으로 묶을 수 있습니다.
- `ComboBox`는 평소 접혀 있다가 클릭 시 펼쳐지는 선택 컨트롤이고, `ListBox`는 항목 전체가 항상 펼쳐져 있는 선택 컨트롤입니다. 두 컨트롤 모두 `ItemsSource`로 컬렉션을 연결할 수 있습니다. 데이터 바인딩과 리스트 활용은 각각 7장과 14장에서 더 깊이 다룹니다.
- `Image` 컨트롤은 `Source` 속성에 애플리케이션 리소스 경로나 `avares://` URI를 지정해 이미지를 표시하며, `Stretch` 속성으로 크기 맞춤 방식을 조절합니다.
- 여러 컨트롤을 조합하면 로그인 폼처럼 실제 애플리케이션에 가까운 화면을 구성할 수 있습니다. 다음 장에서는 이 화면에 실제 동작을 연결합니다.
