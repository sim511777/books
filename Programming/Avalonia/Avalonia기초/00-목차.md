# Avalonia로 배우는 크로스플랫폼 UI 개발

[다음: 1장. Avalonia란 무엇인가 ▶](ch01-Avalonia란무엇인가.md)

---

C#/.NET 기반의 크로스플랫폼 UI 프레임워크 Avalonia 입문서입니다. XAML 기초 문법부터
레이아웃, 데이터 바인딩, MVVM 패턴, 스타일과 템플릿, 그리고 Windows/macOS/Linux로의
배포까지 실전 예제와 함께 순서대로 다룹니다.

각 장은 개념 설명, XAML/C# 예제 코드, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는
이해를 돕는 다이어그램을 함께 실었습니다.

1. 각 장의 XAML/C# 예제를 직접 프로젝트에 옮겨 `dotnet run`으로 실행해보며 결과를 확인하세요.
2. 장 끝의 연습문제를 풀어보면서 이해도를 점검하세요.
3. 7~9장(데이터 바인딩, MVVM, 커맨드)은 Avalonia 개발의 근간이 되는 내용이므로 특히 꼼꼼히 읽어보세요.
4. 18장까지 마친 뒤에는 부록의 요약표를 필요할 때마다 참조용으로 활용하세요.
