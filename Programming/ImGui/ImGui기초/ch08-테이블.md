# 8장. 테이블

[◀ 이전: 7장. 트리와 리스트](ch07-트리와리스트.md) | [📖 목차](00-목차.md) | [다음: 9장. 다이얼로그와 팝업 ▶](ch09-다이얼로그와팝업.md)


5장에서 여러 위젯을 가로로 나란히 배치하는 방법을 다루면서, 구식 API인 `Columns()` / `NextColumn()`를 잠깐 언급했었습니다. 그리고 "정렬이나 크기 조절 같은 기능이 필요하다면 최신 테이블 API를 쓰는 게 낫다"고 예고했습니다. 이번 장이 바로 그 약속을 지키는 자리입니다.

표 형태의 데이터, 즉 이름과 점수와 등급이 나란히 정리된 목록이나 파일 크기와 수정 날짜가 함께 표시되는 파일 목록 같은 것은 실무에서 정말 자주 등장합니다. Dear ImGui는 이런 요구를 위해 `BeginTable()`로 시작하는 전용 테이블 API를 제공하며, 정렬, 리사이즈, 스크롤, 프리징(고정 행/열) 같은 기능까지 옵션 하나로 켤 수 있을 만큼 강력합니다.

## 왜 Columns() 대신 Table API인가

`ImGui::Columns()`는 초창기 ImGui부터 존재했던 기능으로, 단순히 화면을 세로로 나누는 것 이상의 일을 하지 못했습니다. 헤더도, 행 단위의 개념도, 정렬 기능도 없었고, 테두리를 그리는 방식도 제한적이었습니다.

반면 `BeginTable()`로 시작하는 테이블 API는 처음부터 "표"라는 개념 자체를 1급 시민으로 취급합니다. 그 결과 다음과 같은 기능을 몇 가지 플래그만으로 사용할 수 있습니다.

- 헤더 행을 클릭해 각 열의 너비를 마우스로 드래그해 조절(리사이즈)
- 헤더를 클릭해 해당 열 기준으로 데이터 정렬
- 테이블 자체적으로 세로/가로 스크롤 지원, 헤더 행 고정(freeze)
- 홀수/짝수 행 배경색 교대 표시(줄무늬)
- 테두리를 안쪽/바깥쪽 따로 켜고 끄기

이런 기능 하나하나를 `Columns()`로 직접 구현하려면 상당히 번거로운 수작업이 필요했지만, 테이블 API는 이를 프레임워크 차원에서 지원합니다. 그래서 Dear ImGui 공식 문서에서도 새로운 코드에서는 `Columns()`보다 `BeginTable()`을 사용할 것을 권장하고 있습니다. 이 책에서도 앞으로 여러 열로 구성된 데이터를 보여줄 일이 있다면 항상 테이블 API를 기본으로 사용합니다.

## 테이블의 기본 골격

테이블을 그리는 코드는 다음과 같은 형태를 항상 따릅니다.

```cpp
if (ImGui::BeginTable("점수표", 3))
{
    ImGui::TableSetupColumn("이름");
    ImGui::TableSetupColumn("점수");
    ImGui::TableSetupColumn("등급");
    ImGui::TableHeadersRow();

    for (int row = 0; row < rowCount; row++)
    {
        ImGui::TableNextRow();

        ImGui::TableNextColumn();
        ImGui::Text("%s", students[row].name.c_str());

        ImGui::TableNextColumn();
        ImGui::Text("%d", students[row].score);

        ImGui::TableNextColumn();
        ImGui::Text("%c", students[row].grade);
    }

    ImGui::EndTable();
}
```

각 함수의 역할을 하나씩 짚어보겠습니다.

- **`ImGui::BeginTable("id", columnCount)`**: 테이블을 시작합니다. 첫 번째 인자는 화면에 보이지 않는 고유 ID이고, 두 번째 인자는 열의 개수입니다. 반환값이 `false`면(테이블이 화면 밖으로 완전히 클리핑된 경우 등) 내부 코드를 실행할 필요가 없으므로 `if`로 감싸는 것이 관례입니다.
- **`ImGui::TableSetupColumn("헤더")`**: 열 하나를 설정합니다. 열 개수만큼 `BeginTable()` 직후에 순서대로 호출해야 하며, 각 열의 헤더 텍스트, 너비, 정렬 가능 여부 등을 여기서 지정할 수 있습니다.
- **`ImGui::TableHeadersRow()`**: 앞서 `TableSetupColumn()`으로 설정한 헤더들을 실제로 한 행으로 그려줍니다. 헤더가 필요 없는 테이블이라면 생략해도 됩니다.
- **`ImGui::TableNextRow()`**: 새로운 행을 시작합니다. 각 행을 그리기 전에 반드시 한 번씩 호출합니다.
- **`ImGui::TableNextColumn()`**: 현재 행에서 다음 셀로 이동합니다. 호출할 때마다 열 인덱스가 하나씩 증가하며, 마지막 열 다음에 다시 호출하면 자동으로 다음 행의 첫 번째 열로 넘어갑니다(단, 새 행의 시작은 `TableNextRow()`로 명시하는 것이 원칙입니다).
- **`ImGui::EndTable()`**: 테이블을 마무리합니다. `BeginTable()`이 `true`를 반환했을 때만 호출해야 한다는 점에서 `Begin()` / `End()`의 짝 규칙과 살짝 다르니 주의하세요(일반 창의 `End()`는 항상 호출해야 하지만, `EndTable()`은 `BeginTable()`이 `true`일 때만 호출합니다).

셀 안에는 `Text()`뿐 아니라 4장에서 배운 어떤 위젯도 넣을 수 있습니다. 버튼, 체크박스, 슬라이더, 입력 필드 모두 셀 안에 자연스럽게 들어갑니다.

## 테이블 플래그로 기능 켜기

테이블의 진짜 힘은 `BeginTable()`의 세 번째 인자로 넘기는 플래그 조합에서 나옵니다.

```cpp
ImGuiTableFlags flags =
    ImGuiTableFlags_Borders |
    ImGuiTableFlags_RowBg |
    ImGuiTableFlags_Resizable |
    ImGuiTableFlags_Sortable |
    ImGuiTableFlags_ScrollY;

if (ImGui::BeginTable("점수표", 3, flags, ImVec2(0, 300)))
{
    // ...
    ImGui::EndTable();
}
```

자주 쓰이는 플래그들을 정리하면 다음과 같습니다.

| 플래그 | 효과 |
|---|---|
| `ImGuiTableFlags_Borders` | 셀 사이에 테두리 표시(내부/외부 모두) |
| `ImGuiTableFlags_BordersV` / `ImGuiTableFlags_BordersH` | 세로/가로 테두리만 선택적으로 표시 |
| `ImGuiTableFlags_RowBg` | 홀수/짝수 행에 배경색을 교대로 입혀 가독성 향상 |
| `ImGuiTableFlags_Resizable` | 헤더 경계를 드래그해서 열 너비 조절 가능 |
| `ImGuiTableFlags_Sortable` | 헤더 클릭으로 정렬 트리거 가능(정렬 로직 자체는 직접 구현) |
| `ImGuiTableFlags_ScrollY` | 테이블 내부에 세로 스크롤 영역 생성(헤더 고정 효과 포함) |
| `ImGuiTableFlags_Reorderable` | 헤더를 드래그해서 열 순서 변경 가능 |
| `ImGuiTableFlags_SizingStretchSame` | 모든 열이 동일한 비율로 남은 너비를 나눠 갖도록 강제 |

`ImGuiTableFlags_Sortable`은 조금 특별한데, 이 플래그는 "사용자가 헤더를 클릭해 정렬을 요청할 수 있게" 해줄 뿐이고 실제로 데이터를 정렬하는 코드는 여러분이 작성해야 합니다. `ImGui::TableGetSortSpecs()`를 호출하면 어떤 열을 기준으로, 오름차순인지 내림차순인지에 대한 정보를 담은 `ImGuiTableSortSpecs*`를 얻을 수 있고, 이 값이 `SpecsDirty == true`일 때만(즉 정렬 기준이 바뀌었을 때만) 실제 정렬을 수행하면 매 프레임 불필요하게 정렬하는 비용을 피할 수 있습니다.

```cpp
if (ImGuiTableSortSpecs* sortSpecs = ImGui::TableGetSortSpecs())
{
    if (sortSpecs->SpecsDirty && sortSpecs->SpecsCount > 0)
    {
        const ImGuiTableColumnSortSpecs& spec = sortSpecs->Specs[0];
        bool ascending = (spec.SortDirection == ImGuiSortDirection_Ascending);

        std::sort(students.begin(), students.end(),
            [&](const Student& a, const Student& b)
            {
                bool less = false;
                switch (spec.ColumnIndex)
                {
                    case 0: less = a.name  < b.name;  break;
                    case 1: less = a.score < b.score; break;
                    case 2: less = a.grade < b.grade; break;
                }
                return ascending ? less : !less;
            });

        sortSpecs->SpecsDirty = false;
    }
}
```

각 열이 정렬 가능한지, 기본 정렬 방향이 무엇인지는 `TableSetupColumn()`의 플래그로 개별 설정할 수 있습니다.

```cpp
ImGui::TableSetupColumn("이름", ImGuiTableColumnFlags_DefaultSort);
ImGui::TableSetupColumn("점수", ImGuiTableColumnFlags_PreferSortDescending);
ImGui::TableSetupColumn("등급", ImGuiTableColumnFlags_NoSort);
```

## 실전 예제: 학생 성적 테이블

지금까지 배운 요소를 모두 합쳐서, 이름/점수/등급으로 구성된 학생 목록을 정렬 가능하고 테두리와 줄무늬가 있는 테이블로 그려보겠습니다.

```cpp
struct Student
{
    std::string name;
    int score;
    char grade;
};

std::vector<Student> students = {
    { "김민준", 88, 'B' },
    { "이서연", 95, 'A' },
    { "박도윤", 72, 'C' },
    { "최지우", 91, 'A' },
    { "정하은", 63, 'D' },
};

void DrawStudentTable()
{
    ImGuiTableFlags flags =
        ImGuiTableFlags_Borders |
        ImGuiTableFlags_RowBg |
        ImGuiTableFlags_Resizable |
        ImGuiTableFlags_Sortable |
        ImGuiTableFlags_ScrollY;

    // 높이를 지정해 5장에서 배운 것처럼 스크롤 영역을 명시적으로 확보한다.
    if (ImGui::BeginTable("학생성적표", 3, flags, ImVec2(0, 200)))
    {
        ImGui::TableSetupColumn("이름", ImGuiTableColumnFlags_WidthStretch);
        ImGui::TableSetupColumn("점수", ImGuiTableColumnFlags_WidthFixed, 80.0f);
        ImGui::TableSetupColumn("등급", ImGuiTableColumnFlags_WidthFixed, 60.0f);
        ImGui::TableHeadersRow();

        if (ImGuiTableSortSpecs* sortSpecs = ImGui::TableGetSortSpecs())
        {
            if (sortSpecs->SpecsDirty && sortSpecs->SpecsCount > 0)
            {
                const ImGuiTableColumnSortSpecs& spec = sortSpecs->Specs[0];
                bool ascending = (spec.SortDirection == ImGuiSortDirection_Ascending);
                std::sort(students.begin(), students.end(),
                    [&](const Student& a, const Student& b)
                    {
                        bool less = false;
                        switch (spec.ColumnIndex)
                        {
                            case 0: less = a.name  < b.name;  break;
                            case 1: less = a.score < b.score; break;
                            case 2: less = a.grade < b.grade; break;
                        }
                        return ascending ? less : !less;
                    });
                sortSpecs->SpecsDirty = false;
            }
        }

        for (int i = 0; i < (int)students.size(); i++)
        {
            const Student& s = students[i];

            ImGui::TableNextRow();

            ImGui::TableNextColumn();
            ImGui::Text("%s", s.name.c_str());

            ImGui::TableNextColumn();
            ImGui::Text("%d", s.score);

            ImGui::TableNextColumn();
            // 등급에 따라 색을 다르게 표시(12장에서 스타일링을 더 깊이 다룬다).
            ImVec4 color = (s.grade == 'A') ? ImVec4(0.4f, 0.9f, 0.4f, 1.0f)
                                             : ImVec4(1.0f, 1.0f, 1.0f, 1.0f);
            ImGui::TextColored(color, "%c", s.grade);
        }

        ImGui::EndTable();
    }
}
```

이 예제에서 눈여겨볼 부분은 `TableSetupColumn()`에 너비 관련 플래그를 준 것입니다. `ImGuiTableColumnFlags_WidthStretch`를 받은 "이름" 열은 남은 공간을 유동적으로 채우고, `ImGuiTableColumnFlags_WidthFixed`를 받은 "점수"와 "등급" 열은 지정한 픽셀 너비를 고정으로 유지합니다. `ImGuiTableFlags_Resizable` 플래그가 함께 켜져 있으므로, 사용자가 실행 중에 헤더 경계를 드래그하면 이 초기값을 기준으로 자유롭게 너비를 조절할 수 있습니다.

## 셀 안에 인터랙티브한 위젯 넣기

테이블 셀 안에 버튼이나 체크박스처럼 클릭 가능한 위젯을 넣을 때는 7장에서 다룬 ID 충돌 문제가 그대로 적용됩니다. 행마다 같은 라벨의 버튼을 반복해서 그리면 반드시 `PushID()`로 감싸야 합니다.

```cpp
for (int i = 0; i < (int)students.size(); i++)
{
    ImGui::TableNextRow();
    ImGui::PushID(i);

    ImGui::TableNextColumn();
    ImGui::Text("%s", students[i].name.c_str());

    ImGui::TableNextColumn();
    ImGui::Text("%d", students[i].score);

    ImGui::TableNextColumn();
    if (ImGui::Button("삭제"))
    {
        students.erase(students.begin() + i);
        ImGui::PopID();
        break; // 벡터가 변경되었으므로 이번 프레임의 순회는 여기서 중단한다.
    }

    ImGui::PopID();
}
```

행을 지우는 것처럼 순회 중인 컨테이너 자체를 수정하는 작업은 인덱스를 어긋나게 만들 수 있으므로, 삭제가 일어난 즉시 `break`로 루프를 빠져나오는 방식이 안전합니다.

## 요약

- 여러 열로 구성된 데이터를 보여줄 때는 구식 `Columns()` API 대신 `BeginTable()`로 시작하는 최신 테이블 API를 사용해야 합니다. 정렬, 리사이즈, 스크롤, 헤더 고정 등 실무에 필요한 기능을 표준적으로 제공하기 때문입니다.
- 테이블의 기본 골격은 `BeginTable()` → 열 개수만큼 `TableSetupColumn()` → (선택) `TableHeadersRow()` → 각 행마다 `TableNextRow()`와 셀마다 `TableNextColumn()` → `EndTable()` 순서로 이루어집니다.
- `ImGuiTableFlags_Borders`, `_RowBg`, `_Resizable`, `_Sortable`, `_ScrollY` 등의 플래그를 조합해 테이블의 시각적 스타일과 기능을 손쉽게 켤 수 있습니다.
- `ImGuiTableFlags_Sortable`은 헤더 클릭 UI만 제공할 뿐 실제 정렬은 `TableGetSortSpecs()`로 얻은 정보를 바탕으로 직접 구현해야 하며, `SpecsDirty` 플래그로 불필요한 재정렬을 피할 수 있습니다.
- 테이블 셀 안에 버튼 등 인터랙티브 위젯을 반복해서 넣을 때는 7장에서 배운 ID 충돌 문제가 그대로 적용되므로 `PushID()` / `PopID()`로 각 행을 감싸야 합니다.

## 연습문제

1. 5장에서 만들었던 레이아웃 중 `Columns()`를 사용했던 부분이 있다면 `BeginTable()`로 바꿔보고, 어떤 코드가 더 간결해지는지 비교해보세요.
2. 이름/재고수량/단가 세 열로 구성된 상품 목록 테이블을 만들고, `ImGuiTableFlags_Sortable`을 켜서 각 열 기준으로 오름차순/내림차순 정렬이 되도록 구현해보세요.
3. `ImGuiTableFlags_ScrollY`와 고정 높이를 지정해 100개 이상의 행을 담은 테이블을 만들고, 첫 번째 행(헤더)이 스크롤해도 항상 보이는지 확인해보세요.
4. 테이블의 마지막 열에 "수정" 체크박스를 두어, 체크된 행만 색이 다르게 표시되도록 만들어보세요. 이때 체크박스 라벨의 ID 충돌을 어떻게 피했는지 설명해보세요.
5. `ImGuiTableColumnFlags_WidthStretch`와 `ImGuiTableColumnFlags_WidthFixed`를 각각 다른 열에 섞어서 사용해보고, 창 크기를 늘리거나 줄일 때 두 방식의 열이 어떻게 다르게 반응하는지 관찰해보세요.
