C++ 즉시 모드(immediate mode) GUI 라이브러리 Dear ImGui 입문서입니다. 즉시 모드의 핵심
개념부터 기본 위젯, 레이아웃, 테이블, 도킹, 커스텀 렌더링, 스타일링, 상태 관리 패턴, 성능
최적화, 실전 프로젝트까지 순서대로 다룹니다.

각 장은 개념 설명, C++ 예제 코드, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는 이해를
돕는 다이어그램을 함께 실었습니다.
