## A.1 설치 가이드 요약

본문에서는 학습 흐름을 방해하지 않도록 설치 과정을 간략히만 다루었습니다. 여기서는 2장에서 소개한 내용을 한 페이지 분량으로 다시 정리합니다. 실제 화면 구성은 Qt 버전에 따라 조금씩 달라질 수 있으므로, 스크린샷 대신 전체적인 흐름과 각 단계에서 유의할 점을 중심으로 설명합니다.

### Qt Online Installer를 이용한 설치

1. The Qt Company 계정을 만듭니다. 오픈소스 사용자도 무료로 계정을 만들 수 있습니다.
2. Qt Online Installer를 내려받아 실행하고, 계정으로 로그인합니다.
3. 설치할 Qt 버전을 선택합니다. 이 책은 Qt 5.15와 Qt 6 계열 모두를 기준으로 예제를 검증했으므로, 최신 Qt 6 LTS 버전을 선택하는 것이 무난합니다.
4. 함께 설치할 컴파일러 툴체인을 선택합니다. Windows에서는 MSVC 또는 MinGW, macOS에서는 Xcode Clang 연동, Linux에서는 시스템 GCC를 사용하는 구성이 일반적입니다.
5. Qt Creator, Qt Debug Information Files, CMake, Ninja 등 부가 도구 항목을 함께 선택할 수 있습니다. 이미 별도의 CMake나 컴파일러를 갖추고 있다면 중복 설치할 필요는 없습니다.
6. 설치가 끝나면 Qt 라이브러리는 버전과 툴체인별 하위 폴더(예: `6.7.0/msvc2019_64`, `6.7.0/gcc_64`)로 나뉘어 설치됩니다. 이 경로를 기억해 두어야 CMake 설정 시 활용할 수 있습니다.

### 패키지 매니저를 이용한 설치

Qt Online Installer 대신 운영체제의 패키지 매니저(Linux 배포판의 `apt`/`dnf`/`pacman`, macOS의 Homebrew, C++ 패키지 매니저인 vcpkg 등)로도 Qt를 설치할 수 있습니다. 설치 경로가 표준 시스템 경로에 잡히는 경우가 많아 CMake가 별도 설정 없이도 Qt를 찾아내는 경우가 많다는 것이 장점이지만, 배포판이 제공하는 Qt 버전이 최신이 아닐 수 있다는 점은 감안해야 합니다.

### CMake와의 연동 요약

- Qt 6는 CMake를 공식 빌드 시스템으로 채택하고 있으며, `find_package(Qt6 REQUIRED COMPONENTS Widgets)`처럼 필요한 모듈만 선택적으로 찾아 사용합니다.
- Qt를 표준 경로가 아닌 곳에 설치했다면 `CMAKE_PREFIX_PATH`에 Qt 설치 경로를 지정해야 CMake가 이를 찾을 수 있습니다.
- `CMAKE_AUTOMOC`, `CMAKE_AUTOUIC`, `CMAKE_AUTORCC`를 켜 두면 MOC, `.ui` 파일, `.qrc` 리소스 파일 처리가 빌드 과정에 자동으로 연결됩니다.
- Qt Creator를 사용하면 `CMakeLists.txt`를 여는 것만으로 프로젝트 구조 인식과 빌드/실행 버튼이 자동으로 구성되지만, 이 책의 모든 예제는 Qt Creator 없이 명령행 CMake만으로도 동일하게 따라 할 수 있습니다.

이보다 상세한 설치 절차, 운영체제별 세부 화면, 문제 해결 방법은 Qt 공식 문서의 설치 가이드를 참고하시기 바랍니다.

## A.2 이 책에 등장한 주요 클래스 요약표

아래 표는 각 장에서 다룬 대표 클래스를 정리한 것입니다. 복습하거나 특정 기능이 어느 장에서 다뤄졌는지 빠르게 찾아볼 때 활용하시기 바랍니다. 클래스 이름은 실제 Qt API의 이름을 그대로 표기했습니다.

### 1~2장. 기초와 개발 환경

| 클래스 | 역할 |
|---|---|
| `QApplication` | QWidgets 애플리케이션의 진입점. 이벤트 루프와 애플리케이션 전역 설정을 관리 |
| `QWidget` | 모든 UI 구성요소의 기반 클래스. 부모 없이 생성하면 최상위 창이 됨 |
| `QLabel` | 텍스트나 이미지를 표시하는 가장 단순한 위젯 |
| `QObject` | Qt 객체 모델의 근간. 시그널/슬롯, 부모-자식 트리, 동적 프로퍼티의 기반 |

### 3장. 시그널과 슬롯

| 클래스/매크로 | 역할 |
|---|---|
| `Q_OBJECT` | MOC가 처리해야 할 클래스임을 표시하는 매크로 |
| `QObject::connect()` | 시그널과 슬롯(또는 함수, 람다)을 연결하는 정적 함수 |
| `Qt::ConnectionType` | 연결 방식(Auto, Direct, Queued 등)을 지정하는 열거형 |

### 4장. 기본 위젯과 레이아웃 시스템

| 클래스 | 역할 |
|---|---|
| `QPushButton` / `QLabel` / `QLineEdit` | 버튼, 텍스트 표시, 한 줄 텍스트 입력을 위한 기본 위젯 |
| `QCheckBox` / `QRadioButton` / `QComboBox` | 체크박스, 라디오 버튼, 드롭다운 선택 위젯 |
| `QSlider` / `QSpinBox` | 슬라이더와 숫자 스핀 입력 위젯 |
| `QVBoxLayout` / `QHBoxLayout` | 위젯을 세로/가로로 배치하는 레이아웃 |
| `QGridLayout` / `QFormLayout` | 격자 배치, 레이블-입력 쌍 배치에 특화된 레이아웃 |
| `QSizePolicy` | 레이아웃 안에서 위젯이 차지할 크기 정책을 지정 |

### 5장. 메뉴, 툴바, 상태바

| 클래스 | 역할 |
|---|---|
| `QMainWindow` | 메뉴바, 툴바, 상태바, 도킹 위젯을 위한 표준 레이아웃을 갖춘 최상위 창 |
| `QAction` | 메뉴 항목, 툴바 버튼, 단축키를 하나의 객체로 표현하고 여러 곳에서 재사용 |
| `QMenuBar` / `QMenu` | 메뉴바와 드롭다운 메뉴 |
| `QToolBar` | 자주 쓰는 액션을 아이콘/버튼으로 배치하는 도구 모음 |
| `QStatusBar` | 창 하단에 상태 메시지와 상시 위젯을 표시 |

### 6장. 다이얼로그

## A.3 참고 자료 안내

이 책을 마친 후 더 깊이 학습하고 싶다면 다음과 같은 공식 자료를 활용하는 것을 권장합니다.

- **Qt 공식 문서**: 모든 클래스의 멤버 함수, 시그널, 슬롯, 열거형이 예제 코드와 함께 정리되어 있는 가장 신뢰할 수 있는 참고 자료입니다. 이 책에서 다룬 클래스 이름을 그대로 검색하면 훨씬 상세한 설명과 함께 이 책이 다루지 않은 부가 기능들을 확인할 수 있습니다.
- **Qt Creator에 내장된 문서 뷰어**: Qt Creator를 설치했다면 IDE 안에서 바로 클래스 문서를 검색하고 열어볼 수 있는 기능이 내장되어 있습니다. 코드를 작성하다가 곧바로 문서를 확인할 수 있어 편리합니다.
- **Qt 예제 모음**: Qt SDK에는 이 책에서 다루지 않은 다양한 예제 프로젝트(그래픽스 뷰, 애니메이션, 웹 엔진 등)가 함께 설치됩니다. Qt Creator의 예제 탐색 기능을 통해 열람할 수 있습니다.
- **Qt 릴리스 노트**: Qt 5에서 Qt 6로 넘어오며 달라진 API나 새로 추가된 기능을 확인하려면 버전별 릴리스 노트를 참고하는 것이 가장 정확합니다.

이 책에서는 특정 URL을 나열하지 않았습니다. 위에서 언급한 자료들은 모두 검색을 통해 쉽게 찾을 수 있으며, Qt 문서 사이트 안에서도 검색 기능으로 상호 연결되어 있으므로 자료 하나만 찾아도 나머지로 쉽게 이동할 수 있습니다.

## A.4 다음 학습 단계 제안

이 책은 QWidgets 기반 데스크톱 GUI 프로그래밍의 핵심을 다뤘지만, Qt의 세계는 이보다 훨씬 넓습니다. 이 책을 마친 후 관심사에 따라 다음과 같은 방향으로 학습을 이어갈 수 있습니다.

- **커스텀 위젯과 그래픽스 뷰**: `QWidget`을 직접 상속하여 `paintEvent()`로 완전히 새로운 모양의 위젯을 만들거나, `QGraphicsView`/`QGraphicsScene` 프레임워크로 다이어그램 편집기, 게임, 도면 도구처럼 수많은 도형 객체를 다루는 화면을 구성하는 방향입니다.
- **국제화(i18n)**: `tr()` 함수로 감싸 둔 문자열들을 실제로 다국어로 번역하고 배포하려면 Qt Linguist와 `lupdate`/`lrelease` 도구, `QTranslator` 클래스를 학습해야 합니다. 이 책의 예제 코드는 이미 `tr()`을 일관되게 사용하고 있으므로 국제화를 적용하기 좋은 출발점입니다.
- **QML/Qt Quick 심화**: 16장에서 맛보기로 다룬 QML을 더 깊이 파고들면, 애니메이션이 풍부한 터치 UI나 모바일 애플리케이션을 만드는 능력을 갖출 수 있습니다.
- **테스트 자동화**: `QtTest` 모듈을 사용하면 GUI 애플리케이션의 단위 테스트와 UI 이벤트 시뮬레이션 테스트를 작성할 수 있습니다. 실무 프로젝트로 갈수록 중요해지는 영역입니다.
- **플랫폼별 심화 배포**: 17장에서 다룬 배포 개념을 바탕으로, 실제 설치 프로그램 제작 도구(예: Windows의 인스톨러 제작 도구, macOS의 코드 서명과 공증, Linux 패키지 저장소 배포)를 더 깊이 학습하면 제품을 실제 사용자에게 전달하는 전체 파이프라인을 완성할 수 있습니다.
- **직접 프로젝트 확장하기**: 가장 좋은 학습 방법은 18장에서 만든 메모장 애플리케이션을 계속 확장해 보는 것입니다. 찾기/바꾸기, 다크 테마, 최근 파일 목록, 여러 탭으로 파일을 동시에 여는 기능 등을 하나씩 직접 구현해 보면, 이 책에서 배운 개념들이 실전 감각으로 자연스럽게 이어질 것입니다.

Qt는 방대한 프레임워크이며, 한 권의 책으로 모든 것을 다룰 수는 없습니다. 하지만 이 책에서 익힌 시그널/슬롯, 위젯 계층, 모델/뷰, 이벤트 처리, 파일과 데이터베이스 연동 같은 핵심 개념은 Qt의 어느 모듈을 학습하더라도 계속 재사용되는 기반이 됩니다. 새로운 모듈을 만나더라도 낯설게 느껴지지 않는다면, 그것이 이 책의 목표가 달성되었다는 뜻입니다.
