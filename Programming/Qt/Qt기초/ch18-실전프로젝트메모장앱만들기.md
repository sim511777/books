## 18.1 프로젝트 개요

이 장에서는 지금까지 배운 내용을 종합하여 실제로 쓸 수 있는 수준의 텍스트 편집기, 이른바 "메모장" 애플리케이션을 처음부터 끝까지 만들어 봅니다. 메뉴와 툴바(5장에서 다룬 내용), 표준 다이얼로그(6장), 상태바, 파일 입출력(11장), 그리고 필요하다면 스타일시트(10장)까지 이 책에서 배운 여러 요소를 하나의 프로그램 안에서 결합해 볼 것입니다.

완성할 애플리케이션의 요구사항은 다음과 같습니다.

- `QMainWindow`를 기반으로 하고, 중앙 위젯으로 `QPlainTextEdit`를 사용하는 일반 텍스트 편집기입니다.
- **파일 메뉴**: 새 파일, 열기, 저장, 다른 이름으로 저장, 종료
- **편집 메뉴**: 실행 취소, 다시 실행, 잘라내기, 복사, 붙여넣기
- 자주 쓰는 기능에 빠르게 접근할 수 있는 **툴바**
- 현재 커서 위치(줄/열)와 문서 수정 여부를 보여주는 **상태바**
- 파일을 열고 저장할 때 `QFileDialog` 사용
- 문서가 수정되었는지 `QTextDocument::isModified()`로 추적하고, 제목 표시줄에 반영
- 저장하지 않은 상태로 창을 닫으려 할 때 저장 여부를 묻는 확인 대화상자 표시(`closeEvent` 재정의)

이 장은 클래스를 한 번에 완성하지 않고, 기능을 하나씩 추가해 나가는 방식으로 진행합니다. 마지막 절에서 전체 소스 코드를 다시 한번 모아서 제시합니다.

## 18.2 프로젝트 구조와 빌드 설정

프로젝트는 다음과 같은 파일로 구성합니다.

```
NotepadApp/
    CMakeLists.txt
    main.cpp
    mainwindow.h
    mainwindow.cpp
```

`CMakeLists.txt`는 17장에서 다룬 내용을 그대로 적용합니다.

```cmake
cmake_minimum_required(VERSION 3.16)
project(NotepadApp LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(CMAKE_AUTOMOC ON)

if(NOT CMAKE_BUILD_TYPE AND NOT CMAKE_CONFIGURATION_TYPES)
    set(CMAKE_BUILD_TYPE Release CACHE STRING "Build type" FORCE)
endif()

find_package(Qt6 REQUIRED COMPONENTS Widgets)

add_executable(NotepadApp
    main.cpp
    mainwindow.cpp
    mainwindow.h
)

target_link_libraries(NotepadApp PRIVATE Qt6::Widgets)
```

> Qt 5를 사용한다면 `find_package(Qt6 ...)`를 `find_package(Qt5 ...)`로, `Qt6::Widgets`를 `Qt5::Widgets`로 바꾸면 됩니다. 이 장의 예제 코드 자체는 Qt 5.15와 Qt 6 양쪽에서 모두 그대로 컴파일됩니다.

## 18.3 메인 윈도우 골격 만들기

먼저 `QMainWindow`를 상속하는 `MainWindow` 클래스의 뼈대를 만듭니다. 중앙 위젯으로 `QPlainTextEdit`를 배치하는 것부터 시작합니다.

```cpp
// mainwindow.h
#pragma once

#include <QMainWindow>
#include <QString>

QT_BEGIN_NAMESPACE
class QPlainTextEdit;
class QLabel;
class QCloseEvent;
QT_END_NAMESPACE

class MainWindow : public QMainWindow
{
    Q_OBJECT

public:
    explicit MainWindow(QWidget *parent = nullptr);

private:
    QPlainTextEdit *m_editor;
};
```

```cpp
// mainwindow.cpp (초기 버전)
#include "mainwindow.h"

#include <QPlainTextEdit>

MainWindow::MainWindow(QWidget *parent)
    : QMainWindow(parent)
    , m_editor(new QPlainTextEdit(this))
{
    setCentralWidget(m_editor);
    setWindowTitle(tr("제목 없음 - 메모장"));
    resize(800, 600);
}
```

`QPlainTextEdit`는 `QTextEdit`와 달리 서식 없는 순수 텍스트 편집에 최적화된 위젯으로, 큰 텍스트 파일을 다룰 때도 효율적으로 동작합니다. 메모장 같은 일반 텍스트 편집기에는 `QPlainTextEdit`가 자연스러운 선택입니다.

## 18.4 메뉴와 액션 구성

이제 파일 메뉴와 편집 메뉴를 추가합니다. Qt에서는 메뉴 항목, 툴바 버튼, 단축키를 모두 `QAction` 하나로 표현하고 여러 곳에서 재사용하는 것이 표준적인 방식입니다. 편집 메뉴의 각 항목은 `QPlainTextEdit`가 이미 제공하는 슬롯(`undo()`, `redo()`, `cut()`, `copy()`, `paste()`)에 직접 연결할 수 있습니다.

먼저 헤더에 필요한 멤버와 슬롯을 추가합니다.

```cpp
// mainwindow.h (발췌)
private slots:
    void newFile();
    void openFile();
    bool saveFile();
    bool saveFileAs();

private:
    void createActions();
    void createToolBars();

    QPlainTextEdit *m_editor;

    QAction *m_openAction;
    QAction *m_saveAction;
    QAction *m_undoAction;
    QAction *m_redoAction;
    QAction *m_cutAction;
    QAction *m_copyAction;
    QAction *m_pasteAction;
```

`createActions()`에서는 `QMenu::addAction()`의 함수 포인터(functor) 오버로드를 사용하여 액션 생성과 시그널 연결, 단축키 지정을 한 번에 처리합니다.

```cpp
#include <QAction>
#include <QKeySequence>
#include <QMenu>
#include <QMenuBar>

void MainWindow::createActions()
{
    // ----- 파일 메뉴 -----
    QMenu *fileMenu = menuBar()->addMenu(tr("파일(&F)"));

    fileMenu->addAction(tr("새 파일(&N)"), this, &MainWindow::newFile,
                         QKeySequence::New);

    m_openAction = fileMenu->addAction(tr("열기(&O)..."), this, &MainWindow::openFile,
                                        QKeySequence::Open);

    m_saveAction = fileMenu->addAction(tr("저장(&S)"), this, &MainWindow::saveFile,
                                        QKeySequence::Save);

    fileMenu->addAction(tr("다른 이름으로 저장(&A)..."), this, &MainWindow::saveFileAs,
                         QKeySequence::SaveAs);

    fileMenu->addSeparator();

    fileMenu->addAction(tr("종료(&X)"), this, &QWidget::close, QKeySequence::Quit);

    // ----- 편집 메뉴 -----
    QMenu *editMenu = menuBar()->addMenu(tr("편집(&E)"));

    m_undoAction = editMenu->addAction(tr("실행 취소(&U)"), m_editor, &QPlainTextEdit::undo,
                                        QKeySequence::Undo);
    m_redoAction = editMenu->addAction(tr("다시 실행(&R)"), m_editor, &QPlainTextEdit::redo,
                                        QKeySequence::Redo);

    editMenu->addSeparator();

    m_cutAction = editMenu->addAction(tr("잘라내기(&T)"), m_editor, &QPlainTextEdit::cut,
                                       QKeySequence::Cut);
    m_copyAction = editMenu->addAction(tr("복사(&C)"), m_editor, &QPlainTextEdit::copy,
                                        QKeySequence::Copy);
    m_pasteAction = editMenu->addAction(tr("붙여넣기(&P)"), m_editor, &QPlainTextEdit::paste,
                                         QKeySequence::Paste);
}
```

`QKeySequence::New`, `QKeySequence::Open`처럼 표준 키 시퀀스 열거값을 사용하면 운영체제별 관례(Windows/Linux는 Ctrl 조합, macOS는 Cmd 조합)에 맞춰 단축키가 자동으로 결정됩니다.

실행 취소/다시 실행, 잘라내기/복사 버튼은 항상 활성화되어 있으면 안 됩니다. 되돌릴 내용이 없을 때는 비활성화되어야 자연스러운데, 마침 `QPlainTextEdit`가 이런 상태 변화를 알려주는 시그널을 제공합니다.

```cpp
// MainWindow 생성자 안에서 연결
connect(m_editor, &QPlainTextEdit::undoAvailable, m_undoAction, &QAction::setEnabled);
connect(m_editor, &QPlainTextEdit::redoAvailable, m_redoAction, &QAction::setEnabled);
connect(m_editor, &QPlainTextEdit::copyAvailable, m_cutAction, &QAction::setEnabled);
connect(m_editor, &QPlainTextEdit::copyAvailable, m_copyAction, &QAction::setEnabled);

m_undoAction->setEnabled(false);
m_redoAction->setEnabled(false);
m_cutAction->setEnabled(false);
m_copyAction->setEnabled(false);
```

`undoAvailable(bool)`과 `redoAvailable(bool)`은 실행 취소/다시 실행 스택에 항목이 있는지를, `copyAvailable(bool)`은 현재 선택된 텍스트가 있는지를 알려주는 시그널입니다. 이 값을 `QAction::setEnabled(bool)` 슬롯에 그대로 연결하면 별도의 조건문 없이 버튼 활성/비활성이 자동으로 관리됩니다.

## 18.5 툴바 구성

메뉴에서 만든 `QAction`을 그대로 재사용하여 툴바를 구성합니다. 같은 `QAction` 객체를 메뉴와 툴바에 동시에 추가하면, 한쪽 상태(활성화 여부, 체크 상태 등)가 바뀔 때 다른 쪽에도 자동으로 반영됩니다.

```cpp
#include <QToolBar>

void MainWindow::createToolBars()
{
    QToolBar *toolBar = addToolBar(tr("도구 모음"));
    toolBar->setToolButtonStyle(Qt::ToolButtonTextOnly);

    toolBar->addAction(m_openAction);
    toolBar->addAction(m_saveAction);
    toolBar->addSeparator();
    toolBar->addAction(m_undoAction);
    toolBar->addAction(m_redoAction);
    toolBar->addSeparator();
    toolBar->addAction(m_cutAction);
    toolBar->addAction(m_copyAction);
    toolBar->addAction(m_pasteAction);
}
```

아이콘 리소스를 아직 준비하지 않았으므로 `setToolButtonStyle(Qt::ToolButtonTextOnly)`로 버튼에 텍스트만 표시하도록 했습니다. 아이콘을 추가하고 싶다면 각 액션을 만들 때 `QIcon`을 함께 지정하고, 툴바 스타일을 `Qt::ToolButtonTextUnderIcon` 등으로 바꾸면 됩니다.

## 18.6 상태바: 커서 위치와 수정 여부 표시

상태바에는 두 개의 `QLabel`을 상시 위젯(permanent widget)으로 배치하여 커서 위치와 문서 수정 여부를 보여줍니다.

```cpp
// mainwindow.h (발췌)
private slots:
    void updateCursorPositionLabel();
    void updateModifiedLabel(bool modified);

private:
    void createStatusBar();

    QLabel *m_cursorPosLabel;
    QLabel *m_modifiedLabel;
```

```cpp
#include <QLabel>
#include <QStatusBar>
#include <QTextCursor>

void MainWindow::createStatusBar()
{
    m_cursorPosLabel = new QLabel(this);
    m_modifiedLabel = new QLabel(this);

    statusBar()->addPermanentWidget(m_cursorPosLabel);
    statusBar()->addPermanentWidget(m_modifiedLabel);

    statusBar()->showMessage(tr("준비"));
}

void MainWindow::updateCursorPositionLabel()
{
    const QTextCursor cursor = m_editor->textCursor();
    const int line = cursor.blockNumber() + 1;
    const int column = cursor.positionInBlock() + 1;
    m_cursorPosLabel->setText(tr("줄 %1, 열 %2").arg(line).arg(column));
}

void MainWindow::updateModifiedLabel(bool modified)
{
    m_modifiedLabel->setText(modified ? tr("수정됨") : tr("저장됨"));
}
```

`QTextCursor::blockNumber()`는 0부터 시작하는 줄(문단) 번호를, `positionInBlock()`은 해당 줄 안에서의 0부터 시작하는 위치를 돌려주므로, 사람이 읽기 편하도록 각각 1을 더해 표시했습니다.

`updateCursorPositionLabel()`은 `QPlainTextEdit::cursorPositionChanged()` 시그널에, `updateModifiedLabel()`은 `QPlainTextEdit::modificationChanged(bool)` 시그널에 연결합니다.

```cpp
connect(m_editor, &QPlainTextEdit::cursorPositionChanged,
        this, &MainWindow::updateCursorPositionLabel);
connect(m_editor, &QPlainTextEdit::modificationChanged,
        this, &MainWindow::updateModifiedLabel);
```

## 18.7 파일 열기와 저장 구현

파일을 실제로 읽고 쓰는 부분은 11장에서 다룬 `QFile`, `QTextStream`, 그리고 `QFileDialog`를 조합합니다.

```cpp
// mainwindow.h (발췌)
private slots:
    void newFile();
    void openFile();
    bool saveFile();
    bool saveFileAs();

private:
    bool readFromFile(const QString &path);
    bool writeToFile(const QString &path);
    void setCurrentFile(const QString &path);
    QString strippedName(const QString &fullPath) const;

    QString m_currentFilePath;
```

```cpp
#include <QFile>
#include <QFileDialog>
#include <QFileInfo>
#include <QMessageBox>
#include <QTextStream>

void MainWindow::newFile()
{
    if (!maybeSave())
        return;

    m_editor->clear();
    setCurrentFile(QString());
}

void MainWindow::openFile()
{
    if (!maybeSave())
        return;

    const QString path = QFileDialog::getOpenFileName(
        this, tr("파일 열기"), QString(), tr("텍스트 파일 (*.txt);;모든 파일 (*)"));

    if (path.isEmpty())
        return;

    if (readFromFile(path))
        setCurrentFile(path);
}

bool MainWindow::saveFile()
{
    if (m_currentFilePath.isEmpty())
        return saveFileAs();

    return writeToFile(m_currentFilePath);
}

bool MainWindow::saveFileAs()
{
    const QString path = QFileDialog::getSaveFileName(
        this, tr("다른 이름으로 저장"), QString(), tr("텍스트 파일 (*.txt);;모든 파일 (*)"));

    if (path.isEmpty())
        return false;

    if (!writeToFile(path))
        return false;

    setCurrentFile(path);
    return true;
}

bool MainWindow::readFromFile(const QString &path)
{
    QFile file(path);
    if (!file.open(QIODevice::ReadOnly | QIODevice::Text)) {
        QMessageBox::warning(this, tr("파일 열기 실패"),
                              tr("%1 파일을 열 수 없습니다.\n%2")
                                  .arg(path, file.errorString()));
        return false;
    }

    QTextStream in(&file);
    m_editor->setPlainText(in.readAll());
    return true;
}

bool MainWindow::writeToFile(const QString &path)
{
    QFile file(path);
    if (!file.open(QIODevice::WriteOnly | QIODevice::Text)) {
        QMessageBox::warning(this, tr("파일 저장 실패"),
                              tr("%1 파일에 쓸 수 없습니다.\n%2")
                                  .arg(path, file.errorString()));
        return false;
    }

    QTextStream out(&file);
    out << m_editor->toPlainText();

    m_editor->document()->setModified(false);
    return true;
}
```

파일을 여닫는 함수들이 값을 반환하도록(`bool`) 만들어 둔 이유는, 저장이 실제로 성공했는지에 따라 호출하는 쪽(예: 종료 확인 로직)이 다음 동작을 결정할 수 있게 하기 위해서입니다.

## 18.8 수정 여부 추적과 제목 표시줄 반영

Qt의 창 제목에는 `[*]`라는 특수한 자리표시자를 넣을 수 있습니다. `QWidget::setWindowModified(bool)`을 호출해 창의 수정 상태를 `true`로 설정하면 이 자리표시자가 별표(`*`)로, `false`로 설정하면 빈 문자열로 자동 치환됩니다.

```cpp
void MainWindow::setCurrentFile(const QString &path)
{
    m_currentFilePath = path;
    m_editor->document()->setModified(false);
    setWindowModified(false);
    updateModifiedLabel(false);

    const QString shownName = path.isEmpty() ? tr("제목 없음") : strippedName(path);
    setWindowTitle(tr("%1[*] - 메모장").arg(shownName));
}

QString MainWindow::strippedName(const QString &fullPath) const
{
    return QFileInfo(fullPath).fileName();
}
```

문서가 수정될 때마다 `[*]`가 자동으로 갱신되게 하려면, `QPlainTextEdit::modificationChanged(bool)` 시그널을 `QWidget::setWindowModified(bool)` 슬롯에 그대로 연결하면 됩니다.

```cpp
connect(m_editor, &QPlainTextEdit::modificationChanged,
        this, &QWidget::setWindowModified);
```

이렇게 하면 사용자가 글자를 한 글자만 입력해도 제목 표시줄에 즉시 `*`가 나타나고, 저장에 성공하여 `document()->setModified(false)`가 호출되면 다시 사라집니다.

## 18.9 종료 시 저장 확인: closeEvent 재정의

사용자가 저장하지 않은 내용을 가진 채로 창을 닫으려 할 때는 저장할지 물어봐야 합니다. `QMainWindow`(정확히는 `QWidget`)가 닫히기 직전에 호출하는 `closeEvent(QCloseEvent *event)`를 재정의하여 이를 구현합니다.

```cpp
// mainwindow.h (발췌)
protected:
    void closeEvent(QCloseEvent *event) override;

private:
    bool maybeSave();
```

```cpp
#include <QCloseEvent>
#include <QMessageBox>

void MainWindow::closeEvent(QCloseEvent *event)
{
    if (maybeSave()) {
        event->accept();
    } else {
        event->ignore();
    }
}

bool MainWindow::maybeSave()
{
    if (!m_editor->document()->isModified())
        return true;

    const QMessageBox::StandardButton result = QMessageBox::warning(
        this, tr("메모장"),
        tr("문서가 수정되었습니다.\n변경 사항을 저장하시겠습니까?"),
        QMessageBox::Save | QMessageBox::Discard | QMessageBox::Cancel);

    switch (result) {
    case QMessageBox::Save:
        return saveFile();
    case QMessageBox::Discard:
        return true;
    default:
        return false;
    }
}
```

`maybeSave()`는 새 파일을 만들거나(`newFile`), 다른 파일을 열거나(`openFile`), 창을 닫으려 할 때(`closeEvent`) 공통으로 호출되는 함수입니다. 문서가 수정되지 않았다면 곧바로 `true`를 반환해 다음 동작을 그대로 진행시키고, 수정되었다면 저장/취소/무시를 묻는 `QMessageBox`를 띄운 뒤 사용자의 선택에 따라 `true`/`false`를 반환합니다. `event->ignore()`가 호출되면 창이 닫히지 않고 그대로 유지됩니다.

## 18.10 전체 소스 코드

지금까지 단계별로 작성한 코드를 하나로 모으면 다음과 같습니다.

```cpp
// mainwindow.h
#pragma once

#include <QMainWindow>
#include <QString>

QT_BEGIN_NAMESPACE
class QPlainTextEdit;
class QLabel;
class QCloseEvent;
QT_END_NAMESPACE

class MainWindow : public QMainWindow
{
    Q_OBJECT

public:
    explicit MainWindow(QWidget *parent = nullptr);

protected:
    void closeEvent(QCloseEvent *event) override;

private slots:
    void newFile();
    void openFile();
```

```cpp
void MainWindow::updateCursorPositionLabel()
{
    const QTextCursor cursor = m_editor->textCursor();
    const int line = cursor.blockNumber() + 1;
    const int column = cursor.positionInBlock() + 1;
    m_cursorPosLabel->setText(tr("줄 %1, 열 %2").arg(line).arg(column));
}

void MainWindow::updateModifiedLabel(bool modified)
{
    m_modifiedLabel->setText(modified ? tr("수정됨") : tr("저장됨"));
}

void MainWindow::newFile()
{
    if (!maybeSave())
        return;

    m_editor->clear();
    setCurrentFile(QString());
}

void MainWindow::openFile()
{
    if (!maybeSave())
        return;

    const QString path = QFileDialog::getOpenFileName(
        this, tr("파일 열기"), QString(), tr("텍스트 파일 (*.txt);;모든 파일 (*)"));

    if (path.isEmpty())
        return;

    if (readFromFile(path))
        setCurrentFile(path);
}

bool MainWindow::saveFile()
{
    if (m_currentFilePath.isEmpty())
        return saveFileAs();

    return writeToFile(m_currentFilePath);
}

bool MainWindow::saveFileAs()
{
    const QString path = QFileDialog::getSaveFileName(
        this, tr("다른 이름으로 저장"), QString(), tr("텍스트 파일 (*.txt);;모든 파일 (*)"));

    if (path.isEmpty())
        return false;

    if (!writeToFile(path))
        return false;

    setCurrentFile(path);
    return true;
}

bool MainWindow::readFromFile(const QString &path)
{
    QFile file(path);
    if (!file.open(QIODevice::ReadOnly | QIODevice::Text)) {
        QMessageBox::warning(this, tr("파일 열기 실패"),
                              tr("%1 파일을 열 수 없습니다.\n%2")
                                  .arg(path, file.errorString()));
        return false;
    }

    QTextStream in(&file);
    m_editor->setPlainText(in.readAll());
    return true;
}

bool MainWindow::writeToFile(const QString &path)
{
    QFile file(path);
    if (!file.open(QIODevice::WriteOnly | QIODevice::Text)) {
        QMessageBox::warning(this, tr("파일 저장 실패"),
                              tr("%1 파일에 쓸 수 없습니다.\n%2")
                                  .arg(path, file.errorString()));
        return false;
    }

    QTextStream out(&file);
    out << m_editor->toPlainText();

    m_editor->document()->setModified(false);
    return true;
}

void MainWindow::setCurrentFile(const QString &path)
{
    m_currentFilePath = path;
    m_editor->document()->setModified(false);
    setWindowModified(false);
    updateModifiedLabel(false);

    const QString shownName = path.isEmpty() ? tr("제목 없음") : strippedName(path);
    setWindowTitle(tr("%1[*] - 메모장").arg(shownName));
}

QString MainWindow::strippedName(const QString &fullPath) const
{
    return QFileInfo(fullPath).fileName();
}

void MainWindow::closeEvent(QCloseEvent *event)
{
    if (maybeSave()) {
        event->accept();
    } else {
        event->ignore();
    }
}

bool MainWindow::maybeSave()
{
    if (!m_editor->document()->isModified())
        return true;

    const QMessageBox::StandardButton result = QMessageBox::warning(
        this, tr("메모장"),
        tr("문서가 수정되었습니다.\n변경 사항을 저장하시겠습니까?"),
        QMessageBox::Save | QMessageBox::Discard | QMessageBox::Cancel);

    switch (result) {
    case QMessageBox::Save:
        return saveFile();
    case QMessageBox::Discard:
        return true;
    default:
        return false;
    }
}
```

## 18.11 확장 아이디어

완성된 메모장은 기본기에 충실하지만, 실제 제품 수준으로 발전시키려면 다음과 같은 기능을 추가로 고려해 볼 수 있습니다.

- **찾기/바꾸기 기능**: `QDialog`를 상속한 별도의 찾기 대화상자를 만들고, `QPlainTextEdit::find()`(`QTextEdit`에서 상속) 또는 `QTextDocument::find()`를 사용해 텍스트를 검색하고 `QTextCursor`로 선택 영역을 바꿔치기하는 방식으로 구현할 수 있습니다. 6장에서 다룬 사용자 정의 다이얼로그 작성법을 그대로 응용할 수 있는 좋은 연습 주제입니다.
- **다크 테마 적용**: 10장에서 배운 Qt 스타일시트(QSS)를 `qApp->setStyleSheet()`로 적용하거나, 메뉴에 "테마" 항목을 추가해 라이트/다크 스타일시트를 런타임에 전환하도록 만들 수 있습니다.
- **최근 파일 목록**: `QSettings`를 이용해 최근에 연 파일 경로 목록을 저장해 두었다가, 파일 메뉴 하위에 "최근 파일" 서브메뉴로 동적으로 `QAction`을 생성해 보여주는 기능입니다. 애플리케이션을 재시작해도 목록이 유지되도록 만드는 것이 핵심입니다.
- **글꼴 및 자동 줄바꿈 설정**: `QFontDialog`로 편집기 글꼴을 선택하게 하거나, `QPlainTextEdit::setLineWrapMode()`로 자동 줄바꿈 여부를 메뉴에서 토글할 수 있게 만들 수 있습니다.
- **인코딩 처리**: 현재 구현은 `QTextStream`의 기본 인코딩(UTF-8)에 의존합니다. 다양한 인코딩의 텍스트 파일을 다루려면 파일을 열 때 인코딩을 선택하게 하거나 자동 감지 로직을 추가하는 방향으로 확장할 수 있습니다.

## 요약

- `QMainWindow` + 중앙 위젯 `QPlainTextEdit` 구조로 메모장 애플리케이션의 뼈대를 구성했습니다.
- 메뉴, 툴바에서 사용하는 기능을 각각 별도로 구현하지 않고 하나의 `QAction` 객체를 공유함으로써 코드 중복을 줄이고 상태(활성/비활성)를 자동으로 동기화했습니다.
- `QPlainTextEdit`가 제공하는 `undoAvailable`, `redoAvailable`, `copyAvailable`, `cursorPositionChanged`, `modificationChanged` 시그널을 활용하면 상태바와 액션의 활성화 상태를 별도의 폴링 없이 자동으로 갱신할 수 있습니다.
- 파일 열기/저장은 `QFileDialog`로 경로를 얻고 `QFile`과 `QTextStream`으로 실제 입출력을 수행하는 조합으로 구현했습니다.
- 문서 수정 여부는 `QTextDocument::isModified()`로 추적하고, `QWidget::setWindowModified()`와 창 제목의 `[*]` 자리표시자를 이용해 사용자에게 시각적으로 알려줍니다.
- `closeEvent()`를 재정의하고 `maybeSave()`에서 `QMessageBox`로 저장 여부를 물어봄으로써, 저장하지 않은 변경 사항이 실수로 사라지는 것을 방지했습니다.

## 연습문제

1. 이 장의 메모장 애플리케이션에 "모두 선택" 메뉴 항목을 추가하시오. `QPlainTextEdit`의 어떤 슬롯과 어떤 표준 단축키(`QKeySequence`)를 사용해야 하는지 코드로 보이시오.
2. 현재 구현은 파일을 열 때 인코딩을 UTF-8로 가정합니다. 사용자가 파일을 열기 전에 인코딩을 선택할 수 있도록 `QFileDialog`와 결합된 UI를 어떻게 설계할지 서술하시오.
3. `maybeSave()` 함수가 `newFile()`, `openFile()`, `closeEvent()` 세 곳에서 공통으로 호출되는 이유를 설명하고, 만약 이 함수가 없었다면 어떤 문제가 발생할 수 있는지 구체적인 시나리오로 설명하시오.
4. 최근 파일 목록 기능을 추가한다고 할 때, `QSettings`에 어떤 키로 값을 저장하고 애플리케이션 시작 시 어떻게 불러와 메뉴를 구성할지 개략적인 설계를 서술하시오.
5. 편집 메뉴의 잘라내기/복사 액션이 `copyAvailable(bool)` 시그널에 연결되어 있다. 이 시그널이 정확히 어떤 조건에서 `true`/`false`를 전달하는지, 그리고 이를 활용하지 않고 직접 구현한다면 어떤 코드가 필요할지 비교하여 설명하시오.
