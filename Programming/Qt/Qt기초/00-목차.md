# Qt로 배우는 C++ 데스크톱 GUI 프로그래밍

[다음: 1장. Qt란 무엇인가 ▶](ch01-Qt란무엇인가.md)

---

크로스플랫폼 C++ 애플리케이션 프레임워크 Qt를 QWidgets 기반 데스크톱 개발 중심으로 다루는
입문서입니다. 시그널과 슬롯, 기본 위젯과 레이아웃 같은 기초부터 메뉴/툴바/다이얼로그, 모델/뷰
프로그래밍, 커스텀 페인팅, 이벤트 처리, 스타일시트, 파일·설정·데이터베이스 연동, 멀티스레딩,
네트워크 프로그래밍, QML/Qt Quick 연동 기초, 배포와 실전 프로젝트까지 순서대로 다룹니다.

각 장은 개념 설명, C++ 예제 코드, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는 이해를 돕는
다이어그램을 함께 실었습니다.

## 학습 방법 제안

1. 각 장의 예제 코드를 CMake 프로젝트로 옮겨 직접 빌드·실행하며 결과를 확인하세요.
2. 장 끝의 연습문제를 풀어보면서 이해도를 점검하세요.
3. 3장(시그널과 슬롯)은 Qt 전체의 근간이 되는 내용이므로 특히 꼼꼼히 읽어보세요.
4. 16장의 QML 소개는 맛보기 수준이므로, 선언적 UI에 흥미를 느꼈다면 이 저장소의 Slint 책과 비교하며 읽어보는 것도 좋습니다.
5. 18장의 실전 프로젝트는 그동안 배운 내용을 종합하는 자리이니, 코드를 그대로 옮기기보다 스스로 변형해보며 완성해보세요.
