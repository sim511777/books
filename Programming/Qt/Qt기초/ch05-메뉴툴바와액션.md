지금까지 만든 창들은 버튼 몇 개와 입력란이 전부인 단순한 화면이었습니다. 하지만 실제 데스크톱 애플리케이션을 열어 보면 대부분 상단에 메뉴가 있고, 자주 쓰는 기능은 아이콘 버튼이 늘어선 툴바로 빠르게 실행할 수 있으며, 창 아래쪽에는 현재 상태나 진행 상황을 알려주는 상태바가 있습니다. 워드프로세서, 이미지 편집기, IDE 같은 프로그램을 떠올려 보면 이 구조가 얼마나 보편적인지 알 수 있습니다.

Qt는 이런 전형적인 데스크톱 애플리케이션의 뼈대를 `QMainWindow`라는 클래스로 제공합니다. 이번 장에서는 `QMainWindow`의 구조를 이해하고, 메뉴·툴바·단축키가 하나의 명령을 공유하도록 설계된 `QAction`을 배운 뒤, 이를 조합해서 실제 애플리케이션의 뼈대라 할 만한 텍스트 편집기 스켈레톤을 만들어 봅니다.

## 5.1 QMainWindow의 구조

`QMainWindow`는 메뉴바, 하나 이상의 툴바, 상태바, 도킹 위젯 영역, 그리고 중앙 위젯을 표준화된 배치로 담을 수 있는 창 클래스입니다. `QWidget`을 직접 상속해서 이 모든 것을 손으로 배치할 수도 있지만, `QMainWindow`를 쓰면 각 영역이 이미 정해진 자리에 놓이고 서로 겹치지 않도록 레이아웃이 자동으로 관리됩니다.

`QMainWindow`가 관리하는 영역은 다음과 같습니다.

| 영역 | 설명 |
|---|---|
| 메뉴바 | 창 맨 위에 위치하는 `QMenuBar`. `menuBar()`로 접근합니다. |
| 툴바 영역 | 메뉴바 아래(또는 지정한 위치)에 붙는 `QToolBar`들. 여러 개를 추가할 수 있습니다. |
| 중앙 위젯 | 창의 가운데를 채우는 위젯 하나. `setCentralWidget()`으로 지정합니다. |
| 도킹 위젯 영역 | 중앙 위젯 좌우/상하에 붙일 수 있는 `QDockWidget`을 위한 영역입니다. |
| 상태바 | 창 맨 아래에 위치하는 `QStatusBar`. `statusBar()`로 접근합니다. |

`QMainWindow`를 상속해서 창을 만들 때는 보통 다음과 같은 뼈대로 시작합니다.

```cpp
#include <QMainWindow>
#include <QLabel>

class MainWindow : public QMainWindow
{
    Q_OBJECT

public:
    explicit MainWindow(QWidget *parent = nullptr)
        : QMainWindow(parent)
    {
        // 중앙 위젯 지정
        auto *label = new QLabel(tr("중앙 위젯 영역"), this);
        label->setAlignment(Qt::AlignCenter);
        setCentralWidget(label);

        // 메뉴바, 툴바, 상태바는 각각의 접근 함수로 얻어 온다
        setWindowTitle(tr("QMainWindow 예제"));
        resize(640, 480);
    }
};
```

여기서 주목할 점은 `menuBar()`와 `statusBar()`가 "가져오는" 함수라는 것입니다. `QMainWindow`는 이 함수가 처음 호출되는 시점에 필요한 `QMenuBar`/`QStatusBar` 객체를 자동으로 생성해서 반환합니다. 즉 직접 `new QMenuBar()`를 호출해서 붙일 필요가 거의 없습니다. 반면 툴바는 `addToolBar()`를 호출해서 명시적으로 추가해야 합니다. 이 차이는 한 창에 메뉴바와 상태바는 보통 하나씩만 두지만, 툴바는 여러 개를 자유롭게 구성할 수 있기 때문입니다.

`setCentralWidget()`에는 위젯을 하나만 지정할 수 있습니다. 여러 위젯을 중앙에 배치하고 싶다면 지금까지 배운 것처럼 레이아웃을 적용한 컨테이너 위젯(`QWidget` + `QVBoxLayout` 등)을 만들어서 그 컨테이너를 중앙 위젯으로 지정하면 됩니다.

도킹 위젯(`QDockWidget`)은 사용자가 창의 특정 영역을 떼어내거나 다른 위치로 옮길 수 있게 해주는 위젯으로, 파일 탐색기 패널이나 속성 창처럼 보조적인 UI를 배치할 때 사용합니다. 도킹 위젯을 자유롭게 다루는 방법은 이후 장에서 더 큰 예제와 함께 자세히 다루고, 이번 장에서는 `QMainWindow`가 이 영역을 표준으로 제공한다는 사실만 기억해 둡니다.

## 5.2 QAction: 명령을 표현하는 객체

메뉴 항목을 클릭하거나, 툴바의 아이콘 버튼을 누르거나, 키보드 단축키를 누르는 세 가지 방법이 모두 "파일 저장"이라는 같은 명령을 실행한다고 생각해 봅시다. 이 세 가지를 각각 별도의 위젯으로 만들고 각각에 `connect()`를 건다면, 나중에 이 명령을 비활성화하거나 텍스트를 바꿀 때마다 세 곳을 전부 수정해야 합니다.

Qt는 이 문제를 `QAction`이라는 클래스로 해결합니다. `QAction`은 하나의 "명령"을 표현하는 객체로, 텍스트·아이콘·단축키·활성화 여부·체크 상태 등을 한곳에서 관리합니다. 이 액션 객체 하나를 메뉴에도 추가하고 툴바에도 추가하면, 두 UI 요소는 같은 `QAction`을 공유하게 됩니다. 액션의 상태를 바꾸면 메뉴 항목과 툴바 버튼에 동시에 반영됩니다.

```cpp
#include <QAction>

QAction *saveAction = new QAction(tr("저장"), this);
saveAction->setShortcut(QKeySequence::Save);   // Ctrl+S (플랫폼에 따라 다름)
saveAction->setStatusTip(tr("현재 문서를 저장합니다"));
saveAction->setEnabled(false);                  // 아직 저장할 내용이 없음

connect(saveAction, &QAction::triggered, this, &MainWindow::saveFile);
```

`QAction`의 자주 쓰는 멤버 함수는 다음과 같습니다.

| 멤버 함수 | 설명 |
|---|---|
| `setText(const QString &)` | 메뉴/툴바에 표시될 텍스트. `&` 뒤 글자는 단축 문자(Alt+글자)로 동작합니다. |
| `setIcon(const QIcon &)` | 툴바 버튼이나 메뉴 항목 왼쪽에 표시될 아이콘 |
| `setShortcut(const QKeySequence &)` | 단축키 지정 |
| `setStatusTip(const QString &)` | 액션 위에 마우스를 올렸을 때 상태바에 표시할 문구 |
| `setToolTip(const QString &)` | 툴바 버튼에 마우스를 올렸을 때 표시할 툴팁 |
| `setCheckable(bool)` | 토글 가능한(켜짐/꺼짐) 액션으로 만듦 |
| `setChecked(bool)` | 체크 상태 설정(체크 가능한 액션에서만 의미 있음) |
| `setEnabled(bool)` | 활성화/비활성화. 비활성화하면 메뉴 항목이 흐리게 표시되고 클릭이 무시됩니다. |
| `setSeparator(bool)` | 구분선 액션으로 만듦(보통은 `addSeparator()`로 대체) |

`QAction`이 발생시키는 대표적인 시그널은 `triggered()`입니다. 사용자가 메뉴 항목을 클릭하거나, 툴바 버튼을 누르거나, 단축키를 눌렀을 때 어느 경로로 왔든 동일하게 `triggered()`가 발생합니다. 체크 가능한 액션의 경우 상태가 바뀔 때 `toggled(bool)` 시그널도 함께 사용할 수 있습니다.

```cpp
QAction *boldAction = new QAction(tr("굵게"), this);
boldAction->setCheckable(true);
connect(boldAction, &QAction::toggled, this, [](bool checked) {
    qDebug() << "굵게 상태:" << checked;
});
```

## 5.3 메뉴 만들기: QMenuBar와 QMenu

`QMainWindow::menuBar()`는 창에 이미 준비된 `QMenuBar`를 반환합니다. 여기에 `addMenu()`를 호출해서 "파일", "편집" 같은 최상위 메뉴(`QMenu`)를 추가하고, 각 메뉴에 `addAction()`으로 액션을 채워 넣습니다.

```cpp
QMenu *fileMenu = menuBar()->addMenu(tr("파일(&F)"));

QAction *newAction = new QAction(tr("새 파일(&N)"), this);
newAction->setShortcut(QKeySequence::New);
fileMenu->addAction(newAction);

QAction *openAction = new QAction(tr("열기(&O)..."), this);
openAction->setShortcut(QKeySequence::Open);
fileMenu->addAction(openAction);

fileMenu->addSeparator();

QAction *exitAction = new QAction(tr("종료(&X)"), this);
exitAction->setShortcut(QKeySequence::Quit);
connect(exitAction, &QAction::triggered, this, &QWidget::close);
fileMenu->addAction(exitAction);
```

메뉴 제목에 쓴 `&F`, `&N`처럼 앞에 `&`가 붙은 글자는 밑줄로 표시되며, 메뉴바가 활성화된 상태에서 해당 글자 키를 누르면 메뉴가 열리거나 항목이 선택됩니다(Alt 키와 조합해서 사용하는 경우가 많습니다). 이를 니모닉(mnemonic)이라고 부릅니다.

`QMenu::addSeparator()`는 항목 사이에 구분선을 넣어 관련 없는 명령끼리 시각적으로 나누는 데 사용합니다. 위 예제의 "종료" 앞에 구분선을 둔 것처럼, 되돌릴 수 없거나 성격이 다른 명령은 구분선으로 분리하는 것이 일반적인 관례입니다.

하위 메뉴(서브메뉴)가 필요하다면 `QMenu` 안에 또 다른 `QMenu`를 추가하면 됩니다.

```cpp
QMenu *fileMenu = menuBar()->addMenu(tr("파일(&F)"));
QMenu *recentMenu = fileMenu->addMenu(tr("최근 파일"));
recentMenu->addAction(tr("문서1.txt"));
recentMenu->addAction(tr("문서2.txt"));
```

`QMenu::addAction(const QString &text)`처럼 텍스트만 넘기는 오버로드는 내부적으로 `QAction`을 새로 만들어 메뉴에 추가하고 그 포인터를 반환합니다. 간단한 항목이라면 편리하지만, 같은 액션을 툴바와도 공유해야 한다면 앞서처럼 `QAction`을 먼저 만들어 변수에 저장해 두고, 메뉴와 툴바 양쪽에 동일한 포인터를 추가하는 방식을 씁니다.

## 5.4 툴바 만들기: QToolBar

툴바는 자주 쓰는 명령을 아이콘 버튼으로 빠르게 실행할 수 있게 해주는 영역입니다. `QMainWindow::addToolBar()`를 호출하면 새 `QToolBar`가 생성되어 창에 추가되고, 그 포인터가 반환됩니다.

```cpp
QToolBar *fileToolBar = addToolBar(tr("파일 툴바"));
fileToolBar->addAction(newAction);
fileToolBar->addAction(openAction);
fileToolBar->addSeparator();
```

여기서 `newAction`, `openAction`은 앞서 5.3절에서 메뉴에 추가했던 것과 **같은** `QAction` 객체입니다. 즉 메뉴에서 "새 파일"을 클릭하든, 툴바 아이콘을 클릭하든, 아니면 Ctrl+N을 누르든 모두 같은 `triggered()` 시그널로 이어집니다. 이것이 `QAction`을 쓰는 핵심적인 이유입니다.

툴바를 직접 생성해서 특정 위치에 배치하고 싶다면 `QToolBar`를 만들고 `addToolBar(Qt::ToolBarArea, QToolBar *)` 오버로드를 사용합니다.

```cpp
auto *editToolBar = new QToolBar(tr("편집 툴바"), this);
addToolBar(Qt::TopToolBarArea, editToolBar);
```

`QToolBar`가 제공하는 자주 쓰는 설정은 다음과 같습니다.

| 멤버 함수 | 설명 |
|---|---|
| `setMovable(bool)` | 사용자가 툴바를 드래그해서 다른 영역으로 옮길 수 있는지 여부 |
| `setFloatable(bool)` | 툴바를 창 밖으로 분리해 띄울 수 있는지 여부 |
| `setIconSize(const QSize &)` | 툴바 아이콘의 크기 |
| `setToolButtonStyle(Qt::ToolButtonStyle)` | 아이콘만 표시(`Qt::ToolButtonIconOnly`), 텍스트만 표시, 아이콘+텍스트 등 |
| `addSeparator()` | 버튼 사이에 구분선 추가 |
| `addWidget(QWidget *)` | 버튼이 아닌 임의의 위젯(예: 검색창)을 툴바에 삽입 |

```cpp
fileToolBar->setIconSize(QSize(20, 20));
fileToolBar->setToolButtonStyle(Qt::ToolButtonTextUnderIcon);
```

한 창에 여러 개의 툴바를 추가할 수 있으며, 사용자가 툴바를 드래그해서 재배치하면 Qt가 자동으로 레이아웃을 다시 계산합니다. 사용자가 실수로 툴바를 닫았을 때 다시 켤 수 있도록, `QToolBar::toggleViewAction()`이 반환하는 액션을 "보기" 메뉴에 추가해 두는 것이 일반적입니다.

```cpp
QMenu *viewMenu = menuBar()->addMenu(tr("보기(&V)"));
viewMenu->addAction(fileToolBar->toggleViewAction());
```

`toggleViewAction()`은 체크 가능한 액션을 반환하며, 이 액션을 체크/해제하면 해당 툴바가 보이거나 숨겨집니다. 별도의 연결 코드 없이 Qt가 내부적으로 처리해 줍니다.

## 5.5 상태바: QStatusBar

상태바는 창 아래쪽에 위치하며, 현재 진행 상황이나 간단한 안내 메시지를 표시하는 데 사용합니다. `QMainWindow::statusBar()`를 호출하면 상태바가 자동으로 생성되어 반환됩니다.

```cpp
statusBar()->showMessage(tr("준비됨"));
```

`showMessage()`는 두 번째 인자로 밀리초 단위의 타임아웃을 받을 수 있습니다. 타임아웃을 지정하면 그 시간이 지난 뒤 메시지가 자동으로 사라집니다.

```cpp
statusBar()->showMessage(tr("저장했습니다"), 3000);  // 3초 후 사라짐
```

앞서 `QAction::setStatusTip()`으로 지정한 문구는, 그 액션이 포함된 메뉴 항목이나 툴바 버튼 위에 마우스를 올렸을 때 상태바에 자동으로 표시됩니다. 마우스를 치우면 원래 메시지(또는 빈 상태)로 돌아갑니다. 이 기능은 별도의 연결 코드 없이 `QMainWindow`가 처리해 줍니다.

상태바 오른쪽 끝에는 좌표, 줄 번호, 인코딩처럼 항상 표시되어야 하는 정보를 위한 "영구 위젯" 영역을 따로 둘 수 있습니다.

```cpp
auto *lineColumnLabel = new QLabel(tr("1행, 1열"), this);
statusBar()->addPermanentWidget(lineColumnLabel);
```

`addPermanentWidget()`으로 추가한 위젯은 `showMessage()`로 표시되는 일반 메시지와 겹치지 않고 항상 오른쪽에 남아 있습니다. `clearMessage()`를 호출하면 일반 메시지 영역을 즉시 비울 수 있습니다.

## 5.6 단축키와 아이콘

### 5.6.1 QKeySequence

단축키는 `QKeySequence`로 표현합니다. 문자열로 직접 지정할 수도 있지만(`QKeySequence("Ctrl+Shift+N")`), 운영체제마다 관례가 다른 표준 단축키는 `QKeySequence::StandardKey` 열거형을 사용하는 것이 좋습니다. 예를 들어 "저장"의 단축키는 Windows/Linux에서는 Ctrl+S, macOS에서도 대개 Cmd+S이지만, `QKeySequence::Save`를 쓰면 플랫폼별 관례를 Qt가 알아서 맞춰 줍니다.

```cpp
newAction->setShortcut(QKeySequence::New);     // 새로 만들기
openAction->setShortcut(QKeySequence::Open);   // 열기
saveAction->setShortcut(QKeySequence::Save);   // 저장
exitAction->setShortcut(QKeySequence::Quit);   // 종료
cutAction->setShortcut(QKeySequence::Cut);     // 잘라내기
copyAction->setShortcut(QKeySequence::Copy);   // 복사
pasteAction->setShortcut(QKeySequence::Paste); // 붙여넣기
undoAction->setShortcut(QKeySequence::Undo);   // 실행 취소
redoAction->setShortcut(QKeySequence::Redo);   // 다시 실행
```

표준 단축키에 해당하지 않는 임의의 조합이 필요하다면 문자열이나 `QKeySequence(Qt::CTRL | Qt::Key_B)`처럼 직접 지정할 수 있습니다.

```cpp
boldAction->setShortcut(QKeySequence(Qt::CTRL | Qt::Key_B));
```

같은 명령에 두 개 이상의 단축키를 허용하고 싶다면 `setShortcuts(const QList<QKeySequence> &)`를 사용합니다.

### 5.6.2 아이콘 설정

`QAction::setIcon()`에는 `QIcon` 객체를 전달합니다. 프로젝트에 아이콘 리소스를 등록해 두었다면(리소스 파일과 `.qrc`는 이후 장에서 다룹니다) 다음처럼 사용합니다.

```cpp
newAction->setIcon(QIcon(":/icons/new.png"));
```

아직 아이콘 리소스를 준비하지 않았거나 빠르게 프로토타입을 만들고 싶을 때는, Qt의 현재 스타일이 기본으로 제공하는 표준 아이콘을 사용할 수 있습니다. `QWidget::style()`이 반환하는 `QStyle` 객체의 `standardIcon()` 함수에 `QStyle::StandardPixmap` 열거값을 넘기면 됩니다.

```cpp
newAction->setIcon(style()->standardIcon(QStyle::SP_FileIcon));
openAction->setIcon(style()->standardIcon(QStyle::SP_DialogOpenButton));
saveAction->setIcon(style()->standardIcon(QStyle::SP_DialogSaveButton));
```

표준 아이콘은 플랫폼과 스타일에 따라 모양이 조금씩 달라지지만, 별도의 이미지 파일 없이도 그럴듯한 아이콘을 붙일 수 있어 예제나 프로토타입 단계에서 유용합니다. 실제 제품에서는 보통 디자인된 아이콘 세트를 리소스로 포함시켜 사용합니다.

## 5.7 예제: 텍스트 편집기 스켈레톤

지금까지 배운 `QMainWindow`, `QAction`, 메뉴, 툴바, 상태바를 모두 사용해 텍스트 편집기의 뼈대를 만들어 봅니다. 중앙 위젯으로는 여러 줄 텍스트 입력을 지원하는 `QPlainTextEdit`를 사용합니다. `QPlainTextEdit`는 `cut()`, `copy()`, `paste()`, `undo()`, `redo()` 같은 편집 슬롯을 이미 갖추고 있으므로, 이 슬롯들을 액션에 연결하기만 해도 잘라내기·복사·붙여넣기·실행취소·다시실행이 실제로 동작합니다. 반면 파일을 열고 저장하는 기능은 다음 장에서 다룰 `QFileDialog`와 파일 입출력이 필요하므로, 이번 장에서는 상태바에 안내 메시지만 표시하는 자리표시자로 남겨 둡니다. 실제 파일 저장/열기, 찾기/바꾸기, 여러 문서 탭 관리 등 완성된 편집기 기능은 18장에서 이어서 구현합니다.

```cpp
#include <QApplication>
#include <QMainWindow>
#include <QMenuBar>
#include <QMenu>
#include <QToolBar>
#include <QStatusBar>
#include <QAction>
#include <QPlainTextEdit>
#include <QLabel>
#include <QKeySequence>
#include <QStyle>

class MainWindow : public QMainWindow
{
    Q_OBJECT

public:
    explicit MainWindow(QWidget *parent = nullptr)
        : QMainWindow(parent)
    {
        setWindowTitle(tr("텍스트 편집기 (스켈레톤)"));
        resize(800, 600);

        m_editor = new QPlainTextEdit(this);
        setCentralWidget(m_editor);

        createActions();
        createMenus();
        createToolBars();
        createStatusBar();
    }

private:
    void createActions()
    {
        // ---- 파일 관련 액션 ----
        m_newAction = new QAction(tr("새 파일(&N)"), this);
        m_newAction->setShortcut(QKeySequence::New);
        m_newAction->setIcon(style()->standardIcon(QStyle::SP_FileIcon));
        m_newAction->setStatusTip(tr("새 문서를 만듭니다"));
        connect(m_newAction, &QAction::triggered, this, [this]() {
            m_editor->clear();
            statusBar()->showMessage(tr("새 문서를 만들었습니다"), 2000);
        });

        m_openAction = new QAction(tr("열기(&O)..."), this);
        m_openAction->setShortcut(QKeySequence::Open);
        m_openAction->setIcon(style()->standardIcon(QStyle::SP_DialogOpenButton));
        m_openAction->setStatusTip(tr("파일을 엽니다"));
        connect(m_openAction, &QAction::triggered, this, [this]() {
            statusBar()->showMessage(tr("파일 열기는 6장/18장에서 구현합니다"), 3000);
        });

        m_saveAction = new QAction(tr("저장(&S)"), this);
        m_saveAction->setShortcut(QKeySequence::Save);
        m_saveAction->setIcon(style()->standardIcon(QStyle::SP_DialogSaveButton));
        m_saveAction->setStatusTip(tr("현재 문서를 저장합니다"));
        connect(m_saveAction, &QAction::triggered, this, [this]() {
            statusBar()->showMessage(tr("파일 저장은 18장에서 구현합니다"), 3000);
        });

        m_exitAction = new QAction(tr("종료(&X)"), this);
        m_exitAction->setShortcut(QKeySequence::Quit);
        m_exitAction->setStatusTip(tr("편집기를 종료합니다"));
        connect(m_exitAction, &QAction::triggered, this, &QWidget::close);

        // ---- 편집 관련 액션 (QPlainTextEdit의 슬롯에 바로 연결) ----
        m_undoAction = new QAction(tr("실행 취소(&U)"), this);
        m_undoAction->setShortcut(QKeySequence::Undo);
        connect(m_undoAction, &QAction::triggered, m_editor, &QPlainTextEdit::undo);

        m_redoAction = new QAction(tr("다시 실행(&R)"), this);
        m_redoAction->setShortcut(QKeySequence::Redo);
        connect(m_redoAction, &QAction::triggered, m_editor, &QPlainTextEdit::redo);

        m_cutAction = new QAction(tr("잘라내기(&T)"), this);
        m_cutAction->setShortcut(QKeySequence::Cut);
        connect(m_cutAction, &QAction::triggered, m_editor, &QPlainTextEdit::cut);

        m_copyAction = new QAction(tr("복사(&C)"), this);
        m_copyAction->setShortcut(QKeySequence::Copy);
        connect(m_copyAction, &QAction::triggered, m_editor, &QPlainTextEdit::copy);

        m_pasteAction = new QAction(tr("붙여넣기(&P)"), this);
        m_pasteAction->setShortcut(QKeySequence::Paste);
        connect(m_pasteAction, &QAction::triggered, m_editor, &QPlainTextEdit::paste);
    }

    void createMenus()
    {
        QMenu *fileMenu = menuBar()->addMenu(tr("파일(&F)"));
        fileMenu->addAction(m_newAction);
        fileMenu->addAction(m_openAction);
        fileMenu->addAction(m_saveAction);
        fileMenu->addSeparator();
        fileMenu->addAction(m_exitAction);

        QMenu *editMenu = menuBar()->addMenu(tr("편집(&E)"));
        editMenu->addAction(m_undoAction);
        editMenu->addAction(m_redoAction);
        editMenu->addSeparator();
        editMenu->addAction(m_cutAction);
        editMenu->addAction(m_copyAction);
        editMenu->addAction(m_pasteAction);

        m_viewMenu = menuBar()->addMenu(tr("보기(&V)"));
    }

    void createToolBars()
    {
        QToolBar *fileToolBar = addToolBar(tr("파일 툴바"));
        fileToolBar->setToolButtonStyle(Qt::ToolButtonIconOnly);
        fileToolBar->addAction(m_newAction);
        fileToolBar->addAction(m_openAction);
        fileToolBar->addAction(m_saveAction);

        QToolBar *editToolBar = addToolBar(tr("편집 툴바"));
        editToolBar->addAction(m_undoAction);
        editToolBar->addAction(m_redoAction);
        editToolBar->addSeparator();
        editToolBar->addAction(m_cutAction);
        editToolBar->addAction(m_copyAction);
        editToolBar->addAction(m_pasteAction);

        // 툴바를 껐다 켤 수 있도록 "보기" 메뉴에 등록
        m_viewMenu->addAction(fileToolBar->toggleViewAction());
        m_viewMenu->addAction(editToolBar->toggleViewAction());
    }

    void createStatusBar()
    {
        statusBar()->showMessage(tr("준비됨"), 2000);

        m_charCountLabel = new QLabel(tr("0자"), this);
        statusBar()->addPermanentWidget(m_charCountLabel);

        connect(m_editor, &QPlainTextEdit::textChanged, this, [this]() {
            m_charCountLabel->setText(tr("%1자").arg(m_editor->toPlainText().length()));
        });
    }

    QPlainTextEdit *m_editor = nullptr;
    QMenu *m_viewMenu = nullptr;
    QLabel *m_charCountLabel = nullptr;

    QAction *m_newAction = nullptr;
    QAction *m_openAction = nullptr;
    QAction *m_saveAction = nullptr;
    QAction *m_exitAction = nullptr;
    QAction *m_undoAction = nullptr;
    QAction *m_redoAction = nullptr;
    QAction *m_cutAction = nullptr;
    QAction *m_copyAction = nullptr;
    QAction *m_pasteAction = nullptr;
};

int main(int argc, char *argv[])
{
    QApplication app(argc, argv);

    MainWindow window;
    window.show();

    return app.exec();
}

#include "main.moc"
```

이 예제는 `QAction` 하나가 메뉴 항목과 툴바 버튼, 그리고 단축키까지 동시에 담당한다는 사실을 잘 보여줍니다. 예를 들어 `m_copyAction`은 "편집" 메뉴에도, 편집 툴바에도 등록되어 있고 Ctrl+C 단축키도 갖고 있지만, 연결된 슬롯은 `QPlainTextEdit::copy` 하나뿐입니다. 어느 경로로 복사 명령이 내려오든 처리하는 코드는 한 곳에만 있으면 됩니다.

또한 `fileToolBar->toggleViewAction()`을 "보기" 메뉴에 추가해 두었기 때문에, 사용자가 툴바를 드래그해서 어딘가에 숨기더라도 메뉴를 통해 다시 켤 수 있습니다.

## 요약

- `QMainWindow`는 메뉴바, 툴바, 상태바, 도킹 위젯 영역, 중앙 위젯을 표준화된 방식으로 배치해 주는 창 클래스입니다. 중앙 위젯은 `setCentralWidget()`으로, 메뉴바와 상태바는 `menuBar()`/`statusBar()`로 접근하며 필요 시 자동으로 생성됩니다.
- `QAction`은 하나의 명령을 표현하는 객체로, 텍스트·아이콘·단축키·활성화 상태를 한곳에서 관리합니다. 같은 `QAction`을 메뉴와 툴바에 동시에 추가하면 두 UI가 하나의 명령을 공유하게 되고, `triggered()` 시그널 하나만 연결하면 됩니다.
- `QMenuBar::addMenu()`로 최상위 메뉴(`QMenu`)를 만들고, `QMenu::addAction()`/`addSeparator()`/`addMenu()`로 항목·구분선·서브메뉴를 구성합니다.
- `QMainWindow::addToolBar()`로 툴바를 추가하고, `QToolBar::addAction()`으로 액션을 등록합니다. `toggleViewAction()`을 활용하면 툴바를 보이거나 숨기는 액션을 손쉽게 만들 수 있습니다.
- `QStatusBar::showMessage()`로 일시적인 안내 메시지를, `addPermanentWidget()`으로 항상 표시되는 위젯을 상태바에 배치할 수 있습니다. `QAction::setStatusTip()`으로 지정한 문구는 마우스를 올렸을 때 자동으로 상태바에 나타납니다.
- 단축키는 `QKeySequence::StandardKey`(예: `QKeySequence::Save`)를 사용하면 플랫폼 관례를 자동으로 따르고, 아이콘은 리소스 파일이 없어도 `style()->standardIcon()`으로 기본 아이콘을 사용할 수 있습니다.

## 연습문제

1. `QMainWindow`에서 `menuBar()`와 `statusBar()`는 명시적으로 생성하지 않아도 사용할 수 있지만, 툴바는 반드시 `addToolBar()`를 호출해야 하는 이유를 설명해 보세요.
2. "보기" 메뉴에 체크 가능한 액션을 하나 추가하고, 이 액션이 체크/해제될 때마다 상태바에 현재 상태를 표시하도록 `toggled(bool)` 시그널을 연결해 보세요.
3. 이번 장의 텍스트 편집기 예제에 "모두 선택" 액션을 추가하고, `QKeySequence::SelectAll`과 `QPlainTextEdit::selectAll()`을 연결해 메뉴와 툴바 양쪽에서 동작하도록 만들어 보세요.
4. 새로운 툴바를 하나 더 만들어 글꼴 크기를 키우고 줄이는 액션 두 개를 추가하고, 이 툴바도 "보기" 메뉴에서 껐다 켤 수 있도록 `toggleViewAction()`을 등록해 보세요.
5. `QAction`을 사용하지 않고 메뉴 항목과 툴바 버튼을 각각 독립적으로 만들었다고 가정할 때, 저장 기능을 비활성화해야 하는 상황(예: 저장할 변경 사항이 없을 때)에서 코드가 어떻게 달라지는지 비교해서 설명해 보세요.
