# MonoGame으로 배우는 C# 게임 프로그래밍

[다음: 1장. MonoGame이란 무엇인가 ▶](ch01-MonoGame이란무엇인가.md)

---

C#/.NET 기반의 크로스플랫폼 게임 프레임워크 MonoGame 입문서입니다. Game 클래스 수명주기와
콘텐츠 파이프라인 같은 기초부터 입력 처리, 텍스처와 애니메이션, 충돌 감지, 오디오, 카메라,
3D 기초, 게임 상태 관리, 파티클, 세이브/로드, 크로스플랫폼 배포, 실전 미니 게임 제작까지
순서대로 다룹니다.

각 장은 개념 설명, C# 예제 코드, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는 이해를 돕는
다이어그램을 함께 실었습니다.

## 학습 방법 제안

1. 각 장의 예제 코드를 직접 프로젝트에 옮겨 `dotnet run`으로 실행해보며 결과를 확인하세요.
2. 장 끝의 연습문제를 풀어보면서 이해도를 점검하세요.
3. 3~4장(게임 루프, 콘텐츠 파이프라인)은 MonoGame 고유의 개념이므로 특히 꼼꼼히 읽어보세요.
4. 이 저장소의 raylib 책과 비교하며 읽으면, 같은 게임 프로그래밍 개념이 언어/프레임워크마다 어떻게 다르게 표현되는지 더 잘 이해할 수 있습니다.
5. 18장의 실전 프로젝트는 그동안 배운 내용을 종합하는 자리이니, 코드를 그대로 옮기기보다 스스로 변형해보며 완성해보세요.
