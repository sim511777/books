# 11장. 오디오

[◀ 이전: 10장. SpriteFont와 텍스트 렌더링](ch10-SpriteFont와텍스트렌더링.md) | [📖 목차](00-목차.md) | [다음: 12장. 카메라와 변환 행렬 ▶](ch12-카메라와변환행렬.md)


지금까지 우리는 화면에 무언가를 그리는 방법, 입력을 받아 그것을 움직이는 방법을 배웠다. 하지만 완성된 게임이라는 인상을 주는 데 소리만큼 큰 역할을 하는 요소도 드물다. 총을 쏘았을 때 나는 짧은 발사음, 캐릭터가 점프할 때의 효과음, 그리고 게임 전체의 분위기를 만들어주는 배경음악은 시각적 요소 못지않게 플레이어의 몰입감을 좌우한다. 이번 장에서는 MonoGame이 제공하는 오디오 API를 살펴보고, 짧은 효과음과 배경음악을 어떻게 다르게 다뤄야 하는지, 그리고 여러 소리를 동시에 재생하거나 볼륨을 조절하는 방법을 알아본다.

## 효과음과 배경음악, 두 가지 성격의 소리

MonoGame은 게임에서 사용하는 소리를 크게 두 가지 범주로 나누어 다룬다. 하나는 `SoundEffect`로 대표되는 짧은 효과음이고, 다른 하나는 `Song`과 `MediaPlayer`로 대표되는 배경음악이다. 왜 이 둘을 굳이 다른 API로 나누어 놓았을까?

효과음은 보통 길이가 짧고(수백 밀리초에서 몇 초 이내), 게임 진행 중 특정 이벤트가 발생할 때마다 즉시, 그리고 여러 개가 동시에 재생될 수 있어야 한다. 총알이 연속으로 발사되면 발사음도 겹쳐서 들려야 자연스럽다. 반면 배경음악은 보통 길이가 길고(수십 초에서 몇 분), 한 번에 하나만 재생되며, 스트리밍 방식으로 재생되는 것이 자연스럽다. 파일 전체를 메모리에 미리 올려두기보다는 재생하면서 조금씩 읽어 들이는 편이 메모리 효율에 유리하기 때문이다. MonoGame은 이런 성격 차이를 반영해 효과음은 `SoundEffect` 클래스가, 배경음악은 `MediaPlayer`라는 별도의 정적(static) 클래스가 재생을 전담하는 구조를 취하고 있다.

### SoundEffect로 짧은 효과음 재생하기

효과음을 재생하는 가장 간단한 방법은 콘텐츠 파이프라인으로 오디오 파일을 불러온 뒤 `Play` 메서드를 호출하는 것이다. 4장에서 다룬 콘텐츠 파이프라인은 `.wav`, `.mp3`, `.ogg` 같은 오디오 파일도 처리할 수 있으며, MGCB(MonoGame Content Builder)를 통해 프로젝트에 추가해두면 `Content.Load<SoundEffect>`로 불러올 수 있다.

```csharp
private SoundEffect jumpSound;

protected override void LoadContent()
{
    jumpSound = Content.Load<SoundEffect>("jump");
}

protected override void Update(GameTime gameTime)
{
    if (KeyPressed(Keys.Space))
    {
        jumpSound.Play();
    }

    base.Update(gameTime);
}
```

`SoundEffect.Play()`를 호출하면 MonoGame이 내부적으로 재생용 인스턴스를 만들어 즉시 소리를 재생하고, 재생이 끝나면 그 인스턴스를 알아서 정리해준다. 개발자 입장에서는 "이 소리를 지금 재생해줘"라고 지시만 하면 되는 셈이다. 이런 간편함 덕분에 `SoundEffect.Play()`는 점프음, 타격음, 아이템 획득음처럼 재생 도중 세밀한 제어가 필요 없는 짧은 효과음에 잘 어울린다.

`Play` 메서드에는 볼륨, 좌우 패닝(pan), 피치(pitch)를 조절할 수 있는 오버로드도 준비되어 있다.

```csharp
// volume: 0.0(무음) ~ 1.0(원본 볼륨), pitch: -1.0 ~ 1.0, pan: -1.0(왼쪽) ~ 1.0(오른쪽)
jumpSound.Play(volume: 0.8f, pitch: 0.0f, pan: 0.0f);
```

### Song과 MediaPlayer로 배경음악 재생하기

배경음악은 `Song` 타입으로 불러온 뒤, `MediaPlayer`라는 정적 클래스를 통해 재생한다. `SoundEffect`와 달리 `Song` 자체에는 `Play` 메서드가 없다는 점을 눈여겨보자. 배경음악 재생, 정지, 일시정지 같은 동작은 모두 `MediaPlayer`가 도맡아 처리한다.

```csharp
private Song backgroundMusic;

protected override void LoadContent()
{
    backgroundMusic = Content.Load<Song>("theme");
}

protected override void Initialize()
{
    MediaPlayer.Play(backgroundMusic);

    base.Initialize();
}
```

`MediaPlayer`가 게임 전체에서 단 하나의 배경음악만을 담당하는 정적 클래스라는 점은 중요한 설계 특징이다. `MediaPlayer.Play`를 다시 호출하면 이전에 재생 중이던 곡은 자동으로 멈추고 새 곡이 재생되며, `MediaPlayer.Pause()`와 `MediaPlayer.Resume()`으로 일시정지와 재개를, `MediaPlayer.Stop()`으로 완전한 정지를 제어할 수 있다. `MediaPlayer.State` 속성을 통해 현재 재생 중(`MediaState.Playing`)인지, 일시정지 상태(`MediaState.Paused`)인지, 정지 상태(`MediaState.Stopped`)인지도 확인할 수 있다.

```csharp
if (MediaPlayer.State == MediaState.Playing)
{
    MediaPlayer.Pause();
}
else if (MediaPlayer.State == MediaState.Paused)
{
    MediaPlayer.Resume();
}
```

정리하면, "지금 당장 짧게 재생하고 끝나는 소리"는 `SoundEffect`로, "게임이 진행되는 동안 하나만 계속 흐르는 음악"은 `Song`과 `MediaPlayer`의 조합으로 다룬다고 기억해두면 두 API를 헷갈리지 않을 수 있다.

## 볼륨 조절하기

게임을 플레이하다 보면 배경음악은 은은하게, 효과음은 또렷하게 들리도록 균형을 맞추고 싶을 때가 많다. MonoGame은 오디오 볼륨을 세 가지 층위에서 조절할 수 있게 해준다.

**`SoundEffect.MasterVolume`** 은 게임 안에서 재생되는 모든 효과음에 공통으로 적용되는 전역 볼륨이다. 정적(static) 속성이므로 특정 인스턴스가 아니라 `SoundEffect` 클래스 자체에 설정한다. 값의 범위는 0.0(무음)에서 1.0(원본 볼륨)까지다.

```csharp
// 모든 효과음의 볼륨을 절반으로 낮춘다
SoundEffect.MasterVolume = 0.5f;
```

옵션 메뉴에서 "효과음 볼륨" 슬라이더를 만든다면, 그 슬라이더 값을 그대로 `SoundEffect.MasterVolume`에 대입하는 식으로 구현할 수 있다.

**`MediaPlayer.Volume`** 은 배경음악 전용 볼륨이다. 마찬가지로 0.0에서 1.0 사이의 값을 가지며, `SoundEffect.MasterVolume`과는 완전히 독립적으로 동작한다. 옵션 메뉴에 "음악 볼륨"과 "효과음 볼륨"을 따로 두고 싶다면 이 두 속성을 각각 연결하면 된다.

```csharp
MediaPlayer.Volume = 0.3f; // 배경음악은 조금 낮게
```

**개별 인스턴스의 `Volume`** 은 뒤에서 다룰 `SoundEffectInstance`에 설정하는 볼륨으로, 특정 효과음 하나만 다른 소리보다 크거나 작게 재생하고 싶을 때 사용한다. 예를 들어 엔진 소리는 크게, 발소리는 작게 재생하고 싶다면 각 인스턴스의 `Volume`을 따로 지정하면 된다. 이 값 역시 0.0에서 1.0 사이이며, 최종적으로 사용자에게 들리는 실제 볼륨은 `SoundEffect.MasterVolume`과 인스턴스의 `Volume`이 곱해진 값이 된다는 점을 기억해두자.

## 여러 효과음을 동시에, 또는 반복 재생하기: SoundEffectInstance

`SoundEffect.Play()`는 간편하지만, 한 번 재생을 시작하면 그 소리에 대한 제어권을 잃어버린다는 한계가 있다. 예를 들어 캐릭터가 걷는 동안 발소리를 반복 재생하다가, 멈추면 그 발소리만 정확히 멈추고 싶다고 해보자. 매번 `Play()`를 호출하는 방식으로는 지금 재생 중인 소리가 어떤 것인지 추적할 방법이 없다.

이럴 때 사용하는 것이 `SoundEffectInstance`다. `SoundEffect.CreateInstance()`를 호출하면 해당 효과음에 대한 재생 인스턴스를 하나 만들 수 있고, 이 인스턴스는 `Play`, `Pause`, `Resume`, `Stop` 같은 메서드와 `Volume`, `Pitch`, `Pan`, `IsLooped` 같은 속성을 통해 재생 상태를 세밀하게 제어할 수 있다.

```csharp
private SoundEffect footstepSound;
private SoundEffectInstance footstepInstance;

protected override void LoadContent()
{
    footstepSound = Content.Load<SoundEffect>("footstep");
    footstepInstance = footstepSound.CreateInstance();
    footstepInstance.IsLooped = true;
    footstepInstance.Volume = 0.6f;
}

protected override void Update(GameTime gameTime)
{
    bool isWalking = IsPlayerMoving();

    if (isWalking && footstepInstance.State != SoundState.Playing)
    {
        footstepInstance.Play();
    }
    else if (!isWalking && footstepInstance.State == SoundState.Playing)
    {
        footstepInstance.Stop();
    }

    base.Update(gameTime);
}
```

`IsLooped` 속성을 `true`로 설정하면 해당 인스턴스는 `Stop()`을 호출하기 전까지 소리의 끝에 도달할 때마다 처음부터 다시 재생된다. 엔진 소리, 발소리, 배경의 환경음(바람 소리, 물 흐르는 소리)처럼 플레이어가 특정 상태에 머무는 동안 계속 들려야 하는 소리에 유용하다. `SoundEffectInstance`의 `State` 속성으로는 `SoundState.Playing`, `SoundState.Paused`, `SoundState.Stopped` 중 현재 상태를 확인할 수 있다.

동시에 여러 소리를 겹쳐 재생하고 싶을 때도 `SoundEffectInstance`가 유용하다. 하나의 `SoundEffect`에서 여러 개의 인스턴스를 만들어 각각 독립적으로 재생하면, 예를 들어 여러 발의 총알이 짧은 간격으로 발사될 때 발사음이 자연스럽게 겹쳐 들리게 만들 수 있다.

```csharp
private SoundEffect explosionSound;

private void PlayExplosion()
{
    // 매번 새 인스턴스를 만들어 재생하면 이전 폭발음이 끝나지 않아도 겹쳐서 들린다
    SoundEffectInstance instance = explosionSound.CreateInstance();
    instance.Volume = 0.9f;
    instance.Play();
}
```

다만 인스턴스를 계속 새로 만들기만 하고 정리하지 않으면 메모리가 낭비될 수 있으므로, 재생이 끝난 인스턴스는 더 이상 참조하지 않도록 하거나 필요하다면 `Dispose()`를 호출해 명시적으로 해제하는 습관을 들이는 것이 좋다. 간단한 `SoundEffect.Play()`는 이런 정리를 MonoGame이 알아서 처리해주지만, 직접 만든 `SoundEffectInstance`는 개발자가 생명주기를 관리해야 한다는 차이를 기억해두자.

## 배경음악 반복 재생: MediaPlayer.IsRepeating

배경음악은 보통 한 곡이 끝나면 자연스럽게 처음으로 돌아가 계속 흘러나오길 기대한다. `MediaPlayer.IsRepeating` 속성을 `true`로 설정하면 현재 재생 중인 `Song`이 끝났을 때 자동으로 다시 처음부터 재생된다.

```csharp
protected override void Initialize()
{
    MediaPlayer.IsRepeating = true;
    MediaPlayer.Play(backgroundMusic);

    base.Initialize();
}
```

`IsRepeating`은 `MediaPlayer` 전역에 적용되는 속성이므로, 곡을 바꿀 때마다 다시 설정해줄 필요 없이 한 번 켜두면 이후 재생되는 모든 곡에 계속 적용된다. 만약 여러 곡을 순서대로 재생하는 재생목록(playlist) 기능이 필요하다면 `MediaPlayer.Queue`나 `MediaQueue`를 활용할 수도 있지만, 대부분의 인디 게임에서는 레벨이나 화면마다 곡 하나를 반복 재생하는 것으로 충분한 경우가 많다. 화면 전환에 따라 배경음악을 바꾸는 구체적인 흐름은 14장 게임 상태 관리와 화면 전환에서 다시 다룬다.

## 요약

- MonoGame은 짧은 효과음을 위한 `SoundEffect`와 배경음악을 위한 `Song`/`MediaPlayer`를 구분해서 제공한다. `SoundEffect soundEffect = Content.Load<SoundEffect>("이름"); soundEffect.Play();`로 즉시 재생되는 것이 효과음이고, `Song song = Content.Load<Song>("이름"); MediaPlayer.Play(song);`으로 재생하는 것이 배경음악이다.
- `MediaPlayer`는 게임 전체에서 하나의 배경음악 재생을 전담하는 정적 클래스로, `Play`, `Pause`, `Resume`, `Stop`과 `State` 속성을 통해 재생 상태를 제어·확인할 수 있다.
- 볼륨은 세 층위에서 조절한다. `SoundEffect.MasterVolume`은 모든 효과음에 적용되는 전역 볼륨, `MediaPlayer.Volume`은 배경음악 전용 볼륨, 그리고 개별 `SoundEffectInstance.Volume`은 특정 효과음 하나에만 적용되는 볼륨이다.
- 재생 상태를 세밀하게 제어하거나 같은 효과음을 여러 개 동시에 재생하려면 `soundEffect.CreateInstance()`로 `SoundEffectInstance`를 만들어 사용한다. `IsLooped` 속성을 `true`로 설정하면 소리가 끝날 때마다 자동으로 반복 재생된다.
- `MediaPlayer.IsRepeating`을 `true`로 설정하면 현재 재생 중인 배경음악이 끝났을 때 자동으로 처음부터 다시 재생된다.

## 연습문제

1. `SoundEffect.Play()`와 `SoundEffectInstance`를 만들어 재생하는 방식의 차이는 무엇인가? 각각 어떤 상황에 더 적합한지 예를 들어 설명해보자.
2. `Song`에는 왜 `Play` 메서드가 없고, `MediaPlayer`라는 별도의 정적 클래스를 통해서만 재생할 수 있는지 이번 장의 내용을 바탕으로 설명해보자.
3. 옵션 메뉴에서 "효과음 볼륨"과 "음악 볼륨"을 별도의 슬라이더로 제공하려고 한다. 각 슬라이더의 값을 어떤 속성에 연결해야 하는지 설명해보자.
4. 캐릭터가 달리는 동안에는 발소리를 반복 재생하고, 멈추면 즉시 멈추도록 만들고 싶다. `SoundEffectInstance`의 어떤 속성과 메서드를 사용해야 하는지, 그리고 왜 `SoundEffect.Play()`만으로는 구현하기 어려운지 설명해보자.
5. 총알이 초당 여러 발 연속으로 발사되는 슈팅 게임에서, 발사음이 자연스럽게 겹쳐 들리도록 구현하려면 어떤 방식을 사용해야 할까? 이때 생성한 `SoundEffectInstance`들을 어떻게 관리해야 메모리 낭비를 막을 수 있을지도 함께 생각해보자.
