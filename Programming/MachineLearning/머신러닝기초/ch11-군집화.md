## 11.1 비지도학습과 군집화

지도학습에서는 입력 `X`와 정답 `y`가 짝으로 주어지고, 모델은 `X`에서 `y`를 예측하는 규칙을 배웁니다. 비지도학습에서는 `X`만 있습니다. 정답이 없으니 "맞았다/틀렸다"를 말할 수 없고, 대신 **데이터 자체에 숨어 있는 구조**를 찾는 것이 목표가 됩니다.

군집화는 서로 비슷한 샘플끼리 묶어 여러 그룹(군집)으로 나누는 작업입니다. 쓰임새는 다양합니다.

- **고객 세분화**: 구매 이력이 비슷한 고객끼리 묶어 마케팅 전략을 달리합니다.
- **탐색적 분석**: 처음 보는 데이터에 어떤 부류가 있는지 감을 잡습니다.
- **전처리와 특성 생성**: 샘플이 속한 군집 번호를 새로운 특성으로 사용하거나, 군집 대표값으로 데이터를 요약합니다.
- **이상 탐지**: 어느 군집에도 속하지 못하는 샘플을 의심스러운 데이터로 봅니다.

여기서 "비슷하다"의 기준은 대개 **거리**입니다. 특성 공간에서 가까우면 비슷하다고 보는 것이지요. 그래서 군집화 알고리즘은 거리를 어떻게 정의하고, 그룹을 어떤 모양으로 가정하느냐에 따라 갈립니다. 이 장에서는 세 가지 방식을 비교합니다.

| 알고리즘 | 군집을 보는 관점 | k를 미리 정해야 하나 |
| --- | --- | --- |
| k-means | 중심점 주위에 모여 있는 덩어리 | 예 |
| 계층적 군집 | 가까운 것끼리 차례로 합치는 트리 | 아니오(나중에 잘라서 결정) |
| DBSCAN | 샘플이 빽빽한 영역(밀도)의 연결 | 아니오 |

## 11.2 k-means

### 11.2.1 아이디어: 할당과 갱신의 반복

k-means는 가장 널리 쓰이는 군집화 알고리즘입니다. 사용자가 군집 개수 k를 정해 주면, 각 군집을 대표하는 **중심(centroid)** k개를 찾습니다. 알고리즘은 놀라울 만큼 단순합니다.

1. 중심 k개를 임의로 정합니다(보통 데이터 샘플 중에서 고릅니다).
2. **할당 단계**: 모든 샘플을 가장 가까운 중심의 군집에 넣습니다.
3. **갱신 단계**: 각 군집에 속한 샘플들의 평균을 구해 그 군집의 새 중심으로 삼습니다.
4. 할당이 더 이상 바뀌지 않을 때까지 2~3을 반복합니다.

중심을 옮기면 "가장 가까운 중심"이 바뀌는 샘플이 생기고, 할당이 바뀌면 평균이 바뀝니다. 이 두 단계를 번갈아 하면 아래 값이 매번 줄어들거나 같게 유지됩니다.

> **inertia** = 각 샘플과 자기 군집 중심 사이 거리 제곱의 합

inertia는 "군집이 얼마나 촘촘한가"를 나타내는 값이고, k-means는 이 값을 줄이는 방향으로만 움직이므로 반드시 멈춥니다. 다만 **최솟값에 도달한다는 보장은 없고**, 시작점에 따라 다른 곳에서 멈출 수 있습니다. 이 점은 잠시 뒤에 직접 확인합니다.

### 11.2.2 NumPy로 직접 구현

원리를 눈으로 확인하기 위해 위의 알고리즘을 그대로 옮겨 봅니다. 먼저 군집이 3개인 2차원 데이터를 만듭니다.

```python
import numpy as np
from sklearn.datasets import make_blobs

X, y_true = make_blobs(n_samples=300, centers=3, cluster_std=1.0, random_state=42)
print(X.shape)
print(X[:3].round(2))
```

```text
(300, 2)
[[-7.34 -7.73]
 [-7.74 -7.26]
 [-1.69  7.79]]
```

`make_blobs`는 지정한 개수의 덩어리 주위에 샘플을 뿌려 주는 실습용 데이터 생성기입니다. `y_true`에 정답 군집 번호가 들어 있지만, 군집화 알고리즘에는 알려 주지 않습니다. 나중에 결과를 비교할 때만 씁니다.

```python
def kmeans(X, k, n_iter=100, seed=0):
    rng = np.random.default_rng(seed)
    # 1. 샘플 중에서 k개를 골라 초기 중심으로 삼는다
    centers = X[rng.choice(len(X), size=k, replace=False)]
    history = []                                   # 반복마다의 inertia 기록
    for i in range(n_iter):
        # 2. 할당: 모든 샘플과 모든 중심 사이의 거리를 한 번에 계산
        dist = np.linalg.norm(X[:, None, :] - centers[None, :, :], axis=2)
        labels = dist.argmin(axis=1)
        history.append(float((dist.min(axis=1) ** 2).sum()))
        # 3. 갱신: 군집별 평균 (샘플이 하나도 없는 군집은 중심을 그대로 둠)
        new_centers = np.array([
            X[labels == j].mean(axis=0) if np.any(labels == j) else centers[j]
            for j in range(k)
        ])
        # 4. 중심이 더 이상 움직이지 않으면 종료
        if np.allclose(new_centers, centers):
            break
        centers = new_centers
    return labels, centers, history
```

핵심은 거리 계산 한 줄입니다. `X`의 모양은 `(300, 2)`, `centers`는 `(3, 2)`입니다. 여기에 축을 하나씩 끼워 넣어 `(300, 1, 2)`와 `(1, 3, 2)`로 만들면 브로드캐스팅으로 뺄셈이 `(300, 3, 2)`가 됩니다. 마지막 축(`axis=2`)에서 노름을 구하면 "샘플 300개 × 중심 3개"의 거리표를 얻고, `argmin(axis=1)`이 각 샘플에서 가장 가까운 중심의 번호를 줍니다. 반복문 없이 모든 거리를 계산하는 NumPy의 전형적인 방식입니다.

실행해 보겠습니다. 초기 중심이 좋은 경우(`seed=2`)부터 봅니다.

```python
labels, centers, history = kmeans(X, 3, seed=2)
print("반복 횟수:", len(history))
print("inertia 변화:", [round(h, 1) for h in history])
print("군집 크기:", np.bincount(labels))
print("중심:\n", centers[np.argsort(centers[:, 0])].round(2))
print("정답 크기:", np.bincount(y_true))
```

```text
반복 횟수: 2
inertia 변화: [751.2, 566.9]
군집 크기: [100 100 100]
중심:
 [[-6.88 -6.98]
 [-2.63  9.04]
 [ 4.75  2.01]]
정답 크기: [100 100 100]
```

두 번의 반복 만에 수렴했고, inertia는 751.2에서 566.9로 줄었습니다. 군집 크기는 `make_blobs`가 만든 정답 크기와 같고, 중심 좌표도 세 덩어리의 한가운데에 자리 잡았습니다. 군집 번호(0, 1, 2)는 알고리즘이 임의로 붙이는 것이라 정답의 번호와 일치할 필요가 없습니다.

### 11.2.3 초기화에 민감하다

이번에는 초기 중심을 다르게 하는 일곱 번의 시도를 비교합니다.

```python
for seed in range(7):
    _, _, hist = kmeans(X, 3, seed=seed)
    print(f"seed={seed}  반복={len(hist):2d}  최종 inertia={hist[-1]:8.1f}")
```

```text
seed=0  반복=10  최종 inertia=  5693.4
seed=1  반복=10  최종 inertia=  5693.4
seed=2  반복= 2  최종 inertia=   566.9
seed=3  반복= 2  최종 inertia=   566.9
seed=4  반복= 3  최종 inertia=   566.9
seed=5  반복= 6  최종 inertia=  5694.6
seed=6  반복= 6  최종 inertia=   566.9
```

같은 데이터, 같은 알고리즘인데 결과가 크게 갈립니다. inertia가 600 아래인 시도가 있는가 하면 5,700 안팎에서 멈춘 시도도 있습니다. 잘못된 쪽의 군집 모양을 `seed=0`으로 확인해 봅니다.

```python
labels0, centers0, _ = kmeans(X, 3, seed=0)
print("군집 크기:", np.bincount(labels0))
print("중심:\n", centers0[np.argsort(centers0[:, 0])].round(2))
```

```text
군집 크기: [ 55  45 200]
중심:
 [[-7.77 -7.27]
 [-6.16 -6.75]
 [ 1.06  5.53]]
```

중심 두 개가 같은 덩어리 안(좌표 약 -7 근처)에 몰려 있고, 나머지 하나가 두 덩어리(200개)를 혼자 떠안고 있습니다. 어느 중심을 움직여도 inertia가 더 줄지 않는 **지역 최솟값(local minimum)**에 갇힌 것입니다.

해결책은 두 가지입니다.

1. **여러 번 시도해서 가장 좋은 결과를 고른다.** scikit-learn에서는 `n_init`이 그 횟수입니다.
2. **초기 중심을 영리하게 고른다.** `init='k-means++'`는 첫 중심을 무작위로 고른 뒤, 다음 중심들을 "이미 뽑힌 중심에서 멀리 떨어진 샘플일수록 뽑힐 확률이 높게" 고릅니다. 중심들이 처음부터 흩어져 있으니 한 덩어리에 몰릴 가능성이 낮아집니다.

첫 번째 방법을 직접 구현한 코드는 다음처럼 간단합니다. 끝난 결과들 중 inertia가 가장 작은 것을 고르면 됩니다.

```python
def kmeans_best(X, k, n_init=10):
    results = [kmeans(X, k, seed=s) for s in range(n_init)]
    return min(results, key=lambda r: r[2][-1])     # 마지막 inertia가 최소인 결과

labels_b, centers_b, hist_b = kmeans_best(X, 3, n_init=10)
print("최종 inertia:", round(hist_b[-1], 1))
print("군집 크기:", np.bincount(labels_b))
```

```text
최종 inertia: 566.9
군집 크기: [100 100 100]
```

### 11.2.4 scikit-learn의 KMeans

scikit-learn의 `KMeans`는 위 두 가지 대책을 모두 내장하고 있습니다. 다른 추정기와 마찬가지로 `fit`으로 학습하고, 학습된 속성은 이름 끝에 밑줄(`_`)이 붙습니다.

```python
from sklearn.cluster import KMeans

km = KMeans(n_clusters=3, n_init=10, random_state=42).fit(X)
print("inertia:", round(km.inertia_, 1))
print("군집 크기:", np.bincount(km.labels_))
print("중심:\n", km.cluster_centers_[np.argsort(km.cluster_centers_[:, 0])].round(2))
print("반복 횟수:", km.n_iter_)
```

```text
inertia: 566.9
군집 크기: [100 100 100]
중심:
 [[-6.88 -6.98]
 [-2.63  9.04]
 [ 4.75  2.01]]
반복 횟수: 2
```

직접 구현한 `kmeans_best`와 같은 inertia 값이 나왔습니다. 자주 쓰는 속성과 메서드는 다음과 같습니다.

| 이름 | 의미 |
| --- | --- |
| `labels_` | 학습 데이터 각 샘플의 군집 번호 |
| `cluster_centers_` | 군집 중심 좌표 `(k, 특성 수)` |
| `inertia_` | 각 샘플과 자기 중심 사이 거리 제곱합 |
| `n_iter_` | 가장 좋은 시도가 수렴하기까지 걸린 반복 횟수 |
| `predict(X_new)` | 새 샘플을 가장 가까운 중심의 군집으로 분류 |

`predict`로 새 샘플이 어느 군집에 속하는지 알아낼 수 있습니다.

```python
new_points = np.array([[0.0, 0.0], [-8.0, -8.0]])
print(km.predict(new_points))
print(km.transform(new_points).round(2))
```

```text
[2 1]
[[ 9.42  9.81  5.16]
 [17.87  1.51 16.21]]
```

`transform`은 각 새 샘플에서 각 중심까지의 거리를 돌려줍니다. 위 결과의 각 행에서 가장 작은 값의 위치가 `predict` 결과입니다.

초기화 옵션도 비교해 보겠습니다. `n_init=1`로 고정하고 `random_state`만 바꿔 가며, 무작위 초기화(`init='random'`)와 k-means++의 inertia를 비교합니다.

```python
for init in ["random", "k-means++"]:
    scores = []
    for seed in range(8):
        m = KMeans(n_clusters=3, init=init, n_init=1, random_state=seed).fit(X)
        scores.append(round(m.inertia_))
    print(f"{init:10s}", scores)
```

```text
random     [5695, 5693, 567, 567, 567, 567, 567, 567]
k-means++  [567, 567, 567, 567, 567, 567, 567, 567]
```

> **참고**: `n_init`의 기본값은 `'auto'`입니다. `init='k-means++'`일 때는 1회, `init='random'`일 때는 10회 시도합니다. k-means++가 이미 충분히 좋은 시작점을 주기 때문입니다. 그래도 군집이 많거나 데이터가 까다로울 때는 `n_init=10` 정도를 명시해 두는 편이 안전합니다.

### 11.2.5 최적의 k 찾기

k-means는 k를 사용자가 정해야 합니다. 현실에서는 "몇 개의 군집이 있는지"를 모르는 경우가 대부분이므로 k를 바꿔 가며 결과를 비교해야 합니다. 이번에는 군집이 4개인 데이터를 새로 만들어 연습합니다.

```python
from sklearn.metrics import silhouette_score

X4, _ = make_blobs(n_samples=300, centers=4, cluster_std=1.0, random_state=7)

print(" k   inertia   silhouette")
for k in range(1, 9):
    km = KMeans(n_clusters=k, n_init=10, random_state=0).fit(X4)
    if k == 1:
        print(f"{k:2d}  {km.inertia_:8.1f}        -")      # k=1은 실루엣을 정의할 수 없음
    else:
        s = silhouette_score(X4, km.labels_)
        print(f"{k:2d}  {km.inertia_:8.1f}   {s:8.3f}")
```

```text
 k   inertia   silhouette
 1   22312.3        -
 2    9027.1      0.594
 3    2503.3      0.766
 4     571.3      0.807
 5     511.1      0.707
 6     453.5      0.615
 7     400.2      0.487
 8     347.5      0.356
```

**엘보 방법(elbow method)**: k를 늘릴수록 inertia는 항상 줄어듭니다(k가 샘플 수와 같아지면 0이 됩니다). 그래서 inertia의 최솟값을 찾는 것은 의미가 없고, **감소폭이 급격히 줄어드는 지점**을 찾습니다. 위 표에서 k=1에서 2로, 2에서 3으로, 3에서 4로 갈 때는 inertia가 크게 줄지만, k=4 이후로는 조금씩만 줄어듭니다. 그래프로 그리면 팔꿈치(elbow)처럼 꺾이는 곳이 k=4입니다. 우리가 데이터를 4개의 덩어리로 만들었으니 맞는 답입니다.

다만 엘보가 뚜렷하지 않은 데이터도 많아서, 눈으로 판단하는 방법이라는 한계가 있습니다.

**실루엣 점수(silhouette score)**: 각 샘플에 대해 두 값을 구합니다.

- `a`: 같은 군집의 다른 샘플들까지의 평균 거리 (작을수록 군집이 응집되어 있음)
- `b`: 가장 가까운 *다른* 군집의 샘플들까지의 평균 거리 (클수록 다른 군집과 잘 떨어져 있음)

샘플의 실루엣 값은 `(b - a) / max(a, b)`입니다. 값은 -1에서 1 사이이고, 1에 가까우면 자기 군집에 잘 속해 있다는 뜻, 0 근처면 두 군집의 경계에 걸쳐 있다는 뜻, 음수면 엉뚱한 군집에 들어갔을 가능성이 크다는 뜻입니다. `silhouette_score`는 모든 샘플의 평균을 돌려줍니다. 위 표에서 점수가 최대인 k=4가 가장 좋은 선택입니다. 엘보 방법과 달리 "최댓값을 고른다"는 명확한 기준이 있다는 장점이 있습니다.

실루엣 점수는 샘플 수가 많으면 모든 쌍의 거리를 계산해야 해서 느려집니다. 그럴 때는 `silhouette_score(X, labels, sample_size=2000, random_state=0)`처럼 일부 샘플만 사용할 수 있습니다.

두 방법이 항상 같은 답을 주지는 않습니다. 하나의 정답을 구하는 공식이라기보다 **후보를 좁히는 참고 자료**로 쓰고, 최종 선택은 군집이 해석 가능한지, 업무 목적에 맞는지를 함께 보고 결정합니다.

### 11.2.6 k-means를 쓸 때 조심할 점

**특성의 단위(스케일)에 민감합니다.** 거리 기반이므로 값의 범위가 큰 특성이 거리를 좌지우지합니다. 와인 성분 데이터(`load_wine`)로 확인해 봅니다. 이 데이터에는 정답 품종(3종류)이 있으니, 군집 결과가 정답과 얼마나 일치하는지 **수정 랜드 지수(Adjusted Rand Index, ARI)**로 비교하겠습니다. ARI는 두 가지 분할이 얼마나 일치하는지 보는 값으로, 완벽히 일치하면 1, 무작위로 나눈 수준이면 0 근처입니다. 군집 번호가 서로 달라도(0번 군집이 정답의 2번 품종이어도) 상관없이 비교할 수 있습니다.

```python
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import adjusted_rand_score

wine = load_wine()
Xw, yw = wine.data, wine.target
print("특성 수:", Xw.shape[1])
print("표준편차 최소/최대:", Xw.std(axis=0).min().round(2), Xw.std(axis=0).max().round(2))

km_raw = KMeans(n_clusters=3, n_init=10, random_state=0).fit(Xw)
print("원본   ARI:", round(adjusted_rand_score(yw, km_raw.labels_), 3),
      " 실루엣:", round(silhouette_score(Xw, km_raw.labels_), 3))

Xw_s = StandardScaler().fit_transform(Xw)
km_scaled = KMeans(n_clusters=3, n_init=10, random_state=0).fit(Xw_s)
print("표준화 ARI:", round(adjusted_rand_score(yw, km_scaled.labels_), 3),
      " 실루엣:", round(silhouette_score(Xw_s, km_scaled.labels_), 3))
```

```text
특성 수: 13
표준편차 최소/최대: 0.12 314.02
원본   ARI: 0.371  실루엣: 0.571
표준화 ARI: 0.897  실루엣: 0.285
```

특성 중에 `proline`은 값이 수백~천 단위이고 표준편차가 314인 반면, 나머지 특성은 표준편차가 최대 14, 대부분은 3 이하입니다. 그래서 표준화하지 않으면 거리가 사실상 `proline` 하나로 결정됩니다. 표준화(평균 0, 표준편차 1)를 거치면 모든 특성이 공평하게 반영되어 정답과의 일치도가 크게 올라갑니다. **거리 기반 알고리즘에는 스케일링이 사실상 필수**입니다.

여기서 한 가지 눈여겨볼 점이 있습니다. 실루엣 점수는 오히려 표준화하지 않은 쪽이 더 높습니다. 한 특성이 거리를 지배하면 데이터가 사실상 1차원처럼 되어 구분이 쉬워 보이기 때문입니다. 실루엣이 높다고 해서 원하는 구조를 찾았다는 뜻은 아니라는 점을 11.5절에서 다시 다룹니다.

**군집이 둥근 덩어리라고 가정합니다.** k-means는 각 샘플을 가장 가까운 중심에 배정하므로, 군집의 경계는 중심 사이의 직선(수직이등분선)이 됩니다. 길쭉하거나 초승달처럼 휘어진 군집, 크기와 밀도가 많이 다른 군집은 잘 찾지 못합니다. 이 한계는 11.4절 DBSCAN에서 다시 확인합니다.

**이상치에도 민감합니다.** 중심이 평균이라서 멀리 떨어진 소수의 샘플이 중심을 끌어당깁니다.

## 11.3 계층적 군집

계층적 군집(hierarchical clustering)은 k를 처음에 정하지 않습니다. 대신 다음과 같이 합쳐 나갑니다. 이 중 아래에서 위로 합치는 방식을 **병합형(agglomerative)**이라 하고 scikit-learn의 `AgglomerativeClustering`이 이를 구현합니다.

1. 처음에는 모든 샘플이 각각 하나의 군집입니다.
2. 가장 가까운 두 군집을 하나로 합칩니다.
3. 군집이 하나가 될 때까지 2를 반복합니다.

합쳐진 순서와 그때의 거리를 기록하면 나무 모양의 계층 구조(**덴드로그램**)가 됩니다. 나무를 원하는 높이에서 자르면 그 높이에 해당하는 군집 분할을 얻습니다.

### 11.3.1 연결 방식

두 샘플 사이의 거리는 분명하지만, **군집과 군집 사이의 거리**는 정의하기 나름입니다. 이것이 `linkage`(연결 방식) 옵션입니다.

| `linkage` | 군집 간 거리 | 특징 |
| --- | --- | --- |
| `'single'` | 두 군집에서 가장 가까운 샘플 쌍의 거리 | 길게 이어진 모양을 잘 따라가지만, 중간에 샘플 몇 개가 끼면 군집이 사슬처럼 엮임 |
| `'complete'` | 가장 먼 샘플 쌍의 거리 | 지름이 비슷한 촘촘한 군집을 선호 |
| `'average'` | 모든 샘플 쌍 거리의 평균 | single과 complete의 중간 |
| `'ward'`(기본값) | 합쳤을 때 군집 내 분산이 늘어나는 정도 | k-means와 비슷하게 크기가 비슷한 둥근 군집을 만듦. 유클리드 거리 전용 |

여섯 개의 점으로 병합 과정을 직접 들여다봅니다. 군집 개수를 정하지 않고 끝까지 합치려면 `n_clusters=None`과 `distance_threshold=0`을 함께 줍니다. 이때 합쳐진 거리가 `distances_`에 기록됩니다.

```python
from sklearn.cluster import AgglomerativeClustering

P = np.array([[0, 0], [0, 1], [1, 0], [5, 5], [5, 6], [10, 0]], dtype=float)
full = AgglomerativeClustering(n_clusters=None, distance_threshold=0, linkage="single").fit(P)
print("병합 순서(children_):\n", full.children_)
print("병합 거리:", full.distances_.round(2))
```

```text
병합 순서(children_):
 [[0 1]
 [6 2]
 [3 4]
 [7 8]
 [9 5]]
병합 거리: [1.   1.   1.   6.4  7.07]
```

`children_`의 각 행은 한 번의 병합에서 합쳐진 두 군집입니다. 샘플은 0~5번이고, 병합으로 새로 생긴 군집에는 6번부터 순서대로 번호가 붙습니다. 첫 행 `[0 1]`은 0번과 1번 점이 합쳐져 6번 군집이 되었다는 뜻이고, 두 번째 행 `[6 2]`는 6번 군집에 2번 점이 붙어 7번 군집이 되었다는 뜻입니다. 병합 거리가 1, 1, 1에서 6.4, 7.07로 껑충 뛰는 부분에서 자르면 3개의 군집이 나옵니다. 덴드로그램의 높이 차이가 크게 벌어지는 곳을 찾는 것과 같은 원리입니다.

```python
cut = AgglomerativeClustering(n_clusters=None, distance_threshold=3.0, linkage="single").fit(P)
print("군집 수:", cut.n_clusters_)
print("레이블:", cut.labels_)
```

```text
군집 수: 3
레이블: [2 2 2 0 0 1]
```

덴드로그램을 그림으로 그리려면 SciPy의 `scipy.cluster.hierarchy` 모듈(`linkage`, `dendrogram` 함수)을 사용하는 방법이 일반적입니다. 이 책에서는 그림 없이 `children_`와 `distances_`로 원리를 이해하는 데 그칩니다.

### 11.3.2 연결 방식에 따른 차이

연결 방식에 따라 결과가 얼마나 달라지는지, 둥근 덩어리와 초승달 모양 데이터에서 비교합니다.

```python
from sklearn.datasets import make_moons

X_moons, y_moons = make_moons(n_samples=300, noise=0.07, random_state=0)

print("연결방식   blobs ARI   moons ARI")
for link in ["ward", "complete", "average", "single"]:
    ari_b = adjusted_rand_score(y_true, AgglomerativeClustering(n_clusters=3, linkage=link).fit_predict(X))
    ari_m = adjusted_rand_score(y_moons, AgglomerativeClustering(n_clusters=2, linkage=link).fit_predict(X_moons))
    print(f"{link:9s}  {ari_b:9.3f}  {ari_m:10.3f}")

```

잘 분리된 둥근 덩어리(blobs)에서는 어떤 방식이든 완벽하게 찾습니다. 초승달(moons)에서는 `single`만 정답을 맞혔는데, 가까운 점들을 따라 길게 이어 붙이는 성질 덕분입니다. 하지만 이 장점은 양날의 검입니다. 두 초승달 사이에 잡음 점이 몇 개만 끼어도 `single`은 두 군집을 하나로 잇는 다리를 놓아 버립니다.

`AgglomerativeClustering`에는 알아 둘 제약이 몇 가지 있습니다.

- 새 샘플에 쓸 `predict`가 없습니다. 학습 데이터의 군집만 얻을 수 있습니다(`fit_predict`).
- 모든 샘플 쌍의 거리를 다루므로 샘플 수가 많으면(수만 개 이상) 메모리와 시간이 급격히 늘어납니다.
- 한번 합친 것은 되돌리지 않습니다.

## 11.4 DBSCAN

DBSCAN(Density-Based Spatial Clustering of Applications with Noise)은 군집을 "중심 주위의 덩어리"가 아니라 **샘플이 빽빽하게 모여 있는 영역**으로 봅니다. 빽빽한 영역들이 서로 이어져 있으면 하나의 군집이고, 휑한 곳에 홀로 떨어진 샘플은 어느 군집에도 넣지 않고 **노이즈**로 남깁니다. 설정할 값은 두 개입니다.

- `eps`: 이웃으로 인정하는 반경
- `min_samples`: 반경 `eps` 안에 (자기 자신을 포함해) 이만큼 이상의 샘플이 있어야 "빽빽하다"고 인정

이 두 값으로 모든 샘플을 세 종류로 나눕니다.

- **핵심 샘플(core sample)**: 반경 `eps` 안에 `min_samples`개 이상이 있는 샘플. 군집의 뼈대가 됩니다.
- **경계 샘플(border sample)**: 핵심 샘플은 아니지만 어떤 핵심 샘플의 반경 안에 있는 샘플. 군집의 가장자리에 붙습니다.
- **노이즈(noise)**: 둘 다 아닌 샘플. 레이블이 `-1`입니다.

핵심 샘플끼리 서로의 반경 안에 있으면 같은 군집으로 이어지므로, 군집은 꼬불꼬불한 모양이라도 상관없습니다. k를 정하는 대신 군집의 개수는 알고리즘이 결정합니다.

### 11.4.1 비구형 군집에서 k-means와 비교

초승달 데이터에 k-means와 DBSCAN을 모두 적용해 봅니다.

```python
from sklearn.cluster import DBSCAN

km_m = KMeans(n_clusters=2, n_init=10, random_state=0).fit(X_moons)
db_m = DBSCAN(eps=0.2, min_samples=5).fit(X_moons)

print("k-means ARI:", round(adjusted_rand_score(y_moons, km_m.labels_), 3))
print("DBSCAN  ARI:", round(adjusted_rand_score(y_moons, db_m.labels_), 3))
print("DBSCAN 레이블 종류와 개수:", np.unique(db_m.labels_, return_counts=True))
print("핵심 샘플 수:", len(db_m.core_sample_indices_))
```

```text
k-means ARI: 0.234
DBSCAN  ARI: 1.0
DBSCAN 레이블 종류와 개수: (array([0, 1]), array([150, 150]))
핵심 샘플 수: 299
```

k-means는 두 초승달을 가운데에서 직선으로 갈라 버리기 때문에 정답과 거의 맞지 않습니다. DBSCAN은 두 초승달을 정확히 하나씩 찾았습니다. 핵심 샘플은 `core_sample_indices_`에, 모든 핵심 샘플의 좌표는 `components_`에 들어 있습니다.

### 11.4.2 eps의 영향

DBSCAN의 결과는 `eps`에 아주 민감합니다. 값을 바꿔 가며 확인합니다.

```python
print("  eps  군집수  노이즈   ARI")
for eps in [0.05, 0.1, 0.2, 0.3, 0.5]:
    lab = DBSCAN(eps=eps, min_samples=5).fit_predict(X_moons)
    n_clusters = len(set(lab) - {-1})
    n_noise = int((lab == -1).sum())
    print(f"{eps:5.2f}  {n_clusters:5d}  {n_noise:5d}  {adjusted_rand_score(y_moons, lab):6.3f}")
```

```text
  eps  군집수  노이즈   ARI
 0.05      5    269   0.011
 0.10     13     30   0.237
 0.20      2      0   1.000
 0.30      1      0   0.000
 0.50      1      0   0.000
```

`eps`가 너무 작으면 거의 모든 샘플이 노이즈가 되거나 군집이 잘게 쪼개지고, 너무 크면 서로 다른 군집이 하나로 합쳐집니다. 적당한 값은 데이터의 스케일에 따라 달라지므로 **DBSCAN도 스케일링이 필요**합니다.

`eps`를 정하는 흔한 요령은 **k-거리 그래프**입니다. 각 샘플에서 `min_samples`번째로 가까운 이웃까지의 거리를 구해 정렬하고, 이 값이 급격히 커지기 시작하는 곳을 `eps` 후보로 삼습니다. 거리가 갑자기 커지는 샘플들은 이웃이 없는 외톨이일 가능성이 크기 때문입니다.

```python
from sklearn.neighbors import NearestNeighbors

nn = NearestNeighbors(n_neighbors=5).fit(X_moons)
dist, _ = nn.kneighbors(X_moons)          # 첫 번째 이웃은 자기 자신(거리 0)
kdist = np.sort(dist[:, -1])               # 5번째(자기 포함) 이웃까지의 거리
for q in [50, 90, 95, 99, 100]:
    print(f"{q:3d}% 지점: {np.percentile(kdist, q):.3f}")
```

```text
 50% 지점: 0.083
 90% 지점: 0.123
 95% 지점: 0.140
 99% 지점: 0.181
100% 지점: 0.257
```

절반의 샘플은 0.083 안에서, 90%의 샘플은 0.123 안에서 5번째 이웃을 찾습니다. 그 뒤로 값이 서서히 커져 최대 0.257에 이릅니다. `eps=0.2`이면 거의 모든 샘플이 핵심 샘플(앞에서 본 299개)이 되고, 두 초승달 사이의 간격은 `eps`보다 넓어 서로 이어지지 않습니다. 보통은 정렬한 k-거리를 그래프로 그려 꺾이는 지점을 눈으로 찾습니다.

`min_samples`는 클수록 "빽빽하다"의 기준이 엄격해져서 노이즈가 늘고 군집은 보수적으로 만들어집니다. 차원이 늘어날수록, 데이터에 잡음이 많을수록 크게 잡습니다. 특성 수의 두 배 정도에서 시작해 조정하라는 경험 법칙이 흔히 쓰입니다.

### 11.4.3 노이즈 처리

DBSCAN의 강점 중 하나는 이상한 샘플을 억지로 군집에 넣지 않는다는 점입니다. 초승달 데이터에 사방에 흩어진 이상치 30개를 더해서 k-means와 비교해 봅니다.

```python
rng = np.random.default_rng(1)
outliers = rng.uniform(-1.5, 2.5, size=(30, 2))
X_noisy = np.vstack([X_moons, outliers])

db_n = DBSCAN(eps=0.2, min_samples=5).fit(X_noisy)
labels, counts = np.unique(db_n.labels_, return_counts=True)
print("DBSCAN:", dict(zip(labels.tolist(), counts.tolist())))
print("노이즈로 찾은 샘플 중 추가한 이상치 수:", int((db_n.labels_[300:] == -1).sum()), "/ 30")

km_n = KMeans(n_clusters=2, n_init=10, random_state=0).fit(X_noisy)
print("k-means 군집 크기:", np.bincount(km_n.labels_))
```

```text
DBSCAN: {-1: 23, 0: 156, 1: 151}
노이즈로 찾은 샘플 중 추가한 이상치 수: 23 / 30
k-means 군집 크기: [158 172]
```

30개의 이상치 중 대부분이 `-1`(노이즈)로 분리되었습니다. 나머지 7개는 우연히 초승달 곁에 떨어져 군집에 흡수되었는데, 이는 "그 위치에서는 밀도가 충분히 높다"는 DBSCAN의 정의에 따른 결과입니다. 한편 k-means는 노이즈라는 개념이 없어서 모든 샘플을 어딘가에 억지로 배정합니다.

### 11.4.4 DBSCAN의 약점

- **밀도가 서로 다른 군집**: `eps` 하나로 모든 군집을 감당하기 어렵습니다.
- **고차원 데이터**: 차원이 높으면 거리가 의미를 잃어(12장에서 다룰 차원의 저주) 밀도 개념이 흐려집니다.
- **새 샘플 예측 불가**: `predict` 메서드가 없고 `fit_predict`만 있습니다.
- **`eps`에 민감**: 위에서 본 대로입니다.

둥근 덩어리 데이터에서도 DBSCAN은 `eps`를 맞춰 주면 3개의 군집을 찾습니다. 하지만 이런 데이터에서는 k-means가 더 빠르고 간단합니다. 어느 쪽이 낫다고 단정하기보다 **데이터의 모양에 대한 가정이 맞는 도구를 고르는 것**이 중요합니다.

```python
for eps in [0.3, 0.5, 1.0, 1.5]:
    lab = DBSCAN(eps=eps, min_samples=5).fit_predict(X)
    print(f"eps={eps}: 군집 {len(set(lab) - {-1})}개, 노이즈 {int((lab == -1).sum())}개")
```

```text
eps=0.3: 군집 11개, 노이즈 172개
eps=0.5: 군집 5개, 노이즈 52개
eps=1.0: 군집 3개, 노이즈 5개
eps=1.5: 군집 3개, 노이즈 1개
```

`eps`가 0.3일 때는 군집이 11개로 쪼개지고 샘플의 절반 이상이 노이즈지만, 1.0 이상에서는 3개 군집을 정확히 찾습니다. 초승달에서 적절했던 `eps=0.2`와 값이 다른 것은 두 데이터의 스케일과 밀도가 다르기 때문입니다.

## 11.5 군집화 결과를 평가하고 해석하기

지도학습에서는 정확도처럼 "정답과 얼마나 맞는가"라는 객관적인 점수가 있습니다. 군집화는 정답이 없으니 평가가 본질적으로 어렵습니다. 그 이유는 다음과 같습니다.

- **정답 자체가 모호합니다.** 고객을 3그룹으로 나누는 것과 5그룹으로 나누는 것 중 무엇이 "맞는" 것인지는 데이터가 아니라 목적이 결정합니다.
- **알고리즘은 구조가 없어도 군집을 만듭니다.** k-means는 아무 데이터를 줘도 k개로 나눠 줍니다.
- **점수는 알고리즘의 가정을 반영합니다.** 실루엣 점수는 둥근 군집에서 높게 나오므로, 초승달을 정확히 찾은 DBSCAN 결과가 오히려 낮게 평가될 수 있습니다.

두 번째 항목을 확인해 봅니다. 구조가 전혀 없는 균등 분포 데이터에 k-means를 적용합니다.

```python
U = np.random.default_rng(0).uniform(size=(300, 2))
for k in [2, 3, 4, 5]:
    lab = KMeans(n_clusters=k, n_init=10, random_state=0).fit_predict(U)
    print(f"k={k}: 실루엣 {silhouette_score(U, lab):.3f}")
```

```text
k=2: 실루엣 0.359
k=3: 실루엣 0.379
k=4: 실루엣 0.400
k=5: 실루엣 0.382
```

군집이 전혀 없는 데이터인데도 실루엣이 0.4 가까이 나옵니다. 앞의 네 덩어리 데이터에서 최고가 0.8을 넘었던 것과 비교하면 낮지만, 절댓값만 보고 "군집 구조가 있다"고 판단하면 위험하다는 것을 보여 줍니다. 실루엣 점수는 **같은 데이터에서 k나 알고리즘을 비교할 때** 쓰는 것이 안전합니다. 절댓값은 0.7 이상이면 구조가 뚜렷하고 0.25 이하면 구조가 거의 없다고 보는 정도의 대략적인 감각으로만 참고합니다.

평가 방법은 크게 세 가지로 나뉩니다.

- **내부 지표**: 정답 없이 데이터와 군집 결과만으로 계산합니다. `silhouette_score` 외에도 `sklearn.metrics`에 `calinski_harabasz_score`, `davies_bouldin_score` 등이 있습니다.
- **외부 지표**: 일부 샘플에라도 정답이 있을 때 비교합니다. 앞에서 쓴 `adjusted_rand_score`가 대표적입니다.
- **안정성과 해석 가능성**: 아래에서 설명합니다.

### 11.5.1 안정성 확인

데이터를 약간 바꾸거나 초기값을 바꿔도 비슷한 군집이 나온다면 그 구조는 믿을 만합니다. 와인 데이터에 `n_init=1`로 초기값만 바꿔 다섯 번 돌려서, 첫 번째 결과와 나머지가 얼마나 일치하는지 ARI로 확인합니다. 이 비교에는 정답이 필요 없습니다.

```python
runs = [KMeans(n_clusters=3, n_init=1, random_state=s).fit(Xw_s).labels_ for s in range(5)]
print([round(adjusted_rand_score(runs[0], r), 3) for r in runs[1:]])
```

```text
[0.982, 1.0, 1.0, 0.947]
```

값이 1에 가까우면 초기값이 달라도 같은 군집이 나온다는 뜻입니다. 반대로 값이 들쭉날쭉하다면 그 k에서 군집 구조가 불안정하다는 신호입니다.

### 11.5.2 군집 해석하기

군집 번호만 가지고는 아무것도 알 수 없습니다. 군집별로 특성의 평균을 구해 전체 평균과 비교하면 각 군집의 성격이 보입니다. 표준화한 와인 데이터로 얻은 군집 번호를 이용해, 원래 단위의 특성 몇 개만 골라 군집별 평균을 구합니다.

```python
names = list(wine.feature_names)
cols = ["alcohol", "flavanoids", "color_intensity", "proline"]
idx = [names.index(c) for c in cols]
lab = km_scaled.labels_

print("군집  개수  " + "  ".join(f"{c:>15s}" for c in cols))
for j in range(3):
    mean = Xw[lab == j][:, idx].mean(axis=0)
    print(f"{j:3d}  {(lab == j).sum():4d}  " + "  ".join(f"{v:15.2f}" for v in mean))
overall = Xw[:, idx].mean(axis=0)
print("전체  " + f"{len(Xw):4d}  " + "  ".join(f"{v:15.2f}" for v in overall))
```

```text
군집  개수          alcohol       flavanoids  color_intensity          proline
  0    65            12.25             2.05             2.97           510.17
  1    51            13.13             0.82             7.23           619.06
  2    62            13.68             3.00             5.45          1100.23
전체   178            13.00             2.03             5.06           746.89
```

표를 읽으면 군집마다 특징이 드러납니다. 2번 군집은 알코올, 플라바노이드, 프롤린이 모두 전체 평균보다 뚜렷하게 높고, 1번 군집은 플라바노이드가 매우 낮으면서 색 농도가 높으며, 0번 군집은 알코올, 색 농도, 프롤린이 모두 낮은 편입니다. 이렇게 **사람이 이해할 수 있는 이름을 붙일 수 있다면** 그 군집은 쓸모가 있다고 볼 수 있습니다. 반대로 이름을 붙일 수 없는 군집이 나오면 k를 바꾸거나 특성을 다시 고민해 볼 때입니다.

마지막으로 정답이 있는 이 데이터에서는 군집이 실제 품종과 어떻게 대응되는지도 교차표로 확인해 봅니다.

```python
table = np.zeros((3, 3), dtype=int)
for c, t in zip(lab, yw):
    table[c, t] += 1
print("행: 군집 번호, 열: 실제 품종")
print(table)
```

```text
행: 군집 번호, 열: 실제 품종
[[ 0 65  0]
 [ 0  3 48]
 [59  3  0]]
```

대부분의 군집이 한 품종에 몰려 있어 군집화가 품종 구분을 상당 부분 재현했음을 알 수 있습니다. 실무에서는 정답이 없기 때문에 이런 표를 만들 수 없고, 위의 평균 표와 안정성 확인, 그리고 업무 지식이 그 역할을 대신합니다.

## 요약

- 군집화는 정답 없이 비슷한 샘플끼리 묶는 비지도학습입니다. 유사도는 보통 거리로 정의하므로 **특성 스케일링이 중요**합니다.
- **k-means**는 "가까운 중심에 할당 → 군집 평균으로 중심 갱신"을 반복해 inertia를 줄입니다. 구현은 NumPy 브로드캐스팅으로 간단하게 할 수 있습니다.
- k-means는 초기값에 따라 지역 최솟값에 갇힐 수 있으므로 **k-means++**와 **`n_init`**으로 대비합니다.
- k는 **엘보 방법**(inertia 감소폭이 꺾이는 곳)과 **실루엣 점수**(최대인 곳)로 후보를 좁힙니다. 둘 다 참고 자료이지 정답이 아닙니다.
- **계층적 군집**은 가까운 군집을 차례로 합쳐 트리를 만들고, 원하는 높이에서 잘라 군집을 얻습니다. `linkage`에 따라 군집 모양이 달라지며 기본값은 `'ward'`입니다.
- **DBSCAN**은 밀도가 높은 영역을 군집으로 보고 `eps`와 `min_samples`로 조절합니다. k를 정할 필요가 없고 초승달 같은 비구형 군집을 찾으며 노이즈(`-1`)를 분리하지만, `eps`에 민감하고 `predict`가 없습니다.
- 군집 평가는 본질적으로 어렵습니다. 내부 지표(실루엣 등), 외부 지표(ARI), 안정성, 그리고 군집별 특성 요약을 통한 **해석 가능성**을 종합해서 판단합니다.
