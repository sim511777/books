scikit-learn 중심으로 전통적 머신러닝을 다루고, 원리가 중요한 알고리즘(선형 회귀, 로지스틱
회귀, k-NN, 결정 트리, k-means, PCA, 신경망)은 NumPy로 직접 구현해 보여 주는 입문서입니다.
딥러닝은 PyTorch로 신경망 기초, CNN, RNN까지 입문 수준을 다룹니다. 이 저장소의
[Python 기초부터 응용까지](../../Languages/Python/Python기초/00-목차.md)를 읽어 Python 문법을
안다고 가정하며, 수식보다 직관과 코드를 앞세우고 꼭 필요한 수학은 부록에 모았습니다.

각 장은 개념 설명, Python 예제 코드와 실행 결과, 요약, 연습문제로 구성되어 있습니다. 책에
실린 코드는 모두 실제로 실행해 확인했고, 출력은 그 실행 결과입니다.

## 학습 방법 제안

1. 각 장의 코드를 직접 실행해 보세요. 난수 시드를 고정했으므로 같은 결과가 나옵니다(라이브러리 버전에 따라 마지막 자리는 다를 수 있습니다).
2. 장 끝의 연습문제를 풀어보면서 이해도를 점검하세요.
3. 5장(모델 평가와 검증)과 6장(데이터 전처리)은 이후 모든 장의 바탕이 되므로 특히 꼼꼼히 읽어 보세요. 데이터 누수와 과대적합에 대한 감각은 어떤 모델을 쓰더라도 그대로 쓰입니다.
4. 수식이 낯설다면 본문을 먼저 읽고, 필요할 때 부록의 수학 기초로 돌아와 보충하세요.
5. 13장(신경망 기초)을 NumPy로 직접 구현해 본 뒤 14장(PyTorch)을 읽으면, 프레임워크가 자동으로 해 주는 일이 무엇인지 분명히 보입니다.
6. 이 저장소의 [OpenCV 책](../../OpenCV/OpenCV로배우는컴퓨터비전/00-목차.md)과 함께 보면, 15장의 합성곱이 이미지 필터링과 어떻게 이어지는지 이해하기 좋습니다.
7. 18장의 실전 프로젝트는 그동안 배운 내용을 종합하는 자리이니, 코드를 그대로 옮기기보다 다른 데이터셋으로 바꿔 가며 완성해 보세요.
