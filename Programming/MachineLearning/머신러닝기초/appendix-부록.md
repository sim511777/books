## B. 수학 기초 정리

본문에서는 수식을 최소화하고 필요할 때마다 직관을 먼저 설명했습니다. 여기서는 그 아래에 깔린 수학을 한 번 정리합니다. 모든 항목은 짧은 코드로 직접 확인할 수 있게 했습니다.

### B.1 선형대수

#### 벡터와 내적

**벡터**는 숫자의 나열입니다. 머신러닝에서는 샘플 하나의 특성들이 벡터 하나가 됩니다. 두 벡터의 **내적**은 같은 위치의 원소끼리 곱해 모두 더한 값이고, NumPy에서는 `@`로 계산합니다. 선형 회귀의 예측값 `w·x + b`가 바로 내적입니다. 벡터의 **길이(노름)** 는 자기 자신과의 내적의 제곱근이며, 두 벡터가 얼마나 같은 방향을 향하는지는 **코사인 유사도**(내적을 두 길이의 곱으로 나눈 값)로 잽니다. 1에 가까우면 같은 방향, 0이면 직각, -1이면 반대 방향입니다.

```python
import numpy as np

a = np.array([1.0, 2.0, 3.0])
b = np.array([4.0, 5.0, 6.0])
print("합:", a + b)
print("내적:", a @ b)
print("길이(노름):", np.linalg.norm(a).round(4))
cos = a @ b / (np.linalg.norm(a) * np.linalg.norm(b))
print("코사인 유사도:", cos.round(4))
```

```text
합: [5. 7. 9.]
내적: 32.0
길이(노름): 3.7417
코사인 유사도: 0.9746
```

#### 행렬 곱과 shape

행렬은 숫자의 2차원 표입니다. 데이터 행렬 `X`는 (샘플 수, 특성 수) 모양이고, 신경망의 가중치 행렬은 (입력 수, 출력 수) 모양입니다. 행렬 곱 `A @ B`는 **A의 열 수와 B의 행 수가 같아야** 하며, 결과의 shape는 (A의 행 수, B의 열 수)입니다. 결과의 각 원소는 A의 한 행과 B의 한 열의 내적입니다. 신경망의 한 층이 `X @ W + b`인 것도, 선형 회귀를 모든 샘플에 한꺼번에 적용하는 것도 이 연산입니다. 전치(`A.T`)는 행과 열을 맞바꿉니다.

```python
A = np.array([[1, 2],
              [3, 4],
              [5, 6]])          # (3, 2)
B = np.array([[1, 0, 2],
              [0, 1, 3]])       # (2, 3)
C = A @ B
print("A의 shape:", A.shape, " B의 shape:", B.shape, " A@B의 shape:", C.shape)
print(C)
print("전치 A.T의 shape:", A.T.shape)
```

```text
A의 shape: (3, 2)  B의 shape: (2, 3)  A@B의 shape: (3, 3)
[[ 1  2  8]
 [ 3  4 18]
 [ 5  6 28]]
전치 A.T의 shape: (2, 3)
```

shape 오류(`matmul: Input operand ... has a mismatch`)가 나면 두 행렬의 안쪽 크기가 맞는지부터 확인하세요. 딥러닝 코드에서 가장 흔한 오류입니다.

#### 고유값과 고유벡터

정사각 행렬 `M`을 어떤 벡터에 곱하면 보통 벡터의 방향과 길이가 모두 바뀝니다. 그런데 어떤 특별한 벡터 `v`는 `M`을 곱해도 **방향이 바뀌지 않고 길이만 λ배** 됩니다. 이 `v`를 **고유벡터**, λ를 **고유값**이라고 하며 `M v = λ v`로 씁니다. 12장의 PCA에서 공분산 행렬의 고유벡터는 "데이터가 가장 넓게 퍼진 방향"이고, 고유값은 그 방향의 분산 크기입니다. 대칭 행렬(공분산 행렬이 그렇습니다)에는 `np.linalg.eigh`를 씁니다. 고유값을 오름차순으로 돌려줍니다. 일반 행렬은 `np.linalg.eig`를 씁니다.

```python
M = np.array([[2.0, 1.0],
              [1.0, 2.0]])
vals, vecs = np.linalg.eigh(M)
print("고유값:", vals)
print("고유벡터(열):\n", vecs.round(4))
for i in range(2):
    v = vecs[:, i]
    print(f"M @ v{i} = {(M @ v).round(4)},  고유값 * v{i} = {(vals[i] * v).round(4)}")
```

```text
고유값: [1. 3.]
고유벡터(열):
 [[-0.7071  0.7071]
 [ 0.7071  0.7071]]
M @ v0 = [-0.7071  0.7071],  고유값 * v0 = [-0.7071  0.7071]
M @ v1 = [2.1213 2.1213],  고유값 * v1 = [2.1213 2.1213]
```

고유벡터는 **열**에 들어 있고(`vecs[:, i]`), `M @ v`와 `고유값 * v`가 같음을 확인했습니다. 고유벡터는 부호를 뒤집어도 여전히 고유벡터이므로 라이브러리나 버전에 따라 부호가 다르게 나올 수 있습니다.

이제 PCA의 핵심 아이디어를 몇 줄로 확인해 봅시다. 서로 강하게 연관된 두 특성의 데이터에서 공분산 행렬의 고유값을 보면 대부분의 분산이 한 방향에 몰려 있습니다. 그 방향이 첫 번째 주성분입니다.

```python
rng = np.random.default_rng(0)
x1 = rng.normal(size=500)
x2 = 0.8 * x1 + 0.3 * rng.normal(size=500)
X = np.column_stack([x1, x2])
cov = np.cov(X, rowvar=False)
w, V = np.linalg.eigh(cov)
print("공분산 행렬:\n", cov.round(3))
print("고유값(작은 순):", w.round(3))
print("분산 설명 비율(큰 순):", (w[::-1] / w.sum()).round(3))
print("가장 큰 고유값의 고유벡터:", V[:, -1].round(3))
```

```text
공분산 행렬:
 [[1.029 0.825]
 [0.825 0.741]]
고유값(작은 순): [0.047 1.723]
분산 설명 비율(큰 순): [0.973 0.027]
가장 큰 고유값의 고유벡터: [-0.766 -0.643]
```

전체 분산의 97.3%가 첫 번째 방향 하나에 담겨 있습니다. 2차원 데이터를 이 방향의 1차원으로 줄여도 정보 손실이 거의 없다는 뜻이고, 이것이 PCA 차원 축소의 원리입니다.

### B.2 확률

#### 확률과 조건부 확률

사건 A의 **확률** P(A)는 0~1 사이의 값입니다. **조건부 확률** P(A | B)는 "B가 일어났다는 것을 알 때 A가 일어날 확률"입니다. 정의는 다음과 같습니다.

```text
P(A | B) = P(A와 B가 함께 일어날 확률) / P(B)
```

두 사건이 서로 영향을 주지 않으면(독립이면) P(A | B) = P(A)입니다. 7장의 나이브 베이즈는 "특성들이 클래스가 주어졌을 때 서로 독립이다"라는 **순진한(naive)** 가정을 두고 확률을 곱해 나갑니다.

#### 베이즈 정리

조건의 방향을 뒤집어 주는 공식이 **베이즈 정리**입니다.

```text
P(A | B) = P(B | A) × P(A) / P(B)
```

분류 문제에 대입하면, 우리가 알고 싶은 것은 "특성 x를 보았을 때 클래스가 c일 확률" P(c | x)입니다. 그런데 직접 구하기는 어렵고, 반대로 "클래스가 c일 때 특성 x가 나올 확률" P(x | c)와 "클래스 c의 사전 비율" P(c)는 데이터를 세어서 구할 수 있습니다. 베이즈 정리가 이 둘을 이어 줍니다. 가장 유명한 예가 검사 결과의 해석입니다.

어떤 병의 유병률이 1%이고, 검사는 병이 있으면 95%의 확률로 양성이 나오며(민감도), 병이 없어도 5%의 확률로 양성이 나옵니다(위양성률). 검사에서 양성이 나왔을 때 실제로 병이 있을 확률은 얼마일까요?

```python
p_d = 0.01          # 유병률
sens = 0.95         # 민감도: 병이 있을 때 양성
fpr = 0.05          # 위양성률: 병이 없는데 양성
p_pos = sens * p_d + fpr * (1 - p_d)
post = sens * p_d / p_pos
print(f"P(양성 판정) = {p_pos:.4f}")
print(f"P(병 | 양성 판정) = {post:.4f}")

# 시뮬레이션으로 확인
rng = np.random.default_rng(0)
n = 1_000_000
sick = rng.random(n) < p_d
test_pos = np.where(sick, rng.random(n) < sens, rng.random(n) < fpr)
print(f"시뮬레이션: {sick[test_pos].mean():.4f}")
```

```text
P(양성 판정) = 0.0590
P(병 | 양성 판정) = 0.1610
시뮬레이션: 0.1612
```

검사가 95%나 정확한데도 양성 판정을 받은 사람이 실제로 병에 걸렸을 확률은 약 16%에 그칩니다. 병에 걸린 사람이 애초에 드물기 때문에(사전 확률 1%), 병이 없는 사람 99% 중 5%가 만드는 오경보가 병이 있는 사람의 참 양성보다 훨씬 많기 때문입니다. 직관과 어긋나는 이 결과를 **기저율 무시**의 오류라고 부릅니다. 불균형 데이터에서 정밀도가 낮게 나오는 현상(5장)도 같은 원리입니다.

#### 정규분포

**정규분포**(가우스 분포)는 평균 μ를 중심으로 좌우 대칭인 종 모양 분포이고, 퍼짐 정도는 표준편차 σ가 정합니다. 키, 측정 오차처럼 작은 요인이 많이 합쳐진 값은 흔히 정규분포를 따릅니다. 모양을 외우는 대신 다음 경험칙을 기억해 두면 편합니다. 평균에서 1σ, 2σ, 3σ 이내에 들어갈 확률은 각각 약 68%, 95%, 99.7%입니다.

```python
from scipy.stats import norm

for k in (1, 2, 3):
    print(f"평균 ± {k}σ 안에 들어갈 확률: {norm.cdf(k) - norm.cdf(-k):.4f}")

rng = np.random.default_rng(0)
s = rng.normal(loc=170, scale=6, size=100_000)
print("표본 평균, 표준편차:", s.mean().round(2), s.std().round(2))
print(f"평균±1σ 비율: {np.mean(np.abs(s - 170) < 6):.4f}")
```

```text
평균 ± 1σ 안에 들어갈 확률: 0.6827
평균 ± 2σ 안에 들어갈 확률: 0.9545
평균 ± 3σ 안에 들어갈 확률: 0.9973
표본 평균, 표준편차: 169.99 6.0
평균±1σ 비율: 0.6839
```

`norm.cdf(x)`는 표준정규분포에서 x 이하일 확률(누적분포함수)입니다. 평균 170, 표준편차 6으로 뽑은 표본 10만 개에서 평균±6 안에 든 비율이 약 68%로 이론값과 맞습니다. 이 책에서 정규분포는 `StandardScaler`(표준화: 평균을 빼고 표준편차로 나눠 평균 0, 표준편차 1로 만듦), 가우시안 나이브 베이즈, 가중치 초기화, 이상값 판단에 등장했습니다. 표준화한 값이 3을 넘으면(3σ 밖) 드문 값으로 봅니다.

한 가지 용어를 더 정리합니다. **기댓값**은 평균, **분산**은 평균에서의 거리 제곱의 평균, **표준편차**는 분산의 제곱근입니다. 평균제곱오차(MSE)가 "오차의 제곱의 평균"이라는 점에서 분산과 같은 형태입니다.

### B.3 미분

#### 도함수: 순간 변화율

함수 f(x)의 **미분(도함수)** f'(x)는 x가 아주 조금 변할 때 f가 얼마나 변하는지의 비율, 즉 그 점에서의 **접선의 기울기**입니다. 기울기가 양수이면 x를 늘릴 때 f가 증가하고, 음수이면 감소합니다. 경사하강법이 "손실이 줄어드는 방향"을 아는 방법이 바로 이것입니다. 미분을 해석적으로 구하기 어려울 때는 x 양옆의 값으로 근사하는 **수치 미분** `(f(x+h) - f(x-h)) / (2h)`를 쓸 수 있으며, 13장에서 역전파 구현이 맞는지 검증할 때 썼습니다.

자주 쓰는 미분 몇 가지는 다음과 같습니다.

| f(x) | f'(x) |
|---|---|
| x² | 2x |
| xⁿ | n·xⁿ⁻¹ |
| eˣ | eˣ |
| ln x | 1/x |
| 상수 c | 0 |

시그모이드 σ(x) = 1/(1 + e⁻ˣ)의 미분은 σ(x)(1 - σ(x))로, 출력만 알면 계산할 수 있어 로지스틱 회귀와 신경망에서 편리합니다.

#### 편미분과 기울기(그래디언트)

변수가 여러 개인 함수 f(x, y)에서는 **편미분**을 씁니다. 한 변수만 변하고 나머지는 상수로 고정했을 때의 미분입니다. ∂f/∂x는 y를 상수로 보고 x로 미분한 값입니다. 모든 변수의 편미분을 모아 벡터로 만든 것이 **기울기(gradient, ∇f)** 입니다. 기울기 벡터는 **함수 값이 가장 가파르게 증가하는 방향**을 가리키므로, 손실을 줄이려면 그 반대 방향으로 가면 됩니다. 가중치가 수백만 개인 신경망도 원리는 같고, 변수가 수백만 개인 기울기 벡터일 뿐입니다.

예를 들어 f(x, y) = x²y + 3y라면 ∂f/∂x = 2xy, ∂f/∂y = x² + 3입니다. 점 (2, 1)에서의 기울기를 해석적으로 구한 값과 수치 미분으로 구한 값을 비교해 봅시다.

```python
def f(x, y):
    return x**2 * y + 3 * y

def grad_f(x, y):
    return np.array([2 * x * y, x**2 + 3])

h = 1e-5
x0, y0 = 2.0, 1.0
num = np.array([(f(x0 + h, y0) - f(x0 - h, y0)) / (2 * h),
                (f(x0, y0 + h) - f(x0, y0 - h)) / (2 * h)])
print("해석적 기울기:", grad_f(x0, y0))
print("수치 기울기  :", num.round(4))
```

```text
해석적 기울기: [4. 7.]
수치 기울기  : [4. 7.]
```

#### 연쇄 법칙

합성함수 y = f(u), u = g(x)를 x로 미분하려면 **각 단계의 미분을 곱합니다.**

```text
dy/dx = (dy/du) × (du/dx)
```

예를 들어 y = (3x + 1)²이면 u = 3x + 1로 두고 dy/du = 2u, du/dx = 3이므로 dy/dx = 2(3x + 1) × 3입니다. x = 1에서 2 × 4 × 3 = 24입니다.

```python
def g(x):  # y = u^2, u = 3x + 1
    return (3 * x + 1) ** 2

x0 = 1.0
chain = 2 * (3 * x0 + 1) * 3     # dy/du * du/dx
numeric = (g(x0 + h) - g(x0 - h)) / (2 * h)
print("연쇄 법칙:", chain, " 수치 미분:", round(numeric, 4))
```

```text
연쇄 법칙: 24.0  수치 미분: 24.0
```

신경망은 층이 연달아 이어진 거대한 합성함수입니다. 출력층의 손실에서 시작해 층을 거슬러 오며 각 층의 미분을 차례로 곱해 가는 것이 **역전파(13장)** 이고, PyTorch의 `backward()`(14장)는 이 곱셈을 자동으로 해 주는 것입니다.

#### 경사하강법 한 걸음 한 걸음

기울기를 알면 경사하강법은 한 줄입니다. `w = w - 학습률 × 기울기`. 두 변수를 가진 손실 `(w0 - 3)² + (w1 + 1)²`(최솟값은 (3, -1))을 학습률 0.2로 따라 내려가 봅시다.

```python
def loss(w):             # 최솟값은 (3, -1)
    return (w[0] - 3) ** 2 + (w[1] + 1) ** 2

def grad(w):
    return np.array([2 * (w[0] - 3), 2 * (w[1] + 1)])

w = np.array([0.0, 0.0])
lr = 0.2
for step in range(6):
    print(f"step {step}: w={w.round(4)}, loss={loss(w):.4f}")
    w = w - lr * grad(w)
print(f"step 6: w={w.round(4)}, loss={loss(w):.4f}")
```

```text
step 0: w=[0. 0.], loss=10.0000
step 1: w=[ 1.2 -0.4], loss=3.6000
step 2: w=[ 1.92 -0.64], loss=1.2960
step 3: w=[ 2.352 -0.784], loss=0.4666
step 4: w=[ 2.6112 -0.8704], loss=0.1680
step 5: w=[ 2.7667 -0.9222], loss=0.0605
step 6: w=[ 2.86   -0.9533], loss=0.0218
```

한 걸음마다 최솟값 (3, -1)에 가까워지고 손실은 매번 약 0.36배로 줄어듭니다. 3장에서 본 학습률 실험처럼, 학습률을 너무 크게(이 예제에서는 1.0을 넘기면) 잡으면 최솟값을 지나쳐 오히려 멀어집니다.

|---|---|---|---|
| 표 형태 데이터의 분류 | 로지스틱 회귀(스케일링 포함) | 랜덤 포레스트, `HistGradientBoostingClassifier` | 정형 데이터는 단순 모델과 트리 앙상블이 강하다. 딥러닝은 보통 마지막 선택지. |
| 표 형태 데이터의 회귀 | 선형 회귀(규제 포함: `Ridge` 등) | 랜덤 포레스트, 그래디언트 부스팅 회귀 | 평균만 예측하는 `DummyRegressor`와 먼저 비교한다. |
| 샘플이 적다(수백 건 이하) | 로지스틱/선형 회귀, k-NN, 나이브 베이즈 | 선형 커널 SVM, 얕은 트리 | 복잡한 모델은 과대적합하기 쉽다. 교차검증으로 변동폭을 꼭 확인한다. |
| 비선형 경계, 중간 규모(수만 건 이하) | RBF 커널 `SVC`(스케일링 필수) | 트리 앙상블 | SVM은 샘플이 많아지면 학습이 급격히 느려진다. |
| 샘플이 많다(수십만 건 이상) | `LogisticRegression`/`LinearSVC`, `HistGradientBoostingClassifier` | 신경망 | 커널 SVM과 k-NN은 규모가 커지면 부담이 크다. |
| 결측치가 많다 | `HistGradientBoostingClassifier`(NaN을 직접 처리) | `SimpleImputer` + 다른 모델 | 결측 여부 자체가 정보일 수 있다(`add_indicator`). |
| 범주형 특성이 많다 | `OneHotEncoder` + 선형/트리 모델 | 트리 앙상블 | 범주 값이 아주 많으면(고유값이 수백 이상) 원-핫이 커지니 주의한다. |
| 해석 가능성이 중요하다 | 로지스틱/선형 회귀, 얕은 결정 트리 | 앙상블 + `permutation_importance` | 계수 해석은 스케일링과 특성 간 상관을 고려해야 한다. |
| 확률 자체가 필요하다 | 로지스틱 회귀 | 트리 앙상블이나 SVM + `CalibratedClassifierCV` | 확률이 현실의 빈도와 맞는지 확인한 뒤 임계값을 정한다. |
| 클래스 불균형 | 지표를 재현율, PR 곡선으로 바꾼다 | `class_weight="balanced"`, 임계값 조정 | 정확도만 보면 속는다(5장, 18장). |
| 텍스트 분류 | `CountVectorizer`(또는 TF-IDF) + 나이브 베이즈/로지스틱 회귀 | 사전 학습된 언어 모델 | 단어 주머니 기준선이 의외로 강하다. 한국어는 형태소 분석이 필요하다. |
| 이미지 분류 | 사전 학습된 CNN + 전이 학습 | 직접 만든 CNN | 데이터가 적을수록 전이 학습의 이득이 크다(15장). |
| 시계열 예측 | 지연 특성(과거 값)을 만들어 선형/트리 모델 | `nn.LSTM`/`nn.GRU` | 평가할 때는 반드시 **시간순**으로 나눈다. 무작위 분할은 미래를 훔쳐보게 된다. |
| 그룹을 찾고 싶다(정답 없음) | 스케일링 후 `KMeans` | `DBSCAN`(임의 모양, 노이즈), 계층적 군집 | 군집 수와 결과의 의미는 사람이 확인한다(11장). |
| 차원 축소, 시각화 | `PCA` | `TSNE` | t-SNE는 시각화용이다. 거리나 군집 크기를 해석하지 않는다(12장). |
| 이상 탐지 | `IsolationForest` | 군집화 기반(`DBSCAN`) | 이상의 정의와 정답이 불분명하므로 도메인 지식이 중요하다. |

이 표를 쓸 때 기억할 원칙 몇 가지를 덧붙입니다.

- **데이터와 문제 정의가 알고리즘 선택보다 중요합니다.** 좋은 특성과 올바른 평가 방식이 알고리즘 교체보다 성능을 더 많이 바꿉니다.
- **거리나 기울기에 의존하는 모델**(k-NN, SVM, 로지스틱 회귀, 신경망, k-평균, PCA)은 스케일링이 필수이고, **트리 계열**은 필요 없습니다.
- 비슷한 점수 사이에서는 **더 단순하고, 더 빠르고, 더 설명하기 쉬운** 모델을 고릅니다. 점수의 차이가 교차검증의 표준편차 안이라면 구분할 수 없는 것입니다.
- 모델을 정한 뒤에는 17장처럼 **파이프라인**으로 묶고, 테스트 세트는 마지막에 한 번만 사용합니다.
