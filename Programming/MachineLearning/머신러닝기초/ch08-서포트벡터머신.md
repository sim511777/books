서포트 벡터 머신(Support Vector Machine, SVM)은 딥러닝이 대중화되기 전까지 오랫동안 분류 문제의 "최강자" 자리를 지켜 온 알고리즘입니다. 지금도 특성 수는 많지만 샘플이 수천 개 이하인 데이터에서는 여전히 강력한 선택지입니다. SVM이 특별한 이유는 두 가지 아이디어에 있습니다.

1. 클래스를 나누는 경계를 **마진(여유 공간)이 가장 넓게** 긋는다.
2. 직선으로 나눌 수 없는 데이터는 **커널 트릭**으로 고차원으로 보낸 것처럼 다룬다.

이 장을 마치면 다음을 할 수 있습니다.

- 마진, 서포트 벡터, 소프트 마진과 `C`의 의미를 설명한다.
- `LinearSVC`와 `SVC`를 상황에 맞게 사용한다.
- 커널 트릭의 직관을 이해하고, `rbf`와 `poly` 커널의 `gamma`, `degree`, `C`를 조정한다.
- SVM에 스케일링이 필수인 이유와 대용량 데이터에서의 한계를 안다.
- 회귀용 `SVR`을 사용한다.

## 8.1 마진 최대화의 직관

두 클래스를 직선(고차원에서는 초평면)으로 나눈다고 해 봅시다. 데이터가 직선으로 분리된다면 이를 만족하는 직선은 무수히 많습니다. 어느 직선이 가장 좋을까요?

새 샘플은 훈련 샘플과 약간 다른 위치에 나타나기 마련입니다. 경계선이 한쪽 클래스에 바싹 붙어 있다면, 그 클래스의 새 샘플은 조금만 삐끗해도 경계 반대편으로 넘어가 오분류됩니다. 반대로 경계가 **양쪽 클래스에서 최대한 멀리** 떨어져 있다면 이런 흔들림에 가장 강합니다. SVM은 이 직관을 그대로 따릅니다.

- 경계선(결정 경계)에서 양쪽으로 부풀려 클래스 샘플을 만나는 지점까지 만든 띠를 **마진(margin)** 이라고 합니다.
- SVM은 **마진의 폭이 가장 넓은** 경계선을 선택합니다.
- 마진의 가장자리에 걸쳐 있는 샘플들, 즉 경계를 "떠받치는" 샘플들을 **서포트 벡터(support vector)** 라고 합니다.

선형 SVM의 결정 함수는 `f(x) = w·x + b`입니다. `f(x) = 0`이 결정 경계이고, `f(x) = +1`과 `f(x) = -1`이 마진의 양쪽 가장자리입니다. 이때 마진의 폭은 `2 / ‖w‖`입니다. 그러므로 "마진을 넓힌다"는 것은 "`w`의 크기를 줄인다"와 같은 뜻이 됩니다.

## 8.2 서포트 벡터

선형으로 분리 가능한 두 덩어리의 데이터를 만들고, 마진이 최대가 되도록 학습시켜 봅시다. `C`를 아주 크게 주면 훈련 샘플이 마진 안쪽으로 들어오는 것을 거의 허용하지 않는 **하드 마진** 상태가 됩니다. `C`의 의미는 곧 자세히 설명하겠습니다.

```python
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.svm import SVC

# 선형으로 분리되는 두 덩어리
X, y = make_blobs(n_samples=60, centers=[(-2, -2), (2, 2)], cluster_std=0.8, random_state=3)

# C를 매우 크게 -> 사실상 하드 마진
svm = SVC(kernel="linear", C=1e6).fit(X, y)

w = svm.coef_[0]          # 결정 경계의 방향 벡터
b = svm.intercept_[0]     # 절편
print("훈련 정확도:", svm.score(X, y))
print("서포트 벡터 수 (클래스별):", svm.n_support_)
print("w =", w.round(3), ", b =", round(float(b), 3))
print("마진 폭 = 2/||w|| =", round(float(2 / np.linalg.norm(w)), 3))
```

```text
훈련 정확도: 1.0
서포트 벡터 수 (클래스별): [1 1]
w = [0.558 0.854] , b = 0.141
마진 폭 = 2/||w|| = 1.96
```

학습된 모델의 `coef_`가 `w`, `intercept_`가 `b`입니다. 결과를 보면 서포트 벡터가 클래스마다 **단 하나씩**, 모두 2개뿐입니다. 60개의 샘플 중 경계를 결정하는 데 쓰이는 것은 가장 안쪽의 두 점뿐이라는 뜻입니다. 마진의 폭 `2/‖w‖`는 약 1.96으로 계산됩니다.

서포트 벡터가 정말 "마진의 가장자리"에 있는지 결정 함수 값으로 확인해 봅시다.

```python
# 서포트 벡터는 결정 함수 값이 거의 정확히 +1 또는 -1인 점들이다.
f = svm.decision_function(X)
print("서포트 벡터의 결정 함수 값:", f[svm.support_].round(3))

# 서포트 벡터가 아닌 점들은 모두 마진 바깥(|f| > 1)에 있다.
others = np.setdiff1d(np.arange(len(X)), svm.support_)
print("나머지 점들 중 |f|의 최솟값:", round(float(np.abs(f[others]).min()), 3))
```

```text
서포트 벡터의 결정 함수 값: [-1.  1.]
나머지 점들 중 |f|의 최솟값: 1.121
```

서포트 벡터의 결정 함수 값은 정확히 -1과 +1이고, 그 외의 모든 점은 `|f(x)| > 1`, 즉 마진 바깥에 있습니다. 이제 SVM의 가장 흥미로운 성질을 확인해 봅시다. **서포트 벡터가 아닌 샘플을 모두 지우고 서포트 벡터만으로 다시 학습해도 같은 경계가 나옵니다.**

```python
# 서포트 벡터가 아닌 점을 모두 지워도 같은 경계가 나온다.
svm_sv_only = SVC(kernel="linear", C=1e6).fit(X[svm.support_], y[svm.support_])
print("원래 w      :", svm.coef_[0].round(4))
print("SV만으로 학습:", svm_sv_only.coef_[0].round(4))
```

```text
원래 w      : [0.5576 0.8544]
SV만으로 학습: [0.5576 0.8544]
```

경계는 서포트 벡터에 의해서만 결정됩니다. 경계에서 먼 샘플은 위치가 조금 바뀌거나 아예 사라져도 모델에 영향이 없습니다. 이런 성질 때문에 SVM은 경계를 결정하는 소수의 핵심 샘플만 기억하면 되는 **희소(sparse)** 모델이 됩니다. 예측할 때도 서포트 벡터만 사용합니다.

## 8.3 하드 마진, 소프트 마진, 그리고 C

하드 마진은 두 가지 약점이 있습니다.

- 데이터가 선형으로 분리되지 않으면 해가 존재하지 않습니다.
- 이상치 하나가 경계를 크게 흔듭니다. 반대편 클래스 쪽으로 튀어 나온 점 하나 때문에 마진이 극단적으로 좁아질 수 있습니다.

그래서 현실에서는 일부 샘플이 마진 안쪽에 들어오거나 심지어 반대편에 넘어가는 것을 **허용하되 벌점을 매기는** **소프트 마진(soft margin)** 을 씁니다. 목표는 두 가지가 충돌합니다.

```text
최소화:  (1/2) ‖w‖²   +   C × (마진을 침범한 정도의 합)
          └ 마진을 넓게 ┘      └ 훈련 샘플을 정확히 ┘
```

여기서 `C`가 두 목표의 비중을 조절합니다.

| `C` | 의미 | 결과 |
| --- | --- | --- |
| 작다 | 위반을 너그럽게 봐줌 | 마진이 넓고 단순한 경계, 서포트 벡터 많음 (과소적합 위험) |
| 크다 | 위반에 엄격함 | 마진이 좁고 훈련 데이터에 충실한 경계 (과대적합 위험) |

주의할 점은 scikit-learn의 `C`가 **규제의 역수**라는 것입니다. 릿지 회귀의 `alpha`와 달리 `C`가 클수록 규제가 약해집니다.

겹치는 두 덩어리 데이터에서 `C`를 바꿔 가며 확인해 봅시다.

```python
from sklearn.model_selection import train_test_split

# 두 덩어리가 겹치는 데이터: 완벽한 분리는 불가능하다.
X2, y2 = make_blobs(n_samples=400, centers=[(-1, -1), (1, 1)], cluster_std=1.3, random_state=7)
X2_tr, X2_te, y2_tr, y2_te = train_test_split(X2, y2, test_size=0.3, stratify=y2, random_state=7)

print("    C | 서포트 벡터 수 | 마진 폭 | 훈련 정확도 | 테스트 정확도")
for C in [0.001, 0.01, 0.1, 1, 10, 100, 1000]:
    m = SVC(kernel="linear", C=C).fit(X2_tr, y2_tr)
    width = 2 / np.linalg.norm(m.coef_[0])
    print(f"{C:6g} | {m.n_support_.sum():14d} | {width:7.2f} | "
          f"{m.score(X2_tr, y2_tr):11.3f} | {m.score(X2_te, y2_te):13.3f}")
```

```text
    C | 서포트 벡터 수 | 마진 폭 | 훈련 정확도 | 테스트 정확도
 0.001 |            258 |    6.26 |       0.861 |         0.883
  0.01 |            144 |    3.03 |       0.861 |         0.875
   0.1 |             98 |    1.86 |       0.854 |         0.875
     1 |             88 |    1.52 |       0.857 |         0.875
    10 |             87 |    1.51 |       0.857 |         0.875
   100 |             87 |    1.51 |       0.857 |         0.875
  1000 |             87 |    1.51 |       0.857 |         0.875
```

`C`가 작을 때(0.001)는 마진 폭이 6.26이나 되며 훈련 샘플 280개 중 258개가 서포트 벡터입니다. `C`가 커질수록 마진이 좁아지고(1.51까지) 서포트 벡터가 줄어듭니다. `C=1` 이상에서는 값이 거의 변하지 않는데, 이 데이터는 단순해서 `C`를 더 키워도 줄일 수 있는 위반이 남아 있지 않기 때문입니다. 정확도는 훈련·테스트 모두 `C`에 크게 민감하지 않습니다. 이렇게 선형 모델은 상대적으로 둔감하지만, 8.7절에서 보듯 커널이 복잡해지면 `C`와 `gamma`의 영향이 훨씬 커집니다.

## 8.4 LinearSVC와 SVC(kernel="linear")

선형 SVM을 쓰는 방법은 두 가지입니다.

- `SVC(kernel="linear")`: 커널 SVM 구현체(libsvm)에서 선형 커널을 쓰는 방법입니다.
- `LinearSVC`: 선형 모델 전용 구현체(liblinear)로, 대용량 데이터에서 훨씬 빠릅니다.

```python
from sklearn.svm import LinearSVC

lin = LinearSVC(C=1.0, dual="auto", random_state=0).fit(X2_tr, y2_tr)
svc_lin = SVC(kernel="linear", C=1.0).fit(X2_tr, y2_tr)

print("LinearSVC        테스트 정확도:", round(lin.score(X2_te, y2_te), 3), ", w =", lin.coef_[0].round(3))
print("SVC(linear)      테스트 정확도:", round(svc_lin.score(X2_te, y2_te), 3), ", w =", svc_lin.coef_[0].round(3))
```

```text
LinearSVC        테스트 정확도: 0.875 , w = [0.458 0.44 ]
SVC(linear)      테스트 정확도: 0.875 , w = [0.917 0.943]
```

두 모델의 테스트 정확도는 같지만 `w`는 같지 않습니다. `LinearSVC`는 기본적으로 오분류 벌점에 **제곱 힌지 손실**(`loss="squared_hinge"`)을 쓰고 절편에도 규제를 가하는 등 목적 함수가 조금 다르기 때문에, 같은 `C`를 줘도 완전히 같은 모델이 아닙니다. 둘 다 "마진을 최대화하는 선형 분류기"라는 점은 같지만, `C`를 튜닝할 때 서로의 값을 그대로 가져다 쓰면 안 됩니다.

`dual="auto"`는 최적화 문제를 푸는 방식(쌍대 문제 또는 원 문제)을 scikit-learn이 데이터 크기에 맞게 고르게 하는 설정입니다. 특성이 스케일링되지 않았거나 `C`가 클 때는 `ConvergenceWarning`이 뜰 수 있는데, 이때는 `max_iter`를 늘리거나 스케일링을 먼저 적용합니다.

어떤 쪽이든 `decision_function`으로 경계에서 얼마나 떨어져 있는지 부호 있는 값으로 확인할 수 있습니다.

```python
print("결정 함수 값(처음 4개):", svc_lin.decision_function(X2_te[:4]).round(2))
print("예측 클래스          :", svc_lin.predict(X2_te[:4]))
```

```text
결정 함수 값(처음 4개): [-0.17 -2.22 -3.22 -0.3 ]
예측 클래스          : [0 0 0 0]
```

결정 함수 값은 `w·x + b`이며, 부호가 클래스를 결정하고 절댓값이 클수록 경계에서 멀리, 즉 더 "확신"하는 샘플입니다. 이 값은 확률이 아니라는 점에 유의하세요(확률이 필요할 때는 8.8절을 보세요).

## 8.5 커널 트릭: 비선형 데이터를 고차원으로

현실의 데이터는 직선 하나로 나눌 수 없는 경우가 많습니다. 가장 단순한 예가 1차원 직선 위의 데이터입니다. 가운데는 클래스 0, 양쪽 끝은 클래스 1이라면, 직선 위의 한 점(1차원의 "경계")으로는 절대 나눌 수 없습니다.

하지만 각 점 `x`를 `(x, x²)`라는 2차원 점으로 옮기면 어떻게 될까요? 가운데(|x|가 작은) 점들은 아래쪽, 양끝(|x|가 큰) 점들은 위쪽에 놓이므로 가로 직선 하나로 분리할 수 있습니다.

```python
# 1차원 데이터: 가운데(|x| < 1.5)는 클래스 0, 양끝은 클래스 1
x1 = np.linspace(-3, 3, 41)
y1 = (np.abs(x1) > 1.5).astype(int)

raw = LinearSVC(C=10, dual="auto", max_iter=100000).fit(x1.reshape(-1, 1), y1)
print("원래 1차원 특성, 선형 분류기 정확도:", round(raw.score(x1.reshape(-1, 1), y1), 3))

# 특성을 (x, x^2) 2차원으로 "올려 보내면" 직선 하나로 분리된다.
X_lift = np.column_stack([x1, x1 ** 2])
lifted = LinearSVC(C=10, dual="auto", max_iter=100000).fit(X_lift, y1)
print("(x, x^2)로 올린 뒤 선형 분류기 정확도:", round(lifted.score(X_lift, y1), 3))
```

```text
원래 1차원 특성, 선형 분류기 정확도: 0.512
(x, x^2)로 올린 뒤 선형 분류기 정확도: 1.0
```

원래 특성으로는 정확도가 0.512로 사실상 찍는 수준이지만, 특성을 `(x, x²)`로 늘리자 선형 분류기가 완벽하게 분리합니다. **차원을 올리면 선형으로 나눌 수 있게 된다**는 것이 핵심 직관입니다.

문제는 비용입니다. 특성이 많은 데이터에서 모든 2차, 3차 항을 일일이 만들면 특성 수가 폭발합니다. 여기서 **커널 트릭(kernel trick)** 이 등장합니다. SVM의 학습과 예측은 샘플 사이의 **내적**만으로 이루어져 있습니다. 그렇다면 높은 차원으로 실제로 옮기지 않고, "옮겼다면 나왔을 내적 값"을 원래 공간에서 직접 계산하는 함수(커널)만 있으면 됩니다.

2차원 점 `(x1, x2)`를 `(x1², √2·x1·x2, x2²)`라는 3차원으로 옮기는 사상 `φ`를 생각해 봅시다. 이 3차원 공간에서의 내적이 원래 공간에서 `(u·v)²`을 계산한 것과 정확히 같다는 것을 수치로 확인해 보겠습니다.

```python
# 커널 함수는 "올리기"를 실제로 하지 않고도 올린 공간의 내적을 계산해 준다.
rng = np.random.default_rng(0)
u, v = rng.normal(size=2), rng.normal(size=2)


def phi(p):
    # 2차 다항 사상: (x1, x2) -> (x1^2, sqrt(2)*x1*x2, x2^2)
    return np.array([p[0] ** 2, np.sqrt(2) * p[0] * p[1], p[1] ** 2])


explicit = phi(u) @ phi(v)   # 3차원으로 올린 뒤 내적
kernel = (u @ v) ** 2         # 2차원 상태에서 (u·v)^2
print("올린 뒤 내적:", round(float(explicit), 6))
print("커널 (u·v)^2:", round(float(kernel), 6))
```

```text
올린 뒤 내적: 0.004444
커널 (u·v)^2: 0.004444
```

두 값이 일치합니다. 3차원으로 올려서 내적을 계산할 필요 없이, 2차원 상태에서 `(u·v)²` 한 번만 계산하면 됩니다. 다음에 볼 RBF 커널은 이 원리를 극단까지 밀어붙여서, 사실상 **무한 차원**으로 올린 공간의 내적을 계산해 줍니다. 무한 차원은 실제로는 만들 수 없지만 커널 함수 한 줄이면 충분합니다.

scikit-learn의 `SVC`가 지원하는 주요 커널은 다음과 같습니다.

| `kernel` | 커널 함수 | 주요 파라미터 |
| --- | --- | --- |
| `"linear"` | `u·v` | `C` |
| `"poly"` | `(γ·u·v + coef0)^degree` | `degree`, `coef0`, `gamma`, `C` |
| `"rbf"` | `exp(-γ·‖u − v‖²)` | `gamma`, `C` |
| `"sigmoid"` | `tanh(γ·u·v + coef0)` | `gamma`, `coef0`, `C` |

특별한 이유가 없다면 `"rbf"`를 먼저 시도하는 것이 정석입니다.

## 8.6 RBF 커널과 gamma

RBF(Radial Basis Function, 가우시안) 커널 `exp(-γ·‖u − v‖²)`은 두 점의 **유사도**로 읽을 수 있습니다. 두 점이 같으면 1이고, 멀어질수록 0에 가까워집니다. `gamma`는 이 유사도가 얼마나 빨리 감소하는지를 정합니다.

```python
from sklearn.metrics.pairwise import rbf_kernel

p0 = np.array([[0.0, 0.0]])
others = np.array([[0.0, 0.0], [0.5, 0.0], [1.0, 0.0], [2.0, 0.0], [4.0, 0.0]])
for gamma in [0.1, 1.0, 10.0]:
    print(f"gamma={gamma:4}:", rbf_kernel(p0, others, gamma=gamma).round(4)[0])
```

```text
gamma= 0.1: [1.     0.9753 0.9048 0.6703 0.2019]
gamma= 1.0: [1.     0.7788 0.3679 0.0183 0.    ]
gamma=10.0: [1.     0.0821 0.     0.     0.    ]
```

기준점 (0, 0)과 거리 0, 0.5, 1, 2, 4만큼 떨어진 점의 유사도입니다.

- `gamma=0.1`: 거리 2에서도 유사도가 0.67입니다. 멀리 있는 점까지 "비슷하다"고 보므로 영향 범위가 넓고 결정 경계가 **매끄럽습니다**.
- `gamma=10`: 거리 0.5만 되어도 유사도가 0.08로 떨어집니다. 아주 가까운 점만 영향을 주므로, 샘플 하나하나 주위에 작은 "섬"을 만드는 **구불구불한** 경계가 됩니다.

결국 RBF 커널 SVM의 예측은 "서포트 벡터와의 유사도로 가중 투표를 하는 것"과 같습니다. 그래서 `gamma`가 작으면 과소적합, 크면 과대적합이 됩니다. `gamma`와 `C`는 항상 함께 조율해야 합니다. 둘 다 클수록 모델이 복잡해지는 방향으로 작용합니다.

`gamma`의 기본값 `"scale"`은 `1 / (특성 수 × 훈련 데이터의 분산)`으로, 데이터의 규모에 맞춰 적당한 출발점을 잡아 줍니다.

## 8.7 합성 데이터로 커널 비교하기

`make_moons`(두 개의 반달)와 `make_circles`(동심원)는 선형으로 분리되지 않는 대표적인 데이터입니다. 결정 경계를 그림으로 그리지 않고, 테스트 정확도로 커널을 비교해 봅시다.

```python
from sklearn.datasets import make_moons, make_circles

datasets = {
    "moons":   make_moons(n_samples=500, noise=0.25, random_state=0),
    "circles": make_circles(n_samples=500, noise=0.12, factor=0.4, random_state=0),
}

kernels = {
    "linear":         SVC(kernel="linear", C=1.0),
    "poly(2,c=1)":    SVC(kernel="poly", degree=2, coef0=1, C=1.0),
    "poly(3,c=1)":    SVC(kernel="poly", degree=3, coef0=1, C=1.0),
    "poly(3,c=0)":    SVC(kernel="poly", degree=3, coef0=0, C=1.0),   # coef0 기본값
    "rbf":            SVC(kernel="rbf", C=1.0, gamma="scale"),
}

print(f"{'데이터':8s}" + "".join(f"{k:>14s}" for k in kernels))
for name, (Xd, yd) in datasets.items():
    Xd_tr, Xd_te, yd_tr, yd_te = train_test_split(Xd, yd, test_size=0.3, stratify=yd, random_state=0)
    row = ""
    for model in kernels.values():
        row += f"{model.fit(Xd_tr, yd_tr).score(Xd_te, yd_te):14.3f}"
    print(f"{name:8s}" + row)
```

```text
데이터             linear   poly(2,c=1)   poly(3,c=1)   poly(3,c=0)           rbf
moons            0.840         0.847         0.953         0.887         0.947
circles          0.593         0.993         0.993         0.647         0.987
```

결과를 읽어 봅시다.

- **선형 커널**: 동심원에서 0.593으로 거의 찍는 수준입니다. 안쪽 원을 직선 하나로 감쌀 방법이 없기 때문입니다. 반달에서도 0.840에 그칩니다.
- **다항 커널**: `degree=2`, `coef0=1`이면 동심원을 0.993으로 거의 완벽하게 분리합니다. 원의 방정식이 2차식이기 때문입니다. 반달에서는 3차(0.953)가 2차(0.847)보다 낫습니다. 반달의 경계는 구불구불하기 때문입니다.
- **RBF 커널**: 두 데이터 모두 기본 설정만으로 0.947과 0.987을 얻었습니다. 어떤 모양에도 무난히 맞추는 범용성이 RBF가 기본 선택인 이유입니다.
- `coef0`의 기본값은 0입니다. `poly(3,c=0)` 열을 보면 같은 3차 다항식이라도 `coef0=0`일 때 동심원에서 0.647로 크게 나빠지는 것을 볼 수 있습니다. `coef0`는 `(γ·u·v + coef0)^degree` 안의 상수로, 이 값이 0이면 모든 항이 정확히 `degree`차로 고정되어 낮은 차수의 항(상수항 등)이 사라집니다. 다항 커널을 쓸 때는 `coef0=1` 같은 값을 함께 시험하는 것이 좋습니다.

다항 커널의 `degree`를 키워 보면 복잡도가 어떻게 변하는지 알 수 있습니다.

```python
Xc, yc = datasets["moons"]
Xc_tr, Xc_te, yc_tr, yc_te = train_test_split(Xc, yc, test_size=0.3, stratify=yc, random_state=0)

print("degree | 훈련 정확도 | 테스트 정확도")
for degree in [1, 2, 3, 5, 8]:
    m = SVC(kernel="poly", degree=degree, coef0=1, C=1.0).fit(Xc_tr, yc_tr)
    print(f"{degree:6d} | {m.score(Xc_tr, yc_tr):11.3f} | {m.score(Xc_te, yc_te):13.3f}")
```

```text
degree | 훈련 정확도 | 테스트 정확도
     1 |       0.860 |         0.840
     2 |       0.866 |         0.847
     3 |       0.926 |         0.953
     5 |       0.934 |         0.947
     8 |       0.931 |         0.940
```

차수가 1이면 선형과 같아서 성능이 낮고, 3차에서 최고점(테스트 0.953)을 찍은 뒤에는 차수를 높여도 나아지지 않습니다. 차수가 높을수록 계산이 불안정해지고 과대적합되기 쉬우므로, 다항 커널의 차수는 보통 2~4 범위에서 고릅니다.

이번에는 RBF 커널에서 `gamma`가 얼마나 결정적인지 확인해 보겠습니다.

```python
print("gamma 기본값(scale):", round(1 / (Xc_tr.shape[1] * Xc_tr.var()), 3))
print("  gamma | 서포트 벡터 수 | 훈련 정확도 | 테스트 정확도")
for gamma in [0.01, 0.1, 1, 10, 100, 1000]:
    m = SVC(kernel="rbf", C=1.0, gamma=gamma).fit(Xc_tr, yc_tr)
    print(f"{gamma:7g} | {m.n_support_.sum():14d} | {m.score(Xc_tr, yc_tr):11.3f} | {m.score(Xc_te, yc_te):13.3f}")
```

```text
gamma 기본값(scale): 0.914
  gamma | 서포트 벡터 수 | 훈련 정확도 | 테스트 정확도
   0.01 |            214 |       0.837 |         0.813
    0.1 |            147 |       0.866 |         0.847
      1 |             95 |       0.931 |         0.953
     10 |            129 |       0.937 |         0.940
    100 |            292 |       0.977 |         0.907
   1000 |            345 |       1.000 |         0.693
```

표의 변화가 아주 교과서적입니다.

- `gamma=0.01`: 지나치게 매끄러워서 **과소적합**입니다. 훈련 정확도(0.837)도 낮습니다.
- `gamma=1`~`10`: 훈련과 테스트 정확도가 모두 높은 구간입니다.
- `gamma=1000`: 훈련 정확도는 1.000이지만 테스트 정확도는 0.693으로 곤두박질칩니다. 모든 훈련 샘플을 개별적으로 외우는 **과대적합**입니다. 서포트 벡터가 345개로 훈련 샘플(350개)의 거의 전부라는 점도 신호입니다.

서포트 벡터 수는 과대적합 여부를 가늠하는 간단한 지표가 됩니다. 서포트 벡터가 훈련 샘플의 대부분이라면 모델이 데이터를 "외우고" 있을 가능성이 높습니다.

그러면 `C`와 `gamma`는 어떻게 정할까요? 정답은 **교차 검증으로 탐색**하는 것입니다. `GridSearchCV`는 지정한 하이퍼파라미터 조합을 모두 시도하고 교차 검증 점수가 가장 좋은 조합을 골라 줍니다. 값은 로그 간격(0.1, 1, 10, 100처럼 10배씩)으로 넓게 훑는 것이 관례입니다.

```python
from sklearn.model_selection import GridSearchCV

param_grid = {"C": [0.1, 1, 10, 100], "gamma": [0.01, 0.1, 1, 10]}
search = GridSearchCV(SVC(kernel="rbf"), param_grid, cv=5)
search.fit(Xc_tr, yc_tr)
print("최적 파라미터:", search.best_params_)
print("교차검증 점수:", round(search.best_score_, 3))
print("테스트 정확도:", round(search.score(Xc_te, yc_te), 3))
```

```text
최적 파라미터: {'C': 0.1, 'gamma': 10}
교차검증 점수: 0.931
테스트 정확도: 0.94
```

4 × 4 = 16개 조합을 5-겹 교차 검증하므로 모델을 80번 학습했습니다. 찾아낸 최적 조합의 테스트 정확도가 앞서 기본값으로 얻은 값과 비슷한 것은, 이 데이터에는 이미 기본 설정이 충분히 좋았다는 뜻입니다. 또한 `C`와 `gamma`는 서로 보완 관계라서 점수가 비슷한 조합이 여럿 존재하는 경우가 많습니다. 결과로 나온 조합 하나만 맹신하지 말고, 점수가 높은 영역 전체를 보는 것이 좋습니다.

## 8.8 스케일링, 다중 클래스, 확률

### 스케일링은 필수다

SVM도 k-NN처럼 거리(커널)에 기반하므로 **특성의 크기가 다르면 큰 특성이 지배**합니다. 선형 SVM에서도 마진 `2/‖w‖`가 특성의 단위에 따라 달라지기 때문에 스케일링이 중요합니다. 와인 데이터로 확인해 봅시다.

```python
from sklearn.datasets import load_wine
from sklearn.model_selection import cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

Xw, yw = load_wine(return_X_y=True)
no_scale = SVC(kernel="rbf")
with_scale = make_pipeline(StandardScaler(), SVC(kernel="rbf"))

print("스케일링 없음 :", cross_val_score(no_scale, Xw, yw, cv=5).mean().round(3))
print("StandardScaler:", cross_val_score(with_scale, Xw, yw, cv=5).mean().round(3))
```

```text
스케일링 없음 : 0.663
StandardScaler: 0.983
```

스케일링 하나로 0.663이 0.983으로 올랐습니다. SVM을 쓸 때는 `StandardScaler`(또는 `MinMaxScaler`)와 `make_pipeline`으로 묶어서 사용하는 것을 기본 습관으로 삼으세요.

### 다중 클래스

SVM은 본래 두 클래스를 나누는 모델입니다. `SVC`는 클래스 쌍마다 따로 분류기를 만드는 **일대일(one-vs-one)** 방식으로 다중 클래스를 처리하고, `LinearSVC`는 "한 클래스 대 나머지"를 가르는 **일대다(one-vs-rest)** 방식을 씁니다. 사용자는 별다른 설정 없이 그냥 `fit`하면 됩니다.

```python
from sklearn.datasets import load_iris

Xi, yi = load_iris(return_X_y=True)
Xi_tr, Xi_te, yi_tr, yi_te = train_test_split(Xi, yi, test_size=0.3, stratify=yi, random_state=42)

iris_svm = make_pipeline(StandardScaler(), SVC(kernel="rbf", C=1.0)).fit(Xi_tr, yi_tr)
print("붓꽃 3클래스 테스트 정확도:", round(iris_svm.score(Xi_te, yi_te), 3))
print("결정 함수 모양:", iris_svm.decision_function(Xi_te).shape)
```

```text
붓꽃 3클래스 테스트 정확도: 0.933
결정 함수 모양: (45, 3)
```

`SVC`의 `decision_function`은 기본적으로 `(샘플 수, 클래스 수)` 모양으로 정리된 값을 줍니다(`decision_function_shape="ovr"`이 기본값입니다). 내부 학습은 일대일 방식이지만, 결과를 다른 분류기와 같은 모양으로 보여 주는 것입니다.

### 확률이 필요할 때

SVM의 결정 함수 값은 "경계로부터의 거리"일 뿐 확률이 아닙니다. 확률이 필요하다면 `CalibratedClassifierCV`로 감싸 결정 함수 값을 확률로 보정합니다.

```python
from sklearn.calibration import CalibratedClassifierCV

# SVC는 기본적으로 확률을 주지 않는다. 확률이 필요하면 보정기를 감싼다.
calibrated = CalibratedClassifierCV(SVC(kernel="rbf"), ensemble=False, cv=5)
calibrated.fit(Xc_tr, yc_tr)
print(calibrated.predict_proba(Xc_te[:3]).round(3))
print("테스트 정확도:", round(calibrated.score(Xc_te, yc_te), 3))
```

```text
[[0.012 0.988]
 [0.98  0.02 ]
 [0.662 0.338]]
테스트 정확도: 0.947
```

> **참고**: `SVC(probability=True)`라는 옵션도 있지만 scikit-learn 1.9에서 사용이 권장되지 않게(deprecated) 되었고, 이후 버전에서 제거될 예정입니다. 위처럼 `CalibratedClassifierCV`를 사용하세요.

## 8.9 대용량 데이터에서의 한계

커널 SVM의 가장 큰 약점은 **샘플 수가 늘어날 때의 계산 비용**입니다. 커널 SVM은 샘플 쌍 사이의 커널 값을 다루기 때문에 학습 시간이 샘플 수에 대해 제곱보다 빠르게 늘어납니다. 메모리도 많이 씁니다. 직접 시간을 재 봅시다.

```python
import time

print("   샘플 수 | SVC(rbf) 학습 시간 | LinearSVC 학습 시간")
for n in [5000, 10000, 20000, 40000]:
    Xb, yb = make_blobs(n_samples=n, centers=2, n_features=20, cluster_std=10.0, random_state=0)

    t0 = time.perf_counter()
    SVC(kernel="rbf").fit(Xb, yb)
    t_rbf = time.perf_counter() - t0

    t0 = time.perf_counter()
    LinearSVC(dual="auto").fit(Xb, yb)
    t_lin = time.perf_counter() - t0

    print(f"{n:10d} | {t_rbf:16.3f} 초 | {t_lin:17.3f} 초")
```

```text
   샘플 수 | SVC(rbf) 학습 시간 | LinearSVC 학습 시간
      5000 |            0.263 초 |             0.007 초
     10000 |            1.541 초 |             0.014 초
     20000 |            6.228 초 |             0.037 초
     40000 |           25.354 초 |             0.134 초
```

(시간은 사용하는 컴퓨터와 실행 시점에 따라 달라집니다. 이 예제는 40000개 샘플에서 수 초에서 수십 초가 걸릴 수 있습니다. 경향을 보는 것이 목적이므로 기다리기 어렵다면 마지막 크기를 지워도 됩니다.)

샘플 수가 2배가 될 때마다 `SVC`(RBF)의 학습 시간은 몇 배씩 늘어나서, 40000개에서는 수 초에서 수십 초가 걸립니다. 반면 `LinearSVC`는 훨씬 완만하게 늘고, 속도 자체도 압도적으로 빠릅니다. (데이터가 심하게 겹치도록 만들어서 서포트 벡터가 많았기 때문에 `SVC`가 특히 느린 사례이기는 합니다.)

실무에서는 대략 다음과 같이 선택합니다.

- **샘플 수 ~ 수만 개 이하**: `SVC(kernel="rbf")`를 마음껏 시도합니다.
- **샘플이 수십만 개 이상**: `LinearSVC`나 `SGDClassifier(loss="hinge")`처럼 선형 모델을 쓰거나, 트리 기반 앙상블, 딥러닝으로 넘어갑니다.
- **비선형이 꼭 필요한데 데이터가 많을 때**: 커널을 근사하는 `Nystroem` 같은 변환기와 선형 모델을 조합하는 방법이 있습니다. (이 책에서는 다루지 않습니다.)

SVM의 또 다른 한계는 해석이 어렵다는 점(커널 SVM), 그리고 확률을 기본으로 제공하지 않는다는 점입니다.

## 8.10 SVR: 회귀에 쓰는 SVM

SVM의 아이디어는 회귀로도 확장됩니다. 바로 `SVR`(Support Vector Regression)입니다. 분류에서 "마진 바깥으로 나가면 벌점"이었다면, 회귀에서는 **예측선 주위에 폭 `epsilon`의 튜브를 두르고, 이 튜브 안에 있는 샘플은 오차가 없는 것으로 취급**합니다. 튜브 밖으로 벗어난 만큼에만 벌점(`C`로 조절)을 줍니다. 그래서 튜브 안의 샘플은 서포트 벡터가 되지 않습니다.

- `epsilon`: 튜브의 반폭입니다. 클수록 작은 오차를 무시하고 더 단순한 모델이 됩니다.
- `C`, `kernel`, `gamma`: 분류 SVM과 같은 의미입니다.

잡음이 섞인 사인 곡선을 `SVR(kernel="rbf")`로 맞추고 `epsilon`의 영향을 확인해 봅시다.

```python
from sklearn.svm import SVR
from sklearn.metrics import r2_score

rng = np.random.default_rng(0)
Xr = np.sort(rng.uniform(0, 6, size=(200, 1)), axis=0)
yr = np.sin(Xr).ravel() + rng.normal(scale=0.2, size=200)
Xr_tr, Xr_te, yr_tr, yr_te = train_test_split(Xr, yr, test_size=0.3, random_state=0)

print("epsilon | 서포트 벡터 수 | 훈련 R2 | 테스트 R2")
for eps in [0.01, 0.1, 0.3, 0.6]:
    reg = SVR(kernel="rbf", C=10, gamma=1.0, epsilon=eps).fit(Xr_tr, yr_tr)
    print(f"{eps:7.2f} | {len(reg.support_):14d} | {r2_score(yr_tr, reg.predict(Xr_tr)):7.3f} | "
          f"{r2_score(yr_te, reg.predict(Xr_te)):9.3f}")
```

```text
epsilon | 서포트 벡터 수 | 훈련 R2 | 테스트 R2
   0.01 |            138 |   0.921 |     0.913
   0.10 |             87 |   0.923 |     0.915
   0.30 |             25 |   0.914 |     0.897
   0.60 |              6 |   0.830 |     0.791
```

`epsilon`이 작을수록 거의 모든 샘플이 튜브 밖에 놓여 서포트 벡터가 많아집니다(0.01일 때 138개). `epsilon`이 커지면 서포트 벡터가 급격히 줄어(0.6일 때 6개) 모델이 단순해지지만, 너무 크면 곡선의 굴곡을 놓쳐서 R² 점수가 떨어집니다. 이 데이터의 잡음은 표준편차 0.2 정도이므로, 그와 비슷한 수준의 `epsilon`(0.1~0.3)이 적절한 타협점입니다. `epsilon`을 잡음 크기를 가늠하는 도구로 쓸 수도 있습니다.

SVR도 스케일링이 필요합니다. 분류와 같은 방식으로 파이프라인에 묶어 사용합니다.

```python
reg = make_pipeline(StandardScaler(), SVR(kernel="rbf", C=10, epsilon=0.1)).fit(Xr_tr, yr_tr)
print("새 입력 x = 1.5, 3.0 예측:", reg.predict([[1.5], [3.0]]).round(3))
print("실제 sin 값             :", np.sin([1.5, 3.0]).round(3))
```

```text
새 입력 x = 1.5, 3.0 예측: [1.   0.06]
실제 sin 값             : [0.997 0.141]
```

예측값이 실제 사인 값을 대체로 따라가고 있습니다. 데이터에 잡음이 있으므로 약간의 차이는 정상입니다.

## 요약

- SVM은 두 클래스 사이의 **마진이 최대**가 되도록 경계를 긋습니다. 경계는 마진 가장자리에 걸친 **서포트 벡터**들만으로 결정되며, 나머지 샘플은 지워도 결과가 같습니다.
- **소프트 마진**은 마진 침범을 허용하되 벌점을 줍니다. `C`가 작으면 마진이 넓고 단순한 모델(과소적합 쪽), 크면 훈련 데이터에 충실한 모델(과대적합 쪽)입니다. scikit-learn의 `C`는 규제의 **역수**입니다.
- `LinearSVC`는 대용량 선형 문제에, `SVC(kernel=...)`는 비선형 문제에 씁니다. 두 구현은 목적 함수가 조금 달라서 같은 `C`가 같은 모델을 뜻하지 않습니다.
- **커널 트릭**은 고차원으로 실제로 옮기지 않고 그곳의 내적을 계산해 줍니다. `"rbf"`가 기본 선택이며, `gamma`가 클수록 경계가 복잡해집니다. `"poly"`는 `degree`와 `coef0`를 함께 조정합니다.
- `C`와 `gamma`는 서로 영향을 주므로 `GridSearchCV`와 같이 교차 검증으로 함께 탐색하는 것이 좋습니다. 서포트 벡터 수가 훈련 샘플 수에 가까우면 과대적합을 의심해 보세요.
- SVM은 **스케일링이 필수**입니다(와인 데이터에서 0.663 → 0.983). `StandardScaler`와 파이프라인으로 묶어 쓰세요.
- 커널 SVM은 샘플 수가 늘면 학습 시간이 급격히 증가하므로, 대용량 데이터에서는 선형 모델이나 다른 알고리즘이 더 적합합니다.
- 확률이 필요하면 `CalibratedClassifierCV`로 감쌉니다. 회귀에는 `SVR`을 쓰며, `epsilon` 튜브 안의 오차는 무시합니다.

## 연습문제

1. **C의 효과.** `load_breast_cancer` 데이터를 `StandardScaler`와 `SVC(kernel="linear")`의 파이프라인으로 학습시키면서, `C`를 `0.0001, 0.001, 0.01, 0.1, 1, 10, 100`으로 바꿔 가며 서포트 벡터 수, 훈련 정확도, 5-겹 교차 검증 정확도를 표로 출력하세요. (힌트: 파이프라인으로 학습한 뒤 `pipe[-1].n_support_`로 SVM 단계에 접근할 수 있습니다.) `C`가 작아질수록 서포트 벡터 수는 어떻게 변하나요?

2. **XOR 문제.** NumPy로 네 구석 `(0,0), (0,1), (1,0), (1,1)` 주변에 정규분포 잡음을 더해 샘플을 각각 50개씩 만들고, `(0,0)`과 `(1,1)` 쪽은 클래스 0, `(0,1)`과 `(1,0)` 쪽은 클래스 1로 레이블을 붙이세요. 선형 커널, 2차 다항 커널(`coef0=1`), RBF 커널의 정확도를 비교하고, 선형 커널이 실패하는 이유를 설명하세요.

3. **gamma와 C의 지형.** `make_circles(noise=0.2, factor=0.5, random_state=0)` 데이터에서 `C`는 `np.logspace(-2, 3, 6)`, `gamma`는 `np.logspace(-3, 2, 6)` 범위로 `GridSearchCV`를 수행하세요. 최적 조합은 무엇이며, 같은 정도로 좋은 조합이 몇 개나 되나요? (힌트: `search.cv_results_["mean_test_score"]`를 `(6, 6)` 모양으로 바꿔 보세요. 파라미터 순서는 `search.cv_results_["params"]`로 확인합니다.) 또 기본값 `gamma="scale"`이 가리키는 값은 이 범위 안 어디쯤인지도 계산해 보세요.

4. **커널을 직접 확인하기.** `SVC`의 2차 다항 커널(`gamma=1`, `coef0=1`)은 `(u·v + 1)²`입니다. 이 값이 2차원 점을 `φ(x) = (1, √2·x1, √2·x2, x1², √2·x1·x2, x2²)`로 옮긴 뒤의 내적 `φ(u)·φ(v)`와 같음을 8.5절처럼 난수로 만든 벡터 몇 쌍으로 확인하세요. 이 사상이 몇 차원으로의 이동인지, `degree`와 특성 수가 커질 때 이 차원이 얼마나 빨리 늘어날지도 생각해 보세요.

5. **epsilon과 잡음.** 8.10절의 사인 곡선 데이터를 잡음의 표준편차 `0.05, 0.2, 0.5` 세 가지로 만들고, 각각에 대해 `epsilon`을 `[0.01, 0.05, 0.1, 0.2, 0.4, 0.8]`에서 `GridSearchCV`로 고르세요. 최적 `epsilon`이 잡음의 크기와 어떤 관계가 있는지 정리해 보세요.
