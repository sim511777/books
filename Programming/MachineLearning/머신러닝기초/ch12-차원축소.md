현실의 데이터는 특성이 수십, 수백, 때로는 수만 개나 됩니다. 이미지는 픽셀 하나가 특성이고, 문서는 단어 하나가 특성입니다. 특성이 많다고 늘 좋은 것은 아닙니다. 계산이 느려지고, 과대적합이 쉬워지고, 사람이 눈으로 확인할 방법이 없어집니다. **차원 축소(dimensionality reduction)**는 데이터가 가진 정보를 최대한 유지하면서 특성의 개수를 줄이는 기법입니다. 이 장에서는 다음을 배웁니다.

- 차원의 저주가 무엇이고, 차원을 줄이는 목적은 무엇인지
- 가장 대표적인 선형 차원 축소인 **PCA**의 원리와 NumPy 구현, `PCA` 사용법
- 주성분 개수를 고르는 방법, 압축과 노이즈 제거
- 손글씨 숫자 데이터를 2차원으로 줄여서 구조 확인하기
- 시각화에 많이 쓰는 **t-SNE**의 개념과 해석할 때의 주의점
- 비지도 이상 탐지의 한 예인 **IsolationForest**

## 12.1 차원의 저주와 차원 축소의 목적

### 12.1.1 차원이 높아지면 무슨 일이 생길까

저차원에서 잘 통하던 직관이 고차원에서는 어긋납니다. 이를 통틀어 **차원의 저주(curse of dimensionality)**라고 부릅니다. 두 가지 현상을 숫자로 확인해 보겠습니다.

첫째, 고차원에서는 **모든 점이 서로 비슷한 거리**에 놓입니다. 0과 1 사이에서 무작위로 뽑은 점 500개와 기준점 하나 사이의 거리를 차원별로 재어 봅니다.

```python
import numpy as np

rng = np.random.default_rng(0)

print("  차원  최소거리  최대거리  (최대-최소)/최소")
for d in [2, 10, 100, 1000, 10000]:
    P = rng.random((500, d))
    q = rng.random(d)
    dist = np.linalg.norm(P - q, axis=1)
    print(f"{d:6d}  {dist.min():8.2f}  {dist.max():8.2f}  {(dist.max() - dist.min()) / dist.min():14.2f}")
```

```text
  차원  최소거리  최대거리  (최대-최소)/최소
     2      0.03      1.27           40.73
    10      0.34      1.91            4.65
   100      3.39      4.60            0.36
  1000     12.32     13.63            0.11
 10000     40.19     41.38            0.03
```

2차원에서는 가장 가까운 점과 가장 먼 점의 거리가 수십 배 차이 났지만, 10,000차원에서는 최대 거리가 최소 거리의 3% 정도만 더 클 뿐입니다. "가까운 이웃"이라는 개념이 흐려지는 것이지요. k-최근접 이웃, k-means, DBSCAN처럼 거리에 의존하는 알고리즘은 차원이 높을수록 성능이 떨어지기 쉽습니다.

둘째, 고차원에서는 **공간이 거의 비어 있습니다.** 한 변이 2인 정육면체 안에 무작위로 점을 뿌리고, 그중 반지름 1인 구 안에 들어오는 비율을 봅니다.

```python
for d in [2, 5, 10, 20]:
    pts = rng.uniform(-1, 1, size=(200_000, d))
    inside = (np.linalg.norm(pts, axis=1) <= 1).mean()
    print(f"{d:2d}차원: 구 안에 들어온 비율 = {inside:.4f}")
```

```text
 2차원: 구 안에 들어온 비율 = 0.7847
 5차원: 구 안에 들어온 비율 = 0.1641
10차원: 구 안에 들어온 비율 = 0.0026
20차원: 구 안에 들어온 비율 = 0.0000
```

2차원에서는 약 78.5%(원의 넓이 π/4)가 들어오지만, 20차원에서는 20만 개를 뿌려도 하나도 들어오지 않습니다. 고차원 공간의 부피는 대부분 "모서리"에 몰려 있습니다. 같은 밀도로 데이터를 채우려면 차원이 늘어날 때마다 필요한 샘플 수가 폭발적으로 늘어납니다. 샘플은 그대로인데 차원만 늘면 데이터가 듬성듬성해지고, 모델은 우연한 패턴까지 외우게(과대적합) 됩니다.

### 12.1.2 차원 축소의 목적

차원을 줄이면 다음과 같은 이점이 있습니다.

- **시각화**: 사람은 2~3차원까지만 볼 수 있습니다. 수십 차원 데이터를 2차원 산점도로 줄이면 구조를 한눈에 확인할 수 있습니다.
- **압축**: 특성 수를 줄여 저장 공간과 계산 시간을 아낍니다.
- **노이즈 제거**: 중요한 변화는 소수의 방향에 몰려 있고 잡음은 여러 방향에 흩어져 있다는 가정 아래, 소수의 방향만 남겨 잡음을 걸러냅니다.
- **학습 안정화**: 서로 상관이 높은 특성을 정리해 모델의 과대적합을 줄이고 학습 속도를 높입니다.

차원 축소는 크게 두 갈래로 나눌 수 있습니다.

| 갈래 | 방법 | 예 |
| --- | --- | --- |
| 특성 선택 | 원래 특성 중 쓸모 있는 것만 고른다 | 분산이 작은 특성 제거, 중요도 낮은 특성 제거 |
| 특성 추출 | 원래 특성을 조합해 새로운 특성을 만든다 | PCA, t-SNE |

이 장에서는 특성 추출 방식을 다룹니다. 그중 PCA는 원래 특성의 **선형 결합**으로 새 축을 만드는 선형 기법이고, t-SNE는 데이터의 국소적인 이웃 관계를 보존하는 **비선형** 기법입니다.

## 12.2 PCA

### 12.2.1 직관: 분산이 큰 방향 찾기

**주성분 분석(PCA, Principal Component Analysis)**의 아이디어는 이렇습니다. 데이터가 가장 넓게 퍼져 있는 방향이 정보를 가장 많이 담고 있다고 보고, 그 방향으로 새로운 축을 세웁니다.

키와 몸무게 데이터를 생각해 보세요. 키가 큰 사람은 대체로 몸무게도 많이 나가니, 점들이 대각선 방향으로 길쭉한 타원 모양을 이룹니다. 이때 두 특성(키, 몸무게)을 따로 쓰는 대신 "대각선 방향의 값" 하나만 쓰면 점들의 위치를 꽤 잘 설명할 수 있습니다. 대각선과 수직인 방향으로의 퍼짐은 작아서, 버려도 손실이 적기 때문입니다.

PCA는 이 과정을 체계적으로 수행합니다.

1. 각 특성의 평균을 빼서 데이터의 중심을 원점으로 옮깁니다.
2. 분산이 **가장 큰** 방향을 찾습니다. 이것이 제1주성분입니다.
3. 제1주성분과 수직인 방향 중 분산이 가장 큰 방향을 찾습니다. 제2주성분입니다.
4. 이를 특성의 개수만큼 반복합니다. 주성분들은 서로 직교합니다.
5. 앞에서부터 k개의 주성분만 남기고, 데이터를 그 축으로 **투영**한 값을 새 특성으로 씁니다.

이 방향을 구하는 방법은 놀랍도록 간단합니다. 중심을 옮긴 데이터의 **공분산 행렬**을 구하고, 그 **고유벡터**를 찾으면 됩니다. 고유벡터 하나가 주성분 방향 하나이고, 대응하는 **고유값**은 그 방향으로의 분산 크기입니다. 고유값이 큰 순서대로 주성분의 순위가 정해집니다. 왜 고유벡터가 분산이 최대인 방향이 되는지의 증명은 선형대수 부록에서 다루고, 이 장에서는 계산만 따라가겠습니다.

> **공분산 행렬**은 특성들이 함께 움직이는 정도를 모은 정사각 행렬입니다. 대각선 원소는 각 특성의 분산이고, 나머지 원소는 두 특성 사이의 공분산입니다. 특성이 p개이면 p×p 행렬입니다.

### 12.2.2 NumPy로 직접 구현

키-몸무게 같은 상관된 2차원 데이터를 만들고 위 순서를 그대로 구현해 봅니다.

```python
rng = np.random.default_rng(0)
t = rng.normal(size=200)
X2 = np.c_[2 * t + rng.normal(scale=0.5, size=200),
           t + rng.normal(scale=0.5, size=200)]      # 두 특성이 강하게 상관된 데이터

# 1. 중심 이동
mean = X2.mean(axis=0)
Xc = X2 - mean

# 2. 공분산 행렬과 고유분해
cov = np.cov(Xc, rowvar=False)                       # (특성 수, 특성 수)
eigvals, eigvecs = np.linalg.eigh(cov)               # 대칭 행렬 전용, 고유값 오름차순

# 3. 고유값이 큰 순서로 정렬
order = np.argsort(eigvals)[::-1]
eigvals, eigvecs = eigvals[order], eigvecs[:, order]

print("공분산 행렬:\n", cov.round(3))
print("고유값:", eigvals.round(3))
print("주성분 방향(각 열이 한 방향):\n", eigvecs.round(3))
print("설명 분산 비율:", (eigvals / eigvals.sum()).round(3))

# 4. 투영: 중심을 옮긴 데이터에 고유벡터를 곱한다
Z2 = Xc @ eigvecs
print("투영 후 각 축의 분산:", Z2.var(axis=0, ddof=1).round(3))
```

```text
공분산 행렬:
 [[3.85  1.898]
 [1.898 1.238]]
고유값: [4.848 0.24 ]
주성분 방향(각 열이 한 방향):
 [[-0.885  0.465]
 [-0.465 -0.885]]
설명 분산 비율: [0.953 0.047]
투영 후 각 축의 분산: [4.848 0.24 ]
```

결과를 읽어 봅니다.

- 공분산 행렬의 비대각 원소(1.898)가 크니 두 특성이 같은 방향으로 움직인다는 뜻입니다.
- 첫 번째 고유값은 4.848, 두 번째는 0.240입니다. 투영 후 각 축의 분산이 고유값과 똑같다는 점에 주목하세요. **고유값은 그 주성분 방향으로의 분산**입니다.
- 제1주성분이 전체 분산의 95.3%를 설명합니다. 두 특성을 하나로 줄여도 정보의 대부분을 유지한다는 뜻입니다.
- 첫 번째 주성분 방향은 대략 ±(0.885, 0.465)입니다. 각 특성이 `2t`와 `t` 꼴로 만들어졌으므로 기울기 약 1/2인 대각선 방향이 나온 것이 자연스럽습니다. 부호가 음수로 나온 것은 아래에서 설명합니다.

이를 재사용할 수 있도록 함수로 묶습니다. `eigh`가 오름차순으로 돌려주는 것을 내림차순으로 뒤집고, 앞의 k개만 남깁니다.

```python
def my_pca(X, k):
    mean = X.mean(axis=0)
    Xc = X - mean
    eigvals, eigvecs = np.linalg.eigh(np.cov(Xc, rowvar=False))
    order = np.argsort(eigvals)[::-1]
    eigvals, eigvecs = eigvals[order], eigvecs[:, order]
    components = eigvecs[:, :k].T                   # (k, 특성 수): 각 행이 한 주성분
    ratio = eigvals[:k] / eigvals.sum()             # 설명 분산 비율
    return Xc @ components.T, components, ratio, mean
```

### 12.2.3 scikit-learn의 PCA

같은 일을 `PCA`가 해 줍니다. 다른 변환기처럼 `fit`으로 주성분을 학습하고 `transform`으로 투영합니다.

```python
from sklearn.decomposition import PCA

pca2 = PCA(n_components=2).fit(X2)
print("components_:\n", pca2.components_.round(3))
print("explained_variance_:", pca2.explained_variance_.round(3))
print("explained_variance_ratio_:", pca2.explained_variance_ratio_.round(3))
print("mean_:", pca2.mean_.round(3))
print("부호를 무시하면 직접 구현과 같은가:", np.allclose(np.abs(pca2.transform(X2)), np.abs(Z2)))
```

```text
components_:
 [[ 0.885  0.465]
 [-0.465  0.885]]
explained_variance_: [4.848 0.24 ]
explained_variance_ratio_: [0.953 0.047]
mean_: [-0.014  0.018]
부호를 무시하면 직접 구현과 같은가: True
```

자주 쓰는 속성은 다음과 같습니다.

| 이름 | 의미 |
| --- | --- |
| `components_` | 주성분 방향. 각 **행**이 한 주성분(위 직접 구현의 `eigvecs`는 각 **열**) |
| `explained_variance_` | 각 주성분 방향의 분산(고유값) |
| `explained_variance_ratio_` | 전체 분산 중 각 주성분이 설명하는 비율 |
| `mean_` | 학습 데이터의 특성별 평균 (`PCA`가 스스로 중심을 옮깁니다) |
| `n_components_` | 실제로 남긴 주성분 개수 |

한 가지 알아 둘 점이 있습니다. 직접 구현에서는 제1주성분이 (-0.885, -0.465)였는데 `components_`에는 (0.885, 0.465)가 나왔습니다. 고유벡터는 방향만 의미가 있고 부호는 임의이기 때문에, 구현에 따라 부호가 뒤집힐 수 있습니다. 투영 결과의 부호만 달라질 뿐 분산이나 정보량은 같습니다. 그래서 위 코드에서는 `np.abs`로 비교했습니다. 부호가 다르다고 "틀렸다"고 생각하지 마세요.

> `PCA`는 내부적으로 고유분해 대신 특이값 분해(SVD)를 사용해 수치적으로 더 안정적으로 계산합니다. 결과는 같은 주성분 방향입니다. SVD와의 관계 역시 부록에서 다룹니다.

이번에는 더 큰 데이터로 직접 구현과 `PCA`를 비교합니다. 사이킷런에 내장된 손글씨 숫자 데이터는 8×8 픽셀 이미지 1,797장이고, 특성은 픽셀 64개입니다.

```python
from sklearn.datasets import load_digits

digits = load_digits()
Xd, yd = digits.data, digits.target
print("데이터 모양:", Xd.shape, " 픽셀 값 범위:", Xd.min(), "~", Xd.max())

Z_mine, comps_mine, ratio_mine, _ = my_pca(Xd, 10)
pca_d = PCA(n_components=10).fit(Xd)
print("설명 분산 비율(직접):  ", ratio_mine.round(3))
print("설명 분산 비율(sklearn):", pca_d.explained_variance_ratio_.round(3))
print("투영 결과 일치:", np.allclose(np.abs(Z_mine), np.abs(pca_d.transform(Xd)), atol=1e-6))
```

```text
데이터 모양: (1797, 64)  픽셀 값 범위: 0.0 ~ 16.0
설명 분산 비율(직접):   [0.149 0.136 0.118 0.084 0.058 0.049 0.043 0.037 0.034 0.031]
설명 분산 비율(sklearn): [0.149 0.136 0.118 0.084 0.058 0.049 0.043 0.037 0.034 0.031]
투영 결과 일치: True
```

64차원이어도 같은 코드로 같은 결과를 얻었습니다. 제1주성분이 전체 분산의 약 15%, 제2주성분이 약 14%를 설명하고, 주성분이 뒤로 갈수록 설명하는 비율이 조금씩 줄어듭니다.

### 12.2.4 스케일링에 주의

PCA는 분산이 큰 방향을 찾으므로, 특성마다 단위(스케일)가 다르면 값의 범위가 큰 특성이 주성분을 독차지합니다. 11장에서 본 와인 데이터로 확인합니다.

```python
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler

wine = load_wine()
Xw = wine.data

pca_raw = PCA().fit(Xw)
pca_std = PCA().fit(StandardScaler().fit_transform(Xw))

top = np.argmax(np.abs(pca_raw.components_[0]))
print("원본  제1주성분 비율:", pca_raw.explained_variance_ratio_[0].round(3),
      "  가장 크게 기여한 특성:", wine.feature_names[top])
print("표준화 제1주성분 비율:", pca_std.explained_variance_ratio_[0].round(3))
print("표준화 후 상위 3개 비율:", pca_std.explained_variance_ratio_[:3].round(3))
```

```text
원본  제1주성분 비율: 0.998   가장 크게 기여한 특성: proline
표준화 제1주성분 비율: 0.362
표준화 후 상위 3개 비율: [0.362 0.192 0.111]
```

원본 데이터에서는 제1주성분이 사실상 `proline`(값의 범위가 수백~천) 하나이고 그 비율이 99%를 넘습니다. 새로운 정보를 만든 것이 아니라 단위의 효과일 뿐입니다. 표준화를 거치면 분산이 여러 주성분에 나뉘어, 제1주성분의 비율이 36%로 줄어듭니다. **특성들의 단위가 다르면 PCA 전에 `StandardScaler`를 적용**하세요. 반대로 위 숫자 이미지처럼 모든 특성이 같은 단위(픽셀 밝기)인 경우에는 표준화하지 않아도 괜찮습니다.

### 12.2.5 주성분 개수 고르기

몇 개의 주성분을 남길지는 **누적 설명 분산 비율**로 정하는 것이 일반적입니다. 숫자 데이터에서 주성분을 전부 구하고, 누적 합을 봅니다.

```python
pca_full = PCA().fit(Xd)
cum = np.cumsum(pca_full.explained_variance_ratio_)

print("주성분 수  누적 설명 분산")
for k in [2, 5, 10, 20, 30, 40, 64]:
    print(f"{k:8d}  {cum[k - 1]:12.3f}")

for target in [0.80, 0.90, 0.95, 0.99]:
    print(f"{target:.0%} 이상을 설명하는 최소 주성분 수:", int(np.searchsorted(cum, target)) + 1)
```

```text
주성분 수  누적 설명 분산
       2         0.285
       5         0.545
      10         0.738
      20         0.894
      30         0.959
      40         0.988
      64         1.000
80% 이상을 설명하는 최소 주성분 수: 13
90% 이상을 설명하는 최소 주성분 수: 21
95% 이상을 설명하는 최소 주성분 수: 29
99% 이상을 설명하는 최소 주성분 수: 41
```

64개 픽셀 중 29개의 주성분이면 분산의 95%를, 41개면 99%를 설명합니다. 반대로 2개로는 28.5%밖에 설명하지 못합니다. 시각화를 위해 2차원으로 줄이면 정보 손실이 크다는 점을 기억해 두세요.

`n_components`에 1보다 작은 실수를 주면 "이 비율만큼 분산을 설명하는 최소 개수"를 `PCA`가 알아서 정해 줍니다.

```python
pca95 = PCA(n_components=0.95).fit(Xd)
print("선택된 주성분 수:", pca95.n_components_)
print("실제 누적 설명 분산:", pca95.explained_variance_ratio_.sum().round(4))
```

```text
선택된 주성분 수: 29
실제 누적 설명 분산: 0.9548
```

주성분 개수를 고르는 다른 기준도 있습니다. 설명 분산 비율을 그래프로 그려서 감소가 완만해지는 지점(스크리 플롯의 엘보)을 찾거나, 압축한 데이터로 분류기를 학습해서 **성능이 유지되는 최소 개수**를 찾는 방법입니다. 후자는 12.3절에서 해 봅니다.

### 12.2.6 압축, 복원, 노이즈 제거

PCA로 줄인 데이터는 `inverse_transform`으로 원래 차원으로 복원할 수 있습니다. 버린 주성분의 정보는 사라지므로 완벽한 복원은 아니고, 남긴 주성분이 많을수록 원본에 가깝습니다. 학습 데이터로 PCA를 학습하고 테스트 데이터를 줄였다 복원해서 평균 제곱 오차를 확인해 봅니다.

```python
from sklearn.model_selection import train_test_split

Xtr, Xte, ytr, yte = train_test_split(Xd, yd, test_size=0.25, random_state=0, stratify=yd)

print("주성분 수  저장 비율  복원 오차(MSE)")
for k in [5, 10, 20, 29, 40]:
    p = PCA(n_components=k).fit(Xtr)
    restored = p.inverse_transform(p.transform(Xte))
    print(f"{k:8d}  {k / 64:8.2f}  {((Xte - restored) ** 2).mean():12.3f}")
```

```text
주성분 수  저장 비율  복원 오차(MSE)
       5      0.08         8.722
      10      0.16         5.053
      20      0.31         2.099
      29      0.45         0.897
      40      0.62         0.239
```

주성분 29개(원래 크기의 45%)만으로도 오차가 1 이하로 작습니다. 이미지 압축의 원리가 바로 이것입니다. 다만 주성분 행렬 자체도 저장해야 하므로, 샘플 수가 충분히 많을 때 이득이 됩니다.

이 성질을 거꾸로 이용하면 **노이즈 제거**가 됩니다. 이미지의 의미 있는 변화는 소수의 주성분에 몰려 있고, 무작위 잡음은 모든 방향에 고르게 퍼져 있습니다. 주성분 몇 개만 남기면 잡음의 대부분을 버리게 됩니다. 테스트 이미지에 가우시안 잡음을 더한 뒤 줄였다 복원해서, **깨끗한 원본과의 오차**가 어떻게 달라지는지 봅니다.

```python
rng = np.random.default_rng(0)
Xte_noisy = Xte + rng.normal(scale=4.0, size=Xte.shape)
print("잡음을 더한 데이터의 오차(MSE):", round(((Xte_noisy - Xte) ** 2).mean(), 3))

print("남긴 주성분 수  복원 후 오차(MSE)")
for k in [5, 10, 15, 20, 30, 40]:
    p = PCA(n_components=k).fit(Xtr)
    denoised = p.inverse_transform(p.transform(Xte_noisy))
    print(f"{k:12d}  {((denoised - Xte) ** 2).mean():14.3f}")
```

```text
잡음을 더한 데이터의 오차(MSE): 15.868
남긴 주성분 수  복원 후 오차(MSE)
           5           9.980
          10           7.541
          15           6.948
          20           7.068
          30           8.331
          40          10.185
```

잡음이 섞인 데이터의 오차는 15.9인데, 주성분 15개만 남기고 복원하면 6.9로 절반 이하로 줄어듭니다. 그러나 너무 적게 남기면(5개) 신호까지 잃어서 오차가 늘고, 너무 많이 남기면(40개) 잡음이 다시 들어와서 오차가 늘어납니다. 개수가 하이퍼파라미터인 셈입니다. 또한 잡음이 없는 이미지의 오차 역시 0이 아니므로, 노이즈 제거는 "원본을 완벽하게 되살린다"가 아니라 "잡음의 일부를 덜어낸다"는 정도로 이해해야 합니다.

## 12.3 손글씨 숫자를 2차원으로 줄여 보기

64차원의 숫자 이미지를 2개의 주성분으로 줄여서, 2차원 평면에 점으로 찍어 보겠습니다. PCA는 레이블을 전혀 쓰지 않지만, 점의 색깔을 정답 숫자로 칠하면 데이터의 구조가 얼마나 드러나는지 확인할 수 있습니다.

```python
import matplotlib.pyplot as plt

Z_pca = PCA(n_components=2).fit_transform(Xd)
print(Z_pca.shape)

sc = plt.scatter(Z_pca[:, 0], Z_pca[:, 1], c=yd, cmap="tab10", s=8)
plt.colorbar(sc, label="digit")
plt.xlabel("PC1")
plt.ylabel("PC2")
plt.title("Digits: PCA 2D")
plt.show()
```

```text
(1797, 2)
```

산점도를 그려 보면 숫자 0, 4, 6은 평면의 가장자리에서 비교적 따로 모여 있지만, 나머지 숫자들은 가운데에서 많이 겹칩니다. 2개의 주성분이 설명하는 분산이 28.5%뿐이니 당연한 결과입니다. 2차원으로 줄인 데이터의 분류 성능을 정확히 숫자로 확인해 보겠습니다. 주성분 개수를 바꿔 가며 k-최근접 이웃 분류기의 테스트 정확도를 비교합니다. `Pipeline`을 쓰면 PCA가 학습 데이터에만 맞춰지도록 보장할 수 있습니다.

```python
from sklearn.pipeline import make_pipeline
from sklearn.neighbors import KNeighborsClassifier

print("주성분 수  테스트 정확도")
for k in [2, 5, 10, 20, 30, None]:
    steps = [PCA(n_components=k)] if k else []
    model = make_pipeline(*steps, KNeighborsClassifier()).fit(Xtr, ytr)
    label = k if k else "전체(64)"
    print(f"{str(label):>8s}  {model.score(Xte, yte):10.3f}")
```

```text
주성분 수  테스트 정확도
       2       0.618
       5       0.913
      10       0.967
      20       0.976
      30       0.980
  전체(64)       0.980
```

결과를 정리하면 다음과 같습니다.

- 2차원만으로는 정확도가 61.8%에 그칩니다. 시각화에는 충분해도 분류에는 부족합니다.
- 주성분 10개로 이미 96.7%에 도달해, 64개 전부를 쓴 98.0%에 거의 가깝습니다. 입력 차원이 6분의 1로 줄었는데 성능은 1%p 남짓 줄었을 뿐입니다.
- 주성분 30개부터는 전체를 쓴 것과 같은 성능입니다.

이처럼 **차원 축소 후 성능 변화를 보면 "정보가 실제로 몇 차원에 담겨 있는가"를 가늠할 수 있습니다.** 테스트 세트가 작으면 소수점 둘째 자리의 차이는 의미가 없으므로 교차 검증으로 확인하는 편이 안전합니다.

## 12.4 t-SNE와 UMAP

PCA는 선형 변환이라서 곡면처럼 휘어진 구조나 복잡한 군집을 평면에 펴지 못합니다. 위의 숫자 산점도에서도 대부분의 숫자가 겹쳤습니다. 이럴 때 시각화용으로 많이 쓰이는 **t-SNE(t-distributed Stochastic Neighbor Embedding)**는 다른 철학을 씁니다.

### 12.4.1 t-SNE의 개념

t-SNE는 고차원에서 **서로 가까운 점은 저차원에서도 가깝게** 놓이도록 점들의 위치를 조정합니다. 개념은 다음과 같습니다.

1. 고차원 공간에서 각 점에 대해 "가까운 이웃일 확률"을 정의합니다. 가까운 이웃은 높은 확률, 먼 점은 거의 0입니다.
2. 저차원 평면에 점들을 임의로(또는 PCA 결과로) 배치하고, 같은 방식으로 이웃 확률을 정의합니다.
3. 고차원의 이웃 확률과 저차원의 이웃 확률이 최대한 같아지도록 점들의 위치를 경사 하강법으로 옮깁니다.

PCA가 "전체 분산을 가장 많이 보존하는 축"을 찾았다면, t-SNE는 "각 점 주변의 이웃 관계"를 보존하려 합니다. 그래서 멀리 있는 점 사이의 관계는 신경 쓰지 않습니다.

`sklearn.manifold.TSNE`로 같은 숫자 데이터를 줄여 봅니다. 가장 중요한 하이퍼파라미터는 **`perplexity`**입니다. 각 점이 이웃으로 고려하는 점의 대략적인 개수를 조절하며, 기본값은 30입니다.

```python
from sklearn.manifold import TSNE

tsne = TSNE(n_components=2, perplexity=30, random_state=0)
Z_tsne = tsne.fit_transform(Xd)
print(Z_tsne.shape)
print("최종 KL 발산:", round(tsne.kl_divergence_, 3))
```

```text
(1797, 2)
최종 KL 발산: 0.754
```

`kl_divergence_`는 고차원과 저차원의 이웃 확률 분포가 얼마나 다른지를 재는 값으로, 작을수록 이웃 관계를 잘 보존했다는 뜻입니다. 다만 `perplexity`가 다른 결과끼리 이 값을 비교해서 좋고 나쁨을 판단할 수는 없습니다.

PCA와 같은 방식으로 산점도를 그립니다.

```python
sc = plt.scatter(Z_tsne[:, 0], Z_tsne[:, 1], c=yd, cmap="tab10", s=8)
plt.colorbar(sc, label="digit")
plt.title("Digits: t-SNE 2D")
plt.show()
```

PCA의 산점도에서는 겹쳐 있던 숫자들이 t-SNE에서는 거의 열 개의 분명한 덩어리로 갈라집니다. 숫자 1과 7처럼 일부 숫자는 두세 개의 섬으로 나뉘어 나타나기도 합니다(필기 모양이 여러 가지라는 뜻일 수 있습니다). 이 인상을 숫자로도 확인합니다. `trustworthiness`는 저차원에서 이웃이라고 여겨진 점들이 원래 공간에서도 이웃이었는지를 0~1로 재는 지표입니다. 같은 임베딩에 대해 k-최근접 이웃 분류기의 교차 검증 정확도도 함께 봅니다.

```python
from sklearn.manifold import trustworthiness
from sklearn.model_selection import cross_val_score

for name, Z in [("PCA", Z_pca), ("t-SNE", Z_tsne)]:
    trust = trustworthiness(Xd, Z, n_neighbors=10)
    acc = cross_val_score(KNeighborsClassifier(), Z, yd, cv=5).mean()
    print(f"{name:6s}  trustworthiness={trust:.3f}  2차원 kNN 정확도={acc:.3f}")
```

```text
PCA     trustworthiness=0.830  2차원 kNN 정확도=0.603
t-SNE   trustworthiness=0.993  2차원 kNN 정확도=0.976
```

t-SNE가 이웃 관계를 훨씬 잘 보존했고, 2차원에서의 분류 정확도도 PCA의 60%에서 98%까지 올라갔습니다. (여기서의 정확도는 임베딩이 **모든 데이터**를 보고 만들어졌기 때문에 일반화 성능이 아니라 "2차원에서 구조가 얼마나 분리되어 보이는가"를 재는 값으로만 해석해야 합니다.)

### 12.4.2 t-SNE 결과를 해석할 때의 주의점

t-SNE는 예쁜 그림을 그려 주지만 **그림에서 읽어서는 안 되는 것**이 많습니다. 시각화에 익숙하지 않은 사람이 가장 많이 오해하는 부분입니다.

- **덩어리 사이의 거리는 의미가 없습니다.** 가까운 점들이 가깝게 놓이는 것만 보존하므로, 두 덩어리가 멀거나 가깝게 그려졌다고 해서 원래 공간에서도 그렇다고 말할 수 없습니다.
- **덩어리의 크기와 밀도도 의미가 없습니다.** t-SNE는 밀도 차이를 평준화하는 경향이 있어서, 큰 덩어리가 실제로 더 많은 샘플이나 더 큰 분산을 뜻하지 않습니다.
- **축의 값에는 의미가 없습니다.** PCA의 축은 원래 특성의 조합으로 해석할 수 있지만, t-SNE의 두 축은 해석할 대상이 아닙니다.
- **실행마다 그림이 달라질 수 있습니다.** 초기 위치와 최적화 과정의 무작위성 때문입니다. 아래에서 확인합니다.
- **`perplexity`에 따라 모양이 달라집니다.** 너무 작으면 잡음 같은 작은 덩어리가 많이 생기고, 너무 크면 구조가 뭉개집니다. 보통 5~50 사이에서 여러 값을 시도해 봅니다.
- **새 데이터에 적용할 수 없습니다.** `TSNE`에는 `transform`이 없고 `fit_transform`만 있습니다. 학습한 모델을 재사용해서 새 샘플을 같은 평면에 놓을 수 없으므로, 모델의 입력 특성으로 쓰기에는 부적합하고 **탐색과 시각화용**입니다.
- **t-SNE 그림 속 덩어리만 보고 군집 개수를 단정하지 마세요.** 덩어리 개수는 `perplexity`와 초기값에 영향을 받습니다.

무작위 초기화(`init="random"`)로 시드만 바꿔 세 번 그려 보면, 배치는 완전히 달라지지만 이웃 관계의 품질은 거의 같다는 것을 알 수 있습니다. (최신 scikit-learn에서 `TSNE`의 `init` 기본값은 `'pca'`라서 시드를 바꿔도 결과가 거의 같을 수 있습니다. 여기서는 효과를 보이려고 일부러 무작위 초기화를 씁니다.)

```python
print("시드  숫자0 중심    숫자1 중심    trustworthiness")
for seed in [0, 1, 2]:
    Z = TSNE(init="random", random_state=seed).fit_transform(Xd)
    c0, c1 = Z[yd == 0].mean(axis=0), Z[yd == 1].mean(axis=0)
    trust = trustworthiness(Xd, Z, n_neighbors=10)
    print(f"{seed:4d}  ({c0[0]:5.0f},{c0[1]:5.0f})  ({c1[0]:5.0f},{c1[1]:5.0f})  {trust:.3f}")
```

```text
시드  숫자0 중심    숫자1 중심    trustworthiness
   0  (    3,  -59)  (   12,    4)  0.993
   1  (  -13,   58)  (   16,   -8)  0.992
   2  (   55,   -0)  (  -13,   11)  0.993
```

숫자 0과 1의 중심 좌표가 시드마다 전혀 다른 곳에 있습니다. 그림이 회전하거나 뒤집혀도 이웃 관계는 같기 때문에 이 변화는 문제가 아닙니다. 그러나 "0번 숫자는 왼쪽 아래에 있다"처럼 좌표 자체에 의미를 부여하면 안 됩니다.

### 12.4.3 UMAP

**UMAP(Uniform Manifold Approximation and Projection)**은 t-SNE와 비슷한 용도로 널리 쓰이는 비선형 차원 축소 기법입니다. 일반적으로 t-SNE보다 빠르고, 전체적인 구조를 어느 정도 더 잘 보존하는 편이며, 학습한 모델로 새 데이터를 변환할 수 있습니다. scikit-learn에는 포함되어 있지 않고, 별도의 `umap-learn` 패키지로 설치합니다. 이 책에서는 이름과 용도만 소개합니다.

UMAP에도 t-SNE와 같은 해석상의 주의가 대부분 적용됩니다. 덩어리 사이의 거리나 크기를 곧이곧대로 읽지 말고, 하이퍼파라미터(이웃 개수 등)와 시드를 바꿔 가며 같은 구조가 안정적으로 나타나는지 확인한 뒤에 결론을 내리세요. 시각화에서 보인 군집은 **가설**일 뿐이고, 군집이 실제로 의미가 있는지는 11장에서 본 방법이나 도메인 지식으로 따로 검증해야 합니다.

## 12.5 이상 탐지: IsolationForest

차원 축소와는 다른 주제이지만 비지도학습의 또 다른 중요한 응용으로 **이상 탐지(anomaly detection)**를 짧게 소개합니다. 신용카드 부정 사용이나 설비 고장 징후처럼, 이상 사례는 드물고 정답 레이블을 모으기 어려운 경우가 많습니다. 이럴 때 "정상 데이터와 많이 다른 샘플"을 찾아내는 비지도 방법이 유용합니다.

**IsolationForest**는 이런 원리로 동작합니다. 임의의 특성과 임의의 분할점으로 데이터를 반복해서 쪼개면, 정상 샘플은 빽빽하게 모여 있어서 하나로 고립시키기까지 여러 번 쪼개야 하지만, 외톨이 이상치는 몇 번만 쪼개도 혼자 남습니다. 이렇게 **고립시키는 데 필요한 분할 횟수가 적을수록 이상치**라고 판단합니다. 결정 트리를 여러 개(숲) 만들어서 평균을 냅니다.

정상 샘플 300개와 사방에 흩어진 이상치 15개를 섞은 데이터로 확인해 봅니다.

```python
from sklearn.ensemble import IsolationForest

rng = np.random.default_rng(0)
normal = rng.normal(0, 1, size=(300, 2))
anomal = rng.uniform(-6, 6, size=(15, 2))
Xa = np.vstack([normal, anomal])

iso = IsolationForest(n_estimators=100, contamination=0.05, random_state=0).fit(Xa)
pred = iso.predict(Xa)                  # 정상 1, 이상치 -1

print("이상치로 판정한 샘플 수:", int((pred == -1).sum()))
print("정상 300개 중 이상치로 판정:", int((pred[:300] == -1).sum()))
print("추가한 이상치 15개 중 이상치로 판정:", int((pred[300:] == -1).sum()))

scores = iso.score_samples(Xa)          # 낮을수록 이상
print("평균 점수  정상:", scores[:300].mean().round(3), " 이상치:", scores[300:].mean().round(3))
print("(0,0)과 (5,5)의 판정:", iso.predict([[0, 0], [5, 5]]))
```

```text
이상치로 판정한 샘플 수: 16
정상 300개 중 이상치로 판정: 4
추가한 이상치 15개 중 이상치로 판정: 12
평균 점수  정상: -0.418  이상치: -0.654
(0,0)과 (5,5)의 판정: [ 1 -1]
```

사용법은 다른 추정기와 비슷하지만, 몇 가지 알아 둘 점이 있습니다.

- `predict`는 정상이면 `1`, 이상치면 `-1`을 돌려줍니다. DBSCAN의 노이즈 레이블 `-1`과 닮았지만 뜻은 다릅니다.
- `score_samples`는 이상 점수를, `decision_function`은 판정 기준선을 0으로 맞춘 점수를 줍니다. 두 값 모두 **낮을수록 이상치**에 가깝습니다. 임계값을 직접 정하고 싶다면 이 점수를 사용합니다.
- `contamination`은 데이터에 이상치가 대략 몇 퍼센트 있는지에 대한 가정입니다. 이 값으로 판정 기준선이 정해지므로 결과에 큰 영향을 줍니다. 기본값 `'auto'`는 데이터와 무관하게 정해진 기준선을 씁니다.
- 위 결과처럼 정상 분포의 가장자리에 있는 샘플 일부는 이상치로, 이상치 가운데 정상 영역에 우연히 떨어진 것은 정상으로 판정되기도 합니다. 정답이 없는 비지도 방식의 한계이니, 탐지된 샘플은 사람이 검토해서 확인하는 후보 목록으로 쓰는 것이 좋습니다.

이상 탐지에는 이 밖에도 `OneClassSVM`, `LocalOutlierFactor` 등이 있습니다. 모두 `sklearn`에 포함되어 있으니 필요할 때 찾아보세요.

## 요약

- 차원이 높아지면 **점들 사이의 거리가 비슷해지고 공간이 비어서**, 거리 기반 알고리즘의 성능이 떨어지고 과대적합이 쉬워집니다(차원의 저주).
- 차원 축소는 **시각화, 압축, 노이즈 제거, 학습 안정화**를 위해 쓰며, 원래 특성을 조합해 새 특성을 만드는 방식(특성 추출)이 대표적입니다.
- **PCA**는 데이터를 중심으로 옮긴 뒤 공분산 행렬의 고유벡터(분산이 큰 방향)를 구하고 그 방향으로 투영합니다. 고유값이 그 방향의 분산이며, `eigh`로 NumPy에서도 직접 구현할 수 있습니다. 고유벡터의 부호는 임의입니다.
- `PCA`의 주요 속성은 `components_`, `explained_variance_ratio_`, `mean_`입니다. 특성의 단위가 다르면 **먼저 표준화**해야 합니다.
- 주성분 개수는 누적 설명 분산 비율(`PCA(n_components=0.95)`)이나 압축 후 모델 성능으로 정합니다. `inverse_transform`으로 복원하면 압축과 노이즈 제거에 쓸 수 있습니다.
- 손글씨 숫자 64차원을 2차원으로 줄이면 PCA로는 대부분의 숫자가 겹치지만, 주성분 10개만으로도 분류 성능은 크게 줄지 않습니다.
- **t-SNE**는 가까운 이웃 관계를 보존하는 비선형 시각화 기법입니다. 군집을 잘 분리해서 보여 주지만, 덩어리 사이의 거리와 크기, 축의 값은 의미가 없고 `perplexity`와 시드에 따라 그림이 변하며, 새 데이터에는 적용할 수 없습니다. **UMAP**도 비슷한 용도의 기법이며, 같은 해석상의 주의가 필요합니다.
- **IsolationForest**는 무작위 분할로 쉽게 고립되는 샘플을 이상치로 판정하는 비지도 이상 탐지 알고리즘입니다. `predict`는 정상 `1`, 이상 `-1`을 줍니다.
