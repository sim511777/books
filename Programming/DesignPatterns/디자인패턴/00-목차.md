# C#으로 배우는 디자인 패턴

[다음: 1장. 디자인 패턴이란 무엇인가 ▶](ch01-디자인패턴이란.md)

---

객체지향 언어 경험이 있고 소프트웨어 설계 패턴을 처음 배우는 사람을 위한 디자인 패턴 입문서입니다.
GoF(Gang of Four)가 정리한 23가지 고전 디자인 패턴을 생성·구조·행동 세 갈래로 나누어 다루며,
모든 예제 코드는 C#으로 작성했습니다.

각 패턴 장은 "문제 상황 → 패턴 설명 → C# 예제 코드 → 언제 사용하는가 → 요약 → 연습문제" 순서로
구성되어 있으며, 필요한 곳에는 구조를 보여주는 다이어그램을 함께 실었습니다.

## 학습 방법 제안

1. 각 패턴의 "문제 상황"에 나온 나쁜 코드를 먼저 이해하고, 왜 그 코드가 문제인지 스스로 설명해 보세요.
2. C# 예제 코드를 직접 타이핑하고 실행하며, 패턴을 적용하기 전/후의 차이를 비교해 보세요.
3. 장 끝의 연습문제를 풀어보면서 이해도를 점검하세요.
4. 구조가 비슷한 패턴(예: 전략 vs 상태, 데코레이터 vs 프록시, 어댑터 vs 퍼사드)은 각 장에서 비교표를 통해 차이를 짚었으니 함께 읽어보세요.
5. 25장까지 마친 뒤에는 부록의 "패턴 선택 가이드"를 실전에서 어떤 패턴을 쓸지 판단할 때 참고용으로 활용하세요.
