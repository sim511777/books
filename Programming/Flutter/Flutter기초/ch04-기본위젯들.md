# 4장. 기본 위젯들

3장에서 "모든 것은 위젯"이라는 Flutter의 철학과, 위젯들이 `child`·`children`으로 서로를 감싸며 트리를 이룬다는 것을 배웠습니다. 또한 `StatelessWidget`과 `StatefulWidget`의 차이, `build(BuildContext context)`가 위젯 트리를 화면으로 변환하는 과정도 살펴보았습니다.

이번 장에서는 그 트리를 실제로 채워 넣을 때 가장 자주 쓰이는 기본 위젯들을 하나씩 익힙니다. 텍스트를 표시하는 `Text`, 크기와 여백과 배경을 가진 범용 상자인 `Container`, 가로·세로로 자식을 배치하는 `Row`와 `Column`, 이미지를 보여주는 `Image`, 아이콘을 표시하는 `Icon`, 그리고 앱의 기본 뼈대를 잡아주는 `Scaffold`와 `AppBar`까지 다룹니다. 장의 마지막에서는 이 위젯들을 조합해 간단한 프로필 카드 화면을 직접 만들어 보겠습니다.

## 4.1 Text: 글자를 표시하는 위젯

`Text`는 화면에 문자열을 표시하는 가장 기본적인 위젯입니다.

```dart
Text(
  '안녕하세요, Flutter!',
  style: TextStyle(
    fontSize: 20,
    color: Colors.blue,
  ),
)
```

`Text`의 첫 번째 위치 매개변수는 표시할 문자열입니다. `style` 매개변수에 `TextStyle` 객체를 전달하면 글자의 모양을 세밀하게 조정할 수 있습니다. `TextStyle`에서 자주 쓰이는 속성은 다음과 같습니다.

- `fontSize`: 글자 크기 (논리 픽셀 단위, `double`)
- `color`: 글자 색상 (`Color` 타입, `Colors.blue`처럼 `Colors` 클래스가 제공하는 상수를 주로 사용)
- `fontWeight`: 글자 굵기 (`FontWeight.bold`, `FontWeight.w300` 등)
- `fontStyle`: 이탤릭 여부 (`FontStyle.italic`)
- `letterSpacing`, `height`: 자간, 줄 간격

`Text` 위젯 자체에도 정렬이나 줄 수 제한과 관련된 매개변수가 있습니다.

```dart
Text(
  '이 문장은 매우 길어질 수 있으므로 두 줄까지만 표시하고 나머지는 말줄임표로 처리합니다.',
  textAlign: TextAlign.center,
  maxLines: 2,
  overflow: TextOverflow.ellipsis,
)
```

`maxLines`로 최대 줄 수를 지정하고, `overflow: TextOverflow.ellipsis`를 함께 지정하면 글자가 넘칠 때 자동으로 "..." 처리가 됩니다. `Text`는 `StatelessWidget`으로 구현되어 있으며, 표시할 문자열이나 스타일이 바뀌지 않는 한 스스로 다시 그려지지 않는다는 것을 3장에서 배운 개념으로 확인할 수 있습니다.

## 4.2 Container: 크기·여백·배경을 가진 범용 상자

`Container`는 Flutter에서 가장 많이 쓰이는 위젯 중 하나입니다. 하나의 자식을 감싸면서 크기, 여백, 배경색, 테두리, 정렬 등 다양한 시각적 속성을 한 번에 지정할 수 있는 "만능 상자" 역할을 합니다.

```dart
Container(
  width: 200,
  height: 100,
  color: Colors.amber,
  padding: const EdgeInsets.all(8),
  child: const Text('컨테이너 안의 텍스트'),
)
```

주요 매개변수를 정리하면 다음과 같습니다.

- `width`, `height`: 상자의 너비와 높이 (`double`). 지정하지 않으면 자식의 크기나 부모의 제약에 따라 결정됩니다.
- `color`: 배경색. 단, `decoration`을 함께 지정하면 `color`를 직접 쓸 수 없고 `BoxDecoration`의 `color` 속성으로 지정해야 합니다.
- `padding`: 자식과 상자 테두리 사이의 안쪽 여백. `EdgeInsets` 타입을 사용합니다.
- `margin`: 상자 바깥쪽, 다른 위젯과의 간격.
- `alignment`: 자식을 상자 안 어디에 배치할지 (`Alignment.center` 등).
- `child`: 이 상자가 감싸는 자식 위젯 (하나만 가능).

`padding`과 `margin`에 자주 쓰이는 `EdgeInsets`는 다음과 같은 생성자들을 제공합니다.

```dart
EdgeInsets.all(8)                              // 상하좌우 모두 8
EdgeInsets.symmetric(horizontal: 16, vertical: 8) // 좌우 16, 상하 8
EdgeInsets.only(left: 8, top: 4, right: 8, bottom: 4) // 각각 지정
```

배경색만이 아니라 둥근 모서리, 그림자, 그라데이션 같은 더 풍부한 배경 효과가 필요하면 `decoration` 매개변수에 `BoxDecoration`을 지정합니다.

```dart
Container(
  padding: const EdgeInsets.all(16),
  decoration: BoxDecoration(
    color: Colors.white,
    borderRadius: BorderRadius.circular(12),
    boxShadow: const [
      BoxShadow(color: Colors.black26, blurRadius: 6, offset: Offset(0, 3)),
    ],
  ),
  child: const Text('둥근 모서리와 그림자가 있는 카드'),
)
```

`Container`는 이름 그대로 "담는 그릇"입니다. 이 장의 마지막 실전 예제에서 프로필 카드의 배경, 여백, 모서리를 꾸미는 데 바로 이 `Container`를 사용할 것입니다. `BoxDecoration`을 활용한 더 다양한 스타일링 기법은 9장 "테마와 스타일링"에서 이어서 다룹니다.

## 4.3 Row와 Column: 가로·세로 배치 맛보기

지금까지는 자식을 하나만 가지는 위젯들을 살펴봤습니다. 여러 위젯을 나란히 배치하려면 `Row`(가로 방향)와 `Column`(세로 방향)을 사용합니다. 둘 다 `children` 매개변수에 위젯 리스트를 전달받습니다.

```dart
Row(
  mainAxisAlignment: MainAxisAlignment.spaceEvenly,
  children: const [
    Icon(Icons.star),
    Icon(Icons.star),
    Icon(Icons.star),
  ],
)
```

```dart
Column(
  crossAxisAlignment: CrossAxisAlignment.start,
  children: const [
    Text('제목'),
    Text('부제목'),
  ],
)
```

`Row`는 자식들을 왼쪽에서 오른쪽으로, `Column`은 위에서 아래로 순서대로 배치합니다. `mainAxisAlignment`는 배치 방향(주축)을 따라 자식들을 어떻게 정렬할지, `crossAxisAlignment`는 그 반대 방향(교차축)으로 어떻게 정렬할지를 결정합니다. 지금은 "가로로 늘어놓고 싶으면 `Row`, 세로로 쌓고 싶으면 `Column`, 자식은 `children` 리스트로 전달한다"는 정도만 기억해 두면 충분합니다. 자식들의 공간 배분, 정렬 옵션의 전체 목록, `Expanded`나 `Flexible`을 이용한 유연한 크기 조절 등 레이아웃의 본격적인 내용은 5장 "레이아웃 시스템"에서 자세히 다룹니다.

## 4.4 Image: 이미지 표시하기

Flutter에서 이미지를 화면에 표시할 때 가장 많이 쓰는 위젯이 `Image`입니다. 이미지의 출처에 따라 서로 다른 생성자를 사용합니다.

### 로컬 에셋 이미지: Image.asset

프로젝트에 포함된 이미지 파일을 표시할 때는 `Image.asset`을 사용합니다.

```dart
Image.asset('assets/images/profile.png')
```

`Image.asset`을 사용하려면 먼저 이미지 파일을 프로젝트의 `assets` 폴더 같은 곳에 넣고, `pubspec.yaml`에 해당 경로를 등록해야 합니다.

```yaml
flutter:
  uses-material-design: true
  assets:
    - assets/images/profile.png
```

`pubspec.yaml`에 등록되지 않은 경로를 `Image.asset`에 넘기면 앱이 해당 파일을 찾지 못해 오류가 발생하므로, 이미지가 보이지 않을 때 가장 먼저 확인해야 할 부분입니다.

### 네트워크 이미지: Image.network

인터넷 상의 이미지를 URL로 불러와 표시할 때는 `Image.network`를 사용합니다.

```dart
Image.network('https://example.com/images/avatar.png')
```

`Image.network`는 이미지를 내려받는 동안 시간이 걸리므로, 이 다운로드 자체는 Flutter 내부적으로 비동기로 처리됩니다. 로딩 중이나 실패 시의 처리를 세밀하게 다루는 방법(`loadingBuilder`, `errorBuilder`)이나, 네트워크 요청을 직접 다루는 방법은 15장 "네트워크 통신"에서 다시 다룹니다.

`Image` 위젯 공통으로 자주 쓰이는 매개변수는 다음과 같습니다.

- `width`, `height`: 이미지의 표시 크기.
- `fit`: 지정된 영역에 이미지를 어떻게 맞출지 (`BoxFit.cover`, `BoxFit.contain` 등).

```dart
Image.asset(
  'assets/images/profile.png',
  width: 100,
  height: 100,
  fit: BoxFit.cover,
)
```

## 4.5 Icon: 아이콘 표시하기

Flutter는 Material Design 아이콘 세트를 기본으로 내장하고 있으며, `Icon` 위젯으로 손쉽게 사용할 수 있습니다.

```dart
Icon(
  Icons.favorite,
  color: Colors.red,
  size: 24,
)
```

`Icons` 클래스는 `Icons.home`, `Icons.settings`, `Icons.favorite`, `Icons.person`처럼 미리 정의된 아이콘 상수들을 제공합니다. `Icon` 위젯의 매개변수는 다음과 같습니다.

- 첫 번째 위치 매개변수: `IconData` 타입의 아이콘 (예: `Icons.favorite`)
- `color`: 아이콘 색상
- `size`: 아이콘 크기 (논리 픽셀 단위)

아이콘은 흔히 버튼이나 리스트 항목, 앱바 등에서 텍스트와 함께 조합되어 사용됩니다. 아이콘을 누를 수 있는 버튼으로 만들고 싶다면 `IconButton`을 사용하는데, 이는 7장 "사용자 입력과 이벤트 처리"에서 다룹니다.

## 4.6 Scaffold와 AppBar: 앱의 기본 뼈대

지금까지 살펴본 `Text`, `Container`, `Row`, `Column`, `Image`, `Icon`은 화면의 "내용물"을 만드는 위젯입니다. 하지만 실제 앱에는 상단 앱바, 하단 내비게이션, 오른쪽 아래에 떠 있는 액션 버튼처럼 정형화된 구조가 필요할 때가 많습니다. 이런 공통 뼈대를 미리 만들어 제공하는 위젯이 바로 `Scaffold`입니다.

`Scaffold`는 Material Design 앱이 흔히 갖는 화면 구조의 "틀"을 제공하며, 여러 개의 이름 있는 슬롯(매개변수)에 위젯을 채워 넣는 방식으로 사용합니다. 3장에서 위젯 트리를 설명할 때 이미 `Scaffold`가 `appBar`, `body`, `floatingActionButton` 같은 여러 슬롯을 갖는다고 언급했는데, 여기서 각 슬롯을 자세히 살펴보겠습니다.

```dart
Scaffold(
  appBar: AppBar(
    title: const Text('내 프로필'),
    actions: [
      IconButton(
        icon: const Icon(Icons.settings),
        onPressed: () {},
      ),
    ],
  ),
  body: const Center(
    child: Text('본문 내용'),
  ),
  floatingActionButton: FloatingActionButton(
    onPressed: () {},
    child: const Icon(Icons.add),
  ),
)
```

`Scaffold`의 대표적인 슬롯들은 다음과 같습니다.

- `appBar`: 화면 상단에 표시되는 앱바. 보통 `AppBar` 위젯을 전달합니다.
- `body`: 화면의 주된 내용을 담는 영역. 이 자리에 지금까지 배운 `Text`, `Container`, `Column` 등 어떤 위젯이든 들어갈 수 있습니다.
- `floatingActionButton`: 화면 오른쪽 아래에 떠 있는 원형 버튼.
- `bottomNavigationBar`: 화면 하단의 내비게이션 바. 8장 "네비게이션과 라우팅"에서 다룹니다.
- `drawer`: 화면 왼쪽에서 슬라이드로 나타나는 서랍형 메뉴.

`AppBar`는 `Scaffold`의 `appBar` 슬롯에 흔히 사용되는 위젯으로, 화면 제목이나 뒤로가기 버튼, 우측 액션 아이콘들을 배치하는 상단 바입니다.

- `title`: 앱바 중앙(또는 좌측)에 표시할 위젯. 보통 `Text`를 사용합니다.
- `actions`: 앱바 오른쪽 끝에 나열할 위젯 리스트. 보통 `IconButton` 등을 사용합니다.
- `leading`: 앱바 왼쪽 끝에 표시할 위젯. 지정하지 않으면 이전 화면이 있을 경우 자동으로 뒤로가기 버튼이 표시됩니다.
- `backgroundColor`: 앱바의 배경색.

`Scaffold`와 `AppBar`를 사용하면 "화면 상단에는 제목이, 그 아래에는 내용이, 오른쪽 아래에는 액션 버튼이 있는" 전형적인 앱 구조를 별도의 레이아웃 계산 없이 손쉽게 만들 수 있습니다. 이 구조는 앞으로 이 책의 거의 모든 예제 화면에서 반복적으로 등장할 것입니다.

## 4.7 실전 예제: 프로필 카드 화면 만들기

지금까지 배운 위젯들을 모두 조합해서 간단한 프로필 카드 화면을 만들어 보겠습니다. 상단에는 `AppBar`가 있고, 화면 중앙에는 프로필 이미지, 이름, 소개 문구, 아이콘으로 표시한 통계 정보를 담은 카드가 놓이는 구조입니다.

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const ProfileCardApp());
}

class ProfileCardApp extends StatelessWidget {
  const ProfileCardApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: '프로필 카드',
      home: Scaffold(
        appBar: AppBar(
          title: const Text('내 프로필'),
        ),
        body: Center(
          child: Container(
            width: 300,
            padding: const EdgeInsets.all(20),
            decoration: BoxDecoration(
              color: Colors.white,
              borderRadius: BorderRadius.circular(16),
              boxShadow: const [
                BoxShadow(
                  color: Colors.black26,
                  blurRadius: 10,
                  offset: Offset(0, 4),
                ),
              ],
            ),
            child: Column(
              mainAxisSize: MainAxisSize.min,
              children: [
                Image.network(
                  'https://example.com/images/avatar.png',
                  width: 96,
                  height: 96,
                  fit: BoxFit.cover,
                ),
                const SizedBox(height: 12),
                const Text(
                  '김민준',
                  style: TextStyle(
                    fontSize: 22,
                    fontWeight: FontWeight.bold,
                  ),
                ),
                const SizedBox(height: 4),
                const Text(
                  'Flutter 앱 개발자',
                  style: TextStyle(
                    fontSize: 14,
                    color: Colors.grey,
                  ),
                ),
                const SizedBox(height: 16),
                Row(
                  mainAxisAlignment: MainAxisAlignment.spaceEvenly,
                  children: const [
                    Icon(Icons.favorite, color: Colors.red, size: 20),
                    Text('좋아요 128'),
                    Icon(Icons.star, color: Colors.amber, size: 20),
                    Text('평점 4.8'),
                  ],
                ),
              ],
            ),
          ),
        ),
      ),
    );
  }
}
```

이 예제의 위젯 트리를 3장에서 배운 방식으로 따라가 보면 다음과 같습니다.

- `MaterialApp`이 `home`으로 `Scaffold`를 감쌉니다.
- `Scaffold`는 `appBar`로 `AppBar`를, `body`로 `Center`를 가집니다.
- `Center`는 카드 모양을 만드는 `Container`를 자식으로 가집니다.
- `Container`는 `decoration`으로 흰색 배경과 둥근 모서리, 그림자를 지정하고, `child`로 `Column`을 가집니다.
- `Column`은 `children`으로 `Image.network`, `SizedBox`(위젯 사이 여백을 만드는 위젯), 이름과 소개를 표시하는 `Text` 두 개, 그리고 통계를 나열하는 `Row`를 가집니다.
- 그 `Row`는 다시 `Icon`과 `Text`를 번갈아 `children`으로 가집니다.

이처럼 복잡해 보이는 화면도 결국 3장에서 배운 "부모가 child/children으로 자식을 감싸는" 원리를 반복적으로 적용한 결과에 불과합니다. `SizedBox(height: 12)`처럼 폭이나 높이만 지정하고 자식이 없는 위젯은 순수하게 빈 공간(여백)을 만드는 용도로 자주 사용됩니다.

이 화면은 아직 정적입니다. 카드 안의 값들은 한 번 정해지면 바뀌지 않는 `StatelessWidget` 트리로만 구성되어 있기 때문입니다. 만약 좋아요 아이콘을 눌러서 좋아요 숫자가 올라가게 하려면 3장에서 배운 `StatefulWidget`과 `setState()`가 필요합니다. 이 부분은 6장 "상태 관리 기초"와 7장 "사용자 입력과 이벤트 처리"에서 직접 구현해 보겠습니다. 또한 카드의 배치가 화면 크기에 따라 자연스럽게 반응하도록 다듬는 방법은 5장 "레이아웃 시스템"에서 이어집니다.

## 요약

- `Text(문자열, style: TextStyle(...))`은 글자를 표시하는 기본 위젯이며, `fontSize`, `color`, `fontWeight` 등으로 스타일을 지정합니다.
- `Container`는 `width`, `height`, `color`(또는 `decoration`), `padding`, `margin`, `child`를 통해 크기·여백·배경을 가진 범용 상자를 만드는 위젯입니다.
- `Row`(가로)와 `Column`(세로)은 `children` 리스트로 여러 위젯을 나란히 배치합니다. 정렬과 공간 배분의 세부 사항은 5장에서 다룹니다.
- `Image.asset('경로')`는 `pubspec.yaml`에 등록된 로컬 에셋 이미지를, `Image.network('URL')`은 네트워크 이미지를 표시합니다.
- `Icon(Icons.아이콘이름, color: ..., size: ...)`은 Material 아이콘 세트의 아이콘을 표시합니다.
- `Scaffold`는 `appBar`, `body`, `floatingActionButton` 등의 슬롯을 제공하는 앱의 기본 뼈대이며, `AppBar`는 그 상단 바 역할을 하는 위젯으로 `title`, `actions`, `leading` 등을 가집니다.
- 이 기본 위젯들을 3장에서 배운 위젯 트리의 원리(child/children으로 감싸기)에 따라 조합하면 프로필 카드 같은 실제 화면을 만들 수 있습니다.

## 연습문제

1. `Container` 위젯에서 `color`와 `decoration`을 동시에 지정할 수 없는 이유를 문서나 실험을 통해 확인하고, 배경색과 둥근 모서리를 함께 지정하려면 어떻게 해야 하는지 코드로 보이세요.
2. `Image.asset`으로 불러온 이미지가 화면에 나타나지 않을 때 점검해야 할 항목을 최소 두 가지 이상 나열하세요.
3. `EdgeInsets.all(16)`과 `EdgeInsets.symmetric(horizontal: 16, vertical: 8)`의 차이를 설명하고, 각각이 만들어내는 여백을 그림으로 그려 보세요.
4. `Scaffold`의 `appBar`, `body`, `floatingActionButton` 슬롯에 각각 어떤 위젯이 들어갈 수 있는지, 그리고 이 슬롯 구조가 왜 편리한지 3장에서 배운 위젯 트리 개념과 연결지어 설명하세요.
5. 이 장의 프로필 카드 예제를 참고하여, 이름과 소개 문구 대신 자신의 정보를 담고 `Row` 대신 `Column`으로 통계 항목을 세로로 나열하는 새로운 프로필 카드를 작성해 보세요.
