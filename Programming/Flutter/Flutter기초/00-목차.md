# Flutter로 배우는 크로스플랫폼 앱 개발

[다음: 1장. Flutter란 무엇인가 ▶](ch01-Flutter란무엇인가.md)

---

Dart 기반의 크로스플랫폼 UI 툴킷 Flutter 입문서입니다. 이 책은 이 저장소의
[Dart 기초부터 응용까지](../../Languages/Dart/Dart기초/00-목차.md)를 먼저 읽었다고
가정하며, Dart 문법을 다시 설명하지 않고 곧바로 Flutter의 위젯 트리 개념부터 시작합니다.
위젯과 상태 관리 기초부터 레이아웃, 입력·네비게이션, 테마, 리스트, 애니메이션, Form,
비동기 프로그래밍, 네트워크 통신, 로컬 데이터 저장, 플랫폼별 배포, 실전 프로젝트까지
순서대로 다룹니다.

각 장은 개념 설명, Dart/Flutter 예제 코드, 요약, 연습문제로 구성되어 있으며, 필요한 곳에는
이해를 돕는 다이어그램을 함께 실었습니다.

## 학습 방법 제안

1. 이 저장소의 [Dart 기초부터 응용까지](../../Languages/Dart/Dart기초/00-목차.md)를 먼저 읽고 Dart 문법에 익숙해진 뒤 이 책을 시작하세요.

3. 장 끝의 연습문제를 풀어보면서 이해도를 점검하세요.
